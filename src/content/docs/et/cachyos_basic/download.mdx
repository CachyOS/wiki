## ISO allalaadimine

CachyOS ISO on saadaval järgmistest allikatest:

*   [Veebileht](<https://cachyos.org/download>)
*   [SourceForge](<https://sourceforge.net/projects/cachyos-arch/files/>)
*   [CachyOS peegelserver](<https://mirror.cachyos.org/ISO/>)

## ISO terviklikkuse kontrollimine SHA256 abil

:::caution[HOIATUS]
Kontrollige alati ISO terviklikkust, et vältida soovimatuid probleeme paigaldamisel või buutiva meedia loomisel.
:::

**Praegune ISO versioon:** `250824`

**SHA256 räsi:** `0a10af47b009ef459c1ee5f8731f97a3f62c1969df41c1670d53576ccadd0eb6`

<Tabs>

<TabItem label='Windows'>

<Steps>

1. Laadige alla SHA256 räsiga [fail](https://mirror.cachyos.org/ISO/desktop/250824/cachyos-desktop-linux-250824.iso.sha256) **(avage see tekstiredaktoriga, nt Notepadiga).**
2. Avage CMD või PowerShell administraatorina ja [liikuge](<https://www.wikihow.com/Change-Directories-in-Command-Prompt>) kausta, kuhu ISO ja SHA256 failid on salvestatud.
3. Käivitage järgmine käsk:
   ```powershell
   # Näide:
   certUtil -hashfile cachyos-desktop-linux-250824.iso SHA256
   ```
4. Võrrelge certUtil'i räsi väljundit **1. sammus** allalaaditud failis oleva räsiga. Kui need ühtivad, võite CachyOS'i paigaldamisega jätkata.

</Steps>

</TabItem>

<TabItem label='Linux'>

<Steps>

1. Laadige alla SHA256 räsiga [fail](https://mirror.cachyos.org/ISO/desktop/250824/cachyos-desktop-linux-250824.iso.sha256).
2. Avage terminal, liikuge kausta, kus asub `.sha256` fail ja käivitage järgmised käsud:
   ```sh
   # Näide:
   cd Downloads/ || exit
   cat cachyos-desktop-linux-250824.iso.sha256
   # 0a10af47b009ef459c1ee5f8731f97a3f62c1969df41c1670d53576ccadd0eb6
   ```
3. Võrrelge **2. sammu** väljundit ja käivitage järgmine käsk, et kontrollida ISO-faili praegust räsi.
   ```sh
   # Näide:
   sha256sum cachyos-desktop-linux-250824.iso
   ```
4. Kui **2. sammu** ja **3. sammu** räsid ühtivad, võite CachyOS'i paigaldamisega jätkata.

</Steps>

</TabItem>

<TabItem label='macOS'>

<Steps>

## ISO-tõmmise autentsuse kontrollimine (Linux)

Et kontrollida ISO-faili autentsust ja veenduda, et see on tõepoolest ametliku CachyOS'i arendusmeeskonna poolt välja antud:

<Steps>

1. Importige GPG-võti autentsuse kontrollimiseks:

   ```shell
   gpg --keyserver hkps://keys.openpgp.org --recv-key F3B607488DB35A47
   ```

2. Laadige alla ISO-fail ja selle `.sig` signatuurifail ning käivitage järgmine käsk (asendades `full_iso_name.iso` tegeliku ISO-faili nimega):
   ```shell
   gpg --verify full_iso_name.iso.sig full_iso_name.iso
   ```

   Kui saate väljundiks **Good signature** (Hea signatuur), on ISO-fail ehtne:
   ```
   gpg: Signature made dom 24 ago 2025 06:26:23 -03
   gpg:                using RSA key 882DCFE48E2051D48E2562ABF3B607488DB35A47
   gpg: Good signature from "CachyOS <admin@cachyos.org>" [unknown]
   gpg: WARNING: This key is not certified with a trusted signature!
   gpg:          There is no indication that the signature belongs to the owner.
   Primary key fingerprint: 882D CFE4 8E20 51D4 8E25  62AB F3B6 0748 8DB3 5A47
   ```

</Steps>

:::danger
Kui väljundis ei ole teksti **Good signature** (Hea signatuur) või kui võtme ID ei ühti, ärge ISO-tõmmist kasutage. Veenduge, et allalaaditud tõmmis pärineb
seaduslikust CachyOS'i allikast, kuna halb signatuur võib viidata sellele, et ISO-faili on rikutud.
:::
