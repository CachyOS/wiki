:::note[提醒。]
虽然本 wiki 旨在展示 CachyOS 特定信息，但许多内容也适用于 Arch Linux。需要时请随时参考 Arch Wiki 文章，因为它们可以提供额外的背景和详细信息。

[Arch Wiki](https://wiki.archlinux.org/title/Main_page)
:::

以下是一些帮助您充分利用 CachyOS wiki 的技巧，包括一些容易忽略的功能。

- **提供反馈：** 如果您有建议或发现文档中的错误，可以帮助我们要改进！
  - 在每页底部，您会找到一个 `编辑页面` 按钮，它会带您直接到 GitHub 上对应的文件，您可以在那里提出更改。
  - 或者，您可以在我们的 [GitHub 仓库](https://github.com/CachyOS/wiki)上打开一个新问题。
- **搜索是您的第一个工具：** 使用页面顶部的搜索栏（CachyOS 徽标右侧）快速查找与您的问题或问题相关的信息。
- **使用侧边栏导航：**
  - 左侧边栏可滚动，包含整个文档的主目录。使用它来浏览不同部分。

  - 不要忘记右侧边栏。它通常包含当前页面部分的有用概述，便于快速导航。
- **查找交互元素：**
  - **选项卡：** 一些页面使用选项卡来组织相关内容。务必检查所有可用选项卡以获取所需信息。
    - 示例：<ImageComponent imgsrc={import('~/assets/images/tab-example.png')} />
  - **可展开部分：** 折叠在可点击标题（如**"手动安装（高级）"**）下的内容可以展开以显示更详细的信息。
    - 示例：<ImageComponent imgsrc={import('~/assets/images/summary-element-example.png')} />
- **有用的功能：**
  - 代码块：所有代码块右上角都有一个 `复制到剪贴板` 按钮，便于复制。
    - 示例：<ImageComponent imgsrc={import('~/assets/images/code-block-example.png')} />
    :::note[有时代码块用于显示不需要复制的示例输出。]
  - 超链接：注意带下划线和/或彩色的文本。这些是链接到 wiki 的其他部分或外部资源以供进一步阅读。
- 密切关注提示、技巧、警告和注意事项。它们包含重要信息，可以帮助您避免常见陷阱并更快地解决问题。
  - 示例：<ImageComponent imgsrc={import('~/assets/images/note-example.png')} />
