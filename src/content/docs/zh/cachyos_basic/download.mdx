## 官方 ISO 来源

CachyOS ISO 可以从以下来源获取：

*   [官网](<https://cachyos.org/download>)
*   [SourceForge](<https://sourceforge.net/projects/cachyos-arch/files/>)
*   [CachyOS 镜像](<https://mirror.cachyos.org/ISO/>)

## 使用 SHA256 验证 ISO 完整性

:::caution
始终多花一步验证 ISO 的完整性，以避免在安装期间或创建可引导介质时出现任何意外问题。
:::

**当前 ISO 版本：** `260809`

**SHA256 哈希：** `959f6577f45e25ee9fd8c220fd221b08e4ea79412c7315c0f922dd6d86d5e33c`

<Tabs>

<TabItem label='Windows'>

<Steps>

1. 下载包含 SHA256 哈希的 [文件](https://mirror.cachyos.org/ISO/desktop/260809/cachyos-desktop-linux-260809.iso.sha256) **（用文本编辑器打开，例如记事本）**。
2. 以管理员身份打开 CMD 或 PowerShell 并 [导航](<https://www.wikihow.com/Change-Directories-in-Command-Prompt>) 到 ISO 和 SHA256 文件存储的路径。
3. 执行以下命令：
   ```powershell
   # 示例：
   certUtil -hashfile cachyos-desktop-linux-260809.iso SHA256
   ```
4. 将 certUtil 哈希输出与 **步骤 1** 中下载文件中的哈希进行比较。如果它们匹配，您可以继续进行 CachyOS 安装。

</Steps>

</TabItem>

<TabItem label='Linux'>

<Steps>

1. 下载包含 SHA256 哈希的 [文件](https://mirror.cachyos.org/ISO/desktop/260809/cachyos-desktop-linux-260809.iso.sha256)。
2. 打开终端，导航到包含 `.sha256` 和 `.iso` 文件的目录。
3. 执行以下命令：
   ```sh
   # 示例：
   cd ~/Downloads
   sha256sum -c cachyos-desktop-linux-260809.iso.sha256
   # cachyos-desktop-linux-260809.iso: OK
   ```
4. 如果 **步骤 3** 的输出为 OK，您可以继续进行 CachyOS 安装。

</Steps>

</TabItem>

<TabItem label='macOS'>

<Steps>

1. 下载包含 SHA256 哈希的 [文件](https://mirror.cachyos.org/ISO/desktop/260809/cachyos-desktop-linux-260809.iso.sha256)。
2. 打开终端，导航到包含 `.sha256` 文件的目录，并执行以下命令：
   ```sh
   # 示例：
   cd Downloads/
   cat cachyos-desktop-linux-260809.iso.sha256
   # 959f6577f45e25ee9fd8c220fd221b08e4ea79412c7315c0f922dd6d86d5e33c
   ```
3. 将 **步骤 2** 的输出与 ISO 文件的哈希进行比较：
   ```sh
   # 示例：
   shasum -a 256 cachyos-desktop-linux-260809.iso
   ```
4. 如果 **步骤 2** 和 **步骤 3** 的哈希匹配，您可以继续进行 CachyOS 安装。

</Steps>

</TabItem>

</Tabs>

## 验证 ISO 镜像真实性（Linux）

要验证 ISO 文件的真实性：

<Steps>

1. 导入 GPG 密钥作为参考进行比较：

   ```shell
   gpg --keyserver hkps://keys.openpgp.org --recv-key F3B607488DB35A47
   ```

2. 下载 ISO 文件及其 [.sig](https://cdn77.cachyos.org/ISO/desktop/260809/cachyos-desktop-linux-260809.iso.sig) 签名文件，并运行以下命令（将 `full_iso_name.iso` 替换为实际的 ISO 文件名）：
   ```shell
   gpg --verify full_iso_name.iso.sig full_iso_name.iso
   ```

   如果您得到 **Good signature** 输出，则 ISO 文件是真实的：
   ```
   gpg: Signature made dom 09 ago 2026 13:30:06 -03
   gpg:                using RSA key 882DCFE48E2051D48E2562ABF3B607488DB35A47
   gpg: Good signature from "CachyOS <admin@cachyos.org>" [unknown]
   gpg: WARNING: This key is not certified with a trusted signature!
   gpg:          There is no indication that the signature belongs to the owner.
   Primary key fingerprint: 882D CFE4 8E20 51D4 8E25  62AB F3B6 0748 8DB3 5A47
   ```

</Steps>

:::danger
如果输出没有返回 **Good signature** 字符串或密钥 ID 不匹配，请不要使用该 ISO 镜像。错误的签名表明 ISO 已被篡改或已损坏。

确保下载的镜像来自 [合法的 CachyOS 来源](/zh/cachyos_basic/download#official-iso-sources)。
:::
