## 什么是混合显卡？

混合显卡（Hybrid graphics）是一种由两张协同工作的显卡组成的硬件配置。这种方式主要见于笔记本电脑，其中包含 CPU 的集成显卡（iGPU）和独立显卡（dGPU）。

其主要优势在于，集成显卡应该（但非必须）仅用于低负载任务，如浏览网页、观看视频等。另一方面，独立显卡则用于高性能任务，如游戏、视频编辑、3D 建模等。

因此，如果两张 GPU 分担“重”和“轻”任务，那么在当前只有“轻”任务运行时，我们就不需要使用 dGPU，从而可以将其禁用（如同进入休眠状态），大幅降低功耗。这样一来，当再次需要 dGPU 时（例如运行需要使用它的应用程序），它便会唤醒并开始工作。

## 什么是 PRIME Offload？

PRIME 是 Linux 中用于处理不同混合显卡方案的统一技术，例如 NVIDIA Optimus 和 AMD Dynamic Switchable Graphics。PRIME Offload 则是将渲染任务的执行从一个 GPU 转移到另一个 GPU 这一理念在 Linux 中的实现。

闭源 NVIDIA 驱动中的 PRIME 支持实际上直到 435.17 驱动版本才正式加入。因此，如果你使用的是过时的 390xx 甚至 340xx 驱动分支，PRIME Offload 将无法为你工作。另外，我们也强烈不建议你使用处理混合显卡的过时方案，如 nvidia-xrun 或 Bumblebee。它们早已过时且不再受支持（Bumblebee 已超过 8 年未更新），完全依赖变通手段（hacks）且性能低下。与此同时，Nouveau 驱动支持 PRIME Offload，可以作为较旧款 dGPU 的替代方案。

在 CachyOS 中，**你无需配置任何内容即可让 PRIME Offload 正常工作**。通过 nvidia-utils 软件包和 cachyos-settings，你已经拥有了使用 PRIME Offload 所需的一切。

此外，请避免使用 optimus-manager 等工具。它们看起来可能很方便，但请相信我们，它们可能会引发许多问题；如果你的 dGPU 支持 PRIME Offload 和动态电源管理，你完全不需要它们。

### 如何使用 PRIME Offload

要告诉 PRIME 你希望使用独立显卡而非集成显卡，必须在运行程序之前指定一系列环境变量：

```bash
__NV_PRIME_RENDER_OFFLOAD=1 __VK_LAYER_NV_optimus=NVIDIA_only __GLX_VENDOR_LIBRARY_NAME=nvidia <program>
```

这组变量看起来非常繁琐且容易遗忘，因此你可以安装 `nvidia-prime` 软件包（`sudo pacman -S nvidia-prime`），它包含了对应所有这些变量的别名脚本。安装后，使用它运行应用程序将如下所示：

```bash
prime-run <program>
```

其中 `<program>` 是运行你的应用程序的命令名称。

:::note
部分 DX12 游戏即使使用了 `prime-run`，也可能会出现无法正确选择 dGPU 的问题。
要解决此问题，请在 `prime-run` 包装脚本之前添加环境变量 `VK_DRIVER_FILES=/usr/share/vulkan/icd.d/nvidia_icd.json`。
:::

对于两张显卡都由开源 Mesa 驱动管理的配置（例如 AMD+AMD、AMD+Intel，甚至独立显卡由开源 Nouveau 驱动管理的 Intel+NVIDIA 组合），同样无需任何额外配置。要使用独立显卡，只需在启动应用程序或游戏之前指定 `DRI_PRIME=1` 环境变量（与前文介绍的 NVIDIA 变量用法类似），或者直接使用下文介绍的图形化方法即可。

## 图形化方法

你可能会觉得每次都通过终端使用 `prime-run` 启动所需的应用程序不太方便。幸运的是，一些应用程序和桌面环境提供了工具来控制特定应用程序使用哪张 GPU。

### Lutris

要在 Lutris 中配置游戏使用独立显卡运行，你需要进入设置（窗口右下角的三条横线和“Preferences”按钮）。接下来，进入 *“Global Options”* -> *“Display”*。在这里，你可以选择游戏运行所使用的 GPU。

### Steam

Steam 没有专门的图形选项来强制游戏使用独立显卡。不过，你可以在启动游戏前点击齿轮图标进入游戏的属性设置。在“Launch options”字段中，你可以添加 `prime-run` 命令或环境变量。
示例：

```bash
prime-run %command%
```

请务必在 `prime-run` 之后添加 `%command%`。请记住，游戏自身的参数应放在占位符之后，而系统环境变量或包装命令则应放在它之前。

如果想让游戏改用集成显卡运行，可以参考以下针对 Radeon 集成显卡的启动选项示例。对于低功耗游戏，这样做可以获得更长的电池续航和更低的风扇噪音。

```bash
VK_DRIVER_FILES=/usr/share/vulkan/icd.d/radeon_icd.x86_64.json:/usr/share/vulkan/icd.d/radeon_icd.i686.json %command%
```

### KDE Plasma

Plasma 提供了一种非常方便的方式来设置使用独立显卡启动应用程序。不过，此方法仅在你的系统上安装了 `switcheroo-control` 软件包并启用了相应服务时才有效。

在全新安装的 CachyOS 中，该软件包和服务应已通过 chwd 默认启用。

```bash
sudo pacman -S switcheroo-control
sudo systemctl enable --now switcheroo-control
```

执行完这两条命令后，右键点击桌面或应用程序菜单中对应的快捷方式，然后进入 *“Properties”* -> *“Application”* -> *“Advanced Options”*。

你应该勾选 *“Run using dedicated graphics card”* 复选框。

<br />
<ImageComponent imgsrc={import('~/assets/images/plasma-prime.jpg')} />

:::note
使用 `switcheroo-control` 可以让这些选项在所有 PRIME 配置上正常工作，即使是没有 NVIDIA 独立显卡的组合（例如 AMD APU + AMD 独立显卡）。
:::

### GNOME

在 GNOME 上，你同样应该按照上述方式安装 `switcheroo-control`，然后右键点击应用程序图标并选择 *“Run using discrete graphics”*。但请注意，GNOME 不会记住这一选择，下次你从图标启动该应用程序时，它仍会使用集成显卡而非独立显卡。

### Cinnamon

与 Plasma 类似，Cinnamon 也允许你为特定应用程序选择 GPU。右键点击应用程序的桌面快捷方式，进入 Properties，并启用相关选项即可。

<br />
<ImageComponent imgsrc={import('~/assets/images/cinnamon-prime.png')} />

如果该选项不可用，请确保你已安装 `switcheroo-control` 并启用了其服务，因为所有桌面环境都依赖它来实现此功能。
