:::note
Niri 是一个 scrollable-tiling Wayland compositor，通过其基于列的布局系统提供独特的窗口管理方式。
:::

我们设置的主要目标是提供一个工作的 Niri 配置，在保持配置简单易懂的同时，提供流畅直观的桌面体验。

## 常见问题

### Niri 与其他窗口管理器有何不同？

Niri 使用独特的 scrollable-tiling 方法，窗口排列在可以水平滚动的列中。这提供了一个无限的桌面隐喻，对于超宽显示器和需要打开许多应用程序的工作流程特别有用。

### 如何更改键盘布局？

编辑配置文件中的 input 部分：

```txt title='示例'
input {
    keyboard {
        xkb {
            layout "us" // Change from "de" to your preferred layout
        }
    }
}
```

### 我可以自定义间隙和窗口外观吗？

可以，你可以修改 layout 部分：

```txt title='示例'
layout {
    gaps 8 // Change gap size

    focus-ring {
        width 2
        active-color "#your-color"
        inactive-color "#your-color"
    }
}
```

### 如何添加更多启动应用程序？

将它们添加到 startup 部分：

```txt title='示例'
spawn-at-startup "your-application"
```

### 紧急退出键有什么用？

`Super+Escape` 绑定旨在在全屏应用程序阻止 keybinds 时恢复控制。它禁用任何活动的键盘快捷键抑制器。

### 如何配置多个显示器？

取消注释并修改 output 部分以适配你的特定显示器。运行 `niri msg outputs` 获取正确名称：

```txt title='示例'
output "DP-1" {
    mode "1920x1080@60.000"
    scale 1
}
```
