## 快捷键

大多数键组合需要使用 mod 键，在我们的情况下是 Windows 键（称为 SUPER），你可以在配置文件中更改它。
其中一些可能使用 mod1（ALT 键）。

### 应用控制

| 描述 | 按键 |
|-------------|-----|
| 打开终端 | <Kbd linux="Super+Return" /> |
| 打开 Rofi（程序启动器） | <Kbd linux="Alt+Space" /> |
| 打开文件管理器（Thunar） | <Kbd linux="Super+E" /> |
| 关闭当前窗口 | <Kbd linux="Super+Q" /> |

### 工作区导航

| 描述 | 按键 |
|-------------|-----|
| 前往工作区（1-9） | <Kbd linux="Super+1" /> 到 <Kbd linux="Super+9" /> |

### 窗口导航

| 描述 | 按键 |
|-------------|-----|
| 聚焦向左 | <Kbd linux="Super+H" /> |
| 聚焦向右 | <Kbd linux="Super+L" /> |
| 聚焦向下 | <Kbd linux="Super+J" /> |
| 聚焦向上 | <Kbd linux="Super+K" /> |
| 在列之间或堆叠中上下移动窗口 | <Kbd linux="Super+Space" /> |

## 常见问题

### 为什么音量小部件显示错误或卡在 0%？

* 这有时是因为 Qtile volume widget 无法检测你的默认 Output Device。你可以 [查看 wiki](https://docs.qtile.org/en/latest/manual/ref/widgets.html#pulsevolume) 获取更多信息。

### 有 autostart.sh 脚本吗？

* 是的，它位于 Qtile 文件夹的 `scripts/` 中。

### Qtile 的栏可以与鼠标交互吗？

* 是的，例如如果你在小圆点（你的工作区：Active、Inactive、Empty 等）上滚动，你将切换到左侧或右侧，或者点击其中一个。
* 另一个例子是 layout（默认是 columns），点击它允许你在可用 layout 之间切换
* CPU 和 RAM 使用率点击它将打开 Btop（TUI System Monitor）
* 通过交互 volume widget 来增大/降低/静音音量

有关 Qtile 的更多信息，请 [查看他们的 wiki](https://docs.qtile.org/en/stable/)。
