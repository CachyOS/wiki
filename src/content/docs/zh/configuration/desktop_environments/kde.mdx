## 如何安装缺失的 X11 session

KDE 决定将开发拆分为多个包后，X11 session 已从默认安装中移除。

```sh
sudo pacman -S plasma-x11-session kwin-x11
```

完成后，X11 将作为选项列在登录屏幕上。 

## 如何安装缺失的 xorg-server

从 CachyOS 安装器的 26.01 版本起，xorg-server 不再被安装，并且 plasma-x11-session 和 kwin-x11 都不再将 xorg-server 视为依赖项。 因此，如果未手动安装 Xorg 服务器及相关组件，登录时将会出现黑屏。  

```sh
sudo pacman -S xorg-server
```

## 常见问题

### 如何获得 KDE 截图中显示的名为“Emerald”的外观？

- 这是 Emerald Theme + Qogir Icon Theme 的组合，默认未安装。
  - ```sh title='使用以下命令安装两者'
    sudo pacman -S cachyos-emerald-kde-theme-git qogir-icon-theme
    ```
  在 `Appearance & Style - Colors & Themes` 中应用两者
