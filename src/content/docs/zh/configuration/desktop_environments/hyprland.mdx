:::note
Hyprland 是一个 wayland compositor，支持多种布局，如 dwindle（tiling）、scrolling、master、monocle 和自定义布局。它**不是**完整的桌面环境（DE）。
:::

### 为什么使用 Hyprland？

Hyprland 是一个漂亮的动态平铺管理器，提供多种布局和高级 compositor 功能，如 VRR、tearing 和 HDR。CachyOS 的 Hyprland 配置使用通用默认设置，开箱即用，应用程序会遵循系统主题。

**Dotfiles 由 [Jinra](https://github.com/Jinra) 维护**

对于 Noctalia 相关问题，请查看 [Noctalia docs](https://docs.noctalia.dev/)。

## 安装后设置任务

设置完成后，你需要配置一些用户特定的内容。更多设置请参考 Hyprland wiki https://wiki.hypr.land/Configuring/Start/

### 位置 `~/.config/hypr/config`
* `monitors.lua` 将设置你的显示器。（详见 https://wiki.hypr.land/Configuring/Basics/Monitors/）。已为你创建默认块，你可以为额外显示器添加更多。
  * `output` 请编辑 `variables.lua` 中的显示器值；你可以运行 `hyprctl monitors` 获取此 ID（例如 `DP-1`）。如果添加更多显示器，使用 MONITOR2、MONITOR3 等，并同样添加到 `variables.lua`。
  * `mode` 格式应为 `1920x1080@60`（水平 x 垂直 @ 刷新率）。
  * `scale` 你可能需要 `1`，但对于高分辨率显示器可能需要更高的值。
  * 首次调整后可能需要重启，但后续调整应实时反映。
* `variables.lua`
  * 在此添加显示器分配。你的 `PRIMARY_MONITOR` 和 `MONITOR1` 通常是同一显示器。可按需添加/移除 `MONITOR#` 变量。
  * 定义每个显示器的工作区数量。不要超过 10 个。
* `input.lua` 可在此定义各种 Hypr 输入设置。你可能需要调整 `sensitivity`。
* `binds.lua` 查看此文件了解所有 keybind。也可以查看下方的总览。
* `windowrules.lua` 如果你好奇为什么某些窗口有特定行为，查看此文件；你也可以按需添加/移除规则。
* `workspaces.lua` 在此添加各种工作区设置。建议每个显示器添加 3 个工作区（如示例所示），并在主显示器上添加游戏工作区。
* `environment.lua` 用于设置 Hypr 或用户特定的环境变量。如果你使用 UWSM，则不需要调整，更推荐添加到 UWSM env 文件（见下文）。
### 位置 `~/.config/uwsm`
* `env` 是用于定义全局变量的文件，可用于需要为特定用户账户分配的通用变量（例如：`HYPRCURSOR_THEME`、`XCURSOR_THEME`、`QT_QPA_PLATFORM` 等）
### 位置 `~/.config/noctalia`（仅 V5；V4 会有文件在此，但无需触碰，因为它们可通过 Noctalia 设置配置）
* `config.toml` 这是 cachyos-hypr-noctalia 默认配置的位置。如果你好奇为什么默认值与 vanilla noctalia v5 安装不同，这就是原因。你不应需要修改此文件中的任何内容。
### 位置 `noctalia settings`（Super + Z）
* 可在此编辑 Noctalia 设置。建议进入 templates 部分，为你可能使用的任何应用启用颜色模板。
* 还要查看 plugins store，寻找有用的官方和社区插件。

## 从其他 DE/WM 迁移

如果你已安装了其他 DE/WM，可以按照以下说明迁移到此 dots。

:::note
虽然可以用同一用户账户使用 Hyprland，但强烈建议创建新用户账户（包含说明）。此外，即使使用新用户账户，也可能与之前的 DE/WM 存在 daemon 冲突，因此使用单一环境更理想。
:::

确保替换下方尖括号（`<>`）中的变量，包括尖括号本身。

1. 运行 `sudo pacman -S cachyos-hypr-noctalia`。如果与其他 `-settings` 包（如 `cachyos-kde-settings`）发生包冲突，可以删除冲突包，因为这些包不影响当前用户。
1. 要创建新用户，运行 `sudo useradd -m <new_user> -s /bin/fish`。你也可以使用其他 shell（如 /bin/zsh）。
1. 运行 `sudo passwd <new_user>` 设置账户密码。
    * 如果你_真的_想用同一账户（强烈不推荐），则将 dots 复制到用户文件夹 `cp -r /etc/skel/. ~`（确保先创建备份/快照！）
1. 可选地安装 `noctalia-greeter` 或 `sddm` 作为 display manager。`noctalia-greeter` 与 Noctalia 集成更好，但设置稍复杂。
    * 要启用 sddm 作为 display manager，用 `sudo pacman -Syu sddm` 安装，然后运行 `systemctl disable display-manager` 和 `systemctl enable sddm`。
    * 要安装 [Noctalia Greeter](https://github.com/noctalia-dev/noctalia-greeter)，运行 `sudo pacman -Syu noctalia-greeter`，并按照链接文档中的 "Setting up greetd" 部分操作。之后，运行 `systemctl disable display-manager` 和 `systemctl enable greetd`。
1. 重启并从 display manager 选择 Hyprland (UWSM) session。
    * 如果 shell 加载失败，再尝试重启一次。
1. 登录并按照 [Post Setup Tasks](/zh/configuration/desktop_environments/hyprland/#post-setup-tasks) 操作。

## 从 v4 dots 迁移到 V5 / 更新你的 dots

如果你当前使用带有 Noctalia v4 的 cachyos-hypr-noctalia，并从包版本 1.0 更新到更新版本，或想更新你的 dots，请按照以下说明操作。
查看 release 中的完整 change logs 以确定是否应更新你的 dots。
https://github.com/CachyOS/cachyos-hypr-noctalia/releases

### Hypr 更新

:::note
一旦你从 v4 迁移 keybinds 到 v5，它们将不再能调用 Noctalia IPC calls。
:::

1. 如果没有安装 `meld`，请安装它（运行 `pacman -Q meld` 检查是否已安装）。
1. 运行 `meld /etc/skel/.config/hypr ~/.config/hypr`。
1. 从 meld 你将看到所有有更改的文件的总览。蓝色文件有更改，绿色文件是全新的。
    <br />
    <ImageComponent imgsrc={import('~/assets/images/v4-v5-migration/meld_overview.png')} />
1. 点击蓝色文件查看要应用的更改。你可以自行判断应用什么，但如果你没有做任何更改，安全地覆盖整个文件。点击箭头应用更改，点击 x 移除旧行。
    <Aside type="note">确保不要覆盖你可能更改的内容，如显示器设置。</Aside>
    <br />
    <ImageComponent imgsrc={import('~/assets/images/v4-v5-migration/merge.png')} />
1. 你也可以全部合并。
    <br />
    <ImageComponent imgsrc={import('~/assets/images/v4-v5-migration/merge_all_1.png')} />
    <ImageComponent imgsrc={import('~/assets/images/v4-v5-migration/merge_all_2.png')} />
1. 完成文件更改后，保存并退出。
    <br />
    <ImageComponent imgsrc={import('~/assets/images/v4-v5-migration/save_exit.png')} />
1. 全新的绿色文件会询问你想保存在哪里。你可以以相同名称保存在 `~/.config/hypr/config/` 中。共有 4 个新文件。
    * defaults.lua 现在是 variables.lua。你必须手动将任何自定义添加/更改移至新文件。
    * keybinds.lua 现在是 binds.lua。你必须手动将任何自定义添加/更改移至新文件。
    * input.lua 现在是 inputs.lua。你必须手动将任何自定义添加/更改移至新文件。
    * workspaces.lua 是全新的，可以干净地移过来无需更改。
    <br />
    <ImageComponent imgsrc={import('~/assets/images/v4-v5-migration/workspaces.png')} />

### Noctalia 更新

1. 运行 `rm -rf ~/.config/noctalia` 移除当前配置。或者，如果你认为可能需要其中某些内容，将它们移到其他地方。
1. `cp -r /etc/skel/.config/noctalia ~/.config` 将新配置复制到你的主文件夹。

:::note
唯一重要的文件是 config.toml，因此如果包更新时，你可以单独复制它，而不是删除并替换整个文件夹。
:::

### 其他更新

其他文件可能有更新，你可以使用 meld 整合这些更改。查看完整的 release change log 了解其他可能的更改。
 
### 移除孤儿包（v4->v5 迁移）

更新包后，旧依赖将变为 orphan，你可以通过运行 `shelly purify -o` 移除它们。

### 重启

重启应使更改生效。如果 shell 加载失败，再尝试重启一次。

## 常见问题

> _"为什么我的剪贴板历史在重启后不保留？"_

你需要设置一个 secrets store 才能正常工作。Kwallet 已默认安装，但也可以使用 gnome-keyring 或其他 secrets store。如果你想使用 kwallet，从仓库安装 `kwalletmanager`，然后打开它并创建新钱包。最简单的是将密码留空，但也可以设置与 display manager 的自动解锁，这超出了本 wiki 的范围；详见 [Arch wiki](https://wiki.archlinux.org/title/KDE_Wallet#Configuration)。设置钱包后，在 `autostart.lua` 文件中用 `hl.exec_cmd("kwalletd6")` 初始化它。

> "_如何让截图后不弹出 satty？_"

你可以通过按 ctrl + s 保存截图或 ctrl + c 复制来轻松关闭 satty。如果你完全不想弹出 satty，可以在 Noctalia settings > shell > screenshot 中配置复制到剪贴板或保存到文件的设置。

> _"如何更改键盘输入？"_

编辑 `inputs.lua` 并添加 `kb_layout`。详见 [这里](https://wiki.hypr.land/Configuring/Basics/Variables/#input)。

> _"为什么某些主题选项（Dolphin 图标、某些 QT 元素等）不工作？"_

Cachy 的默认仓库只提供 `qt6ct`（QT6 Configuration Tool）。但还有另一个工具对 Plasma QT 应用（如 dolphin、gwenview 等）效果更好。从 AUR 下载 `qt6ct-kde` 并使用它应用 Noctalia 主题。这应该让你的 plasma 应用在 Hyprland 中主题效果更好。

> _"如何更改默认浏览器？"_

运行 `xdg-settings set default-web-browser your_browser.desktop`。你可以通过运行 `ls /usr/share/applications/` 找到浏览器的 desktop 文件名。
