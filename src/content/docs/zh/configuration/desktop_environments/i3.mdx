## 快捷键

大多数键组合需要使用 mod 键，在我们的情况下是 Windows 键（称为 SUPER），你可以在配置文件中更改它。

| 描述 | 按键 |
|-------------|-----|
| 打开终端 | <Kbd linux="Super+Return" /> |

## 常见问题

### 如何为程序创建自动启动？例如“启动时设置壁纸”

* i3 已包含灵活的 autostart 功能，允许你执行任何程序甚至命令

如果你查看配置文件的末尾，会看到一些以 exec 和 exec_always 开头的行。

例如：

```exec chromium```

这意味着每次你登录 i3 session 时，Chromium 将在 workspace 1 启动。

### exec 和 exec_always 有什么区别？

exec_always 让你即使在 i3wm 重新加载后也能始终执行特定操作。

* 更多参考和信息，查看他们的 i3 用户指南
* https://i3wm.org/docs/userguide.html#exec
