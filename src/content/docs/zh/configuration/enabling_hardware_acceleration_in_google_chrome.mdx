本指南概述了在 CachyOS 上为基于 Chromium 的浏览器启用硬件加速的方法。这可将视频/图形任务卸载到你的 GPU，从而提升性能。

## 前提条件

**必需：**
* **基于 Chromium 的浏览器：**（例如 Chrome、Brave、Ungoogled Chromium、Edge）
* **GPU 驱动/API：** 最新的 Mesa（AMD/Intel）或 NVIDIA 驱动，并已配置 Vulkan/VA-API/VDPAU。

**可选：**

* **amdgpu_top：** 如果你想通过终端监控 AMD GPU 活动，可通过包管理器从软件仓库安装 `amdgpu_top`。
* **nvtop：**（仅限 Intel GPU）如果你想通过终端监控 Intel GPU 活动，可通过 Shelly 包管理器安装 `nvtop`（Lunar Lake）和 `intel-gpu-tools`（Lunar Lake 之前架构）。

## 贡献

本指南支持扩展。如果你拥有特定 GPU 和基于 Chromium 的浏览器的可用硬件加速配置，可以通过在“GPU 和浏览器配置”下添加新章节来贡献内容。请包含：

* **浏览器名称**
* **GPU 型号**
* **Flags：** `~/.config/[browser]-flags.conf` 的内容。
* **文件路径：** flags 文件的完整路径。
* **说明（可选）：** 关键驱动、软件包或设置细节。

### 设置步骤

<Steps>

1. 确定 Flags 文件：在“GPU 和浏览器配置”中查找你的浏览器对应的 flags 文件路径。
2. 编辑 Flags 文件：使用 `nano`（或你喜欢的文本编辑器，如 `micro`、`vim`）打开/创建文件。

    ```bash
    nano [PATH_TO_YOUR_BROWSER_FLAGS_FILE]
    # Example: nano ~/.config/chrome-flags.conf
    ```

3. 添加 Flags：将相关的 GPU/浏览器 flags 粘贴到文件中。
4. 保存并关闭。
5. 重启浏览器：关闭所有浏览器实例并重新启动。
6. 验证：访问 `chrome://gpu`（或 `brave://gpu`、`edge://gpu` 等）。确认“Video Acceleration Information”和“Graphics Feature Status”下的状态为“Hardware accelerated”。

</Steps>

## 如何验证视频硬件加速

<Tabs>

<TabItem label='AMD GPU (amdgpu_top)'>

<Steps>

1. 打开终端并运行命令：
    ```bash
    amdgpu_top
    ```
2. 在浏览器中开始播放视频（例如在 YouTube 上）。
3. 观察 `amdgpu_top` 中的 `media` 部分。你应该能在这里看到一定的利用率，表明你的 GPU 媒体引擎处于活动状态。如果在视频播放期间始终保持在 0%，则硬件解码加速可能未完全启用。

</Steps>

</TabItem>

<TabItem label='Intel GPU (nvtop)'>

<Steps>

1. 打开终端并运行命令：
    ```bash
    sudo nvtop
    ```
2. 在浏览器中开始播放视频（例如在 YouTube 上）。
3. 观察 `nvtop` 中的 `ENC/DEC` 百分比，如果视频硬件解码正常启用，该百分比应该会上升。

</Steps>

</TabItem>

<TabItem label='Intel GPU (intel_gpu_tools)'>

<Steps>

1. 打开终端并运行命令：

    ```bash
    sudo intel_gpu_top
    ```

    注意：部分较新的 Intel GPU（如 Lunar Lake GPU）不再通过 `intel_gpu_top` 暴露 GPU 性能计数器，请在这类系统上使用 `nvtop`。

2. 在浏览器中开始播放视频（例如在 YouTube 上）。
3. 观察 `intel_gpu_top` 中的 `Video` 和 `VideoEnhance` 百分比，如果视频硬件解码正常启用，该百分比应该会上升。

</Steps>

</TabItem>

<TabItem label='浏览器开发者工具'>

<Steps>

1. 打开你的基于 Chromium 的浏览器。

2. 开始播放视频（例如在 YouTube 上或本地文件）。

3. 打开开发者工具：按 `F12` 或 `Ctrl+Shift+I`。

4. 切换到 **Media** 选项卡。如果看不到它，点击开发者工具工具栏上的三个点（`...`）或 `>>`（更多选项卡），然后选择 `Media`。

5. 在左侧的“Players”部分，点击对应你视频的条目。

6. 在主面板中，向下滚动到 **Video Decoder** 部分。

7. 查找 `Hardware decoder` 标签，它应该显示为 `true`。如果显示 `false` 或显示软件解码器名称（例如 `FFmpegVideoDecoder`、`VpxVideoDecoder`、`Dav1dVideoDecoder`），则说明该视频未启用硬件加速。

</Steps>

</TabItem>

</Tabs>

## GPU 和浏览器配置

### AMD Radeon RX 6900 XT (Google Chrome)

* **浏览器：** Google Chrome

* **GPU：** AMD Radeon RX 6900 XT

* **Flags 文件：** `~/.config/chrome-flags.conf`

```bash
--use-gl=angle
--use-angle=vulkan
--enable-features=Vulkan,VulkanFromANGLE,DefaultANGLEVulkan,AcceleratedVideoDecodeLinuxZeroCopyGL,AcceleratedVideoEncoder,VaapiIgnoreDriverChecks,UseMultiPlaneFormatForHardwareVideo
```

**说明：** 利用 Vulkan（通过 ANGLE）和 VA-API。`--ozone-platform=x11` 在 Wayland 上可能对某些加速路径有用。


### Nvidia RTX 4090 (Vivaldi)

* **浏览器：** Vivaldi

* **GPU：** Nvidia RTX 4090

* **Flags 文件：** `~/.config/vivaldi-stable.conf`

```bash
--enable-features=VaapiVideoDecoder,AcceleratedVideoDecodeLinuxGL,AcceleratedVideoDecodeLinuxZeroCopyGL
```

* **Flags 文件：** `/usr/share/applications/vivaldi-stable.desktop`

```bash
# Keep all other lines the same
# You should only change this Exec= entry under the '[Desktop Entry]' section
Exec=/usr/bin/vivaldi-stable --enable-features=VaapiVideoDecoder,AcceleratedVideoDecodeLinuxGL,AcceleratedVideoDecodeLinuxZeroCopyGL %U
```

**说明：**

你只需要应用其中一个配置文件修改，但两者都应用也不会导致问题。

或者你可以在 KDE 中执行以下操作：
1. 删除 Vivaldi 的所有任务管理器 / 任务栏快捷方式
2. 在应用程序启动器列表中搜索 `Vivaldi`
3. 右键点击应用程序启动器中的条目并选择 `编辑应用程序...`（`Edit Application...`）
4. 在 `命令行参数`（`Command-line arguments`）部分，在最后一个参数 `%U` 之前添加以下参数：
```
--enable-features=VaapiVideoDecoder,AcceleratedVideoDecodeLinuxGL,AcceleratedVideoDecodeLinuxZeroCopyGL
```
5. 启动 Vivaldi 并将该进程固定到你的任务管理器 / 任务栏

### Vivaldi - NVIDIA RTX 5090（由 icetea 贡献）

* **浏览器：** Vivaldi (8.1)

* **GPU：** NVIDIA GeForce RTX 5090 (Blackwell)

* **Flags 文件路径：** `~/.config/vivaldi-stable.conf`

```bash
--enable-features=VaapiVideoDecoder,AcceleratedVideoDecodeLinuxGL,AcceleratedVideoDecodeLinuxZeroCopyGL,VaapiOnNvidiaGPUs,VaapiIgnoreDriverChecks
--use-gl=angle
--use-angle=gl
--disable-features=Vulkan
--ignore-gpu-blocklist
--ozone-platform=wayland
```

**说明：**
- 需要 `libva-nvidia-driver`。测试于 2026 年 7 月：驱动版本 610.43.03，KDE Plasma（Wayland），Vivaldi 8.1。
- `VaapiIgnoreDriverChecks` 是 NVIDIA 上的关键 flag——如果没有它，解码会初始化且 `vivaldi://gpu` 会声称“Hardware accelerated”，但运行时解码会失败（`vaEndPicture failed, VA error: internal decoding error`）并静默回退到软件解码。
- 请通过开发者工具 → Media 选项卡（解码器名称为 `VaapiVideoDecoder`）和 `nvidia-smi dmon -s u`（播放期间 DEC 列 > 0）进行验证。不要仅依赖 `vivaldi://gpu`。
- `libva-nvidia-driver` 0.0.17 中的 AV1 解码存在故障（修复已合入上游 master，尚未发布——见 [elFarto/nvidia-vaapi-driver#419](https://github.com/elFarto/nvidia-vaapi-driver/issues/419)）。请屏蔽 AV1（例如使用 enhanced-h264ify），以便 YouTube 提供 VP9。

### Google Chrome - NVIDIA RTX 5070（由 pisyukaev 贡献）

* **浏览器：** Google Chrome

* **GPU：** NVIDIA GeForce RTX 5070 (Blackwell / GB205)

* **Flags 文件路径：** `~/.config/chrome-flags.conf`

```bash
--enable-features=AcceleratedVideoDecodeLinuxGL,VaapiVideoDecoder,VaapiIgnoreDriverChecks,VaapiOnNvidiaGPUs
--ignore-gpu-blocklist
```

**说明：**
- 需要 `libva-nvidia-driver` 和 `nvidia-utils`（基于驱动版本 610.43.03 测试）。
- **关键 flag：** `VaapiOnNvidiaGPUs`——这是在 Chrome/Chromium 中为 NVIDIA GPU 启用 VA-API 的关键 flag。没有它，Chrome 会在 `vaapi_wrapper.cc` 中硬编码屏蔽 NVIDIA 设备并静默回退到软件解码。
- 同时建议添加 `VaapiIgnoreDriverChecks` 以防止运行时解码失败。
- `AcceleratedVideoDecodeLinuxGL` 通过 ANGLE 的 OpenGL 后端启用硬件加速视频解码。
- 验证可用：`chrome://gpu` → Video Acceleration Information 显示支持 H264（baseline、main、high）、VP8、VP9（profile0、profile2）、HEVC（main、main 10、main still-picture）和 AV1 解码。
- 验证方法：打开 `chrome://gpu` 并确认“Video Acceleration Information”列出了各解码编解码器。播放 HEVC 视频并检查开发者工具 → Media 选项卡，确认活动解码器为 `VaapiVideoDecoder`。
- 不需要 `--ozone-platform=wayland` flag——Chrome 在 CachyOS 上会自动检测 Wayland。如果遇到问题，可以显式添加 `--ozone-platform=wayland`。
