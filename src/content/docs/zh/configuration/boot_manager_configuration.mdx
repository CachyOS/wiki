## systemd-boot

systemd-boot 有两种配置文件：一种是 systemd-boot 自身的 `/boot/loader/loader.conf`，另一种是每个内核条目对应的 `/boot/loader/entry`。

### 引导加载器配置

在此配置文件中，你可以更改 systemd-boot 的默认条目和超时时间。

```shell
# /boot/loader/loader.conf

default @saved
timeout 5
#console-mode keep # 此选项配置控制台分辨率。
```

### 内核命令行配置

我们提供了一个用于更简便配置 systemd-boot 的工具：[`sdboot-manage`](https://github.com/CachyOS/CachyOS-PKGBUILDS/tree/master/systemd-boot-manager)。
此工具的优点之一是全局 kernel commandline 配置。`sdboot-manage` 的配置文件位于 `/etc/sdboot-manage.conf`。

编辑 `/etc/sdboot-manage.conf` 中的 `LINUX_OPTIONS=` 行以更改内核参数。

```shell
# /etc/sdboot-manage.conf
LINUX_OPTIONS="zswap.enabled=0 nowatchdog quiet splash"
```

更改后，使用以下命令重新生成所有 systemd-boot 条目

```shell
sudo sdboot-manage gen
```

## rEFInd

与 [systemd-boot](/zh/configuration/boot_manager_configuration#systemd-boot) 类似，rEFInd 也有两个配置文件。位于
`boot/efi/EFI/refind` 的 `refind.conf` 主要用于更改 rEFind 的行为，而 `/boot/refind_linux.conf` 用于管理启动选项。
`refind.conf` 包含大量注释，解释了所有选项。

### 内核命令行配置

要将内核参数传递给命令行，修改 `/boot/refind_linux.conf` 中的 "Boot using default options"

```shell
# /boot/refind_linux.conf

"Boot using default options"     "root=PARTUUID=1cb353ec-7f03-4820-8b4b-03baf53a208f rw zswap.enabled=0 nowatchdog quiet splash"
```

对两个配置文件的更改将立即生效。无需运行命令来"保存"更改。

## GRUB

与 [systemd-boot](/zh/configuration/boot_manager_configuration#systemd-boot) 和 [rEFInd](/zh/configuration/boot_manager_configuration#refind) 不同，
GRUB 只有一个配置文件，位于 `/etc/default/grub`。该文件中有很好的文档，解释了每个选项的作用。

### 隐藏 GRUB 启动菜单

要隐藏 GRUB 菜单，只需相应设置以下选项。

```shell
# /etc/default/grub

GRUB_TIMEOUT='0'
GRUB_TIMEOUT_STYLE=hidden
```

按 ESC 键访问 GRUB 提示符。从这里运行 `normal` 或 `exit` 即可回到熟悉的 GRUB 启动菜单。

### 内核命令行配置

要通过 GRUB 将内核参数传递给命令行，我们需要在 `/etc/default/grub` 中编辑 `GRUB_CMDLINE_LINUX_DEFAULT`。

```shell
# /etc/default/grub

GRUB_CMDLINE_LINUX_DEFAULT='nowatchdog zswap.enabled=0 quiet splash'
```

每次修改 GRUB 配置文件后，都需要用以下命令重新生成配置：

```shell
sudo grub-mkconfig -o /boot/grub/grub.cfg
```

### 可启动的 BTRFS 快照

:::note
如果你的 CachyOS 安装是在八月版本之前，你可能需要手动启用可启动 BTRFS 快照功能。

否则，你可以跳过本节，因为它自八月版本起已默认启用。
:::

要启用此功能，安装 grub-btrfs-support 包：

```sh
sudo pacman -S grub-btrfs-support
```

此包安装了必要的脚本和钩子，以自动检测 BTRFS 快照并将其添加到 GRUB 菜单中。

安装后，你的快照将出现在 GRUB 菜单中，类似于 Limine 的行为。


## Limine

Limine 是一个以配置简单著称的现代 bootloader。本指南涵盖入门基础知识。

配置主要在 `/boot/limine.conf`（有时在 EFI system partition）中进行菜单设置，在 `/etc/default/limine` 中进行内核参数设置。

### 启动菜单配置

此文件控制启动菜单的行为和外观。此处所做的更改在保存后立即生效——无需额外命令。

* **Timeout：** 设置 Limine 在自动启动默认条目前等待的秒数。

  ```shell
  # /boot/limine.conf

  timeout: 5
  ```

* **Default Entry：** 指定默认启动的菜单条目。条目从 1 开始编号。如果未设置，默认值为 1。

  ```shell
  # /boot/limine.conf

  default_entry: 2 # 默认启动第二个条目
  ```

  :::tip
   如果 `default_entry` 指向目录（例如 `/+CachyOS`），将禁用自动启动。要自动启动目录中的条目，`default_entry` 必须直接指向该特定条目编号。
  :::

示例（`/boot/limine.conf`）：

```shell
# /boot/limine.conf

timeout: 5
default_entry: 2 # 直接指向下方的 'linux-cachyos' 条目

/+CachyOS        # 条目 1：一个目录（使用 /+ 默认展开）
//linux-cachyos  # 条目 2：实际的启动条目
    protocol: linux
    kernel_path: boot():/vmlinuz-linux-cachyos
    cmdline: quiet splash root=UUID=... rw # 基本内核参数
    module_path: boot():/initramfs-linux-cachyos.img
```

:::note
`boot():/` 指启动驱动器的根目录。
:::

### 主题定制

你可以自定义 Limine 启动菜单的视觉外观：

* **Wallpaper：** 设置背景图片。支持的格式包括 BMP、PNG 和 JPEG。

  ```shell
  # /boot/limine.conf

  wallpaper: boot():/splash.png
  wallpaper_style: stretched # 选项：'stretched'（拉伸）、'tiled'（平铺）、'centered'（居中）
  backdrop: 000000           # 如果样式为 'centered'，则为背景颜色（RRGGBB 十六进制）
  ```

* **Fonts：** 使用 [自定义字体文件](https://github.com/viler-int10h/vga-text-mode-fonts) 并调整其大小。

  ```shell
  # /boot/limine.conf

  term_font: boot():/custom_font.F16
  term_font_scale: 2x2 # 缩放字体大小，适用于高分辨率显示器
  ```

* **Colors：** 修改终端文本和背景颜色。

  ```shell
  # /boot/limine.conf

  term_background: 80000000 # 示例：半透明黑色（AARRGGBB）
  # 其他颜色选项如 term_foreground 等也可用。
  ```

### 内核命令配置

在 CachyOS 上，Limine 启动菜单中的内核条目是**自动管理**的。当你安装或移除内核时，`limine-mkinitcpio-hook` 会在后台使用 `limine-entry-tool` 工具更新启动条目。

虽然条目是自动处理的，但你可以**配置传递给内核的内核参数**（也称为 kernel command line）。

1. **编辑配置文件：** 修改 `/etc/default/limine` 中的 `KERNEL_CMDLINE` 变量。你可以为所有内核设置默认参数，或为特定内核名称（例如 `linux-cachyos`）设置特定参数。

   ```shell
   # /etc/default/limine

   # 大多数内核的默认参数
   KERNEL_CMDLINE[default]="quiet splash rd.udev.log_priority=3"

   # 'linux-cachyos' 内核的特定参数
   KERNEL_CMDLINE["linux-cachyos"]="quiet splash mitigations=off"

   # 回退条目的参数（如果生成）
   # KERNEL_CMDLINE[fallback]="..."
   ```

2. **应用更改：** 保存 `/etc/default/limine` 后，需要重新生成 initramfs 镜像并更新 Limine 条目以应用新的内核参数。运行以下命令：

   ```bash
   sudo limine-mkinitcpio
   ```

   此命令触发 `mkinitcpio` 进程，其中包括 `limine-mkinitcpio-hook`，确保 `/etc/default/limine` 中的更改被合并到 `/boot/limine.conf` 中的启动条目。
