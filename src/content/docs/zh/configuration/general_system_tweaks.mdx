## AMD 性能调整

### AMD P-State 驱动
---------------------------

`amd-pstate` 是 AMD CPU 性能缩放驱动，在 Linux 内核的现代 AMD APU 和 CPU 系列中引入了新的 CPU 频率控制机制。该新机制基于协同处理器性能控制（Collaborative Processor Performance Control，CPPC），比传统的 ACPI 硬件 P-States 提供更细粒度的频率管理。

当前的 AMD CPU/APU 平台使用 ACPI P-states 驱动管理 CPU 频率和时钟，仅在 3 个 P-states 之间切换。CPPC 取代了 ACPI P-states 控制，为 Linux 内核提供了灵活、低延迟的接口，直接向硬件传递性能提示。

以下是 `amd_pstate` 驱动的 3 种操作模式以及在启动时使用它们的内核命令行（cmdline）条目：

- AMD P-State（非自主模式）：`amd_pstate=passive`
- AMD P-State Guided（引导自主模式）：`amd_pstate=guided`
- AMD P-State EPP（自主模式）：`amd_pstate=active`

:::note
当没有进行明确配置时，默认使用 AMD P-State EPP 驱动。
:::

你也可以在运行时切换操作模式以测试各个选项：

- **自主模式（Autonomous mode）**：平台仅考虑为最低性能（Minimum performance）、最高性能（Maximum performance）和能效偏好（Energy Performance Preference）设置的值。
   ```sh
   echo active | sudo tee /sys/devices/system/cpu/amd_pstate/status
   ```

- **引导自主模式（Guided-autonomous mode）**：平台根据当前工作负载以及操作系统通过最低和最高性能寄存器设置的限制来设定运行性能级别。
   ```sh
   echo guided | sudo tee /sys/devices/system/cpu/amd_pstate/status
   ```

- **非自主模式（Non-autonomous mode）**：平台通过期望性能寄存器（Desired Performance Register）直接从操作系统获取期望的性能级别。
   ```sh
   echo passive | sudo tee /sys/devices/system/cpu/amd_pstate/status
   ```

### 配置 AMD P-State EPP

要使用 P-State EPP，有两个可用的 CPU 频率缩放调速器（governor）：`powersave` 和 `performance`。建议使用 powersave 调速器并设置能效偏好。

*   设置 powersave 调速器：`sudo cpupower frequency-set -g powersave`
*   设置 performance 调速器：`sudo cpupower frequency-set -g performance`

要设置偏好，请使用所需的偏好运行以下命令：

```sh
echo power | sudo tee /sys/devices/system/cpu/cpu*/cpufreq/energy_performance_preference
```

可用偏好：`performance`、`power`、`balance_power`、`balance_performance`

### AMD 3D V-Cache 优化器

AMD 发布了一个补丁，用于优化双 CCD 3D CPU（如 7950X3D 和 7900X3D）上的缓存调度。
你需要在 BIOS 的 CPPC 选项下设置为“Driver”选项。这将允许通过 sysfs 覆盖所使用的模式。

有两种模式：

1. Frequency（频率）
2. Cache（缓存）

如果设置为 `cache`，驱动将尝试优先把任务调度到拥有更大缓存的 CCD 上，这主要对游戏有利。
`frequency` 选项则会尝试把任务调度到第二个 CCD 上，其频率高于 3D 缓存 CCD。

Frequency（默认）：
```sh
echo frequency | sudo tee /sys/bus/platform/drivers/amd_x3d_vcache/AMDI0101:00/amd_x3d_mode
```

Cache：
```sh
echo cache | sudo tee /sys/bus/platform/drivers/amd_x3d_vcache/AMDI0101:00/amd_x3d_mode
```

更改模式后，AMD 首选核心（preferred core）统计信息应提供不同的排名。你可以用以下命令读取：
```sh
grep -v /sys/devices/system/cpu/cpu*/cpufreq/amd_pstate_prefcore_ranking
```

### AMD P-State 核心性能提升

AMD Core Performance Boost（又名 AMD Turbo Core）是 AMD 的动态频率缩放技术，允许特定型号的处理器动态调整和控制处理器运行频率，从而在需要时提高性能，同时在正常运行期间保持较低的功耗和发热参数。

要在 CachyOS 上管理 AMD CPB，你可以使用以下命令：

```sh
❯ echo 0 | sudo tee /sys/devices/system/cpu/cpu*/cpufreq/boost # Disable boost for all cores
❯ lscpu -ae # This shows that AMD CPB is disabled globally
CPU NODE SOCKET CORE L1d:L1i:L2:L3 ONLINE    MAXMHZ   MINMHZ       MHZ
  0    0      0    0 0:0:0:0          yes 3301.0000 400.0000 1212.8250
  1    0      0    0 0:0:0:0          yes 3301.0000 400.0000 1394.2180
  2    0      0    1 1:1:1:0          yes 3301.0000 400.0000 1204.4600

❯ echo 1 | sudo tee /sys/devices/system/cpu/cpu0/cpufreq/boost # Enables boost on cpu0
❯ lscpu -ae
CPU NODE SOCKET CORE L1d:L1i:L2:L3 ONLINE    MAXMHZ   MINMHZ       MHZ
  0    0      0    0 0:0:0:0          yes 4564.0000 400.0000 1393.2380
  1    0      0    0 0:0:0:0          yes 3301.0000 400.0000  400.0000
  2    0      0    1 1:1:1:0          yes 3301.0000 400.0000 2157.8469
```

CachyOS 还提供了一个向后移植（backport）了启用 AMD CPB 支持提交的 `power-profiles-daemon` 版本。如果使用 `powersave` 配置文件，AMD CPB 将被禁用；而在 `balanced` 或 `performance` 配置文件下则会启用。

## 性能改进

### [ADIOS I/O 调度器](https://github.com/firelzrd/adios)

由 [firelzrd](https://github.com/firelzrd) 创建

:::note
CachyOS 在内核中包含了 ADIOS 的稳定分支。

**linux-cachyos** 中的当前版本：`3.2.0`

**linux-cachyos-rc** 中的当前版本：`3.2.0`
:::

来自 README 的简要介绍：

- *ADIOS（Adaptive Deadline I/O Scheduler）是 Linux 内核的块层 I/O 调度器，专为现代多队列块设备（blk-mq）设计。它旨在通过结合截止时间调度原理与基于学习的自适应延迟控制机制，为 I/O 操作提供低延迟。*
  - *受 mq-deadline 和 Kyber I/O 调度器概念的启发并在此基础上构建。其核心特性是能够根据过去的性能和请求特征（操作类型、大小）预测 I/O 完成延迟，并利用该预测动态调整请求截止时间和批处理行为。*

简而言之（TLDR）：ADIOS 通过学习存储设备的延迟特征，并利用这些信息动态为 I/O 请求设置截止时间。它将请求划分为四个优先级层级，从关键系统操作（Tier 0）到后台任务（Tier 3），以确保流畅的用户体验。虽然它专注于响应速度，但其行为也可以通过 sysfs 设置进行微调，以平衡延迟和吞吐量。

要观看实时演示，你可以观看此[视频](https://www.youtube.com/watch?v=L9WDcEeHgy4)

#### 如何启用 ADIOS

<Tabs>
    <TabItem label='临时启用（运行时生效）'>
        此方法为当前会话设置调度器。更改将在重启后丢失。
        ```sh
        sync && echo adios | sudo tee /sys/block/<yourdrive>/queue/scheduler
            # Replace <yourdrive> with the actual drive identifier (e.g. sda, sdb, nvme0n1)
        ```
    </TabItem>
    <TabItem label='重启后持久生效'>
        <Steps>
            1. 在你喜欢的文本编辑器（例如 nano、micro、vim）中打开或创建新的 udev 规则文件
                ```sh title='示例'
                sudo nano /etc/udev/rules.d/60-ioschedulers.rules
                ```
            2. 将以下规则添加到文件中。这些规则会根据驱动器类型（HDD、SSD 或 NVMe）自动应用特定的 I/O 调度器。
                ```text
                # HDD
                ACTION=="add|change", KERNEL=="sd[a-z]*", ATTR{queue/rotational}=="1", \
                    ATTR{queue/scheduler}="bfq"

                # SSD
                ACTION=="add|change", KERNEL=="sd[a-z]*|mmcblk[0-9]*", ATTR{queue/rotational}=="0", \
                    ATTR{queue/scheduler}="adios"

                # NVMe SSD
                ACTION=="add|change", KERNEL=="nvme[0-9]*", ATTR{queue/rotational}=="0", \
                    ATTR{queue/scheduler}="adios"
                ```
              3. 保存文件并关闭编辑器。
              4. 重新加载 `udev` 规则以立即应用更改，无需重启。
                  ```sh
                  sudo udevadm control --reload-rules
                  sudo udevadm trigger
                  ```
        </Steps>
    </TabItem>
</Tabs>

常见问题（FAQ）：

- 如果它能提高响应速度，为什么不默认启用呢？
  - ADIOS 仍处于积极开发和持续测试阶段。虽然它为桌面响应速度带来了显著提升，但目前尚不足以作为所有工作负载和硬件类型的默认选项。在某些边缘情况下，错误（bug）可能导致系统卡死等问题。因此，它目前作为一项可选功能，供希望测试并受益于其最新改进的用户使用。

### NVIDIA Smooth Motion（RTX 40xx 和 50xx 系列）

:::note[游戏兼容性]
运行在 DX11、DX12 和 Vulkan 上的游戏。有关 OpenGL 的变通方法，请参阅 FAQ。

DXVK 和 VKD3D 均可正常工作。

**仅支持 64 位应用程序。Smooth Motion 不适用于 32 位应用程序（例如旧的 DX11 游戏）。**

:::

直接引用自 NVIDIA 文档：

*NVIDIA Smooth Motion 是一种基于驱动的全新 AI 模型，通过在两个渲染帧之间推断出一个额外帧来提供更流畅的游戏体验。对于不支持 DLSS Frame Generation 的游戏，NVIDIA Smooth Motion 是在 GeForce RTX 40 系列及更新 GPU 上提升体验的新选择。*

- 如何为游戏启用 NVIDIA Smooth Motion：
  - 添加以下环境变量：
    ```text
    NVPRESENT_ENABLE_SMOOTH_MOTION=1
    ```

常见问题（FAQ）：

- 为什么使用 Smooth Motion 而不是 DLSS Frame Generation？
  - 当游戏不支持 DLSS Frame Generation 时，Smooth Motion 凭借其基于驱动的 AI 模型可作为替代方案。
- 使用 Smooth Motion 有什么缺点吗？
  - 是的，由于额外的帧推断过程，启用 Smooth Motion 可能会引入轻微的输入延迟。
  - 容易与第三方画面叠加层（overlay）产生问题。为避免这种情况，请包含以下环境变量：
    ```text
    NVPRESENT_QUEUE_FAMILY=1
    ```
    :::note[使用此变量可能会对性能产生一定影响。]
    :::
- 为什么 MangoHud 没有报告增加后的帧率？
  - 目前，MangoHud 不会统计 Smooth Motion 生成的额外帧，从而导致报告的帧率产生误导。
    - 使用显示器内置的 FPS 计数器将提供正确的帧率。
- 与 DLSS Frame Generation 相比，图像质量如何？
  - 图像质量不如 DLSS Frame Generation，并且可能会引入画面伪影，尤其是在快速运动场景中。
- 它是否兼容外部帧率限制工具（例如 MangoHud）？
  - 不兼容。游戏内置的帧率限制应该可以正常工作。
- Smooth Motion 可以与 DLSS Frame Generation 同时使用吗？
  - 不可以。一次只能激活一种帧生成方法。
- Smooth Motion 可以用于 OpenGL 应用程序吗？
  - 不能直接使用，因为它是作为 Vulkan 层实现的，但可以通过利用 [Zink](https://docs.mesa3d.org/drivers/zink.html) 将 OpenGL 调用转换为 Vulkan 来实现：
    ```text
    NVPRESENT_ENABLE_SMOOTH_MOTION=1 zink-run <command>
    ```
    :::note
    使用 Zink 可能会影响性能，并在某些游戏中引入画面异常。

    双 GPU 用户需要设置 `DRI_PRIME=1` 以使用 NVIDIA 独立显卡（dGPU），而不是使用更常见的 GPU 选择方法。
    :::

## 省电调整

### thermald

`thermald` 是适用于 Intel 系统的热管理守护进程。它会监控温度传感器并在固件需要采用更激进的降频限流之前，执行诸如限制 CPU 功耗或调整性能状态等散热操作。

它主要适用于通过 `/sys/class/thermal` 暴露 Intel 温控接口的 Intel 笔记本电脑、二合一设备、平板电脑、掌机以及小型主机。受支持的系统通常使用 Intel CPU 温度传感器、Intel P-state、Intel power clamp、RAPL、`INT340X` 或 ACPI DPTF/自适应热表。`thermald` 不支持 AMD CPU。

使用以下命令安装并启用它：

```sh
sudo pacman -S thermald
sudo systemctl enable --now thermald.service
```

检查它是否已正确启动：

```sh
systemctl status thermald.service
journalctl -u thermald.service -b
```

更多信息：

### 启用 RCU Lazy

RCU Lazy 有助于降低空闲或轻负载系统的功耗。这对笔记本电脑和掌机设备非常有用。
在省电方面可带来 5-10% 的提升。不过需要注意，此省电特性可能会根据具体场景略微降低性能。
`linux-cachyos-deckify` 内核会默认启用此选项，因为省电对这类设备而言至关重要。

要启用 RCU Lazy，请将以下参数添加到你的内核 [cmdline](/zh/configuration/boot_manager_configuration/) 参数列表中：
```text
rcutree.enable_rcu_lazy=1
```

## NVIDIA 故障排除

### NVIDIA GSP 固件

NVIDIA GSP 固件**“在某些情况下”**会导致性能下降。虽然 555.58.02 NVIDIA 驱动在很大程度上解决了这个问题，但在某些系统上可能依然存在。
如果你在 KDE 中遇到卡顿或某些情况下性能不佳，可以通过以下配置文件禁用 GSP 固件：
`/etc/modprobe.d/nvidia-gsp.conf`

```text
options nvidia NVreg_EnableGpuFirmware=0
```

创建文件后，执行以下命令：
```sh
sudo mkinitcpio -P
```

:::note
NVIDIA 的[开源内核模块](https://github.com/NVIDIA/open-gpu-kernel-modules)基于 GSP 固件。因此无法禁用 GSP，使用这些模块时此 modprobe 选项将被忽略。请使用 `linux-cachyos-nvidia` 或 `nvidia-dkms`。
:::

通常建议在每次安装新的 NVIDIA 驱动后测试 GSP 固件，因为它经常会引入有益的功能。此外，NVIDIA 也已主要开始使用 GSP 固件进行 QA 测试。

## 音频和软件增强

### 增强笔记本扬声器音质

由于尺寸紧凑和硬件能力有限，笔记本电脑扬声器通常会发出单薄且不尽人意的声音。[EasyEffects](https://wiki.archlinux.org/title/PipeWire#EasyEffects) 可以通过应用各种音频效果和自定义配置，显著提升笔记本内置扬声器的音质。

要开始使用，你需要安装 EasyEffects 及所需依赖：

```bash
# Install EasyEffects
sudo pacman -S easyeffects
# Install additional plugins for more effects
sudo pacman -S lsp-plugins-lv2
sudo pacman -S zam-plugins
sudo pacman -S calf
sudo pacman -S mda.lv2
```

#### 配置

按照以下步骤配置 EasyEffects：

1. 从应用程序菜单启动 EasyEffects，或在终端中输入 `easyeffects`。
2. 导航至 **Output** 选项卡以管理应用于扬声器音频的效果。
3. 切换到 **Effects** 选项卡以添加、修改或调整音频效果。

<ImageComponent imgsrc={import('~/assets/images/easyeffects.png')} />

##### 使用社区预设

为了实现快速且有效的设置，可以从针对各种音频场景定制的**社区创建预设**开始：

1. 从 [EasyEffects Community Presets](https://github.com/wwmm/easyeffects/wiki/Community-presets) 仓库下载预设。
2. 在 EasyEffects 中，点击 **Presets** 按钮并选择 **“Import preset from local storage”**。
3. 找到并选择下载的预设文件。
4. 导入后，预设将出现在你的列表中——点击 **“Load”** 将其应用到音频输出。

<ImageComponent imgsrc={import('~/assets/images/easyeffects-presets.png')} />

##### 创建自定义配置文件

为了获得更个性化的音频体验，你可以为你的笔记本扬声器创建一个专属的自定义配置文件：

1. 点击 Presets 菜单中的 **“+”** 按钮创建一个新预设（例如命名为 **“Laptop Speakers”**）。
2. 选择 **“Load”** 激活新预设。
3. 在 **Output** > **Effects** 选项卡中添加并配置效果，尝试均衡器、低音增强器或立体声加宽器等选项。

##### 使用卷积器效果（Dolby Atmos 笔记本）

**卷积器（Convolver）效果**可以通过应用模拟高质量音频环境的脉冲响应（impulse response）来显著提升音质。不过，它需要精确的配置：

1. 在 **Effects** 选项卡中将 **Convolver** 效果添加到你的效果链。
2. 如果有适用于你笔记本电脑型号的脉冲响应文件（`.wav` 格式），请将其加载。你可以在以下资源中搜索此类文件：
   - https://wiki.archlinux.org/title/Lenovo_ThinkPad_T14_(AMD)_Gen_4#Speakers
   - https://github.com/m4tx/thinkpad-p14s-g4-linux/#sound
   - https://github.com/shuhaowu/linux-thinkpad-speaker-improvements/
3. **防止削波（clipping）**：Convolver 效果可能会显著提高音量。在效果链中的 Convolver 之后添加一个 **Limiter**（限幅器）效果，以控制峰值并避免失真。

<ImageComponent imgsrc={import('~/assets/images/easyeffects-convolver.png')} />

#### 获得最佳效果的提示

- **多做尝试**：尝试不同的预设，以找到最适合你特定笔记本电脑型号和个人听感偏好的选项。
- **循序微调**：对单个效果进行逐步调整，以防止失真或不自然的声音输出。
- **切换对比**：频繁切换 EasyEffects **开/关**，以对比评估相对于默认音频的提升。
- 搜索热门笔记本电脑型号（如 **Framework Laptop 13** 或 **ThinkPad T14**）的**设备专属预设或 Convolver 脉冲响应**，以获得量身定制的效果。
- **自动启动**：通过应用程序的偏好设置将 EasyEffects 配置为开机自启，以确保始终应用你的自定义配置文件。
- **为多个设备自动加载预设**：使用 **PipeWire** > **Presets Autoloading** 选项卡，将特定预设与不同的输出设备（例如扬声器与耳机）关联，从而实现无缝切换。<ImageComponent imgsrc={import('~/assets/images/easyeffects-autoloading.png')} />

### OBS Studio

我们在软件仓库中提供了一个自定义的 `obs-studio-browser` 软件包，相比标准的 `obs-studio` 软件包更推荐安装它。其中包含用于修复诸如 CUDA 错误和虚拟摄像头问题等常见问题的补丁。

## Swap 配置

### 从 ZRam 切换到 Zswap

默认情况下，CachyOS 使用 ZRam 进行交换空间（Swap）管理。不过，如果你更喜欢使用 Zswap，可以按照以下步骤轻松切换：

:::note
本指南假设你采用的是默认 CachyOS 设置，已启用 ZRam，且在安装过程中未创建交换分区或交换文件。
:::

<Steps>
    1. 通过添加内核参数来禁用 ZRam。[编辑你的引导管理器配置](/zh/configuration/boot_manager_configuration) 并添加以下内容：
        ```text
        systemd.zram=0
        ```
    2. 通过添加以下内核参数来启用 Zswap：
        ```text
        zswap.enabled=1 zswap.shrinker_enabled=1 zswap.compressor=lz4 zswap.max_pool_percent=30
        ```
    3. 创建一个空覆盖文件，以禁用会关闭 Zswap 的 [CachyOS udev 规则](https://github.com/CachyOS/CachyOS-Settings/blob/master/usr/lib/udev/rules.d/30-zram.rules)：
        ```bash
        sudo touch /etc/udev/rules.d/30-zram.rules
        ```
    4. 为 Zswap 创建一个交换文件。
        <details>
            <summary>如果你使用的是 Btrfs：</summary>
                <Steps>
                    1. 为交换文件创建一个 Btrfs 子卷：
                        ```bash
                        sudo btrfs subvolume create /swap
                        ```
                    2. 通过修改 `--size` 参数创建一个所需大小的交换文件（例如 8GB）：
                        ```bash "--size"
                        sudo btrfs filesystem mkswapfile --size 4g --uuid clear /swap/swapfile
                        ```
                    3. 激活该交换文件：
                        ```bash
                        sudo swapon /swap/swapfile
                        ```
                    4. 将交换文件添加到 `/etc/fstab` 中，使其在重启后持久生效：
                        ```bash
                        echo "/swap/swapfile none swap defaults 0 0" | sudo tee -a /etc/fstab
                        ```
                </Steps>
        </details>
        <details>
            <summary>如果你使用的不是 Btrfs：</summary>
            <Steps>
                1. 通过修改 `count=` 参数创建一个所需大小的交换文件（例如 8GB）：
                    ```bash "count=8"
                    sudo dd if=/dev/zero of=/swapfile bs=1G count=8
                    ```
                2. 为交换文件设置正确的权限：
                    ```bash
                    sudo chmod 0600 /swapfile
                    ```
                3. 格式化该交换文件：
                    ```bash
                    sudo mkswap /swapfile
                    ```
                4. 将交换文件添加到 `/etc/fstab` 中，使其在重启后持久生效：
                    ```bash
                    echo "/swapfile none swap defaults 0 0" | sudo tee -a /etc/fstab
                    ```
                5. 激活该交换文件：
                    ```bash
                    sudo swapon /swapfile
                    ```
            </Steps>
        </details>
    5. 将 lz4 压缩模块添加到 `mkinitcpio.conf` 配置文件中：
        1. 用文本编辑器打开该文件：
            ```bash
            sudo nano /etc/mkinitcpio.conf
            ```
        2. 找到 `MODULES` 数组并在其中添加 `lz4`。它看起来应该如下所示：
            ```text
            MODULES=(... lz4)
            ```
        3. 按 `Ctrl + O` 并按 `Enter` 确认保存文件，然后按 `Ctrl + X` 退出编辑器。
    6. 重新构建 initramfs 以应用更改。具体命令取决于你的引导管理器：
        <details>
            <summary>systemd-boot</summary>
            ```bash
            sudo sdboot-manage gen
            ```
        </details>
        <details>
            <summary>GRUB</summary>
            ```bash
            sudo grub-mkconfig -o /boot/grub/grub.cfg
            ```
        </details>
        <details>
            <summary>Limine</summary>
            ```bash
            sudo limine-mkinitcpio
            ```
        </details>
    7. 重启系统以应用所有更改。
</Steps>
