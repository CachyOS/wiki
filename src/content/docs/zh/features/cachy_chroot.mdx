[cachy-chroot](https://github.com/CachyOS/cachy-chroot) 是一个简单的辅助程序，用于简化 chroot 到现有 CachyOS 或基于 Arch 的安装系统中的过程。它会列出在机器上发现的所有分区，并支持列出 BTRFS 子卷。此外，`cachy-chroot` 还通过 LUKS 支持加密系统。它会将每个 `fstab` 条目映射到其对应的 `crypttab` 条目，并在退出 chroot 时优雅地关闭所有 LUKS 卷。

:::caution[cachy-chroot 旨在从 live CachyOS 环境中运行。]
:::

:::note
cachy-chroot 支持挂载 Linux 内核支持的任何文件系统，ZFS 除外。
:::

## 使用方法

:::tip
使用方向键导航选项，按 `ENTER` 选择。

**❯** 符号表示当前选中的选项。

**?** 表示需要用户输入。
:::

<Steps>
1. 启动到 CachyOS live ISO
2. 打开终端并使用 `sudo su` 进入 root 用户
3. 确保已安装最新版本的 `cachy-chroot`：
    ```bash
    pacman -Sy cachy-chroot
    ```
4. 输入以下命令运行 `cachy-chroot`：
    ```bash
    cachy-chroot
    ```

6. `cachy-chroot` 将尝试自动挂载根设备 `/etc/fstab` 中列出的所有分区和子卷。如果任何分区挂载失败，系统会通知您并提供手动挂载的选项。您可以选择 `no` 跳过挂载其他分区。
7. **现在您已进入 chroot 环境**。
    ```bash
    [root@CachyOS /]#
    ```
    现在您可以像在已安装系统中一样运行命令。例如，可以更新系统：
    ```bash title="在 chroot 中更新系统"
    pacman -Syu
    ```
    ```bash title="重新生成 initramfs（以防万一）"
    mkinitcpio -P
    ```
    或根据需要执行其他维护任务。
8. 完成后，在提示符输入 `exit` 或按键盘上的 `CTRL+D` 退出 chroot 环境。
    ```bash title="退出 chroot"
    exit
    ```
9. 退出后，`cachy-chroot` 将自动清理已挂载的分区并关闭任何 LUKS 容器。您将返回 live 环境的 shell。

### 故障排除

- **未找到分区：** 确保包含安装的磁盘已连接并被 live 系统识别。可以使用 `lsblk` 或 `fdisk -l` 检查。
- **某些分区自动挂载失败：** 可以尝试在 chroot 环境中手动挂载它们。`cachy-chroot` 会忽略失败并继续。

### 常见问题

- **问：手动挂载其他分区有什么用途？**
  - 答：手动挂载其他分区有多种用途，包括：
    - **fstab 文件损坏或丢失：** 可以手动挂载必要分区（如 `/boot` 或 `/home`）以执行修复或数据恢复。
    - **分区 UUID 已更新：** 如果因更改分区 UUID 导致系统无法启动，可以使用 `cachy-chroot` 挂载分区，然后相应更新 fstab。
