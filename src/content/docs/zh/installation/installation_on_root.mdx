## 开始之前

:::note
如果按下 **启动安装程序** 后只看到 GRUB 和 Limine 作为引导管理器选项，则系统以 Legacy/BIOS 模式启动。
:::

:::note[安装过程中不允许安装多个桌面环境。]
:::

:::caution[以 UEFI 模式安装时，必须在 BIOS/UEFI 设置中禁用 Secure Boot 和 CSM。]
安装后设置 Secure Boot，请参阅 [Secure Boot](/zh/configuration/secure_boot_setup) 部分。

`Legacy USB Support` 应设置为 `Auto`。
:::

:::caution
`Install alongside` 和 `Replace partition` 选项不是 100% 可靠，可能导致安装失败。

安装 CachyOS 时 **强烈建议** 使用 `Manual partitioning`。
:::

:::tip
安装失败后强烈建议重新启动到 ISO。

否则，安装过程中可能会出现持续的错误。

这是因为安装程序在安装失败时没有正确卸载分区。

:::

## 安装方法

### 手动分区

:::note[在进行 UEFI 安装的磁盘分区之前。]
    ```sh title='在终端中执行此命令'
    efibootmgr -v
    ```
如果输出为 `EFI variables are not supported on this system.`，则系统以 Legacy/BIOS 模式启动，你需要确保在 BIOS/UEFI 设置中配置了 UEFI 模式。请参阅 [Requisites](/zh/installation/installation_on_root/#before-you-begin) 部分。
:::

<Tabs>

4. 选择 **Manual partitioning**。

5. 根据所选引导管理器创建具有以下参数的新分区：
    <Tabs>

            - ##### 挂载点：**/boot**

            - ##### 大小：至少 **2048 MiB**
            - ##### 文件系统：**FAT32**
            - ##### 挂载点：**/boot**
            - ##### 标志：**boot**
        </TabItem>
        <TabItem label='GRUB'>
            - ##### 大小：至少 **512 MiB**

            - ##### 挂载点：**/boot/efi**

   - ##### 大小：至少 **20000 MiB**

   - ##### 挂载点：**/**
   - ##### 标志：

8. 选择安装过程中应安装的软件包。

9. 设置登录凭据。

10. 仔细检查安装摘要。如果一切正确，点击 **Install Now** 继续安装。否则，返回并进行必要的更改。

## Windows 和 CachyOS 双启动

:::note[本指南假设 Windows 已经安装在系统上，并且你决定与 Windows 一起安装 CachyOS，共享同一驱动器。]
:::

:::caution
Windows 和 Linux 双启动不是 100% 可靠的。Windows 更新可能会通过覆盖 EFI 分区破坏引导加载器。
在某些情况下，可能永远不会出现问题，但对某些用户来说这可能是一个反复出现的问题。

避免此问题的一种方法是将每个操作系统安装在单独的驱动器上。
:::

:::caution
根据目标引导管理器推荐的最低大小，EFI 分区可能需要调整大小。请参阅 [手动分区](/zh/installation/installation_on_root#manual-partitioning)。

FAT 文件系统无法就地调整大小。要正确"调整" FAT EFI 分区的大小，必须备份现有的 EFI 文件系统，使用 `gparted` 等工具调整现有分区的大小并重新格式化新分区，然后将之前的文件系统结构复制回 EFI 分区。
:::

### 前提条件

- 必须禁用 Windows 快速启动和休眠。
  - 以管理员身份打开 Windows Powershell 并执行以下命令：
      ```ps
      powercfg /H off
      ```
    重启系统以确保更改生效。
- 必须禁用 Windows BitLocker。
  - 检查 BitLocker 是否已启用：
    ```ps title='以管理员身份打开命令提示符并执行以下命令'
    manage-bde -status
    ```
  如果 **Encryption Method** 显示为 `None`，则 BitLocker 已禁用。
- 必须禁用 Secure Boot。
- 一个 ≥30 GB 的空分区。
  - 如何缩小 Windows 分区的指南：
    - 按 `Win + R`，输入 `diskmgmt.msc`，然后按 Enter 打开磁盘管理。
    - 找到你的主 Windows 分区（通常是 C:）并右键点击它。
    - 点击 `Shrink Volume...`，指定至少 **30720 MB**（30 GiB），然后点击 `Shrink`。
- 一个带有 CachyOS 的可启动 USB。
  - 请参阅 [创建可启动的 CachyOS USB 驱动器](/zh/installation/installation_prepare#creating-a-bootable-cachyos-usb-drive) 部分。

<Tabs>
    <TabItem label='Limine'>
        Limine 应该会自动检测 Windows EFI 分区并将其添加到启动菜单。如果 Windows 没有出现在启动菜单中，请运行以下命令：
        ```bash
        sudo limine-scan
        ```
    </TabItem>
    <TabItem label='systemd-boot'>
        **我们需要将 Windows EFI 二进制文件复制到 Linux EFI 分区，以便引导管理器可以识别它们。**

        <Steps>
        1. 使用 `lsblk` 找到 **Windows EFI 分区**。

            ```sh title='在终端中执行此命令'
            lsblk -o NAME,FSTYPE,SIZE,MOUNTPOINT
            ```
            ```sh title='示例输出'
                        NAME        FSTYPE   SIZE MOUNTPOINT
            zram0               15.3G [SWAP]
            nvme0n1            476.9G
            ├─nvme0n1p1 vfat     100M
            ├─nvme0n1p2           16M
            ├─nvme0n1p3 ntfs   234.4G
            ├─nvme0n1p4 ntfs     830M
            ├─nvme0n1p5 vfat       2G /boot
            └─nvme0n1p6 btrfs  239.6G /var/tmp
            ```
            EFI 分区几乎总是格式化为 `FAT32/vfat`。由于 `nvme0n1p1` 没有 Linux 挂载点，我们可以假设这个分区是 Windows EFI 分区。

        2. 临时挂载 Windows EFI 分区。

            ```sh
            sudo mkdir /mnt/WinBoot
            sudo mount /dev/nvme0n1p1 /mnt/WinBoot # 将 `nvme0n1p1` 替换为 Windows EFI 分区的名称。
            ```

        3. 从 **Windows EFI 分区** 复制 EFI 二进制文件到 **Linux EFI 分区**。

            ```sh
            sudo cp -r /mnt/WinBoot/EFI/Microsoft/ /boot/EFI
            ```

        4. 卸载之前挂载的分区。下次启动时 Windows 应该会出现在启动菜单中。

            ```sh
            sudo umount /mnt/WinBoot
            sudo rm -r /mnt/WinBoot
            ```

        </Steps>
    </TabItem>

    <TabItem label='GRUB（仅限旧版安装）'>
        :::tip[CachyOS 默认启用 os-prober。]
        :::
        **GRUB 使用 os-prober 自动检测 Windows EFI 分区并将其添加到启动菜单。**

        <Steps>
        1. 安装 **os-prober**。

            ```sh
            sudo pacman -S os-prober
            ```

        2. 在 GRUB 配置文件中启用 **os-prober**。

            ```sh title='按 CTRL+S 保存，按 CTRL+Q 退出 Micro'
            sudo micro /etc/default/grub
            # /etc/default/grub
            # Probing for other operating systems is disabled for security reasons. Read
            # documentation on GRUB_DISABLE_OS_PROBER, if still want to enable this
            # functionality install os-prober and uncomment to detect and include other
            # operating systems.
            GRUB_DISABLE_OS_PROBER=false

            ```

        3. 更新 grub.cfg，现在使用 **os-prober**。
            ```sh
            sudo grub-mkconfig -o /boot/grub/grub.cfg
            ```

            **Windows 现在应该已添加到启动菜单中。**

        </Steps>
    </TabItem>
</Tabs>
