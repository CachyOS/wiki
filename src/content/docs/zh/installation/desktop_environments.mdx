CachyOS 提供多种桌面环境供你选择。

这取决于个人偏好。选择你最喜欢的那一个。
:::note
安装期间请选择且仅选择一个桌面环境。
:::

可用的选项包括：

1. **KDE Plasma：** 一个全面且灵活的桌面环境，提供多种菜单样式来访问应用程序。它使用 KWin 窗口管理器。KDE Plasma 还拥有一个直观的界面，让你可以轻松地从网上下载和安装新主题、小部件等。
2. **Niri：** 一个可滚动的平铺式 Wayland 合成器，强调简洁和流畅的窗口管理。它使用连续网格布局，针对键盘和触摸板导航进行了优化。我们的 Niri [dotfiles](https://github.com/CachyOS/cachyos-niri-noctalia)。
3. **i3：** 一个流行的 X11 平铺窗口管理器，以其单一、自包含的配置文件和高效的屏幕空间利用而闻名。我们的 i3 [dotfiles](https://github.com/CachyOS/cachyos-i3wm-settings)。
4. **Qtile：** 一个使用 Python 编程语言配置的 X11/Wayland 窗口管理器。提供多种布局和小部件。我们的 [dotfiles](https://github.com/CachyOS/cachyos-qtile-settings)。
5. **Wayfire：** 一个基于 wlroots 的 Wayland 合成器，在自定义、可扩展性和美观性之间取得平衡。我们的 Wayfire [dotfiles](https://github.com/CachyOS/cachyos-wayfire-settings)。
6. **GNOME：** 一个用户友好的桌面环境，采用触摸式界面访问应用程序。虽然易于上手，但自定义选项有限，配置起来可能有些困难。
7. **XFCE：** 一个轻量级且灵活的桌面环境，采用传统的下拉/弹出菜单访问应用程序。它也与 Compiz 兼容。
8. **bspwm：** 一个基于 C 的 X11 窗口管理器，提供灵活的平铺、堆叠和标签布局。
9. **Budgie：** 一个使用 GTK 工具包构建的简单优雅的桌面环境。它旨在提供一个现代且吸引人的界面，易于使用，同时也高度可配置。
10. **Cinnamon：** 一个为 Linux 设计的桌面环境，在高级功能和传统用户体验之间取得平衡。
11. **Cosmic：** 一个现代、注重性能的桌面环境，使用 Rust 和 Smithay 构建。专为生产力和高级用户设计，旨在提供高级功能，同时保持简洁直观的界面。
12. **Hyprland：** 一个视觉上令人愉悦的 Wayland 合成器，使用动态平铺。默认随 CachyOS Noctalia 提供。我们的 dotfiles [在此](https://github.com/CachyOS/cachyos-hypr-noctalia)。
13. **LXDE**（Lightweight X11 Desktop Environment）：一个快速节能的桌面环境，设计用于旧电脑和资源受限的系统。它使用 Openbox 作为默认窗口管理器，专注于提供简单、干净和用户友好的界面。
14. **LXQt：** 一个轻量级桌面环境，由 LXDE 和 Razor-qt 项目合并而成，使用 Qt 构建。
15. **Mate Desktop：** 一个从 GNOME 2 分支出来的传统桌面环境。其特点是经典的外观和感觉，界面简单直观。Mate 为偏好经典外观的用户提供易于使用且高度可定制的桌面体验。
16. **Openbox：** 一个非常流行的 X11 窗口管理器，以其出色的文档和丰富的可用主题选择而闻名。
17. **Sway：** 一个平铺式 Wayland 合成器，也是 X11 上 i3 窗口管理器的直接替代品。它可以使用你现有的 i3 配置，并支持 i3 的大多数功能以及一些额外功能。
