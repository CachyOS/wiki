## 系统要求

在准备安装之前，请确保使用的计算机满足运行 CachyOS 的最低系统要求。安装程序使用在线安装过程，因此稳定的、相对快速的互联网连接是必需的。

:::note[虚拟机]
不建议在虚拟机上安装 CachyOS。虚拟机可能会出现配置不正确的问题，或者完全无法运行。建议在物理机上安装 CachyOS。
:::

<Tabs>

<TabItem label="最低要求">

*   3 GB RAM
*   30 GB 存储空间（HDD/SSD）
*   稳定的互联网连接

:::caution
不稳定的互联网可能导致安装时间延长，最坏情况下会导致安装失败。
:::

</TabItem>

<TabItem label="推荐要求">

*   8GB RAM
*   50 GB 存储空间（SSD/NVMe）
*   [x86-64-v3 兼容 CPU](/zh/installation/installation_prepare#x86_64-microarchitecture-level-support)
*   50 Mbps 或更快的网速
*   NVIDIA GPU（900+ - 例如：GTX 950）、AMD +GCN 1.0（例如：AMD R7 240）或 Intel（集成 HD Graphics 系列或更高。Arc 系列）

</TabItem>

</Tabs>

## 创建可启动的 CachyOS USB 驱动器

有多种工具和方法可用于创建 CachyOS 的可启动 USB 驱动器。

:::tip
在同一驱动器或不同位置保留一份 CachyOS ISO 副本，以便以后通过 chroot 进行故障排除时使用。
:::

:::note
USB 驱动器必须至少有 8GB 的可用空间。
:::

### balenaEtcher

<Steps>

1. 下载 [balenaEtcher](<https://etcher.balena.io/>). balenaEtcher 支持写入 Linux、MacOS 和 Windows 镜像。
   如果下载的是 `.zip` 文件，请解压并使用以下命令执行二进制文件：
      ```sh
      # 解压 zip 文件：
      bsdtar xvf <zip file name>
      # 进入新文件夹：
      cd balenaEtcher-linux-x64/
      # 执行 balenaEtcher：
      ./balena-etcher
      ```
2. 将 USB 驱动器插入计算机。
3. 选择 `Flash from file` 并选择 CachyOS ISO 镜像文件。
4. 点击 `Select target` 并选择之前插入的 USB 驱动器。
5. 按下 `Flash` 开始写入过程。

</Steps>

:::note
balenaEtcher 可能会提示需要管理员权限。如果是，请输入密码并点击 `Authenticate`。
:::

### 命令行界面（Linux & MacOS）

<Steps>

1. 插入 USB 驱动器。
2. 使用以下命令检测插入的 USB 驱动器：
   ```sh
   # Linux
   # USB 驱动器可以通过磁盘型号和大小识别，例如 /dev/sda。
   sudo fdisk -l

   # MacOS
   # USB 驱动器标识为 "/dev/diskY"，其中 "Y" 可能是 0、1 等。
   diskutil list
   ```
3. 运行以下命令将 ISO 内容复制到插入的 USB 驱动器：
   ```sh
   # 将 <usbdrive> 替换为驱动器的标签。
   sudo dd bs=4M if=full_iso_name.iso of=/dev/<usbdrive> status=progress oflag=sync
   ```
</Steps>

- `dd` 现在会将 ISO 文件的内容复制到插入的 USB 驱动器。

### Rufus（仅限 Windows）

<Steps>

1. 插入 USB 驱动器。
2. 下载 [Rufus](<https://rufus.ie/>) 并安装，或运行便携版。
3. 在 `Device` 上，点击下拉列表并选择插入的 USB 驱动器。
4. 在 `Boot selection` 上，点击 `SELECT` 并找到 CachyOS ISO 镜像文件。
5. 点击 `START`。

</Steps>

### Ventoy（Linux & Windows）

<Tabs>

<TabItem label="Linux">

<Steps>

1. 插入 USB 驱动器。
2. 下载 [Ventoy](<https://www.ventoy.net/en/download.html>)
3. 使用以下命令解压 Ventoy：
   ```sh
   # 将 version 替换为正确的版本，例如 ventoy-1.1.07-linux.tar.gz
   bsdtar xvf ventoy-version-linux.tar.gz
   # 进入新文件夹：（版本可能不同）
   cd ventoy-1.1.07/
   ```
4. 通过双击或通过终端执行 `VentoyGUI.x86_64`：
   ```sh
   # 会要求管理员权限，输入你的凭据
   ./VentoyGUI.x86_64
   ```
5. 点击 `Device` 选择插入的 USB 驱动器。
6. 点击 `Install`。
7. 完成将 Ventoy 安装到插入的 USB 驱动器后，关闭窗口并将 CachyOS ISO 文件放入驱动器的新可用分区中。

</Steps>

</TabItem>

<TabItem label="Windows">

<Steps>
1. 插入 USB 驱动器。
2. 下载 [Ventoy](<https://www.ventoy.net/en/download.html>)
3. 运行 `Ventoy2Disk.exe`
4. 点击 `Device` 选择插入的 USB 驱动器。
5. 点击 `Install`。
6. 完成将 Ventoy 安装到 USB 驱动器后，关闭窗口并将 CachyOS ISO 文件放入驱动器的新可用分区中。
</Steps>

</TabItem>

</Tabs>
