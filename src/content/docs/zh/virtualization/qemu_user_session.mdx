## 使用场景：
- **网络**

Root session 不允许 VM 转发端口，而是使用 **NAT**，
这意味着虽然你的 VM 可以看到外部世界，但外部世界看不到你的 VM，
只能看到你的 PC。这没问题，除非你想从 PC 外部直接连接到
你的 VM（例如通过 ssh），你做不到，因为没有可连接的东西。

- **通过转换实现 3D 加速**

Root session 不允许 VMM 使用渲染节点 `/dev/dri/renderD128`，
并且削弱了 `qemu-cli`，因为普通用户几乎无法使用 root qemu。

## 启用 User Session：
非常简单，在主 **VMM** 窗口中，点击 `File -> Add Connection...`
在 `Hypervisor:` 下拉菜单中，选择 `QEMU/KVM user session`。你现在可以按照
[QEMU 和 VMM 设置](/zh/virtualization/qemu_and_vmm_setup) 中的说明以 User 模式而非 Root 模式创建 VM。
