---
title: Using Obs Studio
---



There are many packages providing the Obs Studio but the recommended one for Cachy OS is the obs-studio-browser package from the Cachy OS repo. It is patched with all the required dependencies for smooth install.
It is can be found by searching obs-studio-browser in the Cachy OS Package Installer or by typing '''sudo pacman -S obs-studio-browser''' in the terminal and rebooting.
