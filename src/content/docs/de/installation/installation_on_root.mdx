## Voraussetzungen

:::caution[Secure Boot, CSM und Legacy-USB-Unterstützung müssen in den BIOS/UEFI-Einstellungen deaktiviert sein, wenn im UEFI-Modus installiert wird.]
Informationen zur Einrichtung von Secure Boot nach der Installation finden Sie im Abschnitt [Secure Boot](/de/configuration/secure_boot_setup).
:::

:::caution[Vermeiden Sie die Option „Parallel installieren“ in Calamares, da dies zu Komplikationen führen kann und nicht empfohlen wird.]
:::

:::tip
Es wird dringend empfohlen, die ISO nach einem fehlgeschlagenen Installationsversuch neu zu starten.

Andernfalls können während des Installationsprozesses fortlaufend Fehler auftreten.

Dies geschieht, weil der Installer bei einer fehlgeschlagenen Installation die Partitionen nicht ordnungsgemäß aushängt.

:::

## Installationsmethoden

### Festplatte löschen

Die Option „Festplatte löschen“ in Calamares löscht die ausgewählte Festplatte und installiert CachyOS auf dem Ziel.

<Steps>

1. Booten Sie von der ISO und klicken Sie auf **Installer starten**

2. Wählen Sie den bevorzugten **Bootmanager**. Weitere Informationen finden Sie im Abschnitt [Bootmanager](/de/installation/boot_managers).

3. Stellen Sie die bevorzugte **Sprache** und **Region/Zeitzone** ein

4. Konfigurieren Sie das **Tastaturlayout**

5. Wählen Sie **Festplatte löschen** und wählen Sie ein [Dateisystem](/de/installation/filesystem).

6. Wählen Sie die **Desktop-Umgebung** Ihrer Wahl, siehe [Desktop-Umgebungen](/de/installation/desktop_environments).

7. Passen Sie an, welche Pakete während des Installationsprozesses installiert oder nicht installiert werden sollen.

8. Richten Sie Anmeldeinformationen ein.

9. Überprüfen Sie die Installationszusammenfassung auf der Übersichtsseite sorgfältig. Fahren Sie mit der Installation fort, indem Sie auf **Jetzt installieren** klicken, wenn alles korrekt aussieht. Andernfalls gehen Sie zurück und nehmen Sie die erforderlichen Änderungen vor.

</Steps>

### Manuelle Partitionierung

:::note[Bevor Sie mit der Partitionierung der Festplatte für eine UEFI-Installation fortfahren.]
    ```sh title='Führen Sie diesen Befehl im Terminal aus'
    efibootmgr -v
    ```
Wenn die Ausgabe lautet: `EFI variables are not supported on this system.` dann ist das System im Legacy/BIOS-Modus gebootet und Sie müssen sicherstellen, dass der UEFI-Modus in den BIOS/UEFI-Einstellungen konfiguriert ist. Beachten Sie den **[Abschnitt Voraussetzungen](/de/installation/installation_on_root#_top).**
:::

## Dual Boot

:::note[Diese Anleitung geht davon aus, dass Windows bereits auf dem System installiert ist und Sie sich entschieden haben, CachyOS parallel dazu zu installieren. ]
:::

:::caution
Stellen Sie sicher, dass der Windows-Schnellstart deaktiviert ist.
:::

<Tabs>
    <TabItem label='systemd-boot'>
        **Wir müssen die Windows-EFI-Binärdateien in die Linux-EFI-Partition kopieren, damit der Bootmanager sie erkennen kann.**

        <Steps>
        1. Finden Sie die **Windows-EFI-Partition** mit `lsblk`

            ```sh title='Führen Sie diesen Befehl im Terminal aus'
            lsblk -o NAME,FSTYPE,SIZE,MOUNTPOINT
            ```
            ```sh title='Beispielausgabe'
                        NAME        FSTYPE   SIZE MOUNTPOINT
            zram0               15.3G [SWAP]
            nvme0n1            476.9G
            ├─nvme0n1p1 vfat     100M
            ├─nvme0n1p2           16M
            ├─nvme0n1p3 ntfs   234.4G
            ├─nvme0n1p4 ntfs     830M
            ├─nvme0n1p5 vfat       2G /boot
            └─nvme0n1p6 btrfs  239.6G /var/tmp
            ```
            EFI-Partitionen sind fast immer als `FAT32/vfat` formatiert. Da `nvme0n1p1` keinen Linux-Einhängepunkt hat, können wir davon ausgehen, dass diese Partition die Windows-EFI-Partition ist.

        2. Hängen Sie die Windows-EFI-Partition vorübergehend ein

            ```sh
            sudo mount /dev/nvme0n1p1 /mnt/WinBoot # Ersetzen Sie `nvme0n1p1` durch den Namen der Windows-EFI-Partition.
            ```

        3. Kopieren Sie die EFI-Binärdateien von der **Windows-EFI-Partition** in die **Linux-EFI-Partition**:

            ```sh
            sudo cp -r /mnt/WinBoot/EFI/* /boot/EFI
            ```

        4. Hängen Sie die zuvor eingehängte Partition aus, und Windows sollte beim nächsten Start im Boot-Menü erscheinen.

            ```sh
            sudo umount /mnt/WinBoot
            ```

        </Steps>
    </TabItem>

    <TabItem label='GRUB'>
        **GRUB verwendet os-prober, um die Windows-EFI-Partition automatisch zu erkennen und dem Boot-Menü hinzuzufügen.**

        <Steps>
        1. Installieren und führen Sie **os-prober** aus

            ```sh
            sudo pacman -S os-prober
            sudo os-prober
            ```

        2. Aktivieren Sie **os-prober** in der GRUB-Konfigurationsdatei

            ```sh title='Drücken Sie STRG+S zum Speichern und STRG+Q zum Beenden von Micro'
            sudo micro /etc/default/grub
            # /etc/default/grub
            # Das Suchen nach anderen Betriebssystemen ist aus Sicherheitsgründen deaktiviert. Lesen Sie die
            # Dokumentation zu GRUB_DISABLE_OS_PROBER, wenn Sie diese Funktionalität
            # dennoch aktivieren möchten, installieren Sie os-prober und entfernen Sie das Kommentarzeichen,
            # um andere Betriebssysteme zu erkennen und einzubinden.
            GRUB_DISABLE_OS_PROBER=false

            sudo grub-mkconfig -o /boot/grub/grub.cfg
            ```

            **Windows sollte jetzt dem Boot-Menü hinzugefügt sein.**

        </Steps>
    </TabItem>
</Tabs>
