## Voraussetzungen

:::note[Wenn nur GRUB und Liminie als Bootmanager angeboten werden nach Installationsstart, dann ist das System in Legacy/BIOS-mode gestartet.]
:::

:::danger[Die Installation mehrere Desktop-Umgebungen ist während der Installationsvorgangs nicht zulässig.]
:::

:::caution[Secure Boot, CSM und Legacy-USB-Unterstützung müssen in den BIOS/UEFI-Einstellungen deaktiviert sein, wenn im UEFI-Modus installiert wird.]
Informationen zur Einrichtung von Secure Boot nach der Installation findest du im Abschnitt [Secure Boot](/de/configuration/secure_boot_setup).
:::

:::caution[Vermeide die Option „Parallel installieren“ und "Partition ersetzen" in Calamares, da dies zu Komplikationen führen kann und nicht empfohlen wird.]
:::

:::tip
Es wird dringend empfohlen, die ISO nach einem fehlgeschlagenen Installationsversuch neu zu starten.

Andernfalls können während des Installationsprozesses fortlaufend Fehler auftreten.

Dies geschieht, weil der Installer bei einer fehlgeschlagenen Installation die Partitionen nicht ordnungsgemäß aushängt.
:::

## Installationsmethoden

### Festplatte löschen

Die Option „Festplatte löschen“ in Calamares löscht die ausgewählte Festplatte und installiert CachyOS auf dem Ziel.

<Steps>

1. Boote von der ISO und klicke auf **Installer starten**

2. Wähle den bevorzugten **Bootmanager**. Weitere Informationen findest du im Abschnitt [Bootmanager](/de/installation/boot_managers).

3. Stelle die bevorzugte **Sprache** und **Region/Zeitzone** ein

4. Konfiguriere das **Tastaturlayout**

5. Wähle **Festplatte löschen** und wähle ein [Dateisystem](/de/installation/filesystem).

6. Wähle die **Desktop-Umgebung** deiner Wahl, siehe [Desktop-Umgebungen](/de/installation/desktop_environments).

7. Passe an, welche Pakete während des Installationsprozesses installiert oder nicht installiert werden sollen.

8. Richte Anmeldeinformationen ein.

9. Überprüfe die Installationszusammenfassung auf der Übersichtsseite sorgfältig. Fahre mit der Installation fort, indem du auf **Jetzt installieren** klickst, wenn alles korrekt aussieht. Andernfalls gehe zurück und nimm die erforderlichen Änderungen vor.

</Steps>

### Manuelle Partitionierung

:::note[Bevor du mit der Partitionierung der Festplatte für eine UEFI-Installation fortfährst.]
    ```sh title='Führe diesen Befehl im Terminal aus'
    efibootmgr -v
    ```
Wenn die Ausgabe lautet: `EFI variables are not supported on this system.` dann ist das System im Legacy/BIOS-Modus gebootet und du musst sicherstellen, dass der UEFI-Modus in den BIOS/UEFI-Einstellungen konfiguriert ist. Beachte den **[Abschnitt Voraussetzungen](/de/installation/installation_on_root#_top).**
:::

## Dual Boot Windows und CachyOS

:::note[Diese Anleitung geht davon aus, dass Windows bereits auf dem System installiert ist und du dich entschieden hast, CachyOS parallel dazu zu installieren. ]
:::

:::caution
Das Dual-Booting von Windows und Linux ist nicht zu 100% zuverlässig. Windows-Updates können den Bootloader beschädigen, indem sie die EFI-Partition überschreiben.
In einigen Fällen treten möglicherweise nie Probleme auf, für manche Benutzer kann dies jedoch ein wiederkehrendes Problem sein.

Eine Möglichkeit, dieses Problem zu vermeiden, besteht darin, jedes Betriebssystem auf einem separaten Laufwerk zu installieren.
:::

:::Achtung
Je nach der empfohlenen Mindestgröße des Ziel-Bootmanagers muss die Größe der EFI-Partition möglicherweise angepasst werden. Siehe **[Manuelles Partitionieren](/installation/installation_on_root#manual-partitioning)**. FAT-Dateisysteme können nicht an Ort und Stelle in der Größe geändert werden. Um die FAT-EFI-Partition in der Größe zu ändern, muss das vorhandene EFI-Dateisystem gesichert werden, die vorhandene Partition kann dann mit einem Tool wie `gparted` in der Größe geändert werden und die neue Partition neu formatieren und anschließend die vorherige Dateisystemstruktur zurück in die EFI-Partition kopieren.
:::

### Voraussetzungen

- Deaktivieren Sie den schnellen Start und den Ruhezustand von Windows.
  - Öffnen Sie Windows Powershell als Administrator und führen Sie den folgenden Befehl aus:
      ```ps
      powercfg /H off
      ```
Starten Sie das System neu, um sicherzustellen, dass die Änderungen wirksam werden.
- Windows BitLocker muss deaktiviert sein.
  - So überprüfen Sie, ob BitLocker aktiviert ist:
    ```ps title='Öffnen Sie eine Eingabeaufforderung als Administrator und führen Sie den folgenden Befehl aus'
    manage-bde -status
    ```
  Wenn als Verschlüsselungsmethode „Keine“ angezeigt wird, ist BitLocker deaktiviert.
- Secure Boot muss deaktiviert sein.
- Eine leere Partition mit mindestens 30 GB
  - Anleitung zum Verkleinern einer Windows-Partition:
    - Drücken Sie „Win + R“, geben Sie „diskmgmt.msc“ ein und drücken Sie die Eingabetaste, um die Datenträgerverwaltung zu öffnen.
    - Suchen Sie Ihre Windows-Hauptpartition (normalerweise C:) und klicken Sie mit der rechten Maustaste darauf.
    - Klicken Sie auf 'Volume verkleinern...' und geben Sie mindestens **30720 MB** (30 GB) an. Klicken Sie anschließend auf „Verkleinern“.
- Eine EFI-Partition mit mindestens 2GB
- Bootfähiger USB-Stick mit CachyOS
  - Weitere Informationen finden Sie im Abschnitt [Erstellen eines bootfähigen CachyOS-USB-Sticks](/installation/installation_prepare#creating-a-bootable-cachyos-usb-drive).

<Tabs>
    <TabItem label='systemd-boot'>
        **Wir müssen die Windows-EFI-Binärdateien in die Linux-EFI-Partition kopieren, damit der Bootmanager sie erkennen kann.**

        <Steps>
        1. Finde die **Windows-EFI-Partition** mit `lsblk`

            ```sh title='Führe diesen Befehl im Terminal aus'
            lsblk -o NAME,FSTYPE,SIZE,MOUNTPOINT
            ```
            ```sh title='Beispielausgabe'
                        NAME        FSTYPE   SIZE MOUNTPOINT
            zram0               15.3G [SWAP]
            nvme0n1            476.9G
            ├─nvme0n1p1 vfat     100M
            ├─nvme0n1p2           16M
            ├─nvme0n1p3 ntfs   234.4G
            ├─nvme0n1p4 ntfs     830M
            ├─nvme0n1p5 vfat       2G /boot
            └─nvme0n1p6 btrfs  239.6G /var/tmp
            ```
            EFI-Partitionen sind fast immer als `FAT32/vfat` formatiert. Da `nvme0n1p1` keinen Linux-Einhängepunkt hat, können wir davon ausgehen, dass diese Partition die Windows-EFI-Partition ist. Hinweis: Die EFI-Partition sollte eine Größe von 2 GB haben, andernfalls schlägt die Installation fehl. 

        2. Hänge die Windows-EFI-Partition vorübergehend ein

            ```sh
            sudo mount /dev/nvme0n1p1 /mnt/WinBoot # Ersetze `nvme0n1p1` durch den Namen der Windows-EFI-Partition.
            ```

        3. Kopiere die EFI-Binärdateien von der **Windows-EFI-Partition** in die **Linux-EFI-Partition**:

            ```sh
            sudo cp -r /mnt/WinBoot/EFI/* /boot/EFI
            ```

        4. Hänge die zuvor eingehängte Partition aus, und Windows sollte beim nächsten Start im Boot-Menü erscheinen.

            ```sh
            sudo umount /mnt/WinBoot
            ```

        </Steps>
    </TabItem>

    <TabItem label='GRUB'>
        **GRUB verwendet os-prober, um die Windows-EFI-Partition automatisch zu erkennen und dem Boot-Menü hinzuzufügen.**

        <Steps>
        1. Installiere und führe **os-prober** aus

            ```sh
            sudo pacman -S os-prober
            sudo os-prober
            ```

        2. Aktiviere **os-prober** in der GRUB-Konfigurationsdatei

            ```sh title='Drücke STRG+S zum Speichern und STRG+Q zum Beenden von Micro'
            sudo micro /etc/default/grub
            # /etc/default/grub
            # Das Suchen nach anderen Betriebssystemen ist aus Sicherheitsgründen deaktiviert. Lies die
            # Dokumentation zu GRUB_DISABLE_OS_PROBER, wenn du diese Funktionalität
            # dennoch aktivieren möchtest, installiere os-prober und entferne das Kommentarzeichen,
            # um andere Betriebssysteme zu erkennen und einzubinden.
            GRUB_DISABLE_OS_PROBER=false

            sudo grub-mkconfig -o /boot/grub/grub.cfg
            ```

            **Windows sollte jetzt dem Boot-Menü hinzugefügt sein.**

        </Steps>
    </TabItem>
</Tabs>
