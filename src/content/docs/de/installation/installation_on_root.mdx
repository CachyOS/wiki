## Bevor du anfängst

:::note[Wenn du nach dem Drücken von „Installer starten“ nur GRUB und Limine als Bootmanager-Optionen siehst, dann ist das System im Legacy/BIOS-Modus gebootet.]
:::

:::danger[Die Installation mehrerer Desktop-Umgebungen ist während des Installationsprozesses nicht erlaubt.]
:::

:::caution[Secure Boot und CSM müssen in den BIOS/UEFI-Einstellungen deaktiviert sein, wenn du im UEFI-Modus installierst.]
Um Secure Boot nach der Installation einzurichten, schau im Abschnitt [Secure Boot](/de/configuration/secure_boot_setup) nach.

`Legacy USB Support` sollte auf `Auto` stehen.
:::

:::caution
Die Optionen `Parallel installieren` und `Partition ersetzen` sind nicht 100% zuverlässig und können dazu führen, dass die Installation fehlschlägt.

`Manuelle Partitionierung` ist die **bevorzugte** Methode bei der Installation von CachyOS.
:::

:::tip
Es wird dringend empfohlen, die ISO nach einem fehlgeschlagenen Installationsversuch neu zu starten.

Andernfalls können während des Installationsprozesses immer wieder Fehler auftreten.

Das passiert, weil der Installer bei einer fehlgeschlagenen Installation die Partitionen nicht richtig aushängt.

:::

## Installationsmethoden

### Manuelle Partitionierung

:::note[Bevor du mit der Partitionierung der Festplatte für eine UEFI-Installation fortfährst.]
    ```sh title='Führe diesen Befehl im Terminal aus'
    efibootmgr -v
    ```
Wenn die Ausgabe lautet: `EFI variables are not supported on this system.`, dann ist das System im Legacy/BIOS-Modus gebootet und du musst sicherstellen, dass der UEFI-Modus in den BIOS/UEFI-Einstellungen konfiguriert ist. Siehe dazu den **[Abschnitt Voraussetzungen](/de/installation/installation_on_root#_top).**
:::

#### UEFI/GPT

Die Partitionstabelle variiert je nach Bootmanager. Bitte folge den richtigen Anweisungen für jeden.

<Tabs>

<TabItem label='systemd-boot & rEFInd'>

<Steps>

1. Boote in die ISO und klicke auf den Button **Installer starten**

2. Stell deine bevorzugte **Sprache** und **Region/Zeitzone** ein

3. Konfiguriere das **Tastaturlayout**

4. Wähle **Manuelle Partitionierung**

5. Erstelle eine neue Partition mit folgenden Eigenschaften:
   - ##### Größe: **2048MiB**
   - ##### Dateisystem: **FAT32**
   - ##### Einhängepunkt: **/boot**
   - ##### Flags: **boot**

6. Erstelle eine weitere Partition für **root**:
   - ##### Größe: Mindestens **20000MiB**
   - ##### Dateisystem: **Beliebig**, siehe [Dateisystem](/de/installation/filesystem)
   - ##### Einhängepunkt: **/**
   - ##### Flags:

7. Überprüfe, ob **Bootloader installieren auf:** auf **/boot** zeigt

8. Wähle die **Desktop-Umgebung** deiner Wahl, siehe [Desktop-Umgebungen](/de/installation/desktop_environments).

9. Passe an, welche Pakete während des Installationsprozesses installiert oder nicht installiert werden sollen.

10. Richte die Anmeldedaten ein.

11. Überprüfe die Installationszusammenfassung auf der Übersichtsseite sorgfältig. Fahre mit der Installation fort, indem du auf **Jetzt installieren** klickst, wenn alles korrekt aussieht. Andernfalls gehe zurück und nimm die notwendigen Änderungen vor.

</Steps>

## Dual-Boot von Windows und CachyOS

:::note[Diese Anleitung geht davon aus, dass Windows bereits auf dem System installiert ist und du dich entschieden hast, CachyOS parallel dazu auf demselben Laufwerk zu installieren.]
:::

:::caution
Dual-Boot von Windows und Linux ist nicht 100% zuverlässig. Windows-Updates können den Bootloader beschädigen, indem sie die EFI-Partition überschreiben.
In manchen Fällen treten vielleicht nie Probleme auf, aber für einige Benutzer kann es ein wiederkehrendes Problem sein.

Eine Möglichkeit, dieses Problem zu vermeiden, ist die Installation jedes Betriebssystems auf separaten Laufwerken.
:::

:::caution
Es kann sein, dass du die Größe der EFI-Partition anpassen musst, je nachdem, welche Mindestgröße der Ziel-Bootmanager empfiehlt. Schau dir dazu **[Manuelle Partitionierung](/de/installation/installation_on_root#manuelle-partitionierung)** an. Denk dran, dass die Größe von FAT-Dateisystemen nicht einfach so geändert werden kann. Um die FAT-EFI-Partition richtig in der Größe zu ändern, musst du das vorhandene EFI-Dateisystem sichern, mit einem Tool wie `gparted` die bestehende Partition vergrößern oder verkleinern, die neue Partition neu formatieren und dann die alte Dateisystemstruktur wieder in die EFI-Partition zurückkopieren.
:::

- Voraussetzungen

- Deaktiviere den Windows-Schnellstart und den Ruhezustand
  - Öffne Windows Powershell als Administrator und führe den folgenden Befehl aus:
      ```ps
      powercfg /H off
      ```
    Starte das System neu, um sicherzustellen, dass die Änderungen wirksam werden.
- Windows BitLocker muss deaktiviert sein
  - Überprüfen, ob BitLocker aktiviert ist:
    ```ps title='Öffne eine Eingabeaufforderung als Administrator und führe den folgenden Befehl aus'
    manage-bde -status
    ```
  Wenn bei der Verschlüsselungsmethode `Keine` steht, dann ist BitLocker deaktiviert.
- Secure Boot muss deaktiviert sein.
- Eine leere Partition von +30GB
  - Anleitung zum Verkleinern einer Windows-Partition:
    - Drücke `Win + R`, tippe `diskmgmt.msc` ein und drücke Enter, um die Datenträgerverwaltung zu öffnen.
    - Finde deine Haupt-Windows-Partition (normalerweise C:) und klicke mit der rechten Maustaste darauf.
    - Klicke auf `Volume verkleinern...`, gib mindestens **30720MB** (30GB) an und klicke auf `Verkleinern`.
- Bootfähiger USB-Stick mit CachyOS
  - Siehe Abschnitt [Erstellen eines bootfähigen CachyOS-USB-Laufwerks](/de/installation/installation_prepare#einen-bootfähigen-cachyos-usb-stick-erstellen).

<Tabs>
    <TabItem label='systemd-boot'>
        **Wir müssen die Windows-EFI-Binärdateien auf die Linux-EFI-Partition kopieren, damit der Bootmanager sie erkennen kann.**

        <Steps>
        1. Finde die **Windows-EFI-Partition** mit `lsblk`

            ```sh title='Führe diesen Befehl im Terminal aus'
            lsblk -o NAME,FSTYPE,SIZE,MOUNTPOINT
            ```
            ```sh title='Beispielausgabe'
                        NAME        FSTYPE   SIZE MOUNTPOINT
            zram0               15.3G [SWAP]
            nvme0n1            476.9G
            ├─nvme0n1p1 vfat     100M
            ├─nvme0n1p2           16M
            ├─nvme0n1p3 ntfs   234.4G
            ├─nvme0n1p4 ntfs     830M
            ├─nvme0n1p5 vfat       2G /boot
            └─nvme0n1p6 btrfs  239.6G /var/tmp
            ```
            EFI-Partitionen sind fast immer als `FAT32/vfat` formatiert. Da `nvme0n1p1` keinen Linux-Einhängepunkt hat, können wir davon ausgehen, dass diese Partition die Windows-EFI-Partition ist.

        2. Hänge die Windows-EFI-Partition temporär ein

            ```sh
            sudo mkdir /mnt/WinBoot
            sudo mount /dev/nvme0n1p1 /mnt/WinBoot # Ersetze `nvme0n1p1` durch den Namen der Windows-EFI-Partition.
            ```

        3. Kopiere die EFI-Binärdateien von der **Windows-EFI-Partition** auf die **Linux-EFI-Partition**:

            ```sh
            sudo cp -r /mnt/WinBoot/EFI/Microsoft/ /boot/EFI
            ```

        4. Hänge die zuvor eingehängte Partition aus, und Windows sollte beim nächsten Start im Bootmenü erscheinen.

            ```sh
            sudo umount /mnt/WinBoot
            sudo rm -r /mnt/WinBoot
            ```

        </Steps>
    </TabItem>

    <TabItem label='GRUB'>
        **GRUB verwendet os-prober, um die Windows-EFI-Partition automatisch zu erkennen und zum Bootmenü hinzuzufügen.**

        <Steps>
        1. Installiere und führe **os-prober** aus

            ```sh
            sudo pacman -S os-prober
            sudo os-prober
            ```

        2. Aktiviere **os-prober** in der GRUB-Konfigurationsdatei

            ```sh title='Drücke STRG+S zum Speichern und STRG+Q zum Verlassen von Micro'
            sudo micro /etc/default/grub
            # /etc/default/grub
            # Probing for other operating systems is disabled for security reasons. Read
            # documentation on GRUB_DISABLE_OS_PROBER, if still want to enable this
            # functionality install os-prober and uncomment to detect and include other
            # operating systems.
            GRUB_DISABLE_OS_PROBER=false

            sudo grub-mkconfig -o /boot/grub/grub.cfg
            ```

            **Windows sollte nun zum Bootmenü hinzugefügt sein.**

        </Steps>
    </TabItem>
</Tabs>
