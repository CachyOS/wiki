## Systemanforderungen

Bevor du die Installation vorbereitest, stell sicher, dass der Computer, den du verwendest, die minimalen Systemanforderungen erfüllt, um CachyOS ausführen zu können. Der Installer
verwendet einen Online-Installationsprozess, daher ist eine stabile und relativ schnelle Internetverbindung zwingend erforderlich.

:::note[Virtuelle Maschinen]
Es wird nicht empfohlen, CachyOS auf einer virtuellen Maschine zu installieren. VMs können Probleme durch falsche Konfiguration aufweisen oder gänzlich defekt sein. Es wird empfohlen, CachyOS direkt auf der Hardware („bare metal“) zu installieren.
:::

<Tabs>

<TabItem label="Mindestanforderungen">

*   3 GB RAM
*   30 GB Speicherplatz (HDD/SSD)
*   Stabile Internetverbindung

:::caution
Eine instabile Internetverbindung kann im schlimmsten Fall zu verlängerten Installationszeiten oder fehlgeschlagenen Installationen führen.
:::

</TabItem>

<TabItem label="Empfohlene Anforderungen">

*   8 GB RAM
*   50 GB Speicherplatz (SSD/NVMe)
*   [x86-64-v3-fähige CPU](/de/installation/installation_prepare#x86_64-microarchitecture-level-support)
*   50 Mbit/s oder schnellere Internetgeschwindigkeit
*   NVIDIA GPU (900+ - z.B.: GTX 950), AMD +GCN 1.0 (z.B.: AMD R7 240) oder Intel (integrierte HD Graphics-Serie oder höher. Arc-Serie)

</TabItem>

</Tabs>

## Erstellen eines bootfähigen CachyOS-USB-Laufwerks

Es gibt mehrere Werkzeuge und Methoden, um ein bootfähiges USB-Laufwerk von CachyOS zu erstellen.

:::note
Der USB-Stick muss mindestens 8 GB freien Speicherplatz haben.
:::

### balenaEtcher

<Steps>

1. Lade [balenaEtcher](<https://etcher.balena.io/>) herunter. balenaEtcher unterstützt das Flashen eines Images unter Linux, MacOS und Windows.
   Wenn eine `.zip`-Datei heruntergeladen wurde, entpacke sie und führe die Binärdatei mit den folgenden Befehlen aus:
      ```sh
      # ZIP-Datei entpacken:
      bsdtar xvf <zip file name>
      # In den neuen Ordner wechseln:
      cd balenaEtcher-linux-x64/
      # balenaEtcher ausführen:
      ./balena-etcher
      ```
2. Schließe einen USB-Stick an deinen Computer an.
3. Wähle `Flash from file` und wähle die CachyOS ISO-Image-Datei aus.
4. Klicke auf `Select target` und wähle den zuvor angeschlossenen USB-Stick.
5. Drücke `Flash`, um den Flash-Vorgang zu starten.

</Steps>

:::note
balenaEtcher fragt möglicherweise nach Administratorrechten. Gib in diesem Fall dein Passwort ein und klicke auf `Authentifizieren`.
:::

### Kommandozeile (Linux & MacOS)

<Steps>

1. Schließe einen USB-Stick an.
2. Finde den angeschlossenen USB-Stick mit den folgenden Befehlen:
   ```sh
   # Linux
   # Der USB-Stick könnte z.B. als /dev/sda identifiziert werden, anhand des Festplattenmodells und der Größe.
   sudo fdisk -l

   # MacOS
   # USB-Sticks werden als "/dev/diskY" identifiziert, wobei "Y" 0, 1 usw. sein kann.
   diskutil list
   ```
3. Kopiere den Inhalt der ISO-Datei auf den angeschlossenen USB-Stick, indem du Folgendes ausführst:
   ```sh
   # Ersetze <usbdrive> durch die Bezeichnung des Laufwerks.
   sudo dd bs=4M if=full_iso_name.iso of=/dev/<usbdrive> status=progress oflag=sync
   ```
</Steps>

- `dd` wird nun den Inhalt der ISO-Datei auf den angeschlossenen USB-Stick kopieren.

### Rufus (Nur Windows)

<Steps>

1. Schließe einen USB-Stick an.
2. Lade [Rufus](<https://rufus.ie/>) herunter und installiere es oder führe die portable Version aus.
3. Klicke unter `Device` auf die Dropdown-Liste und wähle den angeschlossenen USB-Stick aus.
4. Klicke unter `Boot selection` auf `SELECT` und suche die CachyOS ISO-Image-Datei.
5. Klicke auf `START`.

</Steps>

### Ventoy (Linux & Windows)

<Tabs>

<TabItem label="Linux">

<Steps>

1. Schließe einen USB-Stick an.
2. Lade [Ventoy](<https://www.ventoy.net/en/download.html>) herunter.
3. Entpacke Ventoy mit dem folgenden Befehl:
   ```sh
   # Ersetze version durch die korrekte, z.B.: ventoy-1.1.07-linux.tar.gz
   bsdtar xvf ventoy-version-linux.tar.gz
   # In den neuen Ordner wechseln: (Version kann sich ändern)
   cd ventoy-1.1.07/
   ```
4. Führe `VentoyGUI.x86_64` entweder per Doppelklick oder über das Terminal aus:
   ```sh
   # Es wird nach Administratorrechten gefragt, gib deine Anmeldedaten ein
   ./VentoyGUI.x86_64
   ```
5. Wähle den angeschlossenen USB-Stick aus, indem du auf `Device` klickst.
6. Klicke auf `Install`.
7. Nachdem die Installation von Ventoy auf dem angeschlossenen USB-Stick abgeschlossen ist, schließe das Fenster und lege die CachyOS ISO-Datei in die neue nutzbare Partition des Laufwerks.

</Steps>

</TabItem>

<TabItem label="Windows">

<Steps>
1. Schließe einen USB-Stick an.
2. Lade [Ventoy](<https://www.ventoy.net/en/download.html>) herunter.
3. Führe `Ventoy2Disk.exe` aus.
4. Wähle den angeschlossenen USB-Stick aus, indem du auf `Device` klickst.
5. Klicke auf `Install`.
6. Nachdem die Installation von Ventoy auf dem USB-Stick abgeschlossen ist, schließe das Fenster und lege die CachyOS ISO-Datei in die neue nutzbare Partition des Laufwerks.
</Steps>

</TabItem>

</Tabs>
