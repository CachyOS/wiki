## Systemanforderungen

Bevor du mit der Installationsvorbereitung beginnst, stell sicher, dass dein Computer die Mindestsystemanforderungen erfüllt, um CachyOS auszuführen. Der Installer
nutzt einen Online-Installationsprozess, daher ist eine stabile und relativ schnelle Internetverbindung zwingend erforderlich.

:::note[Virtuelle Maschinen]
Es wird nicht empfohlen, CachyOS in einer virtuellen Maschine zu installieren. VMs können Probleme mit falscher Konfiguration haben oder komplett kaputt sein. Es wird empfohlen, CachyOS direkt auf dem Rechner (Bare Metal) zu installieren.
:::

<Tabs>

<TabItem label="Mindestanforderungen">

*   3 GB RAM
*   30 GB Speicherplatz (HDD/SSD)
*   Stabile Internetverbindung

:::caution
Eine instabile Internetverbindung kann im schlimmsten Fall zu längeren Installationszeiten oder fehlgeschlagenen Installationen führen.
:::

</TabItem>

<TabItem label="Empfohlene Anforderungen">

*   8 GB RAM
*   50 GB Speicherplatz (SSD/NVMe)
*   [x86-64-v3-fähige CPU](/de/installation/installation_prepare#x86_64-mikroarchitektur-level-unterstützung)
*   50 Mbit/s oder schnellere Internetverbindung
*   NVIDIA GPU (900+ - z.B.: GTX 950), AMD +GCN 1.0 (z.B.: AMD R7 240) oder Intel (Integrierte HD Graphics Serie oder höher, Arc Serie)

</TabItem>

</Tabs>

## Einen bootfähigen CachyOS USB-Stick erstellen

Es gibt mehrere Werkzeuge und Methoden, um einen bootfähigen USB-Stick mit CachyOS zu erstellen.

:::tip
Behalte eine Kopie der CachyOS-ISO auf demselben Laufwerk oder an einem anderen Ort, damit du sie später zur Fehlerbehebung via chroot verwenden kannst.
:::

:::note
Der USB-Stick muss mindestens 8 GB freien Speicherplatz haben.
:::

### balenaEtcher

<Steps>

1. Lade [balenaEtcher](<https://etcher.balena.io/>) herunter. balenaEtcher unterstützt das Flashen eines Images unter Linux, MacOS und Windows.
   Wenn du eine `.zip`-Datei heruntergeladen hast, entpacke sie und führe die Binärdatei mit den folgenden Befehlen aus:
      ```sh
      # zip-Datei entpacken:
      bsdtar xvf <Name der Zip-Datei>
      # In den neuen Ordner wechseln:
      cd balenaEtcher-linux-x64/
      # balenaEtcher ausführen:
      ./balena-etcher
      ```
2. Schließ einen USB-Stick an den Computer an.
3. Wähle `Flash from file` und wähle die CachyOS ISO-Image-Datei aus.
4. Klicke auf `Select target` und wähle den USB-Stick, den du zuvor angesteckt hast.
5. Drücke `Flash`, um den Flash-Vorgang zu starten.

</Steps>

:::note
balenaEtcher könnte nach Administratorrechten fragen. Wenn ja, gib dein Passwort ein und klicke auf `Authentifizieren`.
:::

### Kommandozeile (Linux & MacOS)

<Steps>

1. Steck einen USB-Stick an.
2. Finde den angesteckten USB-Stick mit den folgenden Befehlen:
   ```sh
   # Linux
   # Der USB-Stick könnte z.B. als /dev/sda identifiziert werden, anhand des Festplattenmodells und der Größe.
   sudo fdisk -l

   # MacOS
   # USB-Sticks werden als "/dev/diskY" identifiziert, wobei "Y" 0, 1 etc. sein kann.
   diskutil list
   ```
3. Kopiere den Inhalt der ISO auf den angesteckten USB-Stick, indem du folgenden Befehl ausführst:
   ```sh
   # Ersetze <usbstick> durch die Bezeichnung des Laufwerks.
   sudo dd bs=4M if=ganzer_iso_name.iso of=/dev/<usbstick> status=progress oflag=sync
   ```
</Steps>

- `dd` kopiert nun den Inhalt der ISO-Datei auf den angesteckten USB-Stick.

### Rufus (Nur Windows)

<Steps>

1. Steck einen USB-Stick an.
2. Lade [Rufus](<https://rufus.ie/>) herunter und installiere es, oder starte die portable Version.
3. Klicke bei `Laufwerk` auf die Dropdown-Liste und wähle den angesteckten USB-Stick aus.
4. Klicke bei `Startart` auf `AUSWAHL` und finde die CachyOS ISO-Image-Datei.
5. Klicke auf `START`.

</Steps>

### Ventoy (Linux & Windows)

<Tabs>

<TabItem label="Linux">

<Steps>

1. Steck einen USB-Stick an.
2. Lade [Ventoy](<https://www.ventoy.net/en/download.html>) herunter.
3. Entpacke Ventoy mit dem folgenden Befehl:
   ```sh
   # Ersetze die Version durch die richtige, z.B.: ventoy-1.1.07-linux.tar.gz
   bsdtar xvf ventoy-version-linux.tar.gz
   # Wechsle in den neuen Ordner: (Version kann sich ändern)
   cd ventoy-1.1.07/
   ```
4. Führe `VentoyGUI.x86_64` aus, entweder durch einen Doppelklick darauf oder über das Terminal:
   ```sh
   # Es wird nach Administratorrechten gefragt, gib deine Zugangsdaten ein
   ./VentoyGUI.x86_64
   ```
5. Wähle den angesteckten USB-Stick aus, indem du auf `Device` klickst.
6. Klicke auf `Install`.
7. Nachdem die Installation von Ventoy auf dem angesteckten USB-Stick abgeschlossen ist, schließe das Fenster und kopiere die CachyOS ISO-Datei in die neue nutzbare Partition des Laufwerks.

</Steps>

</TabItem>

<TabItem label="Windows">

<Steps>
1. Steck einen USB-Stick an.
2. Lade [Ventoy](<https://www.ventoy.net/en/download.html>) herunter.
3. Führe `Ventoy2Disk.exe` aus.
4. Wähle den angesteckten USB-Stick aus, indem du auf `Device` klickst.
5. Klicke auf `Install`.
6. Nachdem die Installation von Ventoy auf dem USB-Stick abgeschlossen ist, schließe das Fenster und kopiere die CachyOS ISO-Datei in die neue nutzbare Partition des Laufwerks.
</Steps>

</TabItem>

</Tabs>
