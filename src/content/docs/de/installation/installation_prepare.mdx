## Systemanforderungen

Bevor Sie die Installation vorbereiten, stellen Sie sicher, dass der verwendete Computer die minimalen Systemanforderungen erfüllt, um CachyOS ausführen zu können. Der Installer
verwendet einen Online-Installationsprozess, daher ist eine stabile und relativ schnelle Internetverbindung zwingend erforderlich.

:::note[Virtuelle Maschinen]
Es wird nicht empfohlen, CachyOS auf einer virtuellen Maschine zu installieren. VMs können Probleme durch falsche Konfiguration aufweisen oder gänzlich defekt sein. Es wird empfohlen, CachyOS direkt auf der Hardware („bare metal“) zu installieren.
:::

<Tabs>

<TabItem label="Mindestanforderungen">

*   3 GB RAM
*   30 GB Speicherplatz (HDD/SSD)
*   Stabile Internetverbindung

:::caution
Eine instabile Internetverbindung kann im schlimmsten Fall zu verlängerten Installationszeiten oder fehlgeschlagenen Installationen führen.
:::

</TabItem>

<TabItem label="Empfohlene Anforderungen">

*   8 GB RAM
*   50 GB Speicherplatz (SSD/NVMe)
*   [x86-64-v3-fähige CPU](/de/installation/installation_prepare#x86_64-microarchitecture-level-support)
*   50 Mbit/s oder schnellere Internetgeschwindigkeit
*   NVIDIA GPU (900+ - z.B.: GTX 950), AMD +GCN 1.0 (z.B.: AMD R7 240) oder Intel (integrierte HD Graphics-Serie oder höher. Arc-Serie)

</TabItem>

</Tabs>

## Erstellen eines bootfähigen CachyOS-USB-Laufwerks

Es gibt mehrere Werkzeuge und Methoden, um ein bootfähiges USB-Laufwerk von CachyOS zu erstellen.

:::note
Das USB-Laufwerk muss mindestens 8 GB freien Speicherplatz haben.
:::

### balenaEtcher

<Steps>

1. Laden Sie [balenaEtcher](<https://etcher.balena.io/>) herunter. balenaEtcher unterstützt das Flashen eines Images unter Linux, MacOS und Windows.
   Wenn eine `.zip`-Datei heruntergeladen wurde, entpacken Sie sie und führen Sie die Binärdatei mit den folgenden Befehlen aus:
      ```sh
      # ZIP-Datei entpacken:
      bsdtar xvf <zip file name>
      # In den neuen Ordner wechseln:
      cd balenaEtcher-linux-x64/
      # balenaEtcher ausführen:
      ./balena-etcher
      ```
2. Schließen Sie ein USB-Laufwerk an den Computer an.
3. Wählen Sie `Flash from file` und wählen Sie die CachyOS ISO-Image-Datei aus.
4. Klicken Sie auf `Select target` und wählen Sie das zuvor angeschlossene USB-Laufwerk.
5. Drücken Sie `Flash`, um den Flash-Vorgang zu starten.

</Steps>

:::note
balenaEtcher fragt möglicherweise nach Administratorrechten. Geben Sie in diesem Fall Ihr Passwort ein und klicken Sie auf `Authentifizieren`.
:::

### Kommandozeile (Linux & MacOS)

<Steps>

1. Schließen Sie ein USB-Laufwerk an.
2. Erkennen Sie das angeschlossene USB-Laufwerk mit den folgenden Befehlen:
   ```sh
   # Linux
   # Das USB-Laufwerk könnte z.B. als /dev/sda identifiziert werden, anhand des Festplattenmodells und der Größe.
   sudo fdisk -l

   # MacOS
   # USB-Laufwerke werden als "/dev/diskY" identifiziert, wobei "Y" 0, 1 usw. sein kann.
   diskutil list
   ```
3. Kopieren Sie den Inhalt der ISO-Datei auf das angeschlossene USB-Laufwerk, indem Sie Folgendes ausführen:
   ```sh
   # Ersetzen Sie <usbdrive> durch die Bezeichnung des Laufwerks.
   sudo dd bs=4M if=full_iso_name.iso of=/dev/<usbdrive> status=progress oflag=sync
   ```
</Steps>

- `dd` wird nun den Inhalt der ISO-Datei auf das angeschlossene USB-Laufwerk kopieren.

### Rufus (Nur Windows)

<Steps>

1. Schließen Sie ein USB-Laufwerk an.
2. Laden Sie [Rufus](<https://rufus.ie/>) herunter und installieren Sie es oder führen Sie die portable Version aus.
3. Klicken Sie unter `Device` auf die Dropdown-Liste und wählen Sie das angeschlossene USB-Laufwerk aus.
4. Klicken Sie unter `Boot selection` auf `SELECT` und suchen Sie die CachyOS ISO-Image-Datei.
5. Klicken Sie auf `START`.

</Steps>

### Ventoy (Linux & Windows)

<Tabs>

<TabItem label="Linux">

<Steps>

1. Schließen Sie ein USB-Laufwerk an.
2. Laden Sie [Ventoy](<https://www.ventoy.net/en/download.html>) herunter.
3. Entpacken Sie Ventoy mit dem folgenden Befehl:
   ```sh
   # Ersetzen Sie version durch die korrekte, z.B.: ventoy-1.1.07-linux.tar.gz
   bsdtar xvf ventoy-version-linux.tar.gz
   # In den neuen Ordner wechseln: (Version kann sich ändern)
   cd ventoy-1.1.07/
   ```
4. Führen Sie `VentoyGUI.x86_64` entweder per Doppelklick oder über das Terminal aus:
   ```sh
   # Es wird nach Administratorrechten gefragt, geben Sie Ihre Anmeldedaten ein
   ./VentoyGUI.x86_64
   ```
5. Wählen Sie das angeschlossene USB-Laufwerk aus, indem Sie auf `Device` klicken.
6. Klicken Sie auf `Install`.
7. Nachdem die Installation von Ventoy auf dem angeschlossenen USB-Laufwerk abgeschlossen ist, schließen Sie das Fenster und legen Sie die CachyOS ISO-Datei in die neue nutzbare Partition des Laufwerks.

</Steps>

</TabItem>

<TabItem label="Windows">

<Steps>
1. Schließen Sie ein USB-Laufwerk an.
2. Laden Sie [Ventoy](<https://www.ventoy.net/en/download.html>) herunter.
3. Führen Sie `Ventoy2Disk.exe` aus.
4. Wählen Sie das angeschlossene USB-Laufwerk aus, indem Sie auf `Device` klicken.
5. Klicken Sie auf `Install`.
6. Nachdem die Installation von Ventoy auf dem USB-Laufwerk abgeschlossen ist, schließen Sie das Fenster und legen Sie die CachyOS ISO-Datei in die neue nutzbare Partition des Laufwerks.
</Steps>

</TabItem>
