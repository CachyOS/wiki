CachyOS bietet sofort einsatzbereite Unterstützung für T2 MacBooks, einschließlich der notwendigen Kernel-Patches in allen bereitgestellten Kerneln. Es gibt jedoch entscheidende Schritte, die für eine erfolgreiche Einrichtung erforderlich sind.

:::caution[Mögliche Risiken]
Das vollständige Entfernen von macOS birgt Risiken, wie Datenverlust oder das Unbrauchbarmachen des Geräts. Es wird **dringend empfohlen**, eine macOS-Partition für Firmware-Updates und die Wiederherstellung beizubehalten. Weitere Einzelheiten finden Sie in der [T2 Linux Roadmap](https://wiki.t2linux.org/roadmap/#can-i-completely-remove-macos).

Wenn Sie sich dennoch entscheiden, macOS zu entfernen, stellen Sie sicher, dass Sie ein vollständiges Backup haben und erstellen Sie vorher einen [bootfähigen macOS-Installer](https://support.apple.com/de-de/101578).
:::

## Vor der Installation

Das Erstellen eines bootfähigen macOS-Installers ist optional, wird aber empfohlen, wenn Sie Partitionen ändern oder macOS entfernen möchten. Er kann für Firmware-Updates, zur Fehlerbehebung oder zur Systemwiederherstellung nützlich sein. Eine detaillierte Anleitung finden Sie in [Apples Leitfaden](https://support.apple.com/de-de/101578).

Führen Sie die folgenden Schritte in macOS aus, **bevor** Sie den CachyOS-Installer booten.

### Bootfähigen CachyOS-USB-Stick vorbereiten

Laden Sie das [CachyOS ISO](/de/cachyos_basic/download) herunter und folgen Sie den Anweisungen unter [Erstellen eines bootfähigen CachyOS-USB-Laufwerks](/de/installation/installation_prepare#creating-a-bootable-cachyos-usb-drive), um das Installationsmedium zu erstellen.

### (Optional) WLAN-Firmware extrahieren

:::note
WLAN **funktioniert nicht** standardmäßig während oder nach der Installation, da die erforderliche Firmware proprietär ist und von CachyOS nicht weitergegeben werden darf. Sie benötigen eine Internetverbindung (z. B. Ethernet, USB-Tethering) für den Installationsprozess, es sei denn, Sie befolgen die folgenden Schritte, um die WLAN-Firmware vorzubereiten und während der Installation zu aktivieren.
:::

Öffnen Sie, während Sie sich noch in macOS befinden, das Terminal und führen Sie den folgenden Befehl aus. Dadurch werden die notwendigen WLAN-Firmware-Dateien auf Ihre EFI-Partition kopiert, sodass sie später während der CachyOS-Installation zugänglich sind.
```sh
curl -sL https://wiki.t2linux.org/tools/firmware.sh | bash -s copy_to_efi
```

### Ihre Festplatte vorbereiten

Wenn Sie ein Dual-Boot-System mit macOS (empfohlen) planen, müssen Sie Speicherplatz für CachyOS schaffen. Verwenden Sie das Festplattendienstprogramm in macOS, um die Größe Ihrer vorhandenen macOS-Partition zu ändern:

<Steps>

1. Öffnen Sie das **Festplattendienstprogramm**.
2. Wählen Sie in der Seitenleiste des Festplattendienstprogramms das **Volume** aus, dessen Größe Sie ändern möchten (normalerweise "Macintosh HD" oder ähnlich genannt).
3. Klicken Sie auf die Schaltfläche **"Partitionieren"** in der Symbolleiste.
4. Klicken Sie auf die Schaltfläche **"+" (Plus)** unter dem Tortendiagramm, das Ihre Festplattennutzung darstellt.
5. **Wichtig:** Wenn Sie dazu aufgefordert werden, wählen Sie **"Partition hinzufügen"** und *nicht* "Volume hinzufügen". Sie müssen eine separate Partition für Linux erstellen.
6. **Name:** Geben Sie einen aussagekräftigen Namen für die neue Partition ein (z. B. "CachyOS" oder "Linux").
7. **Format:** Wählen Sie ein beliebiges verfügbares Format (wie APFS oder Mac OS Extended). Der CachyOS-Installer wird diese Partition später neu formatieren, daher ist die anfängliche Wahl unerheblich.
8. **Größe:** Weisen Sie die gewünschte Menge an Speicherplatz für CachyOS zu. **Beachten Sie, dass das Ändern der Partitionsgröße später schwierig oder unmöglich sein kann**, wählen Sie also eine Größe, die Ihren Bedürfnissen entspricht.
10. Klicken Sie auf **"Anwenden"**, um die neue Partition zu erstellen. Das Festplattendienstprogramm wird die Größe Ihrer macOS-Partition anpassen und den neuen leeren Speicherplatz erstellen.

</Steps>


### Secure Boot deaktivieren

<Steps>

1. Starten Sie Ihren Mac neu und halten Sie `Befehl (⌘) + R` direkt nach dem Einschalten gedrückt, um in den Wiederherstellungsmodus zu gelangen.
2. Gehen Sie zu Dienstprogramme > Startsicherheitsdienstprogramm.
3. Wählen Sie unter **Sicherer Start** die Option "Keine Sicherheit" und unter **Erlaubte Startmedien** die Option "Starten von externen oder Wechselmedien erlauben".

</Steps>

Weitere Details finden Sie in [Apples Anleitung zum Startsicherheitsdienstprogramm](https://support.apple.com/de-de/102522).

## Installationsprozess

<Steps>

1.  **Vom CachyOS-USB-Stick booten:**
    *   Starten Sie Ihren Mac neu und halten Sie die `Option (⌥)`-Taste direkt nach dem Einschalten gedrückt.
    *   Wählen Sie den CachyOS-USB-Stick aus (normalerweise als "EFI Boot" bezeichnet).
2.  **(Optional) WLAN in der Live-Umgebung aktivieren:**
    *   Wenn Sie während der Installation WLAN benötigen und kein Ethernet/Tethering haben, öffnen Sie das Terminal, sobald die CachyOS-Live-Umgebung geladen ist.
    *   Führen Sie diese Befehle aus, um die Firmware von der EFI-Partition (erstellt unter [WLAN-Firmware extrahieren](#optional-wlan-firmware-extrahieren)) zu kopieren und den NetworkManager zu konfigurieren:
        ```sh
        # Die EFI-Partition einhängen (normalerweise nvme0n1p1 auf T2-Macs)
        sudo mkdir -p /tmp/apple-wifi-efi
        sudo mount /dev/nvme0n1p1 /tmp/apple-wifi-efi

        # Firmware von EFI in die Live-Umgebung kopieren
        bash /tmp/apple-wifi-efi/firmware.sh get_from_efi
        sudo umount /tmp/apple-wifi-efi

        # NetworkManager für die Verwendung des iwd-Backends konfigurieren
        cat <<EOF | sudo tee /etc/NetworkManager/conf.d/wifi_backend.conf
        [device]
        wifi.backend=iwd
        EOF
        sudo systemctl restart NetworkManager
        ```
    *   Sie sollten sich nun über das Netzwerk-Applet in der Taskleiste mit WLAN-Netzwerken verbinden können.
3.  **Den CachyOS-Installer ausführen:**
    *   Starten Sie den CachyOS-Installer vom Desktop oder aus dem Anwendungsmenü.
    *   Folgen Sie dem Standard-Installationsverfahren und beziehen Sie sich dabei auf die Anleitung [Installation auf Root](/de/installation/installation_on_root).
    *   Wählen Sie beim Partitionieren den zuvor erstellten freien Speicherplatz aus. Lassen Sie den Installer die Formatierung übernehmen.
        :::caution[Vorsicht bei der Partitionierung]
        Seien Sie beim Partitionierungsschritt im Installer **sehr vorsichtig**. Stellen Sie sicher, dass Sie den richtigen freien Speicherplatz auswählen, den Sie vorbereitet haben, und **löschen oder formatieren Sie nicht** versehentlich Ihre vorhandene macOS-Partition, insbesondere wenn Sie ein Dual-Boot-System beibehalten möchten. Überprüfen Sie Ihre Auswahl doppelt, bevor Sie fortfahren.
        :::
    *   Die CachyOS Hardware-Erkennung ([chwd](/de/features/chwd)) sollte während der Installation automatisch die notwendigen T2-spezifischen Boot-Parameter und Konfigurationen anwenden.

</Steps>

## Schritte nach der Installation

Nachdem die Installation abgeschlossen ist und Sie in Ihr neues CachyOS-System neu gestartet haben, müssen Sie möglicherweise einige zusätzliche Schritte durchführen, um sicherzustellen, dass alles reibungslos funktioniert.

### WLAN-Firmware dauerhaft installieren

Wenn Sie dem optionalen Schritt [WLAN in der Live-Umgebung aktivieren](#installationsprozess) gefolgt sind, um die Firmware im Live-ISO zu erhalten, können Sie diesen einfach erneut ausführen, um WLAN zu aktivieren. Andernfalls verbinden Sie sich mit dem Internet (z. B. per Ethernet, USB-Tethering) und folgen Sie den nachstehenden Schritten:

<Steps>
1. Öffnen Sie ein Terminal und laden Sie das Firmware-Paket vom Arch Linux T2-Spiegelserver herunter:
   ```sh
   curl https://mirror.funami.tech/arch-mact2/os/x86_64/apple-bcm-firmware-14.0-1-any.pkg.tar.zst -o apple-bcm-firmware-14.0-1-any.pkg.tar.zst
   ```
2. Installieren Sie das heruntergeladene Paket:
   ```sh
   sudo pacman -U apple-bcm-firmware-14.0-1-any.pkg.tar.zst
   ```
3. Laden Sie die WLAN-Kernelmodule neu:
   ```bash
   sudo modprobe -r brcmfmac_wcc
   sudo modprobe -r brcmfmac
   sudo modprobe brcmfmac
   ```
</Steps>

WLAN sollte nun auch nach Neustarts zuverlässig funktionieren. Sie können die heruntergeladene `.pkg.tar.zst`-Datei entfernen.
