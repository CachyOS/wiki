CachyOS bietet eine Edition für Handheld-Geräte wie das Steam Deck, ROG Ally und Legion Go. Diese Edition bietet ein SteamOS-ähnliches Erlebnis mit Game-Mode-Umschaltung, vorinstallierten Gaming-Anwendungen und mehr.

Die Handheld-Edition verwendet den LAVD-Scheduler als Standard-CPU-Scheduler, der für Handheld-Geräte optimiert ist. Dies führt zu verbesserten Bildraten und einer längeren Akkulaufzeit beim Spielen.

Die Handheld-Edition verwendet `systemd-boot` als Bootmanager. Die Auswahl des Bootmanagers ist nicht verfügbar,
im Gegensatz zur Standard-CachyOS-ISO. Dies soll den Installationsprozess vereinfachen.

## Installation auf dem gesamten Speichermedium

<Steps>

1. **Laden Sie** die neueste Handheld-ISO von der Webseite/dem Forum **herunter**.

2. [Flashen](/de/installation/installation_prepare) Sie die ISO.

3. **Starten** Sie von der ISO.

4. Klicken Sie auf den Button **Launch Installer** (Installer starten).

5. Calamares wird sich nun öffnen. Folgen Sie den Anweisungen auf dem Bildschirm.

6. Wählen Sie beim Partitionierungsschritt bitte die Option **Erase Disk** (Datenträger löschen). Wenn Sie von einer anderen Linux-Distribution kommen, hat diese möglicherweise ein anderes Partitionslayout verwendet. Beachten Sie, dass die Option zum Ersetzen einer Partition problematisch sein kann und möglicherweise nicht wie erwartet funktioniert.

7. Installieren Sie das System.

</Steps>

Nachdem die Installation abgeschlossen ist, fordert Calamares Sie auf, das Gerät neu zu starten.

Der erste Start kann etwas Zeit in Anspruch nehmen, da Steam heruntergeladen und gestartet wird.
Dieser Vorgang kann bis zu 2 Minuten dauern.


## Installation mit Dual-Boot

<Steps>

1. **Laden Sie** die neueste Handheld-ISO von der Webseite/dem Forum **herunter**.

2. [Flashen](/installation/installation_prepare) Sie die ISO.

3. **Starten** Sie von der ISO.

4. Klicken Sie auf den Button **Launch Installer** (Installer starten).

5. Calamares wird sich nun öffnen. Folgen Sie den Anweisungen auf dem Bildschirm.

6. Beim Partitionierungsschritt müssen Sie **Manual Partition** (Manuelle Partitionierung) auswählen und folgende Partitionen erstellen:

    - 2GB /boot
    - XGB / (X kann eine beliebige Größe sein, die Sie dem Root-Dateisystem zuweisen möchten)

7. Fahren Sie mit den Schritten fort und installieren Sie das System.

</Steps>

Nachdem die Installation abgeschlossen ist, fordert Calamares Sie auf, das Gerät neu zu starten.

Der erste Start kann etwas Zeit in Anspruch nehmen, da Steam heruntergeladen und gestartet wird.
Dieser Vorgang kann bis zu 2 Minuten dauern.
