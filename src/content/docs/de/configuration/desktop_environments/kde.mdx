## Wie man die fehlende X11-Sitzung installiert

Nachdem KDE beschlossen hat, die Entwicklung auf mehrere Pakete aufzuteilen, wurde die X11-Sitzung aus der Standardinstallation entfernt.

```sh
sudo pacman -S plasma-x11-session kwin-x11
```

## FAQ

### Wie bekomme ich das gleiche Aussehen wie in den KDE-Screenshots, das "Emerald" heißt?

- Es ist eine Kombination aus dem Emerald-Theme und dem Qogir-Icon-Theme, die nicht standardmäßig installiert sind.
  - ```sh title='Beide mit dem folgenden Befehl installieren'
    sudo pacman -S cachyos-emerald-kde-theme-git qogir-icon-theme
    ```
  Beide in `Erscheinungsbild & Stil - Farben & Designs` anwenden

### Warum sieht SDDM so langweilig und alt aus?

- *Da standardmäßig kein SDDM-Theme angewendet wird, greift SDDM auf das klassische Theme zurück.*
