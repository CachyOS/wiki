## Wie du die fehlende X11-Sitzung installierst

Nachdem KDE entschieden hat, die Entwicklung auf mehrere Pakete aufzuteilen, wurde die X11-Sitzung aus der Standardinstallation entfernt.

```sh
sudo pacman -S plasma-x11-session kwin-x11
```

Nach Abschluss wird X11 auf dem Anmeldebildschirm als Option aufgelistet. 

## Wie du den fehlenden xorg-server installierst

Seit der Version 26.01 des CachyOS-Installers wird xorg-server nicht mehr installiert und ist keine Abhängigkeit mehr von plasma-x11-session oder kwin-x11. Xorg-server und die zugehörigen Komponenten nicht manuell zu installieren wird zur Folge haben, dass ein schwarzer Bildschirm beim Anmelden erscheint.  

```sh
sudo pacman -S xorg-server
```

## FAQ

### Wie bekomme ich den gleichen Look namens "Emerald" wie in den KDE-Screenshots?

- Das ist eine Kombination aus dem Emerald-Theme und dem Qogir-Icon-Theme, die nicht standardmäßig installiert sind.
  - ```sh title='Installier beides mit dem folgenden Befehl'
    sudo pacman -S cachyos-emerald-kde-theme-git qogir-icon-theme
    ```
  Wende beides unter `Erscheinungsbild & Stil - Farben & Designs` an.
