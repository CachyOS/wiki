## Wie du die fehlende X11-Sitzung installierst

Nachdem KDE entschieden hat, die Entwicklung auf mehrere Pakete aufzuteilen, wurde die X11-Sitzung aus der Standardinstallation entfernt.

```sh
sudo pacman -S plasma-x11-session kwin-x11
```

## FAQ

### Wie kriege ich den gleichen Look wie in den KDE-Screenshots, genannt "Emerald"?

- Das ist eine Kombination aus dem Emerald-Theme und dem Qogir-Icon-Theme, die nicht standardmäßig installiert sind.
  - ```sh title='Installier beides mit dem folgenden Befehl'
    sudo pacman -S cachyos-emerald-kde-theme-git qogir-icon-theme
    ```
  Wende beides unter `Erscheinungsbild & Stil - Farben & Designs` an.

### Warum sieht SDDM so langweilig und alt aus?

- *Da standardmäßig kein SDDM-Theme angewendet wird, fällt SDDM auf das klassische Theme zurück.*
