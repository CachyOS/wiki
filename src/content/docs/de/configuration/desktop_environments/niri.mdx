:::note
Niri ist ein scrollbarer Tiling-Wayland-Compositor, der mit seinem spaltenbasierten Layout-System einen einzigartigen Ansatz für die Fensterverwaltung bietet.
:::

Unser Hauptziel bei unserer Konfiguration ist es, eine funktionierende Niri-Konfiguration zu haben, die ein reibungsloses und intuitives Desktop-Erlebnis bietet, während die Konfiguration einfach und zugänglich bleibt.

Werfen Sie einen Blick in unsere [Niri FAQ.](/de/configuration/desktop_environments/niri#faq)

**Dotfiles gepflegt von [Ly-sec](https://github.com/Ly-sec)**

## Tastenkombinationen

Die meisten Tastenkombinationen erfordern die Verwendung der Mod-Taste, die in unserem Fall die Windows-Taste ist (als SUPER bezeichnet). Sie können dies in der Konfigurationsdatei ändern.

## FAQ

### Was unterscheidet Niri von anderen Fenstermanagern?

Niri verwendet einen einzigartigen scrollbaren Tiling-Ansatz, bei dem Fenster in Spalten angeordnet sind, die horizontal gescrollt werden können. Dies bietet eine unendliche Desktop-Metapher, die besonders nützlich für Ultrawide-Monitore und Arbeitsabläufe ist, die viele geöffnete Anwendungen erfordern.

### Wie ändere ich das Tastaturlayout?

Bearbeiten Sie den `input`-Abschnitt in Ihrer Konfigurationsdatei:

```txt title='Beispiel'
input {
    keyboard {
        xkb {
            layout "us" // Ändern Sie "de" in Ihr bevorzugtes Layout
        }
    }
}
```

### Kann ich die Abstände und das Aussehen der Fenster anpassen?

Ja, Sie können den `layout`-Abschnitt ändern:

```txt title='Beispiel'
layout {
    gaps 8 // Größe der Abstände ändern

    focus-ring {
        width 2
        active-color "#your-color"
        inactive-color "#your-color"
    }
}
```

### Wie füge ich weitere Startanwendungen hinzu?

Fügen Sie sie dem `startup`-Abschnitt hinzu:

```txt title='Beispiel'
spawn-at-startup "your-application"
```

### Wofür ist die Notfall-Escape-Taste?

Die `Super+Escape`-Tastenkombination wurde entwickelt, um die Kontrolle wiederherzustellen, wenn eine Vollbildanwendung Ihre Tastenkombinationen blockiert. Sie deaktiviert jeden aktiven Tastenkombinations-Inhibitor.

### Wie konfiguriere ich mehrere Monitore?

Entkommentieren und ändern Sie den `output`-Abschnitt für Ihre spezifischen Bildschirme. Führen Sie `niri msg outputs` aus, um die korrekten Namen zu erhalten:

```txt title='Beispiel'
output "DP-1" {
    mode "1920x1080@60.000"
    scale 1
}
```
