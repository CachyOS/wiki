:::note
Niri ist ein scrollbarer Tiling-Wayland-Compositor, der mit seinem spaltenbasierten Layout-System einen einzigartigen Ansatz zur Fensterverwaltung bietet.
:::

Unser Hauptziel bei unserem Setup ist es, eine funktionierende Niri-Konfiguration zu haben, die ein flüssiges und intuitives Desktop-Erlebnis bietet, während die Konfiguration einfach und zugänglich bleibt.

Schau mal in unsere [Niri FAQ.](/de/configuration/desktop_environments/niri#faq)

**Dotfiles werden von [Ly-sec](https://github.com/Ly-sec) gepflegt**
Bei Problemen mit Noctalia schauen Sie sich bitte die [Noctalia-Doks](https://docs.noctalia.dev/) an.

## Tastenkombinationen

Die meisten Tastenkombinationen erfordern die Verwendung der Mod-Taste, die in unserem Fall die Windows-Taste ist (als SUPER bezeichnet). Du kannst sie in der Konfigurationsdatei ändern.

|-------------|-----|

## FAQ

### Was unterscheidet Niri von anderen Fenstermanagern?

Niri verwendet einen einzigartigen scrollbaren Tiling-Ansatz, bei dem Fenster in Spalten angeordnet sind, die horizontal gescrollt werden können. Dies bietet eine unendliche Desktop-Metapher, die besonders nützlich für Ultrawide-Monitore und Arbeitsabläufe ist, die viele offene Anwendungen erfordern.

### Wie ändere ich das Tastaturlayout?

Bearbeite den `input`-Abschnitt in deiner Konfigurationsdatei:

```txt title='Beispiel'
input {
    keyboard {
        xkb {
            layout "de" // Ändere "us" zu deinem bevorzugten Layout
        }
    }
}
```

### Kann ich die Abstände und das Erscheinungsbild der Fenster anpassen?

Ja, du kannst den `layout`-Abschnitt ändern:

```txt title='Beispiel'
layout {
    gaps 8 // Größe des Abstands ändern

    focus-ring {
        width 2
        active-color "#deine-farbe"
        inactive-color "#deine-farbe"
    }
}
```

### Wie füge ich weitere Autostart-Anwendungen hinzu?

Füge sie zum `startup`-Abschnitt hinzu:

```txt title='Beispiel'
spawn-at-startup "deine-anwendung"
```

### Wofür ist die Notfall-Escape-Taste?

Die Tastenkombination `Super+Escape` wurde entwickelt, um die Kontrolle wiederherzustellen, wenn eine Vollbildanwendung deine Tastenkombinationen blockiert. Sie deaktiviert jeden aktiven Tastenkombinations-Inhibitor.

### Wie konfiguriere ich mehrere Monitore?

Entferne die Kommentarzeichen und ändere den `output`-Abschnitt für deine spezifischen Displays. Führe `niri msg outputs` aus, um die richtigen Namen zu erhalten:

```txt title='Beispiel'
output "DP-1" {
    mode "1920x1080@60.000"
    scale 1
}
```
