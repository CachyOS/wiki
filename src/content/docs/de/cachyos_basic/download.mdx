## Offizielle ISO-Quellen

Du kannst die CachyOS ISO von den folgenden Quellen beziehen:

* [Webseite](https://cachyos.org/download)
* [SourceForge](https://sourceforge.net/projects/cachyos-arch/files/)
* [CachyOS Mirror](https://mirror.cachyos.org/ISO/)

## Integrität der ISO mit SHA256 überprüfen

:::caution[WARNUNG]
Nimm dir immer die zusätzliche Zeit, die Integrität der ISO zu überprüfen, um unerwünschte Probleme bei der Installation oder beim Erstellen eines bootfähigen Mediums zu vermeiden.
:::

**Aktuelle ISO-Version:** `260628`

**SHA256-Hash:** `136c84942eacdc6deed205fe7018c69fe7b70757f2f9b4010936ee05e060f336`

<Tabs>

<TabItem label='Windows'>

<Steps>

1. Lade die [Datei](https://mirror.cachyos.org/ISO/desktop/260628/cachyos-desktop-linux-260628.iso.sha256) mit dem SHA256-Hash herunter **(Öffne sie mit einem Texteditor, z. B. Notepad).**
2. Öffne CMD oder PowerShell als Administrator und [navigiere](https://www.wikihow.com/Change-Directories-in-Command-Prompt) zu dem Pfad, in dem die ISO- und SHA256-Dateien gespeichert sind.
3. Führe den folgenden Befehl aus:
   ```powershell
   # Beispiel:
   certUtil -hashfile cachyos-desktop-linux-260628.iso SHA256
   ```
4. Vergleiche die Hash-Ausgabe von certUtil mit der aus der heruntergeladenen Datei in **Schritt 1**. Wenn sie übereinstimmen, kannst du mit der CachyOS-Installation fortfahren.

</Steps>

</TabItem>

<TabItem label='Linux'>

<Steps>

1. Lade die [Datei](https://mirror.cachyos.org/ISO/desktop/260628/cachyos-desktop-linux-260628.iso.sha256) herunter, die den SHA256-Hash enthält.
2. Öffne ein Terminal, navigiere zu dem Verzeichnis, das die `.sha256`-Datei enthält, und führe die folgenden Befehle aus:
   ```sh
   # Beispiel:
   cd Downloads/
   cat cachyos-desktop-linux-260628.iso.sha256
   # 136c84942eacdc6deed205fe7018c69fe7b70757f2f9b4010936ee05e060f336
   ```
3. Vergleiche die Ausgabe aus **Schritt 2** und führe den folgenden Befehl aus, um den Hash der ISO-Datei zu überprüfen:
   ```sh
   # Beispiel:
   sha256sum cachyos-desktop-linux-260628.iso
   ```
4. Wenn die Hashes aus **Schritt 2** und **Schritt 3** übereinstimmen, kannst du mit der CachyOS-Installation fortfahren.

</Steps>

</TabItem>

## Echtheit des ISO-Images überprüfen (Linux)

Um die Echtheit der ISO-Datei zu überprüfen und sicherzustellen, dass es sich um die offizielle, vom CachyOS-Entwicklungsteam veröffentlichte Version handelt:

<Steps>

1. Importiere den GPG-Schlüssel zur Überprüfung der Echtheit:

   ```shell
   gpg --keyserver hkps://keys.openpgp.org --recv-key F3B607488DB35A47
   ```

2. Lade die ISO-Datei und ihre [.sig](https://cdn77.cachyos.org/ISO/desktop/260628/cachyos-desktop-linux-260628.iso.sig)-Signaturdatei herunter und führe den folgenden Befehl aus (indem du `full_iso_name.iso` durch den tatsächlichen ISO-Dateinamen ersetzt):
   ```shell
   gpg --verify full_iso_name.iso.sig full_iso_name.iso
   ```

   Wenn du eine **Good signature**-Ausgabe erhältst, ist die ISO-Datei echt:
   ```
   gpg: Signature made dom 08 mar 2026 10:39:18 -03
   gpg:                using RSA key 882DCFE48E2051D48E2562ABF3B607488DB35A47
   gpg: Good signature from "CachyOS <admin@cachyos.org>" [unknown]
   gpg: WARNING: This key is not certified with a trusted signature!
   gpg:          There is no indication that the signature belongs to the owner.
   Primary key fingerprint: 882D CFE4 8E20 51D4 8E25  62AB F3B6 0748 8DB3 5A47
   ```

</Steps>

:::danger
Wenn die Ausgabe keine **Good signature** zurückgibt oder die Schlüssel-ID nicht übereinstimmt, verwende das ISO-Image nicht. Stelle sicher, dass das heruntergeladene Image von einer legitimen CachyOS-Quelle stammt, da eine schlechte Signatur darauf hindeuten könnte, dass die ISO-Datei manipuliert wurde.
:::
