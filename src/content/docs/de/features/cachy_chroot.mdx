[cachy-chroot](https://github.com/CachyOS/cachy-chroot) ist ein simples Hilfsprogramm, das den Chroot-Prozess in eine bestehende
CachyOS- oder Arch-basierte Installation vereinfachen soll. Es listet alle auf dem Rechner gefundenen Partitionen auf und unterstützt auch die Auflistung von BTRFS-Subvolumes.
Zu guter Letzt unterstützt `cachy-chroot` auch verschlüsselte Systeme via LUKS. Es ordnet jeden `fstab`-Eintrag den zugehörigen `crypttab`-Einträgen zu
und schließt alle LUKS-Volumes beim Verlassen des Chroots sauber.

:::caution[cachy-chroot ist dafür gedacht, aus einer Live-Umgebung von CachyOS ausgeführt zu werden.]
:::

:::note
cachy-chroot unterstützt so ziemlich jedes Dateisystem, das vom Linux-Kernel unterstützt wird, außer ZFS.
:::

## Benutzung

:::tip
Benutze deine Pfeiltasten, um durch die Optionen zu navigieren, und `ENTER` zum Auswählen.

Das Symbol **❯** zeigt die aktuell ausgewählte Option an.

**?** deutet auf eine Eingabeaufforderung für den Benutzer hin.
:::

<Steps>
1. Boote in eine Live-ISO von CachyOS.
2. Öffne ein Terminal und werde mit `sudo su` zum Root-Benutzer.
3. Stell sicher, dass du das neueste `cachy-chroot` installiert hast, indem du Folgendes ausführst:
    ```bash
    pacman -Sy cachy-chroot
    ```
4. Führe `cachy-chroot` aus, indem du Folgendes eingibst:
    ```bash
    cachy-chroot
    ```
    `cachy-chroot` wird alle verfügbaren Partitionen scannen und auflisten.

6. `cachy-chroot` versucht, alle in der `/etc/fstab` des Root-Geräts aufgeführten Partitionen und Subvolumes automatisch zu mounten. Sollte das Mounten einer Partition fehlschlagen, wirst du benachrichtigt und hast die Möglichkeit, sie bei Bedarf manuell zu mounten. Du kannst `no` wählen, um das Mounten zusätzlicher Partitionen zu überspringen.
7. **Du befindest dich jetzt in der Chroot-Umgebung**.
    ```bash
    [root@CachyOS /]#
    ```
    Du kannst jetzt Befehle ausführen, als wärst du direkt in das installierte System gebootet. Zum Beispiel kannst du das System aktualisieren mit:
    ```bash title="System im Chroot aktualisieren"
    pacman -Syu
    ```
    oder bei Bedarf andere Wartungsaufgaben durchführen.
8. Wenn du fertig bist, verlasse die Chroot-Umgebung, indem du `exit` in die Eingabeaufforderung eingibst oder `STRG+D` auf der Tastatur drückst.
    ```bash title="Chroot verlassen"
    exit
    ```
9. Nach dem Verlassen räumt `cachy-chroot` automatisch die gemounteten Partitionen auf und schließt alle LUKS-Container. Du kehrst zur Shell der Live-Umgebung zurück.

### Fehlerbehebung

- **Keine Partitionen gefunden:** Stell sicher, dass die Festplatte mit deiner Installation angeschlossen ist und vom Live-System erkannt wird. Das kannst du mit `lsblk` oder `fdisk -l` überprüfen.
- **Automount für einige Partitionen schlägt fehl:** Du kannst versuchen, sie manuell innerhalb der Chroot-Umgebung zu mounten. `cachy-chroot` ignoriert Fehler und macht weiter.

### FAQ

- **F: Wozu dient das Mounten zusätzlicher Partitionen?**
  - A: Es gibt mehrere Anwendungsfälle für das manuelle Mounten zusätzlicher Partitionen, darunter:
    - **Kaputte oder fehlende fstab-Datei:** Du kannst notwendige Partitionen (wie `/boot` oder `/home`) manuell mounten, um Reparaturen oder Datenwiederherstellung durchzuführen.
    - **Aktualisierte Partitions-UUIDs:** Wenn dein System nicht bootet, weil du die UUID einer Partition geändert hast, kannst du `cachy-chroot` verwenden, um die Partitionen zu mounten und dann die fstab entsprechend zu aktualisieren.
