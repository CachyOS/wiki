:::caution
Seit Hyprland mit der Überarbeitung begonnen hat, ist es derzeit nicht stabil und es können Fehler/unerwartete Abstürze auftreten. Die Nutzung erfolgt auf eigene Gefahr.
Sogar die "stabile" Version ist fehlerhaft und instabil, daher planen wir nicht, Unterstützung außerhalb unserer Dotfiles anzubieten. Bitte ziehen Sie stattdessen das [Wiki](<https://wiki.hyprland.org/>) von Hyprland zu Rate.
:::

:::tip
Starten Sie Hyprland über den Eintrag ohne systemd, da es sonst nicht startet und zu einem schwarzen Bildschirm führt.

Beispiel: **`Hyprland`** anstelle von **`Hyprland(systemd)`**.
:::

Unser Hauptziel bei diesem Setup ist ein funktionierendes, aber einfaches Hyprland. Daher könnten einige wesentliche Werkzeuge und Programme fehlen, wie zum Beispiel ein grafischer Dateimanager.

Werfen Sie einen Blick in unsere [Hyprland-FAQ.](/de/desktop_environments/hyprland#faq)

**Dotfiles werden von [msmafra](https://github.com/msmafra) und [Lysec](https://github.com/Ly-sec) gepflegt.**

## Tastenkombinationen

Die meisten Tastenkombinationen erfordern die Verwendung der Mod-Taste, die in unserem Fall die Windows-Taste ist (als SUPER bezeichnet). Sie können dies in der Konfigurationsdatei ändern.

### Anwendungssteuerung

| Beschreibung | Taste |
|-------------|-----|
| Terminal öffnen | <Kbd linux="Super+Return" /> |
| Rofi öffnen (Programmstarter) | <Kbd linux="Super+Space" /> |
| Dateimanager öffnen | <Kbd linux="Super+E" /> |
| Aktives Fenster schließen | <Kbd linux="Super+Q" /> |

### Arbeitsflächen-Navigation

| Beschreibung | Taste |
|-------------|-----|
| Zur Arbeitsfläche (1-9) wechseln | <Kbd linux="Super+1" /> bis <Kbd linux="Super+9" /> |
| Nächste Arbeitsfläche | <Kbd linux="Super+Period" /> |
| Vorherige Arbeitsfläche | <Kbd linux="Super+Comma" /> |
| Mit dem Mausrad zwischen Arbeitsflächen wechseln | <Kbd linux="Super+Scroll" /> |

### Fenster-Navigation

| Beschreibung | Taste |
|-------------|-----|
| Fensterfokus nach oben | <Kbd linux="Super+ArrowUp" /> |
| Fensterfokus nach unten | <Kbd linux="Super+ArrowDown" /> |
| Fensterfokus nach links | <Kbd linux="Super+ArrowLeft" /> |
| Fensterfokus nach rechts | <Kbd linux="Super+ArrowRight" /> |
| Aktive Gruppe wechseln | <Kbd linux="Super+Tab" /> |

### Fenster-Management

| Beschreibung | Taste |
|-------------|-----|
| Fenster zur Arbeitsfläche (1-9) verschieben, ohne zu wechseln | <Kbd linux="Super+Shift+1" /> bis <Kbd linux="Super+Shift+9" /> |
| Fenster zur Arbeitsfläche (1-9) verschieben und dorthin wechseln | <Kbd linux="Super+Control+1" /> bis <Kbd linux="Super+Control+9" /> |
| Fenster nach oben verschieben | <Kbd linux="Super+Shift+ArrowUp" /> |
| Fenster nach unten verschieben | <Kbd linux="Super+Shift+ArrowDown" /> |
| Fenster nach links verschieben | <Kbd linux="Super+Shift+ArrowLeft" /> |
| Fenster nach rechts verschieben | <Kbd linux="Super+Shift+ArrowRight" /> |
| Fenstervollbild umschalten | <Kbd linux="Super+F" /> |
| Schwebendes Fenster umschalten | <Kbd linux="Super+V" /> |
| Fenster an alle Arbeitsflächen anheften (schwebend) | <Kbd linux="Super+Y" /> |
| Fenster zur Gruppe hinzufügen/entfernen | <Kbd linux="Super+K" /> |

### Fenstergröße anpassen

| Beschreibung | Taste |
|-------------|-----|
| Größenänderungsmodus aktivieren (H,J,K,L oder Pfeiltasten, Esc zum Beenden) | <Kbd linux="Super+R" /> |
| Fenster verkleinern (nach unten) | <Kbd linux="Super+Control+Shift+J" /> oder <Kbd linux="Super+Control+Shift+ArrowDown" /> |
| Fenster vergrößern (nach oben) | <Kbd linux="Super+Control+Shift+K" /> oder <Kbd linux="Super+Control+Shift+ArrowUp" /> |
| Fenster verkleinern (nach links) | <Kbd linux="Super+Control+Shift+H" /> oder <Kbd linux="Super+Control+Shift+ArrowLeft" /> |
| Fenster vergrößern (nach rechts) | <Kbd linux="Super+Control+Shift+L" /> oder <Kbd linux="Super+Control+Shift+ArrowRight" /> |

### Maussteuerung

| Beschreibung | Taste |
|-------------|-----|
| Fenster mit der Maus bewegen | <Kbd linux="Super+LeftClick" /> |
| Fenstergröße mit der Maus ändern | <Kbd linux="Super+RightClick" /> |

### Systemsteuerung

| Beschreibung | Taste |
|-------------|-----|
| Screenshot aufnehmen | <Kbd linux="Super+A" /> |
| Waybar neu laden | <Kbd linux="Super+O" /> |
| Abstand zwischen Fenstern verringern | <Kbd linux="Super+G" /> |
| Abstände auf Standard zurücksetzen | <Kbd linux="Super+Shift+G" /> |

### Mediensteuerung

| Beschreibung | Taste |
|-------------|-----|
| Lautstärkeregelung | Multimediatasten: <Kbd linux="VolUp" /> <Kbd linux="VolDown" /> <Kbd linux="Mute" /> |
| Helligkeitsregelung | Multimediatasten: hardwareabhängig |
| Wiedergabesteuerung | Multimediatasten: <Kbd linux="Play/Pause" /> <Kbd linux="Next" /> <Kbd linux="Previous" /> |
## FAQ

### Warum haben mein Discord, Thunar und Nautilus einen seltsamen Hintergrund?

Das liegt daran, dass die Deckkraft des Fensters geändert wurde.

* Erwägen Sie, die Fensterregel in der [Hyprland](https://github.com/CachyOS/cachyos-hyprland-settings/blob/master/etc/skel/.config/hypr/config/windowrules.conf#L21)-Konfigurationsdatei zu ändern.

```sh title='Beispiel'
windowrulev2 = opacity 0.92, class:^(thunar|nemo)$
```

### Ist ein Dateimanager enthalten?

* Nein, installieren Sie einen, der Ihnen gefällt.
