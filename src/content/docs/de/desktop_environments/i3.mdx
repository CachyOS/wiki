## Tastenkombinationen

Die meisten Tastenkombinationen erfordern die Verwendung der Mod-Taste, die in unserem Fall die Windows-Taste ist (als SUPER bezeichnet). Sie können dies in der Konfigurationsdatei ändern.

### Anwendungssteuerung

| Beschreibung | Taste |
|---|---|
| Terminal öffnen | <Kbd linux="Super+Return" /> |
| Rofi öffnen (Programmstarter) | <Kbd linux="Control+Space" /> |
| Fokussiertes Fenster schließen | <Kbd linux="Super+Q" /> |

## FAQ

### Wie kann ich ein Programm automatisch starten lassen? Zum Beispiel „beim Start ein Hintergrundbild festlegen“

* i3 verfügt bereits über eine flexible Autostart-Funktion, mit der Sie jedes Programm oder sogar Befehle ausführen können.

Wenn Sie sich das Ende unserer Konfigurationsdatei ansehen, werden Sie einige Zeilen sehen, die mit `exec` und `exec_always` beginnen.

Zum Beispiel:

```exec chromium```
Das bedeutet, dass Chromium auf Arbeitsfläche 1 startet, wann immer Sie sich in Ihrer i3-Sitzung anmelden.

* Was unterscheidet `exec` von `exec_always`?

`exec_always` gibt Ihnen die Möglichkeit, eine bestimmte Aktion immer auszuführen, auch nachdem i3wm neu geladen wurde.

* Für weitere Referenzen und Informationen, siehe das i3-Benutzerhandbuch:
* https://i3wm.org/docs/userguide.html#exec
