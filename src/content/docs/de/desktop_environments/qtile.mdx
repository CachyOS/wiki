## Tastenkürzel

Die meisten Tastenkombinationen erfordern die Verwendung der Mod-Taste, die in unserem Fall die Windows-Taste ist (als SUPER bezeichnet). Sie können dies in der Konfigurationsdatei ändern.
Einige könnten auch die Mod1-Taste (ALT-Taste) verwenden.

### Anwendungssteuerung

| Beschreibung | Taste |
|----------------|-------|
| Terminal öffnen | <Kbd linux="Super+Return" /> |
| Rofi öffnen (Programmstarter) | <Kbd linux="Alt+Leertaste" /> |
| Dateimanager öffnen (Thunar) | <Kbd linux="Super+E" /> |
| Fokussiertes Fenster schließen | <Kbd linux="Super+Q" /> |

### Arbeitsflächennavigation

| Beschreibung | Taste |
|----------------|-------|
| Zur Arbeitsfläche wechseln (1-9) | <Kbd linux="Super+1" /> bis <Kbd linux="Super+9" /> |

### Fensternavigation

| Beschreibung | Taste |
|----------------|-------|
| Fokus nach links verschieben | <Kbd linux="Super+H" /> |
| Fokus nach rechts verschieben | <Kbd linux="Super+L" /> |
| Fokus nach unten verschieben | <Kbd linux="Super+J" /> |
| Fokus nach oben verschieben | <Kbd linux="Super+K" /> |
| Fenster zwischen Spalten oder im Stapel nach oben/unten verschieben | <Kbd linux="Super+Leertaste" /> |

### Fensterverwaltung

| Beschreibung | Taste |
|----------------|-------|
| Fokussiertes Fenster nach links verschieben | <Kbd linux="Super+Shift+H" /> |
| Fokussiertes Fenster nach rechts verschieben | <Kbd linux="Super+Shift+L" /> |
| Fokussiertes Fenster nach unten verschieben | <Kbd linux="Super+Shift+J" /> |
| Fokussiertes Fenster nach oben verschieben | <Kbd linux="Super+Shift+K" /> |
| Vollbild umschalten | <Kbd linux="Super+F" /> |
| Schwebenden Modus umschalten | <Kbd linux="Super+V" /> |
| Fenster fixieren (folgt bei Wechsel der Arbeitsfläche) | <Kbd linux="Super+S" /> |

### Fenstergröße ändern

| Beschreibung | Taste |
|----------------|-------|
| Fokussiertes Fenster nach links vergrößern | <Kbd linux="Super+Control+H" /> |
| Fokussiertes Fenster nach rechts vergrößern | <Kbd linux="Super+Control+L" /> |

| Beschreibung | Taste |

## FAQ

### Warum zeigt das Lautstärke-Widget einen Fehler an oder bleibt bei 0 % hängen?

* Manchmal liegt das daran, dass das Qtile-Lautstärke-Widget Ihr Standard-Ausgabegerät nicht erkennen kann. Weitere Informationen finden Sie im Wiki.
* https://docs.qtile.org/en/latest/manual/ref/widgets.html#pulsevolume

### Gibt es ein autostart.sh Skript?

* Es befindet sich im Ordner scripts/ innerhalb des Qtile-Verzeichnisses.

### Interagiert die Leiste von Qtile mit der Maus?

* Ja, zum Beispiel können Sie durch Scrollen über die kleinen Punkte, die Ihre Arbeitsflächen darstellen (Aktiv, Inaktiv, Leer usw.), nach links oder rechts wechseln oder direkt auf einen klicken.
* Ein weiteres Beispiel ist das Layout (standardmäßig Spalten). Ein Klick darauf ermöglicht den Wechsel zwischen den verfügbaren Layouts.
* Ein Klick auf die CPU- und RAM-Anzeige öffnet Btop (ein Systemmonitor im Terminal).
* Lauter/Leiser/Stumm schalten durch Interaktion mit dem Lautstärke-Widget.

Für weitere Informationen über Qtile, schauen Sie bitte im offiziellen Wiki nach.

* https://docs.qtile.org/en/stable/
