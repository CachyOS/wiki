## 시작하기 전에

:::note
**Launch Installer**를 누른 뒤 부트 매니저 옵션으로 GRUB과 Limine만 표시된다면, 시스템이 Legacy/BIOS 모드로 부팅된 것입니다.
:::

:::note[설치 과정 중에는 여러 데스크톱 환경을 동시에 설치할 수 없습니다.]
:::

:::caution[UEFI 모드로 설치할 때는 BIOS/UEFI 설정에서 Secure Boot와 CSM을 비활성화해야 합니다.]
설치 후 Secure Boot를 설정하려면 [Secure Boot](/configuration/secure_boot_setup) 섹션을 참고하세요.

`Legacy USB Support`는 `Auto`로 설정해야 합니다.
:::

:::caution
`Install alongside`와 `Replace partition` 옵션은 100% 안정적이지 않으며 설치 실패를 유발할 수 있습니다.

CachyOS를 설치할 때는 `Manual partitioning`을 **강력히 권장**합니다.
:::

:::tip
설치 시도가 실패한 뒤에는 ISO로 다시 부팅하는 것을 강력히 권장합니다.

그렇지 않으면 설치 과정에서 연속적인 오류가 발생할 수 있습니다.

이는 설치 실패 시 설치 프로그램이 파티션을 제대로 언마운트하지 못하기 때문에 발생합니다.

:::

## 설치 방법

### 수동 파티션 구성

:::note[UEFI 설치를 위해 디스크 파티션을 진행하기 전에 확인하세요.]
    ```sh title='터미널에서 이 명령 실행'
    efibootmgr -v
    ```
출력이 `EFI variables are not supported on this system.`이라면 시스템이 Legacy/BIOS 모드로 부팅된 것이므로, BIOS/UEFI 설정에서 UEFI 모드가 구성되어 있는지 확인해야 합니다. [요구 사항](/installation/installation_on_root/#before-you-begin) 섹션을 참고하세요.
:::

<Tabs>

## Windows와 CachyOS 듀얼 부팅

:::note[이 가이드는 Windows가 이미 시스템에 설치되어 있고, 같은 드라이브를 공유하여 Windows 옆에 CachyOS를 설치하기로 결정한 경우를 전제로 합니다.]
:::

:::caution
Windows와 Linux의 듀얼 부팅은 100% 안정적이지 않습니다. Windows 업데이트가 EFI 파티션을 덮어써 부트로더를 손상시킬 수 있습니다.
어떤 경우에는 문제가 전혀 발생하지 않을 수도 있지만, 일부 사용자에게는 반복적으로 발생하는 문제가 될 수 있습니다.

이 문제를 피하는 한 가지 방법은 각 운영체제를 별도의 드라이브에 설치하는 것입니다.
:::

:::caution
대상 부트 매니저의 권장 최소 크기에 따라 EFI 파티션의 크기를 조정해야 할 수 있습니다. [수동 파티션 구성](/installation/installation_on_root#manual-partitioning)을 참고하세요.

FAT 파일 시스템은 제자리에서 크기를 조정할 수 없습니다. FAT EFI 파티션의 크기를 올바르게 "조정"하려면 기존 EFI 파일 시스템을 백업하고, `gparted` 같은 도구를 사용해 기존 파티션 크기를 조정한 뒤 새 파티션을 다시 포맷하고, 이전 파일 시스템 구조를 EFI 파티션으로 다시 복사해야 합니다.
:::

### 사전 요구 사항

- Windows 빠른 시작과 최대 절전 모드를 비활성화해야 합니다.
  - Windows Powershell을 관리자 권한으로 열고 다음 명령을 실행합니다.
      ```ps
      powercfg /H off
      ```
    변경 사항이 적용되도록 시스템을 재부팅합니다.
- Windows BitLocker를 비활성화해야 합니다.
  - BitLocker가 활성화되어 있는지 확인합니다.
    ```ps title='명령 프롬프트를 관리자 권한으로 열고 다음 명령 실행'
    manage-bde -status
    ```
  **Encryption Method**가 `None`으로 표시되면 BitLocker가 비활성화된 것입니다.
- Secure Boot를 비활성화해야 합니다.
- 30GB 이상의 빈 파티션이 필요합니다.
  - Windows 파티션을 축소하는 방법:
    - `Win + R`을 누르고 `diskmgmt.msc`를 입력한 뒤 Enter를 눌러 디스크 관리를 엽니다.
    - 기본 Windows 파티션(일반적으로 C:)을 확인하고 마우스 오른쪽 버튼으로 클릭합니다.
    - `Shrink Volume...`을 클릭하고 최소 **30720 MB**(30 GiB)를 지정한 뒤 `Shrink`를 클릭합니다.
- CachyOS가 들어 있는 부팅 가능한 USB가 필요합니다.
  - [부팅 가능한 CachyOS USB 드라이브 만들기](/installation/installation_prepare#creating-a-bootable-cachyos-usb-drive) 섹션을 참고하세요.

<Tabs>
    <TabItem label='Limine'>
        Limine은 Windows EFI 파티션을 자동으로 감지하여 부팅 메뉴에 추가해야 합니다. Windows가 부팅 메뉴에 나타나지 않으면 다음 명령을 실행하세요.
        ```bash
        sudo limine-scan
        ```
    </TabItem>
    <TabItem label='systemd-boot'>
        **부트 매니저가 Windows EFI 바이너리를 인식할 수 있도록 Windows EFI 바이너리를 Linux EFI 파티션으로 복사해야 합니다.**

        <Steps>
        1. `lsblk`로 **Windows EFI 파티션**을 찾습니다.

            ```sh title='터미널에서 이 명령 실행'
            lsblk -o NAME,FSTYPE,SIZE,MOUNTPOINT
            ```
            ```sh title='출력 예시'
                        NAME        FSTYPE   SIZE MOUNTPOINT
            zram0               15.3G [SWAP]
            nvme0n1            476.9G
            ├─nvme0n1p1 vfat     100M
            ├─nvme0n1p2           16M
            ├─nvme0n1p3 ntfs   234.4G
            ├─nvme0n1p4 ntfs     830M
            ├─nvme0n1p5 vfat       2G /boot
            └─nvme0n1p6 btrfs  239.6G /var/tmp
            ```
            EFI 파티션은 거의 항상 `FAT32/vfat`으로 포맷되어 있습니다. `nvme0n1p1`에는 Linux 마운트 지점이 없으므로, 이 파티션을 Windows EFI 파티션으로 간주할 수 있습니다.

        2. Windows EFI 파티션을 임시로 마운트합니다.

            ```sh
            sudo mkdir /mnt/WinBoot
            sudo mount /dev/nvme0n1p1 /mnt/WinBoot # Replace `nvme0n1p1` with the name of the Windows EFI partition.
            ```

        3. **Windows EFI 파티션**의 EFI 바이너리를 **Linux EFI 파티션**으로 복사합니다.

            ```sh
            sudo cp -r /mnt/WinBoot/EFI/Microsoft/ /boot/EFI
            ```

        4. 이전에 마운트한 파티션을 언마운트합니다. 다음 시작 시 Windows가 부팅 메뉴에 표시되어야 합니다.

            ```sh
            sudo umount /mnt/WinBoot
            sudo rm -r /mnt/WinBoot
            ```

        </Steps>
    </TabItem>

    <TabItem label='GRUB (Only for older installations)'>
        :::tip[CachyOS는 기본적으로 os-prober를 활성화합니다.]
        :::
        **GRUB은 os-prober를 사용해 Windows EFI 파티션을 자동으로 감지하고 부팅 메뉴에 추가합니다.**

        <Steps>
        1. **os-prober**를 설치합니다.

            ```sh
            sudo pacman -S os-prober
            ```

        2. GRUB 설정 파일에서 **os-prober**를 활성화합니다.

            ```sh title='Micro에서 CTRL+S를 눌러 저장하고 CTRL+Q를 눌러 종료'
            sudo micro /etc/default/grub
            # /etc/default/grub
            # Probing for other operating systems is disabled for security reasons. Read
            # documentation on GRUB_DISABLE_OS_PROBER, if still want to enable this
            # functionality install os-prober and uncomment to detect and include other
            # operating systems.
            GRUB_DISABLE_OS_PROBER=false

            ```

        3. 이제 **os-prober**를 사용하도록 grub.cfg를 업데이트합니다.
            ```sh
            sudo grub-mkconfig -o /boot/grub/grub.cfg
            ```

            **이제 Windows가 부팅 메뉴에 추가되어야 합니다.**

        </Steps>
    </TabItem>
</Tabs>
