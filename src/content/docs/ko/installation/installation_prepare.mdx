## 시스템 요구 사항

설치를 준비하기 전에 CachyOS를 실행하기 위해 사용하는 컴퓨터가 최소 시스템 요구 사항을 충족하는지 확인하세요. 설치 프로그램은
온라인 설치 과정을 사용하므로 안정적이고 비교적 빠른 인터넷 연결이 필수입니다.

:::note[가상 머신]
가상 머신에 CachyOS를 설치하는 것은 권장되지 않습니다. VM은 잘못된 구성으로 문제가 생기거나 완전히 작동하지 않을 수 있습니다. CachyOS는 실제 하드웨어에 설치하는 것을 권장합니다.
:::

<Tabs>

<TabItem label="최소 요구 사항">

*   3 GB RAM
*   30 GB 저장 공간 (HDD/SSD)
*   안정적인 인터넷 연결

:::caution
불안정한 인터넷은 설치 시간이 길어지거나, 최악의 경우 설치 실패로 이어질 수 있습니다.
:::

</TabItem>

<TabItem label="권장 요구 사항">

*   8GB RAM
*   50 GB 저장 공간 (SSD/NVMe)
*   [x86-64-v3 지원 CPU](/installation/installation_prepare#x86_64-microarchitecture-level-support)
*   50 Mbps 이상 인터넷 속도
*   NVIDIA GPU (900+ - 예: GTX 950), AMD +GCN 1.0 (예: AMD R7 240) 또는 Intel (Integrated HD Graphics 시리즈 이상, Arc 시리즈)

</TabItem>

</Tabs>

## 부팅 가능한 CachyOS USB 드라이브 만들기

부팅 가능한 CachyOS USB 드라이브를 만드는 데 사용할 수 있는 도구와 방법은 여러 가지가 있습니다.

:::tip
나중에 chroot를 통한 문제 해결에 사용할 수 있도록 CachyOS ISO 사본을 같은 드라이브나 다른 위치에 보관하세요.
:::

:::note
USB 드라이브에는 최소 8GB의 사용 가능한 공간이 있어야 합니다.
:::

### balenaEtcher

<Steps>

1. [balenaEtcher](<https://etcher.balena.io/>)를 다운로드합니다. balenaEtcher는 Linux, MacOS, Windows 이미지 플래싱을 지원합니다.
   `.zip` 파일을 다운로드했다면 압축을 풀고 다음 명령으로 바이너리를 실행합니다:
      ```sh
      # Extract zip file:
      bsdtar xvf <zip file name>
      # cd to the new folder:
      cd balenaEtcher-linux-x64/
      # Execute balenaEtcher:
      ./balena-etcher
      ```
2. USB 드라이브를 컴퓨터에 연결합니다.
3. `Flash from file`을 선택하고 CachyOS ISO 이미지 파일을 선택합니다.
4. `Select target`을 클릭하고 앞서 연결한 USB 드라이브를 선택합니다.
5. `Flash`를 눌러 플래싱 과정을 시작합니다.

</Steps>

:::note
balenaEtcher에서 관리자 권한을 요청할 수 있습니다. 요청이 표시되면 비밀번호를 입력하고 `Authenticate`를 클릭하세요.
:::

### 명령줄 인터페이스 (Linux 및 MacOS)

<Steps>

1. USB 드라이브를 연결합니다.
2. 다음 명령을 사용해 연결된 USB 드라이브를 확인합니다:
   ```sh
   # Linux
   # The USB drive could be identified e.g: /dev/sda, by disk model and size.
   sudo fdisk -l

   # MacOS
   # USB drives are identified as "/dev/diskY" where "Y" could be 0,1 etc.
   diskutil list
   ```
3. 다음 명령을 실행해 ISO 내용을 연결된 USB 드라이브로 복사합니다:
   ```sh
   # Replace <usbdrive> with the label of the drive.
   sudo dd bs=4M if=full_iso_name.iso of=/dev/<usbdrive> status=progress oflag=sync
   ```
</Steps>

- 이제 `dd`가 ISO 파일의 내용을 연결된 USB 드라이브에 복사합니다.

### Rufus (Windows 전용)

<Steps>

1. USB 드라이브를 연결합니다.
2. [Rufus](<https://rufus.ie/>)를 다운로드해 설치하거나, 포터블 버전을 실행합니다.
3. `Device`에서 드롭다운 목록을 클릭하고 연결된 USB 드라이브를 선택합니다.
4. `Boot selection`에서 `SELECT`를 클릭하고 CachyOS ISO 이미지 파일을 찾습니다.
5. `START`를 클릭합니다.

</Steps>

### Ventoy (Linux 및 Windows)

<Tabs>

<TabItem label="Linux">

<Steps>

1. USB 드라이브를 연결합니다.
2. [Ventoy](<https://www.ventoy.net/en/download.html>)를 다운로드합니다.
3. 다음 명령을 사용해 Ventoy tar 파일의 압축을 풉니다:
   ```sh
   # Replace version with the correct one e.g: ventoy-1.1.07-linux.tar.gz
   bsdtar xvf ventoy-version-linux.tar.gz
   # cd to the new folder: (version might change)
   cd ventoy-1.1.07/
   ```
4. `VentoyGUI.x86_64`를 더블 클릭하거나 터미널에서 실행합니다:
   ```sh
   # It will ask for administrative privileges, enter your credentials
   ./VentoyGUI.x86_64
   ```
5. `Device`를 클릭해 연결된 USB 드라이브를 선택합니다.
6. `Install`을 클릭합니다.
7. 연결된 USB 드라이브에 Ventoy 설치가 끝나면 창을 닫고, 드라이브의 새 사용 가능 파티션에 CachyOS ISO 파일을 넣습니다.

</Steps>

</TabItem>

<TabItem label="Windows">

<Steps>
1. USB 드라이브를 연결합니다.
2. [Ventoy](<https://www.ventoy.net/en/download.html>)를 다운로드합니다.
3. `Ventoy2Disk.exe`를 실행합니다.
4. `Device`를 클릭해 연결된 USB 드라이브를 선택합니다.
5. `Install`을 클릭합니다.
6. USB 드라이브에 Ventoy 설치가 끝나면 창을 닫고, 드라이브의 새 사용 가능 파티션에 CachyOS ISO 파일을 넣습니다.
</Steps>

</TabItem>

</Tabs>
