다양한 장치에서 최상의 경험을 제공하기 위해 CachyOS는 현재 다음 부트 매니저를 제공합니다: **systemd-boot, rEFInd, GRUB, Limine**.

이 위키 문서는 각 부트 매니저의 기능 구성을 설명하고, 어떤 경우에 선택하면 좋은지에 대한 권장 사항을 포함합니다.
설정 방법은 [부트 매니저 설정](/configuration/boot_manager_configuration)을 참조하세요.

:::caution
**중요 참고:** 일부 MSI 메인보드는 UEFI 사양을 완전히 준수하지 않는 UEFI 펌웨어를 사용합니다. 이로 인해 GRUB 및 rEFInd를 포함한 특정 부트 매니저에서 호환성 문제가 발생할 수 있습니다.

이러한 문제가 발생한다면 `systemd-boot` 또는 `Limine` 사용을 고려하세요.
:::

## 부트 매니저 세부 정보

### systemd-boot

systemd 계열의 일부인 systemd-boot는 최대한 단순하도록 만들어졌습니다. 따라서 UEFI 기반 시스템만 지원합니다. 이 단순하면서도 효율적인 설계 덕분에 안정적이고 빠르지만, 다른 부트 매니저가 지원하는 고급 기능은 일부 포기해야 합니다.

#### 장점
- 설정이 매우 간단합니다.
- 부트 항목이 여러 파일로 분리되어 있어 관리하기 쉽습니다.
- 다른 부트 매니저 사용 시 UEFI 문제가 발생하는 일부 MSI 보드와의 호환성을 보장합니다.
- CachyOS에서는 설정이 기본적으로 자동 생성됩니다.
- 부팅 중 TPM PCR이 측정됩니다.

#### 단점
- BIOS/MBR을 지원하지 않습니다.
- 매우 기본적인 구성입니다: 테마나 사용자 지정 기능이 없습니다.
- 펌웨어의 기본 파일시스템(FAT12/16/32)을 넘어서는 부트 파일시스템을 사용하는 경우, 별도의 ESP 및 [XBOOTLDR](https://wiki.archlinux.org/title/Systemd-boot#Installation_using_XBOOTLDR) 파티션과 EFI 드라이버를 수동으로 추가해야 합니다.
- 자체 ESP 또는 XBOOTLDR 파티션 이외의 파티션에서는 부트 이미지를 찾을 수 없습니다.
- 그렇게 하도록 설정하지 않으면 설정이 자동 생성되지 않습니다.
- 커널 이미지를 root가 아닌 부트 파티션에 저장해야 하는 요구 사항 때문에 Btrfs 스냅샷 롤백을 기본적으로 지원하지 않습니다.
  - 스냅샷 부팅은 사용자 지정 설정에서만 가능합니다(CachyOS에서 제공하지 않음).

---

### rEFInd

rEFIt의 포크인 rEFInd는 원래 MacOS 사용자가 더 쉽게 멀티 부팅할 수 있도록 만들어졌습니다. 그러나 rEFInd는 하드웨어에 구애받지 않는 방식으로 발전했으며, 어떤 시스템에서든 멀티 부팅을 위한 훌륭한 선택지가 되었습니다. rEFInd의 핵심 장점은 부팅 시 모든 저장 장치를 스캔하고, 발견된 각 OS/커널에 해당하는 항목을 표시할 수 있다는 점입니다.

#### 장점
- 저장 장치의 모든 운영체제와 커널을 자동 감지합니다.
- 수동 설정이 거의 또는 전혀 필요하지 않습니다.
- MacOS 부트 선택기를 연상시키는 그래픽 UI를 제공합니다.
- 선택적 터치스크린 지원을 포함해 테마 지원이 뛰어납니다.
- EFI 파일시스템(FAT12/16/32)은 물론 EXT4 및 BTRFS에서도 부트 이미지를 읽을 수 있습니다. `efifs` 패키지의 EFI 드라이버를 설치하면 추가 파일시스템 지원을 활성화할 수 있습니다.

#### 단점
- BIOS 시스템을 지원하지 않습니다.
- 일부 MSI 보드와 호환되지 않습니다(UEFI 사양 위반 때문).
  - 우회 방법으로 수정할 수 있지만 추가 단계가 필요합니다.
- TPM PCR이 측정되지 않습니다. <a href="https://github.com/fwupd/fwupd/wiki/TPM-PCR0-differs-from-reconstruction">TPM PCR0 재구성 테스트에 실패합니다</a>.
  - UEFI stub으로 systemd-stub을 사용하는 UKI로 부팅하면 수정할 수 있습니다. systemd-ukify로 이를 만들 수 있습니다.
  - 또 다른 우회 방법은 TPM PCR을 측정하는 다른 부트로더(예: systemd-boot, GRUB)를 체인로딩하는 것입니다.

### GRUB

GRUB은 제공되는 부트 매니저 중 가장 오래된 것입니다. 매우 큰 기능 세트를 갖추고 있으며, 거의 모든 시스템에서 작동하고, 여전히 가장 널리 사용되는 Linux 부트 매니저입니다.

#### 장점
- 거의 모든 Linux 파일시스템을 지원합니다.
- 널리 사용됩니다 — 문서와 커뮤니티 도움을 풍부하게 찾을 수 있습니다.
- 암호화된 `/boot` 파티션을 지원합니다.
- Btrfs 스냅샷 부팅을 지원합니다(CachyOS에서는 `grub-btrfs-support` 사용).
- BIOS 및 UEFI 시스템을 지원합니다.
- UI가 다소 오래되어 보이지만 테마 지원을 사용할 수 있습니다.
- 부팅 중 TPM PCR이 측정됩니다.

#### 단점
- 크고 복잡하며, 많은 파일시스템 드라이버를 포함합니다.
- systemd-boot, rEFInd, Limine보다 눈에 띄게 느립니다.
- 일부 MSI 보드와 호환되지 않습니다(UEFI 사양 위반).

---

### Limine

Limine은 현대적이고 고급 기능을 갖춘 이식성 높은 멀티프로토콜 부트로더입니다. Limine 부트 프로토콜의 참조 구현 역할을 하며, Linux는 물론 다른 로더의 체인로딩도 지원합니다.

#### 장점
- Multiboot2와 Linux 부트 프로토콜을 포함한 여러 부트 프로토콜을 지원합니다.
- UEFI와 BIOS 시스템 모두에서 부팅할 수 있습니다.
- GRUB과 유사한 테마 기능을 제공합니다.
- `limine-snapper-sync`를 통해 Btrfs 스냅샷을 지원하며, CachyOS에서 Btrfs 사용 시 기본적으로 활성화됩니다.

#### 단점
- `/boot`는 FAT12/16/32 또는 ISO9660을 사용해야 합니다. 다른 파일시스템은 추가 설정이 필요합니다.
- UEFI NVRAM에 항목을 자동으로 추가하지 않습니다. 이는 `efibootmgr`로 수동 수행하거나, CachyOS에 사전 설치된 `limine-entry-tool`로 자동 처리해야 합니다.
- 일부 Chromebook 등에서 사용되는 UFS(Universal Flash Storage)에서는 작동하지 않습니다.
- TPM PCR이 측정되지 않습니다. <a href="https://github.com/fwupd/fwupd/wiki/TPM-PCR0-differs-from-reconstruction">TPM PCR0 재구성 테스트에 실패합니다</a>.
  - UEFI stub으로 systemd-stub을 사용하는 UKI로 부팅하면 수정할 수 있습니다. systemd-ukify로 이를 만들 수 있습니다(<a href="https://github.com/fwupd/fwupd/discussions/9568" target="_blank">여기 참조</a>).
  - 또 다른 우회 방법은 TPM PCR을 측정하는 다른 부트로더(예: systemd-boot, GRUB)를 체인로딩하는 것입니다.

## 요약

- 암호화된 `/boot`, BIOS 호환성, 또는 안정적이고 성숙한 부트 매니저에서 Btrfs 스냅샷을 원한다면 GRUB을 선택하세요.

- Btrfs 스냅샷 통합이 기본 제공되는 현대적인 부트로더와 BIOS/UEFI 동시 지원, Windows 듀얼 부팅(**limine-scan** 사용)을 원한다면 Limine을 선택하세요.

- 깔끔한 그래픽 인터페이스와 UEFI 시스템에서의 자동 멀티 부팅 감지를 원한다면 rEFInd를 선택하세요.

- 가장 단순한 구성을 선호하고 스냅샷이나 고급 기능이 필요하지 않다면 systemd-boot를 선택하세요. UEFI 문제가 있는 MSI 메인보드에서 가장 신뢰할 수 있는 대체 선택지이기도 합니다.
