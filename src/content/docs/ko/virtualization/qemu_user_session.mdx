## 사용 사례:
- **네트워킹**

루트 세션에서는 VM이 포트를 포워딩할 수 없으며 대신 **NAT**를 사용합니다. 
즉, VM은 외부 네트워크에 접근할 수 있지만, 외부에서는 VM을 직접 볼 수 없고 
대신 사용자의 PC만 보입니다. 일반적인 경우에는 문제가 없지만, PC 외부에서 
VM에 직접 연결하려는 경우(예: ssh 사용)에는 연결할 대상이 없기 때문에 접속할 수 없습니다.

- **변환을 통한 3D 가속**

루트 세션에서는 VMM이 렌더 노드 `/dev/dri/renderD128`를 사용할 수 없으며, 
일반 사용자는 루트 qemu를 거의 활용할 수 없기 때문에 `qemu-cli` 사용도 제한됩니다.

## 사용자 세션 활성화:
매우 간단합니다. 기본 **VMM** 창에서 `File -> Add Connection...`을 클릭하고, 
`Hypervisor:` 드롭다운 메뉴에서 `QEMU/KVM user session`을 선택합니다. 이제 
루트 모드가 아닌 사용자 모드에서 [QEMU and VMM Setup](/virtualization/qemu_and_vmm_setup)에 
설명된 방식대로 VM을 만들 수 있습니다.
