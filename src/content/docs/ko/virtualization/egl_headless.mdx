## 사용 사례

- **3D 가속**

`Linux`, `BSD`, `Android`처럼 `OpenGL`을 사용하는 운영 체제에서는 VM 호출을
GPU 하드웨어를 VM에 전용으로 할당하지 않고도, 즉 GPU 패스스루 없이, VM에서 GPU로
직접 전달하고 다시 받아오는 방식으로 소프트웨어 반가상화보다 훨씬 더 나은 성능을 얻을 수 있습니다.

## VMM에서 EGL Headless 사용하기

**VMM**에서 위에서 설명한 조건에 맞는 VM 중 하나를 열고, **User Session** 모드를 사용합니다.
