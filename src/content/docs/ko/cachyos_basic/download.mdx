## 공식 ISO 출처

CachyOS ISO는 다음 출처에서 받을 수 있습니다.

*   [웹사이트](<https://cachyos.org/download>)
*   [SourceForge](<https://sourceforge.net/projects/cachyos-arch/files/>)
*   [CachyOS 미러](<https://mirror.cachyos.org/ISO/>)

## SHA256으로 ISO 무결성 검증하기

:::caution
설치 중이나 부팅 가능한 미디어를 만드는 과정에서 원치 않는 문제가 발생하지 않도록, 항상 ISO 무결성을 검증하는 추가 단계를 진행하세요.
:::

**현재 ISO 버전:** `260426`

**SHA256 해시:** `9a280d1e9732cfe50ab02db6a7e44ae0d9e6a10e6ea394f73192f7c14e263118`

<Tabs>

<TabItem label='Windows'>

<Steps>

1. SHA256 해시가 들어 있는 [파일](https://mirror.cachyos.org/ISO/desktop/260426/cachyos-desktop-linux-260426.iso.sha256)을 다운로드합니다 **(메모장 같은 텍스트 편집기로 여세요)**.
2. CMD 또는 PowerShell을 관리자 권한으로 열고, ISO와 SHA256 파일이 저장된 경로로 [이동](<https://www.wikihow.com/Change-Directories-in-Command-Prompt>)합니다.
3. 다음 명령을 실행합니다.
   ```powershell
   # Example:
   certUtil -hashfile cachyos-desktop-linux-260426.iso SHA256
   ```
4. certUtil 해시 출력값을 **1단계**에서 다운로드한 파일의 값과 비교합니다. 두 값이 일치하면 CachyOS 설치를 진행해도 됩니다.

</Steps>

</TabItem>

<TabItem label='Linux'>

<Steps>

1. SHA256 해시가 들어 있는 [파일](https://mirror.cachyos.org/ISO/desktop/260426/cachyos-desktop-linux-260426.iso.sha256)을 다운로드합니다.
2. 터미널을 열고 `.sha256` 파일과 `.iso` 파일이 모두 들어 있는 디렉터리로 이동합니다.
3. 다음 명령을 실행합니다.
   ```sh
   # Example:
   cd ~/Downloads
   sha256sum -c cachyos-desktop-linux-260426.iso.sha256
   # cachyos-desktop-linux-260426.iso: OK
   ```
4. **3단계**의 출력이 OK라면 CachyOS 설치를 진행해도 됩니다.

</Steps>

</TabItem>

<TabItem label='macOS'>

<Steps>

1. SHA256 해시가 들어 있는 [파일](https://mirror.cachyos.org/ISO/desktop/260426/cachyos-desktop-linux-260426.iso.sha256)을 다운로드합니다.
2. 터미널을 열고 `.sha256` 파일이 들어 있는 디렉터리로 이동한 뒤, 다음 명령을 실행합니다.
   ```sh
   # Example:
   cd Downloads/
   cat cachyos-desktop-linux-260426.iso.sha256
   # 9a280d1e9732cfe50ab02db6a7e44ae0d9e6a10e6ea394f73192f7c14e263118
   ```
3. **2단계**의 출력값을 ISO 파일의 해시와 비교합니다.
   ```sh
   # Example:
   shasum -a 256 cachyos-desktop-linux-260426.iso
   ```
4. **2단계**와 **3단계**의 해시가 일치하면 CachyOS 설치를 진행해도 됩니다.

</Steps>

</TabItem>

</Tabs>

## ISO 이미지 진위 확인하기 (Linux)

ISO 파일의 진위를 확인하려면 다음을 진행합니다.

<Steps>

1. 비교 기준으로 사용할 GPG 키를 가져옵니다.

   ```shell
   gpg --keyserver hkps://keys.openpgp.org --recv-key F3B607488DB35A47
   ```

2. ISO 파일과 해당 [.sig](https://cdn77.cachyos.org/ISO/desktop/260426/cachyos-desktop-linux-260426.iso.sig) 서명 파일을 다운로드한 뒤 다음 명령을 실행합니다. (`full_iso_name.iso`는 실제 ISO 파일 이름으로 바꾸세요.)
   ```shell
   gpg --verify full_iso_name.iso.sig full_iso_name.iso
   ```

   **Good signature** 출력이 표시되면 ISO 파일은 정상적인 원본입니다.
   ```
  gpg: Signature made dom 09 ago 2026 13:30:06 -03
  gpg:                using RSA key 882DCFE48E2051D48E2562ABF3B607488DB35A47
  gpg: Good signature from "CachyOS <admin@cachyos.org>" [unknown]
  gpg: WARNING: This key is not certified with a trusted signature!
  gpg:          There is no indication that the signature belongs to the owner.
  Primary key fingerprint: 882D CFE4 8E20 51D4 8E25  62AB F3B6 0748 8DB3 5A47
   ```

</Steps>

:::danger
출력에 **Good signature** 문자열이 없거나 키 ID가 일치하지 않으면 ISO 이미지를 사용하지 마세요. 잘못된 서명은 ISO가 변조되었거나 손상되었을 가능성을 의미합니다.

다운로드한 이미지가 [정식 CachyOS 출처](/cachyos_basic/download#official-iso-sources)에서 온 것인지 확인하세요.
:::
