## 단축키

대부분의 키 조합은 mod 키를 사용해야 하며, 이 문서에서는 Windows 키를 mod 키로 사용합니다. 이 키는 SUPER로 표기되며, 설정 파일에서 변경할 수 있습니다.
일부 단축키는 mod1, 즉 ALT 키를 사용할 수 있습니다.

### 애플리케이션 제어

| 설명 | 키 |
|-------------|-----|
| 터미널 열기 | <Kbd linux="Super+Return" /> |
| Rofi 열기(프로그램 실행기) | <Kbd linux="Alt+Space" /> |
| 파일 관리자 열기(Thunar) | <Kbd linux="Super+E" /> |
| 포커스된 창 종료 | <Kbd linux="Super+Q" /> |

### 작업공간 탐색

| 설명 | 키 |
|-------------|-----|
| 작업공간으로 이동(1-9) | <Kbd linux="Super+1" />부터 <Kbd linux="Super+9" />까지 |

### 창 탐색

| 설명 | 키 |
|-------------|-----|
| 포커스를 왼쪽으로 이동 | <Kbd linux="Super+H" /> |
| 포커스를 오른쪽으로 이동 | <Kbd linux="Super+L" /> |
| 포커스를 아래로 이동 | <Kbd linux="Super+J" /> |
| 포커스를 위로 이동 | <Kbd linux="Super+K" /> |
| 열 사이에서 창을 이동하거나 스택에서 위/아래로 이동 | <Kbd linux="Super+Space" /> |

## FAQ

### 볼륨 위젯에 오류가 표시되거나 0%에서 멈춰 있는 이유는 무엇인가요?

* 이는 Qtile 볼륨 위젯이 기본 출력 장치를 감지하지 못해서 발생하는 경우가 있습니다. 자세한 정보는 [위키를 참고](https://docs.qtile.org/en/latest/manual/ref/widgets.html#pulsevolume)할 수 있습니다.

### autostart.sh 스크립트가 있나요?

* 네, Qtile 폴더의 `scripts/` 안에 있습니다.

### Qtile의 바는 마우스와 상호작용하나요?

* 네. 예를 들어 작업공간을 나타내는 작은 점들(활성, 비활성, 비어 있음 등) 위에서 스크롤하면 왼쪽 또는 오른쪽 작업공간으로 전환할 수 있고, 그중 하나를 클릭할 수도 있습니다.
* 또 다른 예로 레이아웃(기본값은 columns)을 클릭하면 사용 가능한 레이아웃 사이를 전환할 수 있습니다.
* CPU 및 RAM 사용량을 클릭하면 Btop(TUI 시스템 모니터)이 열립니다.
* 볼륨 위젯과 상호작용하여 볼륨을 높이거나 낮추거나 음소거할 수 있습니다.

Qtile에 대한 자세한 정보는 [Qtile 위키를 확인](https://docs.qtile.org/en/stable/)하세요.
