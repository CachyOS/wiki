## 누락된 X11 세션 설치 방법

KDE가 개발 구성을 여러 패키지로 분리하기로 결정한 이후, X11 세션은 기본 설치에서 제거되었습니다.

```sh
sudo pacman -S plasma-x11-session kwin-x11
```
설치가 완료되면 로그인 화면에서 X11이 선택 옵션으로 표시됩니다.

## 누락된 xorg-server 설치 방법
CachyOS 설치 프로그램 26.01 버전부터는 `xorg-server`가 더 이상 기본으로 설치되지 않으며, `plasma-x11-session`과 `kwin-x11` 모두 `xorg-server`를 의존성으로 포함하지 않습니다. 따라서 Xorg 서버 및 관련 구성 요소를 수동으로 설치하지 않으면 로그인 시 검은 화면이 나타납니다.

```sh
sudo pacman -S xorg-server
```

## FAQ

### KDE 스크린샷에 표시된 "Emerald"와 같은 외형을 사용하려면 어떻게 해야 하나요?

- 기본적으로 설치되지 않는 Emerald 테마 + Qogir 아이콘 테마의 조합입니다.
  - ```sh title='다음 명령으로 둘 다 설치'
    sudo pacman -S cachyos-emerald-kde-theme-git qogir-icon-theme
    ```
  `Appearance & Style - Colors & Themes`에서 둘 다 적용하세요.
