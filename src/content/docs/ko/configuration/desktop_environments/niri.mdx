:::note
Niri는 열 기반 레이아웃 시스템으로 창 관리를 독특하게 처리하는 스크롤 가능한 타일링 Wayland 컴포지터입니다.
:::

저희 설정의 주된 목표는 구성을 단순하고 접근하기 쉽게 유지하면서도, 부드럽고 직관적인 데스크톱 경험을 제공하는 실사용 가능한 Niri 구성을 제공하는 것입니다.

자세한 내용은 [Niri FAQ.](/configuration/desktop_environments/niri#faq)를 참고하세요.

## 단축키

대부분의 키 조합은 mod 키를 사용해야 하며, 이 설정에서는 Windows 키(SUPER로 표기)를 사용합니다. 이 값은 설정 파일에서 변경할 수 있습니다.

### 애플리케이션 제어

| 설명 | 키 |
|-------------|-----|
| 터미널 열기 | <Kbd linux="Super+Return" /> |
| 프로그램 실행기 열기 | <Kbd linux="Super+Ctrl+Return" /> |
| 브라우저 열기(Firefox) | <Kbd linux="Super+B" /> |
| 파일 관리자 열기 | <Kbd linux="Super+E" /> |
| 포커스된 창 닫기 | <Kbd linux="Super+Q" /> |
| 화면 잠금 | <Kbd linux="Super+Alt+L" /> |

### 작업 공간 탐색

| 설명 | 키 |
|-------------|-----|
| 작업 공간으로 이동(1-9) | <Kbd linux="Super+1" />부터 <Kbd linux="Super+9" />까지 |
| 이전 작업 공간 | <Kbd linux="Super+Tab" /> |
| 스크롤 휠로 작업 공간 간 이동 | <Kbd linux="Super+Scroll" /> |

## FAQ

### Niri는 다른 창 관리자와 무엇이 다른가요?

Niri는 창을 가로로 스크롤할 수 있는 열에 배치하는 독특한 스크롤 가능 타일링 방식을 사용합니다. 이는 무한 데스크톱에 가까운 사용 방식을 제공하며, 특히 울트라와이드 모니터와 여러 애플리케이션을 많이 열어 두는 작업 흐름에 유용합니다.

### 키보드 레이아웃은 어떻게 변경하나요?

설정 파일의 input 섹션을 편집하세요.

```txt title='Example'
input {
    keyboard {
        xkb {
            layout "us" // Change from "de" to your preferred layout
        }
    }
}
```

### 간격과 창 모양을 사용자 지정할 수 있나요?

예, layout 섹션을 수정할 수 있습니다.

```txt title='Example'
layout {
    gaps 8 // Change gap size

    focus-ring {
        width 2
        active-color "#your-color"
        inactive-color "#your-color"
    }
}
```

### 시작 애플리케이션을 더 추가하려면 어떻게 하나요?

startup 섹션에 추가하세요.

```txt title='Example'
spawn-at-startup "your-application"
```

### 긴급 탈출 키는 무엇에 사용하나요?

`Super+Escape` 바인딩은 전체 화면 애플리케이션이 단축키를 막았을 때 제어를 복구하도록 설계되었습니다. 이 키는 활성화된 키보드 단축키 억제 기능을 비활성화합니다.

### 여러 모니터는 어떻게 설정하나요?

사용 중인 디스플레이에 맞게 output 섹션의 주석을 해제하고 수정하세요. 올바른 이름을 확인하려면 `niri msg outputs`를 실행하세요.

```txt title='Example'
output "DP-1" {
    mode "1920x1080@60.000"
    scale 1
}
```
