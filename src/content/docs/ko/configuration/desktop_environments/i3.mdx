## 키 바인딩

대부분의 키 조합은 mod 키를 사용해야 합니다. 이 설정에서는 Windows 키를 사용하며 SUPER로 표기합니다. 설정 파일에서 변경할 수 있습니다.

### 애플리케이션 제어

| 설명 | 키 |
|-------------|-----|
| 터미널 열기 | <Kbd linux="Super+Return" /> |
| Rofi 열기(프로그램 실행기) | <Kbd linux="Control+Space" /> |
| 포커스된 창 종료 | <Kbd linux="Super+Q" /> |

### 작업 공간 이동

| 설명 | 키 |
|-------------|-----|
| 작업 공간(1-9)으로 이동 | <Kbd linux="Super+1" />부터 <Kbd linux="Super+9" />까지 |

| 포커스를 위로 변경 | <Kbd linux="Super+ArrowUp" /> |

## FAQ

### 프로그램 자동 시작은 어떻게 만들 수 있나요? 예: “시작 시 배경화면 설정”

* i3에는 어떤 프로그램이나 명령도 실행할 수 있는 유연한 자동 시작 기능이 이미 포함되어 있습니다

설정 파일의 끝부분을 보면 exec 및 exec_always로 시작하는 몇 줄을 볼 수 있습니다.

예:

```exec chromium```

이것은 i3 세션에 로그인할 때마다 Chromium이 작업 공간 1에서 시작된다는 뜻입니다.

### exec와 exec_always의 차이는 무엇인가요?

exec_always는 i3wm이 다시 로드된 뒤에도 특정 동작을 항상 실행할 수 있게 해줍니다.

* 더 자세한 참고 자료와 정보는 i3 사용자 가이드를 확인하세요
* https://i3wm.org/docs/userguide.html#exec

### 멀티미디어 키가 작동하나요?

* 예, 작동합니다.

i3wm에 대한 자세한 정보는 관련 Wiki를 참고하세요.

* https://i3wm.org/docs/userguide.html
