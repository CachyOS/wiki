description: CachyOS를 위한 하드웨어 감지 및 구성
---

[CachyOS Hardware Detection](https://github.com/CachyOS/chwd/)(보통 `chwd`로 더 잘 알려져 있음)는 실행 중인 시스템에 필요한 패키지와 드라이버를 설치하여 다양한 하드웨어를 사용할 수 있게 해줍니다. 여기에는 NVIDIA 그래픽 카드를 사용하는 시스템, T2 MacBook, Steam Deck 및 ROG Ally 같은 휴대용 장치가 포함됩니다.

## 사용법

`chwd`는 일반적으로 설치 중에 실행되어 시스템에 필요한 패키지를 제공합니다. 하지만 설치 후에도 사용할 수 있습니다.

### 자동 구성

`chwd`는 시스템이 최적의 조건에서 작동할 수 있도록 필요한 드라이버와 패키지의 설치 및 구성을 지원합니다.

```sh
sudo chwd -a
```

### 기타

명령어 문법과 다른 사용법은 `chwd`의 도움말 출력을 참고하세요.

```sh
chwd --help
Usage: chwd [OPTIONS]

Options:
  -i, --install <profile>          Install profile
  -r, --remove <profile>           Remove profile
  -d, --detail                     Show detailed info for listings
  -f, --force                      Force reinstall
      --list-installed             List installed kernels
      --list                       List available profiles for all devices
      --list-all                   List all profiles
  -a, --autoconfigure [<classid>]  Autoconfigure
      --ai_sdk                     Toggle AI SDK profiles
      --pmcachedir <PMCACHEDIR>    [default: /var/cache/pacman/pkg]
      --pmconfig <PMCONFIG>        [default: /etc/pacman.conf]
      --pmroot <PMROOT>            [default: /]
  -h, --help                       Print help
  -V, --version                    Print version
```
