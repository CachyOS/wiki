:::note[이 가이드는 기존 CachyOS 설치 환경에서 GPU를 교체하는 경우(NVIDIA ↔ AMD)에 적용됩니다.]
:::

## 사전 요구 사항
  - 교체할 GPU가 올바르게 설치되고 연결되어 있어야 합니다.
  - 시스템이 완전히 최신 상태인지 확인합니다.
    ```bash
    sudo pacman -Syu
    ```

### 마이그레이션 단계

<Tabs>
    <TabItem label='NVIDIA에서 AMD로'>
        AMD 드라이버는 Linux 커널에 포함되어 있지만, 기존 NVIDIA 설정을 정리하고 필요한 AMD 패키지가 설치되어 있는지 확인해야 할 수 있습니다.
        <Steps>
            1. 현재 설치된 NVIDIA 드라이버 프로필을 확인합니다.
                ```bash
                sudo chwd --list-installed
                ```
            2. `-r` 플래그를 사용하여 해당 프로필을 제거합니다.
                ```bash
                sudo chwd -r <profile-name>
                ```
            3. 시스템을 종료한 뒤 AMD GPU를 설치합니다.
            4. 부팅 후 chwd를 사용하여 GPU를 자동으로 감지하고 올바른 AMD 패키지를 설치합니다.
                ```bash
                sudo chwd -a
                ```
            5. 새 드라이버를 설치한 후 initramfs와 부트로더 구성을 업데이트합니다.
                > CachyOS에는 드라이버가 추가되거나 제거될 때 initramfs를 자동으로 다시 빌드하는 pacman hook이 포함되어 있습니다.
                > 이를 통해 부팅 시 올바른 드라이버가 로드됩니다.
                - GRUB: `sudo grub-mkconfig -o /boot/grub/grub.cfg`
                - systemd-boot: `sudo sdboot-manage gen`
                - Limine: `sudo limine-mkinitcpio`
            6. 변경 사항을 적용하려면 재부팅합니다.
                ```bash
                sudo reboot
                ```
            7. 재부팅 후 AMD 드라이버가 활성화되었는지 확인합니다.
                ```bash
                vulkaninfo | grep "deviceName"
                ```
                또는
                ```bash
                glxinfo | grep "OpenGL renderer"
                ```
                AMD GPU가 목록에 표시되면 드라이버가 올바르게 작동하는 것입니다.
        </Steps>
    </TabItem>
    <TabItem label='AMD에서 NVIDIA로'>
        <Steps>
            1. 남아 있는 AMD 패키지를 정리합니다.
                ```bash
                sudo chwd -r amd
                ```
            2. 시스템을 종료한 뒤 NVIDIA GPU를 설치합니다.
            3. 부팅 후 chwd를 사용하여 GPU를 자동으로 감지하고 올바른 NVIDIA 패키지를 설치합니다.
                ```bash
                sudo chwd -a
                ```
            4. 새 드라이버를 설치한 후 initramfs와 부트로더 구성을 업데이트합니다.
                > CachyOS에는 드라이버가 추가되거나 제거될 때 initramfs를 자동으로 다시 빌드하는 pacman hook이 포함되어 있습니다.
                > 이를 통해 부팅 시 올바른 드라이버가 로드됩니다.
                - GRUB: `sudo grub-mkconfig -o /boot/grub/grub.cfg`
                - systemd-boot: `sudo sdboot-manage gen`
                - Limine: `sudo limine-mkinitcpio`
            5. 변경 사항을 적용하려면 재부팅합니다.
                ```bash
                sudo reboot
                ```
            6. 재부팅 후 NVIDIA 드라이버가 활성화되었는지 확인합니다.
                ```bash
                nvidia-smi
                ```
                또는
                ```bash

                ```
                NVIDIA GPU가 목록에 표시되면 드라이버가 올바르게 작동하는 것입니다.
        </Steps>
    </TabItem>
</Tabs>
