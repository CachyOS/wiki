## Mengunduh ISO

ISO CachyOS dapat diperoleh dari sumber-sumber berikut:

*   [Situs Web](<https://cachyos.org/download>)
*   [SourceForge](<https://sourceforge.net/projects/cachyos-arch/files/>)
*   [CachyOS Mirror](<https://mirror.cachyos.org/ISO/>)

## Memverifikasi integritas ISO dengan SHA256

:::caution[PERINGATAN]
Selalu luangkan waktu sejenak untuk memverifikasi integritas ISO agar terhindar dari masalah yang tidak diinginkan saat instalasi atau saat membuat media bootable.
:::

**Versi ISO Saat Ini:** `250824`

**Hash SHA256:** `0a10af47b009ef459c1ee5f8731f97a3f62c1969df41c1670d53576ccadd0eb6`

<Tabs>

<TabItem label='Windows'>

<Steps>

1. Unduh [berkas](https://mirror.cachyos.org/ISO/desktop/250824/cachyos-desktop-linux-250824.iso.sha256) yang berisi hash SHA256 **(Buka dengan Editor Teks, misal: Notepad).**
2. Buka CMD atau PowerShell sebagai Administrator dan [arahkan](<https://www.wikihow.com/Change-Directories-in-Command-Prompt>) ke path tempat berkas ISO dan SHA256 disimpan.
3. Jalankan perintah berikut:
   ```powershell
   # Contoh:
   certUtil -hashfile cachyos-desktop-linux-250824.iso SHA256
   ```
4. Bandingkan keluaran hash dari certUtil dengan yang ada di berkas yang diunduh pada **Langkah 1.** Jika cocok, Anda dapat melanjutkan instalasi CachyOS.

</Steps>

</TabItem>

<TabItem label='Linux'>

<Steps>

1. Unduh [berkas](https://mirror.cachyos.org/ISO/desktop/250824/cachyos-desktop-linux-250824.iso.sha256) yang berisi hash SHA256.
2. Buka terminal dan arahkan ke direktori yang berisi berkas `.sha256`, lalu jalankan perintah berikut:
   ```sh
   # Contoh:
   cd Downloads/
   cat cachyos-desktop-linux-250824.iso.sha256
   # 0a10af47b009ef459c1ee5f8731f97a3f62c1969df41c1670d53576ccadd0eb6
   ```
3. Bandingkan keluaran dari **Langkah 2** dan jalankan perintah berikut untuk memeriksa hash saat ini pada berkas ISO.
   ```sh
   # Contoh:
   sha256sum cachyos-desktop-linux-250824.iso
   ```
4. Jika hash dari **Langkah 2** dan **Langkah 3** cocok, Anda dapat melanjutkan instalasi CachyOS.

</Steps>

</TabItem>

<TabItem label='macOS'>

<Steps>

1. Unduh [berkas](https://mirror.cachyos.org/ISO/desktop/250824/cachyos-desktop-linux-250824.iso.sha256) yang berisi hash SHA256.
2. Buka terminal dan arahkan ke direktori yang berisi berkas `.sha256`, lalu jalankan perintah berikut:
   ```sh
   # Contoh:
   cd Downloads/
   cat cachyos-desktop-linux-250824.iso.sha256
   # 0a10af47b009ef459c1ee5f8731f97a3f62c1969df41c1670d53576ccadd0eb6
   ```
3. Bandingkan keluaran dari **Langkah 2** dan jalankan perintah berikut untuk memeriksa hash saat ini pada berkas ISO.
   ```sh
   # Contoh:
   shasum -a 256 cachyos-desktop-linux-250824.iso
   ```
4. Jika hash dari **Langkah 2** dan **Langkah 3** cocok, Anda dapat melanjutkan instalasi CachyOS.

</Steps>

</TabItem>

</Tabs>

## Verifikasi Keaslian Image ISO (Linux)

Untuk memverifikasi keaslian berkas ISO dan memastikan bahwa berkas tersebut benar-benar dirilis oleh tim pengembang resmi CachyOS:

<Steps>

1. Impor kunci GPG untuk memverifikasi keaslian:

   ```shell
   gpg --keyserver hkps://keys.openpgp.org --recv-key F3B607488DB35A47
   ```

2. Unduh berkas ISO beserta berkas signature `.sig`-nya, lalu jalankan perintah berikut (dengan mengganti `nama_lengkap_iso.iso` dengan nama berkas ISO yang sebenarnya):
   ```shell
   gpg --verify nama_lengkap_iso.iso.sig nama_lengkap_iso.iso
   ```

   Jika Anda mendapatkan keluaran **Good signature** (tanda tangan baik), berarti berkas ISO tersebut asli:
   ```
   gpg: Signature made dom 24 ago 2025 06:26:23 -03
   gpg:                using RSA key 882DCFE48E2051D48E2562ABF3B607488DB35A47
   gpg: Good signature from "CachyOS <admin@cachyos.org>" [unknown]
   gpg: WARNING: This key is not certified with a trusted signature!
   gpg:          There is no indication that the signature belongs to the owner.
   Primary key fingerprint: 882D CFE4 8E20 51D4 8E25  62AB F3B6 0748 8DB3 5A47
   ```

</Steps>

:::danger
Jika keluarannya tidak menampilkan string **Good signature** atau ID kuncinya tidak cocok, jangan gunakan image ISO tersebut dan pastikan image yang diunduh berasal
dari sumber CachyOS yang sah. Tanda tangan yang buruk dapat mengindikasikan bahwa image yang diunduh telah diubah.
:::
