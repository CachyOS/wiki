O [CachyOS Hardware Detection](https://github.com/CachyOS/chwd/) (mais conhecido como `chwd`) permite-nos dar suporte a uma variedade de hardware, instalando os pacotes e controladores (drivers) necessários para o sistema em execução. Isto inclui sistemas com placas gráficas NVIDIA, Macbooks T2 e dispositivos portáteis (handhelds), como o Steam Deck e o ROG Ally.

## Utilização

O `chwd` é normalmente executado durante o tempo de instalação para fornecer os pacotes necessários ao sistema. No entanto, também é possível utilizá-lo após a instalação.

### Configuração Automática

O `chwd` suporta a instalação e configuração dos controladores e pacotes necessários para que o sistema possa funcionar em condições ideais.

```sh
sudo chwd -a
```

### Outros

Consulte a saída de ajuda do `chwd` para obter informações sobre a sintaxe dos comandos e outras utilizações.

```sh
chwd --help
Utilização: chwd [OPÇÕES]

Opções:
  -i, --install <perfil>           Instalar perfil
  -r, --remove <perfil>            Remover perfil
  -d, --detail                     Mostrar informações detalhadas nas listagens
  -f, --force                      Forçar reinstalação
      --list-installed             Listar kernels instalados
      --list                       Listar perfis disponíveis para todos os dispositivos
      --list-all                   Listar todos os perfis
  -a, --autoconfigure [<classid>]  Configuração automática
      --ai_sdk                     Alternar perfis de SDK de IA
      --pmcachedir <PMCACHEDIR>    [predefinição: /var/cache/pacman/pkg]
      --pmconfig <PMCONFIG>        [predefinição: /etc/pacman.conf]
      --pmroot <PMROOT>            [predefinição: /]
  -h, --help                       Imprimir ajuda
  -V, --version                    Imprimir versão
```
