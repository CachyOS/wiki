## Antes de começar

:::note
Se apenas visualizar o GRUB e o Limine como opções de gestor de arranque após premir **Launch Installer**, significa que o sistema foi iniciado em modo Legacy/BIOS.
:::

:::note[Não é permitida a instalação de múltiplos ambientes de desktop durante o processo de instalação.]
:::

:::caution[O Secure Boot e o CSM devem estar desativados nas definições da BIOS/UEFI ao instalar em modo UEFI.]
Para configurar o Secure Boot após a instalação, consulte a secção [Secure Boot](/pt/configuration/secure_boot_setup).

A opção `Legacy USB Support` deve ser definida como `Auto`.
:::

:::caution
As opções `Install alongside` (Instalar ao lado) e `Replace partition` (Substituir partição) não são 100% fiáveis e podem causar a falha da instalação.

O `Manual partitioning` (Particionamento manual) é **fortemente preferido** ao instalar o CachyOS.
:::

:::tip
É altamente recomendável reiniciar no ISO após uma tentativa de instalação falhada.

Caso contrário, podem ocorrer erros contínuos durante o processo de instalação.

Isto acontece porque o instalador não desmonta corretamente as partições numa instalação falhada.
:::

## Métodos de Instalação

### Particionamento Manual

:::note[Antes de prosseguir com o particionamento do disco para uma instalação UEFI.]
    ```sh title='Execute este comando no terminal'
    efibootmgr -v
    ```
Se a mensagem de saída for `EFI variables are not supported on this system.`, então o sistema foi iniciado em modo Legacy/BIOS e deve garantir que o modo UEFI está configurado nas definições da BIOS/UEFI. Consulte a secção de [Requisitos](/pt/installation/installation_on_root/#antes-de-começar).
:::

## Dual Boot entre Windows e CachyOS

:::note[Este guia assume que o Windows já está instalado no sistema e que decidiu instalar o CachyOS ao lado dele, partilhando o mesmo disco.]
:::

:::caution
O Dual Boot entre Windows e Linux não é 100% fiável. As atualizações do Windows podem quebrar o carregador de arranque ao substituir a partição EFI.
Em alguns casos, os problemas podem nunca ocorrer, mas para alguns utilizadores pode ser um problema recorrente.

Uma forma de evitar este problema é instalar cada sistema operativo num disco separado.
:::

:::caution
A partição EFI pode precisar de ser redimensionada, dependendo do tamanho mínimo recomendado para o gestor de arranque de destino. Consulte [Particionamento Manual](/pt/installation/installation_on_root#particionamento-manual).

Sistemas de ficheiros FAT não podem ser redimensionados "in-place" (no local). Para redimensionar corretamente a partição EFI em FAT, deve-se fazer uma cópia de segurança do sistema de ficheiros EFI existente, usar uma ferramenta como o `gparted` para redimensionar a partição existente e reformatar a nova partição, e depois copiar a estrutura de ficheiros anterior de volta para a partição EFI.
:::

### Pré-requisitos

- O Início Rápido (Fast Startup) e a Hibernação do Windows devem estar desativados.
  - Abra o Windows PowerShell como administrador e execute o seguinte comando:
      ```ps
      powercfg /H off
      ```
      Reinicie o sistema para garantir que as alterações surtam efeito.
- O Windows BitLocker deve estar desativado.
  - Verificar se o BitLocker está ativado:
    ```ps title='Abra a Linha de Comandos (Command Prompt) como administrador e execute o seguinte comando'
    manage-bde -status
    ```
  Se o **Encryption Method** (Método de Encriptação) aparecer como `None`, então o BitLocker está desativado.
- O Secure Boot deve estar desativado.
- Uma partição vazia de ≥30 GB.
  - Guia sobre como reduzir uma partição do Windows:
    - Prima `Win + R`, escreva `diskmgmt.msc` e prima Enter para abrir a Gestão de Discos.
    - Identifique a sua partição principal do Windows (geralmente C:) e clique nela com o botão direito.
    - Clique em `Shrink Volume...` (Reduzir Volume...), especifique pelo menos **30720 MB** (30 GiB) e clique em `Shrink` (Reduzir).
- Um USB de arranque com o CachyOS.
  - Consulte a secção [Criar uma Unidade USB de Arranque do CachyOS](/pt/installation/installation_prepare#creating-a-bootable-cachyos-usb-drive).

<Tabs>
    <TabItem label='Limine'>
        O Limine deverá detetar automaticamente a partição EFI do Windows e adicioná-la ao menu de arranque. Se o Windows não aparecer no menu de arranque, execute o seguinte comando:
        ```bash
        sudo limine-scan
        ```
    </TabItem>
    <TabItem label='systemd-boot'>
        **Precisamos de copiar os binários EFI do Windows para a partição EFI do Linux para que o gestor de arranque os possa reconhecer.**

        <Steps>
        1. Localize a **partição EFI do Windows** com o comando `lsblk`.

            ```sh title='Execute este comando no terminal'
            lsblk -o NAME,FSTYPE,SIZE,MOUNTPOINT
            ```
            ```sh title='Exemplo de saída'
                        NAME        FSTYPE   SIZE MOUNTPOINT
            zram0               15.3G [SWAP]
            nvme0n1            476.9G
            ├─nvme0n1p1 vfat     100M
            ├─nvme0n1p2           16M
            ├─nvme0n1p3 ntfs   234.4G
            ├─nvme0n1p4 ntfs     830M
            ├─nvme0n1p5 vfat       2G /boot
            └─nvme0n1p6 btrfs  239.6G /var/tmp
            ```
            As partições EFI são quase sempre formatadas como `FAT32/vfat`. Uma vez que a `nvme0n1p1` não tem um ponto de montagem Linux, podemos assumir que esta partição é a partição EFI do Windows.

        2. Monte temporariamente a partição EFI do Windows.

            ```sh
            sudo mkdir /mnt/WinBoot
            sudo mount /dev/nvme0n1p1 /mnt/WinBoot # Substitua `nvme0n1p1` pelo nome da partição EFI do Windows.
            ```

        3. Copie os binários EFI da **partição EFI do Windows** para a **partição EFI do Linux**.

            ```sh
            sudo cp -r /mnt/WinBoot/EFI/Microsoft/ /boot/EFI
            ```

        4. Desmonte a partição montada anteriormente. O Windows deverá aparecer no menu de arranque no próximo reinício.

            ```sh
            sudo umount /mnt/WinBoot
            sudo rm -r /mnt/WinBoot
            ```

        </Steps>
    </TabItem>

    <TabItem label='GRUB (Apenas para instalações mais antigas)'>
        :::tip[O CachyOS ativa o os-prober por predefinição.]
        :::
        **O GRUB utiliza o os-prober para detetar automaticamente a partição EFI do Windows e adicioná-la ao menu de arranque.**

        <Steps>
        1. Instale o **os-prober**.

            ```sh
            sudo pacman -S os-prober
            ```

        2. Ative o **os-prober** no ficheiro de configuração do GRUB.

            ```sh title='Prima CTRL+S para guardar e CTRL+Q para sair do Micro'
            sudo micro /etc/default/grub
            # /etc/default/grub
            # Probing for other operating systems is disabled for security reasons. Read
            # documentation on GRUB_DISABLE_OS_PROBER, if still want to enable this
            # functionality install os-prober and uncomment to detect and include other
            # operating systems.
            GRUB_DISABLE_OS_PROBER=false

            ```

        3. Atualize o grub.cfg, agora utilizando o **os-prober**.
            ```sh
            sudo grub-mkconfig -o /boot/grub/grub.cfg
            ```

            **O Windows deverá agora estar adicionado ao menu de arranque.**

        </Steps>
    </TabItem>
</Tabs>
