## Requisitos do Sistema

Antes de preparar a instalação, certifique-se de que o computador utilizado cumpre os requisitos mínimos de sistema para correr o CachyOS. O instalador utiliza um processo de instalação online, pelo que uma ligação à internet estável e relativamente rápida é obrigatória.

:::note[Máquinas Virtuais]
Não é recomendado instalar o CachyOS numa máquina virtual. As VMs podem ter problemas com configurações incorretas ou podem falhar totalmente. Recomenda-se a instalação do CachyOS em "bare metal" (diretamente no hardware).
:::

<Tabs>

<TabItem label="Requisitos mínimos">

* 3 GB de RAM
* 30 GB de Espaço de Armazenamento (HDD/SSD)
* Ligação à internet estável

:::caution
Uma internet instável pode resultar em tempos de instalação prolongados ou, no pior dos casos, falhas na instalação.
:::

</TabItem>

<TabItem label="Requisitos recomendados">

* 8GB de RAM
* 50 GB de Espaço de Armazenamento (SSD/NVMe)
* [CPU compatível com x86-64-v3](/installation/installation_prepare#x86_64-microarchitecture-level-support)
* Velocidade de internet de 50 Mbps ou superior
* GPU NVIDIA (900+ - ex: GTX 950), AMD +GCN 1.0 (ex: AMD R7 240) ou Intel (séries Integrated HD Graphics ou superior. Série Arc)

</TabItem>

</Tabs>

## Criar uma Unidade USB de Arranque do CachyOS

Existem várias ferramentas e métodos que podem ser utilizados para criar uma unidade USB de arranque do CachyOS.

:::tip
Mantenha uma cópia do ISO do CachyOS na mesma unidade ou noutro local, para que a possa utilizar mais tarde para resolução de problemas através de chroot.
:::

:::note
A unidade USB deve ter, pelo menos, 8GB de espaço disponível.
:::

### balenaEtcher

<Steps>

1. Transfira o [balenaEtcher](https://etcher.balena.io/). O balenaEtcher suporta a gravação de imagens em Linux, MacOS e Windows.
   Se tiver descarregado um ficheiro `.zip`, extraia-o e execute o binário utilizando os seguintes comandos:
      ```sh
      # Extrair o ficheiro zip:
      bsdtar xvf <nome do ficheiro zip>
      # Entrar na nova pasta:
      cd balenaEtcher-linux-x64/
      # Executar o balenaEtcher:
      ./balena-etcher
      ```
2. Ligue uma unidade USB ao computador.
3. Selecione `Flash from file` e escolha o ficheiro de imagem ISO do CachyOS.
4. Clique em `Select target` e escolha a unidade USB que ligou anteriormente.
5. Prima `Flash` para iniciar o processo de gravação.

</Steps>

:::note
O balenaEtcher poderá solicitar privilégios de administrador. Se for o caso, introduza a sua palavra-passe e clique em `Authenticate`.
:::

### Interface de Linha de Comando (Linux & MacOS)

<Steps>

1. Ligue uma unidade USB.
2. Detete a unidade USB ligada utilizando os seguintes comandos:
   ```sh
   # Linux
   # A unidade USB pode ser identificada, por exemplo: /dev/sda, através do modelo do disco e do tamanho.
   sudo fdisk -l

   # MacOS
   # As unidades USB são identificadas como "/dev/diskY" onde "Y" pode ser 0, 1, etc.
   diskutil list
   ```
3. Copie o conteúdo do ISO para a unidade USB ligada, executando:
   ```sh
   # Substitua <usbdrive> pela etiqueta da unidade.
   sudo dd bs=4M if=nome_completo_do_iso.iso of=/dev/<usbdrive> status=progress oflag=sync
   ```
</Steps>

- O `dd` irá agora copiar o conteúdo do ficheiro ISO para a unidade USB ligada.

### Rufus (Apenas Windows)

<Steps>

1. Ligue uma unidade USB.
2. Transfira o [Rufus](https://rufus.ie/) e instale-o, ou execute a versão portátil.
3. Em `Device` (Dispositivo), clique na lista suspensa e selecione a unidade USB ligada.
4. Em `Boot selection` (Seleção de arranque), clique em `SELECT` (SELECIONAR) e localize o ficheiro de imagem ISO do CachyOS.
5. Clique em `START` (INICIAR).

</Steps>

### Ventoy (Linux & Windows)

<Tabs>

<TabItem label="Linux">

<Steps>

1. Ligue uma unidade USB.
2. Transfira o [Ventoy](https://www.ventoy.net/en/download.html)
3. Extraia (untar) o Ventoy utilizando o seguinte comando:
   ```sh
   # Substitua a versão pela correta, ex: ventoy-1.1.07-linux.tar.gz
   bsdtar xvf ventoy-version-linux.tar.gz
   # Entre na nova pasta: (a versão pode mudar)
   cd ventoy-1.1.07/
   ```
4. Execute o `VentoyGUI.x86_64` clicando duas vezes no ficheiro ou através do terminal:
   ```sh
   # Serão solicitados privilégios de administrador, introduza as suas credenciais
   ./VentoyGUI.x86_64
   ```
5. Selecione a unidade USB ligada clicando em `Device` (Dispositivo).
6. Clique em `Install` (Instalar).
7. Assim que terminar a instalação do Ventoy na unidade USB, feche a janela e coloque o ficheiro ISO do CachyOS na nova partição utilizável da unidade.

</Steps>

</TabItem>

<TabItem label="Windows">

<Steps>
1. Ligue uma unidade USB.
2. Transfira o [Ventoy](https://www.ventoy.net/en/download.html)
3. Execute o `Ventoy2Disk.exe`
4. Selecione a unidade USB ligada clicando em `Device` (Dispositivo).
5. Clique em `Install` (Instalar).
6. Assim que terminar a instalação do Ventoy na unidade USB, feche a janela e coloque o ficheiro ISO do CachyOS na nova partição utilizável da unidade.
</Steps>

</TabItem>
