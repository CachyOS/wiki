## Como instalar a sessão X11 em falta

Após o KDE ter decidido dividir o seu desenvolvimento em múltiplos pacotes, a sessão X11 foi removida da instalação predefinida.

```sh
sudo pacman -S plasma-x11-session kwin-x11
```

Após a conclusão, o X11 será listado como opção no ecrã de início de sessão. 

## Como instalar o xorg-server em falta

A partir da versão 26.01 do instalador do CachyOS, o xorg-server já não é instalado e nem o plasma-x11-session nem o kwin-x11 tratam o xorg-server como dependência.  Como resultado, a falha na instalação manual do servidor Xorg e dos componentes associados resultará num ecrã preto durante o início de sessão.  

```sh
sudo pacman -S xorg-server
```

## FAQ

### Como posso obter o mesmo aspeto mostrado nas capturas de ecrã do KDE, denominado "Emerald"?

- É uma combinação do Tema Emerald + Tema de Ícones Qogir, que não estão instalados por predefinição.
  - ```sh title='Instale ambos com o seguinte comando:'
    sudo pacman -S cachyos-emerald-kde-theme-git qogir-icon-theme
    ```
  Aplique ambos em `Aspeto e Estilo - Cores e Temas`
