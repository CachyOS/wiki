## Εγκατάσταση της συνεδρίας X11

Μετά την απόφαση της ομάδας KDE να χωρίσει την ανάπτυξη σε πολλαπλά πακέτα, η συνεδρία X11 καταργήθηκε από την προεπιλεγμένη εγκατάσταση.

```sh
sudo pacman -S plasma-x11-session kwin-x11
```
Μετά την ολοκλήρωση, το X11 εμφανίζεται ως επιλογή στην οθόνη σύνδεσης.

## Εγκατάσταση του xorg-server που λείπει

Από την έκδοση 26.01 του προγράμματος εγκατάστασης του CachyOS, το xorg-server δεν εγκαθίσταται πλέον και ούτε το plasma-x11-session ούτε το kwin-x11 το περιλαμβάνουν ως εξάρτηση. Κατά συνέπεια, αν δεν εγκαταστήσετε χειροκίνητα τον διακομιστή Xorg και τα σχετικά στοιχεία, θα εμφανίζεται μαύρη οθόνη κατά τη σύνδεση.

```sh
sudo pacman -S xorg-server
```

## Συχνές ερωτήσεις

### Πώς μπορώ να έχω την ίδια εμφάνιση με αυτή που απεικονίζεται στα στιγμιότυπα οθόνης του KDE και έχει την ονομασία «Emerald»;

- Είναι ένας συνδυασμός του θέματος Emerald και του θέματος εικονιδίων Qogir, τα οποία δεν είναι εγκατεστημένα εξαρχής.
  - ```sh title='Εγκαταστήστε και τα δύο με την εξής εντολή'
    sudo pacman -S cachyos-emerald-kde-theme-git qogir-icon-theme
    ```
  Εφαρμόστε και τα δύο στην ενότητα `Εμφάνιση και στυλ -> Χρώματα και θέματα`.

### Η οθόνη σύνδεσης του KDE δεν αντικατοπτρίζει την εμφάνιση της επιφάνειας εργασίας μου. Μπορώ να το διορθώσω;

:::
