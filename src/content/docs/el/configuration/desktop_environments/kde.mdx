## Εγκατάσταση της συνεδρίας X11

Μετά την απόφαση της ομάδας KDE να χωρίσει την ανάπτυξη σε πολλαπλά πακέτα, η συνεδρία X11 καταργήθηκε απο την προεπιλεγμένη εγκατάσταση.

```sh
sudo pacman -S plasma-x11-session kwin-x11
```

## Συχνές ερωτήσεις

### Πώς μπορώ να έχω την ίδια εμφάνιση με αυτή που απεικονίζεται στα στιγμιότυπα οθόνης του KDE και έχει την ονομασία «Emerald»;

- Είναι ένας συνδυασμός του θέματος Emerald και του θέματος εικονιδίων Qogir, τα οποία δεν είναι εγκατεστημένα εξαρχής.
  - ```sh title='Εγκαταστήστε και τα δύο με την εξής εντολή'
    sudo pacman -S cachyos-emerald-kde-theme-git qogir-icon-theme
    ```
  Εφαρμόστε και τα δύο στην ενότητα `Εμφάνιση και στυλ -> Χρώματα και θέματα`.
