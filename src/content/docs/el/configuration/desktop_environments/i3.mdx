## Συνδυασμοί πλήκτρων

Οι περισσότεροι συνδυασμοί πλήκτρων απαιτούν τη χρήση του πλήκτρου mod, το οποίο είναι το πλήκτρο Windows (αναφέρεται ως SUPER) στην περίπτωσή μας. Μπορείτε να αλλάξετε αυτό το πλήκτρο στο αρχείο διαμόρφωσης.

### Έλεγχος εφαρμογών

| Περιγραφή | Πλήκτρα |
|-------------|-----|
| Άνοιγμα τερματικού | <Kbd linux="Super+Return" /> |
| Άνοιγμα μενού εκκίνησης προγραμμάτων (Rofi) | <Kbd linux="Control+Space" /> |
| Τερματισμός εστιασμένου παραθύρου | <Kbd linux="Super+Q" /> |

### Πλοήγηση στους χώρους εργασίας

| Περιγραφή | Πλήκτρα |
|-------------|-----|
| Μετάβαση σε χώρο εργασίας (1-9) | <Kbd linux="Super+1" /> έως <Kbd linux="Super+9" /> |

### Πλοήγηση στα παράθυρα

| Περιγραφή | Πλήκτρα |
|-------------|-----|
| Μετατόπιση εστίασης στα αριστερά | <Kbd linux="Super+Αριστερό βέλος (←)" /> |
| Μετατόπιση εστίασης στα δεξιά | <Kbd linux="Super+Δεξί βέλος (→)" /> |
| Μετατόπιση εστίασης στο πάνω μέρος | <Kbd linux="Super+Πάνω βέλος (↑)" /> |
| Μετατόπιση εστίασης στο κάτω μέρος | <Kbd linux="Super+Κάτω βέλος (↓)" /> |
| Εστίαση στο τελευταίο αιωρούμενο/παρατεθειμένο πλαίσιο | <Kbd linux="Super+Space" /> |

### Διαχείριση παραθύρων

| Περιγραφή | Πλήκτρα |
|-------------|-----|
| Μετακίνηση εστιασμένου παραθύρου σε χώρο εργασίας (1-9) | <Kbd linux="Super+Shift+1" /> έως <Kbd linux="Super+Shift+9" /> |
| Μετακίνηση εστιασμένου παραθύρου προς τα αριστερά | <Kbd linux="Super+Shift+Αριστερό βέλος (←)" /> |
| Μετακίνηση εστιασμένου παραθύρου προς τα δεξιά | <Kbd linux="Super+Shift+Δεξί βέλος (→)" /> |
| Μετακίνηση εστιασμένου παραθύρου προς τα πάνω | <Kbd linux="Super+Shift+Πάνω βέλος (↑)" /> |
| Μετακίνηση εστιασμένου παραθύρου προς τα κάτω | <Kbd linux="Super+Shift+Κάτω βέλος (↓)" /> |
| Εναλλαγή λειτουργίας πλήρους οθόνης | <Kbd linux="Super+F" /> |
| Εναλλαγή λειτουργίας αιώρησης | <Kbd linux="Super+Shift+Space" /> |

### Έλεγχος διάταξης

| Περιγραφή | Πλήκτρα |
|-------------|-----|
| Οριζόντιος διαχωρισμός διάταξης | <Kbd linux="Super+H" /> |
| Κατακόρυφος διαχωρισμός διάταξης | <Kbd linux="Super+V" /> |
| Εναλλαγή διαχωρισμού | <Kbd linux="Super+T" /> |
| Αλλαγή σε διάταξη στοίβαξης | <Kbd linux="Super+S" /> |
| Αλλαγή σε διάταξη καρτελών | <Kbd linux="Super+W" /> |

### Λειτουργία αλλαγής μεγέθους

| Περιγραφή | Πλήκτρα |
|-------------|-----|
| Είσοδος στη λειτουργία αλλαγής μεγέθους | <Kbd linux="Super+R" /> |
| Αλλαγή μεγέθους στα αριστερά (εντός λειτουργίας αλλαγής μεγέθους) | <Kbd linux="Αριστερό βέλος (←)" /> |
| Αλλαγή μεγέθους στα δεξιά (εντός λειτουργίας αλλαγής μεγέθους) | <Kbd linux="Δεξί βέλος (→)" /> |
| Αλλαγή μεγέθους στο πάνω μέρος (εντός λειτουργίας αλλαγής μεγέθους) | <Kbd linux="Πάνω βέλος (↑)" /> |
| Αλλαγή μεγέθους στο κάτω μέρος (εντός λειτουργίας αλλαγής μεγέθους) | <Kbd linux="Κάτω βέλος (↓)" /> |
| Έξοδος από τη λειτουργία αλλαγής μεγέθους | <Kbd linux="Return" /> / <Kbd linux="Escape" /> / <Kbd linux="Super+R" /> |

### Έλεγχος συστήματος

| Περιγραφή | Πλήκτρα |
|-------------|-----|
| Κλείδωμα οθόνης | <Kbd linux="Super+L" /> |
| Επαναφόρτωση της διαμόρφωσης του i3 | <Kbd linux="Super+Shift+C" /> |
| Επιτόπια επανεκκίνηση του i3 | <Kbd linux="Super+Shift+R" /> |
| Έξοδος από το i3 (τερματισμός συνεδρίας X) | <Kbd linux="Super+Shift+E" /> |

## Συχνές ερωτήσεις

### Πώς μπορώ να ρυθμίσω την αυτόματη εκκίνηση ενός προγράμματος (π.χ. ορισμός ταπετσαρίας κατά την εκκίνηση);

* Το i3 περιλαμβάνει ήδη μια ευέλικτη λειτουργία αυτόματης εκκίνησης που επιτρέπει την εκτέλεση οποιουδήποτε προγράμματος ή ακόμα και εντολών.

Εάν κοιτάξετε στο τέλος του αρχείου διαμόρφωσης, θα δείτε μερικές γραμμές που ξεκινούν με exec και exec_always.

Για παράδειγμα:

```exec chromium```

Αυτό σημαίνει ότι το Chromium θα εκκινείται στον χώρο εργασίας 1 κάθε φορά που θα συνδέεστε στη συνεδρία i3.

### Σε τι διαφέρει το exec από το exec_always;

Το exec_always σάς δίνει τη δυνατότητα να εκτελείτε πάντα μια συγκεκριμένη ενέργεια, ακόμα και μετά από επαναφόρτωση του i3.

* Για περισσότερες πληροφορίες, ρίξτε μια ματιά στον οδηγό χρήσης του i3:
* https://i3wm.org/docs/userguide.html#exec

### Λειτουργούν τα πλήκτρα πολυμέσων;

* Ναι, λειτουργούν.

Για περισσότερες πληροφορίες σχετικά με το i3, ανατρέξτε στο επίσημο wiki του.

* https://i3wm.org/docs/userguide.html
