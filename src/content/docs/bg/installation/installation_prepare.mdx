## Системни изисквания

Преди да подготвите инсталацията, се уверете, че компютърът, който използвате, отговаря на минималните системни изисквания за работа с CachyOS. Инсталаторът използва процес на онлайн инсталация, така че стабилна и сравнително бърза интернет връзка е задължителна.

:::note[Виртуални машини]
Не се препоръчва да инсталирате CachyOS на виртуална машина. Виртуалните машини могат да имат проблеми с неправилна конфигурация или да бъдат напълно неизползваеми. Препоръчително е да инсталирате CachyOS на физически хардуер.
:::

<Tabs>

<TabItem label="Минимални изисквания">

*   3 GB RAM
*   30 GB дисково пространство (HDD/SSD)
*   Стабилна интернет връзка

:::caution
Нестабилният интернет може да доведе до удължено време за инсталация или, в най-лошия случай, до неуспешна инсталация.
:::

</TabItem>

<TabItem label="Препоръчителни изисквания">

*   8 GB RAM
*   50 GB дисково пространство (SSD/NVMe)
*   [Процесор с поддръжка на x86-64-v3](/installation/installation_prepare#x86_64-microarchitecture-level-support)
*   50 Mbps или по-висока скорост на интернет
*   NVIDIA GPU (900+ – напр. GTX 950), AMD +GCN 1.0 (напр. AMD R7 240) или Intel (Intel HD Graphics серия или по-нова, Arc серия)

</TabItem>

</Tabs>

## Създаване на bootable USB устройство с CachyOS

Съществуват няколко инструмента и метода за създаване на bootable USB устройство с CachyOS.

:::tip
Запазете копие на CachyOS ISO на същото устройство или на друго място, за да можете да го използвате по-късно за отстраняване на проблеми чрез chroot.
:::

:::note
USB устройството трябва да има поне 8 GB свободно място.
:::

### balenaEtcher

<Steps>

1. Изтеглете [balenaEtcher](https://etcher.balena.io/). balenaEtcher поддържа запис на образ за Linux, MacOS и Windows.
   Ако сте изтеглили `.zip` файл, разархивирайте го и изпълнете изпълнимия файл със следните команди:
   ```sh
   # Разархивиране на zip файла:
   bsdtar xvf <име на zip файла>
   # Промяна на директорията към новата папка:
   cd balenaEtcher-linux-x64/
   # Стартиране на balenaEtcher:
   ./balena-etcher
   ```
2. Свържете USB устройство към компютъра.
3. Изберете `Flash from file` и изберете CachyOS ISO файла.
4. Кликнете `Select target` и изберете USB устройството, което сте свързали.
5. Натиснете `Flash`, за да започнете процеса на запис.

</Steps>

:::note
balenaEtcher може да поиска администраторски права. Ако това се случи, въведете паролата си и кликнете `Authenticate`.
:::

### Интерфейс на командния ред (Linux и MacOS)

<Steps>

1. Свържете USB устройство.
2. Открийте свързаното USB устройство чрез следните команди:
   ```sh
   # Linux
   # USB устройството може да бъде идентифицирано напр. /dev/sda, по модел на диска и размер.
   sudo fdisk -l

   # MacOS
   # USB устройствата се идентифицират като "/dev/diskY", където "Y" може да бъде 0, 1 и т.н.
   diskutil list
   ```
3. Копирайте съдържанието на ISO файла към свързаното USB устройство, като изпълните:
   ```sh
   # Заменете <usbdrive> с идентификатора на устройството.
   sudo dd bs=4M if=пълно_име_на_iso.iso of=/dev/<usbdrive> status=progress oflag=sync
   ```
</Steps>

- `dd` вече ще копира съдържанието на ISO файла към свързаното USB устройство.

### Rufus (само за Windows)

<Steps>

1. Свържете USB устройство.
2. Изтеглете [Rufus](https://rufus.ie/) и го инсталирайте, или използвайте преносимата версия.
3. В `Device` кликнете върху падащото меню и изберете свързаното USB устройство.
4. В `Boot selection` кликнете `SELECT` и намерете CachyOS ISO файла.
5. Кликнете `START`.

</Steps>

### Ventoy (Linux и Windows)

<Tabs>

<TabItem label="Linux">

<Steps>

1. Свържете USB устройство.
2. Изтеглете [Ventoy](https://www.ventoy.net/en/download.html)
3. Разархивирайте Ventoy със следната команда:
   ```sh
   # Заменете version с правилната версия, напр. ventoy-1.1.07-linux.tar.gz
   bsdtar xvf ventoy-version-linux.tar.gz
   # Променете директорията към новата папка: (версията може да се промени)
   cd ventoy-1.1.07/
   ```
4. Стартирайте `VentoyGUI.x86_64` като щракнете два пъти върху него или чрез терминала:
   ```sh
   # Ще поиска администраторски права, въведете данните си
   ./VentoyGUI.x86_64
   ```
5. Изберете свързаното USB устройство, като кликнете върху `Device`.
6. Кликнете `Install`.
7. След като инсталацията на Ventoy в USB устройството приключи, затворете прозореца и поставете CachyOS ISO файла в новия използваем дял на устройството.

</Steps>

</TabItem>

<TabItem label="Windows">

<Steps>
1. Свържете USB устройство.
2. Изтеглете [Ventoy](https://www.ventoy.net/en/download.html)
3. Стартирайте `Ventoy2Disk.exe`
4. Изберете свързаното USB устройство, като кликнете върху `Device`
5. Кликнете `Install`
6. След като инсталацията на Ventoy в USB устройството приключи, затворете прозореца и поставете CachyOS ISO файла в новия използваем дял на устройството.
</Steps>

</TabItem>

</Tabs>
