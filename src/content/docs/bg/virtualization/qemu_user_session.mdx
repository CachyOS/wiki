## Приложения:
- **Мрежа (networking)**

Root session не позволява на виртуална машина да пренасочва портове и вместо това използва **NAT**,
което означава, че докато вашата виртуална машина има достъп до света, светът няма достъп до вашата виртуална машина и
вижда само вашия компютър. Това е добре, освен ако не искате да се свържете директно към
вашата виртуална машина от извън компютъра (например чрез ssh) – тогава не можете, защото няма
към какво да се свържете.

- **3D ускорение чрез транслация**

Root session не позволява на VMM да използва render node `/dev/dri/renderD128` и
ограничава `qemu-cli`, ъй като обикновен потребител трудно може да използва root qemu.

## Активиране на User Session:
Много е просто – в главния прозорец на **VMM** кликнете на `File -> Add Connection...`
и в падащото меню `Hypervisor:` изберете `QEMU/KVM user session`. YСлед това можете
да създадете вашите виртуални машини, както е обяснено в [QEMU and VMM Setup](/virtualization/qemu_and_vmm_setup)
в User режим вместо Root режим.
