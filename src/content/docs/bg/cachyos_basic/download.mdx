## Официални източници за ISO

ISO образът на CachyOS може да бъде получен от следните източници:

*   [Уебсайт](<https://cachyos.org/download>)
*   [SourceForge](<https://sourceforge.net/projects/cachyos-arch/files/>)
*   [CachyOS Mirror](<https://mirror.cachyos.org/ISO/>)

## Проверка на Цялостта на ISO чрез SHA256

:::caution
Винаги отделяйте време да проверите цялостта на ISO образа, за да избегнете нежелани проблеми по време на инсталацията или при създаване на инсталационен носител.
:::

**Текуща версия на ISO:** `260809`

**SHA256 Hash:** `959f6577f45e25ee9fd8c220fd221b08e4ea79412c7315c0f922dd6d86d5e33c`

<Tabs>

<TabItem label='Windows'>

<Steps>

1. Изтеглете [file](https://mirror.cachyos.org/ISO/desktop/260809/cachyos-desktop-linux-260809.iso.sha256) съдържащ SHA256 hash **(Oтворете го с текстов редактор, напр. Notepad)**.
2. Отворете CMD или PowerShell като Administrator и [navigate](<https://www.wikihow.com/Change-Directories-in-Command-Prompt>) до папката, в която се намират ISO и SHA256 файловете.
3. Изпълнете следната команда:
   ```powershell
   # Example:
   certUtil -hashfile cachyos-desktop-linux-260809.iso SHA256
   ```
4. Сравнете изхода от certUtil с този от изтегления файл в **Стъпка 1**. Ако съвпадат, можете да продължите с инсталацията на CachyOS.

</Steps>

</TabItem>

<TabItem label='Linux'>

<Steps>

1. Изтеглете [file](https://mirror.cachyos.org/ISO/desktop/260809/cachyos-desktop-linux-260809.iso.sha256) съдържащ SHA256 hash.
2. Отворете терминал и отидете до папката, съдържаща `.sha256` и `.iso` файловете.
3. Изпълнете следната команда:
   ```sh
   # Example:
   cd ~/Downloads
   sha256sum -c cachyos-desktop-linux-260809.iso.sha256
   # cachyos-desktop-linux-260809.iso: OK
   ```
4. Ако резултатът от **Стъпка 3** е OK, можете да продължите с инсталацията на CachyOS.

</Steps>

</TabItem>

<TabItem label='macOS'>

<Steps>

1. Изтеглете [file](https://mirror.cachyos.org/ISO/desktop/260809/cachyos-desktop-linux-260809.iso.sha256) съдържащ SHA256 hash.
2. Отворете терминал и отидете до папката, съдържаща `.sha256` файла и изпълнете следната команда:
   ```sh
   # Example:
   cd Downloads/
   cat cachyos-desktop-linux-260809.iso.sha256
   # 959f6577f45e25ee9fd8c220fd221b08e4ea79412c7315c0f922dd6d86d5e33c
   ```
3. Сравнете изхода от **Стъпка 2** с хеша на ISO файла:
   ```sh
   # Example:
   shasum -a 256 cachyos-desktop-linux-260809.iso
   ```
4. Ако хешовете от **Стъпка 2** и **Стъпка 3** съвпадат, можете да продължите с инсталацията на CachyOS.

</Steps>

</TabItem>

</Tabs>

## Проверка на Aвтентичността на ISO образа (Linux)

За да проверите автентичността на ISO файла:

<Steps>

1. Импортирайте GPG ключа, който да използвате за сравнение:

   ```shell
   gpg --keyserver hkps://keys.openpgp.org --recv-key F3B607488DB35A47
   ```

2. Изтеглете ISO файла и неговия [.sig](https://cdn77.cachyos.org/ISO/desktop/260809/cachyos-desktop-linux-260809.iso.sig) файл с подписа и изпълнете следната команда (заменете 'full_iso_name.iso' с действителното име на ISO файла):
   ```shell
   gpg --verify full_iso_name.iso.sig full_iso_name.iso
   ```

   Ако получите резултат **Good signature**, ISO файлът е автентичен:
   ```
  gpg: Signature made dom 09 ago 2026 13:30:06 -03
  gpg:                using RSA key 882DCFE48E2051D48E2562ABF3B607488DB35A47
  gpg: Good signature from "CachyOS <admin@cachyos.org>" [unknown]
  gpg: WARNING: This key is not certified with a trusted signature!
  gpg:          There is no indication that the signature belongs to the owner.
  Primary key fingerprint: 882D CFE4 8E20 51D4 8E25  62AB F3B6 0748 8DB3 5A47
   ```

</Steps>

:::danger
Ако резултатът не съдържа **Good signature** или идентификаторът на ключа не съвпада, не използвайте ISO образа. Лош подпис означава, че ISO файлът е бил променен или е повреден.

Уверете се, че изтегленият образ идва от [официален източник на CachyOS] (/cachyos_basic/download#official-iso-sources).
:::
