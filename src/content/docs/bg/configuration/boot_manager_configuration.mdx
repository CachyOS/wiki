## systemd-boot

systemd-boot има два вида конфигурационни файлове: един за самия systemd-boot в `/boot/loader/loader.conf` и по един за всеки
отделен запис на ядро в `/boot/loader/entry`.

### Конфигурация на зареждача

В този конфигурационен файл можете да промените записа по подразбиране и времето за изчакване (timeout) на systemd-boot:

```shell
# /boot/loader/loader.conf

default @saved
timeout 5
#console-mode keep # Тази опция настройва разделителната способност на конзолата.
```

### Конфигуриране на командния ред на ядрото

Предоставяме инструмент за по-лесно конфигуриране на systemd-boot: [`sdboot-manage`](https://github.com/CachyOS/CachyOS-PKGBUILDS/tree/master/systemd-boot-manager).
Едно от предимствата на този инструмент е глобалното конфигуриране на командния ред на ядрото. Конфигурационният файл за `sdboot-manage` се намира в `/etc/sdboot-manage.conf`.

Редактирайте реда `LINUX_OPTIONS=` в `/etc/sdboot-manage.conf`, за да промените параметрите на ядрото.

```shell
# /etc/sdboot-manage.conf
LINUX_OPTIONS="zswap.enabled=0 nowatchdog quiet splash"
```

След като направите промените, генерирайте отново всички записи на systemd-boot със следната команда:

```shell
sudo sdboot-manage gen
```

## rEFInd

Подобно на [systemd-boot](/bg/configuration/boot_manager_configuration#systemd-boot), rEFInd има два конфигурационни файла. `refind.conf`, намиращ се в
`boot/efi/EFI/refind`, служи основно за промяна на поведението на rEFInd, докато `/boot/refind_linux.conf` е за управление на вашите опции за зареждане.
`refind.conf` съдържа подробни коментари, обясняващи всички негови опции.

### Конфигуриране на командния ред на ядрото

За да подадете параметри на ядрото към командния ред, променете "Boot using default options" в `/boot/refind_linux.conf`:

```shell
# /boot/refind_linux.conf

"Boot using default options"     "root=PARTUUID=1cb353ec-7f03-4820-8b4b-03baf53a208f rw zswap.enabled=0 nowatchdog quiet splash"
```

Промените и в двата конфигурационни файла влизат в сила незабавно. Не е необходимо да изпълнявате команда за „запазване“ на промените.

## GRUB

За разлика от [systemd-boot](/bg/configuration/boot_manager_configuration#systemd-boot) и [rEFInd](/bg/configuration/boot_manager_configuration#refind),
GRUB има само един конфигурационен файл, разположен в `/etc/default/grub`. В този файл има доста добра документация, която обяснява какво
прави всяка опция.

### Скриване на менюто за зареждане на GRUB

За да скриете менюто на GRUB, просто задайте следните опции по съответния начин:

```shell
# /etc/default/grub

GRUB_TIMEOUT='0'
GRUB_TIMEOUT_STYLE=hidden
```

Натиснете ESC, за да получите достъп до командния ред на GRUB. Оттам изпълнете `normal` или `exit`, за да се върнете към познатото меню за зареждане на GRUB.

### Конфигуриране на командния ред на ядрото

За да подадете параметри на ядрото към командния ред при GRUB, трябва да редактирате `GRUB_CMDLINE_LINUX_DEFAULT` в `/etc/default/grub`.

```shell
# /etc/default/grub

GRUB_CMDLINE_LINUX_DEFAULT='nowatchdog zswap.enabled=0 quiet splash'
```

Всеки път, когато променяте конфигурационния файл на GRUB, трябва да генерирате конфигурацията наново със следната команда:

```shell
sudo grub-mkconfig -o /boot/grub/grub.cfg
```

### Стартиращи BTRFS снимки (snapshots)

:::note
Ако вашата инсталация на CachyOS е отпреди августовското издание, може да се наложи да активирате ръчно функцията за стартиращи BTRFS снимки.

В противен случай можете да пропуснете този раздел, тъй като тя е активирана по подразбиране от августовското издание насам.
:::

За да активирате функцията, инсталирайте пакета `grub-btrfs-support`:

```sh
sudo pacman -S grub-btrfs-support
```

Този пакет инсталира необходимите скриптове и hooks за автоматично откриване на BTRFS снимките и добавянето им в менюто на GRUB.

След като бъде инсталиран, вашите снимки ще се появят в менюто на GRUB, подобно на поведението при Limine.


## Limine

Limine е модерен мениджър за зареждане, известен със своята проста конфигурация. Това ръководство разглежда основите, за да започнете работа с него.

Конфигурирането се извършва основно в `/boot/limine.conf` (или понякога в EFI системния дял) за настройките на менюто и в `/etc/default/limine` за параметрите на ядрото.

### Конфигуриране на менюто за зареждане

Този файл управлява поведението и външния вид на менюто за зареждане. Направените тук промени влизат в сила веднага след запазване – не са нужни допълнителни команди.

* **Време за изчакване (Timeout):** Задава колко секунди Limine да чака, преди автоматично да зареди записа по подразбиране.

  ```shell
  # /boot/limine.conf

  timeout: 5
  ```

* **Запис по подразбиране (Default Entry):** Указва кой запис от менюто се зарежда по подразбиране. Записите се номерират, започвайки от 1. Ако не е зададено, стойността по подразбиране е 1.

  ```shell
  # /boot/limine.conf

  default_entry: 2 # Зареждане на втория запис по подразбиране
  ```

  :::tip
   Ако `default_entry` сочи към директория (напр. `/+CachyOS`), автоматичното зареждане ще бъде деактивирано. За да се зарежда автоматично запис в директория, `default_entry` трябва да сочи директно към номера на съответния запис.
  :::

Пример (`/boot/limine.conf`):

```shell
# /boot/limine.conf

timeout: 5
default_entry: 2 # Сочи директно към записа 'linux-cachyos' по-долу

/+CachyOS        # Запис 1: Директория (използвайте /+, за да е разгъната по подразбиране)
//linux-cachyos  # Запис 2: Действителният запис за зареждане
    protocol: linux
    kernel_path: boot():/vmlinuz-linux-cachyos
    cmdline: quiet splash root=UUID=... rw # Основни параметри на ядрото
    module_path: boot():/initramfs-linux-cachyos.img
```

:::note
`boot():/` се отнася до главната директория (root) на дяла за зареждане.
:::

### Персонализиране на външния вид

Можете да персонализирате визуалния облик на менюто за зареждане на Limine:

* **Тапет (Wallpaper):** Задайте фоново изображение. Поддържаните формати включват BMP, PNG и JPEG.

  ```shell
  # /boot/limine.conf

  wallpaper: boot():/splash.png
  wallpaper_style: stretched # Опции: 'stretched', 'tiled', 'centered'
  backdrop: 000000           # Цвят на фона (RRGGBB hex), ако стилът е 'centered'
  ```

* **Шрифтове (Fonts):** Използвайте [персонализиран шрифтов файл](https://github.com/viler-int10h/vga-text-mode-fonts) и настройте размера му.

  ```shell
  # /boot/limine.conf

  term_font: boot():/custom_font.F16
  term_font_scale: 2x2 # Мащабира размера на шрифта; полезно за екрани с висока резолюция
  ```

* **Цветове (Colors):** Променете цветовете на текста и фона на терминала.

  ```shell
  # /boot/limine.conf

  term_background: 80000000 # Пример: Полупрозрачно черно (AARRGGBB)
  # Налични са и други опции за цветове като term_foreground и т.н.
  ```

### Конфигуриране на параметрите на ядрото

В CachyOS записите за ядра в менюто за зареждане на Limine се **управляват автоматично**. Когато инсталирате или премахвате ядра, `limine-mkinitcpio-hook` използва инструмента `limine-entry-tool` във фонов режим, за да актуализира записите за зареждане.

Въпреки че записите се управляват автоматично, можете да **конфигурирате параметрите на ядрото** (известни още като команден ред на ядрото), които се подават към ядрото при стартиране.

1. **Редактирайте конфигурационния файл:** Променете променливите `KERNEL_CMDLINE` в `/etc/default/limine`. Можете да зададете параметри по подразбиране за всички ядра или специфични параметри за определени имена на ядра (напр. `linux-cachyos`).

   ```shell
   # /etc/default/limine

   # Параметри по подразбиране за повечето ядра
   KERNEL_CMDLINE[default]="quiet splash rd.udev.log_priority=3"

   # Специфични параметри за ядрото 'linux-cachyos'
   KERNEL_CMDLINE["linux-cachyos"]="quiet splash mitigations=off"

   # Параметри за резервните (fallback) записи (ако се генерират)
   # KERNEL_CMDLINE[fallback]="..."
   ```

2. **Приложете промените:** След като запазите `/etc/default/limine`, трябва да генерирате отново вашите initramfs образи и да актуализирате записите на Limine, за да се приложат новите параметри на ядрото. Изпълнете следната команда:

   ```bash
   sudo limine-mkinitcpio
   ```

   Тази команда задейства процеса `mkinitcpio`, който включва `limine-mkinitcpio-hook`, гарантирайки, че промените ви в `/etc/default/limine` са включени в записите за зареждане в `/boot/limine.conf`.
