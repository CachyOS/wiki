## Как да инсталирате липсващата X11 сесия

След като KDE реши да раздели своето развитие на множество пакети, X11 сесията беше премахната от инсталацията по подразбиране.

```sh
sudo pacman -S plasma-x11-session kwin-x11
```

## ЧЗВ

### Как мога да получа същия външен вид като този, показан на екранните снимки на KDE, наречен „Emerald“?

- Това е комбинация от темата Emerald + иконната тема Qogir, които не са инсталирани по подразбиране.
  - ```sh title='За да инсталирате и двете, изпълнете:'
    sudo pacman -S cachyos-emerald-kde-theme-git qogir-icon-theme
    ```
  Приложете и двете в `Appearance & Style - Colors & Themes`
