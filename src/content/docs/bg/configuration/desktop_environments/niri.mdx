:::note
Niri е подреден Wayland композитор с възможност за скролиране, който предлага уникален подход за управление на прозорци чрез своята система за оформление на базата на колони.
:::

Основната ни цел с тази конфигурация е да предоставим работеща Niri настройка, която осигурява гладко и интуитивно изживяване на работния плот, като същевременно запазва конфигурацията проста и достъпна.

Разгледайте нашия [Niri ЧЗВ.](/configuration/desktop_environments/niri#faq)

## Клавишни комбинации

Повечето клавишни комбинации изискват използването на модификаторния клавиш (mod key), който в нашия случай е клавишът Windows (означен като SUPER). Можете да го промените в конфигурационния файл.

### Управление на приложения

| Описание | Клавиш |
|----------|--------|
| Отваряне на терминал | <Kbd linux="Super+Return" /> |
| Отваряне на стартер за програми | <Kbd linux="Super+Ctrl+Return" /> |
| Отваряне на браузър (Firefox) | <Kbd linux="Super+B" /> |
| Отваряне на файлов мениджър | <Kbd linux="Super+E" /> |
| Затваряне на активния прозорец | <Kbd linux="Super+Q" /> |
| Заключване на екрана | <Kbd linux="Super+Alt+L" /> |

### Навигация между работни пространства

| Описание | Клавиш |
|----------|--------|
| Преминаване към работно пространство (1-9) | <Kbd linux="Super+1" /> до <Kbd linux="Super+9" /> |
| Предишно работно пространство | <Kbd linux="Super+Tab" /> |
| Придвижване между работни пространства с колелце на мишката | <Kbd linux="Super+Scroll" /> |

| Фокус върху първа колона | <Kbd linux="Super+Home" /> |

## ЧЗВ

### Какво прави Niri различен от другите прозоречни мениджъри?

Niri използва уникален подход на подреждане със скролиране, при който прозорците са подредени в колони, които могат да се превъртат хоризонтално. Това предоставя метафора за безкраен работен плот, която е особено полезна за ултрашироки монитори и работни процеси, изискващи много отворени приложения.

### Как да променя клавиатурната подредба?

Редактирайте секцията `input` във вашия конфигурационен файл:

```txt title='Пример'
input {
    keyboard {
        xkb {
            layout "us" // Променете от "de" на вашата желана подредба
        }
    }
}
```

### Мога ли да променя разстоянията между прозорците (gaps) и външния им вид?

Да, можете да промените секцията layout:

```txt title='Пример'
layout {
    gaps 8 // Променете размера на разстоянията

    focus-ring {
        width 2
        active-color "#your-color"
        inactive-color "#your-color"
    }
}
```

### Как да добавя още приложения за автоматично стартиране?

Добавете ги в секцията за стартиране:

```txt title='Пример'
spawn-at-startup "your-application"
```

### За какво служи аварийният клавиш?

Комбинацията `Super+Escape` е предназначена да възстанови контрола, когато приложение на цял екран блокира вашите клавишни комбинации. Тя деактивира всеки активен инхибитор на клавишни комбинации.

### Как да конфигурирам няколко монитора?

Разкоментирайте и променете секцията за вашите конкретни дисплеи. Изпълнете `niri msg outputs`, за да получите правилните имена:

```txt title='Пример'
output "DP-1" {
    mode "1920x1080@60.000"
    scale 1
}
```
