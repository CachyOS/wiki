Deze handleiding beschrijft hoe je hardwareversnelling inschakelt in op Chromium gebaseerde browsers op CachyOS. Hierdoor worden video- en grafische taken naar je GPU verplaatst, wat de prestaties verbetert.

## Vereisten

**Vereist:**
* **Op Chromium gebaseerde browser:** (bijv. Chrome, Brave, Ungoogled Chromium, Edge)
* **GPU-stuurprogramma's/API's:** Up-to-date Mesa- (AMD/Intel) of NVIDIA-stuurprogramma's, met Vulkan/VA-API/VDPAU geconfigureerd.

**Optioneel:**

* **amdgpu_top:** Installeer `amdgpu_top` uit de repository via de pakketbeheerder als je de activiteit van je AMD-GPU vanuit de terminal wilt monitoren.
* **nvtop:** (alleen Intel-GPU's) Installeer `nvtop` (Lunar Lake) en `intel-gpu-tools` (vóór Lunar Lake) via de pakketbeheerder Shelly als je de activiteit van je Intel-GPU vanuit de terminal wilt monitoren.

## Bijdragen

Deze handleiding kan worden uitgebreid. Als je een werkende configuratie voor hardwareversnelling hebt voor een specifieke GPU en op Chromium gebaseerde browser, draag dan bij door een nieuwe sectie toe te voegen onder "Configuraties per GPU & browser". Vermeld daarbij:

* **Naam van de browser**
* **GPU-model**
* **Flags:** inhoud van `~/.config/[browser]-flags.conf`.
* **Bestandspad:** Volledig pad naar het flags-bestand.
* **Opmerkingen (optioneel):** Belangrijke stuurprogramma's, pakketten of bijzonderheden van de configuratie.

### Configuratiestappen

<Steps>

1. Bepaal het flags-bestand: Zoek het pad van het flags-bestand van je browser op in "Configuraties per GPU & browser".
2. Bewerk het flags-bestand: Open/maak het bestand met `nano` (of je favoriete teksteditor, zoals `micro` of `vim`).

    ```bash
    nano [PATH_TO_YOUR_BROWSER_FLAGS_FILE]
    # Voorbeeld: nano ~/.config/chrome-flags.conf
    ```

3. Voeg flags toe: Plak de relevante flags voor je GPU/browser in het bestand.
4. Opslaan & sluiten.
5. Herstart de browser: Sluit alle browservensters en start de browser opnieuw.
6. Controleer: Ga naar `chrome://gpu` (of `brave://gpu`, `edge://gpu`, enz.). Controleer of de status "Hardware accelerated" wordt getoond onder "Video Acceleration Information" en "Graphics Feature Status".

</Steps>

## Hoe controleer je hardwareversnelling voor video

<Tabs>

<TabItem label='AMD GPUs (amdgpu_top)'>

<Steps>

1. Open een terminal en voer het commando uit:
    ```bash
    amdgpu_top
    ```
2. Speel een video af in je browser (bijv. op YouTube).
3. Kijk naar de sectie `media` in `amdgpu_top`. Je zou hier enig gebruik moeten zien, wat aangeeft dat de media-engine van je GPU actief is. Als deze tijdens het afspelen van de video op 0% blijft, wordt hardwareversnelling mogelijk niet volledig gebruikt voor het decoderen.

</Steps>

</TabItem>

<TabItem label='Intel GPUs (nvtop)'>

<Steps>

1. Open een terminal en voer het commando uit:
    ```bash
    sudo nvtop
    ```
2. Speel een video af in je browser (bijv. op YouTube).
3. Kijk naar het percentage `ENC/DEC` in `nvtop`; het percentage zou moeten stijgen als het decoderen van video via de hardware werkt.

</Steps>

</TabItem>

<TabItem label='Intel GPUs (intel_gpu_tools)'>

<Steps>

1. Open een terminal en voer het commando uit:

    ```bash
    sudo intel_gpu_top
    ```

    Let op: sommige nieuwere Intel-GPU's, zoals Lunar Lake-GPU's, tonen de prestatietellers van de GPU niet meer via `intel_gpu_top`; gebruik `nvtop` voor deze systemen

2. Speel een video af in je browser (bijv. op YouTube).
3. Kijk naar de percentages `Video` en `VideoEnhance` in intel_gpu_top; het percentage zou moeten stijgen als het decoderen van video via de hardware werkt.

</Steps>

</TabItem>

<TabItem label='Ontwikkelaarstools van de browser'>

<Steps>

1. Open je op Chromium gebaseerde browser.

2. Speel een video af (bijv. op YouTube of een lokaal bestand).

3. Open de ontwikkelaarstools: druk op `F12` of `Ctrl+Shift+I`.

4. Ga naar het tabblad **Media**. Als je het niet ziet, klik dan op de drie puntjes (`...`) of `>>` (meer tabbladen) in de werkbalk van de ontwikkelaarstools en selecteer `Media`.

5. Klik in de sectie "Players" aan de linkerkant op het item dat bij je video hoort.

6. Scrol in het hoofdpaneel naar de sectie **Video Decoder**.

7. Zoek het label `Hardware decoder`. Dit moet `true` zijn. Als er `false` staat of de naam van een softwaredecoder wordt getoond (bijv. `FFmpegVideoDecoder`, `VpxVideoDecoder`, `Dav1dVideoDecoder`), is hardwareversnelling niet actief voor die video.

</Steps>

</TabItem>

</Tabs>

## Configuraties per GPU & browser

### AMD Radeon RX 6900 XT (Google Chrome)

* **Browser:** Google Chrome

* **GPU:** AMD Radeon RX 6900 XT

* **Flags-bestand:** `~/.config/chrome-flags.conf`

```bash
--use-gl=angle
--use-angle=vulkan
--enable-features=Vulkan,VulkanFromANGLE,DefaultANGLEVulkan,AcceleratedVideoDecodeLinuxZeroCopyGL,AcceleratedVideoEncoder,VaapiIgnoreDriverChecks,UseMultiPlaneFormatForHardwareVideo
```

**Opmerkingen:** Maakt gebruik van Vulkan (via ANGLE) en VA-API. `--ozone-platform=x11` kan op Wayland nuttig zijn voor bepaalde versnellingspaden.


### Nvidia RTX 4090 (Vivaldi)

* **Browser:** Vivaldi

* **GPU:** Nvidia RTX 4090

* **Flags-bestand:** `~/.config/vivaldi-stable.conf`

```bash
--enable-features=VaapiVideoDecoder,AcceleratedVideoDecodeLinuxGL,AcceleratedVideoDecodeLinuxZeroCopyGL
```

* **Flags-bestand:** `/usr/share/applications/vivaldi-stable.desktop`

```bash
# Laat alle andere regels hetzelfde
# Wijzig alleen deze regel Exec= onder de sectie '[Desktop Entry]'
Exec=/usr/bin/vivaldi-stable --enable-features=VaapiVideoDecoder,AcceleratedVideoDecodeLinuxGL,AcceleratedVideoDecodeLinuxZeroCopyGL %U
```

**Opmerkingen:**

Je hoeft maar één van deze wijzigingen in de conf-bestanden toe te passen, maar beide toepassen zou geen problemen moeten geven.

Als alternatief kun je voor KDE het volgende doen:
1. Verwijder alle snelkoppelingen naar Vivaldi in Taakbeheer/de taakbalk
2. Zoek naar `Vivaldi` in de lijst van de applicatiestarter
3. Klik met de rechtermuisknop op het item in de applicatiestarter en selecteer `Edit Application...`
4. Voeg in de sectie `Command-line arguments` de volgende argumenten toe vóór het laatste argument `%U`:
```
--enable-features=VaapiVideoDecoder,AcceleratedVideoDecodeLinuxGL,AcceleratedVideoDecodeLinuxZeroCopyGL
```
5. Start Vivaldi en maak het proces vast aan Taakbeheer/de taakbalk

### Vivaldi - NVIDIA RTX 5090 (Bijgedragen door icetea)

* **Browser:** Vivaldi (8.1)

* **GPU:** NVIDIA GeForce RTX 5090 (Blackwell)

* **Pad van het flags-bestand:** `~/.config/vivaldi-stable.conf`

```bash
--enable-features=VaapiVideoDecoder,AcceleratedVideoDecodeLinuxGL,AcceleratedVideoDecodeLinuxZeroCopyGL,VaapiOnNvidiaGPUs,VaapiIgnoreDriverChecks
--use-gl=angle
--use-angle=gl
--disable-features=Vulkan
--ignore-gpu-blocklist
--ozone-platform=wayland
```

**Opmerkingen:**
- Vereist `libva-nvidia-driver`. Getest in juli 2026: stuurprogramma 610.43.03, KDE Plasma (Wayland), Vivaldi 8.1.
- `VaapiIgnoreDriverChecks` is de belangrijkste flag op NVIDIA. Zonder deze flag wordt het decoderen geïnitialiseerd en beweert `vivaldi://gpu` "Hardware accelerated", maar mislukt het decoderen tijdens runtime (`vaEndPicture failed, VA error: internal decoding error`) en wordt er stilletjes teruggevallen op software.
- Controleer met DevTools → tabblad Media (`VaapiVideoDecoder` als naam van de decoder) en `nvidia-smi dmon -s u` (kolom DEC > 0 tijdens het afspelen). Vertrouw niet alleen op `vivaldi://gpu`.
- Het decoderen van AV1 werkt niet in `libva-nvidia-driver` 0.0.17 (fix staat op upstream master, nog niet uitgebracht, zie [elFarto/nvidia-vaapi-driver#419](https://github.com/elFarto/nvidia-vaapi-driver/issues/419)). Blokkeer AV1 (bijv. met enhanced-h264ify) zodat YouTube VP9 levert.

### Google Chrome - NVIDIA RTX 5070 (Bijgedragen door pisyukaev)

* **Browser:** Google Chrome

* **GPU:** NVIDIA GeForce RTX 5070 (Blackwell / GB205)

* **Pad van het flags-bestand:** `~/.config/chrome-flags.conf`

```bash
--enable-features=AcceleratedVideoDecodeLinuxGL,VaapiVideoDecoder,VaapiIgnoreDriverChecks,VaapiOnNvidiaGPUs
--ignore-gpu-blocklist
```

**Opmerkingen:**
- Vereist `libva-nvidia-driver` en `nvidia-utils` (getest met stuurprogramma 610.43.03).
- **Cruciale flag:** `VaapiOnNvidiaGPUs`. Dit is de belangrijkste flag die VA-API inschakelt op NVIDIA-GPU's in Chrome/Chromium. Zonder deze flag blokkeert Chrome NVIDIA-apparaten hardgecodeerd in `vaapi_wrapper.cc` en valt het stilletjes terug op softwaredecodering.
- `VaapiIgnoreDriverChecks` wordt ook aanbevolen om fouten bij het decoderen tijdens runtime te voorkomen.
- `AcceleratedVideoDecodeLinuxGL` schakelt hardwareversneld decoderen van video in via de OpenGL-backend van ANGLE.
- Werkt bevestigd: `chrome://gpu` → Video Acceleration Information toont ondersteuning voor het decoderen van H264 (baseline, main, high), VP8, VP9 (profile0, profile2), HEVC (main, main 10, main still-picture) en AV1.
- Om te controleren: open `chrome://gpu` en controleer of "Video Acceleration Information" decodeercodecs toont. Speel een HEVC-video af en controleer in DevTools → tabblad Media of `VaapiVideoDecoder` de actieve decoder is.
- De flag `--ozone-platform=wayland` is niet nodig, want Chrome detecteert Wayland automatisch op CachyOS. Als je problemen ondervindt, kun je `--ozone-platform=wayland` expliciet toevoegen.
