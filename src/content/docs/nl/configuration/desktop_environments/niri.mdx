:::note
Niri is een scrollable-tiling Wayland compositor die een unieke benadering van vensterbeheer biedt met een op kolommen gebaseerd indelingssysteem.
:::

Ons belangrijkste doel met onze opstelling is een werkende Niri-configuratie die een soepele en intuïtieve bureaubladervaring biedt, terwijl de configuratie eenvoudig en toegankelijk blijft.

Bekijk onze [Niri FAQ.](/nl/configuration/desktop_environments/niri#faq)

**Dotfiles onderhouden door [Ly-sec](https://github.com/Ly-sec)**
Voor problemen met Noctalia kun je de [Noctalia-documentatie](https://docs.noctalia.dev/) raadplegen.

## FAQ

### Wat maakt Niri anders dan andere window managers?

Niri gebruikt een unieke scrollable-tiling-aanpak waarbij vensters in kolommen worden gerangschikt die horizontaal gescrold kunnen worden. Dit geeft het idee van een oneindig bureaublad, wat vooral handig is voor ultrawide monitoren en werkwijzen waarbij veel applicaties open staan.

### Hoe wijzig ik de toetsenbordindeling?

Bewerk de input-sectie in je configuratiebestand:

```txt title='Voorbeeld'
input {
    keyboard {
        xkb {
            layout "us" // Wijzig "de" naar je gewenste indeling
        }
    }
}
```

### Kan ik de tussenruimtes en het uiterlijk van vensters aanpassen?

Ja, je kunt de layout-sectie aanpassen:

```txt title='Voorbeeld'
layout {
    gaps 8 // Grootte van de tussenruimte wijzigen

    focus-ring {
        width 2
        active-color "#your-color"
        inactive-color "#your-color"
    }
}
```

### Hoe voeg ik meer opstartapplicaties toe?

Voeg ze toe aan de startup-sectie:

```txt title='Voorbeeld'
spawn-at-startup "your-application"
```

### Waar is de nooduitgangtoets voor?

De sneltoets `Super+Escape` is bedoeld om de controle te herstellen wanneer een applicatie op volledig scherm je sneltoetsen blokkeert. Hij schakelt elke actieve blokkering van sneltoetsen uit.

### Hoe configureer ik meerdere monitoren?

Haal het commentaar weg bij de output-sectie en pas deze aan voor je specifieke beeldschermen. Voer `niri msg outputs` uit om de juiste namen te krijgen:

```txt title='Voorbeeld'
output "DP-1" {
    mode "1920x1080@60.000"
    scale 1
}
```
