## systemd-boot

systemd-boot heeft twee soorten configuratiebestanden: één voor systemd-boot zelf in `/boot/loader/loader.conf`, en één voor elk
afzonderlijk kernelitem in `/boot/loader/entry`.

### Configuratie van de loader

In dit configuratiebestand kun je het standaarditem en de time-out van systemd-boot wijzigen

```shell
# /boot/loader/loader.conf

default @saved
timeout 5
#console-mode keep # Deze optie stelt de resolutie van de console in.
```

### Configuratie van de kernelcommandoregel

We bieden een hulpmiddel om systemd-boot eenvoudiger te configureren: [`sdboot-manage`](https://github.com/CachyOS/CachyOS-PKGBUILDS/tree/master/systemd-boot-manager).
Een van de voordelen van dit hulpmiddel is een globale configuratie van de kernelcommandoregel. Het configuratiebestand voor `sdboot-manage` staat in `/etc/sdboot-manage.conf`.

Bewerk de regel `LINUX_OPTIONS=` in `/etc/sdboot-manage.conf` om kernelparameters te wijzigen.

```shell
# /etc/sdboot-manage.conf
LINUX_OPTIONS="zswap.enabled=0 nowatchdog quiet splash"
```

Genereer na het aanbrengen van wijzigingen alle systemd-boot-items opnieuw met het volgende commando

```shell
sudo sdboot-manage gen
```

## rEFInd

Net als [systemd-boot](/nl/configuration/boot_manager_configuration#systemd-boot) heeft rEFInd twee configuratiebestanden. `refind.conf` in
`boot/efi/EFI/refind` is vooral bedoeld om het gedrag van rEFind te wijzigen, terwijl `/boot/refind_linux.conf` dient om je opstartopties te beheren.
`refind.conf` bevat uitgebreide opmerkingen die alle opties uitleggen.

### Configuratie van de kernelcommandoregel

Om kernelparameters door te geven aan de commandoregel, pas je "Boot using default options" aan in `/boot/refind_linux.conf`

```shell
# /boot/refind_linux.conf

"Boot using default options"     "root=PARTUUID=1cb353ec-7f03-4820-8b4b-03baf53a208f rw zswap.enabled=0 nowatchdog quiet splash"
```

Wijzigingen in beide configuratiebestanden worden direct van kracht. Het is niet nodig een commando uit te voeren om wijzigingen "op te slaan".

## GRUB

In tegenstelling tot [systemd-boot](/nl/configuration/boot_manager_configuration#systemd-boot) en [rEFInd](/nl/configuration/boot_manager_configuration#refind)
heeft GRUB maar één configuratiebestand, in `/etc/default/grub`. Dit bestand bevat behoorlijk goede documentatie die uitlegt wat
elke optie doet.

### Het opstartmenu van GRUB verbergen

Om het GRUB-menu te verbergen, stel je de volgende opties als volgt in.

```shell
# /etc/default/grub

GRUB_TIMEOUT='0'
GRUB_TIMEOUT_STYLE=hidden
```

Druk op ESC om toegang te krijgen tot de GRUB-prompt. Voer daar `normal` of `exit` uit om terug te gaan naar het bekende opstartmenu van GRUB.

### Configuratie van de kernelcommandoregel

Om met GRUB kernelparameters door te geven aan de commandoregel, moeten we `GRUB_CMDLINE_LINUX_DEFAULT` bewerken in `/etc/default/grub`.

```shell
# /etc/default/grub

GRUB_CMDLINE_LINUX_DEFAULT='nowatchdog zswap.enabled=0 quiet splash'
```

Elke keer dat we het configuratiebestand van GRUB aanpassen, moeten we de configuratie opnieuw genereren met het volgende commando:

```shell
sudo grub-mkconfig -o /boot/grub/grub.cfg
```

### Opstartbare BTRFS-snapshots

:::note
Als je CachyOS-installatie van vóór de release van augustus is, moet je de functie voor opstartbare BTRFS-snapshots mogelijk handmatig inschakelen.

Anders kun je deze sectie overslaan, omdat de functie sinds de release van augustus standaard is ingeschakeld.
:::

Installeer het pakket grub-btrfs-support om de functie in te schakelen:

```sh
sudo pacman -S grub-btrfs-support
```

Dit pakket installeert de benodigde scripts en hooks om BTRFS-snapshots automatisch te detecteren en toe te voegen aan het GRUB-menu.

Na de installatie verschijnen je snapshots in het GRUB-menu, vergelijkbaar met hoe Limine werkt.


## Limine

Limine is een moderne bootloader die bekendstaat om zijn eenvoudige configuratie. Deze handleiding behandelt de basis om je op weg te helpen.

De configuratie vindt voornamelijk plaats in `/boot/limine.conf` (of soms in de EFI-systeempartitie) voor de menu-instellingen, en in `/etc/default/limine` voor kernelparameters.

### Configuratie van het opstartmenu

Dit bestand bepaalt het gedrag en uiterlijk van het opstartmenu. Wijzigingen worden direct na het opslaan van kracht. Er zijn geen extra commando's nodig.

* **Time-out:** Stelt in hoeveel seconden Limine wacht voordat het standaarditem automatisch wordt opgestart.

  ```shell
  # /boot/limine.conf

  timeout: 5
  ```

* **Standaarditem:** Geeft aan welk menu-item standaard wordt opgestart. Items worden genummerd vanaf 1. Als dit niet is ingesteld, is de standaardwaarde 1.

  ```shell
  # /boot/limine.conf

  default_entry: 2 # Standaard het tweede item opstarten
  ```

  :::tip
   Als `default_entry` naar een map verwijst (bijv. `/+CachyOS`), wordt automatisch opstarten uitgeschakeld. Om automatisch een item binnen een map op te starten, moet `default_entry` direct naar het nummer van dat specifieke item verwijzen.
  :::

Voorbeeld (`/boot/limine.conf`):

```shell
# /boot/limine.conf

timeout: 5
default_entry: 2 # Verwijst direct naar het item 'linux-cachyos' hieronder

/+CachyOS        # Item 1: Een map (gebruik /+ om deze standaard uit te klappen)
//linux-cachyos  # Item 2: Het daadwerkelijk opstartbare item
    protocol: linux
    kernel_path: boot():/vmlinuz-linux-cachyos
    cmdline: quiet splash root=UUID=... rw # Basiskernelparameters
    module_path: boot():/initramfs-linux-cachyos.img
```

:::note
`boot():/` verwijst naar de root van de opstartschijf.
:::

### Thema's

Je kunt het uiterlijk van het opstartmenu van Limine aanpassen:

* **Achtergrond:** Stel een achtergrondafbeelding in. Ondersteunde formaten zijn onder andere BMP, PNG en JPEG.

  ```shell
  # /boot/limine.conf

  wallpaper: boot():/splash.png
  wallpaper_style: stretched # Opties: 'stretched', 'tiled', 'centered'
  backdrop: 000000           # Achtergrondkleur (RRGGBB hex) als de stijl 'centered' is
  ```

* **Lettertypen:** Gebruik een [eigen lettertypebestand](https://github.com/viler-int10h/vga-text-mode-fonts) en pas de grootte aan.

  ```shell
  # /boot/limine.conf

  term_font: boot():/custom_font.F16
  term_font_scale: 2x2 # Schaalt de lettergrootte, handig voor schermen met een hoge resolutie
  ```

* **Kleuren:** Pas de tekst- en achtergrondkleuren van de terminal aan.

  ```shell
  # /boot/limine.conf

  term_background: 80000000 # Voorbeeld: half-transparant zwart (AARRGGBB)
  # Andere kleuropties, zoals term_foreground, enz., zijn beschikbaar.
  ```

### Configuratie van het kernelcommando

Op CachyOS worden kernelitems in het opstartmenu van Limine **automatisch beheerd**. Wanneer je kernels installeert of verwijdert, gebruikt de `limine-mkinitcpio-hook` op de achtergrond het hulpprogramma `limine-entry-tool` om de opstartitems bij te werken.

Hoewel de items automatisch worden afgehandeld, kun je wel **de kernelparameters configureren** (ook wel de kernelcommandoregel genoemd) die bij het opstarten aan de kernel worden doorgegeven.

1. **Bewerk het configuratiebestand:** Pas de variabelen `KERNEL_CMDLINE` aan in `/etc/default/limine`. Je kunt standaardparameters instellen voor alle kernels of specifieke parameters voor bepaalde kernelnamen (bijv. `linux-cachyos`).

   ```shell
   # /etc/default/limine

   # Standaardparameters voor de meeste kernels
   KERNEL_CMDLINE[default]="quiet splash rd.udev.log_priority=3"

   # Specifieke parameters voor de kernel 'linux-cachyos'
   KERNEL_CMDLINE["linux-cachyos"]="quiet splash mitigations=off"

   # Parameters voor fallback-items (indien gegenereerd)
   # KERNEL_CMDLINE[fallback]="..."
   ```

2. **Pas de wijzigingen toe:** Nadat je `/etc/default/limine` hebt opgeslagen, moet je je initramfs-images opnieuw genereren en de Limine-items bijwerken om de nieuwe kernelparameters toe te passen. Voer het volgende commando uit:

   ```bash
   sudo limine-mkinitcpio
   ```

   Dit commando start het `mkinitcpio`-proces, inclusief de `limine-mkinitcpio-hook`, zodat je wijzigingen in `/etc/default/limine` worden verwerkt in de opstartitems in `/boot/limine.conf`.
