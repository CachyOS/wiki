## Systeemvereisten

Zorg er voordat je de installatie voorbereidt voor dat de gebruikte computer voldoet aan de minimale systeemvereisten om CachyOS te kunnen draaien. Het installatieprogramma
gebruikt een online installatieproces, dus een stabiele en redelijk snelle internetverbinding is verplicht.

:::note[Virtuele machines]
Het wordt niet aanbevolen om CachyOS op een virtuele machine te installeren. VM's kunnen problemen hebben door een onjuiste configuratie of volledig kapot zijn. Het wordt aanbevolen om CachyOS op bare metal te installeren.
:::

<Tabs>

<TabItem label="Minimale vereisten">

*   3 GB RAM
*   30 GB opslagruimte (HDD/SSD)
*   Stabiele internetverbinding

:::caution
Een instabiele internetverbinding kan leiden tot langere installatietijden of, in het ergste geval, een mislukte installatie.
:::

</TabItem>

<TabItem label="Aanbevolen vereisten">

*   8GB RAM
*   50 GB opslagruimte (SSD/NVMe)
*   [CPU met ondersteuning voor x86-64-v3](/nl/installation/installation_prepare#ondersteuning-voor-x86_64-microarchitectuurniveaus)
*   Internetsnelheid van 50 Mbps of hoger
*   NVIDIA-GPU (900+ - bijv.: GTX 950), AMD +GCN 1.0 (bijv.: AMD R7 240) of Intel (Integrated HD Graphics-serie of hoger. Arc-serie)

</TabItem>

</Tabs>

## Een opstartbare CachyOS-USB-stick maken

Er zijn verschillende hulpmiddelen en methoden die je kunt gebruiken om een opstartbare USB-stick met CachyOS te maken.

:::tip
Bewaar een kopie van de CachyOS-ISO op dezelfde schijf of op een andere locatie, zodat je deze later kunt gebruiken voor probleemoplossing via chroot.
:::

:::note
De USB-stick moet minimaal 8GB beschikbare ruimte hebben.
:::

### balenaEtcher

<Steps>

1. Download [balenaEtcher](<https://etcher.balena.io/>). balenaEtcher ondersteunt het flashen van een image op Linux, MacOS en Windows.
   Als je een `.zip`-bestand hebt gedownload, pak het dan uit en voer de binary uit met de volgende commando's:
      ```sh
      # Zip-bestand uitpakken:
      bsdtar xvf <zip file name>
      # cd naar de nieuwe map:
      cd balenaEtcher-linux-x64/
      # balenaEtcher uitvoeren:
      ./balena-etcher
      ```
2. Sluit een USB-stick aan op de computer.
3. Selecteer `Flash from file` en kies het CachyOS-ISO-imagebestand.
4. Klik op `Select target` en kies de USB-stick die je eerder hebt aangesloten.
5. Druk op `Flash` om het flashproces te starten.

</Steps>

:::note
balenaEtcher kan om administratorrechten vragen. Voer in dat geval je wachtwoord in en klik op `Authenticate`.
:::

### Commandoregel (Linux & MacOS)

<Steps>

1. Sluit een USB-stick aan.
2. Detecteer de aangesloten USB-stick met de volgende commando's:
   ```sh
   # Linux
   # De USB-stick is te herkennen (bijv.: /dev/sda) aan het schijfmodel en de grootte.
   sudo fdisk -l

   # MacOS
   # USB-sticks worden aangeduid als "/dev/diskY", waarbij "Y" 0, 1 enz. kan zijn.
   diskutil list
   ```
3. Kopieer de inhoud van de iso naar de aangesloten USB-stick door het volgende uit te voeren:
   ```sh
   # Vervang <usbdrive> door het label van de schijf.
   sudo dd bs=4M if=full_iso_name.iso of=/dev/<usbdrive> status=progress oflag=sync
   ```
</Steps>

- `dd` kopieert nu de inhoud van het ISO-bestand naar de aangesloten USB-stick.

### Rufus (alleen Windows)

<Steps>

1. Sluit een USB-stick aan.
2. Download [Rufus](<https://rufus.ie/>) en installeer het, of start de portable versie.
3. Klik bij `Device` op de dropdownlijst en selecteer de aangesloten USB-stick.
4. Klik bij `Boot selection` op `SELECT` en zoek het CachyOS-ISO-imagebestand op.
5. Klik op `START`.

</Steps>

### Ventoy (Linux & Windows)

<Tabs>

<TabItem label="Linux">

<Steps>

1. Sluit een USB-stick aan.
2. Download [Ventoy](<https://www.ventoy.net/en/download.html>)
3. Pak Ventoy uit met het volgende commando:
   ```sh
   # Vervang version door de juiste versie, bijv.: ventoy-1.1.07-linux.tar.gz
   bsdtar xvf ventoy-version-linux.tar.gz
   # cd naar de nieuwe map: (versie kan verschillen)
   cd ventoy-1.1.07/
   ```
4. Start `VentoyGUI.x86_64` door erop te dubbelklikken of via de terminal:
   ```sh
   # Er wordt om administratorrechten gevraagd; voer je inloggegevens in
   ./VentoyGUI.x86_64
   ```
5. Selecteer de aangesloten USB-stick door op `Device` te klikken.
6. Klik op `Install`.
7. Nadat Ventoy op de aangesloten USB-stick is geïnstalleerd, sluit je het venster en plaats je het CachyOS-ISO-bestand op de nieuwe bruikbare partitie van de stick.

</Steps>

</TabItem>

<TabItem label="Windows">

<Steps>
1. Sluit een USB-stick aan.
2. Download [Ventoy](<https://www.ventoy.net/en/download.html>)
3. Start `Ventoy2Disk.exe`
4. Selecteer de aangesloten USB-stick door op `Device` te klikken.
5. Klik op `Install`.
6. Nadat Ventoy op de USB-stick is geïnstalleerd, sluit je het venster en plaats je het CachyOS-ISO-bestand op de nieuwe bruikbare partitie van de stick.
</Steps>

</TabItem>

</Tabs>
