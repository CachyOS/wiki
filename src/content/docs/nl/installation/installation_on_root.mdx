## Voordat je begint

:::note
Als je na het klikken op **Launch Installer** alleen GRUB en Limine als bootmanageropties krijgt, is het systeem opgestart in Legacy/BIOS-modus.
:::

:::note[Het installeren van meerdere bureaubladomgevingen is niet toegestaan tijdens het installatieproces.]
:::

:::caution[Secure Boot en CSM moeten zijn uitgeschakeld in de BIOS/UEFI-instellingen wanneer je in UEFI-modus installeert.]
Om Secure Boot na de installatie in te stellen, zie de sectie [Secure Boot](/nl/configuration/secure_boot_setup).

`Legacy USB Support` moet op `Auto` staan.
:::

:::caution
De opties `Install alongside` en `Replace partition` zijn niet 100% betrouwbaar en kunnen ervoor zorgen dat de installatie mislukt.

`Manual partitioning` heeft **sterk de voorkeur** bij het installeren van CachyOS.
:::

:::tip
Het wordt sterk aanbevolen om na een mislukte installatiepoging opnieuw op te starten vanaf de ISO.

Anders kunnen er tijdens het installatieproces steeds fouten optreden.

Dit gebeurt omdat het installatieprogramma bij een mislukte installatie de partities niet correct unmount.

:::

## Installatiemethoden

### Handmatig partitioneren

:::note[Voordat je verdergaat met het partitioneren van de schijf voor een UEFI-installatie.]
    ```sh title='Voer dit commando uit in de terminal'
    efibootmgr -v
    ```
Als de uitvoer `EFI variables are not supported on this system.` is, dan is het systeem opgestart in Legacy/BIOS-modus en moet je ervoor zorgen dat de UEFI-modus is ingesteld in de BIOS/UEFI-instellingen. Zie de sectie [Vereisten](/nl/installation/installation_on_root/#voordat-je-begint).
:::

## Dual booten met Windows en CachyOS

:::note[Deze handleiding gaat ervan uit dat Windows al op het systeem is geïnstalleerd en dat je hebt besloten CachyOS ernaast te installeren, op dezelfde schijf.]
:::

:::caution
Dual booten met Windows en Linux is niet 100% betrouwbaar. Windows-updates kunnen de bootloader kapotmaken door de EFI-partitie te overschrijven.
In sommige gevallen treden er nooit problemen op, maar voor sommige gebruikers kan het een terugkerend probleem zijn.

Een manier om dit te voorkomen is om elk besturingssysteem op een aparte schijf te installeren.
:::

:::caution
Mogelijk moet de grootte van de EFI-partitie worden aangepast, afhankelijk van de aanbevolen minimale grootte voor de gekozen bootmanager. Zie [Handmatig partitioneren](/nl/installation/installation_on_root#handmatig-partitioneren).

De grootte van FAT-bestandssystemen kan niet ter plekke worden aangepast. Om de FAT EFI-partitie correct te "vergroten", moet je een back-up maken van het bestaande EFI-bestandssysteem, een hulpmiddel zoals `gparted` gebruiken om de grootte van de bestaande partitie aan te passen en de nieuwe partitie opnieuw te formatteren, en daarna de vorige bestandssysteemstructuur terugkopiëren naar de EFI-partitie.
:::

### Vereisten

- Snel opstarten en de slaapstand (hibernation) van Windows moeten zijn uitgeschakeld.
  - Open Windows Powershell als administrator en voer het volgende commando uit:
      ```ps
      powercfg /H off
      ```
    Start het systeem opnieuw op zodat de wijzigingen van kracht worden.
- Windows BitLocker moet zijn uitgeschakeld.
  - Controleren of BitLocker is ingeschakeld:
    ```ps title='Open een opdrachtprompt als administrator en voer het volgende commando uit'
    manage-bde -status
    ```
  Als **Encryption Method** `None` aangeeft, is BitLocker uitgeschakeld.
- Secure Boot moet zijn uitgeschakeld.
- Een lege partitie van ≥30 GB.
  - Handleiding voor het verkleinen van een Windows-partitie:
    - Druk op `Win + R`, typ `diskmgmt.msc` en druk op Enter om Schijfbeheer te openen.
    - Zoek je belangrijkste Windows-partitie (meestal C:) en klik er met de rechtermuisknop op.
    - Klik op `Shrink Volume...`, geef minimaal **30720 MB** (30 GiB) op en klik op `Shrink`.
- Een opstartbare USB-stick met CachyOS.
  - Zie de sectie [Een opstartbare CachyOS-USB-stick maken](/nl/installation/installation_prepare#een-opstartbare-cachyos-usb-stick-maken).

<Tabs>
    <TabItem label='Limine'>
        Limine zou de Windows EFI-partitie automatisch moeten detecteren en aan het opstartmenu moeten toevoegen. Als Windows niet in het opstartmenu verschijnt, voer dan het volgende commando uit:
        ```bash
        sudo limine-scan
        ```
    </TabItem>
    <TabItem label='systemd-boot'>
        **We moeten de Windows EFI-binaries naar de Linux EFI-partitie kopiëren, zodat de bootmanager ze kan herkennen.**

        <Steps>
        1. Zoek de **Windows EFI-partitie** met `lsblk`.

            ```sh title='Voer dit commando uit in de terminal'
            lsblk -o NAME,FSTYPE,SIZE,MOUNTPOINT
            ```
            ```sh title='Voorbeelduitvoer'
                        NAME        FSTYPE   SIZE MOUNTPOINT
            zram0               15.3G [SWAP]
            nvme0n1            476.9G
            ├─nvme0n1p1 vfat     100M
            ├─nvme0n1p2           16M
            ├─nvme0n1p3 ntfs   234.4G
            ├─nvme0n1p4 ntfs     830M
            ├─nvme0n1p5 vfat       2G /boot
            └─nvme0n1p6 btrfs  239.6G /var/tmp
            ```
            EFI-partities zijn bijna altijd geformatteerd als `FAT32/vfat`. Omdat `nvme0n1p1` geen Linux-mountpoint heeft, kunnen we aannemen dat dit de Windows EFI-partitie is.

        2. Mount de Windows EFI-partitie tijdelijk.

            ```sh
            sudo mkdir /mnt/WinBoot
            sudo mount /dev/nvme0n1p1 /mnt/WinBoot # Vervang `nvme0n1p1` door de naam van de Windows EFI-partitie.
            ```

        3. Kopieer de EFI-binaries van de **Windows EFI-partitie** naar de **Linux EFI-partitie**.

            ```sh
            sudo cp -r /mnt/WinBoot/EFI/Microsoft/ /boot/EFI
            ```

        4. Unmount de eerder gemounte partitie. Windows zou bij de volgende keer opstarten in het opstartmenu moeten verschijnen.

            ```sh
            sudo umount /mnt/WinBoot
            sudo rm -r /mnt/WinBoot
            ```

        </Steps>
    </TabItem>

    <TabItem label='GRUB (alleen voor oudere installaties)'>
        :::tip[CachyOS schakelt os-prober standaard in.]
        :::
        **GRUB gebruikt os-prober om de Windows EFI-partitie automatisch te detecteren en aan het opstartmenu toe te voegen.**

        <Steps>
        1. Installeer **os-prober**.

            ```sh
            sudo pacman -S os-prober
            ```

        2. Schakel **os-prober** in het configuratiebestand van GRUB in.

            ```sh title='Druk op CTRL+S om op te slaan en op CTRL+Q om Micro af te sluiten'
            sudo micro /etc/default/grub
            # /etc/default/grub
            # Probing for other operating systems is disabled for security reasons. Read
            # documentation on GRUB_DISABLE_OS_PROBER, if still want to enable this
            # functionality install os-prober and uncomment to detect and include other
            # operating systems.
            GRUB_DISABLE_OS_PROBER=false

            ```

        3. Werk grub.cfg bij, nu met **os-prober**.
            ```sh
            sudo grub-mkconfig -o /boot/grub/grub.cfg
            ```

            **Windows zou nu aan het opstartmenu moeten zijn toegevoegd.**

        </Steps>
    </TabItem>
</Tabs>
