## Toepassingen:
- **netwerken**

Een root session staat niet toe dat een VM poorten doorstuurt en gebruikt in plaats daarvan **NAT**.
Dit betekent dat je VM de buitenwereld wel kan zien, maar de buitenwereld je VM niet kan zien en
in plaats daarvan je pc ziet. Dat is prima, behalve als je van buiten je pc direct verbinding wilt
maken met je VM (bijvoorbeeld via ssh). Dat kan dan niet, omdat er niets is om verbinding mee te maken.

- **3D-acceleratie via vertaling**

Een root session staat niet toe dat VMM de render node `/dev/dri/renderD128` gebruikt en
beperkt `qemu-cli` sterk, omdat een gewone gebruiker nauwelijks gebruik kan maken van root qemu.

## User Session inschakelen:
Het is heel eenvoudig: klik in het hoofdvenster van **VMM** op `File -> Add Connection...`
en selecteer in het dropdownmenu `Hypervisor:` de optie `QEMU/KVM user session`. Je kunt nu
je VM's aanmaken zoals uitgelegd in [QEMU en VMM instellen](/nl/virtualization/qemu_and_vmm_setup),
maar dan in User-modus in plaats van Root-modus.
