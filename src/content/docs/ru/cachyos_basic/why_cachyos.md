---
title: Почему CachyOS?
description: Почему CachyOS может вам подойти
---

CachyOS — это полноценная и отточенная система на базе Arch Linux с удобным установщиком, предварительно настроенными рабочими окружениями и оптимизациями производительности, которые не вредят пользовательскому опыту и безопасности системы.

Ниже перечислены некоторые из ключевых особенностей CachyOS, обеспечивающих улучшенный опыт использования.

## Оптимизированные пакеты и репозитории

CachyOS предлагает большой выбор **[оптимизированных пакетов](<https://packages.cachyos.org/>)** для различных конфигураций оборудования, включая системы `x86-64-v3`, `x86-64-v4` и `Zen4+`, что повышает общую производительность.

Для получения дополнительной информации ознакомьтесь с разделом [**Оптимизированные репозитории.**](/ru/features/optimized_repos)

## Специальное ядро, настроенное на производительность и стабильность

Помимо базового набора патчей ядра CachyOS, который настраивает различные параметры для улучшения отзывчивости системы, CachyOS выборочно применяет наборы патчей, которые ещё не были включены в основную ветку или не входят в стабильную версию ядра.

Эти патчи проходят внутреннее тестирование перед выпуском для пользователей, чтобы гарантировать, что стабильность системы не пострадает. Полный список патчей, предоставляемых CachyOS, см. в разделе [Ядро](/ru/features/kernel).

## Поддержка кастомного планировщика ЦП

По умолчанию EEVDF настроен так, чтобы справедливо распределять доступное время ЦП между всеми задачами, и в основном он ориентирован на рабочие нагрузки, требующие высокой пропускной способности. Ядро CachyOS [**настраивает некоторые параметры EEVDF**](https://github.com/CachyOS/linux/blob/6.15/cachy/kernel/sched/fair.c#L79-81), чтобы повысить интерактивность рабочего стола.

Однако EEVDF по своей сути не был предназначен для обеспечения интерактивности. Учитывая это, CachyOS поставляет ядра с патчем
[BORE (Burst-Oriented Response Enhancer)](https://github.com/firelzrd/bore-scheduler), который улучшает EEVDF для повышения интерактивности при высоких нагрузках.

В версии 6.12 в ядре Linux появилась возможность «горячего» подключения планировщиков BPF и замены EEVDF на другой планировщик.

Для получения дополнительной информации о ядрах, предлагаемых CachyOS, и планировщиках sched-ext см. разделы [Ядро](/ru/features/kernel) и [sched-ext](/ru/configuration/sched-ext).

## Распознавание оборудования

CachyOS включает собственный инструмент распознавания оборудования, который автоматически определяет и устанавливает необходимые драйверы и пакеты для каждой системы, упрощая процесс настройки после установки.

## Приложения CachyOS

По умолчанию CachyOS предоставляет собственный набор приложений, таких как CachyOS Hello и CachyOS Package Installer.

Список приложений, которые CachyOS в настоящее время разрабатывает и поддерживает:

- [**CachyOS Kernel Manager**](https://github.com/CachyOS/kernel-manager): Удобная установка ядер из репозитория или настройка собственного ядра с добавлением своих патчей, а также управление фреймворком sched-ext через [**scx_loader**](<https://github.com/sched-ext/scx/tree/main/rust/scx_loader>).
- [**CachyOS Hello**](https://github.com/CachyOS/CachyOS-Welcome): Приложение для управления настройками, применения исправлений, установки пакетов и получения дополнительной информации о CachyOS.
- [**CachyOS Package Installer**](https://github.com/CachyOS/packageinstaller): Графический интерфейс для простой установки приложений.
- [**cachyos-rate-mirrors**](https://github.com/CachyOS/rate-mirrors): Автоматически ранжирует зеркала Arch и CachyOS для оптимальной скорости загрузки с помощью pacman.
- [**systemd-boot-manager**](https://github.com/CachyOS/systemd-boot-manager): Автоматически создаёт новые записи для systemd-boot-manager, которые можно легко настроить в `/etc/sdboot-manage.conf`.
