CachyOS — это ориентированный на производительность дистрибутив Arch Linux, созданный для обеспечения стабильной, эффективной и удобной для пользователя вычислительной среды. Он предлагает всю мощь и гибкость системы с плавающими обновлениями (rolling-release), дополненную продвинутыми оптимизациями и собственным набором инструментов, который упрощает работу как для новых, так и для опытных пользователей.

## Производительность и оптимизация

### Оптимизированные пакеты и репозитории

CachyOS предоставляет большой выбор **[оптимизированных пакетов](https://packages.cachyos.org/)**, специально скомпилированных для различных современных архитектур ЦП. Это включает поддержку систем `x86-64-v3`, `x86-64-v4` и `Zen4+`, гарантируя, что ваше программное обеспечение будет создано для полного использования возможностей вашего оборудования, что обеспечит значительный прирост производительности.

Для более подробного ознакомления с нашими оптимизированными репозиториями см. наше подробное руководство по **[оптимизированным репозиториям](/ru/features/optimized_repos)**.

### Специальное ядро, настроенное на производительность и стабильность

Помимо базового набора патчей для ядра CachyOS, который настраивает различные параметры ядра для улучшения отзывчивости рабочего стола, CachyOS выборочно включает наборы патчей, которые еще не были включены в основную ветку или не входят в стабильную ревизию ядра.

Поэтому эти патчи проходят внутреннее тестирование перед выпуском для пользователей, чтобы гарантировать, что стабильность не будет затронута. Полный список патчей, которые предоставляет CachyOS, см. в разделе [Ядро](/ru/features/kernel).

### Поддержка передовых планировщиков ЦП

CachyOS поставляет ядра с последними оптимизациями планировщика ЦП, чтобы обеспечить плавную и интерактивную работу рабочего стола даже при высокой нагрузке.

* **EEVDF (планировщик ядра Linux по умолчанию):** Хотя он отлично подходит для общей пропускной способности, ядро CachyOS включает в себя пользовательские **[настройки EEVDF](https://github.com/CachyOS/linux/blob/6.15/cachy/kernel/sched/fair.c#L79-81)** для улучшения отзывчивости рабочего стола.

* **[BORE](https://github.com/firelzrd/bore-scheduler) (Burst-Oriented Response Enhancer):** Для пользователей, которым нужна максимальная интерактивность, наши ядра поддерживают планировщик BORE — набор патчей, который улучшает EEVDF для обеспечения более плавной работы при интенсивных нагрузках.

Для получения дополнительной информации о ядрах, предлагаемых CachyOS, и фреймворке sched-ext см. документацию по **[ядру](/ru/features/kernel)** и **[sched-ext](/ru/configuration/sched-ext)**.

## Удобные инструменты и кастомизация

### [Автоматическое определение оборудования](/ru/features/chwd)

CachyOS включает в себя специальный инструмент определения оборудования, который автоматически обнаруживает и устанавливает необходимые драйверы и пакеты для вашей системы. Это избавляет от необходимости ручного поиска драйверов, экономя ваше время и усилия после установки.

### Настраиваемый процесс установки

Установщик CachyOS позволяет пользователям настраивать свою систему, выбирая окружение рабочего стола, пакеты, файловую систему, загрузчик, ядро и многое другое в соответствии со своими потребностями:

- [Окружения рабочего стола](/ru/installation/desktop_environments/)
- [Загрузчики](/ru/installation/boot_managers/)
- [Варианты ядра](/ru/features/kernel#варианты)
- [Файловые системы](/ru/installation/filesystem)
- [Пользовательские пакеты для включения во время установки](https://github.com/CachyOS/cachyos-calamares/blob/cachyos-limine-qt6/src/modules/netinstall/netinstall.yaml)

### Собственные приложения CachyOS

CachyOS разрабатывает и поддерживает собственный набор приложений для упрощения управления системой и улучшения вашего опыта.

Список приложений, которые CachyOS в настоящее время разрабатывает и поддерживает:

-   **[CachyOS Hello](https://github.com/CachyOS/CachyOS-Welcome):** Приветственное приложение для управления настройками, применения исправлений и установки пакетов.
-   **[CachyOS Package Installer](https://github.com/CachyOS/packageinstaller):** Графический пользовательский интерфейс (GUI) для простой установки приложений.
-   **[CachyOS Kernel Manager](https://github.com/CachyOS/kernel-manager):** Легко устанавливайте ядра из репозитория, настраивайте свои собственные и управляйте фреймворком `sched-ext`.
-   **[cachyos-rate-mirrors](https://github.com/CachyOS/rate-mirrors):** Автоматически ранжирует зеркала Arch и CachyOS для оптимальной скорости загрузки с помощью `pacman`.
-   **[systemd-boot-manager](https://github.com/CachyOS/systemd-boot-manager):** Автоматически создает новые загрузочные записи для `systemd-boot`, которые можно легко настроить через `/etc/sdboot-manage.conf`.
