26.06
----

**Новые возможности:**

* **Пакеты:**
  * Python теперь использует расширенный PGO для повышения производительности
  * Добавлен [патч для GCC](https://www.phoronix.com/news/GCC-x86-Generic-Mispredict) для настройки общего x86 с учётом неправильных предсказаний ветвлений, улучшающий оценку GCC стоимости неправильных предсказаний ветвлений на современных ЦП Intel и AMD
  * Исправлена регрессия, обнаруженная в Phoronix Benchmarks при использовании OpenBLAS на ЦП с большим числом ядер
  * `proton-cachyos` переименован в `proton-cachyos-native`
* **pacman:** Добавлена [сетевая изоляция для scriptlets и hooks](https://github.com/CachyOS/pacman/commit/4056cd687f6379e61e7decb9b66e9b57cb3949a9)
* **Установщик:**
  * Добавлен вариант рабочего стола CachyOS Hyprland Noctalia и превью-видео
  * `paru` удалён из установки; в качестве альтернативы пользователям рекомендуется использовать [Shelly](/ru/configuration/post_install_setup/#обновление-системы) через его GUI или CLI
  * Добавлен SDDM в качестве менеджера дисплея для MangoWM
  * GNOME System Monitor заменён на Resources
  * `realtime-privileges` добавлен в группу аудио пакетов
  * Улучшено определение раскладки и варианта клавиатуры в live-сессии
* **CachyOS-Welcome:**
  * Добавлена поддержка DNS over QUIC (DoQ) через `blocky`
  * Добавлена отдельная страница Troubleshooting
  * Добавлена поддержка терминала Ptyxis
  * Добавлены азербайджанский и греческий переводы
  * Добавлены readme и страницы о вкладе на французском языке
  * Обновлены итальянский, немецкий, французский, японский и болгарский переводы
* **chwd:**
  * Добавлен турецкий перевод
  * `cachyos-handheld` удалён из списков пакетов для портативных устройств
  * Устраняются конфликты драйверов на системах с несколькими GPU, требующих несовместимых веток драйверов (например, смешанные поколения NVIDIA): устанавливается лучший общий драйвер или используется драйвер основного GPU
  * Добавлен 32-разрядный Vulkan-драйвер для виртуальных машин
* **cachyos-settings:** Применены 15-секундные тайм-ауты запуска и 10-секундные тайм-ауты завершения работы для пользовательских служб, что предотвращает 90-секундные задержки при завершении работы

**Исправления:**

* **Установщик:**
  * Исправлен порядок раскладок клавиатуры и обработка конфигурации `locale1`
  * Исправлено копирование корректной конфигурации pacman в установленную систему
  * Удаляются оставшиеся каталоги `/etc/calamares` после установки
  * Очистка Calamares перенесена после всех скриптов установки
  * Удалён избыточный шаг установки Limine после установки
* **CachyOS-Welcome:**
  * Предотвращено падение при выборе "Install Apps" без установленного `cachyos-pi`; кнопка теперь скрыта, если недоступна
  * Исправлено падение при невозможности прочитать или разобрать сохранённый файл настроек; при сбое настройки теперь сбрасываются к значениям по умолчанию
  * Исправлено обнаружение твиков (включая `graphical-session.target.wants`) и глобальное отключение твиков пользовательских служб через polkit
* **chwd:**
  * Исправлены vendor ID виртуальных машин
  * Удалена ненужная активация службы `fprintd`
  * Исправлена защита от удаления Mesa

**Новые возможности:**

* **Установщик:**
  * Shelly теперь заменил Octopi в качестве GUI-менеджера пакетов

  * Очищен и модернизирован набор пакетов GNOME
  * Добавлен вариант установки `MangoWM` с оболочкой `DMS`
* **CachyOS-Welcome:**
  * Добавлена поддержка DNS-over-HTTPS (DoH) через `blocky`
  * Добавлена поддержка пользовательских DNS-серверов и автоматический индикатор/сброс DHCP

  * Добавлена полная поддержка навигации с клавиатуры для доступности
  * PNG-иконки социальных сетей заменены на чёткие SVG с учётом HiDPI
  * `wezterm` добавлен в помощник терминалов
* **chwd:**
  * Добавлено нативное обнаружение USB-устройств (через libusb/sysfs) и определение типа корпуса
  * Добавлена поддержка интеграции отпечатков пальцев (`fprint`) с sudo
  * Добавлено определение семейства/модели ЦП для поддержки `intel-lpmd`
  * **Портативные устройства:** Добавлены точные паттерны для Xbox ROG Ally
  * **Сеть:** Добавлен Wi-Fi профиль Marvell AVASTAR 88W8897 (Surface Pro 4)
  * Разделены профили NVIDIA для ноутбуков и настольных систем
  * Разделены и обновлены профили для виртуальных машин
* **cachyos-settings:** Переключён планировщик ввода-вывода NVMe по умолчанию с `none` на `kyber`

**Исправления:**

* **Установщик:**
  * Способ разбиения на разделы теперь выводится в журнал отладки
  * Устаревшие пакеты микрокода теперь удаляются при переиспользовании существующего загрузочного раздела
* **CachyOS-Welcome:**
  * Исправлена проверка подключения, которая ошибочно возвращала true при сбое ping
  * Иконки внешних ссылок теперь видны в тёмных темах
  * Предотвращён одновременный запуск нескольких экземпляров приложения-приветствия
  * Добавлен `StartupWMClass` для улучшения сопоставления окон `.desktop`
* **chwd:**
  * Удалён хук `kms` из `mkinitcpio.conf` на непортативных настольных системах для исправления конфликтов драйверов NVIDIA
  * Поиск установленных ядер в профилях NVIDIA стал точнее
  * Удалена принудительная Xorg-сессия из профилей NVIDIA 470xx (исправляет совместимость с `plasma-login-manager`)
  * Удалена устаревшая `WaylandEnable=false` для GDM в профилях виртуальных машин
  * Исправлены ложные срабатывания определения портативных устройств (например, конкретные ноутбуки MSI принимались за MSI Claw)
* **cachyos-settings:**
  * Удалено управление питанием `S01x` из-за проблем с драйвером NVIDIA 595
  * Отключён `AggressiveVblank` из-за проблем, связанных с VR, в драйвере NVIDIA

26.01
----

**Новые возможности:**

* **Установщик:**
  * Выбор загрузчика перенесён в Calamares; управление теперь сосредоточено в одном пакете.
  * Определение архитектуры теперь выполняется **до** установки базовой системы для уменьшения объёма загрузки.
  * GRUB теперь использует LUKS2 для шифрования.
  * Добавлен флаг --needed при вызове pacman во избежание двойной установки пакетов.
  * Используется однопроходное сжатие на NVMe для Btrfs
  * Удалены зависимости xorg для рабочих окружений на Wayland.
* **ISO:**
  * Переключён на `plasma-login-manager` для среды ISO.
  * ISO теперь содержит как стабильное, так и LTS-ядро. По умолчанию выбирается стабильное ядро.
  * Сеанс ISO переключён с X11 на Wayland.
* **Netinstall:**
  * Установки Plasma теперь используют `plasma-login-manager` вместо SDDM.
  * Niri теперь использует `noctalia-shell` и обновлённые конфигурационные файлы.
  * Упрощён процесс установки GNOME.
* **Слайды:** Исправлены опечатки в слайдах Calamares и добавлен новый слайд, демонстрирующий вики.
* **Зеркала:** Страница состояния зеркал (<https://packages.cachyos.org/mirrors>) теперь отображает состояние синхронизации зеркал CachyOS.
* **cachyos-settings:** Включён `EnableAggressiveVblank` для модуля NVIDIA. Это сокращает время в верхней половине прерывания для низколатентных прерываний дисплея.
* **chwd:**
  * Устанавливает `nouveau-fw` для включения поддержки VA-API в Nouveau для видеокарт NVIDIA серии Kepler.
  * Добавлена поддержка AI-SDK для нескольких новых видеокарт AMD.
  * HHD заменён на `steamos-manager` и `inputplumber`.
* **Proton-CachyOS:**
  * Добавлена поддержка FSR4 MLFG (машинное обучение для генерации кадров); включается автоматически при использовании `PROTON_FSR4_[RDNA3_]UPGRADE`
  * Добавлена поддержка модуля `d7vk`. Можно включить через `PROTON_DXVK_DDRAW=1`
  * Импортированы патчи для тактильной обратной связи DualSense
  * Добавлен `WINE_BLOCK_HOSTS` для блокировки подключения Wine к определённым доменам
  * Автоматическое включение `ENABLE_HDR_WSI=1` при использовании `winewayland` на дискретных видеокартах NVIDIA
  * Исправлены проблемы с раскладкой клавиатуры при использовании `winewayland.drv`
  * Удалён давний патч, вызывавший снижение 1% минимального FPS
  * Патч `protonfixes` для улучшения обработки выбора пресетов DLSS и перенаправления `libxess_dx11.dll`
  * proton-cachyos-slr теперь используется по умолчанию в "gaming-meta". Нативная версия по-прежнему поддерживается.


**Исправления:**

* **Limine:** Увеличен размер загрузочного раздела до 4192МБ для соответствия высоким требованиям `limine-snapper-sync`.
* **Установщик:**
  * Установщик теперь блокирует продолжение, если раздел EFI слишком мал при использовании вариантов "рядом с" или "заменить раздел".
  * Исправлена проблема, когда при выборе рабочего окружения, переходе на следующий шаг, возврате назад и выборе другого окружения оба оказывались выбранными одновременно.
* **chwd:** Удалена переменная окружения, принудительно задававшая `libva-nvidia-driver`, так как она вызывала проблемы на двухвидеокарточных системах.
* **cachyos-hello**: Исправлена проблема, при которой cachy-update отображался как отключённый, хотя был включён.
* **Контроллер**: Исправлен ввод нескольких контроллеров путём обновления правил ввода до последней версии.
* **Framework 16 (Zen5)**: Исправлена проблема зависания сеанса при вводе текста в Calamares

25.08
----

**Новые возможности:**

* **Сервисы:** Добавлен **packages.cachyos.org** — поиск по пакетам, аналогичный сайту Arch Linux, с возможностью исключить пакеты CachyOS.
* **Ядро:** Установщик теперь дополнительно устанавливает **linux-cachyos-lts** в качестве вторичного/резервного ядра. Рекомендуется по-прежнему использовать стабильное ядро.
* **ISO:** Live ISO переключён на LTS-ядро из-за существующих проблем со стабильным ядром, что повышает надёжность загрузки.
* **Рабочее окружение:** Добавлен **Niri** как вариант рабочего окружения с несколькими предварительно настроенными конфигурационными файлами.
* **NVIDIA:** Включён режим сна **S0ix** на поддерживаемом оборудовании для современного энергосберегающего режима ожидания.
* **GRUB:** Загрузка снимков теперь автоматически включается и настраивается при использовании **Btrfs** в качестве корневой файловой системы.
* **Твики:** **Cachy-Update** интегрирован в страницу твиков приложения Welcome. Cachy-Update добавляет таймер и индикатор в системном трее для уведомлений об обновлениях и позволяет обновляться одним нажатием.
* **Proton-CachyOS:**
    - Добавлена загрузка DLSS-библиотек (версия **310.3.0**), аналогично загрузчику FSR4. Используйте переменную окружения `PROTON_DLSS_UPGRADE=1` для включения.
    - Добавлена переменная окружения `PROTON_DLSS_INDICATOR=1` для включения HUD DLSS.
    - Добавлена загрузка XeSS-библиотек (версия **2.1.0**), аналогично загрузчику DLSS. Используйте `PROTON_XESS_UPGRADE=1` для включения.
    - Добавлен `PROTON_FSR4_RDNA3_UPGRADE` для видеокарт RDNA3. Выполняет то же, что и `PROTON_FSR4_UPGRADE`, но также задаёт ряд других необходимых переменных.
    - Добавлены полные реализации библиотек Nvidia, отсутствующих в Proton. Должно помочь с включением таких опций, как PhysX, в играх, где они ранее были недоступны. **_CachyOS - Kernel - Manager_**
Также мы рады объявить о нашем CachyOS-Kernel-Manager.
В нём есть возможность установить ядро из репозитория, а также сконфигурировать в GUI собственную сборку ядра, что делает очень лёгкой настройку под себя.

Следующие параметры можно выбрать для компиляции ядра:

- Планировщик (BMQ, BORE, cacULE, cfs, PDS, TT)
- NUMA отключён или включён
- KBUILD CFLAGS (-O3 или -O2)
- Установить performance governor по умолчанию
- Включить BBR2
- Tickrate (500Hz, 600Hz, 750Hz, 1000Hz)
- tickless (idle, perodic, full)
- Отключить MQ-Deadline I/O Scheduler
- Отключить Kyber I/O Scheduler
- Включить или отключить MG-LRU
- Включить или отключить DAMON
- Включить или отключить Speculative page fault
- Включить или отключить LRNG (Linux Random Number Generator)
- Применить автоматическую оптимизацию ядра (автоматически определяет ваш CPU March)
- Применить выбор оптимизации ядра (вы увидите список различных CPU-Marches и можете выбрать свой номером)
- Отключить debug (уменьшает размер ядра)
- Включить или отключить nf cone
- Включить LTO (Full, Thin, No)
