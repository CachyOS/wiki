26.03
----

**Новые возможности:**

* **Установщик:**
  * Добавлена поддержка отображения GIF/WebP-анимаций в разделе выбора рабочего стола для демонстрации окружений. Включено для Plasma, GNOME, Niri и COSMIC
  * Добавлена поддержка JPEG XL в разделе выбора рабочего стола для уменьшения размеров изображений
  * Cachy-Update теперь включён по умолчанию для установок GNOME и KDE
  * Улучшена логика установки микрокода — теперь она определяет оборудование и устанавливает подходящий микрокод вместо установки обоих с последующим удалением ненужного
  * Улучшено сообщение об ошибке при слишком маленьком разделе EFI
  * Список рабочих окружений отсортирован от простых и доступных решений до более продвинутых, таких как оконные менеджеры
* **CachyOS-Welcome:**
  * Добавлена кнопка для простой установки и включения «Winboat» — простой виртуальной машины Windows на базе Docker
  * Добавлена поддержка DNS-сервера FFMUC в выборе DNS
  * Добавлен украинский перевод
* **chwd:** Значительно уменьшен размер initramfs для конфигураций с дискретной видеокартой NVIDIA
* **linux-cachyos:** Вместо генерации `0001-cachyos-base-all.patch` теперь для каждого выпуска патченого ядра создаётся релиз в репозитории Linux
* **cachyos-rate-mirrors:** Значительно улучшен опыт для пользователей из Китая и России: добавлена корректная проверка перед оценкой зеркал
* **cachyos-settings:** Добавлена поддержка автоматической установки беспроводного регуляторного домена на основе часового пояса
* **website:** Дизайн сайта переработан и улучшен в соответствии с современными стандартами
* **GitHub:** Добавлены шаблоны задач в важные GitHub-репозитории для повышения качества отчётов об ошибках и помощи пользователям
* **Зеркала:** Новые зеркала в России (jura12, cachy-arch.ru), Швеции (Zyner) и Канаде (All Things Linux)

**Исправления:**

* **Установщик:**
  * Удалена поддержка bcachefs в выборе файловой системы из-за зависимости от bcachefs-dkms
  * Исправлено шифрование при использовании LUKS2 для определённых устройств
  * Исправлено включение менеджера дисплея «ly»
* **cachyos-settings:** `cachyos-bugreport.sh` теперь скрывает IP-адрес, имя пользователя, имя хоста и MAC-адрес
* **chwd:**
  * Универсальные профили для портативных устройств и улучшенная поддержка их видеокарт
  * fwupd теперь включён для портативных устройств Lenovo


**История изменений для портативного издания (Handheld Edition):**

* **gamescope-session:** Заменён gamescope-session-plus на gamescope-session-cachyos, основанный на форке Valve's gamescope-session
  * Включает обновления прошивок для Steam Deck и Lenovo Legion Go
* **plasma-login-manager:** SDDM заменён на plasma-login-manager в качестве менеджера входа
* **bootloaders:** Limine теперь выбран по умолчанию с автоматическими снимками. systemd-boot по-прежнему доступен для выбора
* **Установщик:** Calamares для портативных устройств объединён с версией для настольных ПК
* **ISO:** ISO теперь использует Wayland вместо X11

26.01
----

**Новые возможности:**

* **Установщик:**
  * Выбор загрузчика перенесён в Calamares; управление теперь сосредоточено в одном пакете.
  * Определение архитектуры теперь выполняется **до** установки базовой системы для уменьшения объёма загрузки.
  * GRUB теперь использует LUKS2 для шифрования.
  * Добавлен флаг --needed при вызове pacman во избежание двойной установки пакетов.
  * Используется однопроходное сжатие на NVMe для Btrfs
  * Удалены зависимости xorg для рабочих окружений на Wayland.
* **ISO:**
  * Переключён на `plasma-login-manager` для среды ISO.
  * ISO теперь содержит как стабильное, так и LTS-ядро. По умолчанию выбирается стабильное ядро.
  * Сеанс ISO переключён с X11 на Wayland.
* **Netinstall:**
  * Установки Plasma теперь используют `plasma-login-manager` вместо SDDM.
  * Niri теперь использует `noctalia-shell` и обновлённые конфигурационные файлы.
  * Упрощён процесс установки GNOME.
* **Слайды:** Исправлены опечатки в слайдах Calamares и добавлен новый слайд, демонстрирующий вики.
* **Зеркала:** Страница состояния зеркал (<https://packages.cachyos.org/mirrors>) теперь отображает состояние синхронизации зеркал CachyOS.
* **cachyos-settings:** Включён `EnableAggressiveVblank` для модуля NVIDIA. Это сокращает время в верхней половине прерывания для низколатентных прерываний дисплея.
* **chwd:**
  * Устанавливает `nouveau-fw` для включения поддержки VA-API в Nouveau для видеокарт NVIDIA серии Kepler.
  * Добавлена поддержка AI-SDK для нескольких новых видеокарт AMD.
  * HHD заменён на `steamos-manager` и `inputplumber`.
* **Proton-CachyOS:**
  * Добавлена поддержка FSR4 MLFG (машинное обучение для генерации кадров); включается автоматически при использовании `PROTON_FSR4_[RDNA3_]UPGRADE`
  * Добавлена поддержка модуля `d7vk`. Можно включить через `PROTON_DXVK_DDRAW=1`
  * Импортированы патчи для тактильной обратной связи DualSense
  * Добавлен `WINE_BLOCK_HOSTS` для блокировки подключения Wine к определённым доменам
  * Автоматическое включение `ENABLE_HDR_WSI=1` при использовании `winewayland` на дискретных видеокартах NVIDIA
  * Исправлены проблемы с раскладкой клавиатуры при использовании `winewayland.drv`
  * Удалён давний патч, вызывавший снижение 1% минимального FPS
  * Патч `protonfixes` для улучшения обработки выбора пресетов DLSS и перенаправления `libxess_dx11.dll`
  * proton-cachyos-slr теперь используется по умолчанию в «gaming-meta». Нативная версия по-прежнему поддерживается.


**Исправления:**

* **Limine:** Увеличен размер загрузочного раздела до 4192МБ для соответствия высоким требованиям `limine-snapper-sync`.
* **Установщик:**
  * Установщик теперь блокирует продолжение, если раздел EFI слишком мал при использовании вариантов «рядом с» или «заменить раздел».
  * Исправлена проблема, когда при выборе рабочего окружения, переходе на следующий шаг, возврате назад и выборе другого окружения оба оказывались выбранными одновременно.
* **chwd:** Удалена переменная окружения, принудительно задававшая `libva-nvidia-driver`, так как она вызывала проблемы на двухвидеокарточных системах.
* **cachyos-hello**: Исправлена проблема, при которой cachy-update отображался как отключённый, хотя был включён.
* **Контроллер**: Исправлен ввод нескольких контроллеров путём обновления правил ввода до последней версии.
* **Framework 16 (Zen5)**: Исправлена проблема зависания сеанса при вводе текста в Calamares

  * Добавлена поддержка Xbox ROG Ally/X

  * Используется вариант `btrfs-overlayfs` хука systemd

25.08
----

**Новые возможности:**

* **Сервисы:** Добавлен **packages.cachyos.org** — поиск по пакетам, аналогичный сайту Arch Linux, с возможностью исключить пакеты CachyOS.
* **Ядро:** Установщик теперь дополнительно устанавливает **linux-cachyos-lts** в качестве вторичного/резервного ядра. Рекомендуется по-прежнему использовать стабильное ядро.
* **ISO:** Live ISO переключён на LTS-ядро из-за существующих проблем со стабильным ядром, что повышает надёжность загрузки.
* **Рабочее окружение:** Добавлен **Niri** как вариант рабочего окружения с несколькими предварительно настроенными конфигурационными файлами.
* **NVIDIA:** Включён режим сна **S0ix** на поддерживаемом оборудовании для современного энергосберегающего режима ожидания.
* **GRUB:** Загрузка снимков теперь автоматически включается и настраивается при использовании **Btrfs** в качестве корневой файловой системы.
* **Твики:** **Cachy-Update** интегрирован в страницу твиков приложения Welcome. Cachy-Update добавляет таймер и индикатор в системном трее для уведомлений об обновлениях и позволяет обновляться одним нажатием.
* **Proton-CachyOS:**
    - Добавлена загрузка DLSS-библиотек (версия **310.3.0**), аналогично загрузчику FSR4. Используйте переменную окружения `PROTON_DLSS_UPGRADE=1` для включения.
    - Добавлена переменная окружения `PROTON_DLSS_INDICATOR=1` для включения HUD DLSS.
    - Добавлена загрузка XeSS-библиотек (версия **2.1.0**), аналогично загрузчику DLSS. Используйте `PROTON_XESS_UPGRADE=1` для включения.
    - Добавлен `PROTON_FSR4_RDNA3_UPGRADE` для видеокарт RDNA3. Выполняет то же, что и `PROTON_FSR4_UPGRADE`, но также задаёт ряд других необходимых переменных.
    - Добавлены полные реализации библиотек Nvidia, отсутствующих в Proton. Должно помочь с включением таких опций, как PhysX, в играх, где они ранее были недоступны. Также можно включить их по отдельности: `PROTON_NVIDIA_NVCUDA`, `PROTON_NVIDIA_NVENC`, `PROTON_NVIDIA_NVML` и `PROTON_NVIDIA_NVOPTIX`.
    - Добавлено кэширование шейдеров для отдельных игр, включено по умолчанию, можно отключить через `PROTON_LOCAL_SHADER_CACHE=0`. Шейдеры будут кэшироваться в `<steamlibrary>/shadercache/<appid>` для каждой игры, аналогично включённому предварительному кэшированию шейдеров. Возможны подтормаживания при первом запуске игр, пока кэш шейдеров пересоздаётся, но закешированные шейдеры не будут вытесняться из-за ограничения размера кэша.
    - Добавлен [dxvk-sarek](https://github.com/pythonlover02/DXVK-Sarek) как опциональная замена DXVK для старых видеокарт без полноценной поддержки Vulkan 1.3. Используется ветка `async`, поэтому **НЕ СЛЕДУЕТ** применять в играх с античитом или в многопользовательских играх. Предупреждение принято. Используйте `PROTON_DXVK_SAREK=1` для включения.
    - Добавлен `PROTON_FSR3_UPGRADE` для обновления DLL FSR 3.1 до более новых версий.

**Исправления:**

* **Limine:**
    - Исправлена ошибка `limine bios-install /dev/sdaX` при выборе точки монтирования **/boot** в качестве расположения загрузчика на системах MBR.
    - Исправлено неинициализированное значение пути `bootLoader`, вызывавшее сбои при установке на системах MBR, когда расположение загрузчика не было явно выбрано.
    - Добавлено предупреждение об использовании флага **bios-grub** на загрузочном разделе, что может вызвать ошибку «Stage 3 file not found».
    - Исправлена загрузка в двойной конфигурации с Windows для установок на BIOS.
    - Исправлен сбой при загрузке снимков Btrfs при использовании **GNOME (GDM)**.
* **Запуск установщика:** Добавлены резервные IP-адреса для проверки подключения на случай недоступности **cachyos.org**.

25.07
----

**Новые возможности:**

- **Оболочка**: При установке теперь можно выбрать оболочку пользователя: fish, zsh или bash. По умолчанию по-прежнему используется fish.
- **chwd**: Устанавливает plasma-x11 для устаревших драйверов NVIDIA
- **Netinstall**: Добавлен fwupd для KDE Plasma и Gnome
- **mesa-git**: Добавлена поддержка AMD Anti Lag
- **firefox**: Представлена альтернативная версия Firefox — «firefox-pure», включающая улучшения через профиль userjs. Также добавлен «cachyos-firefox-settings», устанавливаемый поверх Firefox.
- **Proton-CachyOS**:
  - Импортированы коммиты wine-wayland из основного репозитория
  - Добавлена переменная окружения «PROTON_FSR4_UPGRADE», которая автоматически загружает последнюю DLL FSR4 и заменяет её для автоматического апгрейда в играх с поддержкой FSR 3.1
  - Добавлено множество Wayland-патчей из основного репозитория Wine, выпущенных после Wine 10.0.
  - Добавлены патчи для улучшения интеграции с античитом. Спасибо NelloKudo
  - Добавлены патчи для AMD Anti Lag 2 в vkd3d-proton и wine
  - Обновлён umu-protonfixes до последнего коммита

**Исправления:**

- **Keyring**: Улучшена обработка установки keyring во избежание проблем с несколькими повторными попытками.
- **systemd-oomd**: Отключён systemd-oomd, так как возникали проблемы совместной работы с le9, из-за чего приложения завершались слишком рано

**История изменений для портативного издания (Handheld Edition):**

- **handheld-settings**: Импортированы различные настройки SteamOS в портативное издание
- **pipewire**: Установлен минимальный квант 256
- **SteamDeck-OLED**: Устанавливается galileo-mura для Steam Deck OLED
- **Lenovo Legion Go S**: Добавлена поддержка Lenovo Legion Go S

25.05
----

**Новые возможности:**

- **ISO**: Добавлено автоматическое определение при загрузке ISO для идентификации видеокарты NVIDIA и загрузки подходящего модуля (например, nvidia-open, nvidia) — улучшена поддержка серии 10xx и старше.
- **Plymouth**: Добавлена новая анимация Plymouth.
  - Спасибо Eren ([https://github.com/erenyldz89](https://github.com/erenyldz89)) за работу над этим!
- **Браузер**: Cachy-Browser упразднён. Теперь по умолчанию устанавливается Firefox. Руководство по переносу профилей в Firefox (и его форки) можно найти здесь: [https://wiki.cachyos.org/support/faq/#migrating-your-profile-from-cachy-browser-to-firefox](https://wiki.cachyos.org/support/faq/#migrating-your-profile-from-cachy-browser-to-firefox)
- **netinstall**: Добавлены kcalc, filelight, plymouth-kcm и kio-admin в установку KDE.
- **mkinitcpio**: Резервный initramfs теперь отключён по умолчанию. Это позволяет существенно сэкономить дисковое пространство.
- **Зеркала**: Добавлено новое зеркало со скоростью 10 Гбит/с в Бангладеш. Спасибо Limda за хостинг!
- **Proton**:
  - Перебазированы почти все патчи из **Proton CachyOS 9.0**.
  - Включён Wayland-драйвер для сборок Steam Linux Runtime. Включите с помощью `PROTON_ENABLE_WAYLAND=1`. Спасибо [GloriousEggroll](https://github.com/GloriousEggroll) за реализацию.
  - Добавлено множество Wayland-патчей из основного репозитория Wine, выпущенных после Wine 10.0.
  - Исправлены различные проблемы с Wayland-драйвером и Vulkan-играми. Спасибо [Etaash-mathamsetty](https://github.com/Etaash-mathamsetty) за огромный вклад.
  - Добавлена заглушка `amdxc64.dll` для включения FSR4. Используйте `FSR4_UPGRADE=1` для апгрейда игр с FSR3.1 до FSR4. Ещё раз спасибо [Etaash-mathamsetty](https://github.com/Etaash-mathamsetty). Инструкции: [https://github.com/Etaash-mathamsetty/wine-builds/releases/tag/fsr4](https://github.com/Etaash-mathamsetty/wine-builds/releases/tag/fsr4)
  - Добавлены патчи для DualSense для более полного обнаружения аудиоустройств для проводной звуковой тактильной обратной связи. В некоторых играх, полагавшихся на это поведение, функциональность должна восстановиться. Спасибо [ClearlyClaire](https://github.com/ClearlyClaire) за оригинальные патчи и [Exotic0015](https://github.com/Exotic0015) за исследование начиная с **Proton CachyOS 9.0**. Апстрим: [https://gitlab.winehq.org/wine/wine/-/merge_requests/7238](https://gitlab.winehq.org/wine/wine/-/merge_requests/7238)
  - Удалён патч для Dragon Age: Inquisition, так как он не работал. Пока используйте **Proton CachyOS 9.0** для этой игры.
- **GRUB**: Добавлена новая тема GRUB. Спасибо [diegons490](https://github.com/diegons490/cachyos-grub-theme).

**Исправления:**

- **Зеркала**: Исправлена проблема, из-за которой пользователи из России не могли выполнить установку. Проблема решена отказом от CDN77, заблокированного в России.
- **kde-settings**: Отключена иконка Discover в панели задач.
- **ddcutil**: Выпущен ddcutil 2.2.1 pre-release для исправления проблемы зависания видеокарт AMD при просмотре YouTube.

**История изменений для портативного издания (Handheld Edition):**
