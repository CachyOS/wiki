## Загрузка ISO-образа

ISO-образ CachyOS можно получить из следующих источников:

*   [Сайт](<https://cachyos.org/download>)
*   [SourceForge](<https://sourceforge.net/projects/cachyos-arch/files/>)
*   [Зеркало CachyOS](<https://mirror.cachyos.org/ISO/>)

## Проверка целостности ISO-образа с помощью SHA256

:::caution[ПРЕДУПРЕЖДЕНИЕ]
Всегда выполняйте дополнительную проверку целостности ISO-образа, чтобы избежать нежелательных проблем при установке или создании загрузочного носителя.
:::

**Текущая версия ISO:** `250826`

**Хеш SHA256:** `062e14ca7747e7851c2447767c775fa39ee996b9b7e0417498a685aa23ec7b19`

<Tabs>

<TabItem label='Windows'>

<Steps>

1.  Скачайте [файл](https://mirror.cachyos.org/ISO/desktop/250826/cachyos-desktop-linux-250826.iso.sha256) с хешем SHA256 **(откройте его в текстовом редакторе, например, в Блокноте).**
2.  Откройте CMD или PowerShell от имени администратора и [перейдите](<https://www.wikihow.com/Change-Directories-in-Command-Prompt>) в каталог, где хранятся файлы ISO и SHA256.
3.  Выполните следующую команду:
    ```powershell
    # Пример:
    certUtil -hashfile cachyos-desktop-linux-250826.iso SHA256
    ```
4.  Сравните хеш, выведенный утилитой certUtil, с хешем из файла, скачанного на **шаге 1**. Если они совпадают, можно приступать к установке CachyOS.

</Steps>

</TabItem>

<TabItem label='Linux'>

<Steps>

1.  Скачайте [файл](https://mirror.cachyos.org/ISO/desktop/250826/cachyos-desktop-linux-250826.iso.sha256) с хешем SHA256.
2.  Откройте терминал, перейдите в каталог с файлом `.sha256` и выполните следующие команды:
    ```sh
    # Пример:
    cd Downloads/
    cat cachyos-desktop-linux-250826.iso.sha256
    # 062e14ca7747e7851c2447767c775fa39ee996b9b7e0417498a685aa23ec7b19
    ```
3.  Сравните вывод из **шага 2** и выполните следующую команду, чтобы проверить хеш ISO-файла:
    ```sh
    # Пример:
    sha256sum cachyos-desktop-linux-250826.iso
    ```
4.  Если хеши из **шага 2** и **шага 3** совпадают, можно приступать к установке CachyOS.

</Steps>

</TabItem>

<Steps>

## Проверка подлинности ISO-образа (Linux)

Чтобы проверить подлинность ISO-файла и убедиться, что он является официальным релизом от команды разработчиков CachyOS:

<Steps>

1.  Импортируйте GPG-ключ для проверки подлинности:

    ```shell
    gpg --keyserver hkps://keys.openpgp.org --recv-key F3B607488DB35A47
    ```

2.  Скачайте ISO-файл и его файл подписи `.sig`, а затем выполните следующую команду (заменив `full_iso_name.iso` на фактическое имя ISO-файла):
    ```shell
    gpg --verify full_iso_name.iso.sig full_iso_name.iso
    ```

    Если вы получили вывод **Good signature**, значит, ISO-файл подлинный:
    ```
    gpg: Signature made mar 26 ago 2025 14:57:27 -03
    gpg:                using RSA key 882DCFE48E2051D48E2562ABF3B607488DB35A47
    gpg: Good signature from "CachyOS <admin@cachyos.org>" [unknown]
    gpg: WARNING: This key is not certified with a trusted signature!
    gpg:          There is no indication that the signature belongs to the owner.
    Primary key fingerprint: 882D CFE4 8E20 51D4 8E25  62AB F3B6 0748 8DB3 5A47
    ```

</Steps>

:::danger[ПРЕДУПРЕЖДЕНИЕ]
Если в выводе нет строки **Good signature** или ID ключа не совпадает, не используйте этот ISO-образ. Убедитесь, что скачанный образ получен
из легитимного источника CachyOS, так как неверная подпись может указывать на то, что ISO-файл был изменен.
:::
