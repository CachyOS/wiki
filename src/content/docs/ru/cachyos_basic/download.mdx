## Официальные источники ISO

ISO-образ CachyOS можно получить из следующих источников:

*   [Веб-сайт](<https://cachyos.org/download>)
*   [SourceForge](<https://sourceforge.net/projects/cachyos-arch/files/>)
*   [Зеркало CachyOS](<https://mirror.cachyos.org/ISO/>)

## Проверка целостности ISO с помощью SHA256

:::caution[ПРЕДУПРЕЖДЕНИЕ]
Всегда делайте дополнительный шаг для проверки целостности ISO-образа, чтобы избежать нежелательных проблем при установке или создании загрузочного носителя.
:::

**Текущая версия ISO:** `260426`

**Хеш SHA256:** `9a280d1e9732cfe50ab02db6a7e44ae0d9e6a10e6ea394f73192f7c14e263118`

<Tabs>

<TabItem label='Windows'>

<Steps>

1. Загрузите [файл](https://mirror.cachyos.org/ISO/desktop/260426/cachyos-desktop-linux-260426.iso.sha256) с хешем SHA256 **(откройте его в текстовом редакторе, например, в Блокноте).**
2. Откройте CMD или PowerShell от имени администратора и [перейдите](<https://www.wikihow.com/Change-Directories-in-Command-Prompt>) в каталог, где хранятся файлы ISO и SHA256.
3. Выполните следующую команду:
   ```powershell
   # Пример:
   certUtil -hashfile cachyos-desktop-linux-260426.iso SHA256
   ```
4. Сравните хеш, выведенный certUtil, с хешем из загруженного файла в **шаге 1**. Если они совпадают, вы можете приступить к установке CachyOS.

</Steps>

</TabItem>

<TabItem label='Linux'>

<Steps>

1. Загрузите [файл](https://mirror.cachyos.org/ISO/desktop/260426/cachyos-desktop-linux-260426.iso.sha256) с хешем SHA256.
2. Откройте терминал, перейдите в каталог, содержащий файл `.sha256`, и выполните следующие команды:
   ```sh
   # Пример:
   cd Downloads/
   cat cachyos-desktop-linux-260426.iso.sha256
   # 9a280d1e9732cfe50ab02db6a7e44ae0d9e6a10e6ea394f73192f7c14e263118
   ```
3. Сравните вывод из **шага 2** и выполните следующую команду, чтобы проверить хеш ISO-файла:
   ```sh
   # Пример:
   sha256sum cachyos-desktop-linux-260426.iso
   ```
4. Если хеши из **шага 2** и **шага 3** совпадают, вы можете приступить к установке CachyOS.

</Steps>

</TabItem>

## Проверка подлинности образа ISO (Linux)

Чтобы проверить подлинность ISO-файла и убедиться, что он является официальным релизом от команды разработчиков CachyOS:

<Steps>

1. Импортируйте ключ GPG для проверки подлинности:

   ```shell
   gpg --keyserver hkps://keys.openpgp.org --recv-key F3B607488DB35A47
   ```

2. Загрузите ISO-файл и его файл подписи [.sig](https://cdn77.cachyos.org/ISO/desktop/260426/cachyos-desktop-linux-260426.iso.sig) и выполните следующую команду (заменив `full_iso_name.iso` на фактическое имя ISO-файла):
   ```shell
   gpg --verify full_iso_name.iso.sig full_iso_name.iso
   ```

   Если вы получили вывод **Good signature** (правильная подпись), значит, ISO-файл подлинный:
   ```
   gpg: Signature made dom 08 mar 2026 10:39:18 -03
   gpg:                using RSA key 882DCFE48E2051D48E2562ABF3B607488DB35A47
   gpg: Good signature from "CachyOS <admin@cachyos.org>" [unknown]
   gpg: WARNING: This key is not certified with a trusted signature!
   gpg:          There is no indication that the signature belongs to the owner.
   Primary key fingerprint: 882D CFE4 8E20 51D4 8E25  62AB F3B6 0748 8DB3 5A47
   ```

</Steps>

:::danger
Если в выводе отсутствует строка **Good signature** (правильная подпись) или идентификатор ключа не совпадает, не используйте образ ISO. Убедитесь, что загруженный образ получен
из легитимного источника CachyOS, так как неверная подпись может указывать на то, что ISO-образ был изменен.
:::
