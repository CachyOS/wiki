## Официальные источники ISO

ISO-образ CachyOS можно получить из следующих источников:

*   [Веб-сайт](<https://cachyos.org/download>)
*   [SourceForge](<https://sourceforge.net/projects/cachyos-arch/files/>)
*   [Зеркало CachyOS](<https://mirror.cachyos.org/ISO/>)

## Проверка целостности ISO с помощью SHA256

:::caution[ВНИМАНИЕ]
Всегда выполняйте дополнительный шаг по проверке целостности ISO-образа, чтобы избежать нежелательных проблем при установке или создании загрузочного носителя.
:::

**Текущая версия ISO:** `251129`

**Хеш SHA256:** `2ab25f72ce8fece890b440cf9e260fc3d57ae4f5fb5308086f670240de02da7b`

<Tabs>

<TabItem label='Windows'>

<Steps>

1. Загрузите [файл](https://mirror.cachyos.org/ISO/desktop/251129/cachyos-desktop-linux-251129.iso.sha256), содержащий хеш SHA256 **(Откройте его в текстовом редакторе, например, в Блокноте).**
2. Откройте CMD или PowerShell от имени администратора и [перейдите](<https://www.wikihow.com/Change-Directories-in-Command-Prompt>) в каталог, где хранятся файлы ISO и SHA256.
3. Выполните следующую команду:
   ```powershell
   # Пример:
   certUtil -hashfile cachyos-desktop-linux-251129.iso SHA256
   ```
4. Сравните хеш, выведенный утилитой certUtil, с хешем из файла, загруженного на **Шаге 1**. Если они совпадают, вы можете продолжить установку CachyOS.

</Steps>

</TabItem>

<TabItem label='Linux'>

<Steps>

1. Загрузите [файл](https://mirror.cachyos.org/ISO/desktop/251129/cachyos-desktop-linux-251129.iso.sha256), содержащий хеш SHA256.
2. Откройте терминал, перейдите в каталог, содержащий файл `.sha256`, и выполните следующие команды:
   ```sh
   # Пример:
   cd Downloads/
   cat cachyos-desktop-linux-251129.iso.sha256
   # 2ab25f72ce8fece890b440cf9e260fc3d57ae4f5fb5308086f670240de02da7b
   ```
3. Сравните вывод с **Шага 2** и выполните следующую команду для проверки хеша ISO-файла:
   ```sh
   # Пример:
   sha256sum cachyos-desktop-linux-251129.iso
   ```
4. Если хеши с **Шага 2** и **Шага 3** совпадают, вы можете продолжить установку CachyOS.

</Steps>

</TabItem>

## Проверка подлинности ISO-образа (Linux)

Чтобы проверить подлинность ISO-файла и убедиться, что он является официальным релизом от команды разработчиков CachyOS:

<Steps>

1. Импортируйте GPG-ключ для проверки подлинности:

   ```shell
   gpg --keyserver hkps://keys.openpgp.org --recv-key F3B607488DB35A47
   ```

2. Загрузите ISO-файл и его файл подписи `.sig`, а затем выполните следующую команду (заменив `full_iso_name.iso` на фактическое имя ISO-файла):
   ```shell
   gpg --verify full_iso_name.iso.sig full_iso_name.iso
   ```

   Если вы получили вывод **Good signature** (Достоверная подпись), значит ISO-файл подлинный:
   ```
   gpg: Signature made sáb 29 nov 2025 13:10:22 -03
   gpg:                using RSA key 882DCFE48E2051D48E2562ABF3B607488DB35A47
   gpg: Good signature from "CachyOS <admin@cachyos.org>" [unknown]
   gpg: WARNING: This key is not certified with a trusted signature!
   gpg:          There is no indication that the signature belongs to the owner.
   Primary key fingerprint: 882D CFE4 8E20 51D4 8E25  62AB F3B6 0748 8DB3 5A47
   ```

</Steps>

:::danger
Если в выводе отсутствует строка **Good signature** (Достоверная подпись) или идентификатор ключа не совпадает, не используйте этот ISO-образ. Убедитесь, что загруженный образ получен
из легитимного источника CachyOS, так как неверная подпись может указывать на то, что ISO-образ был изменён.
:::
