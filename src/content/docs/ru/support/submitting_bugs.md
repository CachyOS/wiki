# Опишите вашу проблему

- *Что не работает?*
- *Исправляет ли проблему понижение версии пакета X?*
- *Воспользуйтесь поиском, чтобы найти похожие проблемы*
- *Вносили ли вы изменения самостоятельно?*
  - Пример: `Добавление дополнительного флага в файл modprobe`

# Предоставьте логи

В CachyOS есть отличный инструмент для сбора системных логов под названием `cachyos-bugreport.sh`.
Этот инструмент соберёт логи из:

- dmesg
- journalctl
- inxi `(для сбора информации об оборудовании)`

Когда логи будут собраны, пользователю будет предложено загрузить их на наш paste-сайт.

**Выполните следующую команду в терминале и вставьте полученную ссылку в свою тему:**

```sh
sudo cachyos-bugreport.sh
```
