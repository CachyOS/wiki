---
title: Отправка запросов на добавление пакетов в CachyOS
description: Запросы на добавление пакетов из AUR, ...
---

CachyOS предлагает обширный список часто используемых, предварительно скомпилированных пакетов из AUR.
Пользователи могут создавать запросы на добавление пакетов из AUR, которые в случае одобрения будут автоматически обновляться нашим сборочным сервером.

Если вы хотите, чтобы мы добавили пакет, вы можете отправить запрос на GitHub или на форуме.

- GitHub: <https://github.com/CachyOS/distribution/issues>
- Форум: <https://discuss.cachyos.org/c/feedback/repository/11>
- Discord: [Канал обратной связи](https://discord.com/channels/862292009423470592/1150723027986813018)
