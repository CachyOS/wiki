:::note[Это руководство применяется, если вы заменяете ваш графический процессор (NVIDIA ↔ AMD) на существующей установке CachyOS.]
:::

## Предварительные требования
  - Ваш новый графический процессор правильно установлен и подключен.
  - Убедитесь, что ваша система полностью обновлена
    ```bash
    sudo pacman -Syu
    ```

### Шаги по переходу

<Tabs>
    <TabItem label='С NVIDIA на AMD'>
        Хотя драйверы AMD включены в ядро Linux, вам может потребоваться очистить старую конфигурацию NVIDIA и убедиться, что установлены необходимые пакеты AMD.
        <Steps>
            1. Проверьте, какой профиль драйвера NVIDIA установлен в данный момент:
                ```bash
                sudo chwd --list-installed
                ```
            2. Удалите конкретный профиль, используя флаг `-r`:
                ```bash
                sudo chwd -r <имя-профиля>
                ```
            3. Выключите вашу систему и приступайте к установке графического процессора AMD.
            4. После загрузки. Используйте chwd для автоматического определения вашего GPU и установки правильных пакетов AMD.
                ```bash
                sudo chwd -a
                ```
            5. После установки новых драйверов обновите ваш initramfs и конфигурацию загрузчика
                > CachyOS включает хук pacman, который автоматически пересобирает initramfs при добавлении или удалении драйверов.
                > Это гарантирует, что при загрузке будут загружены правильные драйверы.
                - GRUB: `sudo grub-mkconfig -o /boot/grub/grub.cfg`
                - systemd-boot: `sudo sdboot-manage gen`
                - Limine: `sudo limine-mkinitcpio`
            6. Перезагрузитесь, чтобы применить изменения.
                ```bash
                sudo reboot
                ```
            7. После перезагрузки убедитесь, что драйверы AMD активны.
                ```bash
                vulkaninfo | grep "deviceName"
                ```
                или
                ```bash
                glxinfo | grep "OpenGL renderer"
                ```
                Если вы видите в списке ваш графический процессор AMD, значит, драйверы работают корректно.
        </Steps>
    </TabItem>
