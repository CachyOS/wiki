[CachyOS Hardware Detection](https://github.com/CachyOS/chwd/) (более известный как `chwd`) позволяет нам обеспечивать работу разнообразного оборудования путём установки необходимых
пакетов и драйверов для работающей системы. Это включает системы с видеокартами NVIDIA, Macbook T2, а также портативные устройства, такие как Steam Deck и ROG Ally.

## Использование

`chwd` обычно запускается во время установки для предоставления необходимых пакетов для системы. Однако его также можно
использовать и после установки.

### Автоматическая настройка

`chwd` поддерживает установку и настройку необходимых драйверов и пакетов, чтобы система могла работать в оптимальных условиях.

```sh
sudo chwd -a
```

sudo chwd -i amd

### Другое

Обратитесь к справочной информации `chwd` для получения сведений о синтаксисе команд и других вариантах использования.

```sh
chwd --help
Usage: chwd [OPTIONS]

Options:
  -i, --install <profile>          Install profile
  -r, --remove <profile>           Remove profile
  -d, --detail                     Show detailed info for listings
  -f, --force                      Force reinstall
      --list-installed             List installed kernels
      --list                       List available profiles for all devices
      --list-all                   List all profiles
  -a, --autoconfigure [<classid>]  Autoconfigure
      --ai_sdk                     Toggle AI SDK profiles
      --pmcachedir <PMCACHEDIR>    [default: /var/cache/pacman/pkg]
      --pmconfig <PMCONFIG>        [default: /etc/pacman.conf]
      --pmroot <PMROOT>            [default: /]
  -h, --help                       Print help
  -V, --version                    Print version
```
