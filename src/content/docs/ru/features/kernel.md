Ядро CachyOS — это кастомизированное ядро, которое использует улучшения, конфигурации и патчи из апстрима.

## Особенности

### Оптимизация производительности

- **Расширенная компиляция**: Гибко настраиваемый PKGBUILD с поддержкой компиляторов GCC и Clang.
- **Оптимизация на этапе компоновки (LTO)**: Thin LTO включена по умолчанию для лучшей производительности.
- **Профильно-ориентированная оптимизация**: Профилирование с помощью AutoFDO + Propeller для оптимальной генерации кода ([Подробнее](https://cachyos.org/blog/2411-kernel-autofdo/)).
- **Целостность потока управления ядром (kCFI)**: Доступно при использовании LLVM для повышения безопасности.
- **Опции частоты таймера**: Настраивается в диапазоне 300 Гц, 500 Гц, 600 Гц, 750 Гц и 1000 Гц (по умолчанию: 1000 Гц).
- **Архитектурные оптимизации**: Поддержка сборок, оптимизированных под x86-64-v3, x86-64-v4 и AMD Zen4.
- **Оптимизации компилятора**: Расширенные флаги GCC, включая `-fivopts` и `-fmodulo-sched`.

### Улучшения для ЦП

- **Несколько планировщиков**: Планировщики BORE, EEVDF и BMQ для оптимизации под различные рабочие нагрузки.
- **Улучшения AMD P-State**: Поддержка Preferred Core и последние улучшения amd-pstate из linux-next.
- **Поддержка реального времени**: Доступны сборки RT-ядра с интеграцией планировщика BORE.
- **CachyOS Sauce**: Пользовательская конфигурация `CONFIG_CACHY` с твиками планировщика и системы.
- **Оптимизации для низкой задержки**: Патчи для улучшения отзывчивости и уменьшения джиттера.

### Файловая система и память

- **Поддержка ZFS**: Встроенная поддержка файловой системы ZFS с предкомпилированными модулями.
- **Интеграция NVIDIA**:
  - Модули проприетарного драйвера NVIDIA с патчами.
  - Поддержка открытого драйвера NVIDIA.
  - Готовые к использованию модули в репозитории.
- **Улучшения планировщика ввода-вывода**:
  - Улучшенная производительность BFQ и mq-deadline.
  - Поддержка альтернативного планировщика ввода-вывода [ADIOS](https://github.com/firelzrd/adios).
- **Управление памятью**:
  - Патч [le9uo](https://github.com/firelzrd/le9uo) для предотвращения пробуксовки страниц при нехватке памяти.
  - Твики управления памятью из Zen-kernel (уплотнение, оптимизация водяных знаков).

### Дополнительные возможности

#### Поддержка оборудования
- **Игровое оборудование**: Патчи для Steam Deck (аудио, аппаратные квирки, HID) и поддержка ROG Ally.
- **Оборудование Apple**: Поддержка T2 MacBook включена по умолчанию.
- **Оборудование ASUS**: Расширенные патчи для совместимости с оборудованием ASUS.
- **Графика**: Включена поддержка HDR, переопределение min_powercap для AMDGPU (`amdgpu_ignore_min_pcap`).

#### Системные улучшения
- **Мультимедиа**: Модули v4l2loopback включены по умолчанию.
- **Виртуализация**: Поддержка ACS Override для проброса VFIO/GPU.
- **Интеграция из апстрима**: Отобранные патчи из Clear Linux и linux-next.

#### Прочее

Ядро CachyOS также имеет некоторые другие примечательные особенности, которые, хоть и незаметны, улучшают пользовательский опыт:

- Включает отладочный вариант ядра, который предоставляет бинарный файл ядра без удаления отладочной информации. Этот пакет необходим для профилирования ядра с помощью AutoFDO.
- [Binder](https://developer.android.com/reference/android/os/Binder), модуль, необходимый для [Waydroid](https://waydro.id/), включен по умолчанию в конфигурации ядра
и уже [настроен](https://github.com/CachyOS/linux-cachyos/blob/master/linux-cachyos/config#L10784).

## Варианты

CachyOS предлагает широкий выбор вариантов ядра. Все предоставляемые нами ядра поставляются с [базовым набором патчей CachyOS](https://github.com/CachyOS/kernel-patches).
Для каждого ядра существует [соответствующий `-lto` вариант](#соглашение-об-именовании-пакетов), который
собран с помощью [clang](https://clang.llvm.org/) вместо [GCC](https://gcc.gnu.org/).

- **linux-cachyos**
  - Ядро по умолчанию. Рекомендуется использовать его, если вы не уверены, какое ядро выбрать.
  - Частота тиков 1000 Гц для улучшения отзывчивости.
  - Использует планировщик [BORE](https://github.com/firelzrd/bore-scheduler).
  - Собрано с помощью Clang и ThinLTO.
  - Профилировано с помощью нашего собственного профиля [AutoFDO](https://cachyos.org/blog/2411-kernel-autofdo/) для повышения производительности. [Скрипт](https://github.com/CachyOS/cachyos-benchmarker/blob/master/kernel-autofdo.sh), используемый для профилирования ядра.
- **linux-cachyos-bore**
  - Использует планировщик [BORE](https://github.com/firelzrd/bore-scheduler).
- **linux-cachyos-bmq**
  - Использует планировщик BMQ из [Project C](https://gitlab.com/alfredchen/projectc/) от Alfred Chen.
    - `Не поддерживает sched-ext.`
- **linux-cachyos-deckify**
  - Ядро по умолчанию для портативных устройств. Использование любого другого ядра на портативных устройствах **не рекомендуется** и **не поддерживается**.
  - Использует планировщик [BORE](https://github.com/firelzrd/bore-scheduler).
  - Содержит специфичные для портативных устройств патчи поверх базового набора для улучшения совместимости и общего опыта использования.
- **linux-cachyos-eevdf**
  - Модифицирует стандартный планировщик ядра для улучшения отзывчивости.
- **linux-cachyos-lts**
  - Основано на последнем ядре с долгосрочной поддержкой (LTS).
  - Использует планировщик [BORE](https://github.com/firelzrd/bore-scheduler).
  - Минимально пропатчено по сравнению с другими ядрами для обеспечения максимальной стабильности.
- **linux-cachyos-hardened**
  - Использует планировщик [BORE](https://github.com/firelzrd/bore-scheduler).
  - Включает набор патчей [linux-hardened](https://github.com/anthraxx/linux-hardened).
  - Конфигурация ядра основана на [конфигурации linux-hardened](https://gitlab.archlinux.org/archlinux/packaging/packages/linux-hardened/-/blob/main/config).
    - Содержит очень агрессивные меры по усилению защиты, которые значительно снижают производительность и ухудшают пользовательский опыт.
    - `Не поддерживает sched-ext.`
- **linux-cachyos-rc**
  - Основано на последнем mainline ядре из [дерева Линуса](https://github.com/torvalds/linux/).
  - Использует планировщик [BORE](https://github.com/firelzrd/bore-scheduler).
  - Основное ядро для внедрения новых функций в наш набор патчей.
- **linux-cachyos-server**
  - Оптимизировано для серверных нагрузок в отличие от десктопного использования.
    - Частота тиков 300 Гц.
    - Без вытеснения (no preemption).
    - Стандартный EEVDF.
- **linux-cachyos-rt-bore**
  - Вытеснение в реальном времени.
  - Использует планировщик [BORE](https://github.com/firelzrd/bore-scheduler).

:::note
Если не указано иное, можно считать, что все остальные варианты ядра
имеют ту же конфигурацию, что и ядро по умолчанию.
:::

Пожалуйста, создавайте issue в [репозитории linux-cachyos на GitHub](https://github.com/CachyOS/linux-cachyos) с предложениями и улучшениями, которые можно добавить в ядро по умолчанию.

### Соглашение об именовании пакетов

```sh
linux-cachyos # Базовый пакет ядра по умолчанию. Скомпилировано с Clang и ThinLTO
linux-cachyos-hardened # Базовый пакет для hardened-ядра. Скомпилировано с GCC
linux-cachyos-hardened-lto # Аналог linux-cachyos-hardened, скомпилированный с clang
linux-cachyos-hardened-{,lto-}headers
linux-cachyos-hardened-{,lto-}nvidia
linux-cachyos-hardened-{,lto-}nvidia-open
linux-cachyos-hardened-{,lto-}zfs
linux-cachyos-hardened-{,lto-}dbg
```

## Прекомпилированные модули ядра

Чтобы охватить более широкую аудиторию, CachyOS поставляет некоторые известные и часто используемые модули ядра вместе с самим ядром. Это означает, что пользователям больше не
придется перекомпилировать эти модули после каждого обновления ядра или при каждой новой установке ядра, а нужно будет лишь установить их из репозитория, так как они
уже скомпилированы. Это фактически делает ненужными любые пакеты `-dkms`, которые могут быть у пользователя и предоставляют тот же модуль, что и прекомпилированная версия.

### ZFS

[ZFS](https://openzfs.org/wiki/Main_Page) — одна из многих файловых систем, поддерживаемых в CachyOS. Поскольку она лицензирована под
[CDDL](https://opensource.org/license/cddl-1-0), она несовместима с лицензией ядра Linux и поэтому не может быть включена в основное дерево. Поставляемый модуль включает
последние апстрим-функции и исправления для обеспечения совместимости с последним ядром.

### NVIDIA

CachyOS поставляет прекомпилированные версии как проприетарных, так и [открытых](https://github.com/NVIDIA/open-gpu-kernel-modules/) модулей ядра. Из-за того, что разработка
модуля ядра NVIDIA ведется вне основного дерева и, следовательно, не следует графику релизов ядра, стандартная конфигурация иногда может быть несовместима с последней
версией ядра. В качестве обходного пути CachyOS применяет к модулям патчи, созданные сообществом, или патчи, предоставленные непосредственно NVIDIA.

## FAQ

### Почему AutoFDO не используется для всех остальных вариантов ядра?

Потому что это дорогая в плане сборки технология, так как она, по сути, требует сборки ядра дважды, что приводит к большим затратам времени и ресурсов на компиляцию. Процесс сборки ядра с AutoFDO включает следующие шаги:

1) Сборка ядра с включенными AutoFDO и возможностями отладки.
2) Создание профиля, то есть выполнение рабочих нагрузок для сбора данных профилирования для возможных оптимизаций.
3) Пересборка ядра с использованием профиля AutoFDO.

Поэтому на данный момент эта технология присутствует только в варианте [linux-cachyos](/ru/features/kernel#варианты).

Для получения дополнительной информации об AutoFDO нажмите [здесь.](https://cachyos.org/blog/2411-kernel-autofdo/)

### Улучшает ли ядро реального времени производительность в играх?

Нет. Ядро реального времени делает гораздо больше кода вытесняемым по сравнению с обычным полностью вытесняемым ядром. Это означает, что гораздо больше задач (включая
игровые процессы) часто вытесняются и принудительно уступают системные ресурсы, что приводит к ухудшению производительности.
