Помимо наших оптимизированных ядер и репозиториев, мы также предоставляем настройки, которые дополнительно улучшают работу с рабочим столом, а также некоторые
вспомогательные скрипты для повышения удобства использования. Все эти конфигурации и скрипты находятся в пакете `cachyos-settings`.

## Настройки sysctl

Мы предоставляем множество настроек sysctl, направленных на улучшение общей производительности рабочего стола. Каждая запись sysctl подробно документирована
в файле [99-cachyos-settings.conf](https://github.com/CachyOS/CachyOS-Settings/blob/master/usr/lib/sysctl.d/99-cachyos-settings.conf).

Чтобы изменить любое из этих значений, скопируйте исходную запись и создайте новый файл в `/etc/sysctl.d/` с изменённым значением.

### Изменение значений sysctl

<Steps>

1. Посмотрите на исходное значение из `cachyos-settings`

    ```sh
    cat /usr/lib/sysctl.d/99-cachyos-settings.conf
    # Only experimental!
    # Let Realtime tasks run as long they need
    # sched: RT throttling activated
    kernel.sched_rt_runtime_us=-1
    ```

2. Создайте новый файл в `/etc/sysctl.d`, чтобы внести изменения в настройки sysctl

    ```sh title="Возвращаем kernel.sched_rt_runtime_us= к значению по умолчанию"
    sudo micro /etc/sysctl.d/99-kernel-sched-rt.conf # Если файл не существует, эта команда создаст его и позволит вам его редактировать
    kernel.sched_rt_runtime_us=950000
    ```

</Steps>

## Правила udev

- [Правила ZRAM](https://github.com/CachyOS/CachyOS-Settings/blob/master/usr/lib/udev/rules.d/30-zram.rules) - Устанавливает более агрессивное
значение swappiness для ZRAM, чтобы кэш с большей вероятностью выгружался в ZRAM
- [Разрешения HPET](https://github.com/CachyOS/CachyOS-Settings/blob/master/usr/lib/udev/rules.d/40-hpet-permissions.rules) - Разрешает доступ к узлам устройств
`rtc0` и `hpet` для группы audio
- [Управление питанием SATA](https://github.com/CachyOS/CachyOS-Settings/blob/master/usr/lib/udev/rules.d/50-sata.rules) - Устанавливает политику управления питанием для устройств SATA на `max_performance`
- [Правила планировщика I/O](https://github.com/CachyOS/CachyOS-Settings/blob/master/usr/lib/udev/rules.d/60-ioschedulers.rules) - Выбирает оптимальный планировщик для каждого типа дисков (HDD, SSD, NVMe)
- [Правила hdparm](https://github.com/CachyOS/CachyOS-Settings/blob/master/usr/lib/udev/rules.d/69-hdparm.rules) - Устанавливает максимальную производительность для жёстких дисков SATA и IDE
- [NVIDIA RTD3](https://github.com/CachyOS/CachyOS-Settings/blob/master/usr/lib/udev/rules.d/71-nvidia.rules) - Настраивает функциональность динамического управления питанием для поколения GPU Turing. `RTD3 не работает должным образом на GPU Turing с открытыми модулями`
- [Задержка CPU DMA](https://github.com/CachyOS/CachyOS-Settings/blob/master/usr/lib/udev/rules.d/99-cpu-dma-latency.rules) -
Разрешает доступ к узлу устройства `cpu_dma_latency` для группы audio
- [snd_hda_intel PM](https://github.com/CachyOS/CachyOS-Settings/blob/master/usr/lib/udev/rules.d/20-audio-pm.rules) - Устанавливает энергосбережение на `0` при питании от сети и восстанавливает предыдущее значение при переключении на батарею

## Опции modprobe

- Принудительное использование драйвера AMDGPU на Southern Islands (GCN 1.0) и Sea Islands (GCN 2.0)
- Включает [различные настройки](https://github.com/CachyOS/CachyOS-Settings/blob/master/usr/lib/modprobe.d/nvidia.conf) для NVIDIA
- Вносит в чёрный список модули watchdog
- Отключает power_save для аудиодрайвера **sna_hda_intel**

## Вспомогательные скрипты

- `cachyos-bugreport.sh` - Собирает различные логи из `inxi`, `dmesg` и `journalctl` для помощи в устранении неполадок
- `game-performance` - Скрипт-обёртка для **`powerprofilesctl`** для переключения на профиль производительности по требованию.
См. [Переключение профиля питания по требованию](/ru/configuration/gaming#power-profile-switching-on-demand)
- `dlss-swapper` - Скрипт-обёртка для принудительного использования последней версии DLSS в играх, поддерживающих эту технологию
- `dlss-swapper-dll` - Подобно `dlss-swapper`, но требует ручного обновления библиотеки `nvngx_dlss.dll`, поставляемой с игрой; может работать с играми, у которых возникают проблемы с обычной версией скрипта
- `kerver` - Скрипт для удобства, показывающий информацию о текущем ядре
- `paste-cachyos` - Скрипт для вставки вывода терминала или текстовых файлов из системы

    <Tabs>
        <TabItem label="Загрузка текстовых файлов">
            ```sh
            paste-cachyos /путь/к/файлу
            ```
        </TabItem>
        <TabItem label="Загрузка вывода терминала">
            ```sh
            <команда> | paste-cachyos
            ```
        </TabItem>
    </Tabs>
- [pci-latency](https://github.com/CachyOS/CachyOS-Settings/blob/master/usr/bin/pci-latency) - Уменьшает значение latency_timer до `80` для звуковых карт PCI и сбрасывает все остальные устройства PCI до `20` и `0`
    ```sh title="Включение pci-latency в системе"
    sudo systemctl enable --now pci-latency.service
    ```
- `sbctl-batch-sign` - Вспомогательный скрипт для лёгкой подписи образов ядра и EFI-бинарников для безопасной загрузки и их сохранения в базу данных sbctl
- `topmem` - Показывает статистику RAM, swap и ksm для 10 процессов в порядке убывания
- `zink-run` - Упрощает запуск OpenGL-программы через Zink Gallium Driver


## Другие конфигурации

### Настройки использования памяти

- Конфигурация THP Shrinker `max_ptes_none = 409`
- Установка максимального размера журнала systemd в `50MB`
- [ZRAM Generator](https://github.com/CachyOS/CachyOS-Settings/blob/master/usr/lib/systemd/zram-generator.conf) - Устанавливает размер ZRAM равным объёму ОЗУ и использует ZSTD для сжатия

### Правила Ananicy-cpp

- [ananicy-cpp](https://gitlab.com/ananicy-cpp/ananicy-cpp) с [наборами правил, поддерживаемыми сообществом](https://github.com/CachyOS/ananicy-rules)

### Сетевые изменения

- [systemd-resolved в качестве DNS-резолвера по умолчанию](https://github.com/CachyOS/CachyOS-Settings/blob/master/usr/lib/NetworkManager/conf.d/dns.conf) для NetworkManager

### RTC

- Увеличение максимальной запрашиваемой частоты прерываний RTC до `3072`

### Удобство использования NTP

- Предпочтительный сервер установлен на `Cloudflare`
- Резервные серверы: `Google` и `Arch Linux`

### Настройки служб systemd

- Таймаут для запуска службы/юнита установлен на `15с`
- Таймаут для остановки службы/юнита установлен на `10с`
- Мягкий лимит открытых файловых дескрипторов установлен на `2048`
- Жёсткий лимит открытых файловых дескрипторов установлен на `2097152`

### X.Org

- Включить [касание для клика (Tap to Click)](https://github.com/CachyOS/CachyOS-Settings/blob/master/usr/share/X11/xorg.conf.d/20-touchpad.conf) по умолчанию для всех сессий X11
