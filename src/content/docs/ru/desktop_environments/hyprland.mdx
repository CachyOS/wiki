:::caution
Поскольку разработчики Hyprland начали его переработку, имейте в виду, что на данный момент он нестабилен, и вы можете столкнуться с ошибками или неожиданными сбоями. Используйте на свой страх и риск.
Даже их «стабильная» версия также сломана и полна ошибок, поэтому мы не планируем оказывать поддержку за рамками наших конфигурационных файлов. Обращайтесь к их [вики](<https://wiki.hyprland.org/>).
:::

:::tip
Запускайте Hyprland, выбирая пункт без systemd, иначе он не запустится, и вы увидите черный экран.

Например: **`Hyprland`** вместо **`Hyprland(systemd)`**.
:::

Наша главная цель — предоставить рабочую, но простую конфигурацию Hyprland, поэтому некоторые важные инструменты и программы, такие как файловый менеджер с графическим интерфейсом, могут отсутствовать.

Загляните в наш [раздел часто задаваемых вопросов о Hyprland.](/desktop_environments/hyprland#faq)

**Конфигурационные файлы поддерживаются [msmafra](https://github.com/msmafra) и [Lysec](https://github.com/Ly-sec)**

## Горячие клавиши

Большинство комбинаций клавиш требуют использования клавиши-модификатора (в нашем случае это клавиша Windows, обозначаемая как SUPER). Вы можете изменить ее в файле конфигурации.

### Управление приложениями

| Описание | Клавиша |
|-------------|-----|
| Открыть терминал | <Kbd linux="Super+Return" /> |
| Открыть Rofi (запуск приложений) | <Kbd linux="Super+Space" /> |
| Открыть файловый менеджер | <Kbd linux="Super+E" /> |
| Закрыть активное окно | <Kbd linux="Super+Q" /> |

### Навигация по рабочим столам

| Описание | Клавиша |
|-------------|-----|
| Перейти на рабочий стол (1-9) | <Kbd linux="Super+1" /> ... <Kbd linux="Super+9" /> |
| Следующий рабочий стол | <Kbd linux="Super+Period" /> |
| Предыдущий рабочий стол | <Kbd linux="Super+Comma" /> |
| Переключаться между рабочими столами колесиком мыши | <Kbd linux="Super+Scroll" /> |

### Навигация по окнам

| Описание | Клавиша |
|-------------|-----|
| Переместить фокус на окно сверху | <Kbd linux="Super+ArrowUp" /> |
| Переместить фокус на окно снизу | <Kbd linux="Super+ArrowDown" /> |
| Переместить фокус на окно слева | <Kbd linux="Super+ArrowLeft" /> |
| Переместить фокус на окно справа | <Kbd linux="Super+ArrowRight" /> |
| Сменить активную группу | <Kbd linux="Super+Tab" /> |

### Управление окнами

| Описание | Клавиша |
|-------------|-----|
| Переместить окно на рабочий стол (1-9) без переключения | <Kbd linux="Super+Shift+1" /> ... <Kbd linux="Super+Shift+9" /> |
| Переместить окно на рабочий стол (1-9) с переключением на него | <Kbd linux="Super+Control+1" /> ... <Kbd linux="Super+Control+9" /> |
| Переместить окно вверх | <Kbd linux="Super+Shift+ArrowUp" /> |
| Переместить окно вниз | <Kbd linux="Super+Shift+ArrowDown" /> |
| Переместить окно влево | <Kbd linux="Super+Shift+ArrowLeft" /> |
| Переместить окно вправо | <Kbd linux="Super+Shift+ArrowRight" /> |
| Переключить окно в полноэкранный режим | <Kbd linux="Super+F" /> |
| Сделать окно плавающим/закрепить | <Kbd linux="Super+V" /> |
| Закрепить окно на всех рабочих столах (в плавающем режиме) | <Kbd linux="Super+Y" /> |
| Добавить/убрать окно из группы | <Kbd linux="Super+K" /> |

### Изменение размера окон

| Описание | Клавиша |
|-------------|-----|
| Войти в режим изменения размера (используйте H,J,K,L или стрелки, Escape для выхода) | <Kbd linux="Super+R" /> |
| Уменьшить высоту окна | <Kbd linux="Super+Control+Shift+J" /> или <Kbd linux="Super+Control+Shift+ArrowDown" /> |
| Увеличить высоту окна | <Kbd linux="Super+Control+Shift+K" /> или <Kbd linux="Super+Control+Shift+ArrowUp" /> |
| Уменьшить ширину окна | <Kbd linux="Super+Control+Shift+H" /> или <Kbd linux="Super+Control+Shift+ArrowLeft" /> |
| Увеличить ширину окна | <Kbd linux="Super+Control+Shift+L" /> или <Kbd linux="Super+Control+Shift+ArrowRight" /> |

### Управление мышью

| Описание | Клавиша |
|-------------|-----|
| Перемещать окно мышью | <Kbd linux="Super+LeftClick" /> |
| Изменять размер окна мышью | <Kbd linux="Super+RightClick" /> |

### Управление системой

| Описание | Клавиша |
|-------------|-----|
| Сделать скриншот | <Kbd linux="Super+A" /> |
| Перезагрузить Waybar | <Kbd linux="Super+O" /> |
| Уменьшить зазор между окнами | <Kbd linux="Super+G" /> |
| Сбросить зазоры к значению по умолчанию | <Kbd linux="Super+Shift+G" /> |

### Управление медиа

| Описание | Клавиша |
|-------------|-----|
| Управление громкостью | Мультимедийные клавиши: <Kbd linux="VolUp" /> <Kbd linux="VolDown" /> <Kbd linux="Mute" /> |
| Управление яркостью | Мультимедийные клавиши: зависит от оборудования |
| Управление воспроизведением | Мультимедийные клавиши: <Kbd linux="Play/Pause" /> <Kbd linux="Next" /> <Kbd linux="Previous" /> |
## Часто задаваемые вопросы

### Почему у Discord, Thunar и Nautilus странный фон?

Это происходит потому, что для окна установлена измененная прозрачность.

* Рассмотрите возможность изменения правила для окна в файле конфигурации [Hyprland](https://github.com/CachyOS/cachyos-hyprland-settings/blob/master/etc/skel/.config/hypr/config/windowrules.conf#L21).

```sh title='Пример'
windowrulev2 = opacity 0.92, class:^(thunar|nemo)$
```

### Есть ли в комплекте файловый менеджер?

* Нет, установите тот, который вам нравится.
