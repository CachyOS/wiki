:::note
Niri — это композитор Wayland с прокручиваемым тайлингом, который предлагает уникальный подход к управлению окнами благодаря своей системе расположения в виде столбцов.
:::

Наша главная цель при настройке — создать рабочую конфигурацию Niri, которая обеспечит плавный и интуитивно понятный рабочий стол, сохраняя при этом простоту и доступность настроек.

Ознакомьтесь с нашим [FAQ по Niri.](/ru/desktop_environments/niri#faq)

**Файлы конфигурации поддерживаются [Ly-sec](https://github.com/Ly-sec)**

## Горячие клавиши

Большинство комбинаций клавиш требуют использования клавиши-модификатора, которой в нашем случае является клавиша Windows (обозначается как SUPER). Вы можете изменить её в файле конфигурации.

### Управление приложениями

| Описание | Клавиша |
|-------------|-----|
| Открыть терминал | <Kbd linux="Super+Return" /> |
| Открыть Wofi (запуск программ) | <Kbd linux="Super+Space" /> |
| Открыть браузер (Firefox) | <Kbd linux="Super+B" /> |
| Открыть файловый менеджер | <Kbd linux="Super+E" /> |

## FAQ

### Чем Niri отличается от других оконных менеджеров?

Niri использует уникальный подход прокручиваемого тайлинга, где окна организованы в столбцы, которые можно прокручивать по горизонтали. Это создаёт метафору бесконечного рабочего стола, что особенно полезно для сверхшироких мониторов и рабочих процессов, требующих множества открытых приложений.

### Как изменить раскладку клавиатуры?

Отредактируйте секцию `input` в вашем файле конфигурации:

```kdl title='Пример'
input {
    keyboard {
        xkb {
            layout "us" // Измените "de" на предпочитаемую раскладку
        }
    }
}
```

### Можно ли настроить зазоры и внешний вид окон?

Да, вы можете изменить секцию `layout`:

```kdl title='Пример'
layout {
    gaps 8 // Изменить размер зазора

    focus-ring {
        width 2
        active-color "#vash-cvet"
        inactive-color "#vash-cvet"
    }
}
```

### Как добавить больше приложений в автозагрузку?

Добавьте их в секцию `startup`:

```kdl title='Пример'
spawn-at-startup "vashe-prilozhenie"
```

### Для чего нужна клавиша аварийного выхода?

Комбинация `Super+Escape` предназначена для восстановления управления, когда полноэкранное приложение блокирует ваши горячие клавиши. Она отключает любой активный перехватчик сочетаний клавиш.

### Как настроить несколько мониторов?

Раскомментируйте и измените секцию `output` для ваших конкретных дисплеев. Выполните `niri msg outputs`, чтобы получить правильные имена:

```kdl title='Пример'
output "DP-1" {
    mode "1920x1080@60.000"
    scale 1
}
```
