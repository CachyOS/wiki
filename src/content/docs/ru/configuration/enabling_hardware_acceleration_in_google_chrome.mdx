Это руководство описывает, как включить аппаратное ускорение в браузерах на основе Chromium в CachyOS. Это переносит задачи обработки видео/графики на ваш GPU, повышая производительность.

## Предварительные требования

* **Браузер на основе Chromium:** (например, Chrome, Brave, Ungoogled Chromium, Edge)
* **Драйверы/API для GPU:** Актуальные драйверы Mesa (AMD/Intel) или NVIDIA, с настроенными Vulkan/VA-API/VDPAU.
* **amdgpu_top:** Установите `amdgpu_top` из репозитория через менеджер пакетов, если хотите отслеживать активность GPU AMD из терминала.

## Участие

Это руководство можно расширять. Если у вас есть работающая конфигурация аппаратного ускорения для определённого GPU и браузера на основе Chromium, внесите свой вклад, добавив новый раздел в "Конфигурации GPU и браузеров". Укажите:

* **Название браузера**
* **Модель GPU**
* **Флаги:** Содержимое файла `~/.config/[browser]-flags.conf`.
* **Путь к файлу:** Полный путь к файлу с флагами.
* **Примечания (необязательно):** Ключевые драйверы, пакеты или особенности настройки.

## Шаги настройки

<Steps>

1.  Найдите файл с флагами: Определите путь к файлу с флагами вашего браузера в разделе "Конфигурации GPU и браузеров".
2.  Отредактируйте файл с флагами: Откройте/создайте файл с помощью `nano` (или вашего предпочитаемого текстового редактора, например `micro`, `vim`).

    ```bash
    nano [ПУТЬ_К_ФАЙЛУ_С_ФЛАГАМИ_ВАШЕГО_БРАУЗЕРА]
    # Пример: nano ~/.config/chrome-flags.conf
    ```

3.  Добавьте флаги: Вставьте соответствующие флаги для вашего GPU/браузера в файл.
4.  Сохраните и закройте.
5.  Перезапустите браузер: Закройте все окна браузера и запустите его снова.
6.  Проверьте: Перейдите по адресу `chrome://gpu` (или `brave://gpu`, `edge://gpu` и т. д.). Убедитесь, что в разделах "Video Acceleration Information" и "Graphics Feature Status" указан статус "Hardware accelerated".

</Steps>

## Как проверить аппаратное ускорение видео

<Tabs>

<TabItem label='GPU AMD (amdgpu_top)'>

<Steps>

1.  Откройте терминал и выполните команду:
    ```bash
    amdgpu_top
    ```
2.  Начните воспроизведение видео в вашем браузере (например, на YouTube).
3.  Наблюдайте за разделом `media` в `amdgpu_top`. Вы должны увидеть здесь некоторую утилизацию, что указывает на активность медиа-движка вашего GPU. Если во время воспроизведения видео значение остаётся на 0%, возможно, аппаратное ускорение для декодирования не задействовано полностью.

</Steps>

</TabItem>

<TabItem label='Инструменты разработчика браузера'>

<Steps>

1.  Откройте ваш браузер на основе Chromium.

2.  Начните воспроизведение видео (например, на YouTube или из локального файла).

3.  Откройте Инструменты разработчика: Нажмите `F12` или `Ctrl+Shift+I`.

4.  Перейдите на вкладку **Media**. Если вы её не видите, нажмите на три точки (`...`) или `>>` (Больше вкладок) на панели инструментов разработчика, а затем выберите `Media`.

5.  В разделе "Players" слева нажмите на запись, соответствующую вашему видео.

6.  На основной панели прокрутите вниз до раздела **Video Decoder**.

7.  Найдите метку `Hardware decoder`. Её значение должно быть `true`. Если там указано `false` или имя программного декодера (например, `FFmpegVideoDecoder`, `VpxVideoDecoder`, `Dav1dVideoDecoder`), значит аппаратное ускорение для этого видео не активно.

</Steps>

</TabItem>

## Конфигурации GPU и браузеров

### AMD Radeon RX 6900 XT (Google Chrome)

* **Браузер:** Google Chrome

* **GPU:** AMD Radeon RX 6900 XT

* **Файл с флагами:** `~/.config/chrome-flags.conf`

```bash
--use-gl=angle
--use-angle=vulkan
--enable-features=Vulkan,VulkanFromANGLE,DefaultANGLEVulkan,AcceleratedVideoDecodeLinuxZeroCopyGL,AcceleratedVideoEncoder,VaapiIgnoreDriverChecks,UseMultiPlaneFormatForHardwareVideo
--ozone-platform-hint=x11
```

**Примечания:** Использует Vulkan (через ANGLE) и VA-API. Флаг `--ozone-platform-hint=x11` может быть полезен даже в Wayland для некоторых сценариев ускорения.

### [Ваш браузер] - [Ваша модель GPU] (Предоставлено [Ваше имя/ник])

* **Браузер:** [например, Brave, Ungoogled Chromium, Microsoft Edge, Vivaldi, Opera, Chromium]

* **GPU:** [например, NVIDIA GeForce RTX 3080, Intel Iris Xe]

* **Путь к файлу с флагами:** (Критически важно, различается для разных браузеров!)

  * Распространенные пути к `.conf` файлам:

    * Chromium: `~/.config/chromium-flags.conf`

    * Brave Browser: `~/.config/brave-browser-flags.conf`

    * Ungoogled Chromium: `~/.config/ungoogled-chromium-flags.conf`

  * Изменение `.desktop` файла: Некоторые браузеры (Brave, Edge, Vivaldi, Opera) могут требовать редактирования строки `Exec=` в их `.desktop` файле (сначала скопируйте его из `/usr/share/applications/` в `~/.local/share/applications/`).

Содержимое флагов (для `.conf` файла или строки `Exec=`):

```bash
# Вставьте ваши флаги сюда.
# Для .desktop файлов флаги указываются через пробел после исполняемого файла.
```

**Примечания (необязательно):**

* Требуемые драйверы (например, `nvidia-dkms`, `intel-media-driver`).

* Особые соображения по настройке или инструкции по изменению `.desktop` файла.
