# Аппаратное ускорение в браузерах на базе Chromium

Это руководство описывает, как включить аппаратное ускорение в браузерах на базе Chromium в CachyOS. Это переносит задачи, связанные с видео и графикой, на ваш GPU, повышая производительность.

## Необходимые условия

*   **Браузер на базе Chromium:** (например, Chrome, Brave, Ungoogled Chromium, Edge)
*   **Драйверы/API для GPU:** Актуальные драйверы Mesa (AMD/Intel) или NVIDIA с настроенными Vulkan/VA-API/VDPAU.
*   **`amdgpu_top` (для пользователей AMD):** Установите `amdgpu_top` из репозитория через менеджер пакетов, если хотите отслеживать активность GPU AMD из терминала.

## Как внести свой вклад

Это руководство можно дополнять. Если у вас есть рабочая конфигурация аппаратного ускорения для конкретного GPU и браузера на базе Chromium, добавьте новый раздел в «Конфигурации GPU и браузеров». Укажите:

*   **Название браузера**
*   **Модель GPU**
*   **Флаги:** Содержимое файла `~/.config/[browser]-flags.conf`.
*   **Путь к файлу:** Полный путь к файлу с флагами.
*   **Примечания (необязательно):** Ключевые драйверы, пакеты или особенности настройки.

## Шаги настройки

1.  **Найдите файл с флагами:** Определите путь к файлу флагов вашего браузера в разделе «Конфигурации GPU и браузеров».
2.  **Отредактируйте файл:** Откройте или создайте файл с помощью `nano` (или вашего любимого текстового редактора, например `micro`, `vim`).

    ```bash
    nano [ПУТЬ_К_ФАЙЛУ_ФЛАГОВ_ВАШЕГО_БРАУЗЕРА]
    # Пример: nano ~/.config/chrome-flags.conf
    ```

3.  **Добавьте флаги:** Вставьте в файл флаги, подходящие для вашего GPU и браузера.
4.  **Сохраните и закройте.**
5.  **Перезапустите браузер:** Закройте все окна браузера и запустите его снова.
6.  **Проверьте:** Перейдите на страницу `chrome://gpu` (или `brave://gpu`, `edge://gpu` и т. д.). Убедитесь, что в разделах «Video Acceleration Information» и «Graphics Feature Status» указан статус «Hardware accelerated».

## Советы по проверке

Чтобы точно убедиться, что аппаратное ускорение активно во время воспроизведения видео, используйте следующие методы:

### 1. Проверьте загрузку GPU AMD (`amdgpu_top`)

Если у вас GPU от AMD и установлен `amdgpu_top`, откройте терминал и выполните:

```bash
amdgpu_top
````

Во время воспроизведения видео в браузере (например, на YouTube) обратите внимание на раздел `media` в выводе `amdgpu_top`. Вы должны увидеть там некоторую активность, что указывает на работу медиа-движка вашего GPU. Если во время воспроизведения видео значение остаётся на 0%, возможно, аппаратное ускорение для декодирования не задействовано полностью.

### 2. Проверьте инструменты разработчика в браузере (Video Decoder)

Этот метод даёт прямое подтверждение от самого браузера:

1.  Откройте ваш браузер на базе Chromium.

2.  Начните воспроизведение видео (например, на YouTube или локальный файл).

3.  Откройте инструменты разработчика: нажмите `F12` или `Ctrl+Shift+I`.

4.  Перейдите на вкладку **Media**. Если вы её не видите, нажмите на три точки (`...`) или `>>` (Больше вкладок) на панели инструментов разработчика, затем выберите `Media`.

5.  В разделе «Players» слева кликните по записи, соответствующей вашему видео.

6.  На главной панели прокрутите вниз до раздела **Video Decoder**.

7.  Найдите строку `Hardware decoder`. Значение должно быть `true`. Если там указано `false` или имя программного декодера (например, `FFmpegVideoDecoder`, `VpxVideoDecoder`, `Dav1dVideoDecoder`), значит аппаратное ускорение для этого видео не активно.

## Конфигурации GPU и браузеров

### AMD Radeon RX 6900 XT (Google Chrome)

*   **Браузер:** Google Chrome

*   **GPU:** AMD Radeon RX 6900 XT

*   **Файл с флагами:** `~/.config/chrome-flags.conf`

```bash
--use-gl=angle
--use-angle=vulkan
--enable-features=Vulkan,VulkanFromANGLE,DefaultANGLEVulkan,AcceleratedVideoDecodeLinuxZeroCopyGL,AcceleratedVideoEncoder,VaapiIgnoreDriverChecks,UseMultiPlaneFormatForHardwareVideo
--ozone-platform-hint=x11
```

**Примечания:** Использует Vulkan (через ANGLE) и VA-API. Флаг `--ozone-platform-hint=x11` может быть полезен даже в Wayland для некоторых сценариев ускорения.
