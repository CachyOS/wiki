## Как установить недостающую сессию X11

После того как разработчики KDE решили разделить свою разработку на несколько пакетов, сессия X11 была удалена из стандартной установки.

```sh
sudo pacman -S plasma-x11-session kwin-x11
```

## FAQ

### Как мне получить такой же вид, как на скриншотах KDE, под названием "Emerald"?

- Это комбинация темы Emerald и темы иконок Qogir, которые не установлены по умолчанию.
  - ```sh title='Установите обе с помощью следующей команды'
    sudo pacman -S cachyos-emerald-kde-theme-git qogir-icon-theme
    ```
  Примените обе в `Внешний вид - Цвета и темы`

### Почему SDDM выглядит так пресно и старо?

- *Поскольку по умолчанию тема SDDM не применяется, SDDM будет использовать классическую тему.*
  - **Примените тему Breeze, как показано на скриншоте**
