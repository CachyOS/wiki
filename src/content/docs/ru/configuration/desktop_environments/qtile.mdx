## Горячие клавиши

Большинство комбинаций клавиш требуют использования клавиши-модификатора, которой в нашем случае является клавиша Windows (обозначается как SUPER). Вы можете изменить её в файле конфигурации.
Некоторые из них могут использовать mod1 (клавиша ALT).

### Управление приложениями

| Описание | Клавиша |
|-------------|-----|
| Открыть терминал | <Kbd linux="Super+Return" /> |
| Открыть Rofi (запуск программ) | <Kbd linux="Alt+Space" /> |
| Открыть файловый менеджер (Thunar) | <Kbd linux="Super+E" /> |
| Закрыть активное окно | <Kbd linux="Super+Q" /> |

### Навигация по рабочим столам

| Описание | Клавиша |
|-------------|-----|
| Переключиться на рабочий стол (1-9) | <Kbd linux="Super+1" /> до <Kbd linux="Super+9" /> |

### Навигация по окнам

| Описание | Клавиша |

| Переместить фокус вверх | <Kbd linux="Super+K" /> |
| Переместить окна между колонками или вверх/вниз в стеке | <Kbd linux="Super+Space" /> |

## FAQ

### Почему виджет громкости показывает ошибку или застрял на 0%?

* Иногда это происходит из-за того, что виджет громкости Qtile не может определить ваше устройство вывода по умолчанию. Вы можете [заглянуть в вики](https://docs.qtile.org/en/latest/manual/ref/widgets.html#pulsevolume) для получения дополнительной информации.

### Есть ли скрипт autostart.sh?

* Да, он находится в `scripts/` в папке Qtile.

### Взаимодействует ли панель Qtile с мышью?

* Да, например, если вы прокручиваете колесиком мыши по маленьким точкам, которые являются вашими рабочими столами (активный, неактивный, пустой и т.д.), вы переключитесь влево или вправо, или даже сможете кликнуть на один из них.
* Другой пример — раскладка (по умолчанию "колонки"), клик по ней позволяет переключаться между доступными раскладками.
* Использование CPU и RAM: клик по этому виджету откроет Btop (системный монитор для терминала).
* Увеличить/Уменьшить/Выключить звук можно, взаимодействуя с виджетом громкости.

Для получения дополнительной информации о Qtile, пожалуйста, [ознакомьтесь с их вики](https://docs.qtile.org/en/stable/).
