:::caution
С тех пор как Hyprland начал свою переработку, имейте в виду, что в настоящее время он нестабилен, и вы можете столкнуться с ошибками/неожиданными сбоями. Используйте на свой страх и риск.
Даже их "стабильная" версия также сломана и полна ошибок, поэтому мы не планируем оказывать поддержку вне наших dotfiles. Обращайтесь к их [вики](<https://wiki.hyprland.org/>).
:::

Наша главная цель в нашей конфигурации — работающий Hyprland, но при этом простой, поэтому некоторые важные инструменты и программы, такие как графический файловый менеджер, могут отсутствовать.

Загляните в наш [FAQ по Hyprland.](/ru/configuration/desktop_environments/hyprland/#faq)

**Dotfiles поддерживаются [msmafra](https://github.com/msmafra) и [Lysec](https://github.com/Ly-sec)**

## Горячие клавиши

Большинство комбинаций клавиш требуют использования клавиши-модификатора, которая в нашем случае является клавишей Windows (обозначается как SUPER), вы можете изменить ее в файле конфигурации.

### Управление приложениями

| Описание | Клавиша |
|-------------|-----|
| Открыть терминал | <Kbd linux="Super+Return" /> |
| Открыть Rofi (запуск программ) | <Kbd linux="Super+Space" /> |
| Открыть файловый менеджер | <Kbd linux="Super+E" /> |
| Закрыть активное окно | <Kbd linux="Super+Q" /> |

### Навигация по рабочим столам

| Описание | Клавиша |
|-------------|-----|
| Перейти на рабочий стол (1-9) | <Kbd linux="Super+1" /> до <Kbd linux="Super+9" /> |
| Следующий рабочий стол | <Kbd linux="Super+Period" /> |
| Предыдущий рабочий стол | <Kbd linux="Super+Comma" /> |
| Переключаться между рабочими столами колесом прокрутки | <Kbd linux="Super+Scroll" /> |

### Навигация по окнам

| Описание | Клавиша |
|-------------|-----|
| Сфокусироваться на окне сверху | <Kbd linux="Super+ArrowUp" /> |
| Сфокусироваться на окне снизу | <Kbd linux="Super+ArrowDown" /> |
| Сфокусироваться на окне слева | <Kbd linux="Super+ArrowLeft" /> |
| Сфокусироваться на окне справа | <Kbd linux="Super+ArrowRight" /> |
| Сменить активную группу | <Kbd linux="Super+Tab" /> |

### Управление окнами

| Описание | Клавиша |
|-------------|-----|
| Переместить окно на рабочий стол (1-9) без переключения | <Kbd linux="Super+Shift+1" /> до <Kbd linux="Super+Shift+9" /> |
| Переместить окно на рабочий стол (1-9) и переключиться на него | <Kbd linux="Super+Control+1" /> до <Kbd linux="Super+Control+9" /> |
| Переместить окно вверх | <Kbd linux="Super+Shift+ArrowUp" /> |
| Переместить окно вниз | <Kbd linux="Super+Shift+ArrowDown" /> |
| Переместить окно влево | <Kbd linux="Super+Shift+ArrowLeft" /> |
| Переместить окно вправо | <Kbd linux="Super+Shift+ArrowRight" /> |
| Переключить полноэкранный режим для окна | <Kbd linux="Super+F" /> |
| Переключить плавающий режим для окна | <Kbd linux="Super+V" /> |
| Закрепить окно на всех рабочих столах (в плавающем режиме) | <Kbd linux="Super+Y" /> |
| Переключить окно в группу | <Kbd linux="Super+K" /> |

### Изменение размера окон

| Описание | Клавиша |
|-------------|-----|
| Войти в режим изменения размера (используйте H,J,K,L или стрелки, Escape для выхода) | <Kbd linux="Super+R" /> |
| Уменьшить размер окна вниз | <Kbd linux="Super+Control+Shift+J" /> или <Kbd linux="Super+Control+Shift+ArrowDown" /> |
| Увеличить размер окна вверх | <Kbd linux="Super+Control+Shift+K" /> или <Kbd linux="Super+Control+Shift+ArrowUp" /> |
| Уменьшить размер окна влево | <Kbd linux="Super+Control+Shift+H" /> или <Kbd linux="Super+Control+Shift+ArrowLeft" /> |
| Увеличить размер окна вправо | <Kbd linux="Super+Control+Shift+L" /> или <Kbd linux="Super+Control+Shift+ArrowRight" /> |

### Управление мышью

| Описание | Клавиша |
|-------------|-----|
| Перемещать окно с помощью мыши | <Kbd linux="Super+LeftClick" /> |
| Изменять размер окна с помощью мыши | <Kbd linux="Super+RightClick" /> |

### Управление системой

| Описание | Клавиша |
|-------------|-----|
| Сделать скриншот | <Kbd linux="Super+A" /> |
| Перезагрузить Waybar | <Kbd linux="Super+O" /> |
| Уменьшить зазор между окнами | <Kbd linux="Super+G" /> |
| Сбросить зазоры к значениям по умолчанию | <Kbd linux="Super+Shift+G" /> |

### Управление мультимедиа

| Описание | Клавиша |
|-------------|-----|
| Управление громкостью | Мультимедийные клавиши: <Kbd linux="VolUp" /> <Kbd linux="VolDown" /> <Kbd linux="Mute" /> |
| Управление яркостью | Мультимедийные клавиши: зависит от оборудования |
| Управление воспроизведением | Мультимедийные клавиши:  <Kbd linux="Play/Pause" /> <Kbd linux="Next" /> <Kbd linux="Previous" /> |
## FAQ

### Почему у моих Discord, Thunar и Nautilus странный фон?

Это происходит потому, что у окна изменена прозрачность.

* Рассмотрите возможность изменения правила для окна в файле конфигурации [Hyprland](https://github.com/CachyOS/cachyos-hyprland-settings/blob/master/etc/skel/.config/hypr/config/windowrules.conf#L21).

```sh title='Пример'
windowrulev2 = opacity 0.92, class:^(thunar|nemo)$
```

### Включен ли файловый менеджер?

* Нет, установите тот, который вам нравится.
