## Горячие клавиши

Большинство комбинаций клавиш требуют использования клавиши-модификатора, которой в нашем случае является клавиша Windows (обозначается как SUPER). Вы можете изменить её в файле конфигурации.

### Управление приложениями

| Описание | Клавиша |
|-------------|-----|
| Открыть терминал | <Kbd linux="Super+Return" /> |
| Открыть Rofi (запуск программ) | <Kbd linux="Control+Space" /> |
| Закрыть активное окно | <Kbd linux="Super+Q" /> |

### Навигация по рабочим пространствам

| Описание | Клавиша |
|-------------|-----|
| Переключиться на рабочее пространство (1-9) | <Kbd linux="Super+1" /> ... <Kbd linux="Super+9" /> |

### Навигация по окнам

| Описание | Клавиша |
|-------------|-----|
| Переключить фокус влево | <Kbd linux="Super+ArrowLeft" /> |
| Переключить фокус вправо | <Kbd linux="Super+ArrowRight" /> |
| Переключить фокус вверх | <Kbd linux="Super+ArrowUp" /> |
| Переключить фокус вниз | <Kbd linux="Super+ArrowDown" /> |
| Сфокусироваться на последнем плавающем/тайловом контейнере | <Kbd linux="Super+Space" /> |

### Управление окнами

| Описание | Клавиша |

| Переместить активное окно на рабочее пространство (1-9) | <Kbd linux="Super+Shift+1" /> ... <Kbd linux="Super+Shift+9" /> |

| Переместить активное окно вправо | <Kbd linux="Super+Shift+ArrowRight" /> |
| Переместить активное окно вверх | <Kbd linux="Super+Shift+ArrowUp" /> |
| Переместить активное окно вниз | <Kbd linux="Super+Shift+ArrowDown" /> |
| Включить/выключить полноэкранный режим | <Kbd linux="Super+F" /> |
| Включить/выключить плавающий режим | <Kbd linux="Super+Shift+Space" /> |

### Управление раскладкой

| Описание | Клавиша |

### Режим изменения размера

| Описание | Клавиша |
|-------------|-----|
| Войти в режим изменения размера | <Kbd linux="Super+R" /> |
| Изменить размер влево (в режиме изменения размера) | <Kbd linux="ArrowLeft" /> |
| Изменить размер вправо (в режиме изменения размера) | <Kbd linux="ArrowRight" /> |

## FAQ

### Как создать автозапуск для программы? например "установить обои при запуске"

* В i3 уже есть гибкая функция автозапуска, которая позволяет выполнять любую программу или даже команды.

Если вы посмотрите в конец нашего файла конфигурации, вы увидите строки, начинающиеся с exec и exec_always.

Например:

```exec chromium```

Это означает, что Chromium запустится в первом рабочем пространстве при каждом входе в сессию i3.

### Чем exec отличается от exec_always?

exec_always даёт возможность всегда выполнять определённое действие, даже после перезагрузки конфигурации i3wm.

* Для дополнительной информации и справок обратитесь к руководству пользователя i3
* https://i3wm.org/docs/userguide.html#exec

### Работают ли мультимедийные клавиши?

* Да, работают.
