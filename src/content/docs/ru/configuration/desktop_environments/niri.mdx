:::note
Niri — это Wayland-композитор с прокручиваемой мозаикой, который предлагает уникальный подход к управлению окнами с помощью системы макетов на основе столбцов.
:::

Наша главная цель при настройке — создать рабочую конфигурацию Niri, которая обеспечивает плавный и интуитивно понятный опыт использования рабочего стола, сохраняя при этом простоту и доступность конфигурации.

Ознакомьтесь с нашим [FAQ по Niri.](/ru/configuration/desktop_environments/niri#faq)

**Файлы конфигурации поддерживаются [Ly-sec](https://github.com/Ly-sec)**
При возникновении проблем с Noctalia, пожалуйста, обратитесь к [документации Noctalia](https://docs.noctalia.dev/).

## Сочетания клавиш

Большинство сочетаний клавиш требуют использования клавиши-модификатора, которой в нашем случае является клавиша Windows (обозначается как SUPER). Вы можете изменить её в файле конфигурации.

### Управление приложениями

| Описание | Клавиша |
|-------------|-----|
| Открыть терминал | <Kbd linux="Super+Return" /> |
| Открыть меню запуска программ | <Kbd linux="Super+Ctrl+Return" /> |
| Открыть браузер (Firefox) | <Kbd linux="Super+B" /> |
| Открыть файловый менеджер | <Kbd linux="Super+E" /> |
| Закрыть активное окно | <Kbd linux="Super+Q" /> |
| Заблокировать экран | <Kbd linux="Super+Alt+L" /> |

## FAQ

### Чем Niri отличается от других оконных менеджеров?

Niri использует уникальный подход прокручиваемой мозаики, где окна располагаются в столбцах, которые можно прокручивать по горизонтали. Это создает метафору бесконечного рабочего стола, что особенно полезно для сверхшироких мониторов и рабочих процессов, требующих множества открытых приложений.

### Как изменить раскладку клавиатуры?

Отредактируйте раздел `input` в вашем файле конфигурации:

```txt title='Пример'
input {
    keyboard {
        xkb {
            layout "us" // Измените "de" на предпочитаемую раскладку
        }
    }
}
```

### Можно ли настроить отступы и внешний вид окон?

Да, вы можете изменить раздел `layout`:

```txt title='Пример'
layout {
    gaps 8 // Изменить размер отступов

    focus-ring {
        width 2
        active-color "#your-color"
        inactive-color "#your-color"
    }
}
```

### Как добавить больше приложений в автозапуск?

Добавьте их в раздел `startup`:

```txt title='Пример'
spawn-at-startup "your-application"
```

### Для чего нужна клавиша аварийного выхода?

Сочетание `Super+Escape` предназначено для восстановления управления, когда полноэкранное приложение блокирует ваши сочетания клавиш. Оно отключает любой активный ингибитор сочетаний клавиш.

### Как настроить несколько мониторов?

Раскомментируйте и измените раздел `output` для ваших конкретных дисплеев. Выполните `niri msg outputs`, чтобы получить правильные имена:

```txt title='Пример'
output "DP-1" {
    mode "1920x1080@60.000"
    scale 1
}
```
