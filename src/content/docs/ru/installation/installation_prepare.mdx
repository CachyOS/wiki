## Системные требования

Перед подготовкой к установке убедитесь, что используемый компьютер соответствует минимальным системным требованиям для запуска CachyOS. Установщик
использует процесс онлайн-установки, поэтому стабильное и относительно быстрое интернет-соединение является обязательным.

:::note[Виртуальные машины]
Не рекомендуется устанавливать CachyOS на виртуальную машину. Виртуальные машины могут иметь проблемы с неправильной конфигурацией или быть полностью сломанными. Рекомендуется устанавливать CachyOS на "голое железо".
:::

<Tabs>

<TabItem label="Минимальные требования">

*   3 ГБ ОЗУ
*   30 ГБ дискового пространства (HDD/SSD)
*   Стабильное интернет-соединение

:::caution
Нестабильное интернет-соединение может привести к увеличению времени установки или, в худшем случае, к сбоям установки.
:::

</TabItem>

<TabItem label="Рекомендуемые требования">

*   8 ГБ ОЗУ
*   50 ГБ дискового пространства (SSD/NVMe)
*   [Процессор, совместимый с x86-64-v3](/ru/installation/installation_prepare#поддержка-уровня-микроархитектуры-x86_64)
*   Скорость интернета 50 Мбит/с или выше
*   Графический процессор NVIDIA (серия 900+ - например: GTX 950), AMD +GCN 1.0 (например: AMD R7 240) или Intel (серия Integrated HD Graphics или выше, серия Arc)

</TabItem>

</Tabs>

## Создание загрузочного USB-накопителя CachyOS

Существует несколько инструментов и методов, которые можно использовать для создания загрузочного USB-накопителя с CachyOS.

:::tip
Храните копию ISO-образа CachyOS на том же накопителе или в другом месте, чтобы вы могли использовать его позже для устранения неполадок через chroot.
:::

:::note
USB-накопитель должен иметь не менее 8 ГБ свободного места.
:::

### balenaEtcher

<Steps>

1. Скачайте [balenaEtcher](<https://etcher.balena.io/>). balenaEtcher поддерживает запись образов для Linux, MacOS и Windows.
   Если был скачан `.zip` файл, распакуйте его и запустите исполняемый файл с помощью следующих команд:
      ```sh
      # Распаковать zip-файл:
      bsdtar xvf <имя zip-файла>
      # Перейти в новую папку:
      cd balenaEtcher-linux-x64/
      # Запустить balenaEtcher:
      ./balena-etcher
      ```
2. Подключите USB-накопитель к компьютеру.
3. Выберите `Flash from file` и выберите файл ISO-образа CachyOS.
4. Нажмите `Select target` и выберите ранее подключенный USB-накопитель.
5. Нажмите `Flash`, чтобы начать процесс записи.

</Steps>

:::note
balenaEtcher может запросить права администратора. Если это произойдет, введите свой пароль и нажмите `Authenticate`.
:::

### Интерфейс командной строки (Linux и MacOS)

<Steps>

1. Подключите USB-накопитель.
2. Определите подключенный USB-накопитель с помощью следующих команд:
   ```sh
   # Linux
   # USB-накопитель можно определить, например, как /dev/sda, по модели и размеру диска.
   sudo fdisk -l

   # MacOS
   # USB-накопители определяются как "/dev/diskY", где "Y" может быть 0, 1 и т.д.
   diskutil list
   ```
3. Скопируйте содержимое ISO на подключенный USB-накопитель, выполнив:
   ```sh
   # Замените <usbdrive> на метку накопителя.
   sudo dd bs=4M if=полное_имя_iso.iso of=/dev/<usbdrive> status=progress oflag=sync
   ```
</Steps>

- `dd` теперь скопирует содержимое ISO-файла на подключенный USB-накопитель.

### Rufus (только для Windows)

<Steps>

1. Подключите USB-накопитель.
2. Скачайте [Rufus](<https://rufus.ie/>) и установите его или запустите портативную версию.
3. В поле `Device` нажмите на выпадающий список и выберите подключенный USB-накопитель.
4. В поле `Boot selection` нажмите `SELECT` и найдите файл ISO-образа CachyOS.
5. Нажмите `START`.

</Steps>

### Ventoy (Linux и Windows)

<Tabs>

<TabItem label="Linux">

<Steps>

1. Подключите USB-накопитель.
2. Скачайте [Ventoy](<https://www.ventoy.net/en/download.html>)
3. Распакуйте Ventoy с помощью следующей команды:
   ```sh
   # Замените версию на правильную, например: ventoy-1.1.07-linux.tar.gz
   bsdtar xvf ventoy-версия-linux.tar.gz
   # Перейдите в новую папку: (версия может отличаться)
   cd ventoy-1.1.07/
   ```
4. Запустите `VentoyGUI.x86_64`, дважды щелкнув по нему или через терминал:
   ```sh
   # Программа запросит права администратора, введите свои учетные данные
   ./VentoyGUI.x86_64
   ```
5. Выберите подключенный USB-накопитель, нажав на `Device`.
6. Нажмите `Install`.
7. После завершения установки Ventoy на подключенный USB-накопитель закройте окно и поместите ISO-файл CachyOS в новый доступный раздел накопителя.

</Steps>

</TabItem>

<TabItem label="Windows">

<Steps>
1. Подключите USB-накопитель.
2. Скачайте [Ventoy](<https://www.ventoy.net/en/download.html>)
3. Запустите `Ventoy2Disk.exe`
4. Выберите подключенный USB-накопитель, нажав на `Device`.
5. Нажмите `Install`.
6. После завершения установки Ventoy на USB-накопитель закройте окно и поместите ISO-файл CachyOS в новый доступный раздел накопителя.
</Steps>

</TabItem>

</Tabs>
