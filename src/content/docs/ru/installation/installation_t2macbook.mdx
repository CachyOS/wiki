CachyOS обеспечивает встроенную поддержку для MacBook с чипом T2, включая необходимые патчи ядра во всех предоставляемых дистрибутивах. Однако для успешной установки требуется выполнить несколько ключевых шагов.

:::caution[Потенциальные риски]
Полное удаление macOS сопряжено с рисками, такими как потеря данных или приведение устройства в нерабочее состояние. **Настоятельно рекомендуется** сохранить раздел с macOS для обновлений прошивки и восстановления. Подробности см. в [T2 Linux roadmap](https://wiki.t2linux.org/roadmap/#can-i-completely-remove-macos).

Если вы все же решите удалить macOS, убедитесь, что у вас есть полная резервная копия, и заранее создайте [загрузочный установщик macOS](https://support.apple.com/ru-ru/101578).
:::

## Подготовка к установке

Создание загрузочного установщика macOS является необязательным, но рекомендуется, если вы планируете изменять разделы или удалять macOS. Он может пригодиться для обновлений прошивки, устранения неполадок или восстановления системы. Подробные инструкции см. в [руководстве Apple](https://support.apple.com/ru-ru/101578).

Выполните следующие шаги в macOS **перед** загрузкой установщика CachyOS.

### Подготовьте загрузочный USB-накопитель CachyOS

Загрузите [ISO-образ CachyOS](/ru/cachyos_basic/download) и следуйте инструкциям в разделе [Создание загрузочного USB-накопителя CachyOS](/ru/installation/installation_prepare#создание-загрузочного-usb-накопителя-cachyos), чтобы создать установочный носитель.

### (Необязательно) Извлеките прошивку Wi-Fi

:::note
Wi-Fi **не будет работать** «из коробки» во время или после установки, поскольку требуемая прошивка является проприетарной и не может распространяться CachyOS. Для процесса установки вам потребуется подключение к интернету (например, через Ethernet или USB-модем), если только вы не выполните шаги ниже, чтобы заранее подготовить прошивку Wi-Fi и включить ее во время установки.
:::

Находясь в macOS, откройте Терминал и выполните следующую команду. Это скопирует необходимые файлы прошивки Wi-Fi в ваш EFI-раздел, сделав их доступными позже во время установки CachyOS.
```sh
curl -sL https://wiki.t2linux.org/tools/firmware.sh | bash -s copy_to_efi
```

### Подготовьте ваш диск

Если вы планируете использовать двойную загрузку с macOS (рекомендуется), вам необходимо освободить место для CachyOS. Используйте Дисковую утилиту в macOS, чтобы изменить размер существующего раздела macOS:

<Steps>

1.  Откройте **Дисковую утилиту**.
2.  В боковой панели Дисковой утилиты выберите **том**, размер которого вы хотите изменить (обычно называется "Macintosh HD" или похоже).
3.  Нажмите кнопку **«Разбить на разделы»** на панели инструментов.
4.  Нажмите кнопку **«+» (плюс)** под круговой диаграммой, представляющей использование вашего диска.
5.  **Важно:** когда появится запрос, выберите **«Добавить раздел»**, а *не* «Добавить том». Вам нужно создать отдельный раздел для Linux.
6.  **Имя:** Введите описательное имя для нового раздела (например, «CachyOS» или «Linux»).
7.  **Формат:** Выберите любой доступный формат (например, APFS или Mac OS Extended). Установщик CachyOS переформатирует этот раздел позже, поэтому первоначальный выбор не имеет значения.
8.  **Размер:** Выделите желаемый объем дискового пространства для CachyOS. **Имейте в виду, что изменение размера разделов позже может быть затруднительным или невозможным**, поэтому выберите размер, соответствующий вашим потребностям.
10. Нажмите **«Применить»**, чтобы создать новый раздел. Дисковая утилита изменит размер вашего раздела macOS и создаст новое пустое пространство.

</Steps>


### Отключите безопасную загрузку (Secure Boot)

<Steps>

1. Перезагрузите ваш Mac и сразу после включения удерживайте `Command (⌘) + R`, чтобы войти в режим восстановления.
2. Перейдите в Утилиты > Утилита безопасной загрузки.
3. Выберите «Без защиты» в разделе **Безопасная загрузка** и «Разрешить загрузку с внешних или съёмных носителей» в разделе **Разрешённые загрузочные носители**.

</Steps>

Для получения дополнительной информации обратитесь к [руководству Apple по Утилите безопасной загрузки](https://support.apple.com/ru-ru/102522).

Для дополнительного обзора подготовки Mac с чипом T2 к установке Linux обратитесь к [руководству по предустановке t2linux](https://wiki.t2linux.org/guides/preinstall/).

## Процесс установки

<Steps>

1.  **Загрузитесь с USB-накопителя CachyOS:**
    *   Перезагрузите ваш Mac и сразу после включения удерживайте клавишу `Option (⌥)`.
    *   Выберите USB-накопитель CachyOS (обычно помеченный как "EFI Boot").
2.  **(Необязательно) Включите Wi-Fi в Live-окружении:**
    *   Если вам нужен Wi-Fi во время установки и у вас нет Ethernet/модема, откройте терминал после загрузки live-окружения CachyOS.
    *   Выполните эти команды, чтобы скопировать прошивку из раздела EFI (созданного в разделе [Извлеките прошивку Wi-Fi](#необязательно-извлеките-прошивку-wi-fi)) и настроить NetworkManager:
        ```sh
        # Смонтировать раздел EFI (обычно nvme0n1p1 на Mac с T2)
        sudo mkdir -p /tmp/apple-wifi-efi
        sudo mount /dev/nvme0n1p1 /tmp/apple-wifi-efi

        # Скопировать прошивку из EFI в live-окружение
        bash /tmp/apple-wifi-efi/firmware.sh get_from_efi
        sudo umount /tmp/apple-wifi-efi

        # Настроить NetworkManager для использования бэкенда iwd
        cat <<EOF | sudo tee /etc/NetworkManager/conf.d/wifi_backend.conf
        [device]
        wifi.backend=iwd
        EOF
        sudo systemctl restart NetworkManager
        ```
    *   Теперь вы должны иметь возможность подключаться к сетям Wi-Fi с помощью апплета сети в системном трее.
3.  **Запустите установщик CachyOS:**
    *   Запустите установщик CachyOS с рабочего стола или из меню приложений.
    *   Следуйте стандартной процедуре установки, обращаясь к руководству [Установка в корневой раздел](/ru/installation/installation_on_root).
    *   При разметке диска выберите свободное пространство, созданное ранее. Позвольте установщику выполнить форматирование.
        :::caution[Осторожно при разметке]
        Будьте **очень осторожны** на этапе разметки диска в установщике. Убедитесь, что вы выбираете правильное свободное пространство, которое вы подготовили, и **не** удаляйте или не форматируйте случайно ваш существующий раздел macOS, особенно если вы намерены использовать двойную загрузку. Дважды проверьте свой выбор перед тем, как продолжить.
        :::
    *   CachyOS Hardware Detection ([chwd](/ru/features/chwd)) должен автоматически применить необходимые параметры загрузки и конфигурации для T2 во время установки.

</Steps>

## Шаги после установки

После завершения установки и перезагрузки в вашу новую систему CachyOS вам может потребоваться выполнить несколько дополнительных шагов, чтобы убедиться, что все работает гладко.

### Установите прошивку Wi-Fi на постоянной основе

Если вы выполнили необязательный шаг [Включите Wi-Fi в Live-окружении](#процесс-установки), чтобы получить прошивку в live ISO, вы можете просто выполнить его снова, чтобы включить Wi-Fi. В противном случае подключитесь к интернету (например, через Ethernet, USB-модем) и выполните следующие шаги:

<Steps>
1. Откройте терминал и загрузите пакет прошивки из зеркала Arch Linux T2:
   ```sh
   curl https://mirror.funami.tech/arch-mact2/os/x86_64/apple-bcm-firmware-14.0-1-any.pkg.tar.zst -o apple-bcm-firmware-14.0-1-any.pkg.tar.zst
   ```
2. Установите загруженный пакет:
   ```sh
   sudo pacman -U apple-bcm-firmware-14.0-1-any.pkg.tar.zst
   ```
3. Перезагрузите модули ядра Wi-Fi:
   ```bash
   sudo modprobe -r brcmfmac_wcc
   sudo modprobe -r brcmfmac
   sudo modprobe brcmfmac
   ```
</Steps>

Теперь Wi-Fi должен стабильно работать после перезагрузок. Вы можете удалить загруженный файл `.pkg.tar.zst`.
