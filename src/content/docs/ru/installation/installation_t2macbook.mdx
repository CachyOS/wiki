CachyOS обеспечивает поддержку MacBook с чипом T2 «из коробки», включая необходимые патчи для ядра во всех предоставляемых дистрибутивах. Однако для успешной установки требуется выполнить несколько ключевых шагов.

:::caution[Потенциальные риски]
Полное удаление macOS сопряжено с рисками, такими как потеря данных или приведение устройства в нерабочее состояние. **Настоятельно рекомендуется** сохранить раздел с macOS для обновлений прошивки и восстановления системы. Подробности см. в [Дорожной карте T2 Linux](https://wiki.t2linux.org/roadmap/#can-i-completely-remove-macos).

Если вы все же решите удалить macOS, убедитесь, что у вас есть полная резервная копия, и заранее создайте [загрузочный установщик macOS](https://support.apple.com/ru-ru/101578).
:::

## Подготовка к установке

Создание загрузочного установщика macOS не является обязательным, но рекомендуется, если вы планируете изменять разделы или удалять macOS. Он может быть полезен для обновления прошивки, устранения неполадок или восстановления системы. Подробные инструкции можно найти в [руководстве Apple](https://support.apple.com/ru-ru/101578).

Выполните следующие шаги в macOS **перед** загрузкой установщика CachyOS.

### Подготовьте загрузочный USB-накопитель с CachyOS

Скачайте [ISO-образ CachyOS](/ru/cachyos_basic/download) и следуйте инструкциям в разделе [Создание загрузочного USB-накопителя с CachyOS](/ru/installation/installation_prepare#создание-загрузочного-usb-накопителя-cachyos), чтобы создать установочный носитель.

### (Необязательно) Извлечение прошивки Wi-Fi

:::note
Wi-Fi **не будет работать** «из коробки» во время или после установки, поскольку необходимая прошивка является проприетарной и не может распространяться CachyOS. Для процесса установки вам потребуется подключение к интернету (например, через Ethernet или USB-модем), если вы не выполните шаги ниже, чтобы заранее подготовить прошивку Wi-Fi и включить ее во время установки.
:::

Находясь в macOS, откройте Терминал и выполните следующую команду. Она скопирует необходимые файлы прошивки Wi-Fi в ваш раздел EFI, сделав их доступными позже во время установки CachyOS.
```sh
curl -sL https://wiki.t2linux.org/tools/firmware.sh | bash -s copy_to_efi
```

### Подготовьте ваш диск

Если вы планируете использовать двойную загрузку с macOS (рекомендуется), вам нужно освободить место для CachyOS. Используйте приложение «Дисковая утилита» в macOS, чтобы изменить размер существующего раздела macOS:

<Steps>

1.  Откройте **Дисковую утилиту**.
2.  На боковой панели Дисковой утилиты выберите **том**, который вы хотите изменить (обычно называется "Macintosh HD" или подобным образом).
3.  Нажмите кнопку **«Разбить на разделы»** на панели инструментов.
4.  Нажмите кнопку **«+» (плюс)** под круговой диаграммой, представляющей использование вашего диска.
5.  **Важно:** когда появится запрос, выберите **«Добавить раздел»**, а *не* «Добавить том». Вам нужно создать отдельный раздел для Linux.
6.  **Имя:** Введите описательное имя для нового раздела (например, "CachyOS" или "Linux").
7.  **Формат:** Выберите любой доступный формат (например, APFS или Mac OS Extended). Установщик CachyOS позже переформатирует этот раздел, поэтому первоначальный выбор не имеет значения.
8.  **Размер:** Выделите желаемый объем дискового пространства для CachyOS. **Имейте в виду, что последующее изменение размера разделов может быть сложным или невозможным**, поэтому выберите размер, отвечающий вашим потребностям.
10. Нажмите **«Применить»**, чтобы создать новый раздел. Дисковая утилита изменит размер вашего раздела macOS и создаст новое пустое пространство.

</Steps>


### Отключите безопасную загрузку (Secure Boot)

<Steps>

1. Перезагрузите ваш Mac и сразу после включения зажмите `Command (⌘) + R`, чтобы войти в режим восстановления.
2. Перейдите в меню «Утилиты» > «Утилита безопасной загрузки».
3. В разделе **Безопасная загрузка** выберите «Безопасность отключена», а в разделе **Разрешенные загрузочные носители** — «Разрешить загрузку с внешних или съемных носителей».

</Steps>

Для получения дополнительной информации обратитесь к [руководству Apple по Утилите безопасной загрузки](https://support.apple.com/ru-ru/102522).

## Процесс установки

<Steps>

1.  **Загрузитесь с USB-накопителя CachyOS:**
    *   Перезагрузите ваш Mac и сразу после включения зажмите клавишу `Option (⌥)`.
    *   Выберите USB-накопитель с CachyOS (обычно он называется "EFI Boot").
2.  **(Необязательно) Включите Wi-Fi в Live-окружении:**
    *   Если вам нужен Wi-Fi во время установки, и у вас нет Ethernet/USB-модема, откройте терминал после загрузки live-окружения CachyOS.
    *   Выполните эти команды, чтобы скопировать прошивку из раздела EFI (созданного на шаге [Извлечение прошивки Wi-Fi](#необязательно-извлечение-прошивки-wi-fi)) и настроить NetworkManager:
        ```sh
        # Монтируем раздел EFI (обычно nvme0n1p1 на Mac с T2)
        sudo mkdir -p /tmp/apple-wifi-efi
        sudo mount /dev/nvme0n1p1 /tmp/apple-wifi-efi

        # Копируем прошивку из EFI в live-окружение
        bash /tmp/apple-wifi-efi/firmware.sh get_from_efi
        sudo umount /tmp/apple-wifi-efi

        # Настраиваем NetworkManager для использования iwd
        cat <<EOF | sudo tee /etc/NetworkManager/conf.d/wifi_backend.conf
        [device]
        wifi.backend=iwd
        EOF
        sudo systemctl restart NetworkManager
        ```
    *   Теперь вы должны иметь возможность подключаться к сетям Wi-Fi с помощью апплета сети в системном трее.
3.  **Запустите установщик CachyOS:**
    *   Запустите установщик CachyOS с рабочего стола или из меню приложений.
    *   Следуйте стандартной процедуре установки, обращаясь к руководству [Установка в корневой раздел](/ru/installation/installation_on_root).
    *   При разметке диска выберите свободное пространство, созданное ранее. Позвольте установщику выполнить форматирование.
        :::caution[Внимание при разметке диска]
        Будьте **очень осторожны** на этапе разметки диска в установщике. Убедитесь, что вы выбираете правильное свободное пространство, которое вы подготовили, и **не** удаляйте и не форматируйте случайно ваш существующий раздел macOS, особенно если вы собираетесь использовать двойную загрузку. Дважды проверьте свой выбор, прежде чем продолжить.
        :::
    *   CachyOS Hardware Detection ([chwd](/ru/features/chwd)) должен автоматически применить необходимые параметры загрузки и конфигурации для T2 во время установки.

</Steps>

## Действия после установки

После завершения установки и перезагрузки в вашу новую систему CachyOS, вам может потребоваться выполнить несколько дополнительных шагов, чтобы все работало гладко.

### Установите прошивку Wi-Fi на постоянной основе

Если вы выполнили необязательный шаг [Включите Wi-Fi в Live-окружении](#процесс-установки), чтобы получить прошивку в live-образе, вы можете просто повторить его, чтобы включить Wi-Fi. В противном случае подключитесь к интернету (например, через Ethernet, USB-модем) и выполните следующие шаги:

<Steps>
1. Откройте терминал и скачайте пакет с прошивкой из зеркала Arch Linux T2:
   ```sh
   curl https://mirror.funami.tech/arch-mact2/os/x86_64/apple-bcm-firmware-14.0-1-any.pkg.tar.zst -o apple-bcm-firmware-14.0-1-any.pkg.tar.zst
   ```
2. Установите скачанный пакет:
   ```sh
   sudo pacman -U apple-bcm-firmware-14.0-1-any.pkg.tar.zst
   ```
3. Перезагрузите модули ядра Wi-Fi:
   ```bash
   sudo modprobe -r brcmfmac_wcc
   sudo modprobe -r brcmfmac
   sudo modprobe brcmfmac
   ```
</Steps>

Теперь Wi-Fi должен стабильно работать после перезагрузок. Вы можете удалить скачанный файл `.pkg.tar.zst`.
