## Требования

:::caution[Secure Boot, CSM и Legacy USB Support должны быть отключены в настройках BIOS/UEFI при установке в режиме UEFI.]
Чтобы настроить Secure Boot после установки, обратитесь к разделу [Настройка Secure Boot](/ru/configuration/secure_boot_setup).
:::

:::caution[Избегайте использования опции «Установить рядом» в Calamares, так как это может привести к осложнениям и не рекомендуется.]
:::

:::tip
Настоятельно рекомендуется перезагрузить ISO после неудачной попытки установки.

В противном случае в процессе установки могут возникать постоянные ошибки.

Это происходит потому, что установщик не может корректно размонтировать разделы при неудачной установке.

:::

## Способы установки

### Стереть диск

Опция «Стереть диск» в Calamares очистит выбранный диск и установит на него CachyOS.

<Steps>

1. Загрузитесь с ISO и нажмите **Запустить установщик**

2. Выберите предпочтительный **Менеджер загрузки**. Для получения дополнительной информации см. раздел [Менеджеры загрузки](/ru/installation/boot_managers).

3. Установите предпочтительные **Язык** и **Регион/Часовой пояс**

4. Настройте **Раскладку клавиатуры**

5. Выберите **Стереть диск** и выберите [Файловую систему](/ru/installation/filesystem).

6. Выберите предпочтительное **Окружение рабочего стола**, см. [Окружения рабочего стола](/ru/installation/desktop_environments).

7. Настройте, какие пакеты должны или не должны быть установлены в процессе установки.

8. Установите учетные данные для входа.

9. Внимательно просмотрите сводку установки на странице обзора. Если все выглядит правильно, продолжите установку, нажав **Установить сейчас**. В противном случае вернитесь назад и внесите необходимые изменения.

</Steps>

### Ручная разметка

:::note[Перед тем как приступить к разметке диска для установки UEFI.]
    ```sh title='Выполните эту команду в терминале'
    efibootmgr -v
    ```
Если вывод: `EFI variables are not supported on this system.`, то система загружена в режиме Legacy/BIOS, и вам необходимо убедиться, что в настройках BIOS/UEFI сконфигурирован режим UEFI. См. **[раздел Требования](/ru/installation/installation_on_root#_top).**
:::

## Двойная загрузка

:::note[Это руководство предполагает, что Windows уже установлена в системе, и вы решили установить CachyOS рядом с ней.]
:::

:::caution
Убедитесь, что быстрая загрузка Windows (Fast Startup) отключена.
:::

<Tabs>
    <TabItem label='systemd-boot'>
        **Нам нужно скопировать двоичные файлы EFI Windows в раздел EFI Linux, чтобы менеджер загрузки мог их распознать.**

        <Steps>
        1. Найдите **раздел EFI Windows** с помощью `lsblk`

            ```sh title='Выполните эту команду в терминале'
            lsblk -o NAME,FSTYPE,SIZE,MOUNTPOINT
            ```
            ```sh title='Пример вывода'
                        NAME        FSTYPE   SIZE MOUNTPOINT
            zram0               15.3G [SWAP]
            nvme0n1            476.9G
            ├─nvme0n1p1 vfat     100M
            ├─nvme0n1p2           16M
            ├─nvme0n1p3 ntfs   234.4G
            ├─nvme0n1p4 ntfs     830M
            ├─nvme0n1p5 vfat       2G /boot
            └─nvme0n1p6 btrfs  239.6G /var/tmp
            ```
            Разделы EFI почти всегда отформатированы как `FAT32/vfat`. Поскольку `nvme0n1p1` не имеет точки монтирования в Linux, можно предположить, что этот раздел является разделом EFI Windows.

        2. Временно смонтируйте раздел EFI Windows

            ```sh
            sudo mount /dev/nvme0n1p1 /mnt/WinBoot # Замените `nvme0n1p1` на имя раздела EFI Windows.
            ```

        3. Скопируйте двоичные файлы EFI из **раздела EFI Windows** в **раздел EFI Linux**:

            ```sh
            sudo cp -r /mnt/WinBoot/EFI/* /boot/EFI
            ```

        4. Размонтируйте ранее смонтированный раздел, и Windows должна появиться в меню загрузки при следующем запуске.

            ```sh
            sudo umount /mnt/WinBoot
            ```

        </Steps>
    </TabItem>

    <TabItem label='GRUB'>
        **GRUB использует os-prober для автоматического обнаружения раздела EFI Windows и добавления его в меню загрузки.**

        <Steps>
        1. Установите и выполните **os-prober**

            ```sh
            sudo pacman -S os-prober
            sudo os-prober
            ```

        2. Включите **os-prober** в файле конфигурации GRUB

            ```sh title='Нажмите CTRL+S для сохранения и CTRL+Q для выхода из Micro'
            sudo micro /etc/default/grub
            # /etc/default/grub
            # Probing for other operating systems is disabled for security reasons. Read
            # documentation on GRUB_DISABLE_OS_PROBER, if still want to enable this
            # functionality install os-prober and uncomment to detect and include other
            # operating systems.
            GRUB_DISABLE_OS_PROBER=false

            sudo grub-mkconfig -o /boot/grub/grub.cfg
            ```

            **Теперь Windows должна быть добавлена в меню загрузки.**

        </Steps>
    </TabItem>
</Tabs>
