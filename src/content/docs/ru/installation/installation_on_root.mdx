## Перед началом

:::note
Если после нажатия **Launch Installer** (Запустить установщик) вы видите только GRUB и Limine в качестве вариантов загрузчика, значит, система загружена в режиме Legacy/BIOS.
:::

:::note[Установка нескольких сред рабочего стола в процессе установки не допускается.]
:::

:::caution[Secure Boot и CSM должны быть отключены в настройках BIOS/UEFI при установке в режиме UEFI.]
Чтобы настроить Secure Boot после установки, обратитесь к разделу [Secure Boot](/ru/configuration/secure_boot_setup).

`Legacy USB Support` должен быть установлен в `Auto`.
:::

:::caution
Опции `Install alongside` (Установить рядом) и `Replace partition` (Заменить раздел) не являются на 100% надежными и могут привести к сбою установки.

При установке CachyOS **настоятельно рекомендуется** использовать `Manual partitioning` (Ручная разметка).
:::

:::tip
Настоятельно рекомендуется перезагрузиться в ISO после неудачной попытки установки.

В противном случае в процессе установки могут возникать постоянные ошибки.

Это происходит потому, что установщик не может корректно отмонтировать разделы при сбое установки.

:::

## Способы установки

### Ручная разметка

:::note[Прежде чем приступать к разметке диска для установки UEFI.]
    ```sh title='Выполните эту команду в терминале'
    efibootmgr -v
    ```
Если вывод — `EFI variables are not supported on this system.`, значит, система загружена в режиме Legacy/BIOS, и вам необходимо убедиться, что в настройках BIOS/UEFI сконфигурирован режим UEFI. Обратитесь к разделу [Requisites (Требования)](/ru/installation/installation_on_root/#перед-началом).
:::

### Erase Disk (Стереть диск)

Опция **Erase Disk** (Стереть диск) в Calamares сотрет выбранный диск и установит CachyOS на целевое устройство.

<Steps>

1. Загрузитесь в ISO и нажмите **Launch Installer** (Запустить установщик).

2. Выберите предпочитаемый [Загрузчик](/ru/installation/boot_managers).

3. Установите предпочитаемые **Language** (Язык) и **Region/Timezone** (Регион/Часовой пояс).

4. Настройте **Keyboard Layout** (Раскладку клавиатуры).

5. Выберите **Erase Disk** (Стереть диск) и выберите [Файловую систему](/ru/installation/filesystem).

6. Выберите предпочитаемую [Среду рабочего стола](/ru/installation/desktop_environments).

7. Выберите, какие пакеты должны быть установлены в процессе установки.

8. Настройте учетные данные для входа.

9. Внимательно просмотрите сводку установки. Если все выглядит правильно, продолжите установку, нажав **Install Now** (Установить сейчас). В противном случае вернитесь назад и внесите необходимые изменения.

</Steps>

## Двойная загрузка Windows и CachyOS

:::note[Это руководство предполагает, что Windows уже установлена в системе, и вы решили установить CachyOS рядом с ней на том же диске.]
:::

:::caution
Двойная загрузка Windows и Linux не является на 100% надежной. Обновления Windows могут повредить загрузчик, перезаписав EFI-раздел.
В некоторых случаях проблемы могут никогда не возникнуть, но для некоторых пользователей это может стать постоянной проблемой.

Один из способов избежать этой проблемы — установить каждую операционную систему на отдельный диск.
:::

:::caution
Размер EFI-раздела может потребоваться изменить в зависимости от рекомендуемого минимального размера для целевого загрузчика. Обратитесь к разделу [Ручная разметка](/ru/installation/installation_on_root#ручная-разметка).

Файловые системы FAT нельзя изменять "на месте". Чтобы правильно "изменить размер" EFI-раздела FAT, необходимо сделать резервную копию существующей файловой системы EFI, использовать инструмент, такой как `gparted`, чтобы изменить размер существующего раздела и переформатировать новый раздел, а затем скопировать предыдущую структуру файловой системы обратно в EFI-раздел.
:::

### Предварительные требования

- Быстрый запуск и гибернация Windows должны быть отключены.
  - Откройте Windows PowerShell от имени администратора и выполните следующую команду:
      ```ps
      powercfg /H off
      ```
    Перезагрузите систему, чтобы изменения вступили в силу.
- Windows BitLocker должен быть отключен.
  - Проверка, включен ли BitLocker:
    ```ps title='Откройте командную строку от имени администратора и выполните следующую команду'
    manage-bde -status
    ```
  Если **Encryption Method** (Метод шифрования) показывает `None`, значит, BitLocker отключен.
- Secure Boot должен быть отключен.
- Пустой раздел размером ≥30 ГБ.
  - Руководство по сжатию раздела Windows:
    - Нажмите `Win + R`, введите `diskmgmt.msc` и нажмите Enter, чтобы открыть Управление дисками.
    - Найдите ваш основной раздел Windows (обычно C:) и щелкните по нему правой кнопкой мыши.
    - Нажмите `Shrink Volume...` (Сжать том...), укажите не менее **30720 МБ** (30 ГиБ) и нажмите `Shrink` (Сжать).
- Загрузочный USB-накопитель с CachyOS.
  - Обратитесь к разделу [Создание загрузочного USB-накопителя CachyOS](/ru/installation/installation_prepare#создание-загрузочного-usb-накопителя-cachyos).

<Tabs>
    <TabItem label='systemd-boot'>
        **Нам нужно скопировать бинарные файлы Windows EFI в раздел Linux EFI, чтобы загрузчик мог их распознать.**

        <Steps>
        1. Найдите **раздел Windows EFI** с помощью `lsblk`.

            ```sh title='Выполните эту команду в терминале'
            lsblk -o NAME,FSTYPE,SIZE,MOUNTPOINT
            ```
            ```sh title='Пример вывода'
                        NAME        FSTYPE   SIZE MOUNTPOINT
            zram0               15.3G [SWAP]
            nvme0n1            476.9G
            ├─nvme0n1p1 vfat     100M
            ├─nvme0n1p2           16M
            ├─nvme0n1p3 ntfs   234.4G
            ├─nvme0n1p4 ntfs     830M
            ├─nvme0n1p5 vfat       2G /boot
            └─nvme0n1p6 btrfs  239.6G /var/tmp
            ```
            EFI-разделы почти всегда отформатированы как `FAT32/vfat`. Поскольку `nvme0n1p1` не имеет точки монтирования в Linux, можно предположить, что это раздел Windows EFI.

        2. Временно смонтируйте раздел Windows EFI.

            ```sh
            sudo mkdir /mnt/WinBoot
            sudo mount /dev/nvme0n1p1 /mnt/WinBoot # Замените `nvme0n1p1` на имя раздела Windows EFI.
            ```

        3. Скопируйте бинарные файлы EFI из **раздела Windows EFI** в **раздел Linux EFI**.

            ```sh
            sudo cp -r /mnt/WinBoot/EFI/Microsoft/ /boot/EFI
            ```

        4. Отмонтируйте ранее смонтированный раздел. Windows должна появиться в меню загрузки при следующем запуске.

            ```sh
            sudo umount /mnt/WinBoot
            sudo rm -r /mnt/WinBoot
            ```

        </Steps>
    </TabItem>

    <TabItem label='GRUB'>
        **GRUB использует os-prober для автоматического обнаружения раздела Windows EFI и добавления его в меню загрузки.**

        <Steps>
        1. Установите **os-prober**.

            ```sh
            sudo pacman -S os-prober
            ```

        2. Включите **os-prober** в конфигурационном файле GRUB.

            ```sh title='Нажмите CTRL+S для сохранения и CTRL+Q для выхода из Micro'
            sudo micro /etc/default/grub
            # /etc/default/grub
            # Probing for other operating systems is disabled for security reasons. Read
            # documentation on GRUB_DISABLE_OS_PROBER, if still want to enable this
            # functionality install os-prober and uncomment to detect and include other
            # operating systems.
            GRUB_DISABLE_OS_PROBER=false

            ```

        3. Обновите grub.cfg, теперь с использованием **os-prober**.
            ```sh
            sudo grub-mkconfig -o /boot/grub/grub.cfg
            ```

            **Теперь Windows должна быть добавлена в меню загрузки.**

        </Steps>
    </TabItem>
</Tabs>
