CachyOS предлагает версию для портативных устройств, таких как Steam Deck, ROG Ally и Legion Go. Эта версия обеспечивает опыт, схожий со SteamOS, с переключением игрового режима, предустановленными игровыми приложениями и многим другим.

В версии для портативных устройств по умолчанию используется планировщик ЦП LAVD, который оптимизирован для портативных устройств. Это приводит к улучшению частоты кадров и времени автономной работы во время игр.

Версия для портативных устройств использует `systemd-boot` в качестве загрузчика. Выбор загрузчика недоступен,
в отличие от стандартного ISO CachyOS. Это сделано для упрощения процесса установки.

## Установка на корневой раздел

<Steps>

1. **Скачайте** последний ISO-образ для портативных устройств с сайта/форума.

2. [Запишите](/ru/installation/installation_prepare) ISO-образ.

3. **Загрузитесь** с ISO-образа.

4. Нажмите кнопку **Launch Installer** (Запустить установщик).

5. Откроется Calamares. Следуйте инструкциям на экране.

6. На этапе разметки диска, пожалуйста, используйте опцию **Erase Disk** (Стереть диск). Если вы переходите с другого дистрибутива Linux, возможно, он использовал другую схему разметки. Имейте в виду, что опция замены раздела может вызывать проблемы и работать не так, как ожидалось.

7. Установите систему.

</Steps>

После завершения установки Calamares предложит вам перезагрузить устройство.

Первая загрузка может занять некоторое время, так как Steam будет скачиваться и запускаться.
Этот процесс может занять до 2 минут.


## Установка с двойной загрузкой (Dual Boot)

<Steps>

1. **Скачайте** последний ISO-образ для портативных устройств с сайта/форума.

2. [Запишите](/ru/installation/installation_prepare) ISO-образ.

3. **Загрузитесь** с ISO-образа.

4. Нажмите кнопку **Launch Installer** (Запустить установщик).

5. Откроется Calamares. Следуйте инструкциям на экране.

6. На этапе разметки диска вам нужно выбрать **Manual Partition** (Ручная разметка) и создать следующие разделы:

    - 2 ГБ для /boot
    - X ГБ для / (X может быть любым объёмом дискового пространства, который вы хотите выделить для корневой файловой системы)

7. Продолжайте следовать шагам и установите систему.

</Steps>

После завершения установки Calamares предложит вам перезагрузить устройство.

Первая загрузка может занять некоторое время, так как Steam будет скачиваться и запускаться.
Этот процесс может занять до 2 минут.
