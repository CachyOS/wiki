CachyOS предлагает на выбор несколько рабочих окружений.

Этот выбор основан на личных предпочтениях. Выберите то, которое вам нравится больше всего.
:::note
Пожалуйста, выберите только одно рабочее окружение во время установки.
:::

Доступны следующие варианты:

1. **KDE Plasma:** комплексное и гибкое рабочее окружение, предлагающее несколько стилей меню для доступа к приложениям. В нём используется оконный менеджер KWin. KDE Plasma также может похвастаться интуитивно понятным интерфейсом, который позволяет легко загружать и устанавливать новые темы, виджеты и многое другое из сети.
2. **Niri:** прокручиваемый мозаичный композитор Wayland, который делает акцент на простоте и плавном управлении окнами. Он использует непрерывную сеточную разметку, оптимизированную для навигации как с клавиатуры, так и с тачпада. Наши dotfiles для Niri можно найти [dotfiles](https://github.com/CachyOS/cachyos-niri-noctalia).
3. **i3:** популярный мозаичный оконный менеджер для X11, известный своим единым, самодостаточным файлом конфигурации и эффективным использованием пространства экрана. Наши dotfiles для i3 можно найти [dotfiles здесь](https://github.com/CachyOS/cachyos-i3wm-settings).
4. **Qtile:** оконный менеджер для X11/Wayland, который настраивается на языке программирования Python. Предлагает различные раскладки и виджеты. Наши [dotfiles здесь](https://github.com/CachyOS/cachyos-qtile-settings).
5. **Wayfire:** композитор Wayland на основе wlroots, который сочетает в себе кастомизацию, расширяемость и эстетику. Наши dotfiles для Wayfire можно найти [dotfiles](https://github.com/CachyOS/cachyos-wayfire-settings).
6. **GNOME:** удобное рабочее окружение с сенсорным интерфейсом для доступа к приложениям. Хотя его легко освоить, у него ограниченные возможности настройки и его может быть сложно сконфигурировать.
7. **XFCE:** легковесное и гибкое рабочее окружение с традиционным выпадающим/всплывающим меню для доступа к приложениям. Оно также совместимо с Compiz.
8. **bspwm:** оконный менеджер для X11, написанный на C, предлагающий гибкие мозаичные, стековые и вкладочные раскладки.
9. **Budgie:** простое и элегантное рабочее окружение, созданное с использованием набора инструментов GTK. Оно спроектировано для предоставления современного и привлекательного интерфейса, который прост в использовании, но при этом легко настраивается.
10. **Cinnamon:** рабочее окружение для Linux, которое сочетает в себе расширенные функции и традиционный пользовательский опыт.
11. **Cosmic:** современное, ориентированное на производительность рабочее окружение, созданное с использованием Rust и Smithay. Разработанное для продуктивности и опытных пользователей, оно стремится предложить расширенные функции, сохраняя при этом чистый, но интуитивно понятный интерфейс.
12. **Hyprland:** визуально приятный композитор Wayland, использующий динамическую мозаичную компоновку. По умолчанию поставляется с CachyOS Noctalia. Наши dotfiles можно посмотреть [здесь](https://github.com/CachyOS/cachyos-hypr-noctalia).
13. **LXDE** (Lightweight X11 Desktop Environment): быстрое и энергоэффективное рабочее окружение, предназначенное для использования на старых компьютерах и системах с ограниченными ресурсами. Оно использует Openbox в качестве оконного менеджера по умолчанию и фокусируется на предоставлении простого, чистого и удобного интерфейса.
14. **LXQt:** легковесное рабочее окружение, образовавшееся в результате слияния проектов LXDE и Razor-qt и созданное с использованием Qt.
15. **Mate Desktop:** традиционное рабочее окружение, являющееся форком GNOME 2. Оно характеризуется своим классическим внешним видом, с простым и интуитивно понятным пользовательским интерфейсом. Mate предоставляет простой в использовании и легко настраиваемый рабочий стол для пользователей, которые предпочитают более классический внешний вид.
16. **Openbox:** очень популярный оконный менеджер для X11, известный своей превосходной документацией и широким выбором доступных тем.
17. **Sway:** мозаичный композитор Wayland и прямая замена оконного менеджера i3 для X11. Он работает с вашей существующей конфигурацией i3 и поддерживает большинство функций i3, а также некоторые дополнительные.
