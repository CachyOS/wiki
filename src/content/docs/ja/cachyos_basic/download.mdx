## 公式 ISO 配布元

CachyOS の ISO は以下の配布元から入手できます。

*   [公式サイト](<https://cachyos.org/download>)
*   [SourceForge](<https://sourceforge.net/projects/cachyos-arch/files/>)
*   [CachyOS ミラー](<https://mirror.cachyos.org/ISO/>)

## SHA256 による ISO の整合性検証

:::caution
インストール時や起動用メディア作成時の問題を防ぐため、かならず ISO の整合性を検証してください。
:::

**現在の ISO バージョン:** `260308`

**SHA256 ハッシュ:** `69f1ffbded158d4d95e6567e994b1813d0d040d323742aef9f489a0b71ad1d29`

<Tabs>

<TabItem label='Windows'>

<Steps>

1. SHA256 ハッシュが記載された[ファイル](https://mirror.cachyos.org/ISO/desktop/260308/cachyos-desktop-linux-260308.iso.sha256)をダウンロードしてください。**(メモ帳などのテキストエディターで開いてください)**
2. CMD または PowerShell を管理者として開き、ISO と SHA256 ファイルが保存されているパスに[移動](https://www.wikihow.com/Change-Directories-in-Command-Prompt)してください。
3. 以下のコマンドを実行してください。
   ```powershell
   # コマンド例
   certUtil -hashfile cachyos-desktop-linux-260308.iso SHA256
   ```
4. certUtil から出力されたハッシュと**手順 1** でダウンロードしたファイルのハッシュを比較してください。同じであれば、CachyOS のインストールに進めます。

</Steps>

</TabItem>

<TabItem label='Linux'>

<Steps>

1. SHA256 ハッシュが記載された[ファイル](https://mirror.cachyos.org/ISO/desktop/260308/cachyos-desktop-linux-260308.iso.sha256)をダウンロードしてください。
2. ターミナルを開き、`.sha256` ファイルと `.iso` ファイルが両方入っているディレクトリに移動してください。
3. 以下のコマンドを実行してください。
   ```sh
   # コマンド例
   cd ~/Downloads
   sha256sum -c cachyos-desktop-linux-260308.iso.sha256
   # cachyos-desktop-linux-260308.iso: OK
   ```
4. **手順 3** の出力が OK であれば、CachyOS のインストールに進めます。

</Steps>

</TabItem>

<TabItem label='macOS'>

<Steps>

1. SHA256 ハッシュが記載された[ファイル](https://mirror.cachyos.org/ISO/desktop/260308/cachyos-desktop-linux-260308.iso.sha256)をダウンロードしてください。
2. ターミナルを開き、`.sha256` ファイルが入っているディレクトリに移動して以下のコマンドを実行してください。
   ```sh
   # コマンド例
   cd Downloads/
   cat cachyos-desktop-linux-260308.iso.sha256
   # 69f1ffbded158d4d95e6567e994b1813d0d040d323742aef9f489a0b71ad1d29
   ```
3. **手順 2** の出力と ISO ファイルのハッシュを比較してください。
   ```sh
   # コマンド例
   shasum -a 256 cachyos-desktop-linux-260308.iso
   ```
4. **手順 2** と**手順 3** のハッシュが同じであれば、CachyOS のインストールに進めます。

</Steps>

</TabItem>

</Tabs>

## ISO イメージが本物かどうか検証する (Linux)

ISO ファイルが本物かどうか検証するには以下の手順にしたがってください。

<Steps>

1. 比較用の GPG キーをインポートしてください。

   ```shell
   gpg --keyserver hkps://keys.openpgp.org --recv-key F3B607488DB35A47
   ```

2. ISO ファイルと[.sig](https://cdn77.cachyos.org/ISO/desktop/260308/cachyos-desktop-linux-260308.iso.sig) 形式の署名ファイルをダウンロードし、以下のコマンドを実行してください。(`full_iso_name.iso` は実際の ISO ファイル名に置き換えてください)
   ```shell
   gpg --verify full_iso_name.iso.sig full_iso_name.iso
   ```

   **正しい署名**と出力されれば、ISO ファイルは本物です。
   ```
   gpg: 2026年03月08日 10時39分18秒 JSTに施された署名
   gpg:                RSA鍵882DCFE48E2051D48E2562ABF3B607488DB35A47を使用
   gpg: "CachyOS <admin@cachyos.org>"からの正しい署名 [不明の]
   gpg: *警告*: この鍵は信用できる署名で証明されていません!
   gpg:       この署名が所有者のものかどうかの検証手段がありません。
   主鍵フィンガープリント: 882D CFE4 8E20 51D4 8E25  62AB F3B6 0748 8DB3 5A47
   ```

</Steps>

:::danger
**正しい署名**と表示されなかったり、またはキー ID が一致しない場合は、その ISO イメージを使用しないでください。署名が不正であるということは、ISO が改ざんされているか破損していることを表します。

ダウンロードしたイメージが[正規の CachyOS 配布元](/ja/cachyos_basic/download#official-iso-sources)からのものであることを確認してください。
:::
