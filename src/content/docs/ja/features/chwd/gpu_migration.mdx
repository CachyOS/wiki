:::note[このガイドはすでに CachyOS がインストールされている環境で GPU (NVIDIA ↔ AMD) を交換する場合に適用されます。]
:::

## 要件
  - 交換する GPU が正しく取り付けられ接続されていること
  - システムが最新の状態であること
    ```bash
    sudo pacman -Syu
    ```

### 移行手順

<Tabs>
    <TabItem label='NVIDIA から AMD へ'>
        AMD ドライバは Linux カーネルに含まれていますが、古い NVIDIA の設定を削除し、必要な AMD パッケージがインストールされているかを確認する必要があります。
        <Steps>
            1. 現在インストールされている NVIDIA ドライバプロファイルを確認してください。
                ```bash
                sudo chwd --list-installed
                ```
            2. `-r` フラグを使って該当のプロファイルを削除してください。
                ```bash
                sudo chwd -r <プロファイル名>
                ```
            3. システムをシャットダウンして AMD GPU を取り付けてください。
            4. 起動後、chwd を使って GPU を自動検出させ、適切な AMD パッケージをインストールしてください。
                ```bash
                sudo chwd -a
                ```
            5. 新しいドライバのインストール後、initramfs とブートローダーの設定を更新してください。
                > CachyOS にはドライバの追加・削除時に initramfs を自動的に再構築する pacman フックが含まれています。
                > これにより、ブート時に正しいドライバが読み込まれます。
                - GRUB: `sudo grub-mkconfig -o /boot/grub/grub.cfg`
                - systemd-boot: `sudo sdboot-manage gen`
                - Limine: `sudo limine-mkinitcpio`
            6. 変更を適用するために再起動してください。
                ```bash
                sudo reboot
                ```
            7. 再起動後、AMD ドライバが有効になっていることを確認してください。
                ```bash
                vulkaninfo | grep "deviceName"
                ```
                以下のコマンドでも確認できます。
                ```bash
                glxinfo | grep "OpenGL renderer"
                ```
                AMD GPU が表示されていればドライバは正しく動作しています。
        </Steps>
    </TabItem>
    <TabItem label='AMD から NVIDIA へ'>
        <Steps>
            1. AMD パッケージを削除してください。
                ```bash
                sudo chwd -r amd
                ```
            2. システムをシャットダウンして NVIDIA GPU を取り付けてください。
            3. 起動後、chwd を使って GPU を自動検出させ、適切な NVIDIA パッケージをインストールしてください。
                ```bash
                sudo chwd -a
                ```
            4. 新しいドライバのインストール後、initramfs とブートローダーの設定を更新してください。
                > CachyOS にはドライバの追加・削除時に initramfs を自動的に再構築する pacman フックが含まれています。
                > これにより、ブート時に正しいドライバが読み込まれます。
                - GRUB: `sudo grub-mkconfig -o /boot/grub/grub.cfg`
                - systemd-boot: `sudo sdboot-manage gen`
                - Limine: `sudo limine-mkinitcpio`
            5. 変更を適用するために再起動してください。
                ```bash
                sudo reboot
                ```
            6. 再起動後、NVIDIA ドライバが有効になっていることを確認してください。
                ```bash
                nvidia-smi
                ```
                以下のコマンドでも確認できます。
                ```bash
                glxinfo | grep "OpenGL renderer"
                ```
                NVIDIA GPU が表示されていればドライバは正しく動作しています。
        </Steps>
    </TabItem>
</Tabs>
