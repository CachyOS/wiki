[CachyOS ハードウェア識別](https://github.com/CachyOS/chwd/) (`chwd` とも呼ばれます) では、システムに必要なパッケージとドライバをインストールすることで、さまざまなハードウェアへ対応させることができます。NVIDIA グラフィックボードを搭載したシステム、T2 MacBook、Steam Deck や ROG Ally をはじめとしたハンドヘルドデバイスなどに対応しています。

## 使い方

`chwd` は通常インストール時に実行され、自動でシステムに必要なパッケージを設定します。インストール後に使用することもできます。

### 自動設定

`chwd` は必要なドライバとパッケージを自動的にインストール・設定し、システムを最適な状態で動作させることができます。

```sh
sudo chwd -a
```

### そのほか

コマンドの構文やそのほかの使い方については `chwd` のヘルプをご覧ください。

```sh
chwd --help
Usage: chwd [OPTIONS]

Options:
  -i, --install <プロファイル>       プロファイルをインストール
  -r, --remove <プロファイル>        プロファイルを削除
  -d, --detail                     一覧で詳細情報を表示
  -f, --force                      強制的に再インストール
      --list-installed             インストール済みのカーネルを表示
      --list                       すべてのデバイスで利用可能なプロファイルを表示
      --list-all                   すべてのプロファイルを表示
  -a, --autoconfigure [<クラスID>]  自動設定
      --ai_sdk                     AI SDK プロファイルを切り替え
      --pmcachedir <PMCACHEDIR>    [デフォルト: /var/cache/pacman/pkg]
      --pmconfig <PMCONFIG>        [デフォルト: /etc/pacman.conf]
      --pmroot <PMROOT>            [デフォルト: /]
  -h, --help                       ヘルプを出力
  -V, --version                    バージョンを出力
```
