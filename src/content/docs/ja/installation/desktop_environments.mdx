CachyOS はさまざまなデスクトップ環境に対応しており、自由にえらぶことができます。

完全に個人の好みによるため、自分に合った好きなものを探してみましょう。
:::note
インストール時に選択するデスクトップ環境はひとつだけしてください。
:::

利用可能なデスクトップ環境は以下のとおりです。

1. **KDE Plasma:** アプリケーションにアクセスするための複数のスタイルのメニューを備えた、包括的で柔軟なデスクトップ環境です。ウィンドウマネージャーとして KWin を採用しています。KDE Plasma は直感的なインターフェースを持ち、ウェブから新しいテーマやウィジェットなどをかんたんにインストールできます。
2. **Niri:** シンプルさと流れるようにスムーズなウィンドウ管理を重視したスクロール可能なタイリング型 Wayland コンポジターです。無限グリッドレイアウトを採用し、キーボードやタッチパッドのどちらの操作にも最適化されています。CachyOS の Niri ドットファイルは[こちら](https://github.com/CachyOS/cachyos-niri-noctalia)
3. **i3:** ひとつにまとまった自己完結型の設定ファイルと、画面スペースの効率的な活用が特徴の人気な X11 タイリングウィンドウマネージャーです。CachyOS の i3 ドットファイルは[こちら](https://github.com/CachyOS/cachyos-i3wm-settings)
4. **Qtile:** 設定ファイルがプログラミング言語の Python になっている X11/Wayland ウィンドウマネージャーです。さまざまなレイアウトとウィジェットに対応しています。ドットファイルは[こちら](https://github.com/CachyOS/cachyos-qtile-settings)
5. **Wayfire:** カスタマイズ性、拡張性、デザインのバランスをとった wlroots ベースの Wayland コンポジターです。CachyOS の Wayfire ドットファイルは[こちら](https://github.com/CachyOS/cachyos-wayfire-settings)
6. **GNOME:** タッチ操作のインターフェースでアプリケーションにアクセスできる使いやすいデスクトップ環境です。慣れに時間がかからない一方、カスタマイズの幅は限られており、設定が難しいことがあります。
7. **XFCE:** アプリケーションにアクセスするための昔ながらのドロップダウン/ポップアップメニューの、軽量で柔軟なデスクトップ環境です。Compiz との互換性もあります。
8. **bspwm:** C 言語ベースの X11 ウィンドウマネージャーです。柔軟性のあるタイル、スタッキング、タブレイアウトに対応しています。
9. **Budgie:** GTK ツールキットで構築されたシンプルで上品なデスクトップ環境です。使いやすくモダンで洗練されたインターフェースでありながら、高いカスタマイズ性も兼ね備えています。
10. **Cinnamon:** 高度な機能と馴染みやすい使用感のバランスをとった Linux 向けデスクトップ環境です。
11. **Cosmic:** Rust と Smithay で構築されたモダンでパフォーマンス重視のデスクトップ環境です。効率性を意識して上級者ユーザー向けに設計されており、すっきりとした直感的なインターフェースと高い機能性の両立を目指しています。
12. **Hyprland:** ダイナミックタイリング形式を採用した、見ているだけでも気持ちが良い Wayland コンポジターです。標準で CachyOS Noctalia が設定されています。ドットファイルは[こちら](https://github.com/CachyOS/cachyos-hypr-noctalia)
13. **LXDE** (Lightweight X11 Desktop Environment): 古いコンピューターやスペックの低いシステム向けに設計された、高速で省電力なデスクトップ環境です。標準のウィンドウマネージャーとして Openbox を採用し、シンプルでクリーンかつ使いやすいインターフェースを実現しています。
14. **LXQt:** LXDE と Razor-qt プロジェクトの統合から生まれた Qt 製の軽量デスクトップ環境です。
15. **Mate Desktop:** GNOME 2 からフォークされた昔ながらのデスクトップ環境です。クラシックな外観とシンプルで直感的なユーザーインターフェースが特徴です。昔ながらの見た目と操作感を好むユーザー向けに、使いやすく高いカスタマイズ性を持つデスクトップ体験を実現しています。
16. **Openbox:** 充実したドキュメントと豊富なテーマがそろった非常に人気の高い X11 ウィンドウマネージャーです。
17. **Sway:** タイリング型 Wayland コンポジターで、X11 向けの i3 ウィンドウマネージャーからそのまま差し替えても動く代替品です。既存の i3 設定をそのまま使用でき、i3 のほとんどの機能に加えて、一部の拡張機能にも対応しています。
