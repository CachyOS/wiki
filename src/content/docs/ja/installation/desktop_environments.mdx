CachyOS はさまざまなデスクトップ環境を提供しており、自由にえらぶことができます。

完全に個人の好みによるため、自分に合った好きなものを探してみましょう。
:::note
インストール時に選択するデスクトップ環境はひとつだけしてください。
:::

利用可能なデスクトップ環境は以下のとおりです。

1. **KDE Plasma:** アプリケーションにアクセスするための複数のスタイルのメニューを備えた、包括的で柔軟なデスクトップ環境です。ウィンドウマネージャーとして KWin を採用しています。KDE Plasma は直感的なインターフェースを持ち、ウェブから新しいテーマやウィジェットなどをかんたんにダウンロード・インストールできます。
2. **Niri:** シンプルさと流れるようにスムーズなウィンドウ管理を重視したスクロール可能なタイリング Wayland コンポジターです。継続的なグリッドレイアウトを採用し、キーボードとタッチパッドの両方でのナビゲーションに最適化されています。CachyOS の Niri ドットファイルは[こちら](https://github.com/CachyOS/cachyos-niri-settings)
3. **i3:** 単一の設定ファイルと効率的なスクリーン活用で知られる人気の X11 タイリングウィンドウマネージャーです。CachyOS の i3 ドットファイルは[こちら](https://github.com/CachyOS/cachyos-i3wm-settings)
4. **Qtile:** Python で設定できる X11/Wayland ウィンドウマネージャーです。さまざまなレイアウトとウィジェットを提供しています。ドットファイルは[こちら](https://github.com/CachyOS/cachyos-qtile-settings)
5. **Wayfire:** カスタマイズ性、拡張性、美しさのバランスをとった wlroots ベースの Wayland コンポジターです。CachyOS の Wayfire ドットファイルは[こちら](https://github.com/CachyOS/cachyos-wayfire-settings)
6. **GNOME:** タッチスタイルのインターフェースでアプリケーションにアクセスできる使いやすいデスクトップ環境です。学習しやすい一方、カスタマイズの幅は限られており、設定が難しいことがあります。
7. **XFCE:** アプリケーションにアクセスするための従来のドロップダウン/ポップアップメニューを備えた、軽量で柔軟なデスクトップ環境です。Compiz との互換性もあります。
8. **bspwm:** C 言語ベースの X11 ウィンドウマネージャーです。柔軟性のあるタイル、スタッキング、タブレイアウトを提供しています
9. **Budgie:** GTK ツールキットで構築されたシンプルでエレガントなデスクトップ環境です。使いやすくモダンで洗練されたインターフェースでありながら、高いカスタマイズ性も兼ね備えています。
10. **Cinnamon:** 高度な機能と従来のユーザー体験のバランスをとった Linux 向けデスクトップ環境です。
11. **Cosmic:** Rust と Smithay で構築されたモダンでパフォーマンス重視のデスクトップ環境です。生産性と上級者ユーザー向けに設計されており、すっきりした直感的なインターフェースと高い機能性の両立を目指しています。
12. **Hyprland:** ダイナミックタイリングを使用する美しい見た目の Wayland コンポジターです。
13. **LXDE** (Lightweight X11 Desktop Environment): 古いコンピューターやリソースが限られたシステム向けに設計された、高速で省電力なデスクトップ環境です。標準のウィンドウマネージャーとして Openbox を採用し、シンプルでクリーンかつ使いやすいインターフェースを提供しています。
14. **LXQt:** LXDE と Razor-qt プロジェクトの統合から生まれた Qt 製の軽量デスクトップ環境です。
15. **Mate Desktop:** GNOME 2 からフォークされた伝統的なデスクトップ環境です。クラシックな外観とシンプルで直感的なユーザーインターフェースが特徴です。クラシックな見た目と操作感を好むユーザー向けに、使いやすく高いカスタマイズ性を持つデスクトップ体験を提供しています。
16. **Openbox:** 充実したドキュメントと豊富なテーマがそろった非常に人気の高い X11 ウィンドウマネージャーです。
17. **Sway:** タイリング Wayland コンポジターであり、X11 向けの i3 ウィンドウマネージャーをそのまま差し替えても動く代替品です。既存の i3 設定をそのまま使用でき、i3 のほとんどの機能に加えて一部の拡張機能もサポートしています。
18. **UKUI:** 古いコンピューターでも効率的に動作する軽量デスクトップ環境です。GTK と Qt の両方の技術を使用しており、Windows 7 に近い外観を持つため、Linux 初心者にも親しみやすくなっています。
