## システム要件

インストールを始める前に、使用するコンピューターが CachyOS を動作させるための最小システム要件を満たしているか確認してください。インストーラーはオンラインインストール方式を採用しているため、安定しているかつ比較的高速なインターネット接続が必要です。

:::note[仮想マシンについて]
CachyOS を仮想マシンにインストールすることはおすすめしません。VM では設定が正しく動作しなかったり、完全に壊れてしまうことがあります。CachyOS は実機にインストールすることをおすすめします。
:::

<Tabs>

<TabItem label="最小要件">

*   RAM 3 GB
*   ストレージ 30 GB 以上 (HDD/SSD)
*   安定したインターネット接続

:::caution
インターネット接続が不安定な場合、インストール時間が長くなったり、最悪の場合インストールが失敗することがあります。
:::

</TabItem>

<TabItem label="推奨要件">

*   RAM 8 GB
*   ストレージ 50 GB 以上 (SSD/NVMe)
*   [x86-64-v3 対応 CPU](/ja/installation/installation_prepare#x86_64-マイクロアーキテクチャーレベルの対応状況)
*   インターネット速度 50 Mbps 以上
*   NVIDIA GPU (900 番台以上、例: GTX 950)、AMD GCN 1.0 以上 (例: AMD R7 240)、または Intel (統合 HD グラフィックスシリーズ以上、Arc シリーズ含む)

</TabItem>

</Tabs>

## ブート可能な CachyOS USB ドライブの作成

CachyOS のブート可能な USB ドライブを作成するには、いくつかのツールと方法があります。

:::tip
chroot 経由でのトラブルシューティングが必要になるときに備え、CachyOS ISO のコピーを同じドライブまたは別の場所に保存しておきましょう。
:::

:::note
USB ドライブには 8 GB 以上の空き容量が必要です。
:::

### balenaEtcher

<Steps>

1. [balenaEtcher](<https://etcher.balena.io/>) をダウンロードしてください。balenaEtcher は Linux, macOS, Windows のイメージの書き込みに対応しています。
   `.zip` ファイルをダウンロードした場合は、以下のコマンドで展開して実行してください。
      ```sh
      # zip ファイルを展開
      bsdtar xvf <zip ファイル名>
      # 新しいフォルダに移動
      cd balenaEtcher-linux-x64/
      # balenaEtcher を実行
      ./balena-etcher
      ```
2. USB ドライブをコンピューターに接続してください。
3. `Flash from file` をクリックして CachyOS の ISO イメージファイルを選択してください。
4. `Select target` をクリックして、先ほど接続した USB ドライブを選択してください。
5. `Flash` を押して書き込みを開始してください。

</Steps>

:::note
balenaEtcher が管理者権限を求めることがあります。その場合はパスワードを入力して `Authenticate` をクリックしてください。
:::

### コマンドライン (Linux & macOS)

<Steps>

1. USB ドライブを接続してください。
2. 以下のコマンドで接続した USB ドライブを確認してください。
   ```sh
   # Linux
   # USB ドライブはディスクモデルとサイズで識別できます (例: /dev/sda)
   sudo fdisk -l

   # macOS
   # USB ドライブは "/dev/diskY" (Y は 0, 1 など) として識別されます
   diskutil list
   ```
3. 以下のコマンドで ISO の内容を USB ドライブに書き込んでください。
   ```sh
   # <usbdrive> をドライブのラベルに置き換えてください
   sudo dd bs=4M if=full_iso_name.iso of=/dev/<usbdrive> status=progress oflag=sync
   ```
</Steps>

- `dd` が ISO ファイルの内容を USB ドライブに書き込みます。

### Rufus (Windows のみ)

<Steps>

1. USB ドライブを接続してください。
2. [Rufus](<https://rufus.ie/>) をダウンロードしてインストールするか、ポータブル版を実行してください。
3. `デバイス` のドロップダウンリストから接続した USB ドライブをえらんでください。
4. `ブートの種類` の `選択` をクリックして CachyOS の ISO イメージファイルを指定してください。
5. `スタート` をクリックしてください。

</Steps>

### Ventoy (Linux & Windows)

<Tabs>

<TabItem label="Linux">

<Steps>

1. USB ドライブを接続してください。
2. [Ventoy](<https://www.ventoy.net/en/download.html>) をダウンロードしてください。
3. 以下のコマンドで Ventoy を展開してください。
   ```sh
   # バージョン部分を実際のものに置き換えてください (例: ventoy-1.1.07-linux.tar.gz)
   bsdtar xvf ventoy-version-linux.tar.gz
   # 新しいフォルダに移動する (バージョンは異なる場合があります)
   cd ventoy-1.1.07/
   ```
4. `VentoyGUI.x86_64` をダブルクリックするか、ターミナルから実行してください。
   ```sh
   # 管理者権限を求められるため、資格情報を入力する必要があります
   ./VentoyGUI.x86_64
   ```
5. `Device` をクリックして接続した USB ドライブを選択してください。
6. `Install` をクリックしてください。
7. USB ドライブへの Ventoy のインストールが完了したらウィンドウを閉じ、ドライブの新しいパーティションに CachyOS の ISO ファイルをコピーしてください。

</Steps>

</TabItem>

<TabItem label="Windows">

<Steps>
1. USB ドライブを接続してください。
2. [Ventoy](<https://www.ventoy.net/en/download.html>) をダウンロードしてください。
3. `Ventoy2Disk.exe` を実行してください。
4. `Device` をクリックして接続した USB ドライブをえらんでください。
5. `Install` をクリックしてください。
6. USB ドライブへの Ventoy のインストールが完了したらウィンドウを閉じ、ドライブの新しいパーティションに CachyOS の ISO ファイルをコピーしてください。
</Steps>

</TabItem>

</Tabs>
