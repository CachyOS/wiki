## 用途
- **ネットワーク**

ルートセッションでは、仮想マシンからポートフォワーディングすることができず、代わりに NAT が使用されます。つまり、仮想マシンから外部ネットワークにアクセスすることはできますが、外部から仮想マシンへ直接アクセスすることはできず、代わりにホスト PC と同じものとして識別されます。これは PC の外部から仮想マシンに直接アクセスしたい場合 (例: SSH 等) に、接続先が存在しないため失敗するという問題につながります。

- **変換を介した 3D アクセラレーション**

ルートセッションでは **VMM** がレンダーノード `/dev/dri/renderD128` を使用することはできず、
`qemu-cli` の動作も制限されます。これは、一般ユーザーがルートの qemu をほとんど利用できないことが原因です。

## ユーザーセッションを有効にする方法
**VMM** のウィンドウで、`ファイル -> 接続を追加...` の `ハイパーバイザー:` で `QEMU/KVM ユーザーセッション` を選択することで有効にすることができます。これで [QEMU と VMM のセットアップ](/ja/virtualization/qemu_and_vmm_setup)にしたがって、ルートモードではなくユーザーモードで仮想マシンを作成することができるようになります。
