## 不足している X11 セッションをインストールする方法

KDE が複数のパッケージで管理する体制になってから、X11 セッションは標準のインストールから削除されました。

```sh
sudo pacman -S plasma-x11-session kwin-x11
```

## よくある質問

### スクリーンショットにある "Emerald" という名前のものと同じ見た目にするには？

- Emerald テーマと Qogir アイコンテーマの組み合わせで実現できます。デフォルトでインストールされていないため、以下のコマンドでインストールしてください。
  - ```sh title='両方をインストールするコマンド'
    sudo pacman -S cachyos-emerald-kde-theme-git qogir-icon-theme
    ```
  `外観とスタイル - 色とテーマ` で両方を適用してください。
