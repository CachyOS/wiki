## キーバインド

多くのキーバインドは修飾キー (スーパーキーや Windows キーとも呼ばれます) を使用します。設定ファイルから変更することができます。

### アプリケーション操作

| 説明 | キー |
|-------------|-----|
| ターミナルを起動 | <Kbd linux="Super+Return" /> |
| Rofi を開く (プログラムランチャー) | <Kbd linux="Control+Space" /> |
| フォーカス中のウィンドウを閉じる | <Kbd linux="Super+Q" /> |

### ワークスペース操作

| 説明 | キー |
|-------------|-----|
| ワークスペースの切り替え (1-9) | <Kbd linux="Super+1" /> ~ <Kbd linux="Super+9" /> |

### ウィンドウフォーカス

| 説明 | キー |
|-------------|-----|
| 左のウィンドウにフォーカス | <Kbd linux="Super+←" /> |
| 右のウィンドウにフォーカス | <Kbd linux="Super+→" /> |
| 上のウィンドウにフォーカス | <Kbd linux="Super+↑" /> |
| 下のウィンドウにフォーカス | <Kbd linux="Super+↓" /> |
| 直近のフローティング/タイリングコンテナにフォーカス | <Kbd linux="Super+Space" /> |

### ウィンドウ管理

| 説明 | キー |
|-------------|-----|
| ウィンドウを特定のワークスペースへ移動 (1-9) | <Kbd linux="Super+Shift+1" /> ~ <Kbd linux="Super+Shift+9" /> |
| フォーカス中のウィンドウを左に移動 | <Kbd linux="Super+Shift+←" /> |
| フォーカス中のウィンドウを右に移動 | <Kbd linux="Super+Shift+→" /> |
| フォーカス中のウィンドウを上に移動 | <Kbd linux="Super+Shift+↑" /> |
| フォーカス中のウィンドウを下に移動 | <Kbd linux="Super+Shift+↓" /> |
| フルスクリーンの切り替え | <Kbd linux="Super+F" /> |
| フローティングモードの切り替え | <Kbd linux="Super+Shift+Space" /> |

### レイアウト操作

| 説明 | キー |
|-------------|-----|
| 水平方向に分割 | <Kbd linux="Super+H" /> |
| 垂直方向に分割 | <Kbd linux="Super+V" /> |
| 分割方向の切り替え | <Kbd linux="Super+T" /> |
| レイアウトをスタックに変更 | <Kbd linux="Super+S" /> |
| レイアウトをタブに変更 | <Kbd linux="Super+W" /> |

### リサイズモード

| 説明 | キー |
|-------------|-----|
| リサイズモードに入る | <Kbd linux="Super+R" /> |
| 左にリサイズ (リサイズモード中) | <Kbd linux="←" /> |
| 右にリサイズ (リサイズモード中) | <Kbd linux="→" /> |
| 上にリサイズ (リサイズモード中) | <Kbd linux="↑" /> |
| 下にリサイズ (リサイズモード中) | <Kbd linux="↓" /> |
| リサイズモードを終了 | <Kbd linux="Return" /> / <Kbd linux="Escape" /> / <Kbd linux="Super+R" /> |

### システム操作

| 説明 | キー |
|-------------|-----|
| 画面をロック | <Kbd linux="Super+L" /> |
| i3 設定ファイルをリロード | <Kbd linux="Super+Shift+C" /> |
| i3 をその場で再起動 (設定反映) | <Kbd linux="Super+Shift+R" /> |
| i3 を終了 (Xセッションの終了) | <Kbd linux="Super+Shift+E" /> |
## FAQ

### プログラムを自動起動するには？ (例：起動時に壁紙を設定するなど)

* i3 には最初から任意のプログラムやコマンドを実行できる柔軟な自動起動機能が備わっています。

設定ファイルの末尾に、`exec` や `exec_always` で始まる行があります。

例えば...

```exec chromium```

このように記述すると、i3 セッションにログインしたときに Chromium がワークスペース1で開かれます。

### exec と exec_always の違いは？

exec_always にすると i3wm を再起動したときでも実行されるようになります。

* 詳しい情報は i3 のユーザーガイドをご覧ください。
* https://i3wm.org/docs/userguide.html#exec
