## キーバインド

多くのキーバインドは修飾キー (スーパーキーや Windows キーとも呼ばれます) を使用します。設定ファイルから変更することができます。
一部は修飾キー1 (alt キー)を使用します。

### アプリケーション操作

| 説明 | キー |
|-------------|-----|
| ターミナルを起動 | <Kbd linux="Super+Return" /> |
| Rofi を開く (プログラムランチャー) | <Kbd linux="Alt+Space" /> |
| ファイルマネージャー (Thunar) を起動 | <Kbd linux="Super+E" /> |
| フォーカス中のウィンドウを閉じる | <Kbd linux="Super+Q" /> |

### ワークスペース操作

| 説明 | キー |
|-------------|-----|
| ワークスペースの移動 (1-9) | <Kbd linux="Super+1" /> through <Kbd linux="Super+9" /> |

### ウィンドウ操作

| 説明 | キー |
|-------------|-----|
| 左のウィンドウにフォーカス | <Kbd linux="Super+H" /> |
| 右のウィンドウにフォーカス | <Kbd linux="Super+L" /> |
| 下のウィンドウにフォーカス | <Kbd linux="Super+J" /> |
| 上のウィンドウにフォーカス | <Kbd linux="Super+K" /> |
| カラムまたはスタック内でウィンドウを移動 | <Kbd linux="Super+Space" /> |

### ウィンドウ管理

| 説明 | キー |
|-------------|-----|
| フォーカス中のウィンドウを左に移動 | <Kbd linux="Super+Shift+H" /> |
| フォーカス中のウィンドウを右に移動 | <Kbd linux="Super+Shift+L" /> |
| フォーカス中のウィンドウを下に移動 | <Kbd linux="Super+Shift+J" /> |
| フォーカス中のウィンドウを上に移動 | <Kbd linux="Super+Shift+K" /> |
| フルスクリーンの切り替え | <Kbd linux="Super+F" /> |
| フローティングモードの切り替え | <Kbd linux="Super+V" /> |
| ウィンドウを固定 (全ワークスペースに表示) | <Kbd linux="Super+S" /> |

### ウィンドウのサイズ変更

| 説明 | キー |
|-------------|-----|
| ウィンドウを左方向に拡大 | <Kbd linux="Super+Control+H" /> |
| ウィンドウを右方向に拡大 | <Kbd linux="Super+Control+L" /> |
| ウィンドウを下方向に拡大 | <Kbd linux="Super+Control+J" /> |
| ウィンドウを上方向に拡大 | <Kbd linux="Super+Control+K" /> |
| すべてのウィンドウサイズをリセット | <Kbd linux="Super+N" /> |

### レイアウト操作

| 説明 | キー |
|-------------|-----|
| スタックの分割/非分割を切り替え | <Kbd linux="Super+Shift+Return" /> |
| レイアウトの切り替え | <Kbd linux="Super+Tab" /> |

### マウス操作

| 説明 | キー |
|-------------|-----|
| フローティングウィンドウをドラッグして移動 | <Kbd linux="Super+左クリック" /> |
| フローティングウィンドウのリサイズ | <Kbd linux="Super+右クリック" /> |
| ウィンドウを最前面に移動 | <Kbd linux="Super+スクロールホイール押下" /> |

### スクリーンショット

| 説明 | キー |
|-------------|-----|
| Flameshot を起動 (スクリーンショットツール) | <Kbd linux="Print" /> |
| 全画面スクリーンショット (保存先: ~/Pictures) | <Kbd linux="Control+Print" /> |

### システム操作

| 説明 | キー |
|-------------|-----|
| Qtile 設定ファイルをリロード | <Kbd linux="Super+Control+R" /> |
| Qtile を終了 (Xセッションの終了) | <Kbd linux="Super+Control+Q" /> |
## よくある質問

### 音量ウィジェットがエラーになったり、0%から動かない

* これは、Qtile の音量ウィジェットがデフォルトの出力デバイスを正しく検出できない場合に発生することがあります。詳細については[公式 Wiki](https://docs.qtile.org/en/latest/manual/ref/widgets.html#pulsevolume)をお読みください。

### 自動起動用のスクリプト (autostart.sh) はある？

* あります。Qtile 設定フォルダ内の `scripts/` ディレクトリに配置されています。

### Qtile のバーはマウス操作に対応している？

* 対応しています。たとえば、ワークスペース (Active, Inactive, Empty など) を表す小さな点をスクロールすると左右に切りかわり、クリックで直接そのワークスペースに移動できます。
* ほかにもレイアウト (デフォルトではカラム) をクリックすることで使用可能なレイアウトを切りかえられます。
* CPU・RAM の使用率表示をクリックすると、Btop (TUI システムモニター) が起動します。
* ボリュームウィジェットを操作することで、音量の増減やミュートができます。

Qtile についての詳しい情報は[公式 Wiki](https://docs.qtile.org/en/stable/) をご覧ください。
