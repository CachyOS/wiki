:::note
Hyprland は dwindle (タイリング)、スクロール、マスター、モノクル、そしてカスタムのレイアウトなどに対応する Wayland コンポジターです。最初から機能がそろっている**デスクトップ環境 (DE) ではありません。**
:::

### Hyprland をえらぶ理由

Hyprland はさまざまなレイアウトを用意している美しいダイナミックタイリング型のマネージャーで、可変リフレッシュレート、ティアリング、HDR などのコンポジターとして高度な機能を備えています。CachyOS の Hyprland 用ドットファイルでは、インストール直後から快適に利用できるようなデフォルト設定になっており、各アプリケーションもシステム全体のテーマに統一されるよう調整されています。

**ドットファイル提供: [Jinra](https://github.com/Jinra)**

Noctalia に関する問題については [Noctalia のドキュメント](https://docs.noctalia.dev/)をご覧ください。

## 初期設定
セットアップ後は、ご自身に合わせた設定をいくつか行うことをおすすめします。その他の設定については [Hyprland Wiki](https://wiki.hypr.land/Configuring/Start/) をご覧ください。

### `~/.config/hypr/config`
* `monitors.lua` ではモニター設定を行います。詳細は https://wiki.hypr.land/Configuring/Basics/Monitors/ をご覧ください。デフォルトの設定ブロックが用意されており、モニターを追加する場合はブロックを追加できます。
  * `output` のモニター値は `variables.lua` 側で編集します。モニター ID (例: `DP-1`) は `hyprctl monitors` で確認できます。モニターを追加する場合は `MONITOR2`, `MONITOR3` のように指定し、`variables.lua` にも追加してください。
  * `mode` は `1920x1080@60` といった形式 (横解像度×縦解像度@リフレッシュレート) で指定します。
  * `scale` は通常 `1` のままで問題ありませんが、高解像度ディスプレイではより大きな値を設定したほうが良い場合があります。
  * 初回の変更後は再起動が必要になる場合がありますが、それ以降の変更はリアルタイムで反映されます。
* `variables.lua`
  * モニターの割り当てを設定できます。通常は `PRIMARY_MONITOR` と `MONITOR1` は同じモニターに設定してください。必要に応じて `MONITOR#` を追加・削除できます。
  * モニターごとのワークスペース数を指定してください。ただし 10 以下で設定してください。
* `input.lua` Hyprland での入力操作の設定を行うことができます。特に `sensitivity` (感度) の調節をおすすめします。
* `binds.lua` このドットファイルで用意されているすべてのキーバインドを確認できます。下記の一覧も参考にしてください。
* `windowrules.lua` 特定のウィンドウが特別な動作をする理由を確認できます。また、必要に応じてルールを追加・削除できます。
* `workspaces.lua` ワークスペースに関する設定を行うことができます。設定ファイルの例のように、モニターごとに3つのワークスペースを設定し、プライマリモニターへゲーム用ワークスペースを追加することをおすすめします。
* `environment.lua` は Hyprland の設定やカスタムの環境変数の指定に使います。UWSM を使用している場合は設定の必要はなく、UWSM の環境変数ファイルへ追加する方法をおすすめします。
### `~/.config/uwsm`
* `env` グローバル環境変数を定義するファイルです。`HYPRCURSOR_THEME`, `XCURSOR_THEME`, `QT_QPA_PLATFORM` などのユーザーアカウント全体で使用する環境変数を設定できます。
### `~/.config/noctalia` (バージョン5専用、V4 でも存在するが Noctalia settings から設定できるため編集不要)
* `config.toml` には cachyos-hypr-noctalia のデフォルト設定が保存されています。通常の Noctalia V5 の初期設定と異なるのはこのファイルによるものです。基本的には編集する必要はありません。
### `noctalia settings` (Super + Z)
* Noctalia の設定を変更できます。Templates の項目で使用するアプリケーション向けのカラーテンプレートを有効にすることをおすすめします。
* Plugins Store には、便利な公式&コミュニティ製プラグインも用意されています。

## 他の DE/WM から移行する

すでに別のデスクトップ環境 (DE) またはウィンドウマネージャー (WM) をインストールしている場合は、以下の手順でこのドットファイルへ移行できます。

:::note
既存のユーザーアカウントで Hyprland を使用することも可能ですが、新しいユーザーアカウントを作成することを強く推奨します (手順は以下に記載しています)。また、新しいユーザーアカウントを使用した場合でも、以前の DE/WM が使用していたデーモンとの競合が発生する場合があるため、1 つの環境だけを使用するのがより理想的です。
:::

以下の手順では、山括弧 (`<>`) で囲まれた部分を、山括弧も含めて適切な値に置き換えてください。

1. `sudo pacman -S cachyos-hypr-noctalia` を実行してください。`cachyos-kde-settings` など、他の `-settings` パッケージと競合する場合は、それらのパッケージは現在のユーザーに影響しないため、競合するパッケージを削除できます。
1. 新しいユーザーを作成するには、`sudo useradd -m <new_user> -s /bin/fish` を実行してください。必要に応じて、`/bin/zsh` など別のシェルも使用できます。
1. `sudo passwd <new_user>` を実行し、新しいユーザーのパスワードを設定してください。
    * **どうしても**同じユーザーアカウントを使用したい場合 (非推奨) は、かわりに `cp -r /etc/skel/. ~` を実行してドットファイルをホームディレクトリへコピーしてください。その際は、必ず事前にバックアップまたはスナップショットを作成してください。
1. ディスプレイマネージャーとして、必要に応じて `noctalia-greeter` または `sddm` をインストールしてください。`noctalia-greeter` は Noctalia とより良く統合されますが、設定は少し複雑です。
    * SDDM をディスプレイマネージャーとして有効にするには、`sudo pacman -Syu sddm` でインストールし、`systemctl disable display-manager` と `systemctl enable sddm` を実行してください。
    * [Noctalia Greeter](https://github.com/noctalia-dev/noctalia-greeter) をインストールするには、`sudo pacman -Syu noctalia-greeter` を実行し、リンク先のドキュメントの「Setting up greetd」セクションにしたがってください。その後、`systemctl disable display-manager` と `systemctl enable greetd` を実行してください。
1. 再起動し、ディスプレイマネージャーから **Hyprland (UWSM)** セッションを選択してください。
    * シェルの起動に失敗した場合は、もう一度再起動してみてください。
1. ログイン後、[初期設定](/ja/configuration/desktop_environments/hyprland/#初期設定)の内容に従って初期設定を行ってください。

## V4 のドットファイルから V5 へ移行 / ドットファイルの更新

現在 Noctalia V4 の `cachyos-hypr-noctalia` を使用しており、パッケージをバージョン 1.0 から新しいバージョンへ更新した場合、またはドットファイルを更新したい場合は、以下の手順に従ってください。
ドットファイルを更新する必要があるかどうかは、リリースの変更履歴を確認してください。
https://github.com/CachyOS/cachyos-hypr-noctalia/releases

### Hyprland の更新

:::note
V4 のキーバインドを V5 へ移行すると、キーバインドから Noctalia の IPC を呼び出せなくなります。
:::

1. `meld` がインストールされていることを確認してください (`pacman -Q meld`)。インストールされていない場合はインストールしてください。
1. `meld /etc/skel/.config/hypr ~/.config/hypr` を実行してください。
1. Meld が開くと、変更されたすべてのファイルが一覧表示されます。青色のファイルは変更が加えられたファイル、緑色のファイルは新しく追加されたファイルです。

    <i>※Meld は日本語に対応しています。</i>

1. ファイルの編集が完了したら、保存して終了してください。
    <br />
    <ImageComponent imgsrc={import('~/assets/images/v4-v5-migration/save_exit.png')} />
1. 新しく追加された緑色のファイルについては、保存先を尋ねられます。同じファイル名のまま `~/.config/hypr/config/` に保存してください。新しく追加されるファイルは次の 4 つです。
    * `defaults.lua` は `variables.lua` に変更されます。独自に追加・変更した内容は、新しいファイルに手動で移行してください。
    * `keybinds.lua` は `binds.lua` に変更されます。独自に追加・変更した内容は、新しいファイルに手動で移行してください。
    * `input.lua` は `inputs.lua` に変更されます。独自に追加・変更した内容は、新しいファイルに手動で移行してください。
    * `workspaces.lua` は新しく追加されたファイルです。そのままコピーして使用してください。

### Noctalia の更新

1. `rm -rf ~/.config/noctalia` を実行して現在の設定を削除してください。必要になる可能性がある場合は、削除する代わりに別の場所へ移動してください。
1. `cp -r /etc/skel/.config/noctalia ~/.config` を実行し、新しい設定をホームディレクトリへコピーしてください。

:::note
重要なファイルは `config.toml` のみです。そのため、パッケージ更新時にフォルダー全体を置き換えたくない場合は、このファイルだけをコピーしても構いません。
:::

### その他の更新

他のファイルも更新されている場合があります。必要に応じて Meld を使用して変更を取り込んでください。その他の変更内容については、リリースの変更履歴を確認してください。

### 孤立パッケージを削除する (V4 → V5 移行)

パッケージを更新すると、古い依存パッケージが孤立状態になります。`shelly purify -o` を実行して削除してください。

### 再起動

変更を反映するため、再起動してください。シェルの起動に失敗した場合は、もう一度再起動してみてください。

## よくある質問

> _「再起動するとクリップボード履歴が消えるのはなぜ？」_

クリップボード履歴を正しく保持するには、シークレットストアの設定が必要です。KWallet はデフォルトでインストールされていますが、gnome-keyring など別のシークレットストアも使用できます。KWallet を使用する場合は、リポジトリから `kwalletmanager` をインストールし、起動して新しいウォレットを作成してください。パスワードを空欄にするのが最も簡単ですが、ディスプレイマネージャーによる自動ロック解除も設定できます。後者はこの Wiki の範囲外ですので、詳細は [ArchWiki](https://wiki.archlinux.jp/index.php/KDE_Wallet#設定) をご覧ください。ウォレットの設定後、`autostart.lua` ファイル内で `hl.exec_cmd("kwalletd6")` を使って初期化してください。

> _「スクリーンショットの撮影後に satty を表示させないようにするには？」_

satty は Ctrl + S でスクリーンショットを保存するか、Ctrl + C でコピーすると簡単に閉じられます。satty をまったく表示したくない場合は、Noctalia Settings の Shell > Screenshot で、クリップボードにコピーするかファイルに保存するよう設定できます。

> _「キーボードの入力設定を変更するには？」_

`inputs.lua` を編集し、`kb_layout` を追加してください。詳細は [Hyprland Wiki](https://wiki.hypr.land/Configuring/Basics/Variables/#input) をご覧ください。

> _「一部のテーマ設定 (Dolphin のアイコンや一部の QT 要素など) が反映されないのはなぜ？」_

CachyOS のデフォルトリポジトリで提供されるのは `qt6ct` (QT6 Configuration Tool) だけです。しかし、Dolphin や Gwenview などの Plasma QT アプリケーションにより適したツールがあります。かわりに AUR から `qt6ct-kde` をダウンロードし、それを使って Noctalia テーマを適用してください。これにより、Hyprland 上の Plasma アプリケーションにテーマがより適切に反映されます。

> _「デフォルトのブラウザーを変更するには？」_

`xdg-settings set default-web-browser your_browser.desktop` を実行してください。ブラウザーの desktop ファイル名は、`ls /usr/share/applications/` を実行すると確認できます。
