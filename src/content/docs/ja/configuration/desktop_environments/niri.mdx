:::note
Niri はカラムベースのレイアウトシステムを採用した、ユニークなウィンドウ管理の方法によるスクロール式 Wayland コンポジターです。
:::

ここでのセットアップの主な目標は、シンプルでアクセスしやすい設定を維持しつつ、スムーズで直感的なデスクトップ体験を提供する Niri 構成を実現することです。

詳細は [Niri のよくある質問](/ja/configuration/desktop_environments/niri#よくある質問) をご覧ください。

Noctalia 関連の問題については、[Noctalia のドキュメント](https://docs.noctalia.dev/) をご覧ください。

## キーバインド

多くのキーバインドは修飾キー (スーパーキーや Windows キーとも呼ばれます) を使用します。設定ファイルから変更することができます。

### アプリケーション操作

| 説明 | キー |
|-------------|-----|
| ターミナルを起動 | <Kbd linux="Super+Return" /> |
| プログラムランチャーを起動 | <Kbd linux="Super+Ctrl+Return" /> |
| ブラウザ (Firefox) を起動 | <Kbd linux="Super+B" /> |
| ファイルマネージャーを起動 | <Kbd linux="Super+E" /> |
| フォーカス中のウィンドウを閉じる | <Kbd linux="Super+Q" /> |
| 画面をロック | <Kbd linux="Super+Alt+L" /> |

### ワークスペース操作

| 説明 | キー |
|-------------|-----|
| ワークスペースの切り替え (1-9) | <Kbd linux="Super+1" /> ~ <Kbd linux="Super+9" /> |
| 前のワークスペースに戻る | <Kbd linux="Super+Tab" /> |
| スクロールホイールでワークスペース間を移動 | <Kbd linux="Super+スクロール" /> |

### ウィンドウ操作

| 説明 | キー |
|-------------|-----|
| 上のウィンドウ/カラムにフォーカス | <Kbd linux="Super+↑" /> または <Kbd linux="Super+K" /> |
| 下のウィンドウ/カラムにフォーカス | <Kbd linux="Super+↓" /> または <Kbd linux="Super+J" /> |
| 左のカラムにフォーカス | <Kbd linux="Super+←" /> または <Kbd linux="Super+H" /> |
| 右のカラムにフォーカス | <Kbd linux="Super+→" /> または <Kbd linux="Super+L" /> |
| 最初のカラムにフォーカス | <Kbd linux="Super+Home" /> |
| 最後のカラムにフォーカス | <Kbd linux="Super+End" /> |

## よくある質問

### ほかのウィンドウマネージャーと Niri の違いは？

Niri は独自の「スクローラブル・タイリング」方式を採用しており、ウィンドウは水平方向にスクロールできるカラムに配置されます。これにより無限に広がるデスクトップが生まれ、特にウルトラワイドモニターや、多くのアプリケーションを同時に開く用途で効果的です。

### キーボードレイアウトを変更するには？

設定ファイルの `input` セクションを編集してください。

```txt title='設定例'
input {
    keyboard {
        xkb {
            layout "jp" // "us" や "de" からお好みのレイアウトに変更
        }
    }
}
```

### ウィンドウの間隔や見た目をカスタマイズできる？

はい。`layout` の項目から変更できます。

```txt title='設定例'
layout {
    gaps 8 // 間隔を変更

    focus-ring {
        width 2
        active-color "#好きな色"
        inactive-color "#好きな色"
    }
}
```

### 自動起動するアプリケーションを追加するには？

`startup` の項目に追加してください。

```txt title='設定例'
spawn-at-startup "your-application"
```

### 緊急脱出キーは何のためにある？

`Super+Escape` は、フルスクリーンアプリケーションがキーバインドをブロックしてしまった場合に、コントロールを取り戻すためのものです。有効になっているキーボードショートカット抑制処理を強制的に無効化します。

### マルチモニターの設定方法は？

`output` セクションのコメントを解除し、使用しているディスプレイに合わせて編集してください。正しいモニター名を確認するには `niri msg outputs` を実行してください。

```txt title='設定例'
output "DP-1" {
    mode "1920x1080@60.000"
    scale 1
}
```
