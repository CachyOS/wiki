このガイドでは、CachyOS の Chromium 系ブラウザでハードウェアアクセラレーションを有効にする方法を説明します。動画やグラフィックスの処理を GPU に任せることで、パフォーマンスを向上させることができます。

## 要件

**必須**
* **Chromium 系ブラウザ:** (例: Chrome, Brave, Ungoogled Chromium, Edge)
* **GPU ドライバ/API:** Vulkan/VA-API/VDPAU が設定済みの最新の Mesa (AMD/Intel) または NVIDIA ドライバ

**任意**

* **amdgpu_top:** ターミナルから AMD GPU の使用率を監視したい場合は、パッケージマネージャーからリポジトリの `amdgpu_top` をインストールしてください。
* **nvtop:** (Intel GPU のみ) ターミナルから Intel GPU の使用率を監視したい場合は、Shelly パッケージマネージャーから `nvtop` (Lunar Lake) と `intel-gpu-tools` (Lunar Lake 以前) をインストールしてください。

## 貢献について

このガイドはみなさまが拡張することができます。特定の GPU と Chromium 系ブラウザで動作するハードウェアアクセラレーション設定をお持ちの場合は、「GPU とブラウザの設定」セクションに新しい項目を追加して貢献をお願いします。以下の情報を含めてください。

* **ブラウザ名**
* **GPU モデル**
* **フラグ:** `~/.config/[browser]-flags.conf` の内容
* **ファイルパス:** フラグファイルへのフルパス
* **補足 (任意):** ドライバ情報、パッケージ、設定の詳細

### セットアップ手順

<Steps>

1. フラグファイルの特定: このページ下部の「GPU とブラウザの設定」セクションでブラウザのフラグファイルのパスを確認してください。
2. フラグファイルの編集: `nano` (または `micro`, `vim` などのテキストエディター) でファイルを開いてください。

    ```bash
    nano [ブラウザフラグファイルへのパス]
    # 例: nano ~/.config/chrome-flags.conf
    ```

3. フラグの追加: 該当する GPU/ブラウザ向けのフラグをファイルに貼り付けてください。
4. 保存して終了してください。
5. ブラウザの再起動: すべてのブラウザ画面を閉じて再起動してください。
6. 確認: `chrome://gpu` (または `brave://gpu`、`edge://gpu` など) に移動してください。"Video Acceleration Information" と "Graphics Feature Status" が "Hardware accelerated" になっているか確認してください。

</Steps>

## ビデオハードウェアアクセラレーションの確認方法

<Tabs>

<TabItem label='AMD GPU (amdgpu_top)'>

<Steps>

1. ターミナルを開き以下のコマンドを実行してください。
    ```bash
    amdgpu_top
    ```
2. ブラウザで動画を再生してください。(例: YouTube)
3. `amdgpu_top` の `media` 欄を確認してください。GPU のメディアエンジンが動作していれば、ここに使用率が表示されます。動画再生中に 0% のままの場合、デコードにハードウェアアクセラレーションが正しく適用されていない可能性があります。

</Steps>

</TabItem>

<TabItem label='Intel GPU (nvtop)'>

<Steps>

1. ターミナルを開き以下のコマンドを実行してください。
    ```bash
    sudo nvtop
    ```
2. ブラウザで動画を再生してください。(例: YouTube)
3. `nvtop` の `ENC/DEC` の％を確認してください。ハードウェアでのデコードが動作していれば数値が上昇します。

</Steps>

</TabItem>

<TabItem label='Intel GPU (intel_gpu_tools)'>

<Steps>

1. ターミナルを開き以下のコマンドを実行してください。

    ```bash
    sudo intel_gpu_top
    ```

    注意: Lunar Lake GPU など一部の新しい Intel GPU は `intel_gpu_top` で GPU パフォーマンスカウンターを表示しないようになりました。その場合は `nvtop` を使ってください。

2. ブラウザで動画を再生してください。(例: YouTube)
3. `intel_gpu_top` の `Video` と `VideoEnhance` の％を確認してください。ハードウェアでのデコードが動作していれば数値が上昇します。

</Steps>

</TabItem>

<TabItem label='ブラウザの開発者ツール'>

<Steps>

1. Chromium 系ブラウザを開いてください。

2. 動画を再生してください。(例: YouTube またはローカルファイル)

3. `F12` または `Ctrl+Shift+I` で開発者ツールを開いてください。

4. **メディア** タブに移動してください。表示されていない場合は、開発者ツールのツールバーの三点リーダー (`...`) または `>>` (その他のタブ) をクリックして `メディア` をクリックしてください。

5. 左側の「プレーヤー」セクションで再生中の動画に対応する項目をクリックしてください。

6. メインパネルで **動画 デコーダ** セクションまでスクロールしてください。

7. `ハードウェア デコーダ` の値を確認してください。`true` であれば正常です。`false` またはソフトウェアデコーダーの名前 (例: `FFmpegVideoDecoder`, `VpxVideoDecoder`, `Dav1dVideoDecoder`) が表示されている場合、その動画ではハードウェアアクセラレーションが有効になっていません。

</Steps>

</TabItem>

</Tabs>

## GPU とブラウザの設定

### AMD Radeon RX 6900 XT (Google Chrome)

* **ブラウザ:** Google Chrome

* **GPU:** AMD Radeon RX 6900 XT

* **フラグファイル:** `~/.config/chrome-flags.conf`

```bash
--use-gl=angle
--use-angle=vulkan
--enable-features=Vulkan,VulkanFromANGLE,DefaultANGLEVulkan,AcceleratedVideoDecodeLinuxZeroCopyGL,AcceleratedVideoEncoder,VaapiIgnoreDriverChecks,UseMultiPlaneFormatForHardwareVideo
```

**補足:** ANGLE 経由の Vulkan と VA-API を利用しています。`--ozone-platform=x11` は Wayland 環境でも一部のアクセラレーションの条件で有効な場合があります。


### Nvidia RTX 4090 (Vivaldi)

* **ブラウザ:** Vivaldi

* **GPU:** Nvidia RTX 4090

* **フラグファイル:** `~/.config/vivaldi-stable.conf`

```bash
--enable-features=VaapiVideoDecoder,AcceleratedVideoDecodeLinuxGL,AcceleratedVideoDecodeLinuxZeroCopyGL
```

* **フラグファイル:** `/usr/share/applications/vivaldi-stable.desktop`

```bash
# ほかの行はそのままにしてください
# '[Desktop Entry]' セクションの Exec= エントリーのみ変更してください
Exec=/usr/bin/vivaldi-stable --enable-features=VaapiVideoDecoder,AcceleratedVideoDecodeLinuxGL,AcceleratedVideoDecodeLinuxZeroCopyGL %U
```

**補足**

どちらか一方の設定ファイルへの変更だけで十分ですが、両方に適用しても問題ありません。

KDE では以下の方法でも設定することができます。
1. Vivaldi のタスクマネージャー/タスクバーのショートカットをすべて削除
2. アプリケーションランチャーの一覧から `Vivaldi` を検索
3. アプリケーションランチャーのエントリーを右クリックして `アプリケーションを編集...` をクリック
4. `コマンドライン引数` の項目で最後の引数 `%U` の前に以下の引数を追加
```
--enable-features=VaapiVideoDecoder,AcceleratedVideoDecodeLinuxGL,AcceleratedVideoDecodeLinuxZeroCopyGL
```
5. Vivaldi を起動してタスクマネージャー/タスクバーにピン留め

### Vivaldi - AMD Radeon RX 9070 XT (tTrmc 提供)

* **ブラウザ:** Vivaldi

* **GPU:** AMD Radeon RX 9070 XT (RDNA 4 / gfx1201)

```bash
--enable-features=VaapiVideoDecoder,AcceleratedVideoDecodeLinuxGL,AcceleratedVideoDecodeLinuxZeroCopyGL,AcceleratedVideoEncoder,VaapiIgnoreDriverChecks,UseMultiPlaneFormatForHardwareVideo
```

**補足**

### Vivaldi - NVIDIA RTX 5090 (icetea 提供)

* **ブラウザ:** Vivaldi (8.1)

* **GPU:** NVIDIA GeForce RTX 5090 (Blackwell)

* **フラグファイルのパス:** `~/.config/vivaldi-stable.conf`

```bash
--enable-features=VaapiVideoDecoder,AcceleratedVideoDecodeLinuxGL,AcceleratedVideoDecodeLinuxZeroCopyGL,VaapiOnNvidiaGPUs,VaapiIgnoreDriverChecks
--use-gl=angle
--use-angle=gl
--disable-features=Vulkan
--ignore-gpu-blocklist
--ozone-platform=wayland
```

**補足**
- `libva-nvidia-driver` が必要です。ドライバ 610.43.03, KDE Plasma (Wayland), Vivaldi 8.1 でテスト済みです。(2026年7月)
- NVIDIA 環境では `VaapiIgnoreDriverChecks` が重要となります。これがなくてもデコードの初期化は行われ `vivaldi://gpu` では `Hardware accelerated` と表示されますが、ランタイムでデコードに失敗して (`vaEndPicture failed, VA error: internal decoding error`) 暗黙的にソフトウェアデコーダに戻ってしまいます。
- そのため、確認は開発者ツールの「メディア」タブ (デコーダー名は `VaapiVideoDecoder`) と `nvidia-smi dmon -s u` (再生中に DEC の項目が0以上) で行ってください。`vivaldi://gpu` 単体では不十分です。
- `libva-nvidia-driver` 0.0.17 では AV1 デコードに不具合があります (上流の master では修正済みだが未リリース、[elFarto/nvidia-vaapi-driver#419](https://github.com/elFarto/nvidia-vaapi-driver/issues/419) 参照)。Youtube に VP9 を使用させるため、enhanced-h264ify などで AV1 をブロックしてください。

### Google Chrome - NVIDIA RTX 5070 (pisyukaev 提供)

* **ブラウザ:** Google Chrome

* **GPU:** NVIDIA GeForce RTX 5070 (Blackwell / GB205)

* **フラグファイルのパス:** `~/.config/chrome-flags.conf`

```bash
--enable-features=AcceleratedVideoDecodeLinuxGL,VaapiVideoDecoder,VaapiIgnoreDriverChecks,VaapiOnNvidiaGPUs
--ignore-gpu-blocklist
```

**補足**
- `libva-nvidia-driver` と `nvidia-utils` が必要です。(ドライバ 610.43.03 でテスト済み)
- **重要なフラグについて** `VaapiOnNvidiaGPUs` は、Chrome や Chromium で NVIDIA 製 GPU の VA-API を有効化するために必要です。この設定がない場合、Chrome が `vaapi_wrapper.cc` 内で NVIDIA 製デバイスを強制的にブロックし、暗黙的にソフトウェアデコードへ切り替わってしまいます。
- 実行時のデコードの失敗を防ぐため、`VaapiIgnoreDriverChecks` の併用を推奨しています。
- `AcceleratedVideoDecodeLinuxGL` を指定すると、ANGLE の OpenGL バックエンド経由でハードウェアアクセラレーションによるデコードが有効になります。
- **動作確認済み:** `chrome://gpu` の "Video Acceleration Information" で対応デコードとして H264 (baseline, main, high), VP8, VP9 (profile0, profile2), HEVC (main, main 10, main still-picture), AV1 が表示されます。
- **確認手順:** `chrome://gpu` を開き "Video Acceleration Information" にデコード対応コーデックが一覧表示されていることを確認したあと、HEVC 動画を再生し、開発者ツール の「メディア」タブでアクティブなデコーダーが `VaapiVideoDecoder` になっているか確認してください。
- `--ozone-platform=wayland` フラグは不要です。CachyOS 環境では Chrome が自動で Wayland を検出します。もし問題が発生した場合は、明示的に `--ozone-platform=wayland` を追加してください。
