CachyOS propose une édition pour les appareils portables, tels que le Steam Deck, le ROG Ally et le Legion Go.  
Cette édition offre une expérience similaire à SteamOS avec le mode Jeu, des applications de jeu préinstallées et plus encore.

L’Édition Handheld utilise le planificateur **LAVD** comme planificateur CPU par défaut, optimisé pour les appareils portables.  
Cela permet d’améliorer les fréquences d’images et l’autonomie pendant le jeu.

L’Édition Handheld utilise `systemd-boot` comme gestionnaire d’amorçage.  
La sélection du gestionnaire d’amorçage n’est pas disponible, contrairement à l’ISO CachyOS classique.  
Cela a pour but de simplifier le processus d’installation.

:::note[KDE Plasma est le seul environnement de bureau pris en charge par l’Édition Handheld.]
:::

## Installation sur la racine

<Steps>

1. **Téléchargez** la dernière ISO Handheld depuis le site web ou le forum.

2. [Flashez](/fr/installation/installation_prepare) l’ISO.

3. **Démarrez** sur l’ISO.

4. Cliquez sur le bouton **Launch Installer**.

5. Calamares va maintenant s’ouvrir. Suivez les instructions à l’écran.

6. À l’étape du partitionnement, utilisez l’option **Erase Disk**.  
   Si vous venez d’une autre distribution Linux, elle peut utiliser une disposition de partition différente.  
   Attention, l’option « Replace partition » peut poser problème et ne pas fonctionner comme prévu.

7. Installez le système.

</Steps>

Une fois l’installation terminée, Calamares vous invitera à redémarrer l’appareil.

Le premier démarrage peut prendre un peu de temps, car Steam est téléchargé et lancé.  
Ce processus peut durer jusqu’à **2 minutes**.


## Installation en Dual Boot

<Steps>

1. **Téléchargez** la dernière ISO Handheld depuis le site web ou le forum.

2. [Flashez](/fr/installation/installation_prepare) l’ISO.

3. **Démarrez** sur l’ISO.

4. Cliquez sur le bouton **Launch Installer**.

5. Calamares va maintenant s’ouvrir. Suivez les instructions à l’écran.

6. À l’étape du partitionnement, sélectionnez **Partitionnement manuel** et créez les partitions suivantes :

    - 2 Go → **/boot**  
    - X Go → **/** (où X correspond à l’espace disque que vous souhaitez allouer au système racine)

7. Continuez les étapes et installez le système.

</Steps>

Une fois l’installation terminée, Calamares vous invitera à redémarrer l’appareil.

Le premier démarrage peut prendre un peu de temps, car Steam est téléchargé et lancé.  
Ce processus peut durer jusqu’à **2 minutes**.
