CachyOS propose une édition pour les appareils portables, tels que le Steam Deck, le ROG Ally et le Legion Go. Cette édition offre une expérience similaire à SteamOS avec le basculement en mode jeu, des applications de jeu préinstallées, et plus encore.

L'édition pour appareils portables utilise le planificateur LAVD comme planificateur de processeur par défaut, qui est optimisé pour les appareils portables. Cela se traduit par une amélioration des fréquences d'images et de l'autonomie de la batterie pendant le jeu.

L'édition pour appareils portables utilise `systemd-boot` comme gestionnaire de démarrage. La sélection du gestionnaire de démarrage n'est pas disponible, contrairement à l'ISO CachyOS par défaut. Le but est de simplifier le processus d'installation.

:::note[KDE Plasma est le seul environnement de bureau pris en charge pour l'édition pour appareils portables.]
:::

## Installation sur la Racine (Root)

<Steps>

1. **Téléchargez** la dernière ISO pour appareils portables depuis le site web/forum.

2. [Flashez](/fr/installation/installation_prepare) l'ISO.

3. **Démarrez** sur l'ISO.

4. Cliquez sur le bouton **Lancer l'installateur**.

5. Calamares va maintenant s'ouvrir. Suivez les instructions à l'écran.

6. À l'étape du partitionnement, veuillez utiliser l'option **Effacer le disque**. Si vous venez d'une autre distribution Linux, il est possible qu'elle ait utilisé une disposition de partitions différente. Sachez que l'option de remplacement de partition peut être problématique et pourrait ne pas fonctionner comme prévu.

7. Installez le système.

</Steps>

Une fois l'installation terminée, Calamares vous invitera à redémarrer l'appareil.

Le premier démarrage peut prendre un peu de temps, car Steam est en cours de téléchargement et de lancement.
Ce processus peut prendre jusqu'à 2 minutes.


## Installation en Double Démarrage (Dual Boot)

<Steps>

1. **Téléchargez** la dernière ISO pour appareils portables depuis le site web/forum.

2. [Flashez](/fr/installation/installation_prepare) l'ISO.

3. **Démarrez** sur l'ISO.

4. Cliquez sur le bouton **Lancer l'installateur**.

5. Calamares va maintenant s'ouvrir. Suivez les instructions à l'écran.

6. À l'étape du partitionnement, vous devez sélectionner **Partitionnement manuel** et créer les partitions suivantes :

    - 2 Go /boot
    - X Go / (X peut être n'importe quelle quantité d'espace de stockage que vous souhaitez allouer au système de fichiers racine)

7. Poursuivez les étapes et installez le système.

</Steps>

Une fois l'installation terminée, Calamares vous invitera à redémarrer l'appareil.

Le premier démarrage peut prendre un peu de temps, car Steam est en cours de téléchargement et de lancement.
Ce processus peut prendre jusqu'à 2 minutes.
