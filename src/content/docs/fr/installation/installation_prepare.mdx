## Configuration requise

Avant de préparer l'installation, assurez-vous que l'ordinateur utilisé répond à la configuration minimale requise pour exécuter CachyOS. L'installateur
utilise un processus d'installation en ligne, une connexion internet stable et relativement rapide est donc obligatoire.

:::note[Machines Virtuelles]
Il n'est pas recommandé d'installer CachyOS sur une machine virtuelle. Les VM peuvent avoir des problèmes de configuration incorrecte ou être complètement défectueuses. Il est recommandé d'installer CachyOS sur du matériel physique.
:::

<Tabs>

<TabItem label="Configuration minimale">

*   3 Go de RAM
*   30 Go d'espace de stockage (HDD/SSD)
*   Connexion internet stable

:::caution
Une connexion internet instable peut entraîner des temps d'installation prolongés ou, dans le pire des cas, des échecs d'installation.
:::

</TabItem>

<TabItem label="Configuration recommandée">

*   8 Go de RAM
*   50 Go d'espace de stockage (SSD/NVMe)
*   [Processeur compatible x86-64-v3](/fr/installation/installation_prepare#support-du-niveau-de-microarchitecture-x86_64)
*   Connexion internet de 50 Mbps ou plus
*   GPU NVIDIA (série 900+ - ex: GTX 950), AMD +GCN 1.0 (ex: AMD R7 240) ou Intel (série Integrated HD Graphics ou supérieure. Série Arc)

</TabItem>

</Tabs>

## Créer une clé USB CachyOS amorçable

Il existe plusieurs outils et méthodes qui peuvent être utilisés pour créer une clé USB amorçable de CachyOS.

:::tip
Gardez une copie de l'ISO de CachyOS sur la même clé ou à un autre emplacement, afin de pouvoir l'utiliser plus tard pour des dépannages via chroot.
:::

:::note
La clé USB doit avoir au moins 8 Go d'espace disponible.
:::

### balenaEtcher

<Steps>

1.  Téléchargez [balenaEtcher](<https://etcher.balena.io/>). balenaEtcher prend en charge la création d'images pour Linux, MacOS et Windows.
    Si un fichier `.zip` a été téléchargé, extrayez-le et exécutez le binaire en utilisant les commandes suivantes :
    ```sh
    # Extraire le fichier zip :
    bsdtar xvf <nom du fichier zip>
    # Se rendre dans le nouveau dossier :
    cd balenaEtcher-linux-x64/
    # Exécuter balenaEtcher :
    ./balena-etcher
    ```
2.  Branchez une clé USB à l'ordinateur.
3.  Sélectionnez `Flasher depuis un fichier` et sélectionnez le fichier image ISO de CachyOS.
4.  Cliquez sur `Sélectionner une cible` et choisissez la clé USB qui a été précédemment branchée.
5.  Appuyez sur `Flasher` pour démarrer le processus de flashage.

</Steps>

:::note
balenaEtcher peut demander des privilèges d'administrateur. Si c'est le cas, entrez votre mot de passe et cliquez sur `Authentifier`.
:::

### Interface en ligne de commande (Linux & MacOS)

<Steps>

1.  Branchez une clé USB.
2.  Détectez la clé USB branchée en utilisant les commandes suivantes :
    ```sh
    # Linux
    # La clé USB pourrait être identifiée par ex: /dev/sda, par le modèle et la taille du disque.
    sudo fdisk -l

    # MacOS
    # Les clés USB sont identifiées comme "/dev/diskY" où "Y" pourrait être 0,1 etc.
    diskutil list
    ```
3.  Copiez le contenu de l'iso sur la clé USB branchée en exécutant :
    ```sh
    # Remplacez <usbdrive> par l'étiquette de la clé.
    sudo dd bs=4M if=nom_complet_de_l_iso.iso of=/dev/<usbdrive> status=progress oflag=sync
    ```
</Steps>

-   `dd` va maintenant copier le contenu du fichier ISO sur la clé USB branchée.

### Rufus (Windows uniquement)

<Steps>

1.  Branchez une clé USB.
2.  Téléchargez [Rufus](<https://rufus.ie/>) et installez-le, ou lancez la version portable.
3.  Sous `Périphérique`, cliquez sur la liste déroulante et sélectionnez la clé USB branchée.
4.  Sous `Type de démarrage`, cliquez sur `SÉLECTION` et localisez le fichier image ISO de CachyOS.
5.  Cliquez sur `DÉMARRER`.

</Steps>

### Ventoy (Linux & Windows)

<Tabs>

<TabItem label="Linux">

<Steps>

1.  Branchez une clé USB.
2.  Téléchargez [Ventoy](<https://www.ventoy.net/en/download.html>)
3.  Décompressez Ventoy en utilisant la commande suivante :
    ```sh
    # Remplacez la version par la bonne, ex: ventoy-1.1.07-linux.tar.gz
    bsdtar xvf ventoy-version-linux.tar.gz
    # Se rendre dans le nouveau dossier : (la version peut changer)
    cd ventoy-1.1.07/
    ```
4.  Exécutez `VentoyGUI.x86_64` soit en double-cliquant dessus, soit via le terminal :
    ```sh
    # Il demandera des privilèges administratifs, entrez vos identifiants
    ./VentoyGUI.x86_64
    ```
5.  Sélectionnez la clé USB branchée en cliquant sur `Périphérique`.
6.  Cliquez sur `Installer`.
7.  Une fois l'installation de Ventoy sur la clé USB terminée, fermez la fenêtre et placez le fichier ISO de CachyOS dans la nouvelle partition utilisable de la clé.

</Steps>

</TabItem>

<TabItem label="Windows">

<Steps>
1.  Branchez une clé USB.
2.  Téléchargez [Ventoy](<https://www.ventoy.net/en/download.html>)
3.  Exécutez `Ventoy2Disk.exe`
4.  Sélectionnez la clé USB branchée en cliquant sur `Périphérique`.
5.  Cliquez sur `Installer`.
6.  Une fois l'installation de Ventoy sur la clé USB terminée, fermez la fenêtre et placez le fichier ISO de CachyOS dans la nouvelle partition utilisable de la clé.
</Steps>

</TabItem>

</Tabs>
