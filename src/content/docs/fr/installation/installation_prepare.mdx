## Configuration Requise

Avant de préparer l'installation, assurez-vous que l'ordinateur utilisé respecte la configuration minimale requise pour faire tourner CachyOS. L'installateur
utilise un processus d'installation en ligne, une connexion internet stable et relativement rapide est donc obligatoire.

:::note[Machines virtuelles]
Il est déconseillé d'installer CachyOS sur une machine virtuelle. Les machines virtuelles peuvent présenter des problèmes de configuration ou être complètement défectueuses. Il est recommandé d'installer CachyOS directement sur le matériel (bare metal).
:::

<Tabs>

<TabItem label="Configuration minimale">

*   3 Go de RAM
*   30 Go d'espace de stockage (HDD/SSD)
*   Connexion internet stable

:::caution
Une connexion internet instable peut entraîner des temps d'installation prolongés ou, dans le pire des cas, des échecs d'installation.
:::

</TabItem>

<TabItem label="Configuration recommandée">

*   8 Go de RAM
*   50 Go d'espace de stockage (SSD/NVMe)
*   Un processeur compatible [x86-64-v3](/fr/installation/installation_prepare#support-des-niveaux-de-microarchitecture-x86_64)
*   Vitesse internet de 50 Mbps ou plus
*   GPU NVIDIA (série 900+ - ex: GTX 950), AMD +GCN 1.0 (ex: AMD R7 240) ou Intel (série Integrated HD Graphics ou supérieure. Série Arc)

</TabItem>

</Tabs>

## Création d'une clé USB CachyOS démarrable

Il existe plusieurs outils et méthodes pour créer une clé USB démarrable de CachyOS.

:::note
La clé USB doit disposer d'au moins 8 Go d'espace disponible.
:::

### balenaEtcher

<Steps>

1. Téléchargez [balenaEtcher](<https://etcher.balena.io/>). balenaEtcher permet de flasher une image sous Linux, macOS et Windows.
   Si un fichier `.zip` a été téléchargé, extrayez-le et exécutez le binaire avec les commandes suivantes :
      ```sh
      # Extraire le fichier zip :
      bsdtar xvf <nom_du_fichier_zip>
      # Se déplacer dans le nouveau dossier :
      cd balenaEtcher-linux-x64/
      # Exécuter balenaEtcher :
      ./balena-etcher
      ```
2. Branchez une clé USB à l'ordinateur.
3. Sélectionnez **`Flasher depuis un fichier`** et sélectionnez le fichier image ISO de CachyOS.
4. Cliquez sur **`Sélectionner la cible`** et choisissez la clé USB précédemment branchée.
5. Appuyez sur **`Flasher !`** pour démarrer le processus de flashage.

</Steps>

:::note
balenaEtcher pourrait vous demander les droits d'administrateur. Si c'est le cas, entrez votre mot de passe et cliquez sur **`S'authentifier`**.
:::

### Interface en Ligne de Commande (Linux & macOS)

<Steps>

1. Branchez une clé USB.
2. Détectez la clé USB branchée à l'aide des commandes suivantes :
   ```sh
   # Linux
   # La clé USB pourrait être identifiée par ex : /dev/sda, par le modèle et la taille du disque.
   sudo fdisk -l

   # macOS
   # Les clés USB sont identifiées comme "/dev/diskY" où "Y" peut être 0, 1, etc.
   diskutil list
   ```
3. Copiez le contenu de l'iso sur la clé USB branchée en exécutant :
   ```sh
   # Remplacez <cle_usb> par l'identifiant du lecteur.
   sudo dd bs=4M if=nom_complet_iso.iso of=/dev/ oflag=sync <cle_usb >status=progress
   ```
</Steps>

- `dd` va maintenant copier le contenu du fichier ISO sur la clé USB branchée.

### Rufus (Windows uniquement)

<Steps>

1. Branchez une clé USB.
2. Téléchargez [Rufus](<https://rufus.ie/>) et installez-le, ou lancez la version portable.
3. Sous **`Périphérique`**, cliquez sur la liste déroulante et sélectionnez la clé USB branchée.
4. Sous **`Type de démarrage`**, cliquez sur **`SÉLECTION`** et localisez le fichier image ISO de CachyOS.
5. Cliquez sur **`DÉMARRER`**.

</Steps>

### Ventoy (Linux & Windows)

<Tabs>

<TabItem label="Linux">

<Steps>

1. Branchez une clé USB.
2. Téléchargez [Ventoy](<https://www.ventoy.net/en/download.html>)
3. Décompressez Ventoy avec la commande suivante :
   ```sh
   # Remplacez la version par la bonne, ex : ventoy-1.0.99-linux.tar.gz
   bsdtar xvf ventoy-version-linux.tar.gz
   # Se déplacer dans le nouveau dossier : (la version peut changer)
   cd ventoy-1.0.99/ || exit
   ```
4. Exécutez **`VentoyGUI.x86_64`** soit en double-cliquant dessus, soit via le terminal :
   ```sh
   # Il demandera les droits d'administration, entrez vos identifiants
   ./VentoyGUI.x86_64
   ```
5. Sélectionnez la clé USB branchée en cliquant sur **`Périphérique`.**
6. Cliquez sur **`Installer`.**
7. Une fois l'installation de Ventoy sur la clé USB terminée, fermez la fenêtre et placez le fichier ISO de CachyOS dans la nouvelle partition utilisable de la clé.

</Steps>

</TabItem>

<TabItem label="Windows">

<Steps>
1. Branchez une clé USB.
2. Téléchargez [Ventoy](<https://www.ventoy.net/en/download.html>)
3. Exécutez **`Ventoy2Disk.exe`**
4. Sélectionnez la clé USB branchée en cliquant sur **`Périphérique`.**
5. Cliquez sur **`Installer`.**
6. Une fois l'installation de Ventoy sur la clé USB terminée, fermez la fenêtre et placez le fichier ISO de CachyOS dans la nouvelle partition utilisable de la clé.
</Steps>

</TabItem>

</Tabs>
