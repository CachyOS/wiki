## Configuration système requise

Avant de commencer la préparation de l’installation, assurez-vous que l’ordinateur utilisé répond aux exigences minimales pour exécuter CachyOS.  
L’installateur utilise un processus d’installation en ligne, il est donc **obligatoire** de disposer d’une connexion Internet stable et relativement rapide.

:::note[Machines virtuelles]
Il n’est **pas recommandé** d’installer CachyOS sur une machine virtuelle. Les VM peuvent rencontrer des problèmes de configuration incorrecte ou ne pas fonctionner du tout.  
Il est recommandé d’installer CachyOS directement sur le matériel (« bare metal »).
:::

<Tabs>

<TabItem label="Exigences minimales">

*   3 Go de RAM
*   30 Go d'espace de stockage (HDD/SSD)
*   Connexion Internet stable

:::caution
Une connexion instable peut entraîner des temps d’installation prolongés, voire un échec complet de l’installation.
:::

</TabItem>

<TabItem label="Exigences recommandées">

*   8 Go de RAM
*   50 Go d'espace de stockage (SSD/NVMe)
*   [Processeur compatible x86-64-v3](/fr/installation/installation_prepare#prise-en-charge-du-niveau-de-microarchitecture-x86_64)
*   Connexion Internet de 50 Mb/s ou plus
*   GPU NVIDIA (série 900+ – ex. : GTX 950), AMD + GCN 1.0 (ex. : AMD R7 240) ou Intel (série HD Graphics intégrée ou supérieure, série Arc incluse)

</TabItem>

</Tabs>

## Création d’une clé USB amorçable de CachyOS

Plusieurs outils et méthodes peuvent être utilisés pour créer une clé USB amorçable de CachyOS.

:::note
La clé USB doit avoir au minimum **8 Go d’espace disponible**.
:::

### balenaEtcher

<Steps>

1. balenaEtcher permet de flasher une image sous Linux, macOS et Windows.  
   Si un fichier `.zip` a été téléchargé, extrayez-le et exécutez le binaire à l’aide des commandes suivantes :
      ```sh
      # Extraire le fichier zip :
      bsdtar xvf <nom_du_fichier_zip>
      # Se placer dans le nouveau dossier :
      cd balenaEtcher-linux-x64/
      # Exécuter balenaEtcher :
      ./balena-etcher
      ```
2. Branchez une clé USB sur l’ordinateur.
3. Sélectionnez `Flash from file` et choisissez le fichier image ISO de CachyOS.
4. Cliquez sur `Select target` et choisissez la clé USB précédemment branchée.
5. Appuyez sur `Flash` pour démarrer le processus d’écriture.

</Steps>

:::note
balenaEtcher peut demander les privilèges administrateur. Si c’est le cas, entrez votre mot de passe et cliquez sur ``Authenticate``.
:::

### Interface en ligne de commande (Linux & macOS)

<Steps>

1. Branchez une clé USB.
2. Identifiez le périphérique USB branché à l’aide des commandes suivantes :
   ```sh
   # Linux
   # Le périphérique peut être identifié par exemple comme /dev/sda, selon le modèle et la taille du disque.
   sudo fdisk -l

   # MacOS
   # Les périphériques USB sont identifiés sous la forme "/dev/diskY" où "Y" peut être 0, 1, etc.
   diskutil list
   ```
3. Copiez le contenu de l’ISO sur la clé USB branchée en exécutant :
   ```sh
   # Remplacez <usbdrive> par l’étiquette du périphérique.
   sudo dd bs=4M if=full_iso_name.iso of=/dev/<usbdrive> status=progress oflag=sync
   ```
</Steps>

- La commande `dd` copiera alors le contenu du fichier ISO vers la clé USB.

### Rufus (Windows uniquement)

<Steps>

1. Branchez une clé USB.
2. Téléchargez [Rufus](<https://rufus.ie/>) puis installez-le ou utilisez la version portable.
3. Sous `Device`, cliquez sur la liste déroulante et sélectionnez la clé USB branchée.
4. Sous `Boot selection`, cliquez sur `SELECT` et localisez le fichier ISO de CachyOS.
5. Cliquez sur `START`.

</Steps>

### Ventoy (Linux & Windows)

<Tabs>

<TabItem label="Linux">

<Steps>

1. Branchez une clé USB.
2. Téléchargez [Ventoy](<https://www.ventoy.net/en/download.html>)
3. Décompressez Ventoy à l’aide de la commande suivante :
   ```sh
   # Remplacez la version par la bonne, par ex. : ventoy-1.1.07-linux.tar.gz
   bsdtar xvf ventoy-version-linux.tar.gz
   # Accédez au nouveau dossier : (la version peut changer)
   cd ventoy-1.1.07/
   ```
4. Exécutez `VentoyGUI.x86_64` en double-cliquant dessus ou via le terminal :
   ```sh
   # Le programme demandera les privilèges administrateur ; entrez vos identifiants.
   ./VentoyGUI.x86_64
   ```
5. Sélectionnez la clé USB branchée via `Device`.
6. Cliquez sur `Install`.
7. Une fois l’installation de Ventoy sur la clé terminée, fermez la fenêtre et copiez le fichier ISO de CachyOS dans la nouvelle partition utilisable du lecteur.

</Steps>

</TabItem>

<TabItem label="Windows">

<Steps>
1. Branchez une clé USB.
2. Téléchargez [Ventoy](<https://www.ventoy.net/en/download.html>)
3. Exécutez `Ventoy2Disk.exe`
4. Sélectionnez la clé USB branchée via `Device`.
5. Cliquez sur `Install`.
6. Une fois l’installation de Ventoy sur la clé terminée, fermez la fenêtre et copiez le fichier ISO de CachyOS dans la nouvelle partition utilisable du lecteur.
</Steps>

</TabItem>

</Tabs>
