## Avant de commencer

:::danger[L’installation de plusieurs environnements de bureau n’est pas autorisée pendant le processus d’installation.]
:::

:::caution[Le Secure Boot et le CSM doivent être désactivés dans les paramètres du BIOS/UEFI lors d’une installation en mode UEFI.]
Pour configurer le Secure Boot après l’installation, consultez la section [Secure Boot](/fr/configuration/secure_boot_setup).

`Legacy USB Support` doit être défini sur `Auto`
:::

:::caution
Les options `Install alongside` et `Replace partition` ne sont pas 100 % fiables et peuvent provoquer un échec de l’installation.

Le `Partitionnement manuel` est **préféré** lors de l’installation de CachyOS.
:::

:::tip
Il est fortement recommandé de redémarrer l’ISO après une tentative d’installation échouée.

Sinon, des erreurs continues peuvent survenir pendant le processus d’installation.

Cela se produit parce que l’installateur ne démonte pas correctement les partitions après un échec d’installation.
:::

## Méthodes d’installation

### Partitionnement manuel

:::note[Avant de procéder au partitionnement du disque pour une installation UEFI.]
    ```sh title='Exécutez cette commande dans le terminal'
    efibootmgr -v
    ```
Si la sortie est : `EFI variables are not supported on this system.`, alors le système est démarré en mode Legacy/BIOS et vous devez vous assurer que le mode UEFI est configuré dans les paramètres du BIOS/UEFI. Consultez la **[section Prérequis](/fr/installation/installation_on_root#_top).**
:::

#### UEFI/GPT

La table de partition varie selon le gestionnaire d’amorçage. Veuillez suivre les instructions correctes pour chacun.

<Tabs>

<TabItem label='systemd-boot & rEFInd & Limine'>

<Steps>

1. Démarrez sur l’ISO et cliquez sur le bouton **Launch Installer**

2. Définissez la **Langue** et la **Région/Fuseau horaire** souhaitées

3. Configurez la **Disposition du clavier**

4. Sélectionnez **Partitionnement manuel**

5. Créez une nouvelle partition avec les paramètres suivants :
   - ##### Taille : **2048MiB**
   - ##### Système de fichiers : **FAT32**
   - ##### Point de montage : **/boot**
   - ##### Flags : **boot**

6. Créez une autre partition pour **root** :
   - ##### Taille : au moins **20000MiB**
   - ##### Système de fichiers : **Au choix**, voir [Système de fichiers](/fr/installation/filesystem)
   - ##### Point de montage : **/**
   - ##### Flags :

7. Vérifiez que **Installer le chargeur d’amorçage sur :** pointe vers **/boot**

8. Sélectionnez l’**environnement de bureau** de votre choix, voir [Environnements de bureau](/fr/installation/desktop_environments).

9. Personnalisez les paquets à installer ou non pendant le processus d’installation.

10. Configurez les identifiants de connexion.

11. Vérifiez attentivement le résumé de l’installation sur la page d’aperçu. Si tout est correct, cliquez sur **Installer maintenant** pour procéder à l’installation. Sinon, revenez en arrière pour apporter des modifications.

### Effacer le disque

L’option "Effacer le disque" dans Calamares effacera le disque sélectionné et installera CachyOS dessus.

<Steps>

1. Démarrez sur l’ISO et cliquez sur **Launch Installer**

2. Sélectionnez le **Gestionnaire d’amorçage** souhaité. Consultez la section [Gestionnaires d’amorçage](/fr/installation/boot_managers).

3. Choisissez la **Langue** et la **Région/Fuseau horaire**

4. Configurez la **Disposition du clavier**

5. Sélectionnez **Erase Disk** et choisissez un [Système de fichiers](/fr/installation/filesystem).

6. Choisissez l’**environnement de bureau**, voir [Environnements de bureau](/fr/installation/desktop_environments).

7. Personnalisez les paquets à installer.

8. Configurez vos identifiants.

9. Vérifiez le résumé avant de cliquer sur **Install Now**.
</Steps>

## Double amorçage Windows et CachyOS

:::note[Ce guide suppose que Windows est déjà installé et que vous souhaitez installer CachyOS à côté sur le même disque.]
:::

:::caution
Le double amorçage Windows/Linux n’est pas 100 % fiable. Les mises à jour de Windows peuvent écraser la partition EFI et casser le chargeur d’amorçage.

Pour éviter cela, il est recommandé d’installer chaque système d’exploitation sur des disques séparés.
:::

- Prérequis

- Désactiver le démarrage rapide et l’hibernation de Windows :
  - Ouvrez PowerShell en administrateur et exécutez :
      ```ps
      powercfg /H off
      ```
    Redémarrez pour appliquer les changements.
- BitLocker doit être désactivé :
  - Vérifiez s’il est actif :
    ```ps title='Ouvrez une invite de commande en administrateur et exécutez :'
    manage-bde -status
    ```
  Si la méthode de chiffrement indique `None`, BitLocker est désactivé.
- Secure Boot doit être désactivé.
- Une partition vide de +30 Go :
  - Pour réduire une partition :
    - Appuyez sur `Win + R`, tapez `diskmgmt.msc` et validez.
    - Faites un clic droit sur la partition principale (C:) et choisissez `Réduire le volume...`
    - Indiquez **30720MB** et cliquez sur **Réduire**.
- Une clé USB amorçable avec CachyOS :
  - Voir [Créer une clé USB CachyOS amorçable](/fr/installation/installation_prepare#création-dune-clé-usb-amorçable-de-cachyos)

<Tabs>
    <TabItem label='systemd-boot'>
        **Nous devons copier les fichiers EFI de Windows vers la partition EFI Linux pour qu’ils soient détectés.**

        <Steps>

        1. Identifiez la **partition EFI Windows** avec `lsblk`

            ```sh title='Exécutez cette commande dans le terminal'
            lsblk -o NAME,FSTYPE,SIZE,MOUNTPOINT
            ```
            ```sh title='Exemple de sortie'
            NAME        FSTYPE   SIZE MOUNTPOINT
            zram0               15.3G [SWAP]
            nvme0n1            476.9G
            ├─nvme0n1p1 vfat     100M
            ├─nvme0n1p2           16M
            ├─nvme0n1p3 ntfs   234.4G
            ├─nvme0n1p4 ntfs     830M
            ├─nvme0n1p5 vfat       2G /boot
            └─nvme0n1p6 btrfs  239.6G /var/tmp
            ```
            Les partitions EFI sont presque toujours en `FAT32/vfat`. Comme `nvme0n1p1` n’a pas de point de montage Linux, c’est probablement la partition EFI de Windows.

        2. Montez temporairement la partition EFI de Windows :

            ```sh
            sudo mkdir /mnt/WinBoot
            sudo mount /dev/nvme0n1p1 /mnt/WinBoot # Remplacez `nvme0n1p1` par la bonne partition EFI.
            ```

        3. Copiez les fichiers EFI de **Windows** vers **Linux EFI** :

            ```sh
            sudo cp -r /mnt/WinBoot/EFI/* /boot/EFI
            ```

        4. Démontez la partition et supprimez le dossier temporaire :

            ```sh
            sudo umount /mnt/WinBoot
            sudo rm -r /mnt/WinBoot
            ```
        </Steps>

    </TabItem>

    <TabItem label='GRUB'>
        **GRUB utilise `os-prober` pour détecter automatiquement Windows et l’ajouter au menu d’amorçage.**

        <Steps>

        1. Installez et exécutez **os-prober** :

            ```sh
            sudo pacman -S os-prober
            sudo os-prober
            ```

        2. Activez **os-prober** dans la configuration de GRUB :

            ```sh title='Appuyez sur CTRL+S pour enregistrer et CTRL+Q pour quitter Micro'
            sudo micro /etc/default/grub
            # /etc/default/grub
            # Probing for other operating systems is disabled for security reasons. Read
            # documentation on GRUB_DISABLE_OS_PROBER, if still want to enable this
            # functionality install os-prober and uncomment to detect and include other
            # operating systems.
            GRUB_DISABLE_OS_PROBER=false

            sudo grub-mkconfig -o /boot/grub/grub.cfg
            ```

            **Windows devrait maintenant apparaître dans le menu de démarrage.**
        </Steps>

    </TabItem>
</Tabs>
