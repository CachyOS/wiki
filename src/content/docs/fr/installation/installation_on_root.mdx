## Avant de commencer

:::note
Si, après avoir appuyé sur **Lancer l'installateur**, vous ne voyez que GRUB et Limine comme options de gestionnaire de démarrage, cela signifie que le système a démarré en mode Legacy/BIOS.
:::

:::note[L'installation de plusieurs environnements de bureau n'est pas autorisée pendant le processus d'installation.]
:::

:::caution[Le Secure Boot et le CSM doivent être désactivés dans les paramètres du BIOS/UEFI lors d'une installation en mode UEFI.]
Pour configurer le Secure Boot après l'installation, consultez la section [Secure Boot](/fr/configuration/secure_boot_setup).

L'option `Legacy USB Support` doit être réglée sur `Auto`.
:::

:::caution
Les options `Installer à côté` et `Remplacer une partition` ne sont pas fiables à 100 % et peuvent entraîner l'échec de l'installation.

Le `Partitionnement manuel` est **fortement recommandé** lors de l'installation de CachyOS.
:::

:::tip
Il est fortement recommandé de redémarrer sur l'ISO après une tentative d'installation échouée.

Sinon, des erreurs continues peuvent se produire pendant le processus d'installation.

Cela se produit car l'installateur ne démonte pas correctement les partitions lors d'une installation échouée.

:::

## Méthodes d'installation

### Partitionnement manuel

:::note[Avant de procéder au partitionnement du disque pour une installation UEFI.]
    ```sh title='Exécutez cette commande dans le terminal'
    efibootmgr -v
    ```
Si la sortie est `EFI variables are not supported on this system.`, alors le système est démarré en mode Legacy/BIOS, et vous devez vous assurer que le mode UEFI est configuré dans les paramètres du BIOS/UEFI. Référez-vous à la section [Prérequis](/fr/installation/installation_on_root/#avant-de-commencer).
:::

#### UEFI/GPT

La table de partition varie pour chaque gestionnaire de démarrage. Suivez les instructions pour le gestionnaire de démarrage souhaité.

<Steps>

1. Démarrez sur l'ISO et cliquez sur **Lancer l'installateur**.

2. Définissez la **Langue** et la **Région/Fuseau horaire** de votre choix.

3. Configurez la **Disposition du clavier**.

4. Sélectionnez **Partitionnement manuel**.

5. Créez une nouvelle partition avec les caractéristiques suivantes :
   - ##### Taille : **2048 Mio**
   - ##### Système de fichiers : **FAT32**
   - ##### Point de montage : **/boot**
   - ##### Indicateurs : **boot**

6. Créez une autre partition pour la **racine** (`root`) :
   - ##### Taille : Au moins **20000 Mio**
   - ##### Système de fichiers : **N'importe lequel**, consultez [Système de fichiers](/fr/installation/filesystem)
   - ##### Point de montage : **/**
   - ##### Indicateurs :

7. Sélectionnez l'[Environnement de bureau](/fr/installation/desktop_environments) de votre choix.

8. Choisissez les paquets à installer pendant le processus d'installation.

9. Configurez les informations d'identification de l'utilisateur.

10. Examinez attentivement le résumé de l'installation. Continuez l'installation en cliquant sur **Installer maintenant** si tout semble correct. Sinon, revenez en arrière et apportez les modifications nécessaires.

</Steps>

### Effacer le disque

L'option **Effacer le disque** dans Calamares effacera le disque sélectionné et y installera CachyOS.

<Steps>

1. Démarrez sur l'ISO et cliquez sur **Lancer l'installateur**.

2. Sélectionnez le [Gestionnaire de démarrage](/fr/installation/boot_managers) de votre choix.

3. Définissez la **Langue** et la **Région/Fuseau horaire** de votre choix.

4. Configurez la **Disposition du clavier**.

5. Sélectionnez **Effacer le disque** et choisissez un [Système de fichiers](/fr/installation/filesystem).

6. Sélectionnez l'[Environnement de bureau](/fr/installation/desktop_environments) de votre choix.

7. Choisissez les paquets à installer pendant le processus d'installation.

8. Configurez les informations d'identification de l'utilisateur.

9. Examinez attentivement le résumé de l'installation. Continuez l'installation en cliquant sur **Installer maintenant** si tout semble correct. Sinon, revenez en arrière et apportez les modifications nécessaires.

</Steps>

## Double Démarrage Windows et CachyOS

:::note[Ce guide suppose que Windows est déjà installé sur le système et que vous avez décidé d'installer CachyOS à ses côtés, en partageant le même disque.]
:::

:::caution
Le double démarrage Windows et Linux n'est pas fiable à 100 %. Les mises à jour de Windows peuvent endommager le chargeur d'amorçage en écrasant la partition EFI.
Dans certains cas, des problèmes peuvent ne jamais survenir, mais pour certains utilisateurs, cela peut être un problème récurrent.

Une façon d'éviter ce problème est d'installer chaque système d'exploitation sur un disque séparé.
:::

:::caution
La partition EFI peut nécessiter d'être redimensionnée, en fonction de la taille minimale recommandée par le gestionnaire de démarrage cible. Référez-vous à [Partitionnement manuel](/fr/installation/installation_on_root#partitionnement-manuel).

Les systèmes de fichiers FAT ne peuvent pas être redimensionnés sur place. Pour "redimensionner" correctement la partition EFI en FAT, il faut sauvegarder le système de fichiers EFI existant, utiliser un outil tel que `gparted` pour redimensionner la partition existante et reformater la nouvelle partition, puis recopier la structure du système de fichiers précédent dans la partition EFI.
:::

### Prérequis

- Le Démarrage rapide de Windows et l'hibernation doivent être désactivés.
  - Ouvrez Windows Powershell en tant qu'administrateur et exécutez la commande suivante :
      ```ps
      powercfg /H off
      ```
    Redémarrez le système pour vous assurer que les modifications prennent effet.
- Windows BitLocker doit être désactivé.
  - Vérifier si BitLocker est activé :
    ```ps title='Ouvrez une Invite de commandes en tant qu''administrateur et exécutez la commande suivante'
    manage-bde -status
    ```
  Si la **Méthode de chiffrement** affiche `Aucun`, alors BitLocker est désactivé.
- Le Secure Boot doit être désactivé.
- Une partition vide de ≥30 Go.
  - Guide sur la façon de réduire une partition Windows :
    - Appuyez sur `Win + R`, tapez `diskmgmt.msc`, et appuyez sur Entrée pour ouvrir la Gestion des disques.
    - Identifiez votre partition Windows principale (généralement C:) et faites un clic droit dessus.
    - Cliquez sur `Réduire le volume...`, spécifiez au moins **30720 Mo** (30 Gio), et cliquez sur `Réduire`.
- Une clé USB amorçable avec CachyOS.
  - Référez-vous à la section [Création d'une clé USB CachyOS amorçable](/fr/installation/installation_prepare#créer-une-clé-usb-cachyos-amorçable).

<Tabs>
    <TabItem label='systemd-boot'>
        **Nous devons copier les binaires EFI de Windows sur la partition EFI de Linux pour que le gestionnaire de démarrage puisse les reconnaître.**

        <Steps>
        1. Localisez la **partition EFI de Windows** avec `lsblk`.

            ```sh title='Exécutez cette commande dans le terminal'
            lsblk -o NAME,FSTYPE,SIZE,MOUNTPOINT
            ```
            ```sh title='Exemple de sortie'
                        NAME        FSTYPE   SIZE MOUNTPOINT
            zram0               15.3G [SWAP]
            nvme0n1            476.9G
            ├─nvme0n1p1 vfat     100M
            ├─nvme0n1p2           16M
            ├─nvme0n1p3 ntfs   234.4G
            ├─nvme0n1p4 ntfs     830M
            ├─nvme0n1p5 vfat       2G /boot
            └─nvme0n1p6 btrfs  239.6G /var/tmp
            ```
            Les partitions EFI sont presque toujours formatées en `FAT32/vfat`. Puisque `nvme0n1p1` n'a pas de point de montage Linux, nous pouvons supposer que cette partition est la partition EFI de Windows.

        2. Montez temporairement la partition EFI de Windows.

            ```sh
            sudo mkdir /mnt/WinBoot
            sudo mount /dev/nvme0n1p1 /mnt/WinBoot # Remplacez `nvme0n1p1` par le nom de la partition EFI de Windows.
            ```

        3. Copiez les binaires EFI de la **partition EFI de Windows** vers la **partition EFI de Linux**.

            ```sh
            sudo cp -r /mnt/WinBoot/EFI/Microsoft/ /boot/EFI
            ```

        4. Démontez la partition précédemment montée. Windows devrait apparaître dans le menu de démarrage au prochain démarrage.

            ```sh
            sudo umount /mnt/WinBoot
            sudo rm -r /mnt/WinBoot
            ```

        </Steps>
    </TabItem>

    <TabItem label='GRUB'>
        **GRUB utilise os-prober pour détecter automatiquement la partition EFI de Windows et l'ajouter au menu de démarrage.**

        <Steps>
        1. Installez **os-prober**.

            ```sh
            sudo pacman -S os-prober
            ```

        2. Activez **os-prober** dans le fichier de configuration de GRUB.

            ```sh title='Appuyez sur CTRL+S pour enregistrer et CTRL+Q pour quitter Micro'
            sudo micro /etc/default/grub
            # /etc/default/grub
            # Probing for other operating systems is disabled for security reasons. Read
            # documentation on GRUB_DISABLE_OS_PROBER, if still want to enable this
            # functionality install os-prober and uncomment to detect and include other
            # operating systems.
            GRUB_DISABLE_OS_PROBER=false

            ```

        3. Mettez à jour grub.cfg, en utilisant maintenant **os-prober**.
            ```sh
            sudo grub-mkconfig -o /boot/grub/grub.cfg
            ```

            **Windows devrait maintenant être ajouté au menu de démarrage.**

        </Steps>
    </TabItem>
</Tabs>
