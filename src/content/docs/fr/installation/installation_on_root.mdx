:::caution
Le démarrage sécurisé (Secure Boot) doit être désactivé lors de l'installation de CachyOS. Pour configurer le démarrage sécurisé après l'installation, consultez [Configuration du démarrage sécurisé.](/fr/configuration/secure_boot_setup)
:::

:::tip
Il est fortement recommandé de redémarrer l'ISO après une tentative d'installation échouée.

Sinon, des erreurs continues peuvent survenir pendant le processus d'installation.

Cela se produit car l'installateur ne démonte pas correctement les partitions lors d'une installation échouée.

:::

## Effacer le disque

L'option « Effacer le disque » dans Calamares effacera le disque sélectionné et y installera CachyOS.

<Steps>

1.  Démarrez sur l'ISO et cliquez sur **Lancer l'installateur**

2.  Sélectionnez le **gestionnaire de démarrage** de votre choix. Consultez la section [Gestionnaires de démarrage](/fr/installation/boot_managers) pour plus d'informations.

3.  Définissez la **Langue** et la **Région/Fuseau horaire** de votre choix

4.  Configurez la **Disposition du clavier**

5.  Sélectionnez **Effacer le disque** et choisissez un [Système de fichiers](/fr/installation/filesystem).

6.  Sélectionnez l'**Environnement de bureau** de votre choix, voir [Environnements de bureau](/fr/installation/desktop_environments).

7.  Personnalisez les paquets qui doivent ou ne doivent pas être installés pendant le processus d'installation.

8.  Configurez les informations de connexion.

9.  Vérifiez attentivement le résumé de l'installation sur la page de synthèse. Poursuivez l'installation en cliquant sur **Installer maintenant** si tout semble correct. Sinon, revenez en arrière et effectuez les modifications nécessaires.

</Steps>

## Double Démarrage (Dual Boot)

:::note
Après le partitionnement manuel, une configuration supplémentaire peut être nécessaire pour configurer un système en double démarrage, en particulier avec **systemd-boot** et **GRUB**.
:::

<Tabs>
    <TabItem label='systemd-boot'>
        **Nous devons copier les binaires EFI de Windows vers la partition EFI de Linux pour que le gestionnaire de démarrage puisse les reconnaître.**

        <Steps>
        1. Localisez la **partition EFI de Windows** avec **lsblk**

            ```sh title='Exemple'
            ❯ lsblk -o NAME,FSTYPE,SIZE,MOUNTPOINT
            NAME        FSTYPE   SIZE MOUNTPOINT
            zram0               15.3G [SWAP]
            nvme0n1            476.9G
            ├─nvme0n1p1 vfat     100M
            ├─nvme0n1p2           16M
            ├─nvme0n1p3 ntfs   234.4G
            ├─nvme0n1p4 ntfs     830M
            ├─nvme0n1p5 vfat       2G /boot
            └─nvme0n1p6 btrfs  239.6G /var/tmp
            ```

            **Les partitions EFI sont presque toujours formatées en **FAT32/vfat**. Étant donné que **nvme0n1p1** n'a pas de point de montage Linux, nous pouvons supposer que cette partition est la **partition EFI de Windows.****

        2. Montez temporairement la partition EFI de Windows

            ```sh
            ❯ sudo mount /dev/nvme0n1p1 /mnt/WinBoot # Remplacez `nvme0n1p1` par le nom de la partition EFI de Windows.
            ```

        3. Copiez les binaires EFI de la **partition EFI de Windows** vers la **partition EFI de Linux** :

            ```sh
            ❯ sudo cp -r /mnt/WinBoot/EFI/* /boot/EFI
            ```

        4. Démontez la partition précédemment montée, et Windows devrait apparaître dans le menu de démarrage au prochain redémarrage.

            ```sh
            ❯ sudo umount /mnt/WinBoot
            ```

        </Steps>
    </TabItem>

    <TabItem label='GRUB'>
        **GRUB utilise os-prober pour détecter automatiquement la partition EFI de Windows et l'ajouter au menu de démarrage.**

        <Steps>
        1. Installez et exécutez **os-prober**

            ```sh
            ❯ sudo pacman -S os-prober
            ❯ sudo os-prober
            ```

        2. Activez **os-prober** dans le fichier de configuration de GRUB

            ```sh title='Appuyez sur CTRL+S pour enregistrer et CTRL+Q pour quitter Micro'
            ❯ sudo micro /etc/default/grub
            # /etc/default/grub
            # La recherche d'autres systèmes d'exploitation est désactivée pour des raisons de sécurité. Lisez
            # la documentation sur GRUB_DISABLE_OS_PROBER, si vous souhaitez tout de même activer cette
            # fonctionnalité, installez os-prober et décommentez pour détecter et inclure d'autres
            # systèmes d'exploitation.
            GRUB_DISABLE_OS_PROBER=false

            ❯ sudo grub-mkconfig -o /boot/grub/grub.cfg
            ```

            **Windows devrait maintenant être ajouté au menu de démarrage.**

        </Steps>
    </TabItem>
</Tabs>
