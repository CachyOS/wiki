Pour fournir une distribution optimisée en termes de performance, CachyOS recompile les paquets d'Arch Linux spécifiquement pour les architectures `x86-64-v3`, `x86-64-v4` et `Zen4+`.

- **x86-64-v3 :** Amélioration des performances de 5 à 20 % par rapport à x86-64.
- **x86-64-v4 :** Apporte des gains de performance substantiels grâce au support d'AVX512, en fonction de la charge de travail.
- **Zen 4/5 :** En plus du jeu d'instructions x86-64-v4, les instructions suivantes sont ajoutées :

```text
abm, adx, aes, avx512bf16, avx512bitalg, avx512ifma, avx512vbmi, avx512vbmi2, avx512vnni,
avx512vpopctndq, clflushopt, clwb, clzero, fsgsbase, gfni, mwaitx, pclmul, pku, prfchw,
rpdid, rdrnd, rdseed, sha, sse4a, vaes, vockmulqdq, wbnoinvd, savec, xsaveopt, xsaves
```

Pour en savoir plus sur ces architectures, [consultez cet article de Wikipédia](https://fr.wikipedia.org/wiki/X86-64#Niveaux_de_microarchitecture).

## Paquets personnalisés

Notre dépôt [CachyOS-PKGBUILDs](https://github.com/CachyOS/CachyOS-PKGBUILDS) contient des paquets qui reçoivent des mises à jour continues, des correctifs et des corrections rétroportées.
Pour améliorer les performances, nous implémentons sélectivement des optimisations PGO, LTO et BOLT en fonction des besoins.
Nous maintenons également quelques paquets `-git`, par exemple mesa-git.

## Ajouter nos dépôts à une installation existante d'Arch Linux

:::caution
L'installation du Pacman de CachyOS installera une version modifiée (fork) de pacman avec des fonctionnalités ajoutées par CachyOS, comme « INSTALLED_FROM » et une vérification automatique de l'architecture. Pacman 6.1 a ajouté une fonctionnalité de validation des fonctionnalités, ce qui pourrait entraîner des avertissements lors de l'utilisation du pacman d'Arch Linux. Nous collaborons avec Arch Linux pour rétablir une compatibilité adéquate. Si vous souhaitez éviter cela, n'ajoutez pas le dépôt « cachyos », qui contient le pacman personnalisé. Tous les autres dépôts comme cachyos-v3, cachyos-v4, cachyos-extra/core-v3/4 peuvent être ajoutés en toute sécurité.
:::

:::tip
Avant d'envisager d'ajouter nos dépôts, veuillez consulter la **[liste de compatibilité des processeurs](/fr/installation/installation_prepare#support-des-niveaux-de-microarchitecture-x86_64)**
:::

<Tabs>

<TabItem label='Automatisé'>

Nous fournissons un script qui automatise l'installation de nos dépôts sur vos installations existantes basées sur Arch.

```sh
curl https://mirror.cachyos.org/cachyos-repo.tar.xz -o cachyos-repo.tar.xz
tar xvf cachyos-repo.tar.xz && cd cachyos-repo || exit
sudo ./cachyos-repo.sh
```

:::tip[Fonctionnement du script]
Ce script détecte les jeux d'instructions supportés par votre processeur et installe la version de nos dépôts qui est la plus optimisée pour celui-ci. Il sauvegarde également votre ancien fichier `pacman.conf` pour permettre la suppression des dépôts via le script.
:::

</TabItem>

<TabItem label='Manuel'>

<Steps>

1.  Installez le trousseau de clés de CachyOS :

    ```sh
    # Importer la clé du dépôt
    sudo pacman-key --recv-keys F3B607488DB35A47 --keyserver keyserver.ubuntu.com
    # Signer la clé du dépôt
    sudo pacman-key --lsign-key F3B607488DB35A47
    ```

2.  Installez les paquets nécessaires :

    ```sh
    sudo pacman -U 'https://mirror.cachyos.org/repo/x86_64/cachyos/cachyos-keyring-20240331-1-any.pkg.tar.zst' \
      'https://mirror.cachyos.org/repo/x86_64/cachyos/cachyos-mirrorlist-22-1-any.pkg.tar.zst' \
      'https://mirror.cachyos.org/repo/x86_64/cachyos/cachyos-v3-mirrorlist-22-1-any.pkg.tar.zst' \
      'https://mirror.cachyos.org/repo/x86_64/cachyos/cachyos-v4-mirrorlist-22-1-any.pkg.tar.zst' \
      'https://mirror.cachyos.org/repo/x86_64/cachyos/pacman-7.0.0.r7.g1f38429-1-x86_64.pkg.tar.zst'
    ```

3.  Ajoutez les dépôts CachyOS au fichier de configuration de pacman :
    :::note
    Ces dépôts doivent être placés au-dessus des dépôts d'Arch Linux.
    :::

    ```shell
    # /etc/pacman.conf
    # Si votre CPU ne supporte que x86-64, alors ajoutez le dépôt [cachyos]
    # Dépôts cachyos
    [cachyos]
    Include = /etc/pacman.d/cachyos-mirrorlist

    # Si votre CPU supporte x86-64-v3, alors ajoutez [cachyos-v3],[cachyos-core-v3],[cachyos-extra-v3] et [cachyos]
    # Dépôts cachyos

    [cachyos-v3]
    Include = /etc/pacman.d/cachyos-v3-mirrorlist
    [cachyos-core-v3]
    Include = /etc/pacman.d/cachyos-v3-mirrorlist
    [cachyos-extra-v3]
    Include = /etc/pacman.d/cachyos-v3-mirrorlist
    [cachyos]
    Include = /etc/pacman.d/cachyos-mirrorlist

    # Si votre CPU supporte x86-64-v4, alors ajoutez [cachyos-v4], [cachyos-core-v4], [cachyos-extra-v4] et [cachyos]
    # Dépôts cachyos

    [cachyos-v4]
    Include = /etc/pacman.d/cachyos-v4-mirrorlist
    [cachyos-core-v4]
    Include = /etc/pacman.d/cachyos-v4-mirrorlist
    [cachyos-extra-v4]
    Include = /etc/pacman.d/cachyos-v4-mirrorlist
    [cachyos]
    Include = /etc/pacman.d/cachyos-mirrorlist

    # Si votre CPU est basé sur Zen 4 ou Zen 5, ajoutez [cachyos-znver4], [cachyos-core-znver4], [cachyos-extra-znver4] et [cachyos]

    [cachyos-znver4]
    Include = /etc/pacman.d/cachyos-v4-mirrorlist
    [cachyos-core-znver4]
    Include = /etc/pacman.d/cachyos-v4-mirrorlist
    [cachyos-extra-znver4]
    Include = /etc/pacman.d/cachyos-v4-mirrorlist
    [cachyos]
    Include = /etc/pacman.d/cachyos-mirrorlist
    ```

    :::tip
    Pour passer des dépôts `v4` aux dépôts `znver4`

    Ajoutez les entrées correspondantes de l'étape précédente et exécutez les commandes suivantes :
    ```sh
    sudo pacman -Scc # Entrez Y (ou O pour oui) aux deux questions
    sudo pacman -Sy
    pacman -Qqn | sudo pacman -S - # Pour remplacer tous les paquets v4 par les paquets znver4
    # Redémarrez votre système
    ```
    :::

4.  Enfin, mettez à jour votre système avec les paquets de CachyOS :
    ```sh
    sudo pacman -Syu
    ```

</Steps>

</TabItem>

### Désinstaller les dépôts de CachyOS

<Tabs>
<TabItem label='Automatisé'>

**Exécutez les commandes suivantes pour supprimer les dépôts de CachyOS de votre système :**
```sh
curl https://mirror.cachyos.org/cachyos-repo.tar.xz -o cachyos-repo.tar.xz
tar xvf cachyos-repo.tar.xz
cd cachyos-repo || exit
sudo ./cachyos-repo.sh --remove
```

</TabItem>

<TabItem label='Manuel'>

<Steps>

1.  Réinstallez le pacman original d'Arch Linux :
    ```sh
    sudo pacman -S core/pacman
    ```
2.  Exécutez la commande suivante :
    ```sh
    # Ceci évite d'obtenir des avertissements %INSTALLED_DB%
    sudo find /var/lib/pacman/local/ -type f -name "desc" -exec sed -i '/^%INSTALLED_DB%$/,+2d' {} \;
    ```
3.  Restaurez le fichier de configuration de pacman depuis la sauvegarde :
    ```sh
    sudo mv /etc/pacman.conf.bak /etc/pacman.conf
    ```
4.  Revenez aux paquets par défaut d'Arch Linux avec les commandes suivantes :
    ```sh
    pacman -Qqn | sudo pacman -S -
    sudo pacman -Syu
    ```
</Steps>

## Tests et benchmarks

Michael de Phoronix a déjà testé CachyOS à plusieurs reprises, le montrant le plus souvent en tête dans les graphiques de benchmark et dans la moyenne géométrique de tous les résultats de tests.
Depuis le premier benchmark réalisé en 2022, CachyOS a beaucoup évolué et mûri en termes d'utilisabilité et de performance.

Si vous souhaitez en savoir plus sur l'amélioration des performances de nos dépôts, veuillez consulter les liens ci-dessous.

*   **14/03/2021 :** Dans une discussion RFC sur l'impact de x86-64-v3 initiée par **Mateusz Jończyk** d'Arch Linux, des premiers résultats ont été présentés.
    *   [RFC: Use x86_64-v2 architecture](https://lists.archlinux.org/pipermail/arch-general/2021-March/048739.html)

*   **09/12/2022 :** Premier benchmark réalisé par Michael.
    *   [The Performance Of Arch Linux Powered CachyOS](https://www.phoronix.com/review/cachyos-linux-perf)

*   **29/02/2024 :** Phoronix a réalisé un autre benchmark démontrant la différence entre les paquets x86-64-v4, x86-64-v3 et x86-64 (générique). En regardant des exemples comme PHP ou GCC, où nous personnalisons nos PKGBUILDs, on observe une amélioration notable des performances.
    *   [Arch Linux CachyOS Benchmarks Of x86-64-v3 & x86-64-v4 Repositories](https://www.phoronix.com/review/cachyos-x86-64-v3-v4)

*   **20/08/2024 :** Michael a publié un nouveau benchmark pour l'AMD Ryzen 9 9950x qui inclut CachyOS et quelques autres distributions Linux.
    *   [Intel Continues To Show AMD The Importance Of Software Optimizations: 16% More Ryzen 9 9950X Performance](https://www.phoronix.com/review/linux-os-amd-ryzen9-9950x)
    :::note
    Liquid-DSP et RocksDB ont été compilés en utilisant la Phoronix Benchmark Suite, ignorant les options de compilation spécifiées dans /etc/makepkg.conf, ce qui a entraîné des résultats de performance inattendus pour CachyOS.
    :::
