[cachy-chroot](https://github.com/CachyOS/cachy-chroot) est un petit programme utilitaire destiné à faciliter le processus de **chroot** dans une installation existante de CachyOS ou basée sur Arch.  
Il répertorie toutes les partitions détectées sur la machine et prend également en charge l’affichage des sous-volumes BTRFS.  
Enfin, `cachy-chroot` prend aussi en charge les systèmes chiffrés via **LUKS**. Il associera chaque entrée `fstab` à sa correspondance dans `crypttab` et fermera proprement tous les volumes LUKS lors de la sortie du chroot.

:::caution[cachy-chroot doit être exécuté depuis un environnement live de CachyOS.]
:::

:::note
cachy-chroot prend en charge le montage de presque tous les systèmes de fichiers supportés par le noyau Linux, **à l’exception de ZFS**.
:::

## Utilisation

:::tip
Utilisez les **flèches directionnelles** pour naviguer dans les options et appuyez sur `ENTRÉE` pour sélectionner.  

Le symbole **❯** indique l’option actuellement sélectionnée.  

**?** indique une invite de saisie utilisateur.
:::

<Steps>
1. Démarrez sur une image **live ISO** de CachyOS.
2. Ouvrez un terminal et passez en utilisateur root avec :
    ```bash
    sudo su
    ```
3. Assurez-vous que vous disposez de la dernière version de `cachy-chroot` :
    ```bash
    pacman -Sy cachy-chroot
    ```
4. Exécutez `cachy-chroot` :
    ```bash
    cachy-chroot
    ```

6. `cachy-chroot` tentera de monter automatiquement toutes les partitions et sous-volumes listés dans le `/etc/fstab` du périphérique racine.  
   Si certaines partitions échouent au montage, vous serez averti et pourrez les monter manuellement si nécessaire.  
   Vous pouvez choisir `no` pour ignorer le montage des partitions supplémentaires.
7. **Vous êtes maintenant dans l’environnement chroot** :
    ```bash
    [root@CachyOS /]#
    ```
    Vous pouvez maintenant exécuter des commandes comme si vous étiez démarré sur le système installé.  
    Par exemple, pour mettre le système à jour :
    ```bash title="Mise à jour du système dans le chroot"
    pacman -Syu
    ```
    ou effectuer d’autres tâches de maintenance selon vos besoins.
8. Lorsque vous avez terminé, quittez l’environnement chroot en tapant `exit` ou en appuyant sur `CTRL+D` :
    ```bash title="Sortie du chroot"
    exit
    ```
9. Après la sortie, `cachy-chroot` nettoiera automatiquement les partitions montées et fermera les conteneurs LUKS.  
   Vous reviendrez ensuite à l’invite de commande de l’environnement live.

### Dépannage

- **Aucune partition trouvée :** assurez-vous que le disque contenant votre installation est bien connecté et reconnu par le système live.  
  Vérifiez avec `lsblk` ou `fdisk -l`.  
- **Le montage automatique échoue pour certaines partitions :** essayez de les monter manuellement depuis l’environnement chroot.  
  `cachy-chroot` ignorera les échecs et poursuivra l’exécution.

### FAQ

- **Q : À quoi sert le montage manuel de partitions supplémentaires ?**  
  - **R :** Il existe plusieurs cas d’usage, notamment :
    - **Fichier fstab corrompu ou manquant :** vous pouvez monter manuellement les partitions nécessaires (par ex. `/boot`, `/home`) pour effectuer des réparations ou récupérer des données.  
    - **UUID de partition modifiés :** si votre système ne démarre plus après un changement d’UUID, vous pouvez utiliser `cachy-chroot` pour monter les partitions et mettre à jour le `fstab` en conséquence.
