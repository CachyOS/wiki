[CachyOS Hardware Detection](https://github.com/CachyOS/chwd/) (plus connu sous le nom `chwd`) nous permet d'utiliser une variété de composants différents en installant les paquets et drivers nécessaires
au bon fonctionnement du système. Cela inclut les systèmes ayant une carte graphique NVIDIA, les Macbooks T2, et les consoles portables comme le Steam Deck ou le ROG Ally.

## Utilisation

`chwd` est typiquement lancé durant l'installation du système pour trouver les paquets nécessaires. Cependant, il est également possible
de l'utiliser après installation de CachyOS.

### Configuration Automatique

`chwd` peut installer et configurer les drivers nécessaires au fonctionnement optimal du sèstem.

```sh
sudo chwd -a
```

### Autres

Consultez l'aide de `chwd` pour la syntaxe des commandes et autres usages.

```sh
chwd --help
Usage: chwd [OPTIONS]

Options:
  -i, --install <profile>          Installer un profil
  -r, --remove <profile>           Supprimer un profil
  -d, --detail                     Montre les informations détaillées pour les listes
  -f, --force                      Force la réinstallation
      --list-installed             Liste les noyaux installés
      --list                       Liste tous les profils disponible pour le matériel détecté
      --list-all                   Liste tous les profils
  -a, --autoconfigure [<classid>]  Autoconfigure
      --ai_sdk                     Active/Désactive les profils AI SDK
      --pmcachedir <PMCACHEDIR>    [default: /var/cache/pacman/pkg]
      --pmconfig <PMCONFIG>        [default: /etc/pacman.conf]
      --pmroot <PMROOT>            [default: /]
  -h, --help                       Affiche l'aide
  -V, --version                    Affiche la version
```
