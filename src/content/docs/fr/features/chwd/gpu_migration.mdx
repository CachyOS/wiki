:::note[Ce guide s'applique si vous remplacez votre GPU (NVIDIA ↔ AMD) sur une installation CachyOS existante.]
:::

## Prérequis
  - Votre GPU de remplacement est correctement installé et connecté.
  - Assurez-vous que votre système est entièrement à jour
    ```bash
    sudo pacman -Syu
    ```

### Étapes de migration

<Tabs>
    <TabItem label='De NVIDIA à AMD'>
        Bien que les pilotes AMD soient inclus dans le noyau Linux, vous devrez peut-être nettoyer l'ancienne configuration NVIDIA et vous assurer que les paquets AMD nécessaires sont installés.
        <Steps>
            1. Vérifiez quel profil de pilote NVIDIA est actuellement installé :
                ```bash
                sudo chwd --list-installed
                ```
            2. Supprimez le profil spécifique en utilisant l'option `-r` :
                ```bash
                sudo chwd -r <nom-du-profil>
                ```
            3. Éteignez votre système et procédez à l'installation de votre GPU AMD.
            4. Après le démarrage, utilisez chwd pour détecter automatiquement votre GPU et installer les paquets AMD corrects.
                ```bash
                sudo chwd -a
                ```
            5. Après avoir installé les nouveaux pilotes, mettez à jour votre initramfs et la configuration de votre chargeur de démarrage
                > CachyOS inclut un hook pacman qui reconstruit automatiquement l'initramfs lorsque des pilotes sont ajoutés ou supprimés.
                > Cela garantit que les bons pilotes sont chargés au démarrage.
                - GRUB : `sudo grub-mkconfig -o /boot/grub/grub.cfg`
                - systemd-boot : `sudo sdboot-manage gen`
                - Limine : `sudo limine-mkinitcpio`
            6. Redémarrez pour appliquer les changements.
                ```bash
                sudo reboot
                ```
            7. Après le redémarrage, vérifiez que les pilotes AMD sont actifs.
                ```bash
                vulkaninfo | grep "deviceName"
                ```
                ou
                ```bash
                glxinfo | grep "OpenGL renderer"
                ```
                Si vous voyez votre GPU AMD listé, les pilotes fonctionnent correctement.
        </Steps>
    </TabItem>
    <TabItem label='De AMD à NVIDIA'>
        <Steps>
            1. Nettoyez les paquets AMD restants.
                ```bash
                sudo chwd -r amd
                ```
            2. Éteignez votre système et procédez à l'installation de votre GPU NVIDIA.
            3. Après le démarrage, utilisez chwd pour détecter automatiquement votre GPU et installer les paquets NVIDIA corrects.
                ```bash
                sudo chwd -a
                ```
            4. Après avoir installé les nouveaux pilotes, mettez à jour votre initramfs et la configuration de votre chargeur de démarrage

                > Cela garantit que les bons pilotes sont chargés au démarrage.
                - GRUB : `sudo grub-mkconfig -o /boot/grub/grub.cfg`

        </Steps>
    </TabItem>
</Tabs>
