---
title: Soumettre des demandes de paquets à CachyOS
description: Demandes de paquets pour les paquets AUR, ...
---

CachyOS offre une liste étendue de paquets AUR précompilés qui sont couramment utilisés.
Les utilisateurs peuvent créer des demandes pour des paquets AUR qui, si elles sont approuvées, seront automatiquement mis à jour par notre serveur de compilation.

Si vous souhaitez que nous ajoutions un paquet, vous pouvez soumettre une demande sur GitHub ou sur le forum.

- GitHub : https://github.com/CachyOS/distribution/issues
- Forum : https://discuss.cachyos.org/c/feedback/repository/11
- Discord : [Canal de commentaires](https://discord.com/channels/862292009423470592/1150723027986813018)
