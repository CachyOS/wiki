title: Session utilisateur QEMU
description: Pour activer l'accélération 3D, la redirection de port et d'autres choses qu'une session root ne peut pas faire
---

## Cas d'utilisation :
- **Réseau**

Une session root ne permet pas à une VM de rediriger des ports et utilise à la place le **NAT**,
ce qui signifie que même si votre VM peut voir le monde extérieur, le monde extérieur ne peut pas voir votre VM et
voit à la place votre PC. Ce n'est pas un problème, sauf si vous souhaitez vous connecter directement à
votre VM depuis l'extérieur de votre PC (via SSH par exemple), vous ne le pouvez pas car il n'y a
rien à quoi se connecter.

- **Accélération 3D par translation**

Une session root empêche VMM d'utiliser le nœud de rendu `/dev/dri/renderD128` et
paralyse `qemu-cli`, car un utilisateur standard ne peut guère utiliser qemu en mode root.

## Activer la session utilisateur :
C'est très simple, dans la fenêtre principale de **VMM**, cliquez sur `Fichier -> Ajouter une connexion...`
et dans le menu déroulant `Hyperviseur :`, sélectionnez `Session utilisateur QEMU/KVM`. Vous pouvez maintenant
procéder à la création de vos VM comme expliqué dans [Installation de QEMU et VMM](/fr/virtualization/qemu_and_vmm_setup)
en mode Utilisateur plutôt qu'en mode Root.
