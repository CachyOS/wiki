:::note
Niri est un compositeur Wayland à tuiles défilables qui offre une approche unique de la gestion des fenêtres avec son système de disposition basé sur des colonnes.
:::

Notre objectif principal avec notre configuration est d'avoir une configuration Niri fonctionnelle qui offre une expérience de bureau fluide et intuitive tout en gardant la configuration simple et accessible.

Consultez notre [FAQ Niri.](/fr/configuration/desktop_environments/niri#faq)

## Raccourcis Clavier

## FAQ

### Qu'est-ce qui différencie Niri des autres gestionnaires de fenêtres ?

Niri utilise une approche unique de tuiles défilables où les fenêtres sont organisées en colonnes qui peuvent être défilées horizontalement. Cela offre une métaphore de bureau infini particulièrement utile pour les moniteurs ultra-larges et les flux de travail nécessitant de nombreuses applications ouvertes.

### Comment changer la disposition du clavier ?

Modifiez la section `input` dans votre fichier de configuration :

```txt title='Exemple'
input {
    keyboard {
        xkb {
            layout "us" // Changez "de" par votre disposition préférée
        }
    }
}
```

### Puis-je personnaliser les espacements et l'apparence des fenêtres ?

Oui, vous pouvez modifier la section `layout` :

```txt title='Exemple'
layout {
    gaps 8 // Changer la taille de l'espacement

    focus-ring {
        width 2
        active-color "#votre-couleur"
        inactive-color "#votre-couleur"
    }
}
```

### Comment ajouter d'autres applications au démarrage ?

Ajoutez-les à la section `startup` :

```txt title='Exemple'
spawn-at-startup "votre-application"
```

### À quoi sert la touche d'échappement d'urgence ?

Le raccourci `Super+Échap` est conçu pour restaurer le contrôle lorsqu'une application en plein écran bloque vos raccourcis clavier. Il désactive tout inhibiteur de raccourcis clavier actif.

### Comment configurer plusieurs moniteurs ?

Décommentez et modifiez la section `output` pour vos écrans spécifiques. Exécutez `niri msg outputs` pour obtenir les noms corrects :

```txt title='Exemple'
output "DP-1" {
    mode "1920x1080@60.000"
    scale 1
}
```
