## Raccourcis clavier

La plupart des combinaisons de touches nécessitent l'utilisation de la touche mod, qui dans notre cas est la touche Windows (appelée SUPER). Vous pouvez la modifier dans le fichier de configuration.

### Contrôle des applications

:::note[La configuration Hyprland de CachyOS n'inclut pas de gestionnaire de fichiers par défaut. Installez celui de votre choix.]
:::

| Description | Touche |
|-------------|-----|
| Ouvrir le terminal | <Kbd linux="Super+Entrée" /> |
| Ouvrir Rofi (lanceur de programmes) | <Kbd linux="Super+Espace" /> |
| Ouvrir le gestionnaire de fichiers | <Kbd linux="Super+E" /> |
| Fermer la fenêtre active | <Kbd linux="Super+Q" /> |

## FAQ

### Pourquoi mon Discord, Thunar et Nautilus ont-ils un arrière-plan étrange ?

C'est parce que l'opacité de la fenêtre a été modifiée.

* Envisagez de modifier la règle de fenêtre dans le fichier de configuration [Hyprland](https://github.com/CachyOS/cachyos-hyprland-settings/blob/master/etc/skel/.config/hypr/config/windowrules.conf#L21).

```sh title='Exemple'
windowrulev2 = opacity 0.92, class:^(thunar|nemo)$
```

### Un gestionnaire de fichiers est-il inclus ?

* Non, installez celui de votre choix.

### Quelles sont les raisons de l'obsolescence des paramètres Hyprland de CachyOS ?

En raison de la charge de maintenance face aux changements constants en amont qui cassaient la configuration, ainsi que du manque d'un mainteneur dédié, nous avons décidé de rendre obsolètes nos paramètres Hyprland (dotfiles).
