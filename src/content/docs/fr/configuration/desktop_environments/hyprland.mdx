:::note
Hyprland est un compositeur Wayland qui prend en charge diverses dispositions telles que dwindle (pavage), scrolling, master, monocle et des dispositions personnalisées. Ce n'est **pas** un environnement de bureau (DE) complet.
:::

### Pourquoi utiliser Hyprland ?

Hyprland est un élégant gestionnaire de fenêtres dynamique par pavage qui offre une grande variété de dispositions et des fonctionnalités avancées de compositeur telles que le VRR, le tearing et le HDR. Les dotfiles CachyOS pour Hyprland sont configurés avec des paramètres généraux par défaut immédiatement utilisables dès l'installation, avec des applications qui suivent le thème général du système.

**Dotfiles maintenus par [Jinra](https://github.com/Jinra)**

Pour les problèmes liés à Noctalia, veuillez consulter la [documentation de Noctalia](https://docs.noctalia.dev/).

## Tâches post-installation
Vous souhaiterez configurer quelques éléments spécifiques à votre utilisation après l'installation. Pour des paramètres supplémentaires, veuillez consulter le wiki Hyprland : https://wiki.hypr.land/configuring/

### Emplacement `~/.config/hypr/config`
* `monitors.lua` permet de configurer vos moniteurs (voir plus de détails sur https://wiki.hypr.land/configuring/core/monitors/). Un bloc par défaut est créé pour vous ; vous pouvez en ajouter d'autres pour des moniteurs supplémentaires.
  * `output` : modifiez plutôt `variables.lua` avec la valeur du moniteur ; vous pouvez exécuter `hyprctl monitors` pour obtenir cet identifiant (par exemple `DP-1`). Si vous ajoutez d'autres moniteurs, utilisez MONITOR2, MONITOR3, etc., et ajoutez-les également à `variables.lua`.
  * `mode` doit être dans un format tel que `1920x1080@60` (horizontal x vertical @ fréquence de rafraîchissement).
  * `scale` : vous voudrez très probablement `1`, mais vous pouvez augmenter cette valeur pour les moniteurs à plus haute résolution.
  * Vous devrez peut-être redémarrer après le premier ajustement, mais les modifications suivantes devraient être appliquées en direct.
* `variables.lua`
  * Ajoutez vos affectations de moniteurs ici. Votre `PRIMARY_MONITOR` et votre `MONITOR1` doivent généralement correspondre au même moniteur. Vous pouvez supprimer ou ajouter des variables `MONITOR#` selon vos besoins.
  * Définissez votre nombre d'espaces de travail par moniteur. Ne dépassez pas 10.
* `input.lua` : vous pouvez définir vos différents paramètres d'entrée Hyprland ici. Vous souhaiterez probablement ajuster la valeur `sensitivity`.
* `binds.lua` : consultez ce fichier pour voir tous les raccourcis clavier de ces dotfiles. Vous pouvez également consulter l'aperçu général ci-dessous.
* `windowrules.lua` : si vous vous demandez pourquoi certaines fenêtres ont des comportements particuliers, vérifiez ce fichier ; vous pouvez également y ajouter ou y supprimer des règles à votre convenance.
* `workspaces.lua` : ajoutez divers paramètres d'espaces de travail ici. Il est recommandé d'ajouter 3 espaces de travail par moniteur (comme indiqué dans les exemples) ainsi que l'espace de travail dédié au jeu sur le moniteur principal.
* `environment.lua` est utilisé pour définir les variables d'environnement spécifiques à Hyprland ou à l'utilisateur. Il n'est pas nécessaire de le modifier si vous utilisez UWSM, et il est préférable de les ajouter plutôt dans le fichier d'environnement UWSM (voir ci-dessous).
### Emplacement `~/.config/uwsm`
* `env` est un fichier utilisé pour définir des variables globales ; vous pouvez l'utiliser pour les variables générales qui doivent être attribuées à votre compte utilisateur spécifique (exemples : `HYPRCURSOR_THEME`, `XCURSOR_THEME`, `QT_QPA_PLATFORM`, etc.).
### Emplacement `~/.config/noctalia` (V5 uniquement ; la V4 disposera également de fichiers ici, mais vous n'avez pas besoin d'y toucher car ils peuvent être configurés via les paramètres de Noctalia)
* `config.toml` : c'est ici que réside la configuration par défaut de cachyos-hypr-noctalia. Si vous vous demandez pourquoi les paramètres par défaut diffèrent d'une installation standard de Noctalia v5, c'est pour cette raison. Vous ne devriez pas avoir à modifier quoi que ce soit dans ce fichier.
### Emplacement `noctalia settings` (Super + Z)
* Vous pouvez modifier les paramètres de Noctalia ici. Il est recommandé d'aller dans la section des modèles (templates) et d'activer les modèles de couleurs pour les applications que vous utilisez.
* Consultez également la boutique de plugins pour découvrir des plugins officiels et communautaires utiles.

## Migration depuis un autre DE/WM

Si vous avez déjà un autre DE/WM installé, vous pouvez migrer vers ces dotfiles en suivant les instructions ci-dessous.

:::note
Bien qu'il soit possible d'utiliser le même compte utilisateur avec Hyprland, il est fortement recommandé de créer un nouveau compte utilisateur (instructions incluses). De plus, même avec un nouveau compte utilisateur, il peut y avoir des conflits de démons avec votre précédent DE/WM ; il est donc préférable d'utiliser un seul environnement.
:::

Assurez-vous de remplacer les variables entre chevrons (\<\>) ci-dessous, y compris les chevrons eux-mêmes.

1. Exécutez `sudo pacman -S cachyos-hypr-noctalia`. Si vous rencontrez un conflit de paquets avec un autre paquet `-settings` (tel que `cachyos-kde-settings`), vous pouvez supprimer le paquet en conflit car ces paquets n'affectent pas les utilisateurs actuels.
1. Pour créer un nouvel utilisateur, exécutez `sudo useradd -m <new_user> -s /bin/fish`. Vous pouvez également utiliser un autre shell si vous préférez (par exemple `/bin/zsh`).
1. Exécutez `sudo passwd <new_user>` pour définir un mot de passe pour le compte.
    * Si vous voulez _vraiment_ utiliser le même compte (fortement déconseillé), copiez plutôt les dotfiles dans le dossier utilisateur avec `cp -r /etc/skel/. ~` (veillez à créer une sauvegarde ou un instantané au préalable !).
1. Installez éventuellement `noctalia-greeter` ou `sddm` comme gestionnaire d'affichage. `noctalia-greeter` s'intègre mieux à Noctalia, mais sa configuration est légèrement plus complexe.
    * Pour activer sddm comme gestionnaire d'affichage, installez-le avec `sudo pacman -Syu sddm`, puis exécutez `systemctl disable display-manager` et `systemctl enable sddm`.
    * Pour installer [Noctalia Greeter](https://github.com/noctalia-dev/noctalia-greeter), exécutez `sudo pacman -Syu noctalia-greeter` et suivez la section « Setting up greetd » du document lié. Ensuite, exécutez `systemctl disable display-manager` et `systemctl enable greetd`.
1. Redémarrez et sélectionnez la session Hyprland (UWSM) depuis votre gestionnaire d'affichage.
    * Si le shell ne se charge pas, essayez de redémarrer une nouvelle fois.
1. Connectez-vous et suivez les [Tâches post-installation](/fr/configuration/desktop_environments/hyprland/#tâches-post-installation).

## Migration des dotfiles v4 vers la V5 / Mise à jour de vos dotfiles

Si vous utilisez actuellement cachyos-hypr-noctalia avec Noctalia v4 et que vous avez effectué une mise à jour depuis la version 1.0 du paquet vers une version plus récente, ou si vous souhaitez mettre à jour vos dotfiles, suivez les instructions ci-dessous.
Consultez les journaux complets des modifications dans la note de version pour déterminer si vous devez mettre à jour vos dotfiles.
https://github.com/CachyOS/cachyos-hypr-noctalia/releases

### Mises à jour Hypr

:::note
Une fois vos raccourcis migrés de la v4 vers la v5, ils ne fonctionneront plus pour appeler les appels IPC de Noctalia.
:::

1. Installez `meld` si vous ne l'avez pas (`pacman -Q meld` pour vérifier s'il est installé).
1. Exécutez `meld /etc/skel/.config/hypr ~/.config/hypr`.
1. Dans meld, vous verrez un aperçu de tous les fichiers contenant des modifications. Les fichiers bleus comportent des modifications, tandis que les fichiers verts sont entièrement nouveaux.
    <br />
    <ImageComponent imgsrc={import('~/assets/images/v4-v5-migration/meld_overview.png')} />
1. Cliquez sur un fichier bleu pour voir les modifications à appliquer. Vous pouvez juger par vous-même de ce qu'il faut appliquer, mais si vous n'avez fait aucune modification, vous pouvez écraser l'ensemble du fichier sans risque. Cliquez sur la flèche pour appliquer les modifications et sur le x pour supprimer les anciennes lignes.
    <Aside type="note">Veillez à ne pas écraser les éléments que vous avez modifiés, tels que les paramètres de vos moniteurs.</Aside>
    <br />
    <ImageComponent imgsrc={import('~/assets/images/v4-v5-migration/merge.png')} />
1. Vous pouvez également tout fusionner d'un coup.
    <br />
    <ImageComponent imgsrc={import('~/assets/images/v4-v5-migration/merge_all_1.png')} />
    <ImageComponent imgsrc={import('~/assets/images/v4-v5-migration/merge_all_2.png')} />
1. Lorsque vous avez terminé vos modifications pour le fichier, enregistrez et quittez.
    <br />
    <ImageComponent imgsrc={import('~/assets/images/v4-v5-migration/save_exit.png')} />
1. Les nouveaux fichiers verts vous demanderont où vous souhaitez les enregistrer. Vous pouvez les enregistrer dans `~/.config/hypr/config/` avec le même nom. Il y a 4 nouveaux fichiers.
    * `defaults.lua` est désormais `variables.lua`. Vous devez déplacer manuellement vos ajouts/modifications personnalisés vers le nouveau fichier.
    * `keybinds.lua` est désormais `binds.lua`. Vous devez déplacer manuellement vos ajouts/modifications personnalisés vers le nouveau fichier.
    * `input.lua` est désormais `inputs.lua`. Vous devez déplacer manuellement vos ajouts/modifications personnalisés vers le nouveau fichier.
    * `workspaces.lua` est entièrement nouveau et peut être transféré directement sans modification.
    <br />
    <ImageComponent imgsrc={import('~/assets/images/v4-v5-migration/workspaces.png')} />

### Mises à jour Noctalia

1. Exécutez `rm -rf ~/.config/noctalia` pour supprimer les configurations actuelles. Vous pouvez également les déplacer ailleurs si vous pensez pouvoir en avoir besoin.
1. `cp -r /etc/skel/.config/noctalia ~/.config` copiera la nouvelle configuration dans votre dossier personnel.

:::note
Le seul fichier important est config.toml ; vous pouvez donc le copier individuellement au lieu de supprimer et remplacer tout le dossier lors des mises à jour du paquet si vous le souhaitez.
:::

### Autres mises à jour

D'autres fichiers peuvent comporter des mises à jour ; vous pouvez utiliser meld pour les intégrer. Consultez le journal complet des modifications de la version pour voir ce qui a pu changer d'autre.

### Suppression des paquets orphelins (migration v4->v5)

Après la mise à jour du paquet, d'anciennes dépendances deviendront orphelines ; vous pouvez les supprimer en exécutant `shelly purify -o`.

### Redémarrage

Un redémarrage devrait appliquer les modifications. Si le shell ne se charge pas, essayez de redémarrer une nouvelle fois.

## FAQ

> _« Pourquoi l'historique de mon presse-papiers ne persiste-t-il pas après un redémarrage ? »_

Vous devez configurer un gestionnaire de secrets pour que cela fonctionne correctement. Kwallet est installé par défaut, mais vous pouvez également utiliser gnome-keyring ou un autre gestionnaire de secrets. Si vous souhaitez utiliser kwallet, installez `kwalletmanager` depuis le dépôt, puis ouvrez-le et créez un nouveau portefeuille. Le plus simple est de laisser le mot de passe vide, mais vous pouvez aussi configurer le déverrouillage automatique avec votre gestionnaire d'affichage, ce qui dépasse le cadre de ce wiki ; consultez le [wiki Arch](https://wiki.archlinux.org/title/KDE_Wallet#Configuration) pour plus de détails. Après avoir configuré un portefeuille, initialisez-le dans votre fichier `autostart.lua` avec `hl.exec_cmd("kwalletd6")`.

> _« Comment empêcher satty de s'ouvrir après une capture d'écran ? »_

Vous pouvez facilement fermer satty en appuyant sur ctrl + s pour enregistrer votre capture d'écran ou ctrl + c pour la copier. Si vous ne souhaitez pas que satty s'ouvre du tout, vous pouvez configurer l'option pour copier dans le presse-papiers ou enregistrer dans un fichier dans Noctalia settings > shell > screenshot.

> _« Comment modifier la disposition de mon clavier ? »_

Modifiez `inputs.lua` et ajoutez `kb_layout`. Consultez [cette page](https://wiki.hypr.land/configuring/core/config-options/#input).

> _« Pourquoi certaines options de thème (icônes de Dolphin, certains éléments Qt, etc.) ne fonctionnent-elles pas ? »_

Le dépôt par défaut de CachyOS ne fournit que `qt6ct` (QT6 Configuration Tool). Cependant, il existe un autre outil qui fonctionne mieux pour les applications Qt de Plasma comme dolphin, gwenview, etc. Téléchargez plutôt `qt6ct-kde` depuis l'AUR et appliquez le thème Noctalia avec celui-ci. Vos applications Plasma devraient ainsi mieux suivre le thème sous Hyprland.

> _« Comment changer mon navigateur par défaut ? »_

Exécutez `xdg-settings set default-web-browser your_browser.desktop`. Vous pouvez trouver le nom du fichier `.desktop` de votre navigateur en exécutant `ls /usr/share/applications/`.
