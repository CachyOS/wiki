## Raccourcis clavier

La plupart des combinaisons de touches nécessitent l'utilisation de la touche mod, qui dans notre cas est la touche Windows (appelée SUPER), vous pouvez la modifier dans le fichier de configuration.

### Contrôle des applications

| Description | Touche |
|-------------|-----|
| Ouvrir le terminal | <Kbd linux="Super+Entrée" /> |
| Ouvrir Rofi (lanceur de programmes) | <Kbd linux="Contrôle+Espace" /> |
| Fermer la fenêtre active | <Kbd linux="Super+Q" /> |

## FAQ

### Comment puis-je créer un démarrage automatique pour un programme ? Par exemple "définir un fond d'écran au démarrage"

* i3 inclut déjà une fonctionnalité de démarrage automatique flexible qui vous permet d'exécuter n'importe quel programme ou même des commandes.

Si vous regardez à la fin de notre fichier de configuration, vous verrez des lignes commençant par `exec` et `exec_always`.

Par exemple :

```exec chromium```

Cela signifie que Chromium démarrera dans l'espace de travail 1 chaque fois que vous vous connecterez à votre session i3.

### Qu'est-ce qui différencie `exec` de `exec_always` ?

`exec_always` vous donne la possibilité de toujours exécuter une certaine action même après le rechargement d'i3wm.

* Pour plus de références et d'informations, consultez leur guide utilisateur d'i3
* https://i3wm.org/docs/userguide.html#exec

### Les touches multimédia fonctionnent-elles ?
