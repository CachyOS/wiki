## Comment installer la session X11 manquante

Après que KDE a décidé de diviser son développement en plusieurs paquets, la session X11 a été retirée de l'installation par défaut.

```sh
sudo pacman -S plasma-x11-session kwin-x11 xorg-server
```

## FAQ

### Comment puis-je obtenir le même aspect que celui montré dans les captures d'écran de KDE, nommé "Emerald" ?

- C'est une combinaison du thème Emerald et du thème d'icônes Qogir qui ne sont pas installés par défaut.
  - ```sh title='Installez les deux avec la commande suivante'
    sudo pacman -S cachyos-emerald-kde-theme-git qogir-icon-theme
    ```
  Appliquez les deux dans `Apparence - Couleurs et Thèmes`

### Pourquoi SDDM a-t-il l'air si fade et si vieux ?

- *Comme aucun thème SDDM n'est appliqué par défaut, SDDM se rabattra sur le thème classique.*
  - **Appliquez le thème Breeze comme montré dans la capture d'écran**
