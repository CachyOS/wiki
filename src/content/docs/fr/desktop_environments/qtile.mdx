## Raccourcis clavier

La plupart des combinaisons de touches nécessitent l'utilisation de la touche mod, qui dans notre cas est la touche Windows (appelée SUPER). Vous pouvez la modifier dans le fichier de configuration.
Certaines pourraient utiliser la touche mod1 (touche ALT).

### Contrôle des applications

| Description | Touche |
|-------------|-----|
| Ouvrir le terminal | <Kbd linux="Super+Entrée" /> |
| Ouvrir Rofi (lanceur de programmes) | <Kbd linux="Alt+Espace" /> |
| Ouvrir le gestionnaire de fichiers (Thunar) | <Kbd linux="Super+E" /> |
| Fermer la fenêtre active | <Kbd linux="Super+Q" /> |

## FAQ

### Pourquoi le widget de volume affiche-t-il une erreur ou est-il bloqué à 0%?

* C'est parfois dû au fait que le widget de volume de Qtile ne parvient pas à détecter votre périphérique de sortie par défaut. Vous pouvez [consulter le wiki](https://docs.qtile.org/en/latest/manual/ref/widgets.html#pulsevolume) pour plus d'informations.

### Y a-t-il un script autostart.sh?

* Oui, il se trouve dans `scripts/` à partir du dossier Qtile.

### La barre de Qtile interagit-elle avec la souris?

* Oui, par exemple, si vous faites défiler la molette sur les petits points qui représentent vos espaces de travail (Actif, Inactif, Vide, etc.), vous basculerez vers la gauche ou la droite, ou vous pourrez même cliquer sur l'un d'eux.
* Un autre exemple est la disposition (par défaut en colonnes), cliquer dessus vous permet de basculer entre les dispositions disponibles.
* En cliquant sur l'utilisation du CPU et de la RAM, Btop (moniteur système en mode texte) s'ouvrira.
* Augmenter/Baisser/Couper le son en interagissant avec le widget de volume.

Pour plus d'informations sur Qtile, veuillez [consulter leur wiki](https://docs.qtile.org/en/stable/).
