:::caution
Depuis que Hyprland a commencé sa refonte, veuillez noter qu'il n'est actuellement pas stable et que vous pourriez rencontrer des bogues ou des plantages inattendus. Utilisez-le à vos propres risques.
Même leur version « stable » est également défaillante et boguée, c'est pourquoi nous ne prévoyons pas de fournir de support en dehors de nos dotfiles. Référez-vous plutôt à leur [wiki](<https://wiki.hyprland.org/>).
:::

:::tip
Démarrez Hyprland en utilisant l'entrée non systemd, sinon il ne démarrera pas et affichera un écran noir.

Exemple : **`Hyprland`** au lieu de **`Hyprland(systemd)`**.
:::

Notre objectif principal avec notre configuration est d'avoir un Hyprland fonctionnel tout en restant simple. Par conséquent, certains outils et programmes essentiels pourraient manquer, comme un gestionnaire de fichiers avec interface graphique.

Consultez notre [FAQ Hyprland.](/fr/desktop_environments/hyprland#faq)

**Dotfiles maintenus par [msmafra](https://github.com/msmafra) et [Lysec](https://github.com/Ly-sec)**

## Raccourcis clavier

La plupart des combinaisons de touches nécessitent l'utilisation de la touche mod, qui dans notre cas est la touche Windows (référencée comme SUPER). Vous pouvez la modifier dans le fichier de configuration.

### Contrôle des applications

| Description | Touche |
|-------------|-----|
| Ouvrir le terminal | <Kbd linux="Super+Entrée" /> |
| Ouvrir Rofi (lanceur de programmes) | <Kbd linux="Super+Espace" /> |
| Ouvrir le gestionnaire de fichiers | <Kbd linux="Super+E" /> |
| Fermer la fenêtre active | <Kbd linux="Super+Q" /> |

### Navigation entre les espaces de travail

| Description | Touche |
|-------------|-----|
| Aller à l'espace de travail (1-9) | <Kbd linux="Super+1" /> à <Kbd linux="Super+9" /> |
| Espace de travail suivant | <Kbd linux="Super+." /> |
| Espace de travail précédent | <Kbd linux="Super+," /> |
| Se déplacer entre les espaces de travail avec la molette de la souris | <Kbd linux="Super+Molette" /> |

### Navigation entre les fenêtres

| Description | Touche |
|-------------|-----|
| Sélectionner la fenêtre du haut | <Kbd linux="Super+FlècheHaut" /> |
| Sélectionner la fenêtre du bas | <Kbd linux="Super+FlècheBas" /> |
| Sélectionner la fenêtre de gauche | <Kbd linux="Super+FlècheGauche" /> |
| Sélectionner la fenêtre de droite | <Kbd linux="Super+FlècheDroite" /> |
| Changer de groupe actif | <Kbd linux="Super+Tab" /> |

### Gestion des fenêtres

| Description | Touche |
|-------------|-----|
| Déplacer la fenêtre vers l'espace de travail (1-9) sans y basculer | <Kbd linux="Super+Maj+1" /> à <Kbd linux="Super+Maj+9" /> |
| Déplacer la fenêtre vers l'espace de travail (1-9) et y basculer | <Kbd linux="Super+Ctrl+1" /> à <Kbd linux="Super+Ctrl+9" /> |
| Déplacer la fenêtre vers le haut | <Kbd linux="Super+Maj+FlècheHaut" /> |
| Déplacer la fenêtre vers le bas | <Kbd linux="Super+Maj+FlècheBas" /> |
| Déplacer la fenêtre vers la gauche | <Kbd linux="Super+Maj+FlècheGauche" /> |
| Déplacer la fenêtre vers la droite | <Kbd linux="Super+Maj+FlècheDroite" /> |
| Mettre la fenêtre en plein écran | <Kbd linux="Super+F" /> |
| Basculer la fenêtre en mode flottant | <Kbd linux="Super+V" /> |
| Épingler la fenêtre sur tous les espaces de travail (flottante) | <Kbd linux="Super+Y" /> |
| Basculer la fenêtre dans un groupe | <Kbd linux="Super+K" /> |

| Description | Touche |

## FAQ

### Pourquoi mon Discord, Thunar et Nautilus ont-ils un arrière-plan étrange ?

C'est parce que l'opacité de la fenêtre a été modifiée.

* Envisagez de modifier la règle de fenêtre dans le fichier de configuration de [Hyprland](https://github.com/CachyOS/cachyos-hyprland-settings/blob/master/etc/skel/.config/hypr/config/windowrules.conf#L21).

```sh title='Exemple'
windowrulev2 = opacity 0.92, class:^(thunar|nemo)$
```

### Y a-t-il un gestionnaire de fichiers inclus ?

* Non, installez celui que vous préférez.
