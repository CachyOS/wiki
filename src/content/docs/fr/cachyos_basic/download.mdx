## Sources officielles de l'ISO

L'ISO de CachyOS peut être obtenue depuis les sources suivantes :

*   [Site Web](<https://cachyos.org/download>)
*   [SourceForge](<https://sourceforge.net/projects/cachyos-arch/files/>)
*   [Miroir CachyOS](<https://mirror.cachyos.org/ISO/>)

## Vérification de l'intégrité de l'ISO avec SHA256

:::caution[AVERTISSEMENT]
Prenez toujours la précaution de vérifier l'intégrité de l'ISO pour éviter tout problème non désiré lors de l'installation ou de la création d'un support de démarrage.
:::

**Version actuelle de l'ISO :** `260809`

**Hash SHA256 :** `959f6577f45e25ee9fd8c220fd221b08e4ea79412c7315c0f922dd6d86d5e33c`

<Tabs>

<TabItem label='Windows'>

<Steps>

1. Téléchargez le [fichier](https://mirror.cachyos.org/ISO/desktop/260809/cachyos-desktop-linux-260809.iso.sha256) contenant le hash SHA256 **(Ouvrez-le avec un éditeur de texte, par ex. le Bloc-notes).**
2. Ouvrez CMD ou PowerShell en tant qu'administrateur et [naviguez](<https://www.wikihow.com/Change-Directories-in-Command-Prompt>) jusqu'au chemin où sont stockés les fichiers ISO et SHA256.
3. Exécutez la commande suivante :
   ```powershell
   # Exemple :
   certUtil -hashfile cachyos-desktop-linux-260809.iso SHA256
   ```
4. Comparez le hash retourné par certUtil avec celui du fichier téléchargé à l'**Étape 1**. S'ils correspondent, vous pouvez procéder à l'installation de CachyOS.

</Steps>

</TabItem>

<TabItem label='Linux'>

<Steps>

1. Téléchargez le [fichier](https://mirror.cachyos.org/ISO/desktop/260809/cachyos-desktop-linux-260809.iso.sha256) contenant le hash SHA256.
2. Ouvrez un terminal et naviguez vers le répertoire contenant à la fois le fichier `.sha256` et le fichier `.iso`.
3. Exécutez les commandes suivantes :
   ```sh
   # Exemple :
   cd ~/Downloads
   sha256sum -c cachyos-desktop-linux-260809.iso.sha256
   # cachyos-desktop-linux-260809.iso: OK
   ```
4. Si le résultat de l'**Étape 3** est `OK`, vous pouvez procéder à l'installation de CachyOS.

</Steps>

</TabItem>

<TabItem label='macOS'>

<Steps>

1. Téléchargez le [fichier](https://mirror.cachyos.org/ISO/desktop/260809/cachyos-desktop-linux-260809.iso.sha256) contenant le hash SHA256.
2. Ouvrez un terminal, naviguez vers le répertoire contenant le fichier `.sha256` et exécutez les commandes suivantes :
   ```sh
   # Exemple :
   cd Downloads/
   cat cachyos-desktop-linux-260809.iso.sha256
   # 959f6577f45e25ee9fd8c220fd221b08e4ea79412c7315c0f922dd6d86d5e33c
   ```
3. Comparez la sortie de l'**Étape 2** avec le hash du fichier ISO :
   ```sh
   # Exemple :
   shasum -a 256 cachyos-desktop-linux-260809.iso
   ```
4. Si les hashes de l'**Étape 2** et de l'**Étape 3** correspondent, vous pouvez procéder à l'installation de CachyOS.

</Steps>

</TabItem>

## Vérifier l'authenticité de l'image ISO (Linux)

Pour vérifier l'authenticité du fichier ISO :

<Steps>

1. Importez la clé GPG comme référence pour la comparaison :

   ```shell
   gpg --keyserver hkps://keys.openpgp.org --recv-key F3B607488DB35A47
   ```

2. Téléchargez le fichier ISO et son fichier de signature [.sig](https://cdn77.cachyos.org/ISO/desktop/260809/cachyos-desktop-linux-260809.iso.sig) puis exécutez la commande suivante (en remplaçant `full_iso_name.iso` par le nom réel du fichier ISO) :
   ```shell
   gpg --verify full_iso_name.iso.sig full_iso_name.iso
   ```

   Si vous obtenez une sortie **Bonne signature**, le fichier ISO est authentique :
   ```
   gpg: Signature made dom 09 ago 2026 13:30:06 -03
   gpg:                avec la clef RSA 882DCFE48E2051D48E2562ABF3B607488DB35A47
   gpg: Bonne signature de « CachyOS <admin@cachyos.org> » [inconnue]
   gpg: ATTENTION : cette clef n'est pas certifiée avec une signature de confiance.
   gpg:             Rien n'indique que la signature appartient à son propriétaire.
   Empreinte de la clef principale : 882D CFE4 8E20 51D4 8E25  62AB F3B6 0748 8DB3 5A47
   ```

</Steps>

:::danger
Si la sortie ne contient pas la chaîne **Bonne signature** ou si l'ID de la clé ne correspond pas, n'utilisez pas l'image ISO. Une mauvaise signature indique que l'ISO a été altérée ou corrompue.

Assurez-vous que l'image téléchargée provient d'une [source CachyOS légitime](/fr/cachyos_basic/download#sources-officielles-de-liso).
:::
