## Sources ISO Officielles

L'ISO de CachyOS peut être obtenue à partir des sources suivantes :

*   [Site Web](<https://cachyos.org/download>)
*   [SourceForge](<https://sourceforge.net/projects/cachyos-arch/files/>)
*   [Miroir CachyOS](<https://mirror.cachyos.org/ISO/>)

## Vérification de l’intégrité de l’ISO avec SHA256

:::caution[AVERTISSEMENT]
Prenez toujours le temps de vérifier l’intégrité de l’image ISO pour éviter tout problème lors de l’installation ou de la création d’un support amorçable.
:::

**Version actuelle de l’ISO :** `251129`

**Hash SHA256 :** `2ab25f72ce8fece890b440cf9e260fc3d57ae4f5fb5308086f670240de02da7b`

<Tabs>

<TabItem label='Windows'>

<Steps>

1. Téléchargez le [fichier](https://mirror.cachyos.org/ISO/desktop/251129/cachyos-desktop-linux-251129.iso.sha256) contenant l’empreinte SHA256 **(Ouvrez-le avec un éditeur de texte, par ex. Bloc-notes).**
2. Ouvrez CMD ou PowerShell en tant qu’administrateur et [naviguez](<https://www.wikihow.com/Change-Directories-in-Command-Prompt>) jusqu’au dossier où se trouvent les fichiers ISO et SHA256.
3. Exécutez la commande suivante :
   ```powershell
   # Exemple :
   certUtil -hashfile cachyos-desktop-linux-251129.iso SHA256
   ```
4. Comparez le résultat du hachage obtenu avec la sortie de  **l’étape 1**. Si les deux correspondent, vous pouvez poursuivre l’installation de CachyOS.

</Steps>

</TabItem>

<TabItem label='Linux'>

<Steps>

1. Téléchargez le [fichier](https://mirror.cachyos.org/ISO/desktop/251129/cachyos-desktop-linux-251129.iso.sha256) comprenant l'empreinte SHA256.
2. Ouvrez un terminal, accédez au répertoire contenant le fichier `.sha256` puis exécutez les commandes suivantes :
   ```sh
   # Exemple:
   cd Downloads/
   cat cachyos-desktop-linux-251129.iso.sha256
   # 2ab25f72ce8fece890b440cf9e260fc3d57ae4f5fb5308086f670240de02da7b
   ```
3. Comparez le résultat de **l'Etape 2** puis exécutez la commande suivante pour vérifier le hachage du fichier ISO :
   ```sh
   # Exemple:
   sha256sum cachyos-desktop-linux-251129.iso
   ```
4. Si les empreintes de **l'Etape 2** et de **l'Etape 3** correspondent, vous pouvez poursuivre l'installation de CachyOS.

</Steps>

</TabItem>

## Vérifier l’authenticité de l’image ISO (Linux)

Pour vérifier l’authenticité du fichier ISO et s’assurer qu’il s’agit bien de la version officielle publiée par l’équipe de développement CachyOS :

<Steps>

1. Importez la clé GPG permettant de vérifier l’authenticité :

   ```shell
   gpg --keyserver hkps://keys.openpgp.org --recv-key F3B607488DB35A47
   ```

2. Téléchargez le fichier ISO et son fichier de signature [.sig](https://cdn77.cachyos.org/ISO/desktop/251129/cachyos-desktop-linux-251129.iso.sig) uis exécutez la commande suivante (en remplaçant`nom_iso_complet.iso` ar le nom exact de votre ISO) :
   ```shell
   gpg --verify nom_iso_complet.iso.sig nom_iso_complet.iso
   ```

   Si la sortie affiche **Good signature**, le fichier ISO est authentique :
   ```
   gpg: Signature made sáb 29 nov 2025 13:10:22 -03
   gpg:                using RSA key 882DCFE48E2051D48E2562ABF3B607488DB35A47
   gpg: Good signature from "CachyOS <admin@cachyos.org>" [unknown]
   gpg: WARNING: This key is not certified with a trusted signature!
   gpg:          There is no indication that the signature belongs to the owner.
   Primary key fingerprint: 882D CFE4 8E20 51D4 8E25  62AB F3B6 0748 8DB3 5A47
   ```

</Steps>

:::danger
Si la sortie n'affiche pas **Good signature** ou si l’identifiant de clé ne correspond pas, n’utilisez pas l’image ISO. 
Assurez-vous que l’image téléchargée provient d’une source officielle de CachyOS, car une mauvaise signature pourrait indiquer que l’ISO a été altérée.
:::
