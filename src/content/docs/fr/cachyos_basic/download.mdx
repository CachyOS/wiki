## Télécharger l'ISO

L'ISO de CachyOS peut être obtenue depuis les sources suivantes :

*   [Site Web](https://cachyos.org/download)
*   [SourceForge](https://sourceforge.net/projects/cachyos-arch/files/)
*   [Miroir CachyOS](https://mirror.cachyos.org/ISO/)

## Vérifier l'intégrité de l'ISO avec SHA256

:::caution[AVERTISSEMENT]
Prenez toujours la précaution de vérifier l'intégrité de l'ISO pour éviter tout problème indésirable lors de l'installation ou de la création d'un support de démarrage.
:::

**Version actuelle de l'ISO :** `250713`

**Hachage SHA256 :** `22a1e3386a1a25c433f1b9dd5272062856d8311ee637900c5017df7fa40bf627`

<Tabs>

<TabItem label='Windows'>

<Steps>

1. Téléchargez le [fichier](https://mirror.cachyos.org/ISO/desktop/250713/cachyos-desktop-linux-250713.iso.sha256) contenant le hachage SHA256 **(Ouvrez-le avec un éditeur de texte, par exemple le Bloc-notes).**
2. Ouvrez CMD ou PowerShell en tant qu'administrateur et [naviguez](https://www.wikihow.com/Change-Directories-in-Command-Prompt) jusqu'au répertoire où les fichiers ISO et SHA256 sont stockés.
3. Exécutez la commande suivante :
   ```powershell
   # Exemple :
   certUtil -hashfile cachyos-desktop-linux-250713.iso SHA256
   ```
4. Comparez le hachage retourné par certUtil avec celui du fichier téléchargé à l'**étape 1**. S'ils correspondent, vous pouvez procéder à l'installation de CachyOS.

</Steps>

</TabItem>

<TabItem label='Linux'>

<Steps>

1. Téléchargez le [fichier](https://mirror.cachyos.org/ISO/desktop/250713/cachyos-desktop-linux-250713.iso.sha256) contenant le hachage SHA256.
2. Ouvrez un terminal, naviguez jusqu'au répertoire contenant le fichier `.sha256`, et exécutez les commandes suivantes :
   ```sh
   # Exemple :
   cd Téléchargements/ || exit
   cat cachyos-desktop-linux-250713.iso.sha256
   # 22a1e3386a1a25c433f1b9dd5272062856d8311ee637900c5017df7fa40bf627
   ```
3. Comparez la sortie de l'**étape 2** et exécutez la commande suivante pour vérifier le hachage du fichier ISO :
   ```sh
   # Exemple :
   sha256sum cachyos-desktop-linux-250713.iso
   ```
4. Si les hachages de l'**étape 2** et de l'**étape 3** correspondent, vous pouvez procéder à l'installation de CachyOS.

</Steps>

</TabItem>

## Vérifier l'authenticité de l'image ISO (Linux)

Pour vérifier l'authenticité du fichier ISO et vous assurer qu'il s'agit bien de la version officielle publiée par l'équipe de développement de CachyOS :

<Steps>

1. Importez la clé GPG pour vérifier l'authenticité :

   ```shell
   gpg --keyserver hkps://keys.openpgp.org --recv-key F3B607488DB35A47
   ```

2. Téléchargez le fichier ISO et son fichier de signature `.sig`, puis exécutez la commande suivante (en remplaçant `nom_complet_de_l_iso.iso` par le nom réel du fichier ISO) :
   ```shell
   gpg --verify nom_complet_de_l_iso.iso.sig nom_complet_de_l_iso.iso
   ```

   Si vous obtenez une sortie **Good signature**, le fichier ISO est authentique :
   ```
   gpg: Signature made Mo 01 Apr 2024 14:13:30 CEST
   gpg:                using RSA key 882DCFE48E2051D48E2562ABF3B607488DB35A47
   gpg: Good signature from "CachyOS <admin@cachyos.org>" [unknown]
   gpg: WARNING: This key is not certified with a trusted signature!
   gpg:          There is no indication that the signature belongs to the owner.
   Primary key fingerprint: 882D CFE4 8E20 51D4 8E25  62AB F3B6 0748 8DB3 5A47
   ```

</Steps>

:::danger
Si la sortie n'indique pas **Good signature** ou si l'ID de la clé ne correspond pas, n'utilisez pas l'image ISO. Assurez-vous que l'image téléchargée provient
d'une source CachyOS légitime, car une mauvaise signature pourrait suggérer que l'ISO a été altérée.
:::
