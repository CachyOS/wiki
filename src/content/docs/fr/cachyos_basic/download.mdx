## Sources officielles de l'ISO

L'ISO de CachyOS peut être obtenue depuis les sources suivantes :

*   [Site Web](<https://cachyos.org/download>)
*   [SourceForge](<https://sourceforge.net/projects/cachyos-arch/files/>)
*   [Miroir CachyOS](<https://mirror.cachyos.org/ISO/>)

## Vérification de l'intégrité de l'ISO avec SHA256

:::caution[AVERTISSEMENT]
Prenez toujours la précaution de vérifier l'intégrité de l'ISO pour éviter tout problème non désiré lors de l'installation ou de la création d'un support de démarrage.
:::

**Version actuelle de l'ISO :** `260308`

**Hash SHA256 :** `69f1ffbded158d4d95e6567e994b1813d0d040d323742aef9f489a0b71ad1d29`

<Tabs>

<TabItem label='Windows'>

<Steps>

1. Téléchargez le [fichier](https://mirror.cachyos.org/ISO/desktop/260308/cachyos-desktop-linux-260308.iso.sha256) contenant le hash SHA256 **(Ouvrez-le avec un éditeur de texte, par ex. le Bloc-notes).**
2. Ouvrez CMD ou PowerShell en tant qu'administrateur et [naviguez](<https://www.wikihow.com/Change-Directories-in-Command-Prompt>) jusqu'au chemin où sont stockés les fichiers ISO et SHA256.
3. Exécutez la commande suivante :
   ```powershell
   # Exemple :
   certUtil -hashfile cachyos-desktop-linux-260308.iso SHA256
   ```
4. Comparez le hash retourné par certUtil avec celui du fichier téléchargé à l'**Étape 1**. S'ils correspondent, vous pouvez procéder à l'installation de CachyOS.

</Steps>

</TabItem>

<TabItem label='Linux'>

<Steps>

1. Téléchargez le [fichier](https://mirror.cachyos.org/ISO/desktop/260308/cachyos-desktop-linux-260308.iso.sha256) contenant le hash SHA256.
2. Ouvrez un terminal, naviguez vers le répertoire contenant le fichier `.sha256` et exécutez les commandes suivantes :
   ```sh
   # Exemple :
   cd Téléchargements/
   cat cachyos-desktop-linux-260308.iso.sha256
   # 69f1ffbded158d4d95e6567e994b1813d0d040d323742aef9f489a0b71ad1d29
   ```
3. Comparez la sortie de l'**Étape 2** et exécutez la commande suivante pour vérifier le hash du fichier ISO :
   ```sh
   # Exemple :
   sha256sum cachyos-desktop-linux-260308.iso
   ```
4. Si les hashes de l'**Étape 2** et de l'**Étape 3** correspondent, vous pouvez procéder à l'installation de CachyOS.

</Steps>

</TabItem>

## Vérifier l'authenticité de l'image ISO (Linux)

Pour vérifier l'authenticité du fichier ISO et vous assurer qu'il s'agit bien de la version officielle publiée par l'équipe de développement de CachyOS :

<Steps>

1. Importez la clé GPG pour la vérification de l'authenticité :

   ```shell
   gpg --keyserver hkps://keys.openpgp.org --recv-key F3B607488DB35A47
   ```

2. Téléchargez le fichier ISO et son fichier de signature [.sig](https://cdn77.cachyos.org/ISO/desktop/260308/cachyos-desktop-linux-260308.iso.sig) puis exécutez la commande suivante (en remplaçant `nom_complet_de_l_iso.iso` par le nom réel du fichier ISO) :
   ```shell
   gpg --verify nom_complet_de_l_iso.iso.sig nom_complet_de_l_iso.iso
   ```

   Si vous obtenez une sortie **Bonne signature**, le fichier ISO est authentique :
   ```
   gpg: Signature made dom 08 mar 2026 10:39:18 -03
   gpg:                avec la clef RSA 882DCFE48E2051D48E2562ABF3B607488DB35A47
   gpg: Bonne signature de « CachyOS <admin@cachyos.org> » [inconnue]
   gpg: ATTENTION : cette clef n'est pas certifiée avec une signature de confiance.
   gpg:             Rien n'indique que la signature appartient à son propriétaire.
   Empreinte de la clef principale : 882D CFE4 8E20 51D4 8E25  62AB F3B6 0748 8DB3 5A47
   ```

</Steps>

:::danger
Si la sortie ne contient pas la chaîne **Bonne signature** ou si l'ID de la clé ne correspond pas, n'utilisez pas l'image ISO. Assurez-vous que l'image téléchargée provient
d'une source CachyOS légitime, car une mauvaise signature pourrait suggérer que l'ISO a été altérée.
:::
