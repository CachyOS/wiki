:::caution
Jelikož Hyprland zahájil své přepracování, mějte na paměti, že v současné době není stabilní a můžete se setkat s chybami/neočekávanými pády. Používejte na vlastní nebezpečí.
Dokonce i jejich "stabilní" verze je také rozbitá a plná chyb, proto neplánujeme poskytovat podporu mimo naše dotfiles. Místo toho se obraťte na jejich [wiki](<https://wiki.hyprland.org/>).
:::

:::tip
Spusťte Hyprland pomocí položky bez systemd, jinak se nespustí a zobrazí se černá obrazovka.

Příklad: **`Hyprland`** namísto **`Hyprland(systemd)`**.
:::

Naším hlavním cílem s naším nastavením je mít funkční Hyprland, ale zároveň ho udržet jednoduchý, proto mohou chybět některé základní nástroje a programy, jako je například grafický správce souborů.

Podívejte se na naše [Časté dotazy pro Hyprland](/desktop_environments/hyprland#faq).

**Dotfiles spravují [msmafra](https://github.com/msmafra) a [Lysec](https://github.com/Ly-sec)**

## Klávesové zkratky

Většina klávesových kombinací vyžaduje použití modifikační klávesy, což je v našem případě klávesa Windows (označovaná jako SUPER), můžete ji změnit v konfiguračním souboru.

### Ovládání aplikací

| Popis | Klávesa |
|-------------|-----|
| Otevřít terminál | <Kbd linux="Super+Return" /> |
| Otevřít Rofi (spouštěč programů) | <Kbd linux="Super+Space" /> |
| Otevřít správce souborů | <Kbd linux="Super+E" /> |
| Zavřít aktivní okno | <Kbd linux="Super+Q" /> |

### Navigace mezi pracovními plochami

| Popis | Klávesa |
|-------------|-----|
| Přejít na pracovní plochu (1-9) | <Kbd linux="Super+1" /> až <Kbd linux="Super+9" /> |
| Další pracovní plocha | <Kbd linux="Super+Period" /> |
| Předchozí pracovní plocha | <Kbd linux="Super+Comma" /> |
| Přecházet mezi pracovními plochami kolečkem myši | <Kbd linux="Super+Scroll" /> |

### Navigace mezi okny

| Popis | Klávesa |
|-------------|-----|
| Zaměřit okno nahoru | <Kbd linux="Super+ArrowUp" /> |
| Zaměřit okno dolů | <Kbd linux="Super+ArrowDown" /> |
| Zaměřit okno doleva | <Kbd linux="Super+ArrowLeft" /> |
| Zaměřit okno doprava | <Kbd linux="Super+ArrowRight" /> |
| Změnit aktivní skupinu | <Kbd linux="Super+Tab" /> |

### Správa oken

| Popis | Klávesa |
|-------------|-----|
| Přesunout okno na pracovní plochu (1-9) bez přepnutí | <Kbd linux="Super+Shift+1" /> až <Kbd linux="Super+Shift+9" /> |
| Přesunout okno na pracovní plochu (1-9) a přepnout na ni | <Kbd linux="Super+Control+1" /> až <Kbd linux="Super+Control+9" /> |
| Přesunout okno nahoru | <Kbd linux="Super+Shift+ArrowUp" /> |
| Přesunout okno dolů | <Kbd linux="Super+Shift+ArrowDown" /> |
| Přesunout okno doleva | <Kbd linux="Super+Shift+ArrowLeft" /> |
| Přesunout okno doprava | <Kbd linux="Super+Shift+ArrowRight" /> |
| Přepnout okno na celou obrazovku | <Kbd linux="Super+F" /> |
| Přepnout okno do plovoucího režimu | <Kbd linux="Super+V" /> |
| Připnout okno na všechny pracovní plochy (plovoucí) | <Kbd linux="Super+Y" /> |
| Přepnout okno do skupiny | <Kbd linux="Super+K" /> |

### Změna velikosti oken

| Popis | Klávesa |
|-------------|-----|
| Vstoupit do režimu změny velikosti (použijte H,J,K,L nebo šipky, Escape pro ukončení) | <Kbd linux="Super+R" /> |
| Zmenšit okno dolů | <Kbd linux="Super+Control+Shift+J" /> nebo <Kbd linux="Super+Control+Shift+ArrowDown" /> |
| Zvětšit okno nahoru | <Kbd linux="Super+Control+Shift+K" /> nebo <Kbd linux="Super+Control+Shift+ArrowUp" /> |
| Zmenšit okno doleva | <Kbd linux="Super+Control+Shift+H" /> nebo <Kbd linux="Super+Control+Shift+ArrowLeft" /> |
| Zvětšit okno doprava | <Kbd linux="Super+Control+Shift+L" /> nebo <Kbd linux="Super+Control+Shift+ArrowRight" /> |

### Ovládání myší

| Popis | Klávesa |
|-------------|-----|
| Přesunout okno myší | <Kbd linux="Super+LeftClick" /> |
| Měnit velikost okna myší | <Kbd linux="Super+RightClick" /> |

### Ovládání systému

| Popis | Klávesa |
|-------------|-----|
| Pořídit snímek obrazovky | <Kbd linux="Super+A" /> |

| Popis | Klávesa |
|-------------|-----|

## Časté dotazy (FAQ)

### Proč mají mé aplikace Discord, Thunar a Nautilus podivné pozadí?

Je to proto, že okno má upravenou průhlednost.

* Zvažte úpravu pravidla pro okno v konfiguračním souboru [Hyprland](https://github.com/CachyOS/cachyos-hyprland-settings/blob/master/etc/skel/.config/hypr/config/windowrules.conf#L21).

```sh title='Příklad'
windowrulev2 = opacity 0.92, class:^(thunar|nemo)$
```

### Je zahrnut správce souborů?

* Ne, nainstalujte si takový, který se vám líbí.
