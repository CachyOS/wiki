## Oficiální zdroje ISO

Obraz ISO CachyOS lze získat z následujících zdrojů:

*   [Webová stránka](<https://cachyos.org/download>)
*   [SourceForge](<https://sourceforge.net/projects/cachyos-arch/files/>)
*   [CachyOS Mirror](<https://mirror.cachyos.org/ISO/>)

## Ověření integrity ISO pomocí SHA256

:::caution
Vždy proveďte krok navíc k ověření integrity ISO, abyste předešli nežádoucím problémům při instalaci nebo při vytváření spouštěcího média.
:::

**Aktuální verze ISO:** `260809`

**SHA256 Hash:** `959f6577f45e25ee9fd8c220fd221b08e4ea79412c7315c0f922dd6d86d5e33c`

<Tabs>

<TabItem label='Windows'>

<Steps>

1. Stáhněte [soubor](https://mirror.cachyos.org/ISO/desktop/260809/cachyos-desktop-linux-260809.iso.sha256) obsahující SHA256 hash **(Otevřete jej v textovém editoru, např. Poznámkový blok)**.
2. Otevřete CMD nebo PowerShell jako správce a [přejděte](<https://www.wikihow.com/Change-Directories-in-Command-Prompt>) do cesty, kde jsou uloženy soubory ISO a SHA256.
3. Spusťte následující příkaz:
   ```powershell
   # Příklad:
   certUtil -hashfile cachyos-desktop-linux-260809.iso SHA256
   ```
4. Porovnejte výstup hashe z certUtil s hashem ze staženého souboru v **kroku 1**. Pokud se shodují, můžete pokračovat v instalaci CachyOS.

</Steps>

</TabItem>

<TabItem label='Linux'>

<Steps>

1. Stáhněte [soubor](https://mirror.cachyos.org/ISO/desktop/260809/cachyos-desktop-linux-260809.iso.sha256) obsahující SHA256 hash.
2. Otevřete terminál a přejděte do adresáře obsahujícího jak soubor `.sha256`, tak soubor `.iso`.
3. Spusťte následující příkazy:
   ```sh
   # Příklad:
   cd ~/Downloads
   sha256sum -c cachyos-desktop-linux-260809.iso.sha256
   # cachyos-desktop-linux-260809.iso: OK
   ```
4. Pokud je výstup z **kroku 3** OK, můžete pokračovat v instalaci CachyOS.

</Steps>

</TabItem>

<TabItem label='macOS'>

<Steps>

1. Stáhněte [soubor](https://mirror.cachyos.org/ISO/desktop/260809/cachyos-desktop-linux-260809.iso.sha256) obsahující SHA256 hash.
2. Otevřete terminál, přejděte do adresáře obsahujícího soubor `.sha256` a spusťte následující příkazy:
   ```sh
   # Příklad:
   cd Downloads/
   cat cachyos-desktop-linux-260809.iso.sha256
   # 959f6577f45e25ee9fd8c220fd221b08e4ea79412c7315c0f922dd6d86d5e33c
   ```
3. Porovnejte výstup z **kroku 2** s hashem souboru ISO:
   ```sh
   # Příklad:
   shasum -a 256 cachyos-desktop-linux-260809.iso
   ```
4. Pokud se hashe z **kroku 2** a **kroku 3** shodují, můžete pokračovat v instalaci CachyOS.

</Steps>

</TabItem>

</Tabs>

## Ověření pravosti obrazu ISO (Linux)

Pro ověření pravosti souboru ISO:

<Steps>

1. Importujte GPG klíč jako referenci pro porovnání:

   ```shell
   gpg --keyserver hkps://keys.openpgp.org --recv-key F3B607488DB35A47
   ```

2. Stáhněte soubor ISO a jeho soubor podpisu [.sig](https://cdn77.cachyos.org/ISO/desktop/260809/cachyos-desktop-linux-260809.iso.sig) a spusťte následující příkaz (nahraďte `full_iso_name.iso` skutečným názvem souboru ISO):
   ```shell
   gpg --verify full_iso_name.iso.sig full_iso_name.iso
   ```

   Pokud obdržíte výstup **Good signature**, soubor ISO je pravý:
   ```
   gpg: Signature made dom 09 ago 2026 13:30:06 -03
   gpg:                using RSA key 882DCFE48E2051D48E2562ABF3B607488DB35A47
   gpg: Good signature from "CachyOS <admin@cachyos.org>" [unknown]
   gpg: WARNING: This key is not certified with a trusted signature!
   gpg:          There is no indication that the signature belongs to the owner.
   Primary key fingerprint: 882D CFE4 8E20 51D4 8E25  62AB F3B6 0748 8DB3 5A47
   ```

</Steps>

:::danger
Pokud výstup nevrátí řetězec **Good signature** nebo se ID klíče neshoduje, obraz ISO nepoužívejte. Špatný podpis naznačuje, že s obrazem ISO bylo manipulováno nebo že byl poškozen.

Ujistěte se, že stažený obraz pochází z [legitimního zdroje CachyOS](/cs/cachyos_basic/download#oficiální-zdroje-iso).
:::
