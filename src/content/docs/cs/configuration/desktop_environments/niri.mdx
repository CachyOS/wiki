:::note
Niri je waylandový kompozitor s posuvným dlaždicováním (scrollable-tiling), který nabízí jedinečný přístup ke správě oken pomocí systému rozvržení založeného na sloupcích.
:::

Naším hlavním cílem je mít funkční konfiguraci Niri, která poskytuje plynulé a intuitivní prostředí pracovní plochy a zároveň zachovává jednoduchou a přehlednou konfiguraci.

Podívejte se do našeho [Niri FAQ.](/cs/configuration/desktop_environments/niri#faq)

**Konfigurační soubory spravuje [Ly-sec](https://github.com/Ly-sec)**
V případě problémů souvisejících s Noctalií nahlédněte do [dokumentace Noctalia](https://docs.noctalia.dev/).

## Klávesové zkratky

Většina klávesových kombinací vyžaduje použití modifikační klávesy, kterou je v našem případě klávesa Windows (označovaná jako SUPER); změnit ji můžete v konfiguračním souboru.

## FAQ

### Čím se Niri liší od ostatních správců oken?

Niri využívá jedinečný přístup posuvného dlaždicování (scrollable-tiling), kde jsou okna uspořádána ve sloupcích, které lze vodorovně posouvat. To vytváří metaforu nekonečné pracovní plochy, což je obzvláště užitečné pro širokoúhlé monitory a pracovní postupy vyžadující mnoho otevřených aplikací.

### Jak změním rozložení klávesnice?

Upravte sekci `input` ve svém konfiguračním souboru:

```txt title='Příklad'
input {
    keyboard {
        xkb {
            layout "us" // Změňte z "de" na své preferované rozložení
        }
    }
}
```

### Mohu si upravit mezery a vzhled oken?

Ano, můžete upravit sekci `layout`:

```txt title='Příklad'
layout {
    gaps 8 // Změna velikosti mezer

    focus-ring {
        width 2
        active-color "#your-color"
        inactive-color "#your-color"
    }
}
```

### Jak přidám další aplikace spouštěné při startu?

Přidejte je do sekce spouštění při startu:

```txt title='Příklad'
spawn-at-startup "your-application"
```

### K čemu slouží klávesa nouzového úniku?

Zkratka `Super+Escape` je navržena k obnovení ovládání v případě, kdy celoobrazovková aplikace blokuje vaše klávesové zkratky. Vypne jakýkoli aktivní blokátor klávesových zkratek (keyboard shortcut inhibitor).

### Jak nastavím více monitorů?

Odkomentujte a upravte sekci `output` pro vaše konkrétní displeje. Správné názvy výstupů získáte spuštěním `niri msg outputs`:

```txt title='Příklad'
output "DP-1" {
    mode "1920x1080@60.000"
    scale 1
}
```
