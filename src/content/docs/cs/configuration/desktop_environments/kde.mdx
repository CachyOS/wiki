## Jak nainstalovat chybějící relaci X11

Poté, co se projekt KDE rozhodl rozdělit svůj vývoj do více balíčků, byla relace X11 odstraněna z výchozí instalace.

```sh
sudo pacman -S plasma-x11-session kwin-x11
```
Po dokončení se X11 zobrazí jako možnost na přihlašovací obrazovce.

## Jak nainstalovat chybějící xorg-server
Od verze 26.01 instalátoru CachyOS již není `xorg-server` nainstalován a ani `plasma-x11-session`, ani `kwin-x11` nevyžadují `xorg-server` jako závislost. Pokud tedy Xorg server a související komponenty nenainstalujete ručně, zobrazí se při přihlášení černá obrazovka.

```sh
sudo pacman -S xorg-server
```

## Časté dotazy

### Jak mohu dosáhnout stejného vzhledu, jaký je zobrazen na snímcích obrazovky KDE a je pojmenovaný jako „Emerald“?

- Jde o kombinaci motivu Emerald a motivu ikon Qogir, které nejsou ve výchozím nastavení nainstalovány.
  - ```sh title='Nainstalujte oba pomocí následujícího příkazu'
    sudo pacman -S cachyos-emerald-kde-theme-git qogir-icon-theme
    ```
  Oba aplikujte v `Vzhled a styl - Barvy a motivy`
