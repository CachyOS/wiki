Tento průvodce popisuje povolení hardwarové akcelerace v prohlížečích založených na Chromiu v CachyOS. Tím se úlohy spojené s videem a grafikou přesunou na vaši GPU, což zlepší výkon.

## Předpoklady

**Požadováno:**
* **Prohlížeč založený na Chromiu:** (např. Chrome, Brave, Ungoogled Chromium, Edge)
* **Ovladače/API pro GPU:** Aktuální ovladače Mesa (AMD/Intel) nebo NVIDIA s nakonfigurovaným Vulkanem / VA-API / VDPAU.

**Volitelné:**

* **amdgpu_top:** Nainstalujte `amdgpu_top` z repozitáře pomocí správce balíčků, pokud chcete sledovat aktivitu AMD GPU z terminálu.
* **nvtop:** (Pouze pro GPU Intel) Nainstalujte `nvtop` (Lunar Lake) a `intel-gpu-tools` (před Lunar Lake) pomocí správce balíčků Shelly, pokud chcete sledovat aktivitu GPU Intel z terminálu.

## Příspěvek

Tento průvodce je rozšiřitelný. Pokud máte funkční nastavení hardwarové akcelerace pro konkrétní GPU a prohlížeč založený na Chromiu, přispějte přidáním nové sekce pod „Konfigurace GPU a prohlížečů“. Uveďte:

* **Název prohlížeče**
* **Model GPU**
* **Příznaky:** Obsah souboru `~/.config/[prohlížeč]-flags.conf`.
* **Cesta k souboru:** Plná cesta k souboru s příznaky.
* **Poznámky (volitelné):** Klíčové ovladače, balíčky nebo specifika nastavení.

Obsah příznaků (pro soubor `.conf` nebo řádek `Exec=`):

```bash

# U souborů .desktop jsou příznaky odděleny mezerou za spustitelným souborem.
```

**Poznámky (volitelné):**

* Požadované ovladače (např. `nvidia-dkms`, `intel-media-driver`).

* Specifické úvahy o nastavení nebo pokyny k úpravě souboru `.desktop`.


### Kroky nastavení

<Steps>

1. Identifikujte soubor s příznaky: Najděte cestu k souboru s příznaky vašeho prohlížeče v sekci „Konfigurace GPU a prohlížečů“.
2. Upravte soubor s příznaky: Otevřete/vytvořte soubor pomocí `nano` (nebo vašeho preferovaného textového editoru jako `micro`, `vim`).

    ```bash
    nano [CESTA_K_SOUBORU_S_PŘÍZNAKY_PROHLÍŽEČE]
    # Příklad: nano ~/.config/chrome-flags.conf
    ```

3. Přidejte příznaky: Vložte příslušné příznaky pro GPU/prohlížeč do souboru.
4. Uložte a zavřete.
5. Restartujte prohlížeč: Zavřete všechny instance prohlížeče a znovu jej spusťte.
6. Ověřte: Přejděte na `chrome://gpu` (nebo `brave://gpu`, `edge://gpu` atd.). Potvrďte stav „Hardware accelerated“ v sekcích „Video Acceleration Information“ a „Graphics Feature Status“.

</Steps>

## Jak ověřit hardwarovou akceleraci videa

<Tabs>

<TabItem label='AMD GPU (amdgpu_top)'>

<Steps>

1. Otevřete terminál a spusťte příkaz:
    ```bash
    amdgpu_top
    ```
2. Spusťte přehrávání videa v prohlížeči (např. na YouTube).
3. Sledujte sekci `media` v `amdgpu_top`. Měli byste zde vidět určité využití, což znamená, že mediální engine vaší GPU je aktivní. Pokud během přehrávání videa zůstává na 0 %, hardwarová akcelerace nemusí být pro dekódování plně zapojena.

</Steps>

</TabItem>

<TabItem label='Intel GPU (nvtop)'>

<Steps>

1. Otevřete terminál a spusťte příkaz:
    ```bash
    sudo nvtop
    ```
2. Spusťte přehrávání videa v prohlížeči (např. na YouTube).
3. Sledujte hodnotu `ENC/DEC` v procentech v `nvtop`; pokud dekódování videa běží hardwarově, hodnota by měla vzrůst.

</Steps>

</TabItem>

<TabItem label='Intel GPU (intel_gpu_tools)'>

<Steps>

1. Otevřete terminál a spusťte příkaz:

    ```bash
    sudo intel_gpu_top
    ```

    Poznámka: Některé novější GPU Intel, jako jsou GPU Lunar Lake, již nevystavují čítače výkonu GPU přes `intel_gpu_top` – u těchto systémů použijte `nvtop`.

2. Spusťte přehrávání videa v prohlížeči (např. na YouTube).
3. Sledujte hodnoty `Video` a `VideoEnhance` v procentech v `intel_gpu_top`; pokud dekódování videa běží hardwarově, hodnota by měla vzrůst.

</Steps>

</TabItem>

<TabItem label='Nástroje pro vývojáře v prohlížeči'>

<Steps>

1. Otevřete svůj prohlížeč založený na Chromiu.

2. Spusťte přehrávání videa (např. na YouTube nebo z lokálního souboru).

3. Otevřete Nástroje pro vývojáře: Stiskněte `F12` nebo `Ctrl+Shift+I`.

4. Přejděte na kartu **Media**. Pokud ji nevidíte, klikněte na tři tečky (`...`) nebo `>>` (Další karty) na liště Nástrojů pro vývojáře a poté vyberte `Media`.

5. V sekci „Players“ vlevo klikněte na položku odpovídající vašemu videu.

6. V hlavním panelu sjeďte dolů do sekce **Video Decoder**.

7. Hledejte štítek `Hardware decoder`. Měl by mít hodnotu `true`. Pokud zobrazuje `false` nebo název softwarového dekodéru (např. `FFmpegVideoDecoder`, `VpxVideoDecoder`, `Dav1dVideoDecoder`), hardwarová akcelerace pro toto video není aktivní.

</Steps>

</TabItem>

</Tabs>

## Konfigurace GPU a prohlížečů

### AMD Radeon RX 6900 XT (Google Chrome)

* **Prohlížeč:** Google Chrome

* **GPU:** AMD Radeon RX 6900 XT

* **Soubor s příznaky:** `~/.config/chrome-flags.conf`

```bash
--use-gl=angle
--use-angle=vulkan
--enable-features=Vulkan,VulkanFromANGLE,DefaultANGLEVulkan,AcceleratedVideoDecodeLinuxZeroCopyGL,AcceleratedVideoEncoder,VaapiIgnoreDriverChecks,UseMultiPlaneFormatForHardwareVideo
```

**Poznámky:** Využívá Vulkan (přes ANGLE) a VA-API. `--ozone-platform=x11` může být užitečné na Waylandu pro určité cesty akcelerace.


### Nvidia RTX 4090 (Vivaldi)

* **Prohlížeč:** Vivaldi

* **GPU:** Nvidia RTX 4090

* **Soubor s příznaky:** `~/.config/vivaldi-stable.conf`

```bash
--enable-features=VaapiVideoDecoder,AcceleratedVideoDecodeLinuxGL,AcceleratedVideoDecodeLinuxZeroCopyGL
```

* **Soubor s příznaky:** `/usr/share/applications/vivaldi-stable.desktop`

```bash
# Všechny ostatní řádky ponechte beze změny
# Změňte pouze tento záznam Exec= v sekci '[Desktop Entry]'
Exec=/usr/bin/vivaldi-stable --enable-features=VaapiVideoDecoder,AcceleratedVideoDecodeLinuxGL,AcceleratedVideoDecodeLinuxZeroCopyGL %U
```

**Poznámky:**

Mělo by stačit upravit jen jeden z těchto konfiguračních souborů, ale úprava obou by neměla způsobit žádné problémy.

Případně můžete v KDE postupovat takto:
1. Odstraňte případné zástupce pro Vivaldi ze Správce úloh / hlavního panelu.
2. Vyhledejte `Vivaldi` v seznamu Spouštěče aplikací.
3. Klikněte pravým tlačítkem na položku ve Spouštěči aplikací a vyberte `Upravit aplikaci...`.
4. V sekci `Argumenty příkazového řádku` přidejte před poslední argument `%U` následující argumenty:
```
--enable-features=VaapiVideoDecoder,AcceleratedVideoDecodeLinuxGL,AcceleratedVideoDecodeLinuxZeroCopyGL
```
5. Spusťte Vivaldi a připněte proces do Správce úloh / na hlavní panel.

### Vivaldi - AMD Radeon RX 9070 XT (Přispěl/a tTrmc)

* **Prohlížeč:** Vivaldi

* **GPU:** AMD Radeon RX 9070 XT (RDNA 4 / gfx1201)

* **Cesta k souboru s příznaky:** `~/.config/vivaldi-stable.conf`

```bash
--ignore-gpu-blocklist
--enable-gpu-rasterization
--enable-zero-copy
--enable-features=VaapiVideoDecoder,AcceleratedVideoDecodeLinuxGL,AcceleratedVideoDecodeLinuxZeroCopyGL,AcceleratedVideoEncoder,VaapiIgnoreDriverChecks,UseMultiPlaneFormatForHardwareVideo
```

**Poznámky:**
- Testováno na CachyOS s jádrem 6.19.11-1-cachyos, Mesa 26.0.3, GNOME (Wayland), rozlišení displeje 2560x1440.
- Potvrzeno jako funkční: `vivaldi://gpu` zobrazuje Video Decode a Video Encode jako „Hardware accelerated“. Plná podpora kodeků pro dekódování H264, VP9, HEVC, AV1 a kódování H264, AV1. Karta Media v DevTools zobrazuje `VaapiVideoDecoder` jako aktivní dekodér.
- Karta RX 9070 XT (RDNA 4) může být na seznamu blokovaných GPU v Chromiu, proto je vyžadován příznak `--ignore-gpu-blocklist`.
- V logu se může objevit varování: `'--ozone-platform=wayland' is not compatible with Vulkan` — to nebrání fungování hardwarové akcelerace.

### Vivaldi - NVIDIA RTX 5090 (Přispěl/a icetea)

* **Prohlížeč:** Vivaldi (8.1)

* **GPU:** NVIDIA GeForce RTX 5090 (Blackwell)

* **Cesta k souboru s příznaky:** `~/.config/vivaldi-stable.conf`

```bash
--enable-features=VaapiVideoDecoder,AcceleratedVideoDecodeLinuxGL,AcceleratedVideoDecodeLinuxZeroCopyGL,VaapiOnNvidiaGPUs,VaapiIgnoreDriverChecks
--use-gl=angle
--use-angle=gl
--disable-features=Vulkan
--ignore-gpu-blocklist
--ozone-platform=wayland
```

**Poznámky:**
- Vyžaduje `libva-nvidia-driver`. Testováno v červenci 2026: ovladač 610.43.03, KDE Plasma (Wayland), Vivaldi 8.1.
- `VaapiIgnoreDriverChecks` je na kartách NVIDIA klíčový příznak — bez něj se dekódování inicializuje a `vivaldi://gpu` hlásí „Hardware accelerated“, ale za běhu dekódování selže (`vaEndPicture failed, VA error: internal decoding error`) a tiše se přepne na softwarové dekódování.
- Ověřte pomocí DevTools → karta Media (`VaapiVideoDecoder` jako název dekodéru) a `nvidia-smi dmon -s u` (sloupec DEC > 0 během přehrávání). Nespoléhejte se pouze na `vivaldi://gpu`.
- Dekódování AV1 je v `libva-nvidia-driver` 0.0.17 rozbité (oprava je v upstream masteru, zatím nevydaná — viz [elFarto/nvidia-vaapi-driver#419](https://github.com/elFarto/nvidia-vaapi-driver/issues/419)). Zablokujte AV1 (např. pomocí enhanced-h264ify), aby YouTube podávalo VP9.

### Google Chrome - NVIDIA RTX 5070 (Přispěl/a pisyukaev)

* **Prohlížeč:** Google Chrome

* **GPU:** NVIDIA GeForce RTX 5070 (Blackwell / GB205)

* **Cesta k souboru s příznaky:** `~/.config/chrome-flags.conf`

```bash
--enable-features=AcceleratedVideoDecodeLinuxGL,VaapiVideoDecoder,VaapiIgnoreDriverChecks,VaapiOnNvidiaGPUs
--ignore-gpu-blocklist
```

**Poznámky:**
- Vyžaduje `libva-nvidia-driver` a `nvidia-utils` (testováno s ovladačem 610.43.03).
- **Kritický příznak:** `VaapiOnNvidiaGPUs` — toto je klíčový příznak, který v Chrome/Chromiu povoluje VA-API na GPU NVIDIA. Bez něj má Chrome v `vaapi_wrapper.cc` natvrdo zakódovaný blok pro zařízení NVIDIA a tiše se přepne na softwarové dekódování.
- `VaapiIgnoreDriverChecks` se rovněž doporučuje, aby se předešlo chybám dekódování za běhu.
- `AcceleratedVideoDecodeLinuxGL` povoluje hardwarově akcelerované dekódování videa přes OpenGL backend rozhraní ANGLE.
- Ověřeno jako funkční: `chrome://gpu` → Video Acceleration Information zobrazuje podporu dekódování pro H264 (baseline, main, high), VP8, VP9 (profile0, profile2), HEVC (main, main 10, main still-picture) a AV1.
- Pro ověření: Otevřete `chrome://gpu` a potvrďte, že sekce „Video Acceleration Information“ uvádí dekódovací kodeky. Přehrajte HEVC video a zkontrolujte v DevTools → karta Media, zda je jako aktivní dekodér uveden `VaapiVideoDecoder`.
- Příznak `--ozone-platform=wayland` není potřeba — Chrome na CachyOS detekuje Wayland automaticky. Pokud narazíte na problémy, můžete `--ozone-platform=wayland` přidat explicitně.
