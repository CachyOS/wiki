## Než začnete

:::note
Pokud se vám po kliknutí na **Spustit instalátor** zobrazí jako možnosti správce spouštění pouze GRUB a Limine, systém je spuštěn v režimu Legacy/BIOS.
:::

:::note[Během procesu instalace není povoleno instalovat více desktopových prostředí najednou.]
:::

:::caution[Při instalaci v režimu UEFI musí být v nastavení BIOS/UEFI vypnuty funkce Secure Boot a CSM.]
Pro nastavení Secure Bootu po instalaci přejděte do sekce [Secure Boot](/cs/configuration/secure_boot_setup).

Položka `Legacy USB Support` by měla být nastavena na `Auto`.
:::

:::caution
Možnosti `Install alongside` (Nainstalovat vedle) a `Replace partition` (Nahradit oddíl) nejsou 100% spolehlivé a mohou způsobit selhání instalace.

Při instalaci CachyOS je **důrazně upřednostňováno** `Ruční rozdělení disku` (`Manual partitioning`).
:::

:::tip
Po neúspěšném pokusu o instalaci se důrazně doporučuje restartovat systém zpět do ISO obrazu.

V opačném případě může během instalačního procesu docházet k opakovaným chybám.

Dochází k tomu proto, že instalátor při neúspěšné instalaci správně neodpojí oddíly.

:::

## Metody instalace

### Ruční rozdělení disku

:::note[Před zahájením rozdělování disku pro instalaci UEFI.]
    ```sh title='Spusťte tento příkaz v terminálu'
    efibootmgr -v
    ```
Pokud je výstupem `EFI variables are not supported on this system.`, systém je spuštěn v režimu Legacy/BIOS a musíte se ujistit, že je v nastavení BIOS/UEFI nakonfigurován režim UEFI. Podívejte se do sekce [Než začnete](/cs/installation/installation_on_root/#než-začnete).
:::

## Dual boot Windows a CachyOS

:::note[Tento návod předpokládá, že v systému jsou již nainstalovány Windows a rozhodli jste se nainstalovat CachyOS vedle nich na stejný disk.]
:::

:::caution
Dual boot Windows a Linuxu není 100% spolehlivý. Aktualizace Windows mohou poškodit zavaděč přepsáním oddílu EFI.
V některých případech k problémům nemusí nikdy dojít, ale u některých uživatelů se může jednat o opakující se problém.

Jedním ze způsobů, jak se tomuto problému vyhnout, je nainstalovat každý operační systém na samostatný disk.
:::

:::caution
Velikost oddílu EFI může být nutné změnit v závislosti na doporučené minimální velikosti pro cílového správce spouštění. Podívejte se do sekce [Ruční rozdělení disku](/cs/installation/installation_on_root#ruční-rozdělení-disku).

Souborové systémy FAT nelze zvětšovat ani zmenšovat přímo na místě (in-place). Pro správnou „změnu velikosti“ oddílu FAT EFI je nutné zazálohovat stávající souborový systém EFI, pomocí nástroje jako `gparted` změnit velikost stávajícího oddílu a nově ho naformátovat, a poté zkopírovat předchozí strukturu souborového systému zpět na oddíl EFI.
:::

### Požadavky

- Rychlé spuštění (Fast Startup) a hibernace Windows musí být vypnuty.
  - Otevřete Windows PowerShell jako správce a spusťte následující příkaz:
      ```ps
      powercfg /H off
      ```
    Restartujte systém, aby se změny projevily.
- Nástroj Windows BitLocker musí být vypnutý.
  - Kontrola, zda je BitLocker zapnutý:
    ```ps title='Otevřete Příkazový řádek jako správce a spusťte následující příkaz'
    manage-bde -status
    ```
  Pokud je u položky **Encryption Method** uvedeno `None`, pak je BitLocker vypnutý.
- Funkce Secure Boot musí být vypnutá.
- Prázdný oddíl o velikosti ≥ 30 GB.
  - Návod, jak zmenšit oddíl Windows:
    - Stiskněte `Win + R`, napište `diskmgmt.msc` a stisknutím klávesy Enter otevřete Správu disků.
    - Najděte svůj hlavní oddíl Windows (obvykle C:) a klikněte na něj pravým tlačítkem.
    - Klikněte na `Zmenšit svazek...` (`Shrink Volume...`), zadejte alespoň **30720 MB** (30 GiB) a klikněte na `Zmenšit` (`Shrink`).
- Spouštěcí USB disk s CachyOS.
  - Podívejte se do sekce [Vytvoření bootovacího USB disku CachyOS](/cs/installation/installation_prepare#vytvoření-bootovacího-usb-disku-cachyos).

<Tabs>
    <TabItem label='Limine'>
        Limine by měl automaticky rozpoznat oddíl Windows EFI a přidat ho do spouštěcího menu. Pokud se Windows ve spouštěcím menu neobjeví, spusťte následující příkaz:
        ```bash
        sudo limine-scan
        ```
    </TabItem>
    <TabItem label='systemd-boot'>
        **Musíme zkopírovat binární soubory Windows EFI na linuxový oddíl EFI, aby je správce spouštění rozpoznal.**

        <Steps>
        1. Najděte **oddíl Windows EFI** pomocí `lsblk`.

            ```sh title='Spusťte tento příkaz v terminálu'
            lsblk -o NAME,FSTYPE,SIZE,MOUNTPOINT
            ```
            ```sh title='Příklad výstupu'
                        NAME        FSTYPE   SIZE MOUNTPOINT
            zram0               15.3G [SWAP]
            nvme0n1            476.9G
            ├─nvme0n1p1 vfat     100M
            ├─nvme0n1p2           16M
            ├─nvme0n1p3 ntfs   234.4G
            ├─nvme0n1p4 ntfs     830M
            ├─nvme0n1p5 vfat       2G /boot
            └─nvme0n1p6 btrfs  239.6G /var/tmp
            ```
            Oddíly EFI jsou téměř vždy formátovány jako `FAT32/vfat`. Protože `nvme0n1p1` nemá linuxový přípojný bod, můžeme předpokládat, že tento oddíl je oddíl Windows EFI.

        2. Dočasně připojte oddíl Windows EFI.

            ```sh
            sudo mkdir /mnt/WinBoot
            sudo mount /dev/nvme0n1p1 /mnt/WinBoot # Nahraďte `nvme0n1p1` názvem oddílu Windows EFI.
            ```

        3. Zkopírujte binární soubory EFI z **oddílu Windows EFI** na **linuxový oddíl EFI**.

            ```sh
            sudo cp -r /mnt/WinBoot/EFI/Microsoft/ /boot/EFI
            ```

        4. Odpojte dříve připojený oddíl. Windows by se měly při příštím spuštění objevit ve spouštěcím menu.

            ```sh
            sudo umount /mnt/WinBoot
            sudo rm -r /mnt/WinBoot
            ```

        </Steps>
    </TabItem>

    <TabItem label='GRUB (pouze pro starší instalace)'>
        :::tip[CachyOS ve výchozím nastavení povoluje os-prober.]
        :::
        **GRUB používá os-prober k automatické detekci oddílu Windows EFI a jeho přidání do spouštěcího menu.**

        <Steps>
        1. Nainstalujte **os-prober**.

            ```sh
            sudo pacman -S os-prober
            ```

        2. Povolte **os-prober** v konfiguračním souboru GRUBu.

            ```sh title='Stiskněte CTRL+S pro uložení a CTRL+Q pro ukončení Micro'
            sudo micro /etc/default/grub
            # /etc/default/grub
            # Probing for other operating systems is disabled for security reasons. Read
            # documentation on GRUB_DISABLE_OS_PROBER, if still want to enable this
            # functionality install os-prober and uncomment to detect and include other
            # operating systems.
            GRUB_DISABLE_OS_PROBER=false

            ```

        3. Aktualizujte grub.cfg nyní s využitím **os-prober**.
            ```sh
            sudo grub-mkconfig -o /boot/grub/grub.cfg
            ```

            **Windows by nyní měly být přidány do spouštěcího menu.**

        </Steps>
    </TabItem>
</Tabs>
