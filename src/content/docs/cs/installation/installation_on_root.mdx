Secure boot musí být při instalaci CachyOS vypnutý. Pro nastavení Secure Bootu po instalaci se podívejte na [Nastavení Secure Bootu](/configuration/secure_boot_setup).
:::

:::tip
Důrazně se doporučuje restartovat ISO po neúspěšném pokusu o instalaci.

V opačném případě může během instalačního procesu docházet k neustálým chybám.

To se děje, protože instalátor při neúspěšné instalaci správně neodpojí oddíly.

:::

## Smazat disk

Volba "Smazat disk" v Calamares vymaže vybraný disk a nainstaluje CachyOS na cíl.

<Steps>

1. Spusťte ISO a klikněte na **Spustit instalátor**.

2. Vyberte preferovaný **Zavaděč**. Pro více informací se podívejte na sekci [Zavaděče](/installation/boot_managers).

3. Nastavte preferovaný **Jazyk** a **Region/Časové pásmo**.

4. Nakonfigurujte **Rozložení klávesnice**.

5. Vyberte **Smazat disk** a zvolte [Souborový systém](/installation/filesystem).

6. Vyberte požadované **Pracovní prostředí**, viz [Pracovní prostředí](/installation/desktop_environments).

7. Přizpůsobte, které balíčky mají nebo nemají být nainstalovány během instalačního procesu.

8. Nastavte přihlašovací údaje.

9. Pečlivě zkontrolujte souhrn instalace na stránce Přehled. Pokud vše vypadá správně, pokračujte v instalaci kliknutím na ***Nainstalovat nyní***. V opačném případě se vraťte a proveďte potřebné změny.

</Steps>

## Dual Boot

*Po ručním rozdělení disku může být vyžadováno další nastavení pro konfiguraci dual boot systému, zejména s `systemd-boot` a `GRUB`.*

<Tabs>
    <TabItem label='systemd-boot'>
        *Musíme zkopírovat binární soubory Windows EFI na linuxový oddíl EFI, aby je zavaděč rozpoznal.*

        <Steps>
        1. Najděte `oddíl Windows EFI` pomocí `lsblk`

            ```sh title='Příklad'
            ❯ lsblk -o NAME,FSTYPE,SIZE,MOUNTPOINT
            NAME        FSTYPE   SIZE MOUNTPOINT
            zram0               15.3G [SWAP]
            nvme0n1            476.9G
            ├─nvme0n1p1 vfat     100M
            ├─nvme0n1p2           16M
            ├─nvme0n1p3 ntfs   234.4G
            ├─nvme0n1p4 ntfs     830M
            ├─nvme0n1p5 vfat       2G /boot
            └─nvme0n1p6 btrfs  239.6G /var/tmp
            ```

            *Oddíly EFI jsou téměř vždy formátovány jako `FAT32/vfat`, a protože nvme0n1p1 nemá linuxový přípojný bod, předpokládejte, že tento oddíl je `oddíl Windows EFI`.*

        2. Dočasně připojte `oddíl Windows EFI`.

            ```sh
            ❯ sudo mount /dev/nvme0n1p1 /mnt/WinBoot # Nahraďte `nvme0n1p1` oddílem EFI systému Windows
            ```

        3. Zkopírujte binární soubory EFI z `oddílu Windows EFI` na `linuxový oddíl EFI`.

            ```sh
            ❯ sudo cp -r /mnt/WinBoot/EFI/* /boot/EFI
            ```

        4. Odpojte dříve připojený oddíl a Windows by se měl objevit ve spouštěcím menu při příštím startu.

            ```sh
            ❯ sudo umount /mnt/WinBoot
            ```

        </Steps>
    </TabItem>

    <TabItem label='GRUB'>
        *GRUB používá os-prober k automatické detekci oddílu Windows EFI a jeho přidání do spouštěcího menu.*

        <Steps>
        1. Nainstalujte a spusťte `os-prober`

            ```sh
            ❯ sudo pacman -S os-prober
            ❯ sudo os-prober
            ```

        2. Povolte `os-prober` v konfiguračním souboru GRUBu

            ```sh title='Stiskněte CTRL+S pro uložení a CTRL+Q pro ukončení Micro'
            ❯ sudo micro /etc/default/grub
            # /etc/default/grub
            # Prohledávání ostatních operačních systémů je z bezpečnostních důvodů zakázáno. Přečtěte si
            # dokumentaci o GRUB_DISABLE_OS_PROBER, pokud chcete tuto
            # funkci povolit, nainstalujte os-prober a odkomentujte pro detekci a zahrnutí ostatních
            # operačních systémů.
            GRUB_DISABLE_OS_PROBER=false

            ❯ sudo grub-mkconfig -o /boot/grub/grub.cfg
            ```

            **Windows by nyní měl být přidán do spouštěcího menu.**

        </Steps>
    </TabItem>
</Tabs>
