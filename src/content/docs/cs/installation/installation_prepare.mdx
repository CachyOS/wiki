## Systémové požadavky

Před zahájením příprav na instalaci se ujistěte, že používaný počítač splňuje minimální systémové požadavky pro běh CachyOS. Instalátor
využívá online proces instalace, takže stabilní a relativně rychlé připojení k internetu je nezbytné.

:::note[Virtuální stroje]
Nedoporučuje se instalovat CachyOS na virtuální stroj. Virtuální stroje mohou mít problémy s nesprávnou konfigurací nebo nemusí fungovat vůbec. Doporučuje se instalovat CachyOS přímo na fyzický hardware (bare metal).
:::

<Tabs>

<TabItem label="Minimální požadavky">

*   3 GB RAM
*   30 GB úložného prostoru (HDD/SSD)
*   Stabilní připojení k internetu

:::caution
Nestabilní připojení k internetu může způsobit prodloužení doby instalace nebo v nejhorším případě neúspěšnou instalaci.
:::

</TabItem>

<TabItem label="Doporučené požadavky">

*   8 GB RAM
*   50 GB úložného prostoru (SSD/NVMe)
*   [CPU podporující x86-64-v3](/cs/installation/installation_prepare#podpora-úrovně-mikroarchitektury-x86_64)
*   Rychlost internetu 50 Mbps nebo lepší
*   GPU NVIDIA (900+ - např. GTX 950), AMD +GCN 1.0 (např. AMD R7 240) nebo Intel (integrovaná grafika řady HD nebo vyšší, řada Arc)

</TabItem>

</Tabs>

## Vytvoření bootovacího USB disku CachyOS

Existuje několik nástrojů a metod, které lze použít k vytvoření bootovacího USB disku CachyOS.

:::tip
Ponechte si kopii ISO obrazu CachyOS na stejném disku nebo na jiném místě, abyste ji mohli později použít k řešení problémů pomocí chroot.
:::

:::note
USB disk musí mít alespoň 8 GB volného prostoru.
:::

### balenaEtcher

<Steps>

1. Stáhněte si [balenaEtcher](<https://etcher.balena.io/>). balenaEtcher podporuje zápis obrazů na Linuxu, macOS a Windows.
   Pokud byl stažen soubor `.zip`, extrahujte ho a spusťte binární soubor pomocí následujících příkazů:
      ```sh
      # Extrahujte soubor zip:
      bsdtar xvf <název zip souboru>
      # Přejděte do nové složky:
      cd balenaEtcher-linux-x64/
      # Spusťte balenaEtcher:
      ./balena-etcher
      ```
2. Připojte USB disk k počítači.
3. Vyberte `Flash from file` a zvolte ISO obraz CachyOS.
4. Klikněte na `Select target` a zvolte připojený USB disk.
5. Stiskněte `Flash` pro zahájení procesu zápisu.

</Steps>

:::note
balenaEtcher může vyžadovat administrátorská oprávnění. Pokud ano, zadejte své heslo a klikněte na `Authenticate`.
:::

### Příkazová řádka (Linux a MacOS)

<Steps>

1. Připojte USB disk.
2. Detekujte připojený USB disk pomocí následujících příkazů:
   ```sh
   # Linux
   # USB disk může být identifikován např. jako /dev/sda podle modelu a velikosti disku.
   sudo fdisk -l

   # MacOS
   # USB disky jsou identifikovány jako "/dev/diskY", kde "Y" může být 0,1 atd.
   diskutil list
   ```
3. Zkopírujte obsah ISO souboru na připojený USB disk spuštěním:
   ```sh
   # Nahraďte <usbdrive> označením disku.
   sudo dd bs=4M if=full_iso_name.iso of=/dev/<usbdrive> status=progress oflag=sync
   ```
</Steps>

- `dd` nyní zkopíruje obsah ISO souboru na připojený USB disk.

### Rufus (pouze Windows)

<Steps>

1. Připojte USB disk.
2. Stáhněte si [Rufus](<https://rufus.ie/>) a nainstalujte ho, nebo spusťte přenosnou verzi.
3. V poli `Device` klikněte na rozevírací seznam a vyberte připojený USB disk.
4. V poli `Boot selection` klikněte na `SELECT` a vyhledejte ISO obraz CachyOS.
5. Klikněte na `START`.

</Steps>

### Ventoy (Linux a Windows)

<Tabs>

<TabItem label="Linux">

<Steps>

1. Připojte USB disk.
2. Stáhněte si [Ventoy](<https://www.ventoy.net/en/download.html>)
3. Rozbalte Ventoy pomocí následujícího příkazu:
   ```sh
   # Nahraďte verzi správnou verzí např.: ventoy-1.1.07-linux.tar.gz
   bsdtar xvf ventoy-version-linux.tar.gz
   # Přejděte do nové složky: (verze se může lišit)
   cd ventoy-1.1.07/
   ```
4. Spusťte `VentoyGUI.x86_64` dvojklikem nebo přes terminál:
   ```sh
   # Bude vyžadovat administrátorská práva, zadejte své přihlašovací údaje
   ./VentoyGUI.x86_64
   ```
5. Vyberte připojený USB disk kliknutím na `Device`.
6. Klikněte na `Install`.
7. Po dokončení instalace Ventoy na připojený USB disk zavřete okno a umístěte ISO soubor CachyOS do nového použitelného oddílu disku.

</Steps>

</TabItem>

<TabItem label="Windows">

<Steps>
1. Připojte USB disk.
2. Stáhněte si [Ventoy](<https://www.ventoy.net/en/download.html>)
3. Spusťte `Ventoy2Disk.exe`
4. Vyberte připojený USB disk kliknutím na `Device`.
5. Klikněte na `Install`.
6. Po dokončení instalace Ventoy na připojený USB disk zavřete okno a umístěte ISO soubor CachyOS do nového použitelného oddílu disku.
</Steps>

</TabItem>

</Tabs>
