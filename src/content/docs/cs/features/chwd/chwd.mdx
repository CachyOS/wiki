[CachyOS Hardware Detection](https://github.com/CachyOS/chwd/) (zkráceně `chwd`) umožňuje zprovoznit širokou škálu hardwaru instalací nezbytných
balíčků a ovladačů pro běžící systém. To zahrnuje systémy s grafickými kartami NVIDIA, počítače T2 MacBook a handheldy jako Steam Deck a ROG Ally.

## Použití

Nástroj `chwd` se obvykle spouští během instalace, aby systému poskytl potřebné balíčky. Je ale také možné
jej použít po instalaci.

### Automatická konfigurace

Nástroj `chwd` podporuje instalaci a konfiguraci nezbytných ovladačů a balíčků tak, aby systém pracoval za optimálních podmínek.

```sh
sudo chwd -a
```

### Ostatní

Pro syntaxi příkazů a další možnosti použití nahlédněte do nápovědy `chwd`.

```sh
chwd --help
Usage: chwd [OPTIONS]

Options:
  -i, --install <profile>          Install profile
  -r, --remove <profile>           Remove profile
  -d, --detail                     Show detailed info for listings
  -f, --force                      Force reinstall
      --list-installed             List installed kernels
      --list                       List available profiles for all devices
      --list-all                   List all profiles
  -a, --autoconfigure [<classid>]  Autoconfigure
      --ai_sdk                     Toggle AI SDK profiles
      --pmcachedir <PMCACHEDIR>    [default: /var/cache/pacman/pkg]
      --pmconfig <PMCONFIG>        [default: /etc/pacman.conf]
      --pmroot <PMROOT>            [default: /]
  -h, --help                       Print help
  -V, --version                    Print version
```
