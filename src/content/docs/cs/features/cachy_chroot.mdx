[cachy-chroot](https://github.com/CachyOS/cachy-chroot) je jednoduchý pomocný program, který usnadňuje proces chrootování do existujících
instalací CachyOS nebo systémů založených na Archu. Vypíše všechny oddíly nalezené na počítači a také podporuje výpis subvolumů BTRFS.
V neposlední řadě `cachy-chroot` podporuje také šifrované systémy pomocí LUKS. Namapuje každý záznam `fstab` na příslušné záznamy `crypttab`
a při ukončení chrootu korektně uzavře všechny svazky LUKS.

:::caution[cachy-chroot je určen ke spuštění z živého (live) prostředí CachyOS.]
:::

:::note
cachy-chroot podporuje připojení prakticky jakéhokoli souborového systému podporovaného linuxovým jádrem s výjimkou ZFS.
:::

## Použití

:::tip
Pro pohyb mezi možnostmi použijte klávesy se šipkami a pro výběr stiskněte `ENTER`.

Symbol **❯** označuje aktuálně vybranou možnost.

**?** označuje výzvu k zadání vstupu od uživatele.
:::

<Steps>
1. Nabootujte do živého ISO obrazu CachyOS
2. Otevřete terminál a přepněte se na uživatele root pomocí `sudo su`
3. Ujistěte se, že máte nainstalovanou nejnovější verzi `cachy-chroot`, spuštěním:
    ```bash
    pacman -Sy cachy-chroot
    ```
4. Spusťte `cachy-chroot` zadáním:
    ```bash
    cachy-chroot
    ```

6. `cachy-chroot` se pokusí automaticky připojit všechny oddíly a subvolumy uvedené v `/etc/fstab` kořenového zařízení. Pokud se některé oddíly nepodaří připojit, budete na to upozorněni a dostanete možnost připojit je v případě potřeby ručně. Můžete zvolit `no`, pokud chcete připojování dalších oddílů přeskočit.
7. **Nyní se nacházíte v prostředí chroot**.
    ```bash
    [root@CachyOS /]#
    ```
    Nyní můžete spouštět příkazy stejně, jako byste byli nabootováni v nainstalovaném systému. Můžete například aktualizovat systém pomocí:
    ```bash title="Aktualizace systému v chrootu"
    pacman -Syu
    ```
    ```bash title="Pro jistotu znovu vygenerujte initramfs"
    mkinitcpio -P
    ```
    nebo podle potřeby provádět další úkony údržby.
8. Po dokončení ukončete prostředí chroot zadáním `exit` do příkazového řádku nebo stisknutím `CTRL+D` na klávesnici.
    ```bash title="Ukončení chrootu"
    exit
    ```
9. Po ukončení `cachy-chroot` automaticky odpojí připojené oddíly a uzavře všechny kontejnery LUKS. Vrátíte se zpět do shellu živého prostředí.

### Řešení problémů

- **Nebyly nalezeny žádné oddíly:** Ujistěte se, že disk obsahující vaši instalaci je připojen a rozpoznán živým systémem. Můžete to zkontrolovat pomocí `lsblk` nebo `fdisk -l`.
- **Automatické připojení u některých oddílů selže:** Můžete je zkusit připojit ručně z prostředí chroot. `cachy-chroot` chyby ignoruje a pokračuje.

### FAQ

- **Otázka: K čemu slouží připojení dalších oddílů?**
  - Odpověď: Existuje několik případů použití pro ruční připojení dalších oddílů, například:
    - **Poškozený nebo chybějící soubor fstab:** Můžete ručně připojit potřebné oddíly (například `/boot` nebo `/home`), abyste mohli provést opravy nebo obnovu dat.
    - **Aktualizovaná UUID oddílů:** Pokud se váš systém nespustí, protože jste změnili UUID oddílu, můžete použít `cachy-chroot` k připojení oddílů a následné aktualizaci souboru fstab.
