Instalace jádra z repozitáře
---------------------------------------

CachyOS Kernel Manager usnadňuje instalaci a správu jader z jakéhokoli repozitáře Arch Linuxu.

Pro instalaci jádra spusťte aplikaci `CachyOS Kernel Manager` a vyberte požadované jádro zaškrtnutím políčka `[]` ze seznamu všech dostupných možností, poté stačí stisknout `Provést` pro zahájení instalace jádra.

Chcete-li jádro odinstalovat, jednoduše zrušte zaškrtnutí políčka `[]` u nainstalovaného jádra, které chcete odebrat, a znovu stiskněte `Provést`.

<br />
<ImageComponent imgsrc={import('~/assets/images/cachyos-km1.png')} />

:::note
Tlačítko `Provést` se stane nedostupným, když vyberete již nainstalované jádro.
:::

Konfigurace a sestavení vlastního jádra CachyOS
---------------------------------

<br />
<ImageComponent imgsrc={import('~/assets/images/cachyos-km2.png')} />

:::note
CachyOS Kernel Manager je speciálně navržen pro sestavování vlastních jader pro **varianty CachyOS** a nepodporuje sestavování ani konfiguraci standardního jádra Arch Linuxu nebo jakékoli jiné varianty.
:::

*Pro začátek otevřete Kernel Manager a klikněte na tlačítko `Konfigurovat` pro úpravu různých nastavení, jako je požadovaný plánovač, frekvence časovače (tick rate) a další. Jakmile provedete požadované změny, klikněte na `Sestavit jádro` pro zahájení sestavování vašeho vlastního jádra CachyOS.*

**Sestavené balíčky jádra a mezipaměť jsou uloženy v** `~/.cache/cachyos-km/`

**Dostupné možnosti konfigurace:**

* `Vlastní název balíčku`: S touto možností můžete své jádro pojmenovat, jak chcete. Například: `linux-custom-cachy`
* Plánovač (BORE, RC, RT, RT+BORE, EEVDF a BMQ)
* Povolit konfiguraci CachyOS
* Upravit konfiguraci pomocí nconfig, menuconfig, xconfig nebo gconfig
* Povolit/Zakázat NUMA
* Povolit/Zakázat Modprobed-db
* KBUILD CFLAGS (-O3 nebo -O2)
* Výkonnostní governor jako výchozí
* Povolit BBR3
* Výběr tick rate (100Hz, 250Hz, 300Hz, 500Hz, 600Hz, 750Hz, 1000Hz)
* Beztikový režim (idle, periodic, full)
* Preempce (Full, Voluntary nebo Server)
* Transparent Hugepages (Always nebo Madvise)
* Povolit/Zakázat DAMON
* Povolit/Zakázat automatickou detekci architektury CPU
* Aplikovat optimalizaci jádra pro specifické architektury CPU
* Povolit LTO (Full, Thin, No)
* Sestavit modul ZFS
* Sestavit uzavřený modul NVIDIA
* Sestavit otevřený modul NVIDIA
* Zahrnout vmlinux s ladicími informacemi/symboly
* Načíst/Uložit přednastavení konfigurace Kernel Manageru: `(Pouze přednastavení ze samotného správce)`
* Správa patchů jádra (podpora vzdálených i lokálních)

*Jakmile bude jádro úspěšně sestaveno, budete vyzváni k zadání hesla sudo pro jeho instalaci.*

## Správa frameworku Sched-ext

:::caution[Vyžaduje funkční polkit agent, aby správně fungoval.]
Podívejte se na následující **[stránku Arch Wiki pro referenci.](https://wiki.archlinux.org/title/Polkit#Authentication_agents)**
:::

Kernel Manager poskytuje grafické uživatelské rozhraní (GUI) pro správu a ovládání plánovačů sched-ext. Přístup k GUI získáte kliknutím na tlačítko `Konfigurace plánovače sched-ext` v hlavním okně.

<br />
<ImageComponent imgsrc={import('~/assets/images/cachyos-km3.png')} />

Toto GUI vám umožňuje:

- Přepínat mezi různými plánovači sched-ext (scx).
- Povolit nebo zakázat službu plánovače.
- Zkontrolovat aktuálně běžící plánovač.
- Nastavit příznaky a profily plánovače.

Za tímto účelem Kernel Manager používá `scx_loader` s konfigurací uloženou v `/etc/scx_loader.toml`.

Více informací o konfiguračním souboru `scx_loader` naleznete v [této dokumentaci](https://github.com/sched-ext/scx-loader/blob/main/crates/scx_loader/configuration.md).

- Jak `scx_loader` funguje?
    - Jakmile vyberete plánovač a profil, scx_loader spustí plánovač s vybraným profilem a uloží tuto konfiguraci do souboru `/etc/scx_loader.toml`, aby byla zajištěna perzistence po restartu. Příklad toho, jak bude soubor vypadat při výběru `scx_bpfland` s profilem `Gaming`:
        ```toml
        default_sched = "scx_bpfland"
        default_mode = "Gaming"

        [scheds.scx_bpfland]
        auto_mode = []
        gaming_mode = ["-m", "performance"]
        lowlatency_mode = ["-k", "-s", "5000", "-l", "5000"]
        powersave_mode = ["-m", "powersave"]
        ```

### Profily plánovače

- K čemu slouží "profily"?
  - Jsou to přednastavení pro plánovač, která upravují příznaky na základě osvědčených kombinací pro zvýšení efektivity u specifických případů použití, například "Gaming".

Všechny podrobnosti o profilech naleznete v [průvodci plánovači.](/cs/configuration/sched-ext#průvodce-plánovači-profily-a-případy-použití)
