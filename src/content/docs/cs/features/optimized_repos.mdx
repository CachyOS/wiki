Pro poskytnutí výkonnostně optimalizované distribuce CachyOS překompilovává balíčky Arch Linuxu specificky pro architektury `x86-64-v3`, `x86-64-v4` a `Zen4+`.

- **x86-64-v3:** 5%-20% nárůst výkonu ve srovnání s x86-64.
- **x86-64-v4:** Poskytuje podstatné výkonnostní zisky díky podpoře AVX512, v závislosti na zátěži.
- **Zen 4/5:** Kromě instrukční sady x86-64-v4 jsou přidány následující instrukce:

```text
abm, adx, aes, avx512bf16, avx512bitalg, avx512ifma, avx512vbmi, avx512vbmi2, avx512vnni,
avx512vpopctndq, clflushopt, clwb, clzero, fsgsbase, gfni, mwaitx, pclmul, pku, prfchw,
rpdid, rdrnd, rdseed, sha, sse4a, vaes, vockmulqdq, wbnoinvd, savec, xsaveopt, xsaves```

Pro více informací o těchto architekturách se podívejte na [tento článek na Wikipedii](https://en.wikipedia.org/wiki/X86-64#Microarchitecture_levels).

## Přizpůsobené balíčky

Náš repozitář [CachyOS-PKGBUILDs](https://github.com/CachyOS/CachyOS-PKGBUILDS) obsahuje balíčky, které dostávají průběžné aktualizace, patche a zpětně portované opravy.
Pro zvýšení výkonu selektivně implementujeme optimalizace PGO, LTO a BOLT v závislosti na potřebě.
Udržujeme také několik balíčků `-git`, např. mesa-git.

## Přidání našich repozitářů do existující instalace Arch Linuxu

:::caution
Instalace Pacmanu od CachyOS nainstaluje forkovanou verzi Pacmanu s funkcemi přidanými z CachyOS, jako je "INSTALLED_FROM" a automatická kontrola architektury. Pacman 6.1 přidal funkci validace, což by mohlo při použití Pacmanu z Arch Linuxu vést k varováním. Spolupracujeme s Arch Linuxem na zajištění správné kompatibility. Pokud se tomu chcete vyhnout, nepřidávejte repozitář "cachyos", který obsahuje přizpůsobený Pacman. Všechny ostatní repozitáře jako cachyos-v3, cachyos-v4, cachyos-extra/core-v3/4 je v pořádku přidat.
:::

:::tip
Před zvažováním přidání našich repozitářů se prosím podívejte na **[seznam kompatibility CPU](/installation/installation_prepare#x86_64-microarchitecture-level-support)**.
:::

<Tabs>

<TabItem label='Automatizovaně'>

Poskytujeme skript, který automatizuje instalaci našich repozitářů do vašich stávajících instalací založených na Archu.

```sh
curl https://mirror.cachyos.org/cachyos-repo.tar.xz -o cachyos-repo.tar.xz
tar xvf cachyos-repo.tar.xz && cd cachyos-repo
sudo ./cachyos-repo.sh
```

:::tip[Jak skript funguje]
Tento skript detekuje instrukční sady, které vaše CPU podporuje, a nainstaluje tu verzi našich repozitářů, která
je pro něj nejvíce optimalizovaná. Zároveň zálohuje váš starý `pacman.conf` pro případné odstranění repozitářů pomocí skriptu.
:::

</TabItem>

<TabItem label='Ručně'>

<Steps>

1. Nainstalujte klíčenku CachyOS:

   ```sh
   # Importujte klíč repozitáře
   sudo pacman-key --recv-keys F3B607488DB35A47 --keyserver keyserver.ubuntu.com
   # Podepište klíč repozitáře
   sudo pacman-key --lsign-key F3B607488DB35A47
   ```
2. Nainstalujte potřebné balíčky:

   ```sh
   sudo pacman -U 'https://mirror.cachyos.org/repo/x86_64/cachyos/cachyos-keyring-20240331-1-any.pkg.tar.zst' \
   'https://mirror.cachyos.org/repo/x86_64/cachyos/cachyos-mirrorlist-22-1-any.pkg.tar.zst' \
   'https://mirror.cachyos.org/repo/x86_64/cachyos/cachyos-v3-mirrorlist-22-1-any.pkg.tar.zst' \
   'https://mirror.cachyos.org/repo/x86_64/cachyos/cachyos-v4-mirrorlist-22-1-any.pkg.tar.zst' \
   'https://mirror.cachyos.org/repo/x86_64/cachyos/pacman-7.0.0.r7.g1f38429-1-x86_64.pkg.tar.zst'
   ```
3. Přidejte repozitáře CachyOS do konfiguračního souboru pacmana:
   :::note
   Tyto repozitáře by měly být umístěny nad repozitáři Arch Linuxu.
   :::

   ```shell
   # /etc/pacman.conf
   # Pokud vaše CPU podporuje pouze x86-64, přidejte repozitáře [cachyos]
   # repozitáře cachyos
   [cachyos]
   Include = /etc/pacman.d/cachyos-mirrorlist

   # Pokud vaše CPU podporuje x86-64-v3, přidejte [cachyos-v3],[cachyos-core-v3],[cachyos-extra-v3] a [cachyos]
   # repozitáře cachyos

   [cachyos-v3]
   Include = /etc/pacman.d/cachyos-v3-mirrorlist
   [cachyos-core-v3]
   Include = /etc/pacman.d/cachyos-v3-mirrorlist
   [cachyos-extra-v3]
   Include = /etc/pacman.d/cachyos-v3-mirrorlist
   [cachyos]
   Include = /etc/pacman.d/cachyos-mirrorlist

   # Pokud vaše CPU podporuje x86-64-v4, přidejte [cachyos-v4], [cachyos-core-v4], [cachyos-extra-v4] a [cachyos]
   # repozitáře cachyos

   [cachyos-v4]
   Include = /etc/pacman.d/cachyos-v4-mirrorlist
   [cachyos-core-v4]
   Include = /etc/pacman.d/cachyos-v4-mirrorlist
   [cachyos-extra-v4]
   Include = /etc/pacman.d/cachyos-v4-mirrorlist
   [cachyos]
   Include = /etc/pacman.d/cachyos-mirrorlist

   # Pokud je vaše CPU založeno na Zen 4 nebo Zen 5, přidejte [cachyos-znver4], [cachyos-core-znver4], [cachyos-extra-znver4] a [cachyos]

   [cachyos-znver4]
   Include = /etc/pacman.d/cachyos-v4-mirrorlist
   [cachyos-core-znver4]
   Include = /etc/pacman.d/cachyos-v4-mirrorlist
   [cachyos-extra-znver4]
   Include = /etc/pacman.d/cachyos-v4-mirrorlist
   [cachyos]
   Include = /etc/pacman.d/cachyos-mirrorlist
   ```
      :::tip
   Pro přechod z repozitářů `v4` na `znver4`

   Přidejte odpovídající položky z předchozího kroku a spusťte následující příkazy:
    ```sh
    sudo pacman -Scc # Zadejte Y v obou případech
    sudo pacman -Sy
    pacman -Qqn | sudo pacman -S - # Pro nahrazení všech v4 balíčků balíčky znver4
    # Restartujte systém
    ```
   :::

4. Nakonec aktualizujte svůj systém s balíčky CachyOS:
   ```sh
   sudo pacman -Syu
   ```

</Steps>

### Odinstalování repozitářů CachyOS

<Tabs>
<TabItem label='Automatizovaně'>

**Spusťte následující příkazy pro odstranění repozitářů CachyOS z vašeho systému:**
```sh
curl https://mirror.cachyos.org/cachyos-repo.tar.xz -o cachyos-repo.tar.xz
tar xvf cachyos-repo.tar.xz
cd cachyos-repo
sudo ./cachyos-repo.sh --remove
```

</TabItem>

<TabItem label='Ručně'>

<Steps>

1. Znovu nainstalujte původní pacman z Arch Linuxu:
   ```sh
   sudo pacman -S core/pacman
   ```
2. Spusťte následující příkaz:
   ```sh
   # Tím se vyhnete varováním %INSTALLED_DB%
   sudo find /var/lib/pacman/local/ -type f -name "desc" -exec sed -i '/^%INSTALLED_DB%$/,+2d' {} \;
   ```
3. Obnovte konfigurační soubor pacmana ze zálohy:
   ```sh
   sudo mv /etc/pacman.conf.bak /etc/pacman.conf
   ```
4. Přepněte zpět na výchozí balíčky Arch Linuxu pomocí následujících příkazů:
   ```sh
   pacman -Qqn | sudo pacman -S -
   sudo pacman -Syu
   ```
</Steps>

## Testy a benchmarky

Michael z Phoronixu již několikrát benchmarkoval CachyOS, který se většinou umisťuje na předních místech v grafech benchmarků a v geometrickém průměru všech výsledků testů.
Od prvního benchmarku provedeného v roce 2022 se CachyOS vyvinul a mnohem více dospěl z hlediska použitelnosti a výkonu.

Pokud byste se chtěli dozvědět více o nárůstu výkonu díky našim repozitářům, podívejte se na níže uvedené odkazy.

* **14/03/2021:** V RFC diskusi o dopadu x86-64-v3, kterou zahájil **Mateusz Jończyk** z Arch Linuxu, byly ukázány některé počáteční výsledky.
  * [RFC: Use x86_64-v2 architecture](https://lists.archlinux.org/pipermail/arch-general/2021-March/048739.html)

* **09/12/2022:** První benchmark provedený Michaelem.
  * [The Performance Of Arch Linux Powered CachyOS](https://www.phoronix.com/review/cachyos-linux-perf)

* **29/02/2024:** Phoronix provedl další benchmark demonstrující rozdíl mezi balíčky x86-64-v4, x86-64-v3 a x86-64 (generickými). Při pohledu na příklady jako PHP nebo GCC, kde přizpůsobujeme naše PKGBUILDy, je patrné znatelné zlepšení výkonu.
  * [Arch Linux CachyOS Benchmarks Of x86-64-v3 & x86-64-v4 Repositories](https://www.phoronix.com/review/cachyos-x86-64-v3-v4)

* **20/08/2024:** Michael zveřejnil nový benchmark pro AMD Ryzen 9 9950x, který zahrnuje CachyOS a některé další linuxové distribuce.
  * [Intel Continues To Show AMD The Importance Of Software Optimizations: 16% More Ryzen 9 9950X Performance](https://www.phoronix.com/review/linux-os-amd-ryzen9-9950x)
   :::note
   Liquid-DSP a RocksDB byly zkompilovány pomocí Phoronix Benchmark Suite, ignorujíc kompilační příznaky specifikované v /etc/makepkg.conf, což vedlo k neočekávanému výsledku výkonu pro CachyOS.
   :::
