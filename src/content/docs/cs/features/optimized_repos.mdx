Abychom poskytli výkonově optimalizovanou distribuci, CachyOS rekompiluje balíčky Arch Linuxu speciálně pro architektury `x86-64-v3`, `x86-64-v4` a `Zen4+`.

- **x86-64-v3:** Zvýšení výkonu o 5–20 % oproti x86-64.
- **x86-64-v4:** Přináší výrazné zvýšení výkonu díky podpoře AVX512 v závislosti na pracovní zátěži.
- **Zen 4/5:** Kromě instrukční sady x86-64-v4 jsou přidány následující instrukce:

```text
abm, adx, aes, avx512bf16, avx512bitalg, avx512ifma, avx512vbmi, avx512vbmi2, avx512vnni,
avx512vpopctndq, clflushopt, clwb, clzero, fsgsbase, gfni, mwaitx, pclmul, pku, prfchw,
rpdid, rdrnd, rdseed, sha, sse4a, vaes, vockmulqdq, wbnoinvd, savec, xsaveopt, xsaves
```

Chcete-li se o těchto architekturách dozvědět více, [podívejte se na tento článek na Wikipedii](https://en.wikipedia.org/wiki/X86-64#Microarchitecture_levels).

## Migrace z x86-64-v3 na x86-64-v4 nebo znver4

Pokud aktuálně používáte repozitáře x86-64-v3 a váš nový procesor podporuje x86-64-v4 (nebo AMD Zen 4/5), můžete provést migraci podle následujících kroků:

### Kontrola kompatibility CPU

:::caution
Procesory Intel 12. generace (Alder Lake) a novější mohou hlásit podporu `x86-64-v4`, ale v praxi **nemohou spouštět instrukce AVX-512**.

Proč?
- **Konflikt hybridní architektury**: Velká jádra „P-cores“ podporují AVX-512, ale malá jádra „E-cores“ nikoli. Spouštění AVX-512 při aktivních jádrech E-cores by způsobovalo nestabilitu.
- **Řešení společnosti Intel**: Aby se předešlo tomuto nesouladu, Intel zakázal AVX-512 dvěma způsoby:
  - **Aktualizace mikrokódu/BIOSu** (rané čipy Alder Lake): AVX-512 bylo možné znovu povolit vynecháním nebo vrácením aktualizací mikrokódu.
  - **Hardwarové vypálení (fusing)** (pozdější čipy z roku 2022 a novější): AVX-512 je trvale zakázáno z výroby, což znemožňuje jeho opětovné povolení.

Protože `x86-64-v4` vyžaduje AVX-512, měly by být tyto procesory považovány pouze za **x86-64-v3**.
:::

- Ověření podpory `x86-64-v4`:
  ```sh title='Spusťte následující příkaz:'
  /lib/ld-linux-x86-64.so.2 --help | grep supported
  ```
  - ✅ `x86-64-v4 (supported, searched)` → CPU podporuje v4
  - ❌ Chybí řádek `x86-64-v4` → CPU nepodporuje v4

Příklad (CPU podporuje v4):
  ```sh
  $ /lib/ld-linux-x86-64.so.2 --help | grep supported
    x86-64-v2 (supported, searched)
    x86-64-v3 (supported, searched)
    x86-64-v4 (supported, searched)
  ```

- U procesorů AMD Zen 4/5 zkontrolujte, zda váš CPU hlásí znver4 nebo znver5:
  - Spusťte následující příkaz:
    ```sh
    gcc -march=native -Q --help=target 2>&1 | grep -Po "^\s+-march=\s+\K(\w+)\$"
    ```
    Pokud je výstupem `znver4` nebo `znver5`, můžete pokračovat v migraci.

:::note
Jak x86-64-v4, tak znver4 používají stejný seznam zrcadel `/etc/pacman.d/cachyos-v4-mirrorlist`.
:::

:::note[Pokud se potřebujete vrátit k předchozímu repozitáři nebo změnu vrátit zpět, bude se vám tento návod hodit.]
Příklad: Ze znver4 na v4.
:::

### Kroky migrace

<Steps>
1. Upravte `/etc/pacman.conf` a nahraďte své repozitáře `x86-64-v3` jedním z následujících podle podpory vašeho CPU:
    <Tabs>
        <TabItem label="x86-64-v4">
            ```ini title='/etc/pacman.conf'
            [cachyos-v4]
            Include = /etc/pacman.d/cachyos-v4-mirrorlist

            [cachyos-core-v4]
            Include = /etc/pacman.d/cachyos-v4-mirrorlist

            [cachyos-extra-v4]
            Include = /etc/pacman.d/cachyos-v4-mirrorlist
            ```
        </TabItem>

        <TabItem label="znver4 (pouze AMD Zen 4/5)">
          ```ini title='/etc/pacman.conf'
          [cachyos-znver4]
          Include = /etc/pacman.d/cachyos-v4-mirrorlist

          [cachyos-core-znver4]
          Include = /etc/pacman.d/cachyos-v4-mirrorlist

          [cachyos-extra-znver4]
          Include = /etc/pacman.d/cachyos-v4-mirrorlist
        ```
        </TabItem>
        Repozitáře `[cachyos]`, `[core]`, `[extra]` a `[multilib]` ponechte beze změny.
        </Tabs>
2. Vyčistěte mezipaměť balíčků a synchronizujte databáze:

   ```sh
   sudo pacman -Scc   # Potvrďte dvakrát stisknutím 'y'
   sudo pacman -Sy
   ```

3. Přeinstalujte všechny balíčky pro přechod na novou architekturu:

   ```sh
   pacman -Qqn | sudo pacman -S -
   ```

4. Restartujte systém.
</Steps>

## Přidání našich repozitářů do stávající instalace Arch Linuxu

:::tip
Než zvážíte přidání našich repozitářů, podívejte se na **[seznam kompatibility CPU](/cs/installation/installation_prepare#podpora-úrovně-mikroarchitektury-x86_64)**
:::

<Tabs>

<TabItem label='Automatizovaně'>

Poskytujeme skript, který automatizuje instalaci našich repozitářů do vašich stávajících instalací založených na Arch Linuxu.

```sh
curl https://mirror.cachyos.org/cachyos-repo.tar.xz -o cachyos-repo.tar.xz
tar xvf cachyos-repo.tar.xz && cd cachyos-repo
sudo ./cachyos-repo.sh
```

:::tip[Jak skript funguje]
Tento skript detekuje instrukční sady, které váš CPU podporuje, a nainstaluje tu verzi našich repozitářů, která
je pro něj nejvíce optimalizovaná. Také zálohuje váš starý soubor `pacman.conf` pro případné odstranění repozitářů pomocí skriptu.
:::

</TabItem>

<TabItem label='Manuálně'>
    :::caution
    Instalace CachyOS Pacmana nainstaluje forknutý pacman s přidanými funkcemi z CachyOS, jako je „INSTALLED_FROM“ a automatická kontrola architektury. Pacman 6.1 přidal funkci validace vlastností, která může při používání pacmana z Arch Linuxu vést k varováním. Spolupracujeme s Arch Linuxem na opětovném zajištění řádné kompatibility. Pokud se tomu chcete vyhnout, nepřidávejte repozitář „cachyos“, který obsahuje upravený pacman. Všechny ostatní repozitáře, jako cachyos-v3, cachyos-v4 a cachyos-extra/core-v3/4, je bezpečné přidat.
    :::

<Steps>

1. Nainstalujte klíčenku CachyOS:

   ```sh
   # Importujte klíč repozitáře
   sudo pacman-key --recv-keys F3B607488DB35A47 --keyserver keyserver.ubuntu.com
   # Podepište klíč repozitáře
   sudo pacman-key --lsign-key F3B607488DB35A47
   ```
2. Nainstalujte potřebné balíčky:

   ```sh
   sudo pacman -U 'https://mirror.cachyos.org/repo/x86_64/cachyos/cachyos-keyring-20240331-1-any.pkg.tar.zst' \
   'https://mirror.cachyos.org/repo/x86_64/cachyos/cachyos-mirrorlist-27-1-any.pkg.tar.zst' \
   'https://mirror.cachyos.org/repo/x86_64/cachyos/cachyos-v3-mirrorlist-27-1-any.pkg.tar.zst' \
   'https://mirror.cachyos.org/repo/x86_64/cachyos/cachyos-v4-mirrorlist-27-1-any.pkg.tar.zst' \
   'https://mirror.cachyos.org/repo/x86_64/cachyos/pacman-7.1.0.r9.g54d9411-6-x86_64.pkg.tar.zst'
   ```
3. Přidejte repozitáře CachyOS do konfiguračního souboru pacmana:
   :::note
   Tyto repozitáře by měly být umístěny nad repozitáři Arch Linuxu.
   :::

   ```ini
   # /etc/pacman.conf
   # Pokud váš CPU podporuje pouze x86-64, přidejte repozitář [cachyos]
   # cachyos repos
   [cachyos]
   Include = /etc/pacman.d/cachyos-mirrorlist

   # Pokud váš CPU podporuje x86-64-v3, přidejte [cachyos-v3],[cachyos-core-v3],[cachyos-extra-v3] a [cachyos]
   # cachyos repos

   [cachyos-v3]
   Include = /etc/pacman.d/cachyos-v3-mirrorlist
   [cachyos-core-v3]
   Include = /etc/pacman.d/cachyos-v3-mirrorlist
   [cachyos-extra-v3]
   Include = /etc/pacman.d/cachyos-v3-mirrorlist
   [cachyos]
   Include = /etc/pacman.d/cachyos-mirrorlist

   # Pokud váš CPU podporuje x86-64-v4, přidejte [cachyos-v4], [cachyos-core-v4], [cachyos-extra-v4] a [cachyos]
   # cachyos repos

   [cachyos-v4]
   Include = /etc/pacman.d/cachyos-v4-mirrorlist
   [cachyos-core-v4]
   Include = /etc/pacman.d/cachyos-v4-mirrorlist
   [cachyos-extra-v4]
   Include = /etc/pacman.d/cachyos-v4-mirrorlist
   [cachyos]
   Include = /etc/pacman.d/cachyos-mirrorlist

   # Pokud je váš CPU založen na architektuře Zen 4 nebo Zen 5, přidejte [cachyos-znver4], [cachyos-core-znver4], [cachyos-extra-znver4] a [cachyos]

   [cachyos-znver4]
   Include = /etc/pacman.d/cachyos-v4-mirrorlist
   [cachyos-core-znver4]
   Include = /etc/pacman.d/cachyos-v4-mirrorlist
   [cachyos-extra-znver4]
   Include = /etc/pacman.d/cachyos-v4-mirrorlist
   [cachyos]
   Include = /etc/pacman.d/cachyos-mirrorlist
   ```
      :::tip
   Pro přechod z repozitářů `v4` na `znver4`

   Přidejte odpovídající položky z předchozího kroku a spusťte následující příkazy:
    ```sh
    sudo pacman -Scc # V obou případech zadejte Y
    sudo pacman -Sy
    pacman -Qqn | sudo pacman -S --needed - # Nahradí všechny balíčky v4 balíčky znver4
    # Restartujte systém
    ```
   :::

4. Nakonec aktualizujte systém balíčky CachyOS:
   ```sh
   sudo pacman -Syu
   ```

</Steps>

</TabItem>

</Tabs>

### Odstranění repozitářů CachyOS

<Tabs>
<TabItem label='Automatizovaně'>

**Spusťte následující příkazy pro odstranění repozitářů CachyOS ze systému:**
```sh
curl https://mirror.cachyos.org/cachyos-repo.tar.xz -o cachyos-repo.tar.xz
tar xvf cachyos-repo.tar.xz
cd cachyos-repo
sudo ./cachyos-repo.sh --remove
```

</TabItem>

<TabItem label='Manuálně'>

<Steps>

1. Přeinstalujte původní pacman z Arch Linuxu:
   ```sh
   sudo pacman -S core/pacman
   ```
2. Spusťte následující příkaz:
   ```sh
   # Tím se vyhnete varováním %INSTALLED_DB%
   sudo find /var/lib/pacman/local/ -type f -name "desc" -exec sed -i '/^%INSTALLED_DB%$/,+2d' {} \;
   ```
3. Obnovte konfigurační soubor pacmana ze zálohy:
   ```sh
   sudo mv /etc/pacman.conf.bak /etc/pacman.conf
   ```
4. Přepněte zpět na výchozí balíčky Arch Linuxu pomocí následujících příkazů:
   ```sh
   pacman -Qqn | sudo pacman -S -
   sudo pacman -Syu
   ```
</Steps>

</TabItem>
</Tabs>

## Testy a benchmarky

Michael z Phoronixu již několikrát provedl benchmarky CachyOS, které se většinou ukázaly jako vedoucí v grafech benchmarků a v geometrickém průměru všech výsledků testů.
Od prvního benchmarku v roce 2022 se CachyOS výrazně vyvinul a dospěl v oblasti použitelnosti a výkonu.

Pokud se chcete dozvědět více o nárůstu výkonu díky našim repozitářům, podívejte se na níže uvedené odkazy.

* **14/03/2021:** V diskusi RFC o dopadu x86-64-v3, kterou zahájil **Mateusz Jończyk** z Arch Linuxu, se ukázaly počáteční výsledky.
  * [RFC: Use x86_64-v2 architecture](https://lists.archlinux.org/pipermail/arch-general/2021-March/048739.html)

* **09/12/2022:** První benchmark provedený Michaelem.
  * [The Performance Of Arch Linux Powered CachyOS](https://www.phoronix.com/review/cachyos-linux-perf)

* **29/02/2024:** Phoronix provedl další benchmark ukazující rozdíl mezi balíčky x86-64-v4, x86-64-v3 a x86-64 (obecné). Na příkladech jako PHP nebo GCC, kde upravujeme naše soubory PKGBUILD, je patrné výrazné zlepšení výkonu.
  * [Arch Linux CachyOS Benchmarks Of x86-64-v3 & x86-64-v4 Repositories](https://www.phoronix.com/review/cachyos-x86-64-v3-v4)

* **20/08/2024:** Michael zveřejnil nový benchmark pro procesor AMD Ryzen 9950x, který zahrnuje CachyOS a některé další linuxové distribuce.
  * [Intel Continues To Show AMD The Importance Of Software Optimizations: 16% More Ryzen 9 9950X Performance](https://www.phoronix.com/review/linux-os-amd-ryzen9-9950x)
   :::note
   Liquid-DSP a RocksDB byly kompilovány pomocí Phoronix Benchmark Suite, přičemž byly ignorovány příznaky kompilace zadané v /etc/makepkg.conf, což vedlo k neočekávaným výsledkům výkonu pro CachyOS.
   :::
