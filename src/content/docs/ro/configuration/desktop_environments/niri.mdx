:::note
Niri este un compozitor Wayland de tip scrollable-tiling (mozaic derulabil) care oferă o abordare unică a gestionării ferestrelor cu sistemul său de layout bazat pe coloane.
:::

Scopul nostru principal cu configurarea noastră este să avem o setare Niri funcțională care să ofere o experiență desktop fluidă și intuitivă, păstrând în același timp configurația simplă și accesibilă.

Aruncă o privire în [FAQ-ul nostru Niri.](/ro/configuration/desktop_environments/niri#faq)

**Dotfiles menținute de [Ly-sec](https://github.com/Ly-sec)**
Pentru probleme legate de Noctalia, te rugăm să consulți [documentația Noctalia](https://docs.noctalia.dev/).

## Scurtături de tastatură

Majoritatea combinațiilor de taste necesită utilizarea tastei mod, care în cazul nostru este tasta Windows (referită ca SUPER); o poți schimba în fișierul de configurare.

### Controlul Aplicațiilor

| Descriere | Tastă |
|-----------|-------|
| Deschide terminalul | <Kbd linux="Super+Return" /> |
| Deschide lansatorul de programe | <Kbd linux="Super+Ctrl+Return" /> |
| Deschide browserul (Firefox) | <Kbd linux="Super+B" /> |
| Deschide managerul de fișiere | <Kbd linux="Super+E" /> |
| Închide fereastra focalizată | <Kbd linux="Super+Q" /> |
| Blochează ecranul | <Kbd linux="Super+Alt+L" /> |

## FAQ

### Ce face Niri diferit de alți manageri de ferestre?

Niri folosește o abordare unică de tip scrollable-tiling în care ferestrele sunt aranjate în coloane care pot fi derulate orizontal. Acest lucru oferă o metaforă de desktop infinit, care este utilă în special pentru monitoarele ultrawide și fluxurile de lucru care necesită multe aplicații deschise.

### Cum schimb aranjamentul tastaturii (keyboard layout)?

Editează secțiunea `input` din fișierul tău de configurare:

```txt title='Exemplu'
input {
    keyboard {
        xkb {
            layout "ro" // Schimbă din "us" în layout-ul tău preferat
        }
    }
}
```

### Pot personaliza golurile (gaps) și aspectul ferestrelor?

Da, poți modifica secțiunea `layout`:

```txt title='Exemplu'
layout {
    gaps 8 // Schimbă dimensiunea spațiului dintre ferestre

    focus-ring {
        width 2
        active-color "#culoarea-ta"
        inactive-color "#culoarea-ta"
    }
}
```

### Cum adaug mai multe aplicații la pornire?

Adaugă-le în secțiunea `startup`:

```txt title='Exemplu'
spawn-at-startup "aplicatia-ta"
```

### Pentru ce este tasta de evacuare de urgență (emergency escape)?

Combinația `Super+Escape` este concepută pentru a restaura controlul atunci când o aplicație fullscreen îți blochează scurtăturile de taste. Aceasta dezactivează orice inhibitor activ al scurtăturilor de tastatură.

### Cum configurez monitoare multiple?

Decomentează și modifică secțiunea `output` pentru afișajele tale specifice. Rulează `niri msg outputs` pentru a obține numele corecte:

```txt title='Exemplu'
output "DP-1" {
    mode "1920x1080@60.000"
    scale 1
}
```
