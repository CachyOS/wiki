## Cum se instalează sesiunea X11 lipsă

După ce KDE a decis să își împartă dezvoltarea în mai multe pachete, sesiunea X11 a fost eliminată din instalarea implicită.

```sh
sudo pacman -S plasma-x11-session kwin-x11
```

## FAQ

### Cum pot obține același aspect ca cel prezentat în capturile de ecran KDE, numit „Emerald”?

- Este o combinație între Tema Emerald + Tema de pictograme Qogir, care nu sunt instalate implicit.
  - ```sh title='Instalează-le pe ambele cu următoarea comandă'
    sudo pacman -S cachyos-emerald-kde-theme-git qogir-icon-theme
    ```
  Aplică-le pe ambele în `Appearance & Style - Colors & Themes`

### De ce arată SDDM atât de fad și de vechi?

- *Deoarece nicio temă SDDM nu este aplicată implicit, SDDM va folosi tema clasică.*
