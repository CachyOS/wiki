## systemd-boot

systemd-boot are două tipuri de fișiere de configurare: unul pentru systemd-boot în sine în `/boot/loader/loader.conf`, și unul pentru fiecare intrare de kernel individuală în `/boot/loader/entries`.

### Configurarea Loader-ului

În acest fișier de configurare, poți schimba intrarea implicită și timpul de așteptare (timeout) al systemd-boot.

```shell
# /boot/loader/loader.conf

default @saved
timeout 5
#console-mode keep # Această opțiune configurează rezoluția consolei.
```

### Configurarea Liniei de Comandă a Kernelului

Oferim o unealtă pentru configurarea mai ușoară a systemd-boot: [`sdboot-manage`](https://github.com/CachyOS/CachyOS-PKGBUILDS/tree/master/systemd-boot-manager).
Unul dintre avantajele acestei unelte este configurarea globală a liniei de comandă a kernelului. Fișierul de configurare pentru `sdboot-manage` se află în `/etc/sdboot-manage.conf`.

Editează linia `LINUX_OPTIONS=` în `/etc/sdboot-manage.conf` pentru a schimba parametrii de kernel.

```shell
# /etc/sdboot-manage.conf
LINUX_OPTIONS="zswap.enabled=0 nowatchdog quiet splash"
```

După ce ai făcut modificări, regenerează toate intrările systemd-boot cu următoarea comandă:

```shell
sudo sdboot-manage gen
```

## rEFInd

La fel ca [systemd-boot](/ro/configuration/boot_manager_configuration#systemd-boot), rEFInd are două fișiere de configurare. `refind.conf` situat în
`boot/efi/EFI/refind` este în principal pentru schimbarea modului în care se comportă rEFInd, în timp ce `/boot/refind_linux.conf` este pentru gestionarea opțiunilor de boot.
`refind.conf` conține comentarii extinse care explică toate opțiunile sale.

### Configurarea Liniei de Comandă a Kernelului

Pentru a transmite parametri de kernel liniei de comandă, modifică "Boot using default options" în `/boot/refind_linux.conf`.

```shell
# /boot/refind_linux.conf

"Boot using default options"     "root=PARTUUID=1cb353ec-7f03-4820-8b4b-03baf53a208f rw zswap.enabled=0 nowatchdog quiet splash"
```

Modificările ambelor fișiere de configurare vor intra în vigoare imediat. Rularea unei comenzi pentru a „salva” modificările nu este necesară.

## GRUB

Spre deosebire de [systemd-boot](/ro/configuration/boot_manager_configuration#systemd-boot) și [rEFInd](/ro/configuration/boot_manager_configuration#refind),
GRUB are un singur fișier de configurare situat în `/etc/default/grub`. Există o documentație destul de bună în acest fișier care explică ce
face fiecare opțiune.

### Ascunderea Meniului de Boot GRUB

Pentru a ascunde meniul GRUB, pur și simplu setează următoarele opțiuni în mod corespunzător.

```shell
# /etc/default/grub

GRUB_TIMEOUT='0'
GRUB_TIMEOUT_STYLE=hidden
```

Apasă ESC pentru a obține acces la promptul GRUB. De aici rulează `normal` sau `exit` pentru a te întoarce la meniul familiar de boot GRUB.

### Configurarea Liniei de Comandă a Kernelului

Pentru a transmite parametri de kernel liniei de comandă cu GRUB, trebuie să edităm `GRUB_CMDLINE_LINUX_DEFAULT` în interiorul `/etc/default/grub`.

```shell
# /etc/default/grub

GRUB_CMDLINE_LINUX_DEFAULT='nowatchdog zswap.enabled=0 quiet splash'
```

De fiecare dată când modificăm fișierul de configurare GRUB, trebuie să refacem configurația cu următoarea comandă:

```shell
sudo grub-mkconfig -o /boot/grub/grub.cfg
```

### Snapshot-uri BTRFS bootabile

:::note
Dacă instalarea ta CachyOS este dinainte de versiunea din august, s-ar putea să fie nevoie să activezi manual funcția de snapshot-uri BTRFS bootabile.

Altfel, poți sări peste această secțiune, deoarece funcția a fost activată implicit începând cu versiunea din august.
:::

Pentru a activa funcția, instalează pachetul `grub-btrfs-support`:

```sh
sudo pacman -S grub-btrfs-support
```

Acest pachet instalează scripturile și hook-urile necesare pentru a detecta automat snapshot-urile BTRFS și a le adăuga în meniul GRUB.

Odată instalat, snapshot-urile tale vor apărea în meniul GRUB, similar cu comportamentul Limine.


## Limine

Limine este un bootloader modern cunoscut pentru configurația sa simplă. Acest ghid acoperă elementele de bază pentru a începe.

Configurarea are loc în principal în `/boot/limine.conf` (sau uneori în partiția de sistem EFI) pentru setările meniului și în `/etc/default/limine` pentru parametrii de kernel.

### Configurarea Meniului de Boot

Acest fișier controlează comportamentul și aspectul meniului de boot. Modificările făcute aici intră în vigoare imediat după salvare – nu sunt necesare comenzi suplimentare.

* **Timeout:** Setează câte secunde așteaptă Limine înainte de a boota automat intrarea implicită.

  ```shell
  # /boot/limine.conf

  timeout: 5
  ```

* **Intrarea Implicită:** Specifică care intrare din meniu bootează implicit. Intrările sunt numerotate începând de la 1. Dacă nu este setată, valoarea implicită este 1.

  ```shell
  # /boot/limine.conf

  default_entry: 2 # Bootează a doua intrare implicit
  ```

  :::tip
   Dacă `default_entry` indică un director (ex. `/+CachyOS`), pornirea automată va fi dezactivată. Pentru a boota automat o intrare dintr-un director, `default_entry` trebuie să indice direct numărul acelei intrări specifice.
  :::

Exemplu (`/boot/limine.conf`):

```shell
# /boot/limine.conf

timeout: 5
default_entry: 2 # Indică direct intrarea 'linux-cachyos' de mai jos

/+CachyOS        # Intrarea 1: Un director (folosește /+ pentru a-l extinde implicit)
//linux-cachyos  # Intrarea 2: Intrarea efectivă bootabilă
    protocol: linux
    kernel_path: boot():/vmlinuz-linux-cachyos
    cmdline: quiet splash root=UUID=... rw # Parametri de kernel de bază
    module_path: boot():/initramfs-linux-cachyos.img
```

:::note
`boot():/` se referă la rădăcina unității de boot.
:::

### Tematizare

Poți personaliza aspectul vizual al meniului de boot Limine:

* **Tapet (Wallpaper):** Setează o imagine de fundal. Formatele suportate includ BMP, PNG și JPEG.

  ```shell
  # /boot/limine.conf

  wallpaper: boot():/splash.png
  wallpaper_style: stretched # Opțiuni: 'stretched', 'tiled', 'centered'
  backdrop: 000000           # Culoarea de fundal (hex RRGGBB) dacă stilul este 'centered'
  ```

* **Fonturi:** Folosește un [fișier de font personalizat](https://github.com/viler-int10h/vga-text-mode-fonts) și ajustează-i dimensiunea.

  ```shell
  # /boot/limine.conf

  term_font: boot():/custom_font.F16
  term_font_scale: 2x2 # Scalează dimensiunea fontului, util pentru ecrane de înaltă rezoluție
  ```

* **Culori:** Modifică culorile textului și ale fundalului terminalului.

  ```shell
  # /boot/limine.conf

  term_background: 80000000 # Exemplu: Negru semi-transparent (AARRGGBB)
  # Sunt disponibile și alte opțiuni de culoare precum term_foreground etc.
  ```

### Configurarea Comenzii Kernelului

În CachyOS, intrările de kernel din meniul de boot Limine sunt **gestionate automat**. Când instalezi sau elimini kerneluri, hook-ul `limine-mkinitcpio-hook` folosește utilitarul `limine-entry-tool` în fundal pentru a actualiza intrările de boot.

Deși intrările sunt gestionate automat, poți **configura parametrii de kernel** (cunoscuți și sub numele de kernel command line) care sunt transmiși kernelului la pornire.

1. **Editează fișierul de configurare:** Modifică variabilele `KERNEL_CMDLINE` în `/etc/default/limine`. Poți seta parametri impliciți pentru toate kernelurile sau parametri specifici pentru anumite nume de kernel (ex. `linux-cachyos`).

   ```shell
   # /etc/default/limine

   # Parametri impliciți pentru majoritatea kernelurilor
   KERNEL_CMDLINE[default]="quiet splash rd.udev.log_priority=3"

   # Parametri specifici pentru kernelul 'linux-cachyos'
   KERNEL_CMDLINE["linux-cachyos"]="quiet splash mitigations=off"

   # Parametri pentru intrările fallback (dacă sunt generate)
   # KERNEL_CMDLINE[fallback]="..."
   ```

2. **Aplică modificările:** După salvarea `/etc/default/limine`, trebuie să regenerezi imaginile initramfs și să actualizezi intrările Limine pentru a aplica noii parametri de kernel. Rulează următoarea comandă:

   ```bash
   sudo limine-mkinitcpio
   ```

   Această comandă declanșează procesul `mkinitcpio`, care include `limine-mkinitcpio-hook`, asigurându-te că modificările tale din `/etc/default/limine` sunt încorporate în intrările de boot din `/boot/limine.conf`.
