## Surse Oficiale pentru ISO

Imaginea ISO CachyOS poate fi obținută din următoarele surse:

*   [Pagina web](<https://cachyos.org/download>)
*   [SourceForge](<https://sourceforge.net/projects/cachyos-arch/files/>)
*   [Mirror CachyOS](<https://mirror.cachyos.org/ISO/>)

## Verificarea integrității ISO cu SHA256

:::caution
Fă-ți mereu timp pentru pasul suplimentar de verificare a integrității imaginii ISO, pentru a evita orice probleme nedorite în timpul instalării sau în timpul creării unui mediu de boot.
:::

**Versiunea curentă ISO:** `260124`

**Hash SHA256:** `0c070fba1eb06a740983e8e195ecb686c4fc2060920137af1cedbd5ffca5be47`

<Tabs>

<TabItem label='Windows'>

<Steps>

1. Descarcă [fișierul](https://mirror.cachyos.org/ISO/desktop/260124/cachyos-desktop-linux-260124.iso.sha256) care conține hash-ul SHA256 **(Deschide-l cu un editor de text, de exemplu, Notepad)**.
2. Deschide CMD sau PowerShell ca Administrator și [navighează](<https://www.wikihow.com/Change-Directories-in-Command-Prompt>) către calea unde sunt stocate fișierele ISO și SHA256.
3. Execută următoarea comandă:
   ```powershell
   # Exemplu:
   certUtil -hashfile cachyos-desktop-linux-260124.iso SHA256
   ```
4. Compară hash-ul generat de certUtil cu cel din fișierul descărcat la **Pasul 1**. Dacă acestea coincid, poți continua cu instalarea CachyOS.

</Steps>

</TabItem>

<TabItem label='Linux'>

<Steps>

1. Descarcă [fișierul](https://mirror.cachyos.org/ISO/desktop/260124/cachyos-desktop-linux-260124.iso.sha256) care conține hash-ul SHA256.
2. Deschide un terminal, navighează în directorul care conține fișierul `.sha256` și execută următoarele comenzi:
   ```sh
   # Exemplu:
   cd ~/Downloads
   cat cachyos-desktop-linux-260124.iso.sha256
   # 0c070fba1eb06a740983e8e195ecb686c4fc2060920137af1cedbd5ffca5be47
   ```
3. Compară rezultatul de la **Pasul 2** cu hash-ul fișierului ISO:
   ```sh
   # Exemplu:
   sha256sum cachyos-desktop-linux-260124.iso
   ```
4. Dacă hash-urile de la **Pasul 2** și **Pasul 3** coincid, poți continua cu instalarea CachyOS.

</Steps>

</TabItem>

<TabItem label='macOS'>

<Steps>

1. Descarcă [fișierul](https://mirror.cachyos.org/ISO/desktop/260124/cachyos-desktop-linux-260124.iso.sha256) care conține hash-ul SHA256.
2. Deschide un terminal, navighează în directorul care conține fișierul `.sha256` și execută următoarele comenzi:
   ```sh
   # Exemplu:
   cd Downloads/
   cat cachyos-desktop-linux-260124.iso.sha256
   # 0c070fba1eb06a740983e8e195ecb686c4fc2060920137af1cedbd5ffca5be47
   ```
3. Compară rezultatul de la **Pasul 2** cu hash-ul fișierului ISO:
   ```sh
   # Exemplu:
   shasum -a 256 cachyos-desktop-linux-260124.iso
   ```
4. Dacă hash-urile de la **Pasul 2** și **Pasul 3** coincid, poți continua cu instalarea CachyOS.

</Steps>

</TabItem>

## Verificarea autenticității imaginii ISO (Linux)

Pentru a verifica autenticitatea fișierului ISO:

<Steps>

1. Importă cheia GPG ca referință pentru comparare:

   ```shell
   gpg --keyserver hkps://keys.openpgp.org --recv-key F3B607488DB35A47
   ```

2. Descarcă fișierul ISO și fișierul său de semnătură [.sig](https://cdn77.cachyos.org/ISO/desktop/260124/cachyos-desktop-linux-260124.iso.sig) și rulează următoarea comandă (înlocuiește `nume_complet_iso.iso` cu numele real al fișierului ISO):
   ```shell
   gpg --verify nume_complet_iso.iso.sig nume_complet_iso.iso
   ```

   Dacă primești un mesaj de tipul **Good signature**, fișierul ISO este autentic:
   ```
   gpg: Signature made sáb 24 ene 2026 12:16:37 -03
   gpg:                using RSA key 882DCFE48E2051D48E2562ABF3B607488DB35A47
   gpg: Good signature from "CachyOS <admin@cachyos.org>" [unknown]
   gpg: WARNING: This key is not certified with a trusted signature!
   gpg:          There is no indication that the signature belongs to the owner.
   Primary key fingerprint: 882D CFE4 8E20 51D4 8E25  62AB F3B6 0748 8DB3 5A47
   ```

</Steps>

:::danger
Dacă rezultatul nu conține șirul **Good signature** sau dacă ID-ul cheii nu coincide, nu folosi imaginea ISO. O semnătură greșită sugerează că fișierul ISO a fost modificat sau este corupt.

Asigură-te că imaginea descărcată provine dintr-o [sursă CachyOS legitimă](/ro/cachyos_basic/download#surse-oficiale-pentru-iso).
:::
