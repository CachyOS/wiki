---
title: Regulile Comunității Oficiale CachyOS
description: Discord, Reddit, Twitter, Forum
---

Încălcarea acestor reguli nu este permisă și va duce la interzicerea (ban) contului:

1. Este interzisă insultarea participanților la comunitate.
2. Este interzisă incitarea la ură etnică.
3. Este interzisă postarea de materiale pornografice.
4. Discutarea subiectelor politice este interzisă atunci când scapă de sub control.
5. Discutarea subiectelor religioase este interzisă.
6. Este interzisă publicitatea pentru alte resurse fără acordul administrației.
7. Este interzisă uzurparea identității unei alte persoane (impersonarea).
8. Este interzis flood-ul (publicarea aceluiași tip de informație de mai multe ori la rând).
9. Este interzisă provocarea conflictelor între participanți.
10. Acesta este un spațiu sigur pentru LGBTQ+ și, prin urmare, este interzisă provocarea și insultarea persoanelor LGBTQ+.

Încălcarea acestor reguli va rezulta în timeout-uri, putând escalada până la interzicerea contului pentru abateri repetate:

1. Folosirea altor limbi decât engleza pentru comunicare este interzisă, cu excepția cazului în care conversația este de tip „small-talk” sau există un canal dedicat pentru acea limbă.
