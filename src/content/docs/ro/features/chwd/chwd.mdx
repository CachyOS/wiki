[CachyOS Hardware Detection](https://github.com/CachyOS/chwd/) (cunoscut sub numele de `chwd`) ne permite să susținem o varietate de componente hardware prin instalarea pachetelor și driverelor necesare pentru sistemul curent. Aceasta include sisteme care rulează plăci grafice NVIDIA, MacBook-uri cu procesor T2 și dispozitive portabile (handheld) precum Steam Deck și ROG Ally.

## Utilizare

`chwd` este de obicei rulat în timpul procesului de instalare pentru a furniza pachetele necesare sistemului. Totuși, este posibil să îl folosești și după instalare.

### Configurare Automată

`chwd` suportă instalarea și configurarea driverelor și pachetelor necesare astfel încât sistemul să funcționeze în condiții optime.

```sh
sudo chwd -a
```

### Altele

Consultă mesajul de ajutor al `chwd` pentru sintaxa comenzilor și alte moduri de utilizare.

```sh
chwd --help
Usage: chwd [OPTIONS]

Options:
  -i, --install <profile>          Install profile
  -r, --remove <profile>           Remove profile
  -d, --detail                     Show detailed info for listings
  -f, --force                      Force reinstall
      --list-installed             List installed kernels
      --list                       List available profiles for all devices
      --list-all                   List all profiles
  -a, --autoconfigure [<classid>]  Autoconfigure
      --ai_sdk                     Toggle AI SDK profiles
      --pmcachedir <PMCACHEDIR>    [default: /var/cache/pacman/pkg]
      --pmconfig <PMCONFIG>        [default: /etc/pacman.conf]
      --pmroot <PMROOT>            [default: /]
  -h, --help                       Print help
  -V, --version                    Print version
```
