[cachy-chroot](https://github.com/CachyOS/cachy-chroot) este un program simplu de ajutor pentru a ușura procesul de intrare în chroot într-o instalare existentă
de CachyOS sau bazată pe Arch. Acesta listează toate partițiile descoperite pe mașină și suportă, de asemenea, listarea subvolumelor BTRFS.
Nu în ultimul rând, `cachy-chroot` suportă și sisteme criptate prin LUKS. Va mapa fiecare intrare `fstab` la intrările sale `crypttab`
desemnate și va închide cu grație toate volumele LUKS la ieșirea din chroot.

:::caution[cachy-chroot este destinat să fie rulat dintr-un mediu live CachyOS.]
:::

:::note
cachy-chroot suportă montarea aproape oricărui sistem de fișiere suportat de kernelul Linux, cu excepția ZFS.
:::

## Utilizare

:::tip
Folosește tastele săgeată pentru a naviga prin opțiuni și `ENTER` pentru a selecta.

Simbolul **❯** indică opțiunea selectată curent.

**?** indică o solicitare de introducere a datelor de către utilizator.
:::

<Steps>
1. Bootează într-un ISO live CachyOS
2. Deschide un terminal și intră ca utilizator root cu `sudo su`
3. Asigură-te că ai instalată cea mai recentă versiune `cachy-chroot` rulând:
    ```bash
    pacman -Sy cachy-chroot
    ```
4. Rulează `cachy-chroot` tastând:
    ```bash
    cachy-chroot
    ```
    `cachy-chroot` va scana și va lista toate partițiile disponibile.

6. `cachy-chroot` va încerca să monteze automat toate partițiile și subvolumele listate sub `/etc/fstab` de pe dispozitivul root. Dacă montarea vreunei partiții eșuează, vei fi notificat și vei avea opțiunea de a le monta manual dacă este necesar. Poți alege `no` pentru a omite montarea partițiilor suplimentare.
7. **Acum ești în mediul chroot**.
    ```bash
    [root@CachyOS /]#
    ```
    Acum poți rula comenzi ca și cum ai fi pornit sistemul instalat. De exemplu, poți actualiza sistemul cu:
    ```bash title="Actualizarea sistemului în chroot"
    pacman -Syu
    ```
    sau poți efectua alte sarcini de întreținere după cum este necesar.
8. Când ai terminat, ieși din mediul chroot scriind `exit` la prompt sau apăsând `CTRL+D` pe tastatură.
    ```bash title="Ieșirea din chroot"
    exit
    ```
9. După ieșire, `cachy-chroot` va curăța automat partițiile montate și va închide orice containere LUKS. Te vei întoarce în consola mediului live.
</Steps>

### Depanare

- **Nu au fost găsite partiții:** Asigură-te că discul care conține instalarea ta este conectat și recunoscut de sistemul live. Poți verifica cu `lsblk` sau `fdisk -l`.
- **Montarea automată eșuează pentru unele partiții:** Poți încerca să le montezi manual din interiorul mediului chroot. `cachy-chroot` va ignora eșecurile și va continua.

### Întrebări frecvente (FAQ)

- **Î: La ce folosește montarea partițiilor suplimentare?**
  - R: Există mai multe cazuri de utilizare pentru montarea manuală a partițiilor suplimentare, inclusiv:
    - **Fișier fstab corupt sau lipsă:** Poți monta manual partițiile necesare (precum `/boot` sau `/home`) pentru a efectua reparații sau recuperarea datelor.
    - **UUID-uri de partiție actualizate:** Dacă sistemul tău nu pornește pentru că ai schimbat UUID-ul unei partiții, poți folosi `cachy-chroot` pentru a monta partițiile și apoi să actualizezi fstab corespunzător.
