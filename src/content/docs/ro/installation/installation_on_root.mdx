## Înainte de a începe

:::note
Dacă primești doar GRUB și Limine ca opțiuni pentru managerul de boot după ce apeși pe **Launch Installer**, înseamnă că sistemul este pornit în modul Legacy/BIOS.
:::

:::note[Instalarea mai multor medii desktop nu este permisă în timpul procesului de instalare.]
:::

:::caution[Secure Boot și CSM trebuie să fie dezactivate în setările BIOS/UEFI atunci când instalezi în modul UEFI.]
Pentru a configura Secure Boot după instalare, consultă secțiunea [Secure Boot](/ro/configuration/secure_boot_setup).

Opțiunea `Legacy USB Support` ar trebui să fie setată pe `Auto`.
:::

:::caution
Opțiunile `Install alongside` și `Replace partition` nu sunt 100% fiabile și pot duce la eșecul instalării.

**Partiționarea manuală** este puternic preferată atunci când instalezi CachyOS.
:::

:::tip
Este recomandat cu tărie să repornești de pe imaginea ISO după o încercare de instalare eșuată.

Altfel, pot apărea erori continue în timpul procesului de instalare.

Acest lucru se întâmplă deoarece instalatorul nu demontează corect partițiile în cazul unei instalări eșuate.
:::

## Metode de Instalare

### Partiționare Manuală

:::note[Înainte de a continua cu partiționarea discului pentru o instalare UEFI.]
    ```sh title='Execută această comandă în terminal'
    efibootmgr -v
    ```
Dacă rezultatul este `EFI variables are not supported on this system.`, atunci sistemul este pornit în modul Legacy/BIOS și trebuie să te asiguri că modul UEFI este configurat în setările BIOS/UEFI. Consultă secțiunea [Cerințe](/ro/installation/installation_on_root/#înainte-de-a-începe).
:::

<TabItem label='systemd-boot & rEFInd'>

<Steps>

1. Pornește de pe imaginea ISO și apasă pe **Launch Installer**.

2. Setează **Limba** și **Regiunea/Fusul orar** preferate.

3. Configurează **Aranjamentul tastaturii**.

4. Selectează **Manual partitioning**.

5. Creează o partiție nouă cu următoarele setări:
   - ##### Dimensiune: **2048 MiB**
   - ##### Sistem de fișiere: **FAT32**
   - ##### Punct de montare: **/boot**
   - ##### Flag-uri: **boot**

6. Creează o altă partiție pentru **root**:
   - ##### Dimensiune: Cel puțin **20000 MiB**
   - ##### Sistem de fișiere: **Oricare**, consultă [Sisteme de fișiere](/ro/installation/filesystem)
   - ##### Punct de montare: **/**
   - ##### Flag-uri:

7. Selectează [Mediul Desktop](/ro/installation/desktop_environments) dorit.

8. Alege ce pachete ar trebui să fie instalate în timpul procesului de instalare.

9. Configurează datele de autentificare (utilizator și parolă).

10. Revizuiește cu atenție rezumatul instalării. Continuă instalarea apăsând pe **Install Now** dacă totul pare corect. Altfel, mergi înapoi și fă modificările necesare.

</Steps>

### Erase Disk

<Steps>

1. Pornește de pe imaginea ISO și apasă pe **Launch Installer**.

2. Selectează [Managerul de Boot](/ro/installation/boot_managers) preferat.

4. Configurează **Aranjamentul tastaturii**.

5. Selectează **Erase Disk** și alege un [Sistem de fișiere](/ro/installation/filesystem).

6. Selectează [Mediul Desktop](/ro/installation/desktop_environments) dorit.

7. Alege ce pachete ar trebui să fie instalate în timpul procesului de instalare.

8. Configurează datele de autentificare.

</Steps>

## Dual Boot între Windows și CachyOS

:::note[Acest ghid presupune că Windows este deja instalat pe sistem și ai decis să instalezi CachyOS pe lângă el, pe același disc.]
:::

:::caution
Dual boot-ul între Windows și Linux nu este 100% fiabil. Actualizările de Windows pot strica bootloader-ul prin suprascrierea partiției EFI.
În unele cazuri, problemele pot să nu apară niciodată, dar pentru unii utilizatori poate fi o problemă recurentă.

O modalitate de a evita această problemă este instalarea fiecărui sistem de operare pe discuri separate.
:::

:::caution
Partiția EFI ar putea trebui redimensionată, în funcție de dimensiunea minimă recomandată pentru managerul de boot ales. Consultă [Partiționarea Manuală](/ro/installation/installation_on_root#partiționare-manuală).

Sistemele de fișiere FAT nu pot fi redimensionate „pe loc”. Pentru a „redimensiona” corect partiția EFI FAT, trebuie să faci o copie de rezervă a sistemului de fișiere EFI existent, să folosești o unealtă precum `gparted` pentru a redimensiona partiția existentă și a reformata noua partiție, apoi să recopiezi structura anterioară a sistemului de fișiere înapoi în partiția EFI.
:::

### Cerințe preliminare

- Opțiunile Windows Fast Startup și Hibernation trebuie să fie dezactivate.
  - Deschide Windows Powershell ca administrator și execută următoarea comandă:
      ```ps
      powercfg /H off
      ```
    Repornește sistemul pentru a te asigura că modificările au intrat în vigoare.
- Windows BitLocker trebuie să fie dezactivat.
  - Verificarea dacă BitLocker este activat:
    ```ps title='Deschide un Command Prompt ca administrator și execută următoarea comandă'
    manage-bde -status
    ```
  Dacă **Encryption Method** apare ca `None`, atunci BitLocker este dezactivat.
- Secure Boot trebuie să fie dezactivat.
- O partiție goală de ≥30 GB.
  - Ghid despre cum să micșorezi o partiție Windows:
    - Apasă `Win + R`, tastează `diskmgmt.msc` și apasă Enter pentru a deschide Disk Management.
    - Identifică partiția principală de Windows (de obicei C:) și fă click dreapta pe ea.
    - Apasă pe `Shrink Volume...`, specifică cel puțin **30720 MB** (30 GiB) și apasă pe `Shrink`.
- Un stick USB bootabil cu CachyOS.
  - Consultă secțiunea [Crearea unui stick USB bootabil cu CachyOS](/ro/installation/installation_prepare#crearea-unui-stick-usb-bootabil-cu-cachyos).

<Tabs>
    <TabItem label='systemd-boot'>
        **Trebuie să copiem binarele EFI de Windows în partiția EFI de Linux, astfel încât managerul de boot să le poată recunoaște.**

        <Steps>
        1. Localizează **partiția EFI de Windows** cu `lsblk`.

            ```sh title='Execută această comandă în terminal'
            lsblk -o NAME,FSTYPE,SIZE,MOUNTPOINT
            ```
            ```sh title='Exemplu de rezultat'
                        NAME        FSTYPE   SIZE MOUNTPOINT
            zram0               15.3G [SWAP]
            nvme0n1            476.9G
            ├─nvme0n1p1 vfat     100M
            ├─nvme0n1p2           16M
            ├─nvme0n1p3 ntfs   234.4G
            ├─nvme0n1p4 ntfs     830M
            ├─nvme0n1p5 vfat       2G /boot
            └─nvme0n1p6 btrfs  239.6G /var/tmp
            ```
            Partițiile EFI sunt aproape întotdeauna formatate ca `FAT32/vfat`. Deoarece `nvme0n1p1` nu are un punct de montare Linux, putem presupune că această partiție este partiția EFI de Windows.

        2. Montează temporar partiția EFI de Windows.

            ```sh
            sudo mkdir /mnt/WinBoot
            sudo mount /dev/nvme0n1p1 /mnt/WinBoot # Înlocuiește `nvme0n1p1` cu numele partiției EFI de Windows.
            ```

        3. Copiază binarele EFI din **partiția EFI de Windows** în **partiția EFI de Linux**.

            ```sh
            sudo cp -r /mnt/WinBoot/EFI/Microsoft/ /boot/EFI
            ```

        4. Demontează partiția montată anterior. Windows ar trebui să apară în meniul de boot la următoarea pornire.

            ```sh
            sudo umount /mnt/WinBoot
            sudo rm -r /mnt/WinBoot
            ```

        </Steps>
    </TabItem>

    <TabItem label='GRUB'>
        **GRUB folosește os-prober pentru a detecta automat partiția EFI de Windows și a o adăuga în meniul de boot.**

        <Steps>
        1. Instalează **os-prober**.

            ```sh
            sudo pacman -S os-prober
            ```

        2. Activează **os-prober** în fișierul de configurare GRUB.

            ```sh title='Apasă CTRL+S pentru a salva și CTRL+Q pentru a ieși din Micro'
            sudo micro /etc/default/grub
            # /etc/default/grub
            # Probing for other operating systems is disabled for security reasons. Read
            # documentation on GRUB_DISABLE_OS_PROBER, if still want to enable this
            # functionality install os-prober and uncomment to detect and include other
            # operating systems.
            GRUB_DISABLE_OS_PROBER=false

            ```

        3. Actualizează grub.cfg, folosind acum **os-prober**.
            ```sh
            sudo grub-mkconfig -o /boot/grub/grub.cfg
            ```

            **Windows ar trebui să fie acum adăugat în meniul de boot.**

        </Steps>
    </TabItem>
</Tabs>
