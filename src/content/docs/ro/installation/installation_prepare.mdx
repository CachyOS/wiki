## Cerințe de sistem

Înainte de a pregăti instalarea, asigură-te că computerul utilizat îndeplinește cerințele minime de sistem pentru a rula CachyOS. Instalatorul
folosește un proces de instalare online, deci o conexiune la internet stabilă și relativ rapidă este obligatorie.

:::note[Mașini Virtuale]
Nu se recomandă instalarea CachyOS pe o mașină virtuală. VM-urile pot avea probleme din cauza configurării incorecte sau pot fi complet nefuncționale. Se recomandă instalarea CachyOS direct pe hardware (bare metal).
:::

<Tabs>

<TabItem label="Cerințe minime">

*   3 GB RAM
*   30 GB spațiu de stocare (HDD/SSD)
*   Conexiune stabilă la internet

:::caution
Un internet instabil poate duce la timpi de instalare prelungiți sau, în cel mai rău caz, la eșecul instalării.
:::

</TabItem>

<TabItem label="Cerințe recomandate">

*   8 GB RAM
*   50 GB spațiu de stocare (SSD/NVMe)
*   [Procesor capabil x86-64-v3](/ro/installation/installation_prepare#suport-pentru-nivelul-de-microarhitectură-x86_64)
*   Viteză de internet de 50 Mbps sau mai bună
*   GPU NVIDIA (900+ - ex: GTX 950), AMD +GCN 1.0 (ex: AMD R7 240) sau Intel (seria Integrated HD Graphics sau superioară. Seria Arc)

</TabItem>

</Tabs>

## Crearea unui stick USB bootabil cu CachyOS

Există mai multe unelte și metode care pot fi folosite pentru a crea un stick USB bootabil cu CachyOS.

:::tip
Păstrează o copie a imaginii ISO CachyOS pe același stick sau într-o altă locație, astfel încât să o poți folosi ulterior pentru depanare prin chroot.
:::

:::note
Stick-ul USB trebuie să aibă cel puțin 8 GB de spațiu disponibil.
:::

### balenaEtcher

<Steps>

1. Descarcă [balenaEtcher](<https://etcher.balena.io/>). balenaEtcher suportă scrierea unei imagini pe Linux, MacOS și Windows.
   Dacă s-a descărcat un fișier `.zip`, extrage-l și execută binarul folosind următoarele comenzi:
      ```sh
      # Extragere fișier zip:
      bsdtar xvf <nume fișier zip>
      # Intrare în noul dosar:
      cd balenaEtcher-linux-x64/
      # Executare balenaEtcher:
      ./balena-etcher
      ```
2. Introdu un stick USB în computer.
3. Selectează `Flash from file` și alege fișierul imaginii ISO CachyOS.
4. Apasă pe `Select target` și alege stick-ul USB introdus anterior.
5. Apasă pe `Flash` pentru a începe procesul de scriere.

</Steps>

:::note
balenaEtcher ar putea solicita privilegii de administrator. Dacă se întâmplă asta, introdu parola și apasă pe `Authenticate`.
:::

### Interfața în linie de comandă (Linux & MacOS)

<Steps>

1. Introdu un stick USB.
2. Detectează stick-ul USB introdus folosind următoarele comenzi:
   ```sh
   # Linux
   # Stick-ul USB poate fi identificat ex: /dev/sda, după modelul discului și dimensiune.
   sudo fdisk -l

   # MacOS
   # Stick-urile USB sunt identificate ca "/dev/diskY" unde "Y" poate fi 0, 1 etc.
   diskutil list
   ```
3. Copiază conținutul ISO-ului pe stick-ul USB rulând:
   ```sh
   # Înlocuiește <usbdrive> cu eticheta unității (ex: sda).
   sudo dd bs=4M if=nume_complet_iso.iso of=/dev/<usbdrive> status=progress oflag=sync
   ```
</Steps>

- `dd` va copia acum conținutul fișierului ISO pe stick-ul USB.

### Rufus (Doar Windows)

<Steps>

1. Introdu un stick USB.
2. Descarcă [Rufus](<https://rufus.ie/>) și instalează-l, sau rulează versiunea portabilă.
3. La `Device`, apasă pe lista derulantă și selectează stick-ul USB introdus.
4. La `Boot selection`, apasă pe `SELECT` și localizează fișierul imaginii ISO CachyOS.
5. Apasă pe `START`.

</Steps>

### Ventoy (Linux & Windows)

<Tabs>

<TabItem label="Linux">

<Steps>

1. Introdu un stick USB.
2. Descarcă [Ventoy](<https://www.ventoy.net/en/download.html>)
3. Dezarhivează Ventoy folosind următoarea comandă:
   ```sh
   # Înlocuiește versiunea cu cea corectă, ex: ventoy-1.1.07-linux.tar.gz
   bsdtar xvf ventoy-versiune-linux.tar.gz
   # Intrare în noul dosar: (versiunea se poate schimba)
   cd ventoy-1.1.07/
   ```
4. Execută `VentoyGUI.x86_64` fie făcând dublu click pe el, fie prin terminal:
   ```sh
   # Va solicita privilegii administrative, introdu credențialele tale
   ./VentoyGUI.x86_64
   ```
5. Selectează stick-ul USB introdus apăsând pe `Device`.
6. Apasă pe `Install`.
7. După ce termină de instalat Ventoy pe stick-ul USB, închide fereastra și plasează fișierul ISO CachyOS în noua partiție utilizabilă a stick-ului.

</Steps>

</TabItem>

<TabItem label="Windows">

<Steps>
1. Introdu un stick USB.
2. Descarcă [Ventoy](<https://www.ventoy.net/en/download.html>)
3. Rulează `Ventoy2Disk.exe`
4. Selectează stick-ul USB introdus apăsând pe `Device`.
5. Apasă pe `Install`.
6. După ce termină de instalat Ventoy pe stick-ul USB, închide fereastra și plasează fișierul ISO CachyOS în noua partiție utilizabilă a stick-ului.
</Steps>

</TabItem>
