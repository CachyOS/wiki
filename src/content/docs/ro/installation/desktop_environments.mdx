CachyOS oferă mai multe medii desktop din care poți alege.

Această decizie se bazează pe preferințele personale. Alege-l pe cel care îți place cel mai mult.
:::note
Te rugăm să selectezi un singur mediu desktop în timpul instalării.
:::

Opțiunile disponibile sunt:

1. **KDE Plasma:** un mediu desktop cuprinzător și flexibil care oferă multiple stiluri de meniuri pentru accesarea aplicațiilor. Include managerul de ferestre KWin. KDE Plasma se mândrește, de asemenea, cu o interfață intuitivă care îți permite să descarci și să instalezi cu ușurință teme noi, widget-uri și multe altele de pe web.
2. **Niri:** un compozitor Wayland de tip tiling (mozaic) derulabil, care pune accent pe simplitate și pe gestionarea fluidă a ferestrelor. Folosește o structură de tip grilă continuă, optimizată atât pentru navigarea prin tastatură, cât și prin touchpad. Găsești [dotfiles-urile](https://github.com/CachyOS/cachyos-niri-settings) noastre pentru Niri aici.
3. **i3:** un manager de ferestre de tip tiling popular pentru X11, cunoscut pentru fișierul său de configurare unic și utilizarea eficientă a spațiului ecranului. Găsești [dotfiles-urile noastre pentru i3 aici](https://github.com/CachyOS/cachyos-i3wm-settings).
4. **Qtile:** un manager de ferestre pentru X11/Wayland care este configurat folosind limbajul de programare Python. Oferă diverse layout-uri și widget-uri. Găsești [dotfiles-urile noastre aici](https://github.com/CachyOS/cachyos-qtile-settings).
5. **Wayfire:** un compozitor Wayland bazat pe wlroots care echilibrează personalizarea, extensibilitatea și estetica. Găsești [dotfiles-urile](https://github.com/CachyOS/cachyos-wayfire-settings) noastre pentru Wayfire aici.
6. **GNOME:** un mediu desktop prietenos cu o interfață de tip touch pentru accesarea aplicațiilor. Deși este ușor de învățat, are opțiuni limitate de personalizare și poate fi dificil de configurat.
7. **XFCE:** un mediu desktop ușor și flexibil, cu un meniu tradițional de tip drop-down/pop-up pentru accesarea aplicațiilor. Este, de asemenea, compatibil cu Compiz.
8. **bspwm:** un manager de ferestre X11 bazat pe C, care oferă layout-uri flexibile de tip tiling, stacking și tabbing.
9. **Budgie:** un mediu desktop simplu și elegant, construit folosind toolkit-ul GTK. Este conceput să ofere o interfață modernă și atractivă, ușor de utilizat, fiind în același timp extrem de configurabil.
10. **Cinnamon:** un mediu desktop pentru Linux care echilibrează funcțiile avansate cu o experiență de utilizare tradițională.
11. **Cosmic:** un mediu desktop modern, orientat spre performanță, construit cu Rust și Smithay. Conceput pentru productivitate și utilizatori avansați, își propune să ofere funcții avansate menținând o interfață curată, dar intuitivă.
12. **Hyprland:** un compozitor Wayland plăcut vizual care folosește tiling dinamic.
13. **LXDE** (Lightweight X11 Desktop Environment): un mediu desktop rapid și economic, conceput pentru a fi utilizat pe computere vechi și sisteme cu resurse limitate. Folosește Openbox ca manager de ferestre implicit și se concentrează pe oferirea unei interfețe simple, curate și prietenoase.
14. **LXQt:** un mediu desktop ușor, format prin fuziunea proiectelor LXDE și Razor-qt, construit cu Qt.
15. **Mate Desktop:** un mediu desktop tradițional, derivat din GNOME 2. Se caracterizează prin aspectul său clasic, cu o interfață simplă și intuitivă. Mate oferă o experiență desktop ușor de utilizat și extrem de personalizabilă pentru utilizatorii care preferă un aspect mai clasic.
16. **Openbox:** un manager de ferestre X11 foarte popular, cunoscut pentru documentația sa excelentă și o selecție largă de teme disponibile.
17. **Sway:** un compozitor Wayland de tip tiling și un înlocuitor direct pentru managerul de ferestre i3 pentru X11. Funcționează cu configurația i3 existentă și suportă majoritatea funcțiilor i3, plus câteva în plus.
18. **UKUI:** un mediu desktop ușor, eficient, care funcționează bine pe computere mai vechi. Folosește atât tehnologii GTK, cât și Qt, și are un aspect vizual similar cu Windows 7, fiind prietenos pentru noii utilizatori de Linux.
