:::caution
Od kiedy Hyprland rozpoczął prace nad przebudową, należy pamiętać, że nie jest on obecnie stabilny i mogą wystąpić błędy/niespodziewane awarie. Używasz go na własne ryzyko.
Nawet ich "stabilna" wersja jest również zepsuta i pełna błędów, dlatego nie planujemy zapewniać wsparcia poza naszymi plikami konfiguracyjnymi (dotfiles). Zamiast tego odsyłamy do ich [wiki](https://wiki.hyprland.org/).
:::

:::tip
Uruchom Hyprland używając wpisu bez systemd, w przeciwnym razie nie uruchomi się i pojawi się czarny ekran.

Przykład: **`Hyprland`** zamiast **`Hyprland(systemd)`**.
:::

Naszym głównym celem przy tworzeniu tej konfiguracji było stworzenie działającego Hyprland, zachowując jednocześnie prostotę, dlatego może brakować niektórych niezbędnych narzędzi i programów, takich jak graficzny menedżer plików.

Zapoznaj się z naszym [FAQ dotyczącym Hyprland.](/desktop_environments/hyprland#faq)

**Pliki konfiguracyjne (dotfiles) utrzymywane przez [msmafra](https://github.com/msmafra) i [Lysec](https://github.com/Ly-sec)**

## Skróty klawiszowe

Większość kombinacji klawiszy wymaga użycia klawisza modyfikującego (mod key), którym w naszym przypadku jest klawisz Windows (określany jako SUPER). Można go zmienić w pliku konfiguracyjnym.

### Sterowanie aplikacjami

| Opis | Klawisz |
|-------------|-----|
| Otwórz terminal | <Kbd linux="Super+Return" /> |
| Otwórz Rofi (uruchamianie programów) | <Kbd linux="Super+Space" /> |
| Otwórz menedżer plików | <Kbd linux="Super+E" /> |
| Zamknij aktywne okno | <Kbd linux="Super+Q" /> |

### Nawigacja po obszarach roboczych

| Opis | Klawisz |
|-------------|-----|
| Przejdź do obszaru roboczego (1-9) | <Kbd linux="Super+1" /> do <Kbd linux="Super+9" /> |
| Następny obszar roboczy | <Kbd linux="Super+Period" /> |
| Poprzedni obszar roboczy | <Kbd linux="Super+Comma" /> |
| Przełączanie między obszarami roboczymi za pomocą kółka myszy | <Kbd linux="Super+Scroll" /> |

### Nawigacja po oknach

| Opis | Klawisz |
|-------------|-----|
| Przenieś fokus na okno powyżej | <Kbd linux="Super+ArrowUp" /> |
| Przenieś fokus na okno poniżej | <Kbd linux="Super+ArrowDown" /> |
| Przenieś fokus na okno po lewej | <Kbd linux="Super+ArrowLeft" /> |
| Przenieś fokus na okno po prawej | <Kbd linux="Super+ArrowRight" /> |
| Zmień aktywną grupę | <Kbd linux="Super+Tab" /> |

### Zarządzanie oknami

| Opis | Klawisz |
|-------------|-----|
| Przenieś okno do obszaru roboczego (1-9) bez przełączania | <Kbd linux="Super+Shift+1" /> do <Kbd linux="Super+Shift+9" /> |
| Przenieś okno do obszaru roboczego (1-9) i przełącz się na niego | <Kbd linux="Super+Control+1" /> do <Kbd linux="Super+Control+9" /> |
| Przesuń okno w górę | <Kbd linux="Super+Shift+ArrowUp" /> |
| Przesuń okno w dół | <Kbd linux="Super+Shift+ArrowDown" /> |
| Przesuń okno w lewo | <Kbd linux="Super+Shift+ArrowLeft" /> |
| Przesuń okno w prawo | <Kbd linux="Super+Shift+ArrowRight" /> |
| Przełącz tryb pełnoekranowy okna | <Kbd linux="Super+F" /> |
| Przełącz tryb pływający okna | <Kbd linux="Super+V" /> |
| Przypnij okno do wszystkich obszarów roboczych (w trybie pływającym) | <Kbd linux="Super+Y" /> |
| Przełącz okno do grupy | <Kbd linux="Super+K" /> |

### Zmiana rozmiaru okien

| Opis | Klawisz |
|-------------|-----|
| Wejdź w tryb zmiany rozmiaru (użyj H,J,K,L lub strzałek, Escape aby wyjść) | <Kbd linux="Super+R" /> |
| Zmniejsz okno w pionie | <Kbd linux="Super+Control+Shift+J" /> lub <Kbd linux="Super+Control+Shift+ArrowDown" /> |
| Zwiększ okno w pionie | <Kbd linux="Super+Control+Shift+K" /> lub <Kbd linux="Super+Control+Shift+ArrowUp" /> |
| Zmniejsz okno w poziomie | <Kbd linux="Super+Control+Shift+H" /> lub <Kbd linux="Super+Control+Shift+ArrowLeft" /> |
| Zwiększ okno w poziomie | <Kbd linux="Super+Control+Shift+L" /> lub <Kbd linux="Super+Control+Shift+ArrowRight" /> |

| Opis | Klawisz |

| Przesuń okno za pomocą myszy | <Kbd linux="Super+LeftClick" /> |

| Opis | Klawisz |

## FAQ

### Dlaczego mój Discord, Thunar i Nautilus mają dziwne tło?

Dzieje się tak, ponieważ okno ma zmodyfikowaną przezroczystość.

* Rozważ modyfikację reguły okna (window rule) w pliku konfiguracyjnym [Hyprland](https://github.com/CachyOS/cachyos-hyprland-settings/blob/master/etc/skel/.config/hypr/config/windowrules.conf#L21).

```sh title='Przykład'
windowrulev2 = opacity 0.92, class:^(thunar|nemo)$
```

### Czy jest dołączony menedżer plików?

* Nie, zainstaluj taki, który Ci odpowiada.
