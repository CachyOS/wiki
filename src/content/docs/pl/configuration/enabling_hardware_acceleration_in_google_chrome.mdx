Ten przewodnik opisuje włączanie akceleracji sprzętowej w przeglądarkach opartych na Chromium w systemie CachyOS. Odciąża to zadania związane z wideo/grafiką na twoją kartę graficzną, poprawiając wydajność.

## Wymagania wstępne

**Wymagane:**
* **Przeglądarka oparta na Chromium:** (np. Chrome, Brave, Ungoogled Chromium, Edge)
* **Sterowniki/API GPU:** Aktualne sterowniki Mesa (AMD/Intel) lub NVIDIA, ze skonfigurowanym Vulkan/VA-API/VDPAU.

**Opcjonalne:**

* **amdgpu_top:** Zainstaluj `amdgpu_top` z repozytorium za pomocą menedżera pakietów, jeśli chcesz monitorować aktywność GPU AMD z terminala.
* **nvtop:** (Tylko dla GPU Intela) Zainstaluj `nvtop` (Lunar Lake) i `intel-gpu-tools` (przed Lunar Lake) za pomocą menedżera pakietów Shelly, jeśli chcesz monitorować aktywność GPU Intela z terminala.

## Wkład w rozwój

Ten przewodnik można rozbudowywać. Jeśli masz działającą konfigurację akceleracji sprzętowej dla określonego GPU i przeglądarki opartej na Chromium, wnieś swój wkład, dodając nową sekcję w „Konfiguracje GPU i przeglądarek”. Podaj:

* **Nazwa przeglądarki**
* **Model GPU**
* **Flagi:** Zawartość pliku `~/.config/[browser]-flags.conf`.
* **Ścieżka pliku:** Pełna ścieżka do pliku z flagami.
* **Notatki (opcjonalnie):** Kluczowe sterowniki, pakiety lub szczegóły konfiguracji.

### Kroki konfiguracji

<Steps>

1. Zidentyfikuj plik z flagami: Znajdź ścieżkę do pliku z flagami swojej przeglądarki w sekcji „Konfiguracje GPU i przeglądarek”.
2. Edytuj plik z flagami: Otwórz/utwórz plik za pomocą `nano` (lub preferowanego edytora tekstu, jak `micro`, `vim`).

    ```bash
    nano [ŚCIEŻKA_DO_PLIKU_FLAG_TWOJEJ_PRZEGLĄDARKI]
    # Przykład: nano ~/.config/chrome-flags.conf
    ```

3. Dodaj flagi: Wklej odpowiednie flagi dla GPU/przeglądarki do pliku.
4. Zapisz i zamknij.
5. Uruchom ponownie przeglądarkę: Zamknij wszystkie instancje przeglądarki i uruchom ją ponownie.
6. Zweryfikuj: Przejdź do `chrome://gpu` (lub `brave://gpu`, `edge://gpu` itp.). Potwierdź status „Hardware accelerated” w sekcjach „Video Acceleration Information” i „Graphics Feature Status”.

</Steps>

## Jak zweryfikować sprzętową akcelerację wideo

<Tabs>

<TabItem label='GPU AMD (amdgpu_top)'>

<Steps>

1. Otwórz terminal i uruchom polecenie:
    ```bash
    amdgpu_top
    ```
2. Zacznij odtwarzać wideo w przeglądarkce (np. na YouTube).
3. Obserwuj sekcję `media` w `amdgpu_top`. Powinieneś zobaczyć tu pewne użycie, co wskazuje, że silnik multimedialny twojego GPU jest aktywny. Jeśli pozostaje na poziomie 0% podczas odtwarzania wideo, akceleracja sprzętowa może nie być w pełni włączona do dekodowania.

</Steps>

</TabItem>

<TabItem label='GPU Intel (nvtop)'>

<Steps>

1. Otwórz terminal i uruchom polecenie:
    ```bash
    sudo nvtop
    ```
2. Zacznij odtwarzać wideo w przeglądarce (np. na YouTube).
3. Obserwuj procent `ENC/DEC` w `nvtop`. Procent powinien wzrosnąć, jeśli dekodowanie wideo działa sprzętowo.

</Steps>

</TabItem>

<TabItem label='GPU Intel (intel_gpu_tools)'>

<Steps>

1. Otwórz terminal i uruchom polecenie:

    ```bash
    sudo intel_gpu_top
    ```

    Uwaga: Niektóre nowsze GPU Intela, takie jak te z serii Lunar Lake, nie udostępniają już liczników wydajności GPU za pomocą `intel_gpu_top`. Dla tych systemów użyj `nvtop`.

2. Zacznij odtwarzać wideo w przeglądarce (np. na YouTube).
3. Obserwuj procenty `Video` i `VideoEnhance` w `intel_gpu_top`. Procenty te powinny wzrosnąć, jeśli dekodowanie wideo działa sprzętowo.

</Steps>

</TabItem>

<TabItem label='Narzędzia deweloperskie przeglądarki'>

<Steps>

1. Otwórz swoją przeglądarkę opartą na Chromium.

2. Zacznij odtwarzać wideo (np. na YouTube lub z pliku lokalnego).

3. Otwórz narzędzia deweloperskie: Naciśnij `F12` lub `Ctrl+Shift+I`.

4. Przejdź do zakładki **Media**. Jeśli jej nie widzisz, kliknij trzy kropki (`...`) lub `>>` (Więcej kart) na pasku narzędzi deweloperskich, a następnie wybierz `Media`.

5. W sekcji „Odtwarzacze” po lewej stronie kliknij wpis odpowiadający twojemu wideo.

6. W głównym panelu przewiń w dół do sekcji **Dekoder wideo**.

7. Poszukaj etykiety `Dekoder sprzętowy`. Powinna mieć wartość `true`. Jeśli jest `false` lub pokazuje nazwę dekodera programowego (np. `FFmpegVideoDecoder`, `VpxVideoDecoder`, `Dav1dVideoDecoder`), akceleracja sprzętowa nie jest aktywna dla tego wideo.

</Steps>

</TabItem>

</Tabs>

## Konfiguracje GPU i przeglądarek

### AMD Radeon RX 6900 XT (Google Chrome)

* **Przeglądarka:** Google Chrome

* **GPU:** AMD Radeon RX 6900 XT

* **Plik z flagami:** `~/.config/chrome-flags.conf`

```bash
--use-gl=angle
--use-angle=vulkan
--enable-features=Vulkan,VulkanFromANGLE,DefaultANGLEVulkan,AcceleratedVideoDecodeLinuxZeroCopyGL,AcceleratedVideoEncoder,VaapiIgnoreDriverChecks,UseMultiPlaneFormatForHardwareVideo
```

**Notatki:** Wykorzystuje Vulkan (przez ANGLE) i VA-API. Flaga `--ozone-platform=x11` może być przydatna na Waylandzie dla niektórych ścieżek akceleracji.


### Nvidia RTX 4090 (Vivaldi)

* **Przeglądarka:** Vivaldi

* **GPU:** Nvidia RTX 4090

* **Plik z flagami:** `~/.config/vivaldi-stable.conf`

```bash
--enable-features=VaapiVideoDecoder,AcceleratedVideoDecodeLinuxGL,AcceleratedVideoDecodeLinuxZeroCopyGL
```

* **Plik z flagami:** `/usr/share/applications/vivaldi-stable.desktop`

```bash
# Pozostaw wszystkie inne linie bez zmian
# Powinieneś zmienić tylko ten wpis Exec= w sekcji '[Desktop Entry]'
Exec=/usr/bin/vivaldi-stable --enable-features=VaapiVideoDecoder,AcceleratedVideoDecodeLinuxGL,AcceleratedVideoDecodeLinuxZeroCopyGL %U
```

**Notatki:**

Powinieneś zastosować tylko jedną z tych zmian w plikach konfiguracyjnych, ale zastosowanie obu nie powinno powodować problemów.

Alternatywnie możesz zrobić następujące kroki dla KDE:
1. Usuń wszelkie skróty Vivaldi z Menedżera zadań / paska zadań.
2. Wyszukaj `Vivaldi` na liście Menu aplikacji.
3. Kliknij prawym przyciskiem myszy wpis w Menu aplikacji i wybierz `Edytuj aplikację...`.
4. W sekcji `Argumenty wiersza poleceń` dodaj następujące argumenty przed ostatnim argumentem `%U`:
```
--enable-features=VaapiVideoDecoder,AcceleratedVideoDecodeLinuxGL,AcceleratedVideoDecodeLinuxZeroCopyGL
```
5. Uruchom Vivaldi i przypnij proces do Menedżera zadań / paska zadań.

### Vivaldi - NVIDIA RTX 5090 (Autor: icetea)

* **Przeglądarka:** Vivaldi (8.1)

* **GPU:** NVIDIA GeForce RTX 5090 (Blackwell)

* **Ścieżka do pliku z flagami:** `~/.config/vivaldi-stable.conf`

```bash
--enable-features=VaapiVideoDecoder,AcceleratedVideoDecodeLinuxGL,AcceleratedVideoDecodeLinuxZeroCopyGL,VaapiOnNvidiaGPUs,VaapiIgnoreDriverChecks
--use-gl=angle
--use-angle=gl
--disable-features=Vulkan
--ignore-gpu-blocklist
--ozone-platform=wayland
```

**Notatki:**
- Wymaga `libva-nvidia-driver`. Przetestowano w lipcu 2026: sterownik 610.43.03, KDE Plasma (Wayland), Vivaldi 8.1.
- `VaapiIgnoreDriverChecks` to kluczowa flaga na kartach NVIDIA — bez niej dekodowanie się inicjalizuje i `vivaldi://gpu` twierdzi „Hardware accelerated”, ale dekodowanie w czasie rzeczywistym kończy się błędem (`vaEndPicture failed, VA error: internal decoding error`) i po cichu przełącza się na dekodowanie programowe.
- Zweryfikuj w Narzędziach deweloperskich → zakładka Media (`VaapiVideoDecoder` jako nazwa dekodera) oraz poleceniem `nvidia-smi dmon -s u` (kolumna DEC > 0 podczas odtwarzania). Nie polegaj wyłącznie na `vivaldi://gpu`.
- Dekodowanie AV1 nie działa w `libva-nvidia-driver` 0.0.17 (poprawka w gałęzi master projektu, jeszcze niewydana — zobacz [elFarto/nvidia-vaapi-driver#419](https://github.com/elFarto/nvidia-vaapi-driver/issues/419)). Zablokuj AV1 (np. za pomocą enhanced-h264ify), aby YouTube serwował VP9.

### Google Chrome - NVIDIA RTX 5070 (Autor: pisyukaev)

* **Przeglądarka:** Google Chrome

* **GPU:** NVIDIA GeForce RTX 5070 (Blackwell / GB205)

* **Ścieżka do pliku z flagami:** `~/.config/chrome-flags.conf`

```bash
--enable-features=AcceleratedVideoDecodeLinuxGL,VaapiVideoDecoder,VaapiIgnoreDriverChecks,VaapiOnNvidiaGPUs
--ignore-gpu-blocklist
```

**Notatki:**
- Wymaga `libva-nvidia-driver` oraz `nvidia-utils` (przetestowano ze sterownikiem 610.43.03).
- **Kluczowa flaga:** `VaapiOnNvidiaGPUs` — to główna flaga włączająca VA-API na GPU NVIDIA w Chrome/Chromium. Bez niej Chrome ma na stałe zaszytą blokadę urządzeń NVIDIA w `vaapi_wrapper.cc` i po cichu przełącza się na dekodowanie programowe.
- Flaga `VaapiIgnoreDriverChecks` jest również zalecana, aby zapobiec błędom dekodowania w trakcie działania.
- Flaga `AcceleratedVideoDecodeLinuxGL` włącza akcelerowane sprzętowo dekodowanie wideo przez backend OpenGL w ANGLE.
- Potwierdzone działanie: `chrome://gpu` → Video Acceleration Information pokazuje wsparcie dekodowania dla H264 (baseline, main, high), VP8, VP9 (profile0, profile2), HEVC (main, main 10, main still-picture) oraz AV1.
- Aby zweryfikować: Otwórz `chrome://gpu` i potwierdź, że w sekcji „Video Acceleration Information” widnieją kodeki dekodowania. Odtwórz wideo HEVC i sprawdź w Narzędziach deweloperskich → zakładka Media, czy aktywnym dekoderem jest `VaapiVideoDecoder`.
- Flaga `--ozone-platform=wayland` nie jest potrzebna — Chrome automatycznie wykrywa Wayland w CachyOS. Jeśli napotkasz problemy, możesz dodać `--ozone-platform=wayland` jawnie.
