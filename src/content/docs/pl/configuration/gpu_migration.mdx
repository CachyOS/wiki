## Zmiana GPU w CachyOS

:::note[Ten przewodnik dotyczy sytuacji, w której wymieniasz swoją kartę graficzną (NVIDIA ↔ AMD) na istniejącej instalacji CachyOS.]
:::

### Wymagania wstępne
  - Twoja nowa karta graficzna jest prawidłowo zainstalowana i podłączona.
  - Upewnij się, że system jest w pełni zaktualizowany
    ```bash
    sudo pacman -Syu
    ```

### Kroki migracji

<Tabs>
    <TabItem label='Z NVIDIA na AMD'>
        Chociaż sterowniki AMD są zawarte w jądrze Linux, może być konieczne wyczyszczenie starej konfiguracji NVIDIA i upewnienie się, że niezbędne pakiety AMD są zainstalowane.
        <Steps>
            1. Usuń wszystkie pakiety NVIDIA.
                ```bash
                sudo chwd -r nvidia
                ```
            2. Wyczyść bieżącą konfigurację chwd.
                ```bash
                 sudo rm -f /etc/mkinitcpio.conf.d/chwd.conf
                ```
            3. Użyj chwd, aby automatycznie wykryć twoje GPU i zainstalować odpowiednie pakiety AMD.
                ```bash
                sudo chwd -a
                ```
            4. Po zainstalowaniu nowych sterowników zaktualizuj initramfs i konfigurację bootloadera.
                > CachyOS zawiera hak pacmana, który automatycznie przebudowuje initramfs, gdy sterowniki są dodawane lub usuwane.
                > Zapewnia to załadowanie prawidłowych sterowników podczas uruchamiania systemu.
                - GRUB: `sudo grub-mkconfig -o /boot/grub/grub.cfg`
                - systemd-boot: `sudo sdboot-manage gen`
                - Limine: `sudo limine-mkinitcpio`
            5. Uruchom ponownie system, aby zastosować zmiany.
                ```bash
                sudo reboot
                ```
            6. Po ponownym uruchomieniu zweryfikuj, czy sterowniki AMD są aktywne.
                ```bash
                vulkaninfo | grep "deviceName"
                ```
                lub
                ```bash
                glxinfo | grep "OpenGL renderer"
                ```
                Jeśli zobaczysz na liście swoją kartę graficzną AMD, oznacza to, że sterowniki działają poprawnie.
        </Steps>
    </TabItem>
    <TabItem label='Z AMD na NVIDIA'>

                > Zapewnia to załadowanie prawidłowych sterowników podczas uruchamiania systemu.
