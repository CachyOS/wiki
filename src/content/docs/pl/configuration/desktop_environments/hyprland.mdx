## Skróty klawiszowe

Większość kombinacji klawiszy wymaga użycia klawisza modyfikującego, którym w naszym przypadku jest klawisz Windows (określany jako SUPER). Możesz go zmienić w pliku konfiguracyjnym.

### Kontrola Aplikacji

:::note[Konfiguracja Hyprland w CachyOS domyślnie nie zawiera menedżera plików. Zainstaluj wybrany przez siebie.]
:::

| Opis | Klawisz |
|-------------|-----|
| Otwórz terminal | <Kbd linux="Super+Return" /> |
| Otwórz Rofi (Uruchamianie programów) | <Kbd linux="Super+Space" /> |
| Otwórz menedżer plików | <Kbd linux="Super+E" /> |
| Zamknij aktywne okno | <Kbd linux="Super+Q" /> |

## FAQ

### Dlaczego mój Discord, Thunar i Nautilus mają dziwne tło?

Dzieje się tak, ponieważ okno ma zmodyfikowaną przezroczystość.

* Rozważ modyfikację reguły okna w pliku konfiguracyjnym [Hyprland](https://github.com/CachyOS/cachyos-hyprland-settings/blob/master/etc/skel/.config/hypr/config/windowrules.conf#L21).

```sh title='Przykład'
windowrulev2 = opacity 0.92, class:^(thunar|nemo)$
```

### Czy dołączony jest Menedżer Plików?

* Nie, zainstaluj taki, który Ci odpowiada.

### Jakie są powody wycofania ustawień Hyprland w CachyOS?

Ze względu na obciążenie związane z utrzymaniem konfiguracji w obliczu ciągłych zmian w projekcie źródłowym, które ją psuły, oraz brak dedykowanego opiekuna, zdecydowaliśmy się wycofać nasze ustawienia Hyprland (dotfiles).
