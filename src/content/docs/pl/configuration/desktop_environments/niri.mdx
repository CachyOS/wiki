:::note
Niri to przewijany, kafelkowy kompozytor Wayland, który oferuje unikalne podejście do zarządzania oknami dzięki systemowi układu opartemu na kolumnach.
:::

Naszym głównym celem jest posiadanie działającej konfiguracji Niri, która zapewnia płynne i intuicyjne doświadczenie pulpitu, jednocześnie utrzymując prostą i przystępną konfigurację.

Zapoznaj się z naszym [FAQ na temat Niri.](/pl/configuration/desktop_environments/niri#faq)

**Pliki konfiguracyjne utrzymywane przez [Ly-sec](https://github.com/Ly-sec)**

## Skróty klawiszowe

Większość kombinacji klawiszy wymaga użycia klawisza modyfikującego, którym w naszym przypadku jest klawisz Windows (określany jako SUPER). Możesz go zmienić w pliku konfiguracyjnym.

|-------------|-----|

## FAQ

### Co odróżnia Niri od innych menedżerów okien?

Niri używa unikalnego podejścia przewijanego kafelkowania, gdzie okna są ułożone w kolumny, które można przewijać poziomo. Zapewnia to metaforę nieskończonego pulpitu, która jest szczególnie użyteczna w przypadku monitorów ultraszerokokątnych i przepływów pracy wymagających wielu otwartych aplikacji.

### Jak zmienić układ klawiatury?

Edytuj sekcję `input` w swoim pliku konfiguracyjnym:

```txt title='Przykład'
input {
    keyboard {
        xkb {
            layout "pl" // Zmień "de" na preferowany układ
        }
    }
}
```

### Czy mogę dostosować odstępy i wygląd okien?

Tak, możesz zmodyfikować sekcję `layout`:

```txt title='Przykład'
layout {
    gaps 8 // Zmień rozmiar odstępów

    focus-ring {
        width 2
        active-color "#twój-kolor"
        inactive-color "#twój-kolor"
    }
}
```

### Jak dodać więcej aplikacji startowych?

Dodaj je do sekcji `startup`:

```txt title='Przykład'
spawn-at-startup "twoja-aplikacja"
```

### Do czego służy klawisz awaryjnego wyjścia?

Skrót `Super+Escape` ma na celu przywrócenie kontroli, gdy aplikacja pełnoekranowa blokuje skróty klawiszowe. Wyłącza on każdy aktywny inhibitor skrótów klawiszowych.

### Jak skonfigurować wiele monitorów?

Odkomentuj i zmodyfikuj sekcję `output` dla swoich konkretnych wyświetlaczy. Uruchom `niri msg outputs`, aby uzyskać poprawne nazwy:

```txt title='Przykład'
output "DP-1" {
    mode "1920x1080@60.000"
    scale 1
}
```
