:::note
Niri to kompozytor Wayland z przewijanymi kafelkami, który oferuje unikalne podejście do zarządzania oknami dzięki systemowi układu opartemu na kolumnach.
:::

Naszym głównym celem przy naszej konfiguracji jest stworzenie działającej konfiguracji Niri, która zapewnia płynne i intuicyjne doświadczenie pulpitu, jednocześnie utrzymując konfigurację prostą i przystępną.

Zapoznaj się z naszym [FAQ dla Niri](/pl/configuration/desktop_environments/niri#faq).

**Pliki konfiguracyjne (dotfiles) utrzymywane przez [Ly-sec](https://github.com/Ly-sec)**
W razie problemów z Noctalia, prosimy zapoznać się z [dokumentacją Noctalia](https://docs.noctalia.dev/).

## Skróty klawiszowe

Większość kombinacji klawiszy wymaga użycia klawisza modyfikatora, którym w naszym przypadku jest klawisz Windows (określany jako SUPER). Można go zmienić w pliku konfiguracyjnym.

### Kontrola Aplikacji

| Opis | Klawisz |
|-------------|-----|
| Otwórz terminal | <Kbd linux="Super+Return" /> |
| Otwórz launcher programów | <Kbd linux="Super+Ctrl+Return" /> |
| Otwórz przeglądarkę (Firefox) | <Kbd linux="Super+B" /> |
| Otwórz menedżer plików | <Kbd linux="Super+E" /> |
| Zamknij aktywne okno | <Kbd linux="Super+Q" /> |

## FAQ

### Co odróżnia Niri od innych menedżerów okien?

Niri wykorzystuje unikalne podejście przewijanych kafelków, w którym okna są rozmieszczone w kolumnach, które można przewijać poziomo. Zapewnia to metaforę nieskończonego pulpitu, która jest szczególnie przydatna w przypadku monitorów ultraszerokokątnych i przepływów pracy wymagających wielu otwartych aplikacji.

### Jak zmienić układ klawiatury?

Edytuj sekcję `input` w pliku konfiguracyjnym:

```txt title='Przykład'
input {
    keyboard {
        xkb {
            layout "us" // Zmień z "de" na preferowany układ
        }
    }
}
```

### Czy mogę dostosować odstępy i wygląd okien?

Tak, możesz zmodyfikować sekcję `layout`:

```txt title='Przykład'
layout {
    gaps 8 // Zmień rozmiar odstępów

    focus-ring {
        width 2
        active-color "#twój-kolor"
        inactive-color "#twój-kolor"
    }
}
```

### Jak dodać więcej aplikacji startowych?

Dodaj je do sekcji `startup`:

```txt title='Przykład'
spawn-at-startup "twoja-aplikacja"
```

### Do czego służy klawisz wyjścia awaryjnego?

Skrót `Super+Escape` ma na celu przywrócenie kontroli, gdy aplikacja pełnoekranowa blokuje Twoje skróty klawiszowe. Wyłącza on każdy aktywny inhibitor skrótów klawiaturowych.

### Jak skonfigurować wiele monitorów?

Odkomentuj i zmodyfikuj sekcję `output` dla swoich konkretnych wyświetlaczy. Uruchom `niri msg outputs`, aby uzyskać poprawne nazwy:

```txt title='Przykład'
output "DP-1" {
    mode "1920x1080@60.000"
    scale 1
}
```
