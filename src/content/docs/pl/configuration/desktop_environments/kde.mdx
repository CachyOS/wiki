## Jak zainstalować brakującą sesję X11

Po tym, jak KDE zdecydowało się podzielić swój rozwój na wiele pakietów, sesja X11 została usunięta z domyślnej instalacji.

```sh
sudo pacman -S plasma-x11-session kwin-x11
```

## FAQ

### Jak mogę uzyskać ten sam wygląd, co na zrzutach ekranu KDE, o nazwie "Emerald"?

- Jest to połączenie motywu Emerald + motywu ikon Qogir, które nie są domyślnie instalowane.
  - ```sh title='Zainstaluj oba za pomocą następującego polecenia'
    sudo pacman -S cachyos-emerald-kde-theme-git qogir-icon-theme
    ```
  Zastosuj oba w `Wygląd i styl - Kolory i motywy`

### Dlaczego SDDM wygląda tak nijako i staro?

- *Ponieważ domyślnie nie jest stosowany żaden motyw SDDM, SDDM powróci do klasycznego motywu.*
  - **Zastosuj motyw Breeze, jak pokazano na zrzucie ekranu**
