## Oficjalne źródła ISO

Obraz ISO CachyOS można pobrać z następujących źródeł:

*   [Strona internetowa](<https://cachyos.org/download>)
*   [SourceForge](<https://sourceforge.net/projects/cachyos-arch/files/>)
*   [Mirror CachyOS](<https://mirror.cachyos.org/ISO/>)

## Weryfikacja integralności ISO za pomocą SHA256

:::caution
Zawsze wykonaj dodatkowy krok weryfikacji integralności ISO, aby uniknąć niepożądanych problemów podczas instalacji lub tworzenia nośnika startowego.
:::

**Aktualna wersja ISO:** `260426`

**Skrót SHA256:** `9a280d1e9732cfe50ab02db6a7e44ae0d9e6a10e6ea394f73192f7c14e263118`

<Tabs>

<TabItem label='Windows'>

<Steps>

1. Pobierz [plik](https://mirror.cachyos.org/ISO/desktop/260426/cachyos-desktop-linux-260426.iso.sha256) zawierający skrót SHA256 **(Otwórz go w edytorze tekstu, np. Notatniku)**.
2. Otwórz CMD lub PowerShell jako Administrator i [przejdź](<https://www.wikihow.com/Change-Directories-in-Command-Prompt>) do ścieżki, w której przechowywane są pliki ISO i SHA256.
3. Wykonaj następujące polecenie:
   ```powershell
   # Przykład:
   certUtil -hashfile cachyos-desktop-linux-260426.iso SHA256
   ```
4. Porównaj skrót z wyniku polecenia certUtil z tym z pobranego pliku w **Kroku 1**. Jeśli są zgodne, możesz kontynuować instalację CachyOS.

</Steps>

</TabItem>

<TabItem label='Linux'>

<Steps>

1. Pobierz [plik](https://mirror.cachyos.org/ISO/desktop/260426/cachyos-desktop-linux-260426.iso.sha256) zawierający skrót SHA256.
2. Otwórz terminal, przejdź do katalogu zawierającego plik `.sha256` i wykonaj następujące polecenia:
   ```sh
   # Przykład:
   cd ~/Downloads
   cat cachyos-desktop-linux-260426.iso.sha256
   # 9a280d1e9732cfe50ab02db6a7e44ae0d9e6a10e6ea394f73192f7c14e263118
   ```
3. Porównaj wynik z **Kroku 2** ze skrótem pliku ISO:
   ```sh
   # Przykład:
   sha256sum cachyos-desktop-linux-260426.iso
   ```
4. Jeśli skróty z **Kroku 2** i **Kroku 3** są zgodne, możesz kontynuować instalację CachyOS.

</Steps>

</TabItem>

<TabItem label='macOS'>

<Steps>

1. Pobierz [plik](https://mirror.cachyos.org/ISO/desktop/260426/cachyos-desktop-linux-260426.iso.sha256) zawierający skrót SHA256.
2. Otwórz terminal, przejdź do katalogu zawierającego plik `.sha256` i wykonaj następujące polecenia:
   ```sh
   # Przykład:
   cd Downloads/

   # 9a280d1e9732cfe50ab02db6a7e44ae0d9e6a10e6ea394f73192f7c14e263118
   ```

3. Porównaj wynik z **Kroku 2** ze skrótem pliku ISO:
   ```sh

   ```
4. Jeśli skróty z **Kroku 2** i **Kroku 3** są zgodne, możesz kontynuować instalację CachyOS.

</Steps>

</TabItem>

## Weryfikacja autentyczności obrazu ISO (Linux)

Aby zweryfikować autentyczność pliku ISO:

<Steps>

1. Zaimportuj klucz GPG jako odniesienie do porównania:

   ```shell
   gpg --keyserver hkps://keys.openpgp.org --recv-key F3B607488DB35A47
   ```

2. Pobierz plik ISO i jego plik sygnatury [.sig](https://cdn77.cachyos.org/ISO/desktop/260426/cachyos-desktop-linux-260426.iso.sig), a następnie uruchom następujące polecenie (zastąp `full_iso_name.iso` rzeczywistą nazwą pliku ISO):
   ```shell
   gpg --verify full_iso_name.iso.sig full_iso_name.iso
   ```

   Jeśli otrzymasz wynik **Good signature**, plik ISO jest autentyczny:
   ```
   gpg: Signature made dom 08 mar 2026 10:39:18 -03
   gpg:                using RSA key 882DCFE48E2051D48E2562ABF3B607488DB35A47
   gpg: Good signature from "CachyOS <admin@cachyos.org>" [unknown]
   gpg: WARNING: This key is not certified with a trusted signature!
   gpg:          There is no indication that the signature belongs to the owner.
   Primary key fingerprint: 882D CFE4 8E20 51D4 8E25  62AB F3B6 0748 8DB3 5A47
   ```

</Steps>

:::danger
Jeśli wynik nie zawiera ciągu **Good signature** lub ID klucza nie jest zgodne, nie używaj obrazu ISO. Zły podpis sugeruje, że obraz ISO został zmodyfikowany lub uszkodzony.

Upewnij się, że pobrany obraz pochodzi z [legalnego źródła CachyOS](/pl/cachyos_basic/download#oficjalne-źródła-iso).
:::
