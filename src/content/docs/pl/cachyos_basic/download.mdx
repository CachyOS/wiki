## Oficjalne źródła ISO

ISO CachyOS można pobrać z następujących źródeł:

*   [Strona internetowa](<https://cachyos.org/download>)
*   [SourceForge](<https://sourceforge.net/projects/cachyos-arch/files/>)
*   [Mirror CachyOS](<https://mirror.cachyos.org/ISO/>)

## Weryfikacja integralności ISO za pomocą SHA256

:::caution[OSTRZEŻENIE]
Zawsze wykonuj dodatkowy krok weryfikacji integralności ISO, aby uniknąć niepożądanych problemów podczas instalacji lub tworzenia nośnika rozruchowego.
:::

**Aktualna wersja ISO:** `250828`

**Hash SHA256:** `83ab50783ed41bff0f497b223a78312edef7d4d718f22baf7a6b01a6eb85d88b`

<Tabs>

<TabItem label='Windows'>

<Steps>

1. Pobierz [plik](https://mirror.cachyos.org/ISO/desktop/250828/cachyos-desktop-linux-250828.iso.sha256) zawierający hash SHA256 **(Otwórz go za pomocą edytora tekstu, np. Notatnik).**
2. Otwórz CMD lub PowerShell jako Administrator i [przejdź](<https://www.wikihow.com/Change-Directories-in-Command-Prompt>) do ścieżki, w której przechowywane są pliki ISO i SHA256.
3. Wykonaj następujące polecenie:
   ```powershell
   # Przykład:
   certUtil -hashfile cachyos-desktop-linux-250828.iso SHA256
   ```
4. Porównaj wynik hash certUtil z tym z pobranego pliku w **Kroku 1**. Jeśli się zgadzają, możesz przystąpić do instalacji CachyOS.

</Steps>

</TabItem>

<TabItem label='Linux'>

<Steps>

1. Pobierz [plik](https://mirror.cachyos.org/ISO/desktop/250828/cachyos-desktop-linux-250828.iso.sha256) zawierający hash SHA256.
2. Otwórz terminal, przejdź do katalogu zawierającego plik `.sha256` i wykonaj następujące polecenia:
   ```sh
   # Przykład:
   cd Downloads/
   cat cachyos-desktop-linux-250828.iso.sha256
   # 83ab50783ed41bff0f497b223a78312edef7d4d718f22baf7a6b01a6eb85d88b
   ```
3. Porównaj wynik z **Kroku 2** i wykonaj następujące polecenie, aby sprawdzić hash pliku ISO:
   ```sh
   # Przykład:
   sha256sum cachyos-desktop-linux-250828.iso
   ```
4. Jeśli hashe z **Kroku 2** i **Kroku 3** się zgadzają, możesz przystąpić do instalacji CachyOS.

</Steps>

</TabItem>

## Weryfikacja autentyczności obrazu ISO (Linux)

Aby zweryfikować autentyczność pliku ISO i upewnić się, że jest to oficjalna wersja wydana przez zespół deweloperski CachyOS:

<Steps>

1. Importuj klucz GPG do weryfikacji autentyczności:

   ```shell
   gpg --keyserver hkps://keys.openpgp.org --recv-key F3B607488DB35A47
   ```

2. Pobierz plik ISO i jego plik podpisu `.sig`, a następnie uruchom następujące polecenie (zastępując `full_iso_name.iso` rzeczywistą nazwą pliku ISO):
   ```shell
   gpg --verify full_iso_name.iso.sig full_iso_name.iso
   ```

   Jeśli otrzymasz wynik **Good signature**, plik ISO jest autentyczny:
   ```
   gpg: Signature made czw 28 sie 2025 10:41:14 -03
   gpg:                using RSA key 882DCFE48E2051D48E2562ABF3B607488DB35A47
   gpg: Good signature from "CachyOS <admin@cachyos.org>" [unknown]
   gpg: WARNING: This key is not certified with a trusted signature!
   gpg:          There is no indication that the signature belongs to the owner.
   Primary key fingerprint: 882D CFE4 8E20 51D4 8E25  62AB F3B6 0748 8DB3 5A47
   ```

</Steps>

:::danger
Jeśli wynik nie zwraca ciągu **Good signature** lub ID klucza się nie zgadza, nie używaj obrazu ISO. Upewnij się, że pobrany obraz pochodzi
z legalnego źródła CachyOS, ponieważ zły podpis może sugerować, że ISO zostało zmodyfikowane.
:::
