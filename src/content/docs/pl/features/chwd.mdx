[Wykrywanie Sprzętu CachyOS](https://github.com/CachyOS/chwd/) (lepiej znane jako `chwd`) pozwala nam na obsługę różnorodnego sprzętu poprzez instalację niezbędnych
pakietów i sterowników dla działającego systemu. Obejmuje to systemy z kartami graficznymi NVIDIA, Macbooki T2 oraz urządzenia przenośne, takie jak Steam Deck i ROG Ally.

## Użycie

`chwd` jest zazwyczaj uruchamiane podczas instalacji, aby dostarczyć niezbędne pakiety dla systemu. Można go jednak również
użyć po instalacji.

### Automatyczna Konfiguracja

`chwd` obsługuje instalowanie i konfigurowanie niezbędnych sterowników i pakietów, aby system mógł działać w optymalnych warunkach.

```sh
sudo chwd -a
```

### Inne

Sprawdź pomoc `chwd`, aby poznać składnię poleceń i inne zastosowania.

```sh
chwd --help
Usage: chwd [OPTIONS]

Options:
  -i, --install <profil>           Zainstaluj profil
  -r, --remove <profil>            Usuń profil
  -d, --detail                     Pokaż szczegółowe informacje dla list
  -f, --force                      Wymuś ponowną instalację
      --list-installed             Wyświetl zainstalowane jądra
      --list                       Wyświetl dostępne profile dla wszystkich urządzeń
      --list-all                   Wyświetl wszystkie profile
  -a, --autoconfigure [<classid>]  Autokonfiguracja
      --ai_sdk                     Przełącz profile AI SDK
      --pmcachedir <PMCACHEDIR>    [domyślnie: /var/cache/pacman/pkg]
      --pmconfig <PMCONFIG>        [domyślnie: /etc/pacman.conf]
      --pmroot <PMROOT>            [domyślnie: /]
  -h, --help                       Wyświetl pomoc
  -V, --version                    Wyświetl wersję
```
