[cachy-chroot](https://github.com/CachyOS/cachy-chroot) to prosty program pomocniczy, który ułatwia proces chrootowania do istniejącej instalacji CachyOS lub systemu opartego na Archu. Wypisuje on wszystkie partycje wykryte na maszynie, a także obsługuje listowanie podwoluminów BTRFS.
Co więcej, `cachy-chroot` obsługuje również systemy szyfrowane za pomocą LUKS. Mapuje on każdy wpis z `fstab` do odpowiadającego mu wpisu w `crypttab` i zamyka wszystkie woluminy LUKS po wyjściu z chroota.

## Użycie

Proces chrootowania **musi** być wykonany z obrazu live ISO. Poniżej znajduje się przykład użycia `cachy-chroot` w instalacji CachyOS z BTRFS.

```sh title="Chrootowanie z cachy-chroot"
sudo su # Wejdź na użytkownika root w obrazie live ISO
pacman -Sy cachy-chroot # Upewnij się, że cachy-chroot jest w najnowszej wersji
cachy-chroot

```

Po wybraniu partycji głównej program poprosi o zamontowanie dodatkowych partycji, np. partycji `/boot`.

```sh title="Montowanie dodatkowych partycji"
✔ Do you want to mount additional partitions? · yes # Czy chcesz zamontować dodatkowe partycje? · tak
? Enter the mount point for additional partition (e.g. /boot) type 'skip' to cancel:  › # Podaj punkt montowania dla dodatkowej partycji (np. /boot) wpisz 'skip' aby anulować: › # /boot dla systemd-boot, /boot/efi dla GRUB i rEFInd
```

Po zakończeniu wyjdź ze środowiska chroot, wpisując `exit` w wierszu poleceń lub naciskając `CTRL+D` na klawiaturze.

```sh title="Wychodzenie z chroot"
exit
```
