## Wymagania systemowe

Przed przygotowaniem instalacji upewnij się, że używany komputer spełnia minimalne wymagania systemowe do uruchomienia CachyOS. Instalator
korzysta z procesu instalacji online, więc stabilne i stosunkowo szybkie połączenie internetowe jest obowiązkowe.

:::note[Maszyny wirtualne]
Nie zaleca się instalowania CachyOS na maszynie wirtualnej. Maszyny wirtualne mogą mieć problemy z powodu nieprawidłowej konfiguracji lub być całkowicie zepsute. Zaleca się instalowanie CachyOS bezpośrednio na sprzęcie (bare metal).
:::

<Tabs>

<TabItem label="Wymagania minimalne">

*   3 GB RAM
*   30 GB przestrzeni dyskowej (HDD/SSD)
*   Stabilne połączenie internetowe

:::caution
Niestabilny internet może skutkować wydłużonym czasem instalacji lub, w najgorszym przypadku, niepowodzeniem instalacji.
:::

</TabItem>

<TabItem label="Wymagania zalecane">

*   8 GB RAM
*   50 GB przestrzeni dyskowej (SSD/NVMe)
*   [Procesor zgodny z x86-64-v3](/pl/installation/installation_prepare#wsparcie-dla-poziomu-mikroarchitektury-x86_64)
*   Prędkość internetu 50 Mb/s lub lepsza
*   GPU NVIDIA (seria 900+ - np. GTX 950), AMD +GCN 1.0 (np. AMD R7 240) lub Intel (zintegrowana seria HD Graphics lub nowsza, seria Arc)

</TabItem>

</Tabs>

## Tworzenie rozruchowego dysku USB z CachyOS

Istnieje kilka narzędzi i metod, których można użyć do utworzenia rozruchowego dysku USB z CachyOS.

:::note
Dysk USB musi mieć co najmniej 8 GB dostępnej przestrzeni.
:::

### balenaEtcher

<Steps>

1. Pobierz [balenaEtcher](<https://etcher.balena.io/>). balenaEtcher obsługuje tworzenie obrazów na Linuksie, MacOS i Windows.
   Jeśli pobrano plik `.zip`, rozpakuj go i uruchom plik binarny za pomocą następujących poleceń:
      ```sh
      # Rozpakuj plik zip:
      bsdtar xvf <nazwa pliku zip>
      # Przejdź do nowego folderu:
      cd balenaEtcher-linux-x64/
      # Uruchom balenaEtcher:
      ./balena-etcher
      ```
2. Podłącz dysk USB do komputera.
3. Wybierz `Flash from file` i wskaż plik obrazu ISO CachyOS.
4. Kliknij `Select target` i wybierz wcześniej podłączony dysk USB.
5. Naciśnij `Flash`, aby rozpocząć proces wgrywania.

</Steps>

:::note
balenaEtcher może poprosić o uprawnienia administratora. Jeśli tak się stanie, wprowadź swoje hasło i kliknij `Uwierzytelnij`.
:::

### Interfejs wiersza poleceń (Linux i MacOS)

<Steps>

1. Podłącz dysk USB.
2. Wykryj podłączony dysk USB za pomocą następujących poleceń:
   ```sh
   # Linux
   # Dysk USB może być zidentyfikowany np. jako /dev/sda, na podstawie modelu i rozmiaru dysku.
   sudo fdisk -l

   # MacOS
   # Dyski USB są identyfikowane jako "/dev/diskY", gdzie "Y" może być 0, 1 itp.
   diskutil list
   ```
3. Skopiuj zawartość iso na podłączony dysk USB, uruchamiając:
   ```sh
   # Zastąp <usbdrive> etykietą dysku.
   sudo dd bs=4M if=pełna_nazwa_iso.iso of=/dev/<usbdrive> status=progress oflag=sync
   ```
</Steps>

- `dd` skopiuje teraz zawartość pliku ISO na podłączony dysk USB.

### Rufus (tylko Windows)

<Steps>

1. Podłącz dysk USB.
2. Pobierz [Rufus](<https://rufus.ie/>) i zainstaluj go lub uruchom wersję przenośną.
3. W polu `Urządzenie` kliknij na listę rozwijaną i wybierz podłączony dysk USB.
4. W polu `Wybór rozruchu` kliknij `WYBIERZ` i zlokalizuj plik obrazu ISO CachyOS.
5. Kliknij `START`.

</Steps>

### Ventoy (Linux i Windows)

<Tabs>

<TabItem label="Linux">

<Steps>

1. Podłącz dysk USB.
2. Pobierz [Ventoy](<https://www.ventoy.net/en/download.html>)
3. Rozpakuj Ventoy za pomocą następującego polecenia:
   ```sh
   # Zastąp wersję poprawną, np. ventoy-1.1.07-linux.tar.gz
   bsdtar xvf ventoy-wersja-linux.tar.gz
   # Przejdź do nowego folderu: (wersja może się zmienić)
   cd ventoy-1.1.07/
   ```
4. Uruchom `VentoyGUI.x86_64` poprzez dwukrotne kliknięcie lub przez terminal:
   ```sh
   # Poprosi o uprawnienia administracyjne, wprowadź swoje poświadczenia
   ./VentoyGUI.x86_64
   ```
5. Wybierz podłączony dysk USB, klikając na `Urządzenie`.
6. Kliknij `Zainstaluj`.
7. Po zakończeniu instalacji Ventoy na podłączonym dysku USB, zamknij okno i umieść plik ISO CachyOS na nowej, użytecznej partycji dysku.

</Steps>

</TabItem>

<TabItem label="Windows">

<Steps>
1. Podłącz dysk USB.
2. Pobierz [Ventoy](<https://www.ventoy.net/en/download.html>)
3. Uruchom `Ventoy2Disk.exe`
4. Wybierz podłączony dysk USB, klikając na `Urządzenie`.
5. Kliknij `Zainstaluj`.
6. Po zakończeniu instalacji Ventoy na dysku USB, zamknij okno i umieść plik ISO CachyOS na nowej, użytecznej partycji dysku.
</Steps>

</TabItem>

</Tabs>
