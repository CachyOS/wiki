CachyOS zapewnia gotowe wsparcie dla MacBooków z czipem T2, włączając w to niezbędne łatki jądra we wszystkich dostarczanych kernelach. Jednakże, istnieją kluczowe kroki, które należy wykonać, aby zapewnić pomyślną konfigurację.

:::caution[Potencjalne ryzyko]
Całkowite usunięcie systemu macOS niesie ze sobą ryzyko, takie jak utrata danych lub unieruchomienie urządzenia. **Zdecydowanie zaleca się** zachowanie partycji z macOS w celu aktualizacji oprogramowania sprzętowego i odzyskiwania systemu. Więcej informacji można znaleźć w [planie rozwoju T2 Linux](https://wiki.t2linux.org/roadmap/#can-i-completely-remove-macos).

Jeśli mimo to zdecydujesz się na usunięcie macOS, upewnij się, że masz pełną kopię zapasową i wcześniej utwórz [bootowalny instalator macOS](https://support.apple.com/pl-pl/101578).
:::

## Przed instalacją

Stworzenie bootowalnego instalatora macOS jest opcjonalne, ale zalecane, jeśli planujesz modyfikować partycje lub usuwać macOS. Może być przydatne do aktualizacji oprogramowania sprzętowego, rozwiązywania problemów lub przywracania systemu. Szczegółowe instrukcje znajdziesz w [przewodniku Apple](https://support.apple.com/pl-pl/101578).

Wykonaj poniższe kroki w systemie macOS **zanim** uruchomisz instalator CachyOS.

### Przygotuj bootowalny nośnik USB CachyOS

Pobierz [obraz ISO CachyOS](/pl/cachyos_basic/download) i postępuj zgodnie z instrukcjami w [Tworzenie bootowalnego nośnika USB CachyOS](/pl/installation/installation_prepare#tworzenie-bootowalnego-dysku-usb-z-cachyos), aby utworzyć nośnik instalacyjny.

### (Opcjonalnie) Wyodrębnij oprogramowanie sprzętowe Wi-Fi

:::note
Wi-Fi **nie będzie działać** od razu podczas instalacji ani po niej, ponieważ wymagane oprogramowanie sprzętowe jest własnościowe i nie może być redystrybuowane przez CachyOS. Będziesz potrzebować połączenia z internetem (np. Ethernet, tethering USB) podczas procesu instalacji, chyba że wykonasz poniższe kroki, aby wcześniej przygotować oprogramowanie sprzętowe Wi-Fi i włączyć je podczas instalacji.
:::

Będąc jeszcze w systemie macOS, otwórz Terminal i wykonaj następujące polecenie. Spowoduje to skopiowanie niezbędnych plików oprogramowania sprzętowego Wi-Fi na partycję EFI, dzięki czemu będą one dostępne później podczas instalacji CachyOS.
```sh
curl -sL https://wiki.t2linux.org/tools/firmware.sh | bash -s copy_to_efi
```

### Przygotuj swój dysk

Jeśli planujesz dual-boot z macOS (zalecane), musisz stworzyć miejsce dla CachyOS. Użyj aplikacji Narzędzie dyskowe w macOS, aby zmienić rozmiar istniejącej partycji macOS:

<Steps>

1.  Otwórz **Narzędzie dyskowe**.
2.  Na pasku bocznym Narzędzia dyskowego wybierz **wolumin**, którego rozmiar chcesz zmienić (zwykle o nazwie „Macintosh HD” lub podobnej).
3.  Kliknij przycisk **„Partycja”** na pasku narzędzi.
4.  Kliknij przycisk **„+” (plus)** pod wykresem kołowym reprezentującym wykorzystanie dysku.
5.  **Co najważniejsze**, po wyświetleniu monitu wybierz **„Dodaj partycję”**, *a nie* „Dodaj wolumin”. Musisz utworzyć osobną partycję dla Linuksa.
6.  **Nazwa:** Wprowadź opisową nazwę dla nowej partycji (np. „CachyOS” lub „Linux”).
7.  **Format:** Wybierz dowolny dostępny format (np. APFS lub Mac OS Extended). Instalator CachyOS sformatuje tę partycję później, więc początkowy wybór nie ma znaczenia.
8.  **Rozmiar:** Przydziel żądaną ilość miejsca na dysku dla CachyOS. **Pamiętaj, że zmiana rozmiaru partycji w późniejszym czasie może być trudna lub niemożliwa**, więc wybierz rozmiar odpowiadający Twoim potrzebom.
10. Kliknij **„Zastosuj”**, aby utworzyć nową partycję. Narzędzie dyskowe zmieni rozmiar partycji macOS i utworzy nową pustą przestrzeń.

</Steps>


### Wyłącz Secure Boot

<Steps>

1. Uruchom ponownie komputer Mac i przytrzymaj klawisze `Command (⌘) + R` natychmiast po włączeniu zasilania, aby wejść w tryb odzyskiwania.
2. Przejdź do Narzędzia > Narzędzie bezpiecznego uruchamiania.
3. W sekcji **Bezpieczny rozruch** wybierz „Brak zabezpieczeń”, a w sekcji **Dozwolone nośniki rozruchowe** wybierz „Zezwalaj na uruchamianie z nośników zewnętrznych lub wymiennych”.

</Steps>

Więcej szczegółów znajdziesz w [przewodniku Apple dotyczącym Narzędzia bezpiecznego uruchamiania](https://support.apple.com/pl-pl/102522).

## Proces instalacji

<Steps>

1.  **Uruchom system z nośnika USB CachyOS:**
    *   Uruchom ponownie komputer Mac i przytrzymaj klawisz `Option (⌥)` natychmiast po włączeniu zasilania.
    *   Wybierz nośnik USB CachyOS (zwykle oznaczony jako „EFI Boot”).
2.  **(Opcjonalnie) Włącz Wi-Fi w środowisku Live:**
    *   Jeśli potrzebujesz Wi-Fi podczas instalacji i nie masz połączenia Ethernet/tetheringu, otwórz terminal po załadowaniu środowiska Live CachyOS.
    *   Uruchom te polecenia, aby skopiować oprogramowanie sprzętowe z partycji EFI (utworzonej w kroku [Wyodrębnij oprogramowanie sprzętowe Wi-Fi](#opcjonalnie-wyodrębnij-oprogramowanie-sprzętowe-wi-fi)) i skonfigurować NetworkManager:
        ```sh
        # Zamontuj partycję EFI (zwykle nvme0n1p1 na Macach z T2)
        sudo mkdir -p /tmp/apple-wifi-efi
        sudo mount /dev/nvme0n1p1 /tmp/apple-wifi-efi

        # Skopiuj oprogramowanie sprzętowe z EFI do środowiska live
        bash /tmp/apple-wifi-efi/firmware.sh get_from_efi
        sudo umount /tmp/apple-wifi-efi

        # Skonfiguruj NetworkManager, aby używał backendu iwd
        cat <<EOF | sudo tee /etc/NetworkManager/conf.d/wifi_backend.conf
        [device]
        wifi.backend=iwd
        EOF
        sudo systemctl restart NetworkManager
        ```
    *   Powinieneś teraz móc łączyć się z sieciami Wi-Fi za pomocą apletu sieciowego w zasobniku systemowym.
3.  **Uruchom instalator CachyOS:**
    *   Uruchom instalator CachyOS z pulpitu lub menu aplikacji.
    *   Postępuj zgodnie ze standardową procedurą instalacji, korzystając z przewodnika [Instalacja na partycji root](/pl/installation/installation_on_root).
    *   Podczas partycjonowania wybierz wcześniej utworzoną wolną przestrzeń. Pozwól instalatorowi zająć się formatowaniem.
        :::caution[Uwaga dotycząca partycjonowania]
        Bądź **bardzo ostrożny** podczas etapu partycjonowania w instalatorze. Upewnij się, że wybierasz właściwą, przygotowaną wolną przestrzeń i **nie** usuwaj ani nie formatuj przypadkowo istniejącej partycji macOS, zwłaszcza jeśli zamierzasz korzystać z dual-boot. Sprawdź dwukrotnie swój wybór przed kontynuowaniem.
        :::
    *   Wykrywanie sprzętu CachyOS ([chwd](/pl/features/chwd/chwd)) powinno automatycznie zastosować niezbędne parametry startowe i konfiguracje specyficzne для T2 podczas instalacji.

</Steps>

## Kroki po instalacji

Po zakończeniu instalacji i ponownym uruchomieniu nowego systemu CachyOS może być konieczne wykonanie kilku dodatkowych kroków, aby wszystko działało płynnie.

### Zainstaluj na stałe oprogramowanie sprzętowe Wi-Fi

Jeśli wykonałeś opcjonalny krok [Włącz Wi-Fi w środowisku Live](#proces-instalacji), aby uzyskać oprogramowanie sprzętowe na obrazie live ISO, możesz po prostu powtórzyć ten krok, aby włączyć Wi-Fi. W przeciwnym razie połącz się z internetem (np. przez Ethernet, tethering USB) i wykonaj poniższe kroki:

<Steps>
1. Otwórz terminal i pobierz pakiet oprogramowania sprzętowego z serwera lustrzanego Arch Linux T2:
   ```sh
   curl https://mirror.funami.tech/arch-mact2/os/x86_64/apple-bcm-firmware-14.0-1-any.pkg.tar.zst -o apple-bcm-firmware-14.0-1-any.pkg.tar.zst
   ```
2. Zainstaluj pobrany pakiet:
   ```sh
   sudo pacman -U apple-bcm-firmware-14.0-1-any.pkg.tar.zst
   ```
3. Przeładuj moduły jądra Wi-Fi:
   ```bash
   sudo modprobe -r brcmfmac_wcc
   sudo modprobe -r brcmfmac
   sudo modprobe brcmfmac
   ```
</Steps>

Wi-Fi powinno teraz działać niezawodnie po ponownym uruchomieniu. Możesz usunąć pobrany plik `.pkg.tar.zst`.

### Dalsza konfiguracja
Aby skonfigurować inne komponenty sprzętowe, takie jak dźwięk, kamera internetowa, Touch Bar itp., zapoznaj się z różnymi przewodnikami na [wiki t2linux](https://wiki.t2linux.org/roadmap/#configuring-the-installation).
