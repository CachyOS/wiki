## Zanim zaczniesz

:::note
Jeśli po naciśnięciu **Uruchom Instalator** jedynymi opcjami menedżera rozruchu są GRUB i Limine, oznacza to, że system został uruchomiony w trybie Legacy/BIOS.
:::

:::note[Instalacja wielu środowisk graficznych podczas procesu instalacji jest niedozwolona.]
:::

:::caution[Secure Boot i CSM muszą być wyłączone w ustawieniach BIOS/UEFI podczas instalacji w trybie UEFI.]
Aby skonfigurować Secure Boot po instalacji, zapoznaj się z sekcją [Secure Boot](/pl/configuration/secure_boot_setup).

`Legacy USB Support` powinno być ustawione na `Auto`.
:::

:::caution
Opcje `Zainstaluj obok` i `Zastąp partycję` nie są w 100% niezawodne i mogą spowodować niepowodzenie instalacji.

`Ręczne partycjonowanie` jest **zdecydowanie preferowane** podczas instalacji CachyOS.
:::

:::tip
Zaleca się ponowne uruchomienie komputera z ISO po nieudanej próbie instalacji.

W przeciwnym razie podczas procesu instalacji mogą występować ciągłe błędy.

Dzieje się tak, ponieważ instalator nie odmontowuje poprawnie partycji po nieudanej instalacji.

:::

## Metody instalacji

### Ręczne partycjonowanie

:::note[Przed przystąpieniem do partycjonowania dysku pod instalację UEFI.]
    ```sh title='Wykonaj to polecenie w terminalu'
    efibootmgr -v
    ```
Jeśli wynikiem jest `EFI variables are not supported on this system.`, oznacza to, że system jest uruchomiony w trybie Legacy/BIOS i należy upewnić się, że tryb UEFI jest skonfigurowany w ustawieniach BIOS/UEFI. Zapoznaj się z sekcją [Wymagania](/pl/installation/installation_on_root/#zanim-zaczniesz).
:::

<Steps>

1. Uruchom system z ISO i kliknij **Uruchom Instalator**.

3. Skonfiguruj **Układ klawiatury**.

   - ##### Punkt montowania: **/boot**
   - ##### Flagi: **boot**

   - ##### Rozmiar: Co najmniej **20000 MiB**
   - ##### System plików: **Dowolny**, zapoznaj się z [System plików](/pl/installation/filesystem)
   - ##### Punkt montowania: **/**

## Dual Boot Windows i CachyOS

:::note[Ten poradnik zakłada, że system Windows jest już zainstalowany na komputerze, a ty zdecydowałeś się zainstalować CachyOS obok niego, na tym samym dysku.]
:::

:::caution
Dual boot Windows i Linux nie jest w 100% niezawodny. Aktualizacje Windows mogą uszkodzić program rozruchowy poprzez nadpisanie partycji EFI.
W niektórych przypadkach problemy mogą nigdy nie wystąpić, ale dla niektórych użytkowników może to być powracający problem.

Jednym ze sposobów uniknięcia tego problemu jest zainstalowanie każdego systemu operacyjnego na osobnym dysku.
:::

:::caution
Partycja EFI może wymagać zmiany rozmiaru, w zależności od zalecanego minimalnego rozmiaru dla docelowego menedżera rozruchu. Zapoznaj się z [Ręczne partycjonowanie](/pl/installation/installation_on_root#ręczne-partycjonowanie).

Systemy plików FAT nie mogą być zmieniane w locie. Aby poprawnie „zmienić rozmiar” partycji FAT EFI, należy utworzyć kopię zapasową istniejącego systemu plików EFI, użyć narzędzia takiego jak `gparted` do zmiany rozmiaru istniejącej partycji i sformatowania nowej, a następnie skopiować poprzednią strukturę systemu plików z powrotem na partycję EFI.
:::

### Wymagania wstępne

- Szybkie uruchamianie (Fast Startup) i hibernacja w systemie Windows muszą być wyłączone.
  - Otwórz Windows Powershell jako administrator i wykonaj następujące polecenie:
      ```ps
      powercfg /H off
      ```
    Uruchom ponownie system, aby upewnić się, że zmiany zostały zastosowane.
- Windows BitLocker musi być wyłączony.
  - Sprawdzanie, czy BitLocker jest włączony:
    ```ps title='Otwórz Wiersz polecenia jako administrator i wykonaj następujące polecenie'
    manage-bde -status
    ```
  Jeśli **Metoda szyfrowania** pokazuje `Brak`, to BitLocker jest wyłączony.
- Secure Boot musi być wyłączony.
- Pusta partycja o rozmiarze ≥30 GB.
  - Poradnik, jak zmniejszyć partycję Windows:
    - Naciśnij `Win + R`, wpisz `diskmgmt.msc` i naciśnij Enter, aby otworzyć Zarządzanie dyskami.
    - Zidentyfikuj swoją główną partycję Windows (zwykle C:) i kliknij ją prawym przyciskiem myszy.
    - Kliknij `Zmniejsz wolumin...`, określ co najmniej **30720 MB** (30 GiB) i kliknij `Zmniejsz`.
- Bootowalny pendrive z CachyOS.
  - Zapoznaj się z sekcją [Tworzenie bootowalnego pendrive'a USB z CachyOS](/pl/installation/installation_prepare#tworzenie-bootowalnego-dysku-usb-z-cachyos).

<Tabs>
    <TabItem label='systemd-boot'>
        **Musimy skopiować pliki binarne Windows EFI na partycję EFI Linuksa, aby menedżer rozruchu mógł je rozpoznać.**

        <Steps>
        1. Zlokalizuj **partycję Windows EFI** za pomocą `lsblk`.

            ```sh title='Wykonaj to polecenie w terminalu'
            lsblk -o NAME,FSTYPE,SIZE,MOUNTPOINT
            ```
            ```sh title='Przykładowy wynik'
                        NAME        FSTYPE   SIZE MOUNTPOINT
            zram0               15.3G [SWAP]
            nvme0n1            476.9G
            ├─nvme0n1p1 vfat     100M
            ├─nvme0n1p2           16M
            ├─nvme0n1p3 ntfs   234.4G
            ├─nvme0n1p4 ntfs     830M
            ├─nvme0n1p5 vfat       2G /boot
            └─nvme0n1p6 btrfs  239.6G /var/tmp
            ```
            Partycje EFI są prawie zawsze sformatowane jako `FAT32/vfat`. Ponieważ `nvme0n1p1` nie ma punktu montowania Linuksa, możemy założyć, że ta partycja jest partycją Windows EFI.

        2. Tymczasowo zamontuj partycję Windows EFI.

            ```sh
            sudo mkdir /mnt/WinBoot
            sudo mount /dev/nvme0n1p1 /mnt/WinBoot # Zastąp `nvme0n1p1` nazwą partycji Windows EFI.
            ```

        3. Skopiuj pliki binarne EFI z **partycji Windows EFI** na **partycję EFI Linuksa**.

            ```sh
            sudo cp -r /mnt/WinBoot/EFI/Microsoft/ /boot/EFI
            ```

        4. Odmontuj wcześniej zamontowaną partycję. Windows powinien pojawić się w menu rozruchowym przy następnym uruchomieniu.

            ```sh
            sudo umount /mnt/WinBoot
            sudo rm -r /mnt/WinBoot
            ```

        </Steps>
    </TabItem>

    <TabItem label='GRUB'>
        **GRUB używa os-prober do automatycznego wykrywania partycji Windows EFI i dodawania jej do menu rozruchowego.**

        <Steps>
        1. Zainstaluj **os-prober**.

            ```sh
            sudo pacman -S os-prober
            ```

        2. Włącz **os-prober** w pliku konfiguracyjnym GRUB.

            ```sh title='Naciśnij CTRL+S, aby zapisać i CTRL+Q, aby wyjść z Micro'
            sudo micro /etc/default/grub
            # /etc/default/grub
            # Probing for other operating systems is disabled for security reasons. Read
            # documentation on GRUB_DISABLE_OS_PROBER, if still want to enable this
            # functionality install os-prober and uncomment to detect and include other
            # operating systems.
            GRUB_DISABLE_OS_PROBER=false

            ```

        3. Zaktualizuj grub.cfg, teraz używając **os-prober**.
            ```sh
            sudo grub-mkconfig -o /boot/grub/grub.cfg
            ```

            **Windows powinien teraz zostać dodany do menu rozruchowego.**

        </Steps>
    </TabItem>
