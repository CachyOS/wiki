## Wymagania

:::caution[Secure Boot, CSM i Legacy USB Support muszą być wyłączone w ustawieniach BIOS/UEFI podczas instalacji w trybie UEFI.]
Aby skonfigurować Secure Boot po instalacji, zapoznaj się z sekcją [Konfiguracja Secure Boot](/pl/configuration/secure_boot_setup).
:::

:::caution[Unikaj używania opcji "Zainstaluj obok" w Calamares, ponieważ może to prowadzić do komplikacji i nie jest zalecane.]
:::

:::tip
Zdecydowanie zaleca się ponowne uruchomienie ISO po nieudanej próbie instalacji.

W przeciwnym razie podczas procesu instalacji mogą wystąpić kolejne błędy.

Dzieje się tak, ponieważ instalator nie odmontowuje poprawnie partycji po nieudanej instalacji.

:::

## Metody instalacji

### Wymaż dysk

Opcja "Wymaż dysk" w Calamares wyczyści wybrany dysk i zainstaluje na nim CachyOS.

<Steps>

1. Uruchom system z ISO i kliknij **Uruchom instalator**

2. Wybierz preferowany **Menedżer rozruchu**. Sprawdź sekcję [Menedżery rozruchu](/pl/installation/boot_managers), aby uzyskać więcej informacji.

3. Ustaw preferowany **Język** i **Region/Strefę czasową**

4. Skonfiguruj **Układ klawiatury**

5. Wybierz **Wymaż dysk** i wybierz [System plików](/pl/installation/filesystem).

6. Wybierz preferowane **Środowisko graficzne**, zobacz [Środowiska graficzne](/pl/installation/desktop_environments).

7. Dostosuj, które pakiety powinny, a które nie powinny być instalowane podczas procesu instalacji.

8. Skonfiguruj dane logowania.

9. Dokładnie przejrzyj podsumowanie instalacji na stronie przeglądu. Jeśli wszystko wygląda poprawnie, kontynuuj instalację, klikając **Zainstaluj teraz**. W przeciwnym razie wróć i wprowadź niezbędne zmiany.

</Steps>

### Ręczne partycjonowanie

:::note[Przed przystąpieniem do partycjonowania dysku pod instalację UEFI.]
    ```sh title='Wykonaj to polecenie w terminalu'
    efibootmgr -v
    ```
Jeśli wynik to: `EFI variables are not supported on this system.`, oznacza to, że system został uruchomiony w trybie Legacy/BIOS i musisz upewnić się, że tryb UEFI jest skonfigurowany w ustawieniach BIOS/UEFI. Zapoznaj się z sekcją **[Wymagania](/pl/installation/installation_on_root#_top).**
:::

## Dual Boot Windows i CachyOS

:::note[Ten przewodnik zakłada, że system Windows jest już zainstalowany w systemie i zdecydowałeś się zainstalować CachyOS obok niego, na tym samym dysku.]
:::

:::caution
Dual boot Windows i Linux nie jest w 100% niezawodny. Aktualizacje systemu Windows mogą uszkodzić program rozruchowy, nadpisując partycję EFI.
W niektórych przypadkach problemy mogą nigdy nie wystąpić, ale dla niektórych użytkowników może to być powracający problem.

Jednym ze sposobów uniknięcia tego problemu jest zainstalowanie każdego systemu operacyjnego na oddzielnych dyskach.
:::

- Wymagania wstępne

- Wyłącz Szybkie uruchamianie i Hibernację w Windows
  - Otwórz Windows Powershell jako Administrator i wykonaj następujące polecenie:
      ```ps
      powercfg /H off
      ```
    Uruchom ponownie system, aby upewnić się, że zmiany zostały zastosowane.
- Windows BitLocker musi być wyłączony
  - Sprawdzanie, czy BitLocker jest włączony:
    ```ps title='Otwórz Wiersz polecenia jako administrator i wykonaj następujące polecenie'
    manage-bde -status
    ```
  Jeśli Metoda szyfrowania (Encryption Method) pokazuje `None`, BitLocker jest wyłączony.
- Secure Boot musi być wyłączony.
- Pusta partycja o rozmiarze +30 GB
  - Poradnik, jak zmniejszyć partycję Windows:
    - Naciśnij `Win + R`, wpisz `diskmgmt.msc` i naciśnij Enter, aby otworzyć Zarządzanie dyskami.
    - Zidentyfikuj swoją główną partycję Windows (zwykle C:) i kliknij na nią prawym przyciskiem myszy.
    - Kliknij `Zmniejsz wolumin...` i określ co najmniej **30720MB** (30GB), a następnie kliknij `Zmniejsz`.
- Bootowalny pendrive z CachyOS
  - Zapoznaj się z sekcją [Tworzenie bootowalnego pendrive'a z CachyOS](/pl/installation/installation_prepare#tworzenie-bootowalnego-pendrive-a-usb-z-cachyos).

<Tabs>
    <TabItem label='systemd-boot'>
        **Musimy skopiować pliki binarne Windows EFI na partycję Linux EFI, aby menedżer rozruchu mógł je rozpoznać.**

        <Steps>
        1. Zlokalizuj **partycję Windows EFI** za pomocą `lsblk`

            ```sh title='Wykonaj to polecenie w terminalu'
            lsblk -o NAME,FSTYPE,SIZE,MOUNTPOINT
            ```
            ```sh title='Przykładowy wynik'
                        NAME        FSTYPE   SIZE MOUNTPOINT
            zram0               15.3G [SWAP]
            nvme0n1            476.9G
            ├─nvme0n1p1 vfat     100M
            ├─nvme0n1p2           16M
            ├─nvme0n1p3 ntfs   234.4G
            ├─nvme0n1p4 ntfs     830M
            ├─nvme0n1p5 vfat       2G /boot
            └─nvme0n1p6 btrfs  239.6G /var/tmp
            ```
            Partycje EFI są prawie zawsze sformatowane jako `FAT32/vfat`. Ponieważ `nvme0n1p1` nie ma punktu montowania w Linuksie, możemy założyć, że ta partycja jest partycją Windows EFI.

        2. Tymczasowo zamontuj partycję Windows EFI

            ```sh
            sudo mkdir /mnt/WinBoot
            sudo mount /dev/nvme0n1p1 /mnt/WinBoot # Zastąp `nvme0n1p1` nazwą partycji Windows EFI.
            ```

        3. Skopiuj pliki binarne EFI z **partycji Windows EFI** na **partycję Linux EFI**:

            ```sh
            sudo cp -r /mnt/WinBoot/EFI/* /boot/EFI
            ```

        4. Odmontuj wcześniej zamontowaną partycję, a Windows powinien pojawić się w menu rozruchowym przy następnym uruchomieniu.

            ```sh
            sudo umount /mnt/WinBoot
            sudo rm -r /mnt/WinBoot
            ```

        </Steps>
    </TabItem>

    <TabItem label='GRUB'>
        **GRUB używa os-prober do automatycznego wykrywania partycji Windows EFI i dodawania jej do menu rozruchowego.**

        <Steps>
        1. Zainstaluj i uruchom **os-prober**

            ```sh
            sudo pacman -S os-prober
            sudo os-prober
            ```

        2. Włącz **os-prober** w pliku konfiguracyjnym GRUB

            ```sh title='Naciśnij CTRL+S, aby zapisać i CTRL+Q, aby wyjść z Micro'
            sudo micro /etc/default/grub
            # /etc/default/grub
            # Probing for other operating systems is disabled for security reasons. Read
            # documentation on GRUB_DISABLE_OS_PROBER, if still want to enable this
            # functionality install os-prober and uncomment to detect and include other
            # operating systems.
            GRUB_DISABLE_OS_PROBER=false

            sudo grub-mkconfig -o /boot/grub/grub.cfg
            ```

            **Windows powinien teraz zostać dodany do menu rozruchowego.**

        </Steps>
    </TabItem>
</Tabs>
