## ISO-nerladdning

CachyOS ISO kan hämtas från följande källor:

*   [Webbplats](<https://cachyos.org/download>)
*   [SourceForge](<https://sourceforge.net/projects/cachyos-arch/files/>)
*   [CachyOS Mirror](<https://mirror.cachyos.org/ISO/>)

## Verifiera ISO-integritet med SHA256

:::caution[VARNING]
Ta alltid det extra steget och verifiera ISO:ns integritet för att undvika oönskade problem vid installation eller vid skapande av bootningsbart media.
Always take an extra step to verify the ISO's integrity to avoid any undesired issues at installation or while creating a bootable media.
:::

**Aktuell ISO-version:** `250713`

**SHA256-hash:** `22a1e3386a1a25c433f1b9dd5272062856d8311ee637900c5017df7fa40bf627`

<Tabs>

<TabItem label='Windows'>

<Steps>

1. Ladda ner [filen](https://mirror.cachyos.org/ISO/desktop/250713/cachyos-desktop-linux-250713.iso.sha256) som innehåller SHA256-hashet **(Öppna med en textredigerare så som Anteckningar).**
2. Öppna CMD eller PowerShell som Administratör och [navigera](<https://www.wikihow.com/Change-Directories-in-Command-Prompt>) till sökvägen där ISO- och SHA256-filerna lagras.
3. Utför följande kommando:
   ```powershell
   # Exempel:
   certUtil -hashfile cachyos-desktop-linux-250713.iso SHA256
   ```
4. Jämför certUtil-hashutdatan med den i den nerladdade filen i **Steg 1**. Om de matchar så kan du fortsätta med CachyOS-installationen.

</Steps>

</TabItem>

<TabItem label='Linux'>

<Steps>

1. Ladda ner [filen](https://mirror.cachyos.org/ISO/desktop/250713/cachyos-desktop-linux-250713.iso.sha256) som innehåller SHA256-hashet.
2. Öppna en terminal, navigera till mappen som innehåller `.sha256`-filen, och utför följande kommandon:
   ```sh
   # Exempel:
   cd Downloads/
   cat cachyos-desktop-linux-250713.iso.sha256
   # 22a1e3386a1a25c433f1b9dd5272062856d8311ee637900c5017df7fa40bf627
   ```
3. Jämyör utdatan från **Steg 2** och utför följande kommando för att kontrollera ISO-filens hash:
   ```sh
   # Exempel:
   sha256sum cachyos-desktop-linux-250713.iso
   ```
4. Om hashen från **Steg 2** och **Steg 3** matchar, kan du fortsätta med CachyOS-installationen.

</Steps>

</TabItem>

## Vefiriera ISO-avbildens äkthet (Linux)

För att verifiera ISO-filen och för att vara säker på att det är den officiella som släppts av CachyOS-utvecklingsteamet:

<Steps>

1. Importera GPG-nyckeln för att verifiera äktheten:

   ```shell
   gpg --keyserver hkps://keys.openpgp.org --recv-key F3B607488DB35A47
   ```

2. Ladda ner ISO-filen och dess `.sig`-signaturfil och utför följande kommando (genom att ersätta `full_iso_name.iso` med det faktiska ISO-filnamnet):
   ```shell
   gpg --verify full_iso_name.iso.sig full_iso_name.iso
   ```

   Om du får **Good signature** som utdata är ISO-filen äkta:
   ```
   gpg: Signature made Mo 01 Apr 2024 14:13:30 CEST
   gpg:                using RSA key 882DCFE48E2051D48E2562ABF3B607488DB35A47
   gpg: Good signature from "CachyOS <admin@cachyos.org>" [unknown]
   gpg: WARNING: This key is not certified with a trusted signature!
   gpg:          There is no indication that the signature belongs to the owner.
   Primary key fingerprint: 882D CFE4 8E20 51D4 8E25  62AB F3B6 0748 8DB3 5A47
   ```

</Steps>

:::danger
Om utdatan inte returnerar en **Good signature**-sträng eller om nyckel-ID:t inte matchar, använd inte ISO-avbildningen. SÅ till att den nerladdade avbilden 
kommer från en legitim CachyOS-källa, eftersom en ogiltig signatur troligen betyder att ISO:n har manipulerats.
:::
