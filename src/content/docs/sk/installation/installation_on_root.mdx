## Pred začatím

:::note
Ak sa vám po stlačení **Launch Installer** zobrazia ako možnosti zavádzača iba GRUB a Limine, systém je spustený v režime Legacy/BIOS.
:::

:::note[Inštalácia viacerých desktopových prostredí nie je počas procesu inštalácie povolená.]
:::

:::caution[Secure Boot a CSM musia byť pri inštalácii v režime UEFI v nastaveniach BIOS/UEFI vypnuté.]
Ak chcete nastaviť Secure Boot po inštalácii, pozrite si sekciu [Secure Boot](/sk/configuration/secure_boot_setup).

Možnosť `Legacy USB Support` by mala byť nastavená na `Auto`.
:::

:::caution
Možnosti `Install alongside` a `Replace partition` nie sú 100 % spoľahlivé a môžu spôsobiť zlyhanie inštalácie.

Pri inštalácii CachyOS sa **dôrazne uprednostňuje** `Manuálne rozdelenie disku`.
:::

:::tip
Po neúspešnom pokuse o inštaláciu sa dôrazne odporúča reštartovať do ISO obrazu.

V opačnom prípade sa môžu počas procesu inštalácie vyskytovať opakované chyby.

Stáva sa to preto, lebo inštalátor pri neúspešnej inštalácii správne neodpojí partície.

:::

## Spôsoby inštalácie

### Manuálne rozdelenie disku

:::note[Pred pokračovaním v rozdeľovaní disku pre inštaláciu v režime UEFI.]
    ```sh title='Spustite tento príkaz v termináli'
    efibootmgr -v
    ```
Ak je výstup `EFI variables are not supported on this system.`, systém je spustený v režime Legacy/BIOS a musíte zabezpečiť, aby bol v nastaveniach BIOS/UEFI nakonfigurovaný režim UEFI. Pozrite si sekciu [Požiadavky](/sk/installation/installation_on_root/#pred-začatím).
:::

## Duálne zavádzanie Windows a CachyOS

:::note[Tento sprievodca predpokladá, že v systéme je už nainštalovaný Windows a rozhodli ste sa popri ňom nainštalovať CachyOS na ten istý disk.]
:::

:::caution
Duálne zavádzanie Windows a Linuxu nie je 100 % spoľahlivé. Aktualizácie Windows môžu poškodiť zavádzač prepísaním EFI partície.
V niektorých prípadoch sa problémy nemusia nikdy vyskytnúť, no pre niektorých používateľov to môže byť opakujúci sa problém.

Jedným zo spôsobov, ako sa tomuto problému vyhnúť, je nainštalovať každý operačný systém na samostatný disk.
:::

:::caution
Veľkosť EFI partície môže byť potrebné zmeniť v závislosti od odporúčanej minimálnej veľkosti pre cieľový zavádzač. Pozrite si sekciu [Manuálne rozdelenie disku](/sk/installation/installation_on_root#manuálne-rozdelenie-disku).

Súborové systémy FAT nie je možné zväčšiť ani zmenšiť priamo na mieste. Na správnu „zmenu veľkosti“ FAT EFI partície je potrebné zálohovať existujúci EFI súborový systém, použiť nástroj ako `gparted` na zmenu veľkosti existujúcej partície a preformátovanie novej partície a potom skopírovať pôvodnú štruktúru súborového systému späť na EFI partíciu.
:::

### Požiadavky

- Funkcie Fast Startup (Rýchle spustenie) a Hibernation (Dlhodobý spánok) vo Windows musia byť vypnuté.
  - Otvorte Windows PowerShell ako správca a spustite nasledujúci príkaz:
      ```ps
      powercfg /H off
      ```
    Reštartujte systém, aby sa zmeny prejavili.
- Windows BitLocker musí byť vypnutý.
  - Kontrola, či je BitLocker zapnutý:
    ```ps title='Otvorte Príkazový riadok ako správca a spustite nasledujúci príkaz'
    manage-bde -status
    ```
  Ak položka **Encryption Method** zobrazuje `None`, BitLocker je vypnutý.
- Secure Boot musí byť vypnutý.
- Prázdna partícia s veľkosťou ≥ 30 GB.
  - Návod na zmenšenie partície Windows:
    - Stlačte `Win + R`, zadajte `diskmgmt.msc` a stlačte Enter na otvorenie nástroja Správa diskov (Disk Management).
    - Nájdite hlavnú partíciu Windows (zvyčajne C:) a kliknite na ňu pravým tlačidlom myši.
    - Kliknite na `Shrink Volume...` (`Zmenšiť zväzok...`), zadajte aspoň **30720 MB** (30 GiB) a kliknite na `Shrink` (`Zmenšiť`).
- Bootovací USB disk s CachyOS.
  - Pozrite si sekciu [Vytvorenie bootovacieho USB disku CachyOS](/sk/installation/installation_prepare#vytvorenie-bootovacieho-usb-disku-cachyos).

<Tabs>
    <TabItem label='Limine'>
        Limine by mal automaticky rozpoznať EFI partíciu Windows a pridať ju do ponuky zavádzania. Ak sa Windows v ponuke zavádzania nezobrazí, spustite nasledujúci príkaz:
        ```bash
        sudo limine-scan
        ```
    </TabItem>
    <TabItem label='systemd-boot'>
        **Musíme skopírovať binárne súbory Windows EFI na linuxovú EFI partíciu, aby ich zavádzač dokázal rozpoznať.**

        <Steps>
        1. Nájdite **Windows EFI partíciu** pomocou `lsblk`.

            ```sh title='Spustite tento príkaz v termináli'
            lsblk -o NAME,FSTYPE,SIZE,MOUNTPOINT
            ```
            ```sh title='Príklad výstupu'
                        NAME        FSTYPE   SIZE MOUNTPOINT
            zram0               15.3G [SWAP]
            nvme0n1            476.9G
            ├─nvme0n1p1 vfat     100M
            ├─nvme0n1p2           16M
            ├─nvme0n1p3 ntfs   234.4G
            ├─nvme0n1p4 ntfs     830M
            ├─nvme0n1p5 vfat       2G /boot
            └─nvme0n1p6 btrfs  239.6G /var/tmp
            ```
            EFI partície sú takmer vždy naformátované ako `FAT32/vfat`. Keďže `nvme0n1p1` nemá linuxový prípojný bod, môžeme predpokladať, že táto partícia je Windows EFI partícia.

        2. Dočasne pripojte Windows EFI partíciu.

            ```sh
            sudo mkdir /mnt/WinBoot
            sudo mount /dev/nvme0n1p1 /mnt/WinBoot # Nahraďte `nvme0n1p1` názvom Windows EFI partície.
            ```

        3. Skopírujte binárne súbory EFI z **Windows EFI partície** na **linuxovú EFI partíciu**.

            ```sh
            sudo cp -r /mnt/WinBoot/EFI/Microsoft/ /boot/EFI
            ```

        4. Odpojte predtým pripojenú partíciu. Windows by sa mal pri nasledujúcom spustení zobraziť v ponuke zavádzania.

            ```sh
            sudo umount /mnt/WinBoot
            sudo rm -r /mnt/WinBoot
            ```

        </Steps>
    </TabItem>

    <TabItem label='GRUB (Iba pre staršie inštalácie)'>
        :::tip[CachyOS predvolene povoľuje os-prober.]
        :::
        **GRUB používa os-prober na automatické zistenie Windows EFI partície a jej pridanie do ponuky zavádzania.**

        <Steps>
        1. Nainštalujte **os-prober**.

            ```sh
            sudo pacman -S os-prober
            ```

        2. Povoľte **os-prober** v konfiguračnom súbore GRUB.

            ```sh title='Pre uloženie stlačte CTRL+S a pre ukončenie v editore Micro stlačte CTRL+Q'
            sudo micro /etc/default/grub
            # /etc/default/grub
            # Probing for other operating systems is disabled for security reasons. Read
            # documentation on GRUB_DISABLE_OS_PROBER, if still want to enable this
            # functionality install os-prober and uncomment to detect and include other
            # operating systems.
            GRUB_DISABLE_OS_PROBER=false

            ```

        3. Aktualizujte grub.cfg teraz už s použitím **os-prober**.
            ```sh
            sudo grub-mkconfig -o /boot/grub/grub.cfg
            ```

            **Windows by teraz mal byť pridaný do ponuky zavádzania.**

        </Steps>
    </TabItem>
</Tabs>
