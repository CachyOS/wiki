:::note
Niri je posuvne-dlaždicový (scrollable-tiling) Wayland kompozítor, ktorý ponúka jedinečný prístup k správe okien prostredníctvom svojho stĺpcového systému rozloženia.
:::

Naším hlavným cieľom pri tomto nastavení je mať funkčnú konfiguráciu Niri, ktorá poskytuje plynulý a intuitívny desktopový zážitok a zároveň zachováva konfiguráciu jednoduchú a prístupnú.

Pozrite si naše [často kladené otázky (FAQ) pre Niri.](/sk/configuration/desktop_environments/niri#faq)

**Konfiguračné súbory spravuje [Ly-sec](https://github.com/Ly-sec)**
V prípade problémov súvisiacich s Noctalia si prosím pozrite [dokumentáciu Noctalia](https://docs.noctalia.dev/).

## Klávesové skratky

Väčšina klávesových kombinácií vyžaduje použitie modifikačného klávesu, ktorým je v našom prípade kláves Windows (označovaný ako SUPER); môžete ho zmeniť v konfiguračnom súbore.

### Ovládanie aplikácií

| Popis | Kláves |
|-------|--------|
| Otvorenie terminálu | <Kbd linux="Super+Return" /> |
| Otvorenie spúšťača programov | <Kbd linux="Super+Ctrl+Return" /> |
| Otvorenie prehliadača (Firefox) | <Kbd linux="Super+B" /> |
| Otvorenie správcu súborov | <Kbd linux="Super+E" /> |

## FAQ

### Čím sa Niri líši od ostatných správcov okien?

Niri využíva jedinečný posuvne-dlaždicový prístup, pri ktorom sú okná usporiadané do stĺpcov, ktoré sa dajú posúvať horizontálne. Poskytuje to metaforu nekonečnej pracovnej plochy, čo je obzvlášť užitočné pre ultraširokouhlé monitory a pracovné postupy vyžadujúce mnoho otvorených aplikácií.

### Ako zmením rozloženie klávesnice?

Upravte sekciu `input` vo vašom konfiguračnom súbore:

```txt title='Príklad'
input {
    keyboard {
        xkb {
            layout "us" // Zmeňte z "de" na vaše preferované rozloženie
        }
    }
}
```

### Môžem si prispôsobiť medzery a vzhľad okien?

Áno, môžete upraviť sekciu `layout`:

```txt title='Príklad'
layout {
    gaps 8 // Zmeňte veľkosť medzery

    focus-ring {
        width 2
        active-color "#your-color"
        inactive-color "#your-color"
    }
}
```

### Ako pridám ďalšie aplikácie spúšťané pri štarte?

Pridajte ich do sekcie spúšťania pri štarte:

```txt title='Príklad'
spawn-at-startup "your-application"
```

### Na čo slúži kláves núdzového úniku?

Klávesová skratka `Super+Escape` je určená na obnovenie ovládania, keď celoobrazovková aplikácia zablokuje vaše klávesové skratky. Vypne akýkoľvek aktívny blokátor klávesových skratiek.

### Ako nastavím viacero monitorov?

Odkomentujte a upravte sekciu `output` pre vaše konkrétne displeje. Spustite `niri msg outputs`, aby ste získali správne názvy:

```txt title='Príklad'
output "DP-1" {
    mode "1920x1080@60.000"
    scale 1
}
```
