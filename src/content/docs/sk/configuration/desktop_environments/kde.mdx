## Ako nainštalovať chýbajúcu reláciu X11

Po tom, čo sa KDE rozhodlo rozdeliť vývoj do viacerých balíkov, bola relácia X11 odstránená z predvolenej inštalácie.

```sh
sudo pacman -S plasma-x11-session kwin-x11
```
Po dokončení sa X11 zobrazí ako možnosť na prihlasovacej obrazovke.

## Ako nainštalovať chýbajúci xorg-server
Od verzie 26.01 inštalátora CachyOS už `xorg-server` nie je nainštalovaný a ani `plasma-x11-session`, ani `kwin-x11` ho nemajú ako závislosť. V dôsledku toho, ak Xorg server a súvisiace komponenty nenainštalujete manuálne, zobrazí sa pri prihlásení čierna obrazovka.

```sh
sudo pacman -S xorg-server
```

## Často kladené otázky (FAQ)

### Ako môžem získať rovnaký vzhľad, ako je zobrazený na snímkach obrazovky KDE, pomenovaný ako „Emerald“?

- Je to kombinácia témy Emerald + témy ikon Qogir, ktoré nie sú predvolene nainštalované.
  - ```sh title='Nainštalujte oboje pomocou nasledujúceho príkazu'
    sudo pacman -S cachyos-emerald-kde-theme-git qogir-icon-theme
    ```
  Aplikujte oboje v `Vzhľad a štýl - Farby a motívy`

### Prihlasovacia obrazovka KDE nezrkadlí vzhľad mojej pracovnej plochy, ako to môžem opraviť?

:::tip[Toto funguje pre SDDM aj pre Plasma Login Manager.]
:::
