## systemd-boot

systemd-boot má dva druhy konfiguračných súborov: jeden pre samotný systemd-boot v `/boot/loader/loader.conf` a jeden pre každú
jednotlivú položku jadra v `/boot/loader/entry`.

### Konfigurácia zavádzača

V tomto konfiguračnom súbore môžete zmeniť predvolenú položku a časový limit systemd-boot

```shell
# /boot/loader/loader.conf

default @saved
timeout 5
#console-mode keep # Táto možnosť konfiguruje rozlíšenie konzoly.
```

### Konfigurácia príkazového riadku jadra

Poskytujeme nástroj na jednoduchšiu konfiguráciu systemd-boot: [`sdboot-manage`](https://github.com/CachyOS/CachyOS-PKGBUILDS/tree/master/systemd-boot-manager).
Jednou z výhod tohto nástroja je globálna konfigurácia príkazového riadku jadra. Konfiguračný súbor pre `sdboot-manage` sa nachádza v `/etc/sdboot-manage.conf`.

Upravte riadok `LINUX_OPTIONS=` v `/etc/sdboot-manage.conf` na zmenu parametrov jadra.

```shell
# /etc/sdboot-manage.conf
LINUX_OPTIONS="zswap.enabled=0 nowatchdog quiet splash"
```

Po vykonaní zmien znova vygenerujte všetky položky systemd-boot pomocou nasledujúceho príkazu

```shell
sudo sdboot-manage gen
```

## rEFInd

Podobne ako [systemd-boot](/sk/configuration/boot_manager_configuration#systemd-boot), aj rEFInd má dva konfiguračné súbory. `refind.conf` sa nachádza v
`boot/efi/EFI/refind` a slúži hlavne na zmenu správania rEFInd, zatiaľ čo `/boot/refind_linux.conf` slúži na správu vašich možností spustenia.
`refind.conf` obsahuje rozsiahle komentáre, ktoré vysvetľujú všetky jeho možnosti.

### Konfigurácia príkazového riadku jadra

Ak chcete odovzdať parametre jadra do príkazového riadku, upravte „Boot using default options“ v `/boot/refind_linux.conf`

```shell
# /boot/refind_linux.conf

"Boot using default options"     "root=PARTUUID=1cb353ec-7f03-4820-8b4b-03baf53a208f rw zswap.enabled=0 nowatchdog quiet splash"
```

Zmeny v oboch konfiguračných súboroch sa prejavia okamžite. Spúšťanie príkazu na „uloženie“ zmien nie je potrebné.

## GRUB

Na rozdiel od [systemd-boot](/sk/configuration/boot_manager_configuration#systemd-boot) a [rEFInd](/sk/configuration/boot_manager_configuration#refind),
GRUB má iba jeden konfiguračný súbor, ktorý sa nachádza v `/etc/default/grub`. V tomto súbore je pomerne dobrá dokumentácia, ktorá vysvetľuje, čo
každá možnosť robí.

### Skrytie ponuky zavádzania GRUB

Ak chcete skryť ponuku GRUB, jednoducho nastavte nasledujúce možnosti zodpovedajúcim spôsobom.

```shell
# /etc/default/grub

GRUB_TIMEOUT='0'
GRUB_TIMEOUT_STYLE=hidden
```

Stlačením klávesu ESC získate prístup k príkazovému riadku GRUB. Odtiaľto spustite `normal` alebo `exit`, aby ste sa vrátili do známej ponuky zavádzania GRUB.

### Konfigurácia príkazového riadku jadra

Ak chcete odovzdať parametre jadra do príkazového riadku pomocou GRUB, musíte upraviť `GRUB_CMDLINE_LINUX_DEFAULT` v súbore `/etc/default/grub`.

```shell
# /etc/default/grub

GRUB_CMDLINE_LINUX_DEFAULT='nowatchdog zswap.enabled=0 quiet splash'
```

Zakaždým, keď upravíte konfiguračný súbor GRUB, musíte znova vytvoriť konfiguráciu pomocou nasledujúceho príkazu:

```shell
sudo grub-mkconfig -o /boot/grub/grub.cfg
```

### Spustiteľné snímky BTRFS

:::note
Ak vaša inštalácia CachyOS pochádza spred augustového vydania, možno budete musieť funkciu spustiteľných snímok BTRFS povoliť manuálne.

V opačnom prípade môžete túto sekciu preskočiť, pretože od augustového vydania je povolená predvolene.
:::

Ak chcete túto funkciu povoliť, nainštalujte balík grub-btrfs-support:

```sh
sudo pacman -S grub-btrfs-support
```

Tento balík nainštaluje potrebné skripty a háčiky (hooks) na automatické rozpoznanie snímok BTRFS a ich pridanie do ponuky GRUB.

Po nainštalovaní sa vaše snímky zobrazia v ponuke GRUB podobne, ako sa správa Limine.


## Limine

Limine je moderný zavádzač známy svojou jednoduchou konfiguráciou. Táto príručka pokrýva základy pre rýchly štart.

Konfigurácia prebieha primárne v súbore `/boot/limine.conf` (alebo niekedy na systémovej partícii EFI) pre nastavenia ponuky a v `/etc/default/limine` pre parametre jadra.

### Konfigurácia ponuky zavádzania

Tento súbor riadi správanie a vzhľad ponuky zavádzania. Zmeny vykonané tu sa prejavia okamžite po uložení – nie sú potrebné žiadne ďalšie príkazy.

* **Časový limit:** Nastavuje, koľko sekúnd Limine čaká pred automatickým spustením predvolenej položky.

  ```shell
  # /boot/limine.conf

  timeout: 5
  ```

* **Predvolená položka:** Určuje, ktorá položka ponuky sa spustí predvolene. Položky sú číslované od 1. Ak nie je nastavená, predvolená hodnota je 1.

  ```shell
  # /boot/limine.conf

  default_entry: 2 # Predvolene spustí druhú položku
  ```

  :::tip
   Ak `default_entry` ukazuje na priečinok (napr. `/+CachyOS`), automatické spustenie bude vypnuté. Ak chcete automaticky spustiť položku v priečinku, `default_entry` musí ukazovať priamo na číslo danej konkrétnej položky.
  :::

Príklad (`/boot/limine.conf`):

```shell
# /boot/limine.conf

timeout: 5
default_entry: 2 # Ukazuje priamo na položku 'linux-cachyos' nižšie

/+CachyOS        # Položka 1: Priečinok (použite /+ na predvolené rozbalenie)
//linux-cachyos  # Položka 2: Skutočná spustiteľná položka
    protocol: linux
    kernel_path: boot():/vmlinuz-linux-cachyos
    cmdline: quiet splash root=UUID=... rw # Základné parametre jadra
    module_path: boot():/initramfs-linux-cachyos.img
```

:::note
`boot():/` označuje koreň zavádzacieho disku.
:::

### Vzhľad (Témy)

Vizuálny vzhľad ponuky zavádzania Limine si môžete prispôsobiť:

* **Pozadie:** Nastavte obrázok na pozadí. Podporované formáty sú BMP, PNG a JPEG.

  ```shell
  # /boot/limine.conf

  wallpaper: boot():/splash.png
  wallpaper_style: stretched # Možnosti: 'stretched', 'tiled', 'centered'
  backdrop: 000000           # Farba pozadia (RRGGBB hex), ak je štýl 'centered'
  ```

* **Písma:** Použite [vlastný súbor písma](https://github.com/viler-int10h/vga-text-mode-fonts) a upravte jeho veľkosť.

  ```shell
  # /boot/limine.conf

  term_font: boot():/custom_font.F16
  term_font_scale: 2x2 # Zmení mierku písma, užitočné pre displeje s vysokým rozlíšením
  ```

* **Farby:** Upravte farby textu a pozadia terminálu.

  ```shell
  # /boot/limine.conf

  term_background: 80000000 # Príklad: Polopriehľadná čierna (AARRGGBB)
  # K dispozícii sú aj ďalšie možnosti farieb, napríklad term_foreground atď.
  ```

### Konfigurácia príkazového riadku jadra

V systéme CachyOS sú položky jadra v ponuke zavádzania Limine **spravované automaticky**. Keď nainštalujete alebo odstránite jadrá, `limine-mkinitcpio-hook` na pozadí použije nástroj `limine-entry-tool` na aktualizáciu položiek zavádzania.

Hoci sú položky spravované automaticky, môžete **nakonfigurovať parametre jadra** (známe aj ako príkazový riadok jadra), ktoré sa jadru odovzdávajú pri spustení.

1. **Upravte konfiguračný súbor:** Upravte premenné `KERNEL_CMDLINE` v súbore `/etc/default/limine`. Môžete nastaviť predvolené parametre pre všetky jadrá alebo konkrétne parametre pre určité názvy jadier (napr. `linux-cachyos`).

   ```shell
   # /etc/default/limine

   # Predvolené parametre pre väčšinu jadier
   KERNEL_CMDLINE[default]="quiet splash rd.udev.log_priority=3"

   # Konkrétne parametre pre jadro 'linux-cachyos'
   KERNEL_CMDLINE["linux-cachyos"]="quiet splash mitigations=off"

   # Parametre pre záložné (fallback) položky (ak sú vygenerované)
   # KERNEL_CMDLINE[fallback]="..."
   ```

2. **Použite zmeny:** Po uložení súboru `/etc/default/limine` je potrebné znova vygenerovať obrazy initramfs a aktualizovať položky Limine, aby sa použili nové parametre jadra. Spustite nasledujúci príkaz:

   ```bash
   sudo limine-mkinitcpio
   ```

   Tento príkaz spustí proces `mkinitcpio`, ktorý zahŕňa `limine-mkinitcpio-hook`, čím zabezpečí, že vaše zmeny v `/etc/default/limine` sa zapracujú do položiek zavádzania v `/boot/limine.conf`.
