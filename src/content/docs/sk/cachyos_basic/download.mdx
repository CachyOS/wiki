## Oficiálne zdroje ISO

ISO obraz CachyOS je možné získať z nasledujúcich zdrojov:

*   [Webstránka](<https://cachyos.org/download>)
*   [SourceForge](<https://sourceforge.net/projects/cachyos-arch/files/>)
*   [Zrkadlo CachyOS](<https://mirror.cachyos.org/ISO/>)

## Overenie integrity ISO obrazu pomocou SHA256

:::caution
Vždy urobte krok navyše a overte integritu ISO obrazu, aby ste predišli akýmkoľvek nežiaducim problémom počas inštalácie alebo pri vytváraní bootovacieho média.
:::

**Aktuálna verzia ISO:** `260809`

**SHA256 hash:** `959f6577f45e25ee9fd8c220fd221b08e4ea79412c7315c0f922dd6d86d5e33c`

<Tabs>

<TabItem label='Windows'>

<Steps>

1. Stiahnite si [súbor](https://mirror.cachyos.org/ISO/desktop/260809/cachyos-desktop-linux-260809.iso.sha256) obsahujúci SHA256 hash **(otvorte ho v textovom editore, napr. Poznámkový blok)**.
2. Otvorte CMD alebo PowerShell ako správca a [prejdite](<https://www.wikihow.com/Change-Directories-in-Command-Prompt>) do cesty, kde sú uložené súbory ISO a SHA256.
3. Spustite nasledujúci príkaz:
   ```powershell
   # Príklad:
   certUtil -hashfile cachyos-desktop-linux-260809.iso SHA256
   ```
4. Porovnajte výstup hashu z nástroja certUtil s hashom zo stiahnutého súboru v **Kroku 1**. Ak sa zhodujú, môžete pokračovať v inštalácii CachyOS.

</Steps>

</TabItem>

<TabItem label='Linux'>

<Steps>

1. Stiahnite si [súbor](https://mirror.cachyos.org/ISO/desktop/260809/cachyos-desktop-linux-260809.iso.sha256) obsahujúci SHA256 hash.
2. Otvorte terminál a prejdite do adresára obsahujúceho súbory `.sha256` aj `.iso`.
3. Spustite nasledujúce príkazy:
   ```sh
   # Príklad:
   cd ~/Downloads
   sha256sum -c cachyos-desktop-linux-260809.iso.sha256
   # cachyos-desktop-linux-260809.iso: OK
   ```
4. Ak je výstup z **Kroku 3** `OK`, môžete pokračovať v inštalácii CachyOS.

</Steps>

</TabItem>

<TabItem label='macOS'>

<Steps>

1. Stiahnite si [súbor](https://mirror.cachyos.org/ISO/desktop/260809/cachyos-desktop-linux-260809.iso.sha256) obsahujúci SHA256 hash.
2. Otvorte terminál, prejdite do adresára obsahujúceho súbor `.sha256` a spustite nasledujúce príkazy:
   ```sh
   # Príklad:
   cd Downloads/
   cat cachyos-desktop-linux-260809.iso.sha256
   # 959f6577f45e25ee9fd8c220fd221b08e4ea79412c7315c0f922dd6d86d5e33c
   ```
3. Porovnajte výstup z **Kroku 2** s hashom súboru ISO:
   ```sh
   # Príklad:
   shasum -a 256 cachyos-desktop-linux-260809.iso
   ```
4. Ak sa hashe z **Kroku 2** a **Kroku 3** zhodujú, môžete pokračovať v inštalácii CachyOS.

</Steps>

</TabItem>

</Tabs>

## Overenie autenticity ISO obrazu (Linux)

Na overenie autenticity ISO súboru:

<Steps>

1. Importujte GPG kľúč ako referenciu na porovnanie:

   ```shell
   gpg --keyserver hkps://keys.openpgp.org --recv-key F3B607488DB35A47
   ```

2. Stiahnite si ISO súbor a jeho podpisový súbor [.sig](https://cdn77.cachyos.org/ISO/desktop/260809/cachyos-desktop-linux-260809.iso.sig) a spustite nasledujúci príkaz (nahraďte `full_iso_name.iso` skutočným názvom ISO súboru):
   ```shell
   gpg --verify full_iso_name.iso.sig full_iso_name.iso
   ```

   Ak dostanete výstup **Good signature**, ISO súbor je pravý:
   ```
   gpg: Signature made dom 09 ago 2026 13:30:06 -03
   gpg:                using RSA key 882DCFE48E2051D48E2562ABF3B607488DB35A47
   gpg: Good signature from "CachyOS <admin@cachyos.org>" [unknown]
   gpg: WARNING: This key is not certified with a trusted signature!
   gpg:          There is no indication that the signature belongs to the owner.
   Primary key fingerprint: 882D CFE4 8E20 51D4 8E25  62AB F3B6 0748 8DB3 5A47
   ```

</Steps>

:::danger
Ak výstup nevráti reťazec **Good signature** alebo sa ID kľúča nezhoduje, ISO obraz nepoužívajte. Zlý podpis naznačuje, že s ISO obrazom bolo manipulované alebo je poškodený.

Uistite sa, že stiahnutý obraz pochádza z [legitímneho zdroja CachyOS](/sk/cachyos_basic/download#oficiálne-zdroje-iso).
:::
