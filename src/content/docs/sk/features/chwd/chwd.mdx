[Detekcia hardvéru CachyOS](https://github.com/CachyOS/chwd/) (známejšia ako `chwd`) nám umožňuje podporovať rôzne druhy hardvéru inštaláciou potrebných
balíkov a ovládačov pre spustený systém. To zahŕňa systémy s grafickými kartami NVIDIA, MacBooky T2 a vreckové zariadenia ako Steam Deck a ROG Ally.

## Použitie

`chwd` sa zvyčajne spúšťa počas inštalácie na poskytnutie potrebných balíkov pre systém. Je však možné
ho použiť aj po inštalácii.

### Automatická konfigurácia

`chwd` podporuje inštaláciu a konfiguráciu potrebných ovládačov a balíkov, aby systém mohol pracovať v optimálnych podmienkach.

```sh
sudo chwd -a
```

### Ostatné

Syntax príkazov a ďalšie použitie nájdete vo výstupe pomocníka pre `chwd`.

```sh
chwd --help
Usage: chwd [OPTIONS]

Options:
  -i, --install <profile>          Install profile
  -r, --remove <profile>           Remove profile
  -d, --detail                     Show detailed info for listings
  -f, --force                      Force reinstall
      --list-installed             List installed kernels
      --list                       List available profiles for all devices
      --list-all                   List all profiles
  -a, --autoconfigure [<classid>]  Autoconfigure
      --ai_sdk                     Toggle AI SDK profiles
      --pmcachedir <PMCACHEDIR>    [default: /var/cache/pacman/pkg]
      --pmconfig <PMCONFIG>        [default: /etc/pacman.conf]
      --pmroot <PMROOT>            [default: /]
  -h, --help                       Print help
  -V, --version                    Print version
```
