---
title: Enviar solicitudes de paquetes a CachyOS
description: Solicitudes de paquetes para paquetes de AUR, ...
---

CachyOS ofrece una extensa lista de paquetes de AUR precompilados que son de uso común.
Los usuarios pueden crear solicitudes para paquetes de AUR que, si se aprueban, nuestro servidor de compilación actualizará automáticamente.

Si quieres que añadamos un paquete, puedes enviar una solicitud en GitHub o en el foro.

- GitHub: <https://github.com/CachyOS/distribution/issues>
- Foro: <https://discuss.cachyos.org/c/feedback/repository/11>
- Discord: [Canal de comentarios](https://discord.com/channels/862292009423470592/1150723027986813018)
