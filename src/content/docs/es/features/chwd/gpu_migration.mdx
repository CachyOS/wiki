:::note[Esta guía aplica si estás reemplazando tu GPU (NVIDIA ↔ AMD) en una instalación existente de CachyOS.]
:::

## Prerrequisitos
  - Tu GPU de reemplazo está instalada y conectada correctamente.
  - Asegúrate de que tu sistema esté completamente actualizado
    ```bash
    sudo pacman -Syu
    ```

### Pasos de migración

<Tabs>
    <TabItem label='De NVIDIA a AMD'>
        Aunque los controladores de AMD están incluidos en el Kernel de Linux, es posible que necesites limpiar la configuración antigua de NVIDIA y asegurarte de que los paquetes necesarios de AMD estén instalados.
        <Steps>
            1. Comprueba qué perfil de controlador de NVIDIA está instalado actualmente:
                ```bash
                sudo chwd --list-installed
                ```
            2. Elimina el perfil específico usando la opción `-r`:
                ```bash
                sudo chwd -r <nombre-del-perfil>
                ```
            3. Apaga tu sistema y procede a instalar tu GPU AMD.
            4. Después de arrancar. Usa chwd para detectar automáticamente tu GPU e instalar los paquetes correctos de AMD.
                ```bash
                sudo chwd -a
                ```
            5. Después de instalar los nuevos controladores, actualiza tu initramfs y la configuración del gestor de arranque
                > CachyOS incluye un hook de pacman que reconstruye automáticamente el initramfs cuando se añaden o eliminan controladores.
                > Esto asegura que los controladores correctos se carguen en el arranque.
                - GRUB: `sudo grub-mkconfig -o /boot/grub/grub.cfg`
                - systemd-boot: `sudo sdboot-manage gen`
                - Limine: `sudo limine-mkinitcpio`
            6. Reinicia para aplicar los cambios.
                ```bash
                sudo reboot
                ```
            7. Después de reiniciar, verifica que los controladores de AMD estén activos.
                ```bash
                vulkaninfo | grep "deviceName"
                ```
                o
                ```bash
                glxinfo | grep "OpenGL renderer"
                ```
                Si ves tu GPU AMD en la lista, los controladores funcionan correctamente.
        </Steps>
    </TabItem>
    <TabItem label='De AMD a NVIDIA'>
        <Steps>
            1. Limpia los paquetes restantes de AMD.
                ```bash
                sudo chwd -r amd
                ```
            2. Apaga tu sistema y procede a instalar tu GPU NVIDIA.
            3. Después de arrancar. Usa chwd para detectar automáticamente tu GPU e instalar los paquetes correctos de NVIDIA.
                ```bash
                sudo chwd -a
                ```
            4. Después de instalar los nuevos controladores, actualiza tu initramfs y la configuración del gestor de arranque
                > CachyOS incluye un hook de pacman que reconstruye automáticamente el initramfs cuando se añaden o eliminan controladores.
                > Esto asegura que los controladores correctos se carguen en el arranque.
                - GRUB: `sudo grub-mkconfig -o /boot/grub/grub.cfg`
                - systemd-boot: `sudo sdboot-manage gen`
                - Limine: `sudo limine-mkinitcpio`
            5. Reinicia para aplicar los cambios.
                ```bash
                sudo reboot
                ```
            6. Después de reiniciar, verifica que los controladores de NVIDIA estén activos.
                ```bash
                nvidia-smi
                ```
                o
                ```bash
                glxinfo | grep "OpenGL renderer"
                ```
                Si ves tu GPU NVIDIA en la lista, los controladores funcionan correctamente.
        </Steps>
    </TabItem>
</Tabs>
