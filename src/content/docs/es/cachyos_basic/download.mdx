## Verificando la integridad de la ISO con SHA256

:::caution[ADVERTENCIA]
Siempre tome el paso adicional de verificar la integridad de la ISO para evitar cualquier problema no deseado en la instalación o al crear un medio de arranque.
:::

**Versión Actual de la ISO:** `251209`

**Hash SHA256:** `e188d7041c867cedcf5dd9bfb519bc29951bc2ca5fbebacf1381cbd7639ba894`

<Tabs>

<TabItem label='Windows'>

<Steps>

1. Descargue el [archivo](https://mirror.cachyos.org/ISO/desktop/251209/cachyos-desktop-linux-251209.iso.sha256) que contiene el hash SHA256 **(Ábralo con un editor de texto, p. ej., Bloc de notas).**
2. Abra CMD o PowerShell como Administrador y [navegue](<https://www.wikihow.com/Change-Directories-in-Command-Prompt>) a la ruta donde se almacenan los archivos ISO y SHA256.
3. Ejecute el siguiente comando:
   ```powershell
   # Ejemplo:
   certUtil -hashfile cachyos-desktop-linux-251209.iso SHA256
   ```
4. Compare la salida del hash de certUtil con la del archivo descargado en el **Paso 1**. Si coinciden, puede proceder con la instalación de CachyOS.

</Steps>

</TabItem>

<TabItem label='Linux'>

<Steps>

1. Descargue el [archivo](https://mirror.cachyos.org/ISO/desktop/251209/cachyos-desktop-linux-251209.iso.sha256) que contiene el hash SHA256.
2. Abra una terminal, navegue al directorio que contiene el archivo `.sha256` y ejecute los siguientes comandos:
   ```sh
   # Ejemplo:
   cd Downloads/
   cat cachyos-desktop-linux-251209.iso.sha256
   # e188d7041c867cedcf5dd9bfb519bc29951bc2ca5fbebacf1381cbd7639ba894
   ```
3. Compare la salida del **Paso 2** y ejecute el siguiente comando para verificar el hash del archivo ISO:
   ```sh
   # Ejemplo:
   sha256sum cachyos-desktop-linux-251209.iso
   ```
4. Si los hashes del **Paso 2** y el **Paso 3** coinciden, puede proceder con la instalación de CachyOS.

</Steps>

</TabItem>

## Verificar la Autenticidad de la Imagen ISO (Linux)

Para verificar la autenticidad del archivo ISO y asegurarse de que es el oficial publicado por el equipo de desarrollo de CachyOS:

<Steps>

1. Importe la clave GPG para verificar la autenticidad:

   ```shell
   gpg --keyserver hkps://keys.openpgp.org --recv-key F3B607488DB35A47
   ```

2. Descargue el archivo ISO y su archivo de firma [.sig](https://cdn77.cachyos.org/ISO/desktop/251209/cachyos-desktop-linux-251209.iso.sig) y ejecute el siguiente comando (reemplazando `nombre_completo_iso.iso` con el nombre real del archivo ISO):
   ```shell
   gpg --verify nombre_completo_iso.iso.sig nombre_completo_iso.iso
   ```

   Si obtiene una salida de **Good signature** (Firma correcta), el archivo ISO es genuino:
   ```
   gpg: Signature made mar 09 dic 2025 17:45:13 -03
   gpg:                using RSA key 882DCFE48E2051D48E2562ABF3B607488DB35A47
   gpg: Good signature from "CachyOS <admin@cachyos.org>" [unknown]
   gpg: WARNING: This key is not certified with a trusted signature!
   gpg:          There is no indication that the signature belongs to the owner.
   Primary key fingerprint: 882D CFE4 8E20 51D4 8E25  62AB F3B6 0748 8DB3 5A47
   ```

</Steps>

:::danger
Si la salida no devuelve una cadena de **Good signature** (Firma correcta) o el ID de la clave no coincide, no utilice la imagen ISO. Asegúrese de que la imagen descargada provenga
de una fuente legítima de CachyOS, ya que una firma incorrecta podría sugerir que la ISO ha sido manipulada.
:::
