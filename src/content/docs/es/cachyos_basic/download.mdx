## Verificando la integridad de la ISO con SHA256

:::caution
Da siempre el paso adicional de verificar la integridad de la ISO para evitar cualquier problema no deseado durante la instalación o al crear un medio de arranque.
:::

**Versión Actual de la ISO:** `260809`

**Hash SHA256:** `959f6577f45e25ee9fd8c220fd221b08e4ea79412c7315c0f922dd6d86d5e33c`

<Tabs>

<TabItem label='Windows'>

<Steps>

1. Descarga el [archivo](https://mirror.cachyos.org/ISO/desktop/260809/cachyos-desktop-linux-260809.iso.sha256) que contiene el hash SHA256 **(Ábrelo con un editor de texto, p. ej., Bloc de notas)**.
2. Abre CMD o PowerShell como Administrador y [navega](<https://www.wikihow.com/Change-Directories-in-Command-Prompt>) a la ruta donde se almacenan los archivos ISO y SHA256.
3. Ejecuta el siguiente comando:
   ```powershell
   # Ejemplo:
   certUtil -hashfile cachyos-desktop-linux-260809.iso SHA256
   ```
4. Compara la salida del hash de certUtil con la del archivo descargado en el **Paso 1**. Si coinciden, puedes proceder con la instalación de CachyOS.

</Steps>

</TabItem>

<TabItem label='Linux'>

<Steps>

1. Descarga el [archivo](https://mirror.cachyos.org/ISO/desktop/260809/cachyos-desktop-linux-260809.iso.sha256) que contiene el hash SHA256.
2. Abre una terminal y navega al directorio que contiene tanto el archivo `.sha256` como el archivo `.iso`.
3. Ejecuta los siguientes comandos:
   ```sh
   # Ejemplo:
   cd ~/Downloads
   sha256sum -c cachyos-desktop-linux-260809.iso.sha256
   # cachyos-desktop-linux-260809.iso: OK
   ```
4. Si la salida del **Paso 3** es OK, puedes proceder con la instalación de CachyOS.

</Steps>

</TabItem>

<TabItem label='macOS'>

<Steps>

1. Descarga el [archivo](https://mirror.cachyos.org/ISO/desktop/260809/cachyos-desktop-linux-260809.iso.sha256) que contiene el hash SHA256.
2. Abre una terminal, navega al directorio que contiene el archivo `.sha256` y ejecuta los siguientes comandos:
   ```sh
   # Ejemplo:
   cd Downloads/
   cat cachyos-desktop-linux-260809.iso.sha256
   # 959f6577f45e25ee9fd8c220fd221b08e4ea79412c7315c0f922dd6d86d5e33c
   ```
3. Compara la salida del **Paso 2** con el hash del archivo ISO:
   ```sh
   # Ejemplo:
   shasum -a 256 cachyos-desktop-linux-260809.iso
   ```
4. Si los hashes del **Paso 2** y el **Paso 3** coinciden, puedes proceder con la instalación de CachyOS.

</Steps>

</TabItem>

## Verificar la Autenticidad de la Imagen ISO (Linux)

Para verificar la autenticidad del archivo ISO:

<Steps>

1. Importa la clave GPG como referencia para comparar:

   ```shell
   gpg --keyserver hkps://keys.openpgp.org --recv-key F3B607488DB35A47
   ```

2. Descarga el archivo ISO y su archivo de firma [.sig](https://cdn77.cachyos.org/ISO/desktop/260809/cachyos-desktop-linux-260809.iso.sig) y ejecuta el siguiente comando (reemplazando `full_iso_name.iso` con el nombre real del archivo ISO):
   ```shell
   gpg --verify full_iso_name.iso.sig full_iso_name.iso
   ```

   Si obtienes una salida con **Good signature**, el archivo ISO es genuino:
   ```
   gpg: Signature made dom 09 ago 2026 13:30:06 -03
   gpg:                using RSA key 882DCFE48E2051D48E2562ABF3B607488DB35A47
   gpg: Good signature from "CachyOS <admin@cachyos.org>" [unknown]
   gpg: WARNING: This key is not certified with a trusted signature!
   gpg:          There is no indication that the signature belongs to the owner.
   Primary key fingerprint: 882D CFE4 8E20 51D4 8E25  62AB F3B6 0748 8DB3 5A47
   ```

</Steps>

:::danger
Si la salida no devuelve la cadena **Good signature** o el ID de la clave no coincide, no utilices la imagen ISO. Una firma incorrecta sugiere que la ISO ha sido manipulada o está dañada.

Asegúrate de que la imagen descargada provenga de una [fuente legítima de CachyOS](/es/cachyos_basic/download#fuentes-oficiales-de-la-iso).
:::
