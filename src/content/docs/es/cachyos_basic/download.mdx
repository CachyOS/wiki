## Verificar la integridad de la ISO con SHA256

:::caution[ADVERTENCIA]
Siempre toma el paso adicional de verificar la integridad de la ISO para evitar problemas no deseados durante la instalación o al crear un medio de arranque.
:::

**Versión actual de la ISO:** `251129`

**Hash SHA256:** `2ab25f72ce8fece890b440cf9e260fc3d57ae4f5fb5308086f670240de02da7b`

<Tabs>

<TabItem label='Windows'>

<Steps>

1. Descarga el [archivo](https://mirror.cachyos.org/ISO/desktop/251129/cachyos-desktop-linux-251129.iso.sha256) que contiene el hash SHA256 **(Ábrelo con un editor de texto, por ejemplo, el Bloc de notas).**
2. Abre CMD o PowerShell como Administrador y [navega](<https://www.wikihow.com/Change-Directories-in-Command-Prompt>) a la ruta donde se guardan los archivos ISO y SHA256.
3. Ejecuta el siguiente comando:
   ```powershell
   # Ejemplo:
   certUtil -hashfile cachyos-desktop-linux-251129.iso SHA256
   ```
4. Compara el hash de salida de certUtil con el del archivo descargado en el **Paso 1**. Si coinciden, puedes proceder con la instalación de CachyOS.

</Steps>

</TabItem>

<TabItem label='Linux'>

<Steps>

1. Descarga el [archivo](https://mirror.cachyos.org/ISO/desktop/251129/cachyos-desktop-linux-251129.iso.sha256) que contiene el hash SHA256.
2. Abre una terminal, navega al directorio que contiene el archivo `.sha256` y ejecuta los siguientes comandos:
   ```sh
   # Ejemplo:
   cd Descargas/
   cat cachyos-desktop-linux-251129.iso.sha256
   # 2ab25f72ce8fece890b440cf9e260fc3d57ae4f5fb5308086f670240de02da7b
   ```
3. Compara la salida del **Paso 2** y ejecuta el siguiente comando para comprobar el hash del archivo ISO:
   ```sh
   # Ejemplo:
   sha256sum cachyos-desktop-linux-251129.iso
   ```
4. Si los hashes del **Paso 2** y el **Paso 3** coinciden, puedes proceder con la instalación de CachyOS.

</Steps>

</TabItem>

## Verificar la autenticidad de la imagen ISO (Linux)

Para verificar la autenticidad del archivo ISO y asegurarte de que es el oficial publicado por el equipo de desarrollo de CachyOS:

<Steps>

1. Importa la clave GPG para verificar la autenticidad:

   ```shell
   gpg --keyserver hkps://keys.openpgp.org --recv-key F3B607488DB35A47
   ```

2. Descarga el archivo ISO y su archivo de firma [.sig](https://cdn77.cachyos.org/ISO/desktop/251129/cachyos-desktop-linux-251129.iso.sig) y ejecuta el siguiente comando (reemplazando `nombre_completo_iso.iso` con el nombre real del archivo ISO):
   ```shell
   gpg --verify nombre_completo_iso.iso.sig nombre_completo_iso.iso
   ```

   Si obtienes una salida de **Good signature** (**Firma correcta**), el archivo ISO es genuino:
   ```
   gpg: Signature made sáb 29 nov 2025 13:10:22 -03
   gpg:                using RSA key 882DCFE48E2051D48E2562ABF3B607488DB35A47
   gpg: Good signature from "CachyOS <admin@cachyos.org>" [unknown]
   gpg: WARNING: This key is not certified with a trusted signature!
   gpg:          There is no indication that the signature belongs to the owner.
   Primary key fingerprint: 882D CFE4 8E20 51D4 8E25  62AB F3B6 0748 8DB3 5A47
   ```

</Steps>

:::danger
Si la salida no devuelve una cadena de **Good signature** (**Firma correcta**) o el ID de la clave no coincide, no uses la imagen ISO. Asegúrate de que la imagen descargada provenga
de una fuente legítima de CachyOS, ya que una firma incorrecta podría sugerir que la ISO ha sido manipulada.
:::
