## systemd-boot

systemd-boot tiene dos tipos de archivos de configuración: uno para el propio systemd-boot en `/boot/loader/loader.conf` y otro para cada entrada del kernel en `/boot/loader/entry`.

### Configuración del gestor

En este archivo de configuración, puede cambiar la opción predeterminada y el tiempo de espera de systemd-boot.

```shell
# /boot/loader/loader.conf

default @saved
timeout 5
#console-mode keep # Esta opción configura la resolución de la consola. ```

### Configuración de la línea de comandos del kernel

Ofrecemos una herramienta para facilitar la configuración de systemd-boot: [`sdboot-manage`](https://github.com/CachyOS/CachyOS-PKGBUILDS/tree/master/systemd-boot-manager).
Una de las ventajas de esta herramienta es la configuración global de la línea de comandos del kernel. El archivo de configuración de `sdboot-manage` se encuentra en `/etc/sdboot-manage.conf`.

Edite la línea `LINUX_OPTIONS=` en `/etc/sdboot-manage.conf` para cambiar los parámetros del kernel.

```shell
# /etc/sdboot-manage.conf
LINUX_OPTIONS="zswap.enabled=0 nowatchdog quiet splash"
```

Después de realizar los cambios, regenere todas las entradas de systemd-boot con el siguiente comando:

```shell
sudo sdboot-manage gen
```

## rEFInd

Al igual que [systemd-boot](/configuration/boot_manager_configuration#systemd-boot), rEFInd tiene dos archivos de configuración. `refind.conf`, ubicado en `boot/efi/EFI/refind`, se utiliza principalmente para modificar el comportamiento de rEFind, mientras que `/boot/refind_linux.conf` se utiliza para administrar las opciones de arranque.
`refind.conf` contiene comentarios detallados que explican todas sus opciones.

### Configuración de la línea de comandos del kernel

Para pasar los parámetros del kernel a la línea de comandos, modifique "Boot using default options" en `/boot/refind_linux.conf`

```shell
# /boot/refind_linux.conf

"Boot using default options" "root=PARTUUID=1cb353ec-7f03-4820-8b4b-03baf53a208f rw zswap.enabled=0 nowatchdog quiet splash"
```

Los cambios en ambos archivos de configuración surtirán efecto inmediatamente. No es necesario ejecutar un comando para guardar los cambios.

## GRUB

A diferencia de [systemd-boot](/configuration/boot_manager_configuration#systemd-boot) y [rEFInd](/configuration/boot_manager_configuration#refind),
GRUB solo tiene un archivo de configuración ubicado en `/etc/default/grub`. Hay documentación muy útil en este archivo que explica la función de cada opción.

### Ocultar el menú de arranque de GRUB

Para ocultar el menú de GRUB, simplemente configure las siguientes opciones como corresponda.

```shell
# /etc/default/grub

GRUB_TIMEOUT='0'
GRUB_TIMEOUT_STYLE=hidden
```

Pulse ESC para acceder a la linea de comandos de GRUB. Desde aquí, ejecute `normal` o `exit` para volver al menú familiar de arranque de GRUB.

### Configuración de la línea de comandos del kernel

Para pasar parámetros del kernel a la línea de comandos con GRUB, debemos editar `GRUB_CMDLINE_LINUX_DEFAULT` en `/etc/default/grub`.

```shell
# /etc/default/grub

GRUB_CMDLINE_LINUX_DEFAULT='nowatchdog zswap.enabled=0 quiet splash'
```

Cada vez que modificamos el archivo de configuración de GRUB, debemos rehacer la configuración con el siguiente comando:

```shell
sudo grub-mkconfig -o /boot/grub/grub.cfg
```

### Instantáneas BTRFS de arranque

:::note
Si su instalación de CachyOS es anterior a la versión de agosto, es posible que deba habilitar manualmente la función de instantáneas BTRFS de arranque.

De lo contrario, puede omitir esta sección, ya que está habilitada de forma predeterminada desde la versión de agosto.

:::

Para habilitar esta función, instale el paquete grub-btrfs-support:

```sh
sudo pacman -S grub-btrfs-support
```

Este paquete instala los scripts y los ganchos necesarios para detectar automáticamente las instantáneas de BTRFS y añadirlas al menú de GRUB.

Una vez instaladas, las instantáneas aparecerán en el menú de GRUB, de forma similar a como lo hace Limine.

## Limine

Limine es un gestor de arranque moderno conocido por su sencilla configuración. Esta guía cubre los conceptos básicos para empezar.

La configuración se realiza principalmente en `/boot/limine.conf` (o, a veces, en la partición del sistema EFI) para la configuración del menú, y en `/etc/default/limine` para los parámetros del kernel.

### Configuración del menú de arranque

Este archivo controla el comportamiento y la apariencia del menú de arranque. Los cambios realizados aquí surten efecto inmediatamente después de guardarlos; no se necesitan comandos adicionales.

* **Tiempo de espera:** Establece cuántos segundos espera Limine antes de iniciar automáticamente la entrada predeterminada.

```shell
# /boot/limine.conf

tiempo de espera: 5
```

* **Entrada predeterminada:** Especifica qué entrada del menú se inicia por defecto. Las entradas se numeran a partir del 1. Si no se establece, el valor predeterminado es 1.

```shell
# /boot/limine.conf

Default_entry: 2 # Inicia la segunda entrada por defecto
```

:::tip
Si `default_entry` apunta a un directorio (p. ej., `/+CachyOS`), el arranque automático se deshabilitará. Para iniciar automáticamente una entrada dentro de un directorio, `default_entry` debe apuntar directamente a ese número de entrada específico. :::

Ejemplo (`/boot/limine.conf`):

```shell
# /boot/limine.conf

timeout: 5
default_entry: 2 # Points directly to the 'linux-cachyos' entry below

/+CachyOS        # Entry 1: A directory (use /+ to expand by default)
//linux-cachyos  # Entry 2: The actual bootable entry
    protocol: linux
    kernel_path: boot():/vmlinuz-linux-cachyos
    cmdline: quiet splash root=UUID=... rw # Basic kernel parameters
    module_path: boot():/initramfs-linux-cachyos.img
```

:::note
`boot():/` se refiere a la raíz de la unidad de arranque.
:::

### Temas

Puede personalizar la apariencia del menú de arranque de Limine:

* **Fondo de pantalla:** Establezca una imagen de fondo. Los formatos compatibles incluyen BMP, PNG y JPEG.

  ```shell
  # /boot/limine.conf
  
  wallpaper: boot():/splash.png
  wallpaper_style: stretched # Opciones: 'stretched', 'tiled', 'centered'
  background: 000000 # Color de fondo (RRGGBB hexadecimal) si el estilo es 'centered'
  ```

* **Fuentes:** Usa un [archivo de fuente personalizado](https://github.com/viler-int10h/vga-text-mode-fonts) y ajusta su tamaño.

```shell
# /boot/limine.conf

term_font: boot():/custom_font.F16
term_font_scale: 2x2 # Ajusta el tamaño de la fuente, útil para pantallas de alta resolución.
```

* **Colores:** Modifica el texto y los colores de fondo de la terminal.

```shell
# /boot/limine.conf

term_background: 80000000 # Ejemplo: Negro semitransparente (AARRGGBB)
# Hay otras opciones de color disponibles, como term_foreground, etc.
```

### Configuración de comandos del kernel

En CachyOS, las entradas del kernel en el menú de arranque de Limine se gestionan automáticamente. Al instalar o eliminar kernels, `limine-mkinitcpio-hook` utiliza la utilidad `limine-entry-tool` en segundo plano para actualizar las entradas de arranque.

Si bien las entradas se gestionan automáticamente, puede configurar los parámetros del kernel (también conocidos como la línea de comandos del kernel) que se pasan al kernel al arrancar.

1. Edite el archivo de configuración: Modifique las variables `KERNEL_CMDLINE` en `/etc/default/limine`. Puede establecer parámetros predeterminados para todos los kernels o parámetros específicos para ciertos nombres de kernel (p. ej., `linux-cachyos`).

```shell
# /etc/default/limine

# Parámetros predeterminados para la mayoría de los kernels
KERNEL_CMDLINE[default]="quiet splash rd.udev.log_priority=3"

# Parámetros específicos para el kernel 'linux-cachyos'
KERNEL_CMDLINE["linux-cachyos"]="quiet splash mitigations=off"

# Parámetros para las entradas de reserva (si se generan)
# KERNEL_CMDLINE[fallback]="..."
```

2. **Aplicar los cambios:** Después de guardar `/etc/default/limine`, debe regenerar las imágenes de initramfs y actualizar las entradas de Limine para aplicar los nuevos parámetros del kernel. Ejecute el siguiente comando:

```bash
sudo limine-mkinitcpio
```

Este comando activa el proceso `mkinitcpio`, que incluye el `limine-mkinitcpio-hook`, lo que garantiza que los cambios en `/etc/default/limine` se incorporen a las entradas de arranque en `/boot/limine.conf`.
