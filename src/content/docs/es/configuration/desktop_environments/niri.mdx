:::note
Niri es un compositor de Wayland de mosaico desplazable que ofrece un enfoque único para la gestión de ventanas con su sistema de diseño basado en columnas.
:::

Nuestro objetivo principal con nuestra configuración es tener una configuración de Niri funcional que proporcione una experiencia de escritorio fluida e intuitiva, manteniendo la configuración simple y accesible.

Eche un vistazo a nuestras [Preguntas frecuentes sobre Niri.](/es/configuration/desktop_environments/niri#preguntas-frecuentes)

## Atajos de teclado

La mayoría de las combinaciones de teclas requieren el uso de la tecla mod, que en nuestro caso es la tecla de Windows (referida como SUPER), puedes cambiarla en el archivo de configuración.

### Control de aplicaciones

| Descripción | Tecla |
|-------------|-----|
| Abrir terminal | <Kbd linux="Super+Intro" /> |
| Abrir Wofi (Lanzador de programas) | <Kbd linux="Super+Espacio" /> |
| Abrir navegador (Firefox) | <Kbd linux="Super+B" /> |
| Abrir gestor de archivos | <Kbd linux="Super+E" /> |
| Cerrar ventana activa | <Kbd linux="Super+Q" /> |
| Bloquear pantalla | <Kbd linux="Super+Alt+L" /> |

## Preguntas frecuentes

### ¿Qué hace a Niri diferente de otros gestores de ventanas?

Niri utiliza un enfoque único de mosaico desplazable donde las ventanas se organizan en columnas que se pueden desplazar horizontalmente. Esto proporciona una metáfora de escritorio infinito que es particularmente útil para monitores ultrapanorámicos y flujos de trabajo que requieren muchas aplicaciones abiertas.

### ¿Cómo cambio la distribución del teclado?

Edita la sección `input` en tu archivo de configuración:

```txt title='Ejemplo'
input {
    keyboard {
        xkb {
            layout "es" // Cambia "de" por tu distribución preferida
        }
    }
}
```

### ¿Puedo personalizar los espacios y la apariencia de las ventanas?

Sí, puedes modificar la sección `layout`:

```txt title='Ejemplo'
layout {
    gaps 8 // Cambiar el tamaño del espacio

    focus-ring {
        width 2
        active-color "#tu-color"
        inactive-color "#tu-color"
    }
}
```

### ¿Cómo añado más aplicaciones de inicio?

Añádelas a la sección `startup`:

```txt title='Ejemplo'
spawn-at-startup "tu-aplicacion"
```

### ¿Para qué sirve la tecla de escape de emergencia?

El atajo `Super+Escape` está diseñado para restaurar el control cuando una aplicación a pantalla completa bloquea tus atajos de teclado. Desactiva cualquier inhibidor de atajos de teclado activo.

### ¿Cómo configuro múltiples monitores?

Descomenta y modifica la sección `output` para tus pantallas específicas. Ejecuta `niri msg outputs` para obtener los nombres correctos:

```txt title='Ejemplo'
output "DP-1" {
    mode "1920x1080@60.000"
    scale 1
}
```
