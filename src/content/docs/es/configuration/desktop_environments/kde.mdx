## Cómo instalar la sesión X11 que falta

Después de que KDE decidiera dividir su desarrollo en múltiples paquetes, la sesión X11 fue eliminada de la instalación por defecto.

```sh
sudo pacman -S plasma-x11-session kwin-x11
```

## Preguntas Frecuentes

### ¿Cómo puedo obtener la misma apariencia que la que se muestra en las capturas de pantalla de KDE, llamada "Emerald"?

- Es una combinación del tema Emerald + el tema de iconos Qogir, que no se instalan por defecto.
  - ```sh title='Instala ambos con el siguiente comando'
    sudo pacman -S cachyos-emerald-kde-theme-git qogir-icon-theme
    ```
  Aplica ambos en `Apariencia y estilo - Colores y temas`

### ¿Por qué SDDM se ve tan soso y anticuado?

- *Como no se aplica ningún tema de SDDM por defecto, SDDM recurrirá al tema clásico.*
  - **Aplica el tema Breeze como se muestra en la captura de pantalla**
