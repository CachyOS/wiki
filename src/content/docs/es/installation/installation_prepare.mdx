## Requisitos del sistema

Antes de preparar la instalación, asegúrate de que el ordenador que vas a utilizar cumple con los requisitos mínimos del sistema para poder ejecutar CachyOS. El instalador
utiliza un proceso de instalación en línea, por lo que es obligatoria una conexión a internet estable y relativamente rápida.

:::note[Máquinas Virtuales]
No se recomienda instalar CachyOS en una máquina virtual. Las VMs pueden tener problemas con una configuración incorrecta o pueden estar completamente rotas. Se recomienda instalar CachyOS directamente en el hardware (bare metal).
:::

<Tabs>

<TabItem label="Requisitos mínimos">

*   3 GB de RAM
*   30 GB de espacio de almacenamiento (HDD/SSD)
*   Conexión a internet estable

:::caution
Una conexión a internet inestable puede resultar en tiempos de instalación prolongados o, en el peor de los casos, en instalaciones fallidas.
:::

</TabItem>

<TabItem label="Requisitos recomendados">

*   8 GB de RAM
*   50 GB de espacio de almacenamiento (SSD/NVMe)
*   [CPU compatible con x86-64-v3](/es/installation/installation_prepare#soporte-para-niveles-de-microarquitectura-x86_64)
*   Velocidad de internet de 50 Mbps or superior
*   GPU NVIDIA (serie 900+; p. ej.: GTX 950), AMD +GCN 1.0 (p. ej.: AMD R7 240) o Intel (gráficos integrados serie HD o superior. Serie Arc)

</TabItem>

</Tabs>

## Creación de una unidad USB de arranque de CachyOS

Existen varias herramientas y métodos que se pueden utilizar para crear una unidad USB de arranque de CachyOS.

:::note
La unidad USB debe tener al menos 8GB de espacio disponible.
:::

### balenaEtcher

<Steps>

1. Descarga [balenaEtcher](<https://etcher.balena.io/>). balenaEtcher permite grabar una imagen en Linux, MacOS y Windows.
   Si se descargó un archivo `.zip`, extráelo y ejecuta el binario usando los siguientes comandos:
      ```sh
      # Extraer archivo zip:
      bsdtar xvf <nombre del archivo zip>
      # cd a la nueva carpeta:
      cd balenaEtcher-linux-x64/
      # Ejecutar balenaEtcher:
      ./balena-etcher
      ```
2. Conecta una unidad USB al ordenador.
3. Selecciona `Flash from file` y elige el archivo de imagen ISO de CachyOS.
4. Haz clic en `Select target` y elige la unidad USB que conectaste previamente.
5. Presiona `Flash` para iniciar el proceso de grabación.

</Steps>

:::note
balenaEtcher puede solicitar privilegios de administrador. Si es así, introduce tu contraseña y haz clic en `Authenticate`.
:::

### Interfaz de Línea de Comandos (Linux & MacOS)

<Steps>

1. Conecta una unidad USB.
2. Detecta la unidad USB conectada usando los siguientes comandos:
   ```sh
   # Linux
   # La unidad USB podría identificarse como, p. ej.: /dev/sda, por el modelo y tamaño del disco.
   sudo fdisk -l

   # MacOS
   # Las unidades USB se identifican como "/dev/diskY" donde "Y" podría ser 0, 1, etc.
   diskutil list
   ```
3. Copia el contenido de la iso a la unidad USB conectada ejecutando:
   ```sh
   # Reemplaza <usbdrive> con la etiqueta de la unidad.
   sudo dd bs=4M if=nombre_completo_de_la_iso.iso of=/dev/<usbdrive> status=progress oflag=sync
   ```
</Steps>

- `dd` copiará ahora el contenido del archivo ISO a la unidad USB conectada.

### Rufus (Solo Windows)

<Steps>

1. Conecta una unidad USB.
2. Descarga [Rufus](<https://rufus.ie/>) e instálalo, o ejecuta la versión portable.
3. En `Dispositivo` (`Device`), haz clic en la lista desplegable y selecciona la unidad USB conectada.
4. En `Elección de arranque` (`Boot selection`), haz clic en `SELECCIONAR` (`SELECT`) y localiza el archivo de imagen ISO de CachyOS.
5. Haz clic en `EMPEZAR` (`START`).

</Steps>

### Ventoy (Linux & Windows)

<Tabs>

<TabItem label="Linux">

<Steps>

1. Conecta una unidad USB.
2. Descarga [Ventoy](<https://www.ventoy.net/en/download.html>)
3. Descomprime Ventoy usando el siguiente comando:
   ```sh
   # Reemplaza la versión con la correcta, p. ej.: ventoy-1.1.07-linux.tar.gz
   bsdtar xvf ventoy-version-linux.tar.gz
   # cd a la nueva carpeta: (la versión puede cambiar)
   cd ventoy-1.1.07/
   ```
4. Ejecuta `VentoyGUI.x86_64` haciendo doble clic en él o a través de la terminal:
   ```sh
   # Pedirá privilegios de administrador, introduce tus credenciales
   ./VentoyGUI.x86_64
   ```
5. Selecciona la unidad USB conectada haciendo clic en `Dispositivo` (`Device`).
6. Haz clic en `Instalar` (`Install`).
7. Después de que termine de instalar Ventoy en la unidad USB conectada, cierra la ventana y coloca el archivo ISO de CachyOS en la nueva partición utilizable de la unidad.

</Steps>

</TabItem>

<TabItem label="Windows">

<Steps>
1. Conecta una unidad USB.
2. Descarga [Ventoy](<https://www.ventoy.net/en/download.html>)
3. Ejecuta `Ventoy2Disk.exe`
4. Selecciona la unidad USB conectada haciendo clic en `Dispositivo` (`Device`).
5. Haz clic en `Instalar` (`Install`).
6. Después de que termine de instalar Ventoy en la unidad USB, cierra la ventana y coloca el archivo ISO de CachyOS en la nueva partición utilizable de la unidad.
</Steps>

</TabItem>

</Tabs>
