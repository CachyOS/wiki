## Requisitos del sistema

Antes de preparar la instalación, asegúrese de que el ordenador que va a utilizar cumple con los requisitos mínimos del sistema para poder ejecutar CachyOS. El instalador
utiliza un proceso de instalación en línea, por lo que es obligatoria una conexión a internet estable y relativamente rápida.

:::note[Máquinas Virtuales]
No se recomienda instalar CachyOS en una máquina virtual. Las VM pueden tener problemas con una configuración incorrecta o pueden estar completamente rotas. Se recomienda instalar CachyOS en hardware real (bare metal).
:::

<Tabs>

<TabItem label="Requisitos mínimos">

*   3 GB de RAM
*   30 GB de espacio de almacenamiento (HDD/SSD)
*   Conexión a internet estable

:::caution
Una conexión a internet inestable puede resultar en tiempos de instalación prolongados o, en el peor de los casos, en instalaciones fallidas.
:::

</TabItem>

<TabItem label="Requisitos recomendados">

*   8 GB de RAM
*   50 GB de espacio de almacenamiento (SSD/NVMe)
*   [CPU compatible con x86-64-v3](/es/installation/installation_prepare#soporte-de-nivel-de-microarquitectura-x86_64)
*   Velocidad de internet de 50 Mbps o superior
*   GPU NVIDIA (serie 900+ - ej: GTX 950), AMD +GCN 1.0 (ej: AMD R7 240) o Intel (serie Integrated HD Graphics o superior. Serie Arc)

</TabItem>

</Tabs>

## Creación de una unidad USB de arranque de CachyOS

Existen varias herramientas y métodos que se pueden utilizar para crear una unidad USB de arranque de CachyOS.

:::tip
Guarde una copia de la ISO de CachyOS en la misma unidad o en una ubicación diferente, para que pueda usarla más tarde para solucionar problemas a través de chroot.
:::

:::note
La unidad USB debe tener al menos 8 GB de espacio disponible.
:::

### balenaEtcher

<Steps>

1. Descargue [balenaEtcher](<https://etcher.balena.io/>). balenaEtcher permite grabar una imagen en Linux, MacOS y Windows.
   Si se descargó un archivo `.zip`, extráigalo y ejecute el binario usando los siguientes comandos:
      ```sh
      # Extraer archivo zip:
      bsdtar xvf <nombre del archivo zip>
      # cd a la nueva carpeta:
      cd balenaEtcher-linux-x64/
      # Ejecutar balenaEtcher:
      ./balena-etcher
      ```
2. Conecte una unidad USB al ordenador.
3. Seleccione `Flash from file` y elija el archivo de imagen ISO de CachyOS.
4. Haga clic en `Select target` y elija la unidad USB que conectó anteriormente.
5. Presione `Flash` para iniciar el proceso de grabación.

</Steps>

:::note
balenaEtcher puede solicitar privilegios de administrador. Si es así, introduzca su contraseña y haga clic en `Authenticate`.
:::

### Interfaz de Línea de Comandos (Linux y MacOS)

<Steps>

1. Conecte una unidad USB.
2. Detecte la unidad USB conectada usando los siguientes comandos:
   ```sh
   # Linux
   # La unidad USB podría identificarse, por ejemplo, como /dev/sda, por el modelo y tamaño del disco.
   sudo fdisk -l

   # MacOS
   # Las unidades USB se identifican como "/dev/diskY" donde "Y" podría ser 0, 1, etc.
   diskutil list
   ```
3. Copie el contenido de la iso a la unidad USB conectada ejecutando:
   ```sh
   # Reemplace <usbdrive> con la etiqueta de la unidad.
   sudo dd bs=4M if=nombre_completo_iso.iso of=/dev/<usbdrive> status=progress oflag=sync
   ```
</Steps>

- `dd` copiará ahora el contenido del archivo ISO a la unidad USB conectada.

### Rufus (Solo para Windows)

<Steps>

1. Conecte una unidad USB.
2. Descargue [Rufus](<https://rufus.ie/>) e instálelo, o ejecute la versión portable.
3. En `Dispositivo`, haga clic en la lista desplegable y seleccione la unidad USB conectada.
4. En `Elección de arranque`, haga clic en `SELECCIONAR` y localice el archivo de imagen ISO de CachyOS.
5. Haga clic en `EMPEZAR`.

</Steps>

### Ventoy (Linux y Windows)

<Tabs>

<TabItem label="Linux">

<Steps>

1. Conecte una unidad USB.
2. Descargue [Ventoy](<https://www.ventoy.net/en/download.html>)
3. Descomprima Ventoy usando el siguiente comando:
   ```sh
   # Reemplace la versión con la correcta, ej: ventoy-1.1.07-linux.tar.gz
   bsdtar xvf ventoy-version-linux.tar.gz
   # cd a la nueva carpeta: (la versión podría cambiar)
   cd ventoy-1.1.07/
   ```
4. Ejecute `VentoyGUI.x86_64` haciendo doble clic en él o a través del terminal:
   ```sh
   # Pedirá privilegios de administrador, introduzca sus credenciales
   ./VentoyGUI.x86_64
   ```
5. Seleccione la unidad USB conectada haciendo clic en `Dispositivo`.
6. Haga clic en `Instalar`.
7. Después de que termine de instalar Ventoy en la unidad USB conectada, cierre la ventana y coloque el archivo ISO de CachyOS en la nueva partición utilizable de la unidad.

</Steps>

</TabItem>

<TabItem label="Windows">

<Steps>
1. Conecte una unidad USB.
2. Descargue [Ventoy](<https://www.ventoy.net/en/download.html>)
3. Ejecute `Ventoy2Disk.exe`
4. Seleccione la unidad USB conectada haciendo clic en `Dispositivo`.
5. Haga clic en `Instalar`.
6. Después de que termine de instalar Ventoy en la unidad USB, cierre la ventana y coloque el archivo ISO de CachyOS en la nueva partición utilizable de la unidad.
</Steps>

</TabItem>

</Tabs>
