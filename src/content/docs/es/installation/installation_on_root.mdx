## Requisitos

:::caution[El Arranque Seguro (Secure Boot), CSM y la compatibilidad con USB heredado (Legacy USB) deben estar desactivados en la configuración de la BIOS/UEFI al instalar en modo UEFI.]
Para configurar el Arranque Seguro después de la instalación, consulta la sección [Arranque Seguro](/es/configuration/secure_boot_setup).
:::

:::caution[Evita usar la opción "Instalar junto a" en Calamares, ya que puede generar complicaciones y no se recomienda.]
:::

:::tip
Es muy recomendable reiniciar la ISO después de un intento de instalación fallido.

De lo contrario, pueden ocurrir errores continuos durante el proceso de instalación.

Esto sucede porque el instalador no desmonta correctamente las particiones en una instalación fallida.

:::

## Métodos de Instalación

### Borrar disco

La opción "Borrar disco" en Calamares limpiará el disco seleccionado e instalará CachyOS en el destino.

<Steps>

1. Arranca desde la ISO y haz clic en **Lanzar instalador**

2. Selecciona el **Gestor de Arranque** preferido. Consulta la sección [Gestores de Arranque](/es/installation/boot_managers) para más información.

3. Establece el **Idioma** y la **Región/Zona Horaria** preferidos.

4. Configura la **Distribución del Teclado**

5. Selecciona **Borrar disco** y elige un [Sistema de archivos](/es/installation/filesystem).

6. Selecciona el **Entorno de Escritorio** de tu elección, consulta [Entornos de Escritorio](/es/installation/desktop_environments).

7. Personaliza qué paquetes deben o no deben instalarse durante el proceso de instalación.

8. Configura las credenciales de inicio de sesión.

9. Revisa cuidadosamente el resumen de la instalación en la página de Resumen. Procede con la instalación haciendo clic en **Instalar ahora** si todo parece correcto. De lo contrario, retrocede y realiza los cambios necesarios.

</Steps>

### Particionado Manual

:::note[Antes de proceder con el particionado del disco para una instalación UEFI.]
    ```sh title='Ejecuta este comando en la terminal'
    efibootmgr -v
    ```
Si la salida es: `EFI variables are not supported on this system.` (Las variables EFI no son compatibles con este sistema.), entonces el sistema ha arrancado en modo Legacy/BIOS y necesitas asegurarte de que el modo UEFI esté configurado en los ajustes de la BIOS/UEFI. Consulta la **[sección de Requisitos](/es/installation/installation_on_root#_top).**
:::

## Arranque Dual (Dual Boot)

:::note[Esta guía asume que Windows ya está instalado en el sistema y has decidido instalar CachyOS junto a él.]
:::

:::caution
Asegúrate de que el Inicio rápido de Windows esté desactivado.
:::

<Tabs>
    <TabItem label='systemd-boot'>
        **Necesitamos copiar los binarios EFI de Windows a la partición EFI de Linux para que el gestor de arranque pueda reconocerlos.**

        <Steps>
        1. Localiza la **partición EFI de Windows** con `lsblk`

            ```sh title='Ejecuta este comando en la terminal'
            lsblk -o NAME,FSTYPE,SIZE,MOUNTPOINT
            ```
            ```sh title='Ejemplo de salida'
                        NAME        FSTYPE   SIZE MOUNTPOINT
            zram0               15.3G [SWAP]
            nvme0n1            476.9G
            ├─nvme0n1p1 vfat     100M
            ├─nvme0n1p2           16M
            ├─nvme0n1p3 ntfs   234.4G
            ├─nvme0n1p4 ntfs     830M
            ├─nvme0n1p5 vfat       2G /boot
            └─nvme0n1p6 btrfs  239.6G /var/tmp
            ```
            Las particiones EFI casi siempre están formateadas como `FAT32/vfat`. Dado que `nvme0n1p1` no tiene un punto de montaje de Linux, podemos asumir que esta partición es la partición EFI de Windows.

        2. Monta temporalmente la partición EFI de Windows

            ```sh
            sudo mount /dev/nvme0n1p1 /mnt/WinBoot # Reemplaza `nvme0n1p1` con el nombre de la partición EFI de Windows.
            ```

        3. Copia los binarios EFI desde la **partición EFI de Windows** a la **partición EFI de Linux**:

            ```sh
            sudo cp -r /mnt/WinBoot/EFI/* /boot/EFI
            ```

        4. Desmonta la partición previamente montada, y Windows debería aparecer en el menú de arranque en el próximo inicio.

            ```sh
            sudo umount /mnt/WinBoot
            ```

        </Steps>
    </TabItem>

    <TabItem label='GRUB'>
        **GRUB utiliza os-prober para detectar automáticamente la partición EFI de Windows y añadirla al menú de arranque.**

        <Steps>
        1. Instala y ejecuta **os-prober**

            ```sh
            sudo pacman -S os-prober
            sudo os-prober
            ```

        2. Habilita **os-prober** en el archivo de configuración de GRUB

            ```sh title='Presiona CTRL+S para guardar y CTRL+Q para salir de Micro'
            sudo micro /etc/default/grub
            # /etc/default/grub
            # Probing for other operating systems is disabled for security reasons. Read
            # documentation on GRUB_DISABLE_OS_PROBER, if still want to enable this
            # functionality install os-prober and uncomment to detect and include other
            # operating systems.
            GRUB_DISABLE_OS_PROBER=false

            sudo grub-mkconfig -o /boot/grub/grub.cfg
            ```

            **Windows debería ahora estar añadido al menú de arranque.**

        </Steps>
    </TabItem>
</Tabs>
