## Antes de empezar

:::note[Si después de presionar "Launch Installer" solo aparecen GRUB y Limine como opciones de gestor de arranque, entonces el sistema ha arrancado en modo Legacy/BIOS.]
:::

:::danger[No está permitido instalar múltiples entornos de escritorio durante el proceso de instalación.]
:::

:::caution[Secure Boot y CSM deben estar deshabilitados en la configuración de la BIOS/UEFI al instalar en modo UEFI.]
Para configurar Secure Boot después de la instalación, consulta la sección [Secure Boot](/es/configuration/secure_boot_setup).

`Legacy USB Support` debe estar configurado en `Auto`
:::

:::caution
Las opciones `Install alongside` (Instalar junto a) y `Replace partition` (Reemplazar partición) no son 100% fiables y pueden hacer que la instalación falle.

Se **prefiere** el `Manual partitioning` (Particionado manual) al instalar CachyOS.
:::

:::tip
Es altamente recomendable reiniciar el ISO después de un intento de instalación fallido.

De lo contrario, pueden ocurrir errores continuos durante el proceso de instalación.

Esto sucede porque el instalador no desmonta correctamente las particiones en una instalación fallida.

:::

## Métodos de Instalación

### Particionado Manual

:::note[Antes de proceder con el particionado del disco para una instalación UEFI.]
    ```sh title='Ejecuta este comando en la terminal'
    efibootmgr -v
    ```
Si la salida es: `EFI variables are not supported on this system.` (Las variables EFI no son compatibles en este sistema), entonces el sistema ha arrancado en modo Legacy/BIOS y necesitas asegurarte de que el modo UEFI esté configurado en los ajustes de la BIOS/UEFI. Consulta la **[sección de Requisitos](/es/installation/installation_on_root#_top).**
:::

#### UEFI/GPT

La tabla de particiones varía para cada gestor de arranque. Por favor, sigue las instrucciones correctas para cada uno.

<Tabs>

<TabItem label='systemd-boot & rEFInd'>

<Steps>

1. Arranca desde el ISO y haz clic en el botón **Launch Installer** (Lanzar Instalador).

2. Establece el **Idioma** y la **Región/Zona Horaria** preferidos.

3. Configura la **Disposición del Teclado**.

4. Selecciona **Manual partitioning** (Particionado manual).

5. Crea una nueva partición con lo siguiente:
   - ##### Tamaño: **2048MiB**
   - ##### Sistema de archivos: **FAT32**
   - ##### Punto de montaje: **/boot**
   - ##### Banderas (Flags): **boot**

6. Crea otra partición para la **raíz (root)**:
   - ##### Tamaño: Al menos **20000MiB**
   - ##### Sistema de archivos: **Cualquiera**, consulta [Sistema de archivos](/es/installation/filesystem)
   - ##### Punto de montaje: **/**
   - ##### Banderas (Flags):

7. Verifica que **Install boot loader on:** (Instalar gestor de arranque en:) apunte a **/boot**.

8. Selecciona el **Entorno de Escritorio** de tu elección, consulta [Entornos de Escritorio](/es/installation/desktop_environments).

9. Personaliza qué paquetes deben o no deben instalarse durante el proceso de instalación.

10. Configura las credenciales de inicio de sesión.

11. Revisa cuidadosamente el resumen de la instalación en la página de Resumen. Procede con la instalación haciendo clic en **Install Now** (Instalar Ahora) si todo parece correcto. De lo contrario, vuelve atrás y haz los cambios necesarios.

</Steps>

### Borrar Disco

La opción "Erase Disk" (Borrar Disco) en Calamares borrará el disco seleccionado e instalará CachyOS en el destino.

<Steps>

1. Arranca desde el ISO y haz clic en **Launch Installer** (Lanzar Instalador).

2. Selecciona el **Gestor de Arranque** preferido. Consulta la sección [Gestores de Arranque](/es/installation/boot_managers) para más información.

3. Establece el **Idioma** y la **Región/Zona Horaria** preferidos.

4. Configura la **Disposición del Teclado**.

5. Selecciona **Erase Disk** (Borrar Disco) y elige un [Sistema de archivos](/es/installation/filesystem).

6. Selecciona el **Entorno de Escritorio** de tu elección, consulta [Entornos de Escritorio](/es/installation/desktop_environments).

7. Personaliza qué paquetes deben o no deben instalarse durante el proceso de instalación.

8. Configura las credenciales de inicio de sesión.

9. Revisa cuidadosamente el resumen de la instalación en la página de Resumen. Procede con la instalación haciendo clic en **Install Now** (Instalar Ahora) si todo parece correcto. De lo contrario, vuelve atrás y haz los cambios necesarios.

</Steps>

## Arranque Dual de Windows y CachyOS

:::note[Esta guía asume que Windows ya está instalado en el sistema y has decidido instalar CachyOS junto a él compartiendo la misma unidad.]
:::

:::caution
El arranque dual de Windows y Linux no es 100% fiable. Las actualizaciones de Windows pueden romper el gestor de arranque al sobrescribir la partición EFI.
En algunos casos, puede que nunca ocurran problemas, pero para algunos usuarios puede ser un problema recurrente.

Una forma de evitar este problema es instalar cada sistema operativo en unidades separadas.
:::

:::caution
Es posible que sea necesario cambiar el tamaño de la partición EFI, dependiendo del tamaño mínimo recomendado para el gestor de arranque de destino. Consulta **[Particionado Manual](/es/installation/installation_on_root#particionado-manual)**. Ten en cuenta que los sistemas de archivos FAT no se pueden redimensionar en el lugar. Para "redimensionar" correctamente la partición EFI FAT, se debe hacer una copia de seguridad del sistema de archivos EFI existente, usar una herramienta como `gparted` para cambiar el tamaño de la partición existente y reformatear la nueva partición, y luego copiar la estructura del sistema de archivos anterior de nuevo en la partición EFI.
:::

- Prerrequisitos

- Desactivar el Inicio Rápido y la Hibernación de Windows
  - Abre Windows PowerShell como Administrador y ejecuta el siguiente comando:
      ```ps
      powercfg /H off
      ```
    Reinicia el sistema para asegurarte de que los cambios surtan efecto.
- BitLocker de Windows debe estar desactivado
  - Comprobando si BitLocker está activado:
    ```ps title='Abre un Símbolo del sistema como administrador y ejecuta el siguiente comando'
    manage-bde -status
    ```
  Si el Método de Cifrado aparece como `None` (Ninguno), entonces BitLocker está desactivado.
- Secure Boot debe estar desactivado.
- Una partición vacía de +30GB
  - Guía sobre cómo reducir una partición de Windows:
    - Presiona `Win + R`, escribe `diskmgmt.msc` y presiona Enter para abrir la Administración de discos.
    - Identifica tu partición principal de Windows (normalmente C:) y haz clic derecho sobre ella.
    - Haz clic en `Shrink Volume...` (Reducir Volumen...) y especifica al menos **30720MB** (30GB) y haz clic en `Shrink` (Reducir).
- USB arrancable con CachyOS
  - Consulta la sección [Crear una unidad USB arrancable de CachyOS](/es/installation/installation_prepare#crear-una-unidad-usb-de-arranque-de-cachyos).

<Tabs>
    <TabItem label='systemd-boot'>
        **Necesitamos copiar los binarios EFI de Windows a la partición EFI de Linux para que el gestor de arranque pueda reconocerlos.**

        <Steps>
        1. Localiza la **partición EFI de Windows** con `lsblk`

            ```sh title='Ejecuta este comando en la terminal'
            lsblk -o NAME,FSTYPE,SIZE,MOUNTPOINT
            ```
            ```sh title='Salida de ejemplo'
                        NAME        FSTYPE   SIZE MOUNTPOINT
            zram0               15.3G [SWAP]
            nvme0n1            476.9G
            ├─nvme0n1p1 vfat     100M
            ├─nvme0n1p2           16M
            ├─nvme0n1p3 ntfs   234.4G
            ├─nvme0n1p4 ntfs     830M
            ├─nvme0n1p5 vfat       2G /boot
            └─nvme0n1p6 btrfs  239.6G /var/tmp
            ```
            Las particiones EFI casi siempre están formateadas como `FAT32/vfat`. Dado que `nvme0n1p1` no tiene un punto de montaje de Linux, podemos suponer que esta partición es la partición EFI de Windows.

        2. Monta temporalmente la partición EFI de Windows

            ```sh
            sudo mkdir /mnt/WinBoot
            sudo mount /dev/nvme0n1p1 /mnt/WinBoot # Reemplaza `nvme0n1p1` con el nombre de la partición EFI de Windows.
            ```

        3. Copia los binarios EFI de la **partición EFI de Windows** a la **partición EFI de Linux**:

            ```sh
            sudo cp -r /mnt/WinBoot/EFI/Microsoft/ /boot/EFI
            ```

        4. Desmonta la partición montada previamente, y Windows debería aparecer en el menú de arranque en el próximo inicio.

            ```sh
            sudo umount /mnt/WinBoot
            sudo rm -r /mnt/WinBoot
            ```

        </Steps>
    </TabItem>

    <TabItem label='GRUB'>
        **GRUB usa os-prober para detectar automáticamente la partición EFI de Windows y agregarla al menú de arranque.**

        <Steps>
        1. Instala y ejecuta **os-prober**

            ```sh
            sudo pacman -S os-prober
            sudo os-prober
            ```

        2. Habilita **os-prober** en el archivo de configuración de GRUB

            ```sh title='Presiona CTRL+S para guardar y CTRL+Q para salir de Micro'
            sudo micro /etc/default/grub
            # /etc/default/grub
            # Probing for other operating systems is disabled for security reasons. Read
            # documentation on GRUB_DISABLE_OS_PROBER, if still want to enable this
            # functionality install os-prober and uncomment to detect and include other
            # operating systems.
            GRUB_DISABLE_OS_PROBER=false

            sudo grub-mkconfig -o /boot/grub/grub.cfg
            ```

            **Windows debería ahora estar añadido al menú de arranque.**

        </Steps>
    </TabItem>
</Tabs>
