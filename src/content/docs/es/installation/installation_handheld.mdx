CachyOS ofrece una edición para dispositivos portátiles, como la Steam Deck, ROG Ally y Legion Go. Esta edición proporciona una experiencia similar a la de SteamOS con cambio de modo de juego, aplicaciones de juegos preinstaladas y más.

La Edición para Dispositivos Portátiles utiliza el planificador LAVD como el planificador de CPU predeterminado, el cual está optimizado para dispositivos portátiles. Esto resulta en una mejora de la tasa de fotogramas y la duración de la batería durante el juego.

La Edición para Dispositivos Portátiles usa `systemd-boot` como gestor de arranque. La selección del gestor de arranque no está disponible, a diferencia de la ISO predeterminada de CachyOS. Esto tiene como objetivo simplificar el proceso de instalación.

## Instalación en la Raíz

<Steps>

1. **Descargue** la última ISO para Dispositivos Portátiles desde el sitio web/foro.

2. [Flashee](/es/installation/installation_prepare) la ISO.

3. **Inicie** desde la ISO.

4. Haga clic en el botón **Lanzar Instalador**.

5. Calamares se abrirá. Siga las instrucciones en pantalla.

6. En el paso de particionado, por favor use la opción **Borrar Disco**. Si viene de otra distribución de Linux, es posible que haya estado usando un esquema de particiones diferente. Tenga en cuenta que la opción de reemplazar partición puede ser problemática y podría no funcionar como se espera.

7. Instale el Sistema.

</Steps>

Una vez completada la instalación, Calamares le pedirá que reinicie el dispositivo.

El primer arranque puede tardar un poco, ya que Steam se está descargando e iniciando.
Este proceso puede tardar hasta 2 minutos.


## Instalación con Arranque Dual

<Steps>

1. **Descargue** la última ISO para Dispositivos Portátiles desde el sitio web/foro.

2. [Flashee](/es/installation/installation_prepare) la ISO.

3. **Inicie** desde la ISO.

4. Haga clic en el botón **Lanzar Instalador**.

5. Calamares se abrirá. Siga las instrucciones en pantalla.

6. En el paso de particionado, necesita seleccionar **Particionado Manual** y crear las siguientes particiones:

    - 2GB /boot
    - XGB / (X puede ser cualquier cantidad de espacio de almacenamiento que desee asignar al sistema de archivos raíz)

7. Continúe con los pasos e instale el sistema.

</Steps>

Una vez completada la instalación, Calamares le pedirá que reinicie el dispositivo.

El primer arranque puede tardar un poco, ya que Steam se está descargando e iniciando.
Este proceso puede tardar hasta 2 minutos.
