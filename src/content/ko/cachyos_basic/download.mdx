## 공식 ISO 소스

CachyOS ISO 이미지는 다음 소스에서 다운로드할 수 있습니다:

*   [공식 웹사이트](<https://cachyos.org>)
*   [SourceForge](<https://sourceforge.net>)
*   [CachyOS 미러](<https://cachyos.org>)

## SHA256을 이용한 ISO 무결성 검증

:::caution
설치 중 발생할 수 있는 원치 않는 문제나 부팅 미디어 생성 오류를 방지하기 위해, 항상 ISO 파일의 무결성을 검증하는 단계를 거치시기 바랍니다.
:::

**현재 ISO 버전:** `260426`

**SHA256 해시:** `9a280d1e9732cfe50ab02db6a7e44ae0d9e6a10e6ea394f73192f7c14e263118`

<Tabs>

<TabItem label='Windows'>

<Steps>

1. SHA256 해시가 포함된 [파일](https://cachyos.orgdesktop/260426/cachyos-desktop-linux-260426.iso.sha256)을 다운로드합니다. **(메모장 같은 텍스트 편집기로 열어볼 수 있습니다.)**
2. 명령 프롬프트(CMD) 또는 PowerShell을 관리자 권한으로 실행한 뒤, ISO 파일과 SHA256 파일이 저장된 경로로 [이동](<https://wikihow.com>)합니다.
3. 다음 명령어를 실행합니다:
   ```powershell
   # 실행 예시:
   certUtil -hashfile cachyos-desktop-linux-260426.iso SHA256
   ```
4. certUtil 명령어가 출력한 해시값과 **1단계**에서 다운로드한 파일의 해시값을 비교합니다. 두 값이 일치하면 CachyOS 설치를 진행하셔도 좋습니다.

</Steps>

</TabItem>

<TabItem label='Linux'>

<Steps>

1. SHA256 해시가 포함된 [파일](https://cachyos.orgdesktop/260426/cachyos-desktop-linux-260426.iso.sha256)을 다운로드합니다.
2. 터미널을 열고 `.sha256` 파일과 `.iso` 파일이 모두 있는 디렉토리로 이동합니다.
3. 다음 명령어를 실행합니다:
   ```sh
   # 실행 예시:
   cd ~/Downloads
   sha256sum -c cachyos-desktop-linux-260426.iso.sha256
   # cachyos-desktop-linux-260426.iso: OK
   ```
4. **3단계**의 출력 결과가 OK로 나오면 CachyOS 설치를 진행하셔도 좋습니다.

</Steps>

</TabItem>

<TabItem label='macOS'>

<Steps>

1. SHA256 해시가 포함된 [파일](https://cachyos.orgdesktop/260426/cachyos-desktop-linux-260426.iso.sha256)을 다운로드합니다.
2. 터미널을 열고 `.sha256` 파일이 있는 디렉토리로 이동한 뒤 다음 명령어를 실행합니다:
   ```sh
   # 실행 예시:
   cd Downloads/
   cat cachyos-desktop-linux-260426.iso.sha256
   # 9a280d1e9732cfe50ab02db6a7e44ae0d9e6a10e6ea394f73192f7c14e263118
   ```
3. **2단계**의 출력 결과와 실제 ISO 파일의 해시값을 비교합니다:
   ```sh
   # 실행 예시:
   shasum -a 256 cachyos-desktop-linux-260426.iso
   ```
4. **2단계**와 **3단계**에서 얻은 해시값이 서로 일치하면 CachyOS 설치를 진행하셔도 좋습니다.

</Steps>

</TabItem>

</Tabs>

## ISO 이미지 진본성 검증 (Linux)

ISO 파일이 변조되지 않은 실제 공식 파일인지 서명을 확인하는 방법입니다:

<Steps>

1. 비교 기준으로 삼을 GPG 공개키를 가져옵니다:

   ```shell
   gpg --keyserver hkps://keys.openpgp.org --recv-key F3B607488DB35A47
   ```

2. ISO 파일과 해당 파일의 [.sig 서명 파일](https://cachyos.org)을 다운로드한 후 다음 명령어를 실행합니다 (`full_iso_name.iso` 부분을 실제 ISO 파일 이름으로 변경하세요):
   ```shell
   gpg --verify full_iso_name.iso.sig full_iso_name.iso
   ```

   출력 결과에 **Good signature** 문구가 포함되어 있다면 해당 ISO 파일은 원본이 맞습니다:
  ```
   gpg: Signature made dom 08 mar 2026 10:39:18 -03
   gpg:                using RSA key 882DCFE48E2051D48E2562ABF3B607488DB35A47
   gpg: Good signature from "CachyOS <admin@cachyos.org>" [unknown]
   gpg: WARNING: This key is not certified with a trusted signature!
   gpg:          There is no indication that the signature belongs to the owner.
   Primary key fingerprint: 882D CFE4 8E20 51D4 8E25  62AB F3B6 0748 8DB3 5A47
   ```

</Steps>

:::danger
출력 결과에 **Good signature**라는 문자열이 없거나 키 ID가 일치하지 않는 경우, 해당 ISO 이미지를 사용하지 마십시오. 잘못된 서명은 ISO 파일이 임의로 위변조되었거나 다운로드 중에 손상되었음을 의미합니다.

다운로드한 이미지가 신뢰할 수 있는 [공식 CachyOS 소스](/cachyos_basic/download#official-iso-sources)에서 가져온 것인지 다시 확인하시기 바랍니다.
:::
